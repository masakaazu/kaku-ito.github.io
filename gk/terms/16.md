## 16-1 DQN とその改良

### まとめ表

| 手法 | 改良点 |
| :-: | :-: |
| DQN（2013） | Q学習の行動価値を CNN で近似。画面の画素から直接学ぶ。経験再生・ターゲットネットワーク |
| ダブル DQN | 行動を選ぶネットワークと評価するネットワークを分け、行動価値の過大評価を減らす |
| デュエリングネットワーク | 状態価値 V と、行動ごとの有利さ（アドバンテージ）A に分けて推定する |
| ノイジーネットワーク | 重みにノイズを加え、ε-greedy の代わりに探索させる |
| Rainbow | DQN の6つの改良を組み合わせる |
| Ape-X | 多数のアクターが集めた経験を、優先度つき経験再生で1つの学習器が学ぶ（分散） |
| Agent57 | Atari の57ゲームすべてで人間の基準を超えた |

### DQN の基本

#### DQN（でぃーきゅーえぬ / Deep Q-Network）

- 意味：Q学習の行動価値関数を深いニューラルネットワーク（CNN）で近似する方法。DeepMind が 2013年に発表した
- ポイント：ゲームの画面の画素をそのまま入力し、将来の報酬を見積もる価値関数を出力する。Atari 2600 のゲームで、人間の専門家を超えたものもあった

#### 経験再生（けいけんさいせい / experience replay）

- 意味：エージェントの経験（状態・行動・報酬・次の状態）をメモリにためておき、そこからランダムに取り出して学習する工夫
- ポイント：続けて集めたデータどうしの相関を弱め、学習を安定させる。DQN の2つの工夫のひとつ。優先度つき経験再生は、学ぶことが多い経験を多く取り出す

#### ターゲットネットワーク（たーげっとねっとわーく / target network）

- 意味：学習の目標の値（教師信号）を計算するために、少し前の重みで固定しておく別のネットワーク
- ポイント：目標が毎回動いてしまうのを防ぎ、学習を安定させる。DQN のもうひとつの工夫

### DQN の改良

#### ダブル DQN（だぶるでぃーきゅーえぬ / Double DQN）

- 意味：行動を選ぶネットワークと、その行動の価値を評価するネットワークを分けて、Q学習の行動価値の過大評価を減らす DQN の改良
- ポイント：DQN は一部のゲームで行動価値を大きく見積もりすぎていた。表形式で考えられたダブルQ学習の考え方を深層学習に広げた

#### デュエリングネットワーク（でゅえりんぐねっとわーく / dueling network）

- 意味：ネットワークの出力を、状態価値関数 V と、行動ごとの有利さを表すアドバンテージ関数 A の2つに分けて推定する構造
- ポイント：価値がほぼ同じ行動がたくさんあるときに、よりよく評価できる。学習のアルゴリズムは変えず、ネットワークの形だけ変える

#### ノイジーネットワーク（のいじーねっとわーく / NoisyNet）

- 意味：ネットワークの重みに、学習で調整するノイズを加えて、行動にばらつきを持たせ、探索させる方法
- ポイント：ε-greedy（DQN）やエントロピー報酬（A3C）といった探索の工夫の代わりになる

#### Rainbow（れいんぼー / Rainbow）

- 意味：ダブル DQN・デュエリング・ノイジーネット・優先度つき経験再生など、DQN の6つの改良を1つにまとめた方法
- ポイント：組み合わせると、Atari でデータ効率・最終の性能ともに最高になった。7色＝DQN＋6つの改良

#### Ape-X（えいぷえっくす / Ape-X）

- 意味：たくさんのアクター（行動する役）がそれぞれの環境で集めた経験を、共有の経験再生メモリにためて、学習器（ラーナー）が学ぶ分散型の深層強化学習
- ポイント：行動と学習を切り離す。優先度つき経験再生で大事なデータを重点的に学ぶ

#### Agent57（えーじぇんとふぃふてぃせぶん / Agent57）

- 意味：Atari の57のゲームすべてで、人間の標準的な基準を超えた初めての深層強化学習のエージェント。DeepMind が 2020年に発表した
- ポイント：とても探索的な方策から、完全に活用する方策までの方策の集まりを学び、どれを優先するかを適応的に選ぶ

## 16-2 方策の学習とゲーム・言語への応用

### まとめ表

| 手法・事例 | 中身 |
| :-: | :-: |
| A3C | 複数のアクター・学習器が並列・非同期に学ぶ Actor-Critic |
| PPO | 方策を少しずつしか変えないようにした方策勾配法。実装が簡単で安定 |
| 連続値制御（DDPG） | ロボットの関節の角度のような連続した行動を扱う |
| OpenAI Five | Dota 2 で世界王者に勝った（2019年） |
| AlphaStar | StarCraft II でグランドマスター（2019年） |
| RLHF | 人のフィードバックで報酬モデルを作り、強化学習で言語モデルを調整 |

### 方策の学習

#### A3C（えーすりーしー / Asynchronous Advantage Actor-Critic）

- 意味：複数のアクター・学習器を並列に動かし、非同期に勾配を更新する Actor-Critic の方法。DeepMind が 2016年に発表した
- ポイント：並列に動かすと学習が安定する（経験再生を使わない）。GPU ではなく複数コアの CPU 1台で、半分の時間で当時の最高の性能を出した
- 語の意味：asynchronous＝非同期の、advantage＝有利さ

#### PPO（ぴーぴーおー / proximal policy optimization）

- 意味：方策が1回の更新で大きく変わりすぎないようにした目的関数で、同じデータを何回も使ってミニバッチで更新する方策勾配法。OpenAI が 2017年に発表した
- ポイント：TRPO（信頼領域方策最適化）のよさを持ちながら、ずっと実装が簡単。RLHF でもよく使われる
- 語の意味：proximal＝近くの

#### 連続値制御（れんぞくちせいぎょ / continuous control）

- 意味：ロボットの関節のトルクやハンドルの角度のように、行動が連続した値をとる制御の問題
- ポイント：DQN は行動が離散（ボタンのどれか）のときの方法。DDPG は決定論的方策勾配にもとづく Actor-Critic で、連続の行動空間を扱える

#### 報酬成形（ほうしゅうせいけい / reward shaping）

- 意味：本来の報酬に、ゴールに近づいたことを表す補助の報酬を足して、学習を速くする工夫
- ポイント：報酬がまれにしかもらえない（疎な）問題で効く。設計をまちがえると、意図しない行動を学ぶことがある

### ゲームと言語への応用

#### OpenAI Five（おーぷんえーあいふぁいぶ / OpenAI Five）

- 意味：OpenAI が作った、チーム対戦ゲーム Dota 2 をプレイする AI。2019年4月13日に世界王者のチームを破った
- ポイント：自己対戦（self-play）の強化学習を、大規模な分散学習で10か月続けた。長い時間の見通し・不完全な情報・連続で複雑な状態と行動が難しさ

#### アルファスター（AlphaStar）（あるふぁすたー / AlphaStar）

- 意味：DeepMind が作った、リアルタイム戦略ゲーム StarCraft II をプレイする AI。2019年8月にグランドマスターの位に達した
- ポイント：人のプレイの模倣学習と、多数のエージェントを競わせるマルチエージェントの強化学習を組み合わせた

#### マルチエージェント強化学習（MARL）（まるちえーじぇんときょうかがくしゅう / multi-agent reinforcement learning）

- 意味：同じ環境の中に、学習する複数のエージェントがいるときのふるまいを研究する強化学習の分野
- ポイント：ほかのエージェントも学んで変わるので、環境が一定ではなくなる。協力・競争の両方がある

#### RLHF（あーるえるえいちえふ / reinforcement learning from human feedback）

- 意味：人のフィードバック（どちらの出力がよいかの比較など）から報酬モデルを学習し、それを報酬にして強化学習（PPO など）で AI の方策を調整する方法
- ポイント：ChatGPT などの対話 AI の学習に使われる。InstructGPT は、人の手本での教師ありファインチューニング → 出力の順位づけで報酬モデル → RLHF の順に作った

## 16-3 ロボットと実世界への応用

### まとめ表

| 用語 | 中身 |
| :-: | :-: |
| sim2real | シミュレーションで学んだ方策を、実世界（実機）に移す |
| ドメインランダマイゼーション | シミュレータの見た目や物理をランダムに変えて学び、実世界を「変化のひとつ」にする |
| 残差強化学習 | 従来の制御でできる部分はそのまま使い、残り（残差）だけを強化学習で学ぶ |
| オフライン強化学習 | 新たにデータを集めず、すでに集めたデータだけで学ぶ |
| 状態表現学習 | 行動で変わる環境の特徴を、低い次元の表現として学ぶ |

### シミュレーションから実世界へ

#### sim2real（しむつーりある / simulation to reality）

- 意味：シミュレーションの中で学習した方策やモデルを、実世界のロボットなどに移して使うこと
- ポイント：シミュレーションならデータがたくさん取れて安全だが、実世界とのずれ（リアリティギャップ）があると、うまく動かない

#### ドメインランダマイゼーション（どめいんらんだまいぜーしょん / domain randomization）

- 意味：シミュレータの見た目（テクスチャ・光）や物理（重さ・摩擦）をランダムに変えて学習し、実世界でも通用するようにする方法
- ポイント：変化を十分に大きくすれば、実世界もモデルにとっては変化のひとつに見える

#### 残差強化学習（ざんさきょうかがくしゅう / residual reinforcement learning）

- 意味：従来のフィードバック制御でうまく解ける部分と、残り（残差）に分け、残差だけを強化学習で解く方法。最終の制御は2つの信号の和
- ポイント：接触や摩擦のように、物理のモデルで書きにくい部分を強化学習で補う

#### オフライン強化学習（おふらいんきょうかがくしゅう / offline reinforcement learning）

- 意味：前もって集めたデータだけを使い、環境とやりとりして新しいデータを集めずに方策を学ぶ強化学習
- ポイント：医療・教育・ロボットのように、試しに動かすと危ない、費用がかかる場面で役立つ

#### 状態表現学習（じょうたいひょうげんがくしゅう / state representation learning）

- 意味：エージェントの行動によって変わる環境の特徴を、低い次元で、時間とともに変わる表現として学ぶこと
- ポイント：次元を下げると次元の呪いを避けられ、強化学習の方策の学習も速くなる

## 16-4 データ生成

### まとめ表

| モデル | 中身 |
| :-: | :-: |
| GAN（2014） | 生成器と識別器を競わせる |
| DCGAN | GAN に CNN を使う。安定して画像を生成 |
| Pix2Pix | ペアの画像で学ぶ画像から画像への変換（条件つき GAN） |
| CycleGAN | ペアのない画像どうしの変換。サイクル一貫性損失 |
| 拡散モデル | ノイズを少しずつ加える過程を逆にたどってノイズを除き、画像を作る |
| NeRF | 何枚かの写真から、別の視点の画像を合成する（3次元の場面を表す） |

### GAN の仲間

#### 敵対的生成ネットワーク（GAN）（てきたいてきせいせいねっとわーく / generative adversarial network）

- 意味：データを作る生成器（generator）と、本物か生成器が作ったものかを見分ける識別器（discriminator）の2つのネットワークを競わせて学習する生成モデル。2014年にグッドフェローらが発表した
- ポイント：生成器は識別器がまちがえる確率を最大にするように学ぶ（ミニマックスゲーム）。理想の解では、生成器は訓練データの分布を再現し、識別器はどこでも 1/2 を出す
- 例：偽札をつくる人（生成器）と警察（識別器）のたとえ

#### DCGAN（でぃーしーがん / deep convolutional GAN）

- 意味：GAN の生成器と識別器に、構造にいくつかの制約を加えた CNN を使ったもの
- ポイント：プーリングの代わりにストライドつきの畳み込みを使い、バッチ正規化を入れるなどして、安定して画像を生成できるようにした

#### Pix2Pix（ぴくすつーぴくす / pix2pix）

- 意味：条件つきの GAN で、入力の画像から出力の画像への変換（画像から画像への翻訳）を学ぶ方法
- ポイント：入力と出力がペアになった訓練データが必要。ラベルの地図から写真を作る、線画から物を作る、白黒画像に色をつけるなど

#### CycleGAN（さいくるがん / CycleGAN）

- 意味：ペアになっていない2つの画像の集まり（例：馬とシマウマ）のあいだで画像を変換する方法
- ポイント：X → Y の変換 G と、Y → X の逆変換 F を同時に学び、F(G(X)) ≒ X になるようにするサイクル一貫性損失を使う

### そのほかの生成モデル

#### 拡散モデル（かくさんもでる / diffusion model）

- 意味：データにノイズを少しずつ加えていく過程（拡散過程）を逆向きにたどるように学習し、ランダムなノイズから少しずつノイズを取り除いてデータを作る生成モデル
- ポイント：高い品質の画像を生成でき、DALL-E 2 や Stable Diffusion などの画像生成 AI で使われる。GAN より学習が安定しやすいが、生成に何段階もかかる

#### NeRF（なーふ / neural radiance fields）

- 意味：何枚かの写真から、場面を「位置と見る向き → 密度と色」を返す全結合のネットワークで表し、新しい視点から見た画像を合成する方法
- ポイント：入力は5次元の座標（位置 x, y, z と見る向き θ, φ）。ボリュームレンダリングで画像にする

#### 画像生成・文章生成・音声生成（がぞうせいせい・ぶんしょうせいせい・おんせいせいせい / image, text, audio generation）

- 意味：生成モデルで、新しい画像・文章・音声を作るタスク
- 例：画像は GAN・拡散モデル、文章は GPT などの言語モデル（#15）、音声は WaveNet（#15）

## 問題演習

### 16-1

#### 問 gk-16-o01

- 問：Q学習の行動価値関数を CNN で近似し、ゲームの画面の画素から直接、制御の方策を学んだ 2013年の手法はどれか。
- ア：A3C
- イ：PPO
- ウ：DQN
- エ：AlphaStar
- 正解：ウ
- 解説：DQN は、Q学習の一種で訓練した CNN で、入力は生の画素、出力は将来の報酬を見積もる価値関数。Atari 2600 の7つのゲームで試し、3つで人間の専門家を超えた。
- アの意味：並列・非同期の Actor-Critic。
- イの意味：方策の変化を小さく抑えた方策勾配法。
- ウの意味：正しい。
- エの意味：StarCraft II の AI。
- 出典：オリジナル問題（根拠：Mnih ほか「Playing Atari with Deep Reinforcement Learning」（『The model is a convolutional neural network, trained with a variant of Q-learning, whose input is raw pixels and whose output is a value function estimating future rewards.』））

#### 問 gk-16-o02

- 問：DQN が一部のゲームで行動価値を大きく見積もりすぎる問題を、ダブルQ学習の考え方で減らした改良はどれか。
- ア：ダブル DQN
- イ：デュエリングネットワーク
- ウ：ノイジーネットワーク
- エ：Ape-X
- 正解：ア
- 解説：Q学習は条件によって行動価値を過大評価する。ダブル DQN は、表形式で考えられたダブルQ学習の考え方を大規模な関数近似に広げ、過大評価を減らして性能も上げた。
- アの意味：正しい。
- イの意味：状態価値とアドバンテージに分ける構造。
- ウの意味：重みにノイズを加えて探索する。
- エの意味：分散型の学習のしくみ。
- 出典：オリジナル問題（根拠：van Hasselt ほか「Deep Reinforcement Learning with Double Q-learning」（『The popular Q-learning algorithm is known to overestimate action values under certain conditions.』））

#### 問 gk-16-o03

- 問：ネットワークの出力を、状態価値関数と、状態に依存する行動のアドバンテージ関数の2つに分けて推定する構造はどれか。
- ア：ダブル DQN
- イ：Rainbow
- ウ：ターゲットネットワーク
