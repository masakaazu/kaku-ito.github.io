## 06-1 強化学習のしくみ

### まとめ表

| 学習 | 使うデータ | 目的 |
| :-: | :-: | :-: |
| 教師あり学習 | 入力と正解の組 | 正解を当てる |
| 教師なし学習 | 入力だけ | 構造を見つける |
| 強化学習 | 行動の結果の報酬 | 将来までの報酬の合計（収益）を最大にする |

### 基本の言葉

#### 強化学習（きょうかがくしゅう / reinforcement learning）

- 意味：エージェントが環境の中で状態を見て行動し、その結果の報酬を手がかりに、将来までの報酬の合計（収益）が最大になる行動のしかたを学ぶ方法
- ポイント：正解は与えられず、試行錯誤で学ぶ。報酬がすぐに来ないことも多い（遅れた報酬）

#### エージェント・環境・状態・行動・報酬（えーじぇんと・かんきょう・じょうたい・こうどう・ほうしゅう / agent, environment, state, action, reward）

- 意味：エージェントは学んで行動する主体、環境はエージェントのまわりの世界。エージェントは状態を観測して行動し、環境は次の状態と報酬を返す
- 例：ゲームなら、プレイヤーがエージェント、画面が状態、ボタン操作が行動、得点が報酬

#### 方策（ほうさく / policy）

- 意味：ある状態でどの行動をとるかを決めるルール。π（パイ）で表す
- ポイント：強化学習の目的は、収益が最大になる方策（最適方策）を見つけること

#### マルコフ決定過程（MDP）（まるこふけっていかてい / Markov decision process）

- 意味：状態・行動・状態の移り変わりの確率・報酬で、意思決定の問題を表すモデル。強化学習の問題はふつう MDP として表す
- ポイント：次の状態は今の状態と行動だけで決まり、それより前の歴史によらない（マルコフ性）

#### 割引率（わりびきりつ / discount rate）

- 意味：将来の報酬を、今の価値に直すときに掛ける 0〜1 の数。γ（ガンマ）で表す
- ポイント：γ が小さいほど目先の報酬を重視する。γ を使うと無限に続く場合も報酬の合計が発散しない

## 06-2 探索と活用

### まとめ表

| 方法 | 行動の選び方 |
| :-: | :-: |
| greedy（貪欲） | いつも、いま一番よさそうな行動 |
| ε-greedy 方策 | 確率 ε でランダム（探索）、1−ε で一番よさそうな行動（活用） |
| UCB 方策 | よさそうな度合いに、試した回数が少ないほど大きいおまけを足して選ぶ |

### バンディット

#### 探索と活用のトレードオフ（たんさくとかつようのとれーどおふ / exploration-exploitation trade-off）

- 意味：これまでの経験で一番よい行動を選ぶ（活用）と、もっとよい行動を見つけるため別の行動も試す（探索）のバランスをとる問題
- ポイント：活用ばかりだとよりよい行動を見逃し、探索ばかりだと報酬が増えない

#### バンディットアルゴリズム（ばんでぃっとあるごりずむ / bandit algorithm）

- 意味：当たりの確率がわからない複数のスロットマシン（多腕バンディット）を、どの順に何回引けば報酬が最大になるかを考える問題と、その解き方
- ポイント：状態が変わらない、いちばん単純な強化学習の問題。広告やウェブページのどの案を出すかの選択（A/B テストの代わり）に使う

#### ε-greedy 方策（いぷしろんぐりーでぃほうさく / ε-greedy policy）

- 意味：小さい確率 ε でランダムに行動を選び（探索）、それ以外は今いちばん価値が高い行動を選ぶ（活用）方法
- ポイント：ε が大きいほど探索が多い。学習が進むにつれて ε を小さくすることもある

#### UCB 方策（ゆーしーびーほうさく / upper confidence bound）

- 意味：行動の価値の推定に、「まだあまり試していない（推定があやふやな）行動ほど大きく」なる項を足し、その合計が最大の行動を選ぶ方法
- ポイント：ランダムではなく、不確かさにもとづいて探索する
- 語の意味：Upper Confidence Bound＝信頼区間の上限

## 06-3 価値の学習と方策の学習

### まとめ表

| アプローチ | 学ぶもの | 代表 |
| :-: | :-: | :-: |
| 価値ベース | 行動価値関数 Q(s,a) | Q 学習、SARSA、DQN |
| 方策ベース | 方策そのもの | 方策勾配法、REINFORCE |
| 両方 | 方策（Actor）と価値（Critic） | Actor-Critic、A3C |

### 価値関数

#### 状態価値関数（じょうたいかちかんすう / state-value function）

- 意味：ある状態から、ある方策に従って行動したときに、将来もらえる収益の期待値。V(s) と書く
- ポイント：「その状態にいることがどれだけよいか」を表す

#### 行動価値関数（こうどうかちかんすう / action-value function）

- 意味：ある状態である行動をとり、その後ある方策に従ったときに、将来もらえる収益の期待値。Q(s,a) と書き、Q値とも呼ぶ
- ポイント：Q値が一番大きい行動を選べばよいので、方策を直接持たなくてよい

#### Q学習（きゅーがくしゅう / Q-learning）

- 意味：行動価値関数 Q を、次の状態で一番大きい Q値を使って更新していく価値ベースの方法
- ポイント：実際に次にとる行動ではなく最大の Q値で更新するので、方策オフ型（off-policy）。1989年にワトキンスがまとめた。ディープラーニングと組み合わせたのが DQN

#### SARSA（さるさ / State-Action-Reward-State-Action）

- 意味：行動価値関数 Q を、次の状態で実際に選んだ行動の Q値を使って更新する価値ベースの方法
- ポイント：今の方策で選んだ行動で更新するので、方策オン型（on-policy）。Q学習との違いがよく問われる
- 語の意味：更新に使う S（状態）・A（行動）・R（報酬）・S（次の状態）・A（次の行動）の頭文字

### 方策を直接学ぶ

#### 方策勾配法（ほうさくこうばいほう / policy gradient method）

- 意味：方策をパラメータで表し、収益が大きくなる方向（勾配）にパラメータを直接更新する方法
- ポイント：行動が連続値（ロボットの関節の角度など）でも扱いやすい

#### REINFORCE（れいんふぉーす / REINFORCE）

- 意味：1エピソードを最後まで行って得た収益を使って方策の勾配を計算する、基本的な方策勾配法。1992年にウィリアムズが発表
- ポイント：モンテカルロ法で収益を求めるので、ばらつき（分散）が大きくなりやすい

#### Actor-Critic（あくたーくりてぃっく / actor-critic）

- 意味：行動を決める Actor（方策）と、その行動を評価する Critic（価値関数）を一緒に学ぶ方法
- ポイント：価値ベースと方策ベースを組み合わせたもの。A3C などのもとになった

#### モデルフリーとモデルベース（もでるふりー・もでるべーす / model-free, model-based）

- 意味：環境のしくみ（状態の移り変わりや報酬）のモデルを使うのがモデルベース、使わずに経験だけから学ぶのがモデルフリー
- ポイント：Q学習・SARSA・方策勾配法はモデルフリー。モデルフリーのほうが実装しやすく広く使われている

#### 強化学習の応用（きょうかがくしゅうのおうよう / applications of reinforcement learning）

- 意味：ゲーム・ロボットの制御・自動運転・広告の配信・在庫や空調の最適化など、行動を順番に決める問題に使われる
- 例：工場のロボットが試行錯誤で物のつかみ方を覚える

#### 問 gk-06-o06

- 問：強化学習の割引率の役割として正しいものはどれか。
- ア：学習の速さを決める
- イ：ランダムに行動する確率を決める

- ウの意味：正しい。
- エの意味：関係ない。
- 出典：オリジナル問題（根拠：R. S. Sutton・A. G. Barto「Reinforcement Learning: An Introduction」第2版（『The discount rate determines the present value of future rewards』））

#### 問 gk-06-o07

- 問：無限に続く問題で、報酬の合計を計算するときに割引率を使う利点として Spinning Up が挙げているものはどれか。

- イの意味：探索は必要。
- ウの意味：強化学習はもともと正解ラベルを使わない。
- エの意味：正しい。
