## 20-1 言葉の定義

### まとめ表

| 言葉 | 中身 | 条文 |
| :-: | :-: | :-: |
| 個人情報 | 生きている個人の情報で、特定の個人を識別できるもの（ほかの情報と簡単に照らし合わせて識別できるものもふくむ）、または個人識別符号をふくむもの | 第2条1項 |
| 個人識別符号 | 顔・指紋などの体の特徴を変換した符号、旅券番号・マイナンバーなど1人ずつちがう番号 | 第2条2項 |
| 要配慮個人情報 | 人種・信条・病歴・犯罪の経歴など、差別や偏見につながりうる情報 | 第2条3項 |
| 個人データ | 個人情報データベース等（検索できるように整理したもの）を作っている個人情報 | 第16条3項 |
| 保有個人データ | 事業者が開示・訂正・利用停止などをする権限を持つ個人データ | 第16条4項 |
| 個人関連情報 | 生きている個人の情報で、個人情報・仮名加工情報・匿名加工情報のどれでもないもの（Cookie・閲覧の履歴など） | 第2条7項 |

### 個人情報

#### 個人情報（こじんじょうほう / personal information）

- 意味：生存する個人に関する情報で、氏名・生年月日などで特定の個人を識別できるもの（ほかの情報と容易に照合して識別できるものもふくむ）、または個人識別符号をふくむもの
- ポイント：亡くなった人の情報は対象外。会社の名前など法人の情報も対象外。顔が写っていてだれか分かる画像や、声も個人情報になりうる

#### 個人識別符号（こじんしきべつふごう / individual identification code）

- 意味：それだけで特定の個人を識別できる符号として、政令で決めたもの。体の一部の特徴を変換した符号（顔認証のデータ・指紋・DNA など）と、1人ずつ割り当てた番号（旅券番号・基礎年金番号・運転免許証の番号・マイナンバーなど）がある
- ポイント：個人識別符号をふくむだけで個人情報になる。携帯電話の番号やメールアドレスは、ふつう個人識別符号には入らない

#### 要配慮個人情報（ようはいりょこじんじょうほう / special care-required personal information）

- 意味：人種・信条・社会的身分・病歴・犯罪の経歴・犯罪の被害を受けた事実など、本人への不当な差別や偏見が生じないよう、とくに配慮が必要な情報をふくむ個人情報
- ポイント：取得するときに、原則として本人の同意が必要（第20条2項）。オプトアウトでの第三者提供はできない

### データの単位

#### 個人データ（こじんでーた / personal data）

- 意味：個人情報データベース等（コンピュータなどで特定の個人情報を検索できるように体系的に整理した集まり）を作っている個人情報
- ポイント：安全管理・委託先の監督・第三者提供の制限は「個人データ」についての義務。整理されていない紙のメモの個人情報は個人データではない

#### 保有個人データ（ほゆうこじんでーた / retained personal data）

- 意味：個人情報取扱事業者が、開示・訂正・追加・削除・利用停止・消去・第三者提供の停止を行う権限を持つ個人データ
- ポイント：本人は、保有個人データの開示などを請求できる（第33条など）。委託されて預かっているだけのデータは、委託した側の保有個人データ

#### 個人情報取扱事業者（こじんじょうほうとりあつかいじぎょうしゃ / business operator handling personal information）

- 意味：個人情報データベース等を事業に使っている者。国の機関・地方公共団体・独立行政法人などは除く
- ポイント：会社の大きさや扱う人数は問わない（小さな会社や NPO、個人事業主もふくむ）

#### 個人情報保護委員会（こじんじょうほうほごいいんかい / Personal Information Protection Commission, PPC）

- 意味：個人情報保護法を所管し、事業者の監督やガイドラインの作成を行う日本の行政機関。2016年1月に設置
- ポイント：大きな漏えいなどが起きたら、事業者はこの委員会に報告する

## 20-2 個人情報取扱事業者の義務

### まとめ表

| 場面 | 義務 | 条文 |
| :-: | :-: | :-: |
| 取得 | 利用目的をできる限り特定、取得したら通知・公表。不正な手段で取得しない。要配慮個人情報は本人の同意 | 第17・20・21条 |
| 利用 | 利用目的の範囲をこえるなら本人の同意。違法・不当な行為を助長する使い方をしない | 第18・19条 |
| 保管 | 安全管理のための措置、従業者と委託先の監督。大きな漏えいは委員会に報告し本人に通知 | 第23〜26条 |
| 提供 | 第三者に提供するには原則として本人の同意（例外：法令・オプトアウトなど）。委託・事業の承継・共同利用は「第三者」にあたらない | 第27条 |
| 外国 | 外国にある第三者への提供は、原則として外国への提供を認める本人の同意 | 第28条 |
| 本人の請求 | 保有個人データの開示・訂正・利用停止などに対応 | 第33条〜 |

### 取得と利用

#### 利用目的の特定（りようもくてきのとくてい / specification of purpose of use）

- 意味：個人情報を扱うときは、その利用の目的をできる限り具体的に決めなければならない、という義務
- ポイント：「事業活動に使うため」のようなあいまいな書き方ではなく、何に使うかが分かるように書く。変えるときは、元の目的と関連があると合理的に認められる範囲まで

#### 目的外利用の制限（もくてきがいりようのせいげん / restriction by purpose of use）

- 意味：前もって本人の同意を得ないで、特定した利用目的に必要な範囲をこえて個人情報を扱ってはならない、という義務
- ポイント：法令にもとづく場合、人の生命・身体・財産を守るために必要で同意を得にくい場合などは例外
- 例：問い合わせ対応のために集めた情報を、同意なく AI の学習に使う（目的に入っていなければ目的外利用になりうる）

#### 適正な取得（てきせいなしゅとく / proper acquisition）

- 意味：うそやその他の不正な手段で個人情報を取得してはならない、という義務。要配慮個人情報は、原則として前もって本人の同意を得て取得する

### 保管

#### 安全管理措置（あんぜんかんりそち / security control measures）

- 意味：扱う個人データの漏えい・滅失・毀損を防ぐなど、安全管理のために必要で適切な措置をとる義務
- ポイント：組織・人・物理・技術の面からの対策。従業者の監督（第24条）、委託先の監督（第25条）もある

#### 委託（いたく / entrustment）

- 意味：個人データの扱いの全部または一部を、外部の業者などにまかせること
- ポイント：利用目的の範囲内での委託にともなう提供は「第三者提供」にあたらないので本人の同意は不要。そのかわり委託先を必要かつ適切に監督する義務がある
- 例：AI の開発会社に、学習のための顧客データの処理を任せる

#### 漏えい等の報告（ろうえいとうのほうこく / reporting of data breaches）

- 意味：個人の権利利益を害するおそれが大きい漏えいなど（要配慮個人情報、不正アクセス、1,000人をこえるもの など、委員会規則で決めたもの）が起きたとき、個人情報保護委員会に報告し、本人に通知する義務

### 提供

#### 第三者提供（だいさんしゃていきょう / provision to a third party）

- 意味：個人データを、本人と事業者以外の者に渡すこと。原則として前もって本人の同意が必要
- ポイント：法令にもとづく場合、人の生命などを守るために必要で同意を得にくい場合などは例外。委託・合併などの事業の承継・共同利用での提供は「第三者」にあたらない

#### オプトアウト（おぷとあうと / opt-out）

- 意味：本人が求めれば提供をやめることにしたうえで、決まった事項を前もって本人に知らせる（または容易に知れる状態にする）とともに個人情報保護委員会に届け出れば、同意なしで第三者提供できるしくみ
- ポイント：要配慮個人情報や、不正に取得した個人データ、オプトアウトで受け取った個人データは、オプトアウトで提供できない
- 語の意味：opt out＝（あとから）ぬける。反対は前もって同意をもらうオプトイン

#### 共同利用（きょうどうりよう / joint use）

- 意味：特定の者のあいだで個人データを一緒に使うこと。共同で使うこと・データの項目・使う者の範囲・利用目的・管理の責任者を、前もって本人に知らせていれば、第三者提供にあたらない

#### 外国にある第三者への提供（がいこくにあるだいさんしゃへのていきょう / provision to a third party in a foreign country）

- 意味：外国にある第三者に個人データを渡すときは、原則として「外国の第三者への提供を認める」という本人の同意が必要、というルール
- ポイント：日本と同じ水準の制度があると認めた国（EU・英国）や、決まった基準の体制を整えた相手なら例外。同意をもらうときは、その国の制度などの情報を本人に伝える
- 例：海外のクラウドの AI サービスに顧客の個人データを送る

#### 開示請求（かいじせいきゅう / request for disclosure）

- 意味：本人が、自分が識別される保有個人データを見せるよう事業者に求めること。電子のデータで渡す方法も選べる
- ポイント：ほかに訂正・追加・削除、利用停止・消去、第三者提供の停止の請求もある

## 20-3 仮名加工情報と匿名加工情報

### まとめ表

| | 仮名加工情報 | 匿名加工情報 |
| :-: | :-: | :-: |
| 加工 | ほかの情報と照らし合わせない限り、特定の個人を識別できないようにする | 特定の個人を識別できず、元の個人情報に戻せないようにする |
| 目的 | 主に社内での分析（AI の学習など） | 社外への提供・ほかの会社との利活用 |
| 第三者への提供 | 原則としてできない | 本人の同意なしでできる（項目などを公表） |
| 利用目的の変更 | できる（公表する） | ― |
| 本人の開示請求など | 対象外 | 対象外 |

### 加工

#### 仮名加工情報（かめいかこうじょうほう / pseudonymously processed information）

- 意味：氏名などの一部を削ったり、個人識別符号をすべて削ったりして、ほかの情報と照らし合わせない限り特定の個人を識別できないように加工した、個人に関する情報
- ポイント：2022年4月施行の改正で作られた。事業者の中での分析に使いやすくするためのもので、利用目的を変更しやすい。第三者への提供は原則できない。削った情報（削除情報等）は漏れないように管理する

#### 匿名加工情報（とくめいかこうじょうほう / anonymously processed information）

- 意味：特定の個人を識別できないように個人情報を加工し、さらに元の個人情報に戻せないようにした情報
- ポイント：決まった基準で加工し、ふくまれる項目を公表すれば、本人の同意なしで第三者に提供できる。ほかの情報と照らし合わせて本人を見つけようとすること（識別行為）は禁止

## 20-4 GDPR

### まとめ表

| 項目 | 中身 |
| :-: | :-: |
| 正式名 | EU 一般データ保護規則（規則 2016/679）。2018年5月から適用 |
| 域外適用 | EU に住む人の個人データを集める・処理するなら、EU の外の会社にも適用される |
| 越境移転 | EU の外への移転は、十分性認定がある国（日本など）か、標準契約条項などの保護措置があるときに認められる |
| 本人の権利 | 消去権（忘れられる権利）、データポータビリティの権利、プロファイリングへの異議など |
| 漏えい | データ侵害から72時間以内に監督機関に報告 |
| 制裁金 | とても高額（最大で全世界の売上高の4%などのいずれか高いほう） |

### GDPR

#### GDPR（じーでぃーぴーあーる / General Data Protection Regulation）

- 意味：EU の中のすべての個人のデータの保護を強め、統一するための EU の規則。EU 一般データ保護規則
- ポイント：EU に拠点がなくても、EU の人の個人データを扱えば適用される（域外適用）。日本は2019年に十分性認定を受け、日本と EU のあいだで個人データを移しやすくなった

#### 十分性認定（じゅうぶんせいにんてい / adequacy decision）

- 意味：EU の欧州委員会が、ある国の個人データの保護の水準が EU と同じくらい十分だと認めること。認められた国へは追加の保護措置なしで個人データを移せる

#### 消去権（忘れられる権利）（しょうきょけん / right to erasure, right to be forgotten）

- 意味：本人が、自分に関する個人データを消すよう求める権利（GDPR 第17条）

## 問題演習

### 20-1

#### 問 gk-20-o01

- 問：個人情報保護法の「個人情報」の説明として正しいものはどれか。
- ア：生存する個人に関する情報で、特定の個人を識別できるもの（ほかの情報と容易に照合して識別できるものもふくむ）、または個人識別符号をふくむもの
- イ：亡くなった人もふくむ、すべての人に関する情報
- ウ：会社などの法人に関する情報もふくむ
- エ：コンピュータで検索できるように整理された情報に限られる
- 正解：ア
- 解説：個人情報は、生存する個人に関する情報で、氏名・生年月日などで特定の個人を識別できるもの（ほかの情報と容易に照合して識別できるものをふくむ）か、個人識別符号をふくむもの。
- アの意味：正しい。
- イの意味：亡くなった人の情報は対象外。
- ウの意味：法人の情報は対象外（役員の氏名などは個人情報になる）。
- エの意味：それは個人データの説明。個人情報は整理されていなくてもよい。
- 出典：オリジナル問題（根拠：個人情報の保護に関する法律 第二条第一項（『この法律において「個人情報」とは、生存する個人に関する情報であって、次の各号のいずれかに該当するものをいう。』））

#### 問 gk-20-o02

- 問：次のうち、個人識別符号にあたるものはどれか。
- ア：携帯電話の番号
- イ：会社のメールアドレス
- ウ：顔認証のために顔の特徴をコンピュータで使えるように変換したデータ
- エ：住んでいる市の名前
- 正解：ウ
- 解説：個人識別符号には、体の一部の特徴をコンピュータで使うために変換した符号で、特定の個人を識別できるもの（顔認証のデータ・指紋など）と、旅券番号などの1人ずつ割り当てた番号がある。
- アの意味：ふつうは個人識別符号にあたらない（ほかの情報とあわせて個人情報になりうる）。
- イの意味：個人識別符号ではない（氏名がふくまれれば個人情報）。
- ウの意味：正しい。
- エの意味：それだけでは個人を識別できない。
- 出典：オリジナル問題（根拠：個人情報の保護に関する法律 第二条第二項第一号（『特定の個人の身体の一部の特徴を電子計算機の用に供するために変換した文字、番号、記号その他の符号であって、当該特定の個人を識別することができるもの』））

#### 問 gk-20-o03

- 問：本人の人種・信条・社会的身分・病歴・犯罪の経歴など、不当な差別や偏見が生じないよう取扱いにとくに配慮が必要な記述をふくむ個人情報を何というか。

- イ：要配慮個人情報
- ウ：仮名加工情報
- エ：個人関連情報
- 正解：イ

- アの意味：事業者が開示・訂正などをする権限を持つ個人データ。
- イの意味：正しい。
- ウの意味：ほかの情報と照合しない限り個人を識別できないように加工した情報。
- エの意味：個人情報・仮名加工情報・匿名加工情報のどれでもない個人に関する情報。
- 出典：オリジナル問題（根拠：個人情報の保護に関する法律 第二条第三項（『この法律において「要配慮個人情報」とは、本人の人種、信条、社会的身分、病歴、犯罪の経歴、犯罪により害を被った事実その他本人に対する不当な差別、偏見その他の不利益が生じないようにその取扱いに特に配慮を要するものとして政令で定める記述等が含まれる個人情報をいう。』））

#### 問 gk-20-o04

- 問：個人情報保護法で「個人データ」とは何か。
- ア：個人情報データベース等を構成する個人情報
- イ：すべての個人情報
- ウ：匿名加工情報のこと
- エ：インターネット上に公開された個人情報
- 正解：ア
- 解説：個人データは、個人情報データベース等（特定の個人情報を検索できるように体系的に構成したもの）を構成する個人情報。安全管理や第三者提供の制限は個人データについての義務。
- アの意味：正しい。
- イの意味：整理されていない個人情報は個人データではない。
- ウの意味：加工して個人を識別できなくした別の情報。
- エの意味：公開かどうかは関係ない。
- 出典：オリジナル問題（根拠：個人情報の保護に関する法律 第十六条第三項（『この章において「個人データ」とは、個人情報データベース等を構成する個人情報をいう。』））

#### 問 gk-20-o05

- 問：個人情報取扱事業者が、開示・内容の訂正・利用の停止・消去・第三者への提供の停止を行う権限を持つ個人データを何というか。
- ア：個人関連情報
- イ：要配慮個人情報
- ウ：匿名加工情報
