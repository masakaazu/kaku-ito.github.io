## 12-1 RNN の基本

### まとめ表

| 名前 | 中身 |
| :-: | :-: |
| RNN | 前の時刻の隠れ層の状態を、次の時刻の入力に戻す（循環がある） |
| エルマンネットワーク | 隠れ層の値を文脈ユニットに保存して戻す |
| ジョルダンネットワーク | 出力層の値を文脈ユニットに保存して戻す |
| 双方向 RNN | 前から読む RNN と後ろから読む RNN を組み合わせる |
| BPTT | 時間方向に展開して誤差逆伝播法を使う学習のしかた |
| 教師強制 | 学習のとき、次の時刻の入力に、予測ではなく正解を入れる |

### RNN

#### 回帰型ニューラルネットワーク（RNN）（かいきがたにゅーらるねっとわーく / recurrent neural network）

- 意味：ネットワークの中に循環があり、ある時刻の隠れ層の出力を次の時刻の入力にも使うニューラルネットワーク。リカレントニューラルネットワークともいう
- ポイント：過去の情報を隠れ状態として持ち越せるので、順番に意味がある時系列データを扱える。循環のない順伝播型ネットワーク（FFN）と対比される
- 語の意味：recurrent＝くり返し起こる

#### 時系列データ（じけいれつでーた / time series data, sequential data）

- 意味：時間や順番に沿って並び、前後の関係に意味があるデータ
- 例：文章（単語の並び）、音声、株価、センサーの値

#### 回帰結合層（かいきけつごうそう / recurrent layer）

- 意味：前の時刻の自分の出力を、今の時刻の入力と一緒に受け取る層。RNN の中心となる層

#### エルマンネットワーク（えるまんねっとわーく / Elman network）

- 意味：3層のネットワークに文脈ユニットを足し、隠れ層の値を文脈ユニットに写して次の時刻に戻す RNN。1990年にエルマンが発表した
- ポイント：ジョルダンネットワークとまとめて単純回帰型ネットワーク（SRN）と呼ぶ

#### ジョルダンネットワーク（じょるだんねっとわーく / Jordan network）

- 意味：エルマンネットワークに似ているが、文脈ユニットが隠れ層ではなく出力層から値を受け取る RNN。1986年にジョルダンが発表した
- ポイント：エルマン＝隠れ層から、ジョルダン＝出力層から、で区別する

#### 双方向 RNN（そうほうこうあーるえぬえぬ / bidirectional RNN）

- 意味：入力の列を前から読む RNN と、後ろから読む RNN の2つを組み合わせたもの
- ポイント：前後両方の文脈を使えるので、文全体が手元にあるタスク（品詞の判定など）で強い。リアルタイムの予測のように未来が見えない場面には使えない

### RNN の学習

#### BPTT（びーぴーてぃーてぃー / backpropagation through time）

- 意味：RNN を時刻ごとに展開して、時間をさかのぼって誤差逆伝播法を使う学習の方法
- ポイント：長い列では、時間をさかのぼるほど勾配を何度も掛け合わせるので、勾配消失・勾配爆発が起きやすい
- 語の意味：through time＝時間を通して

#### 教師強制（きょうしきょうせい / teacher forcing）

- 意味：RNN の学習で、次の時刻の入力に、モデル自身の予測ではなく正解のデータを入れる方法
- ポイント：前の予測の誤りが後ろに積み重なるのを防ぎ、学習が速くなる。推論のときは正解がないので、学習と推論で条件がずれる（露出バイアス）

#### RNN の勾配消失・勾配爆発（あーるえぬえぬのこうばいしょうしつ・こうばいばくはつ / vanishing / exploding gradient in RNN）

- 意味：長い時系列で、時間をさかのぼるにつれて勾配が小さくなりすぎる、または大きくなりすぎる問題
- ポイント：消失すると遠い過去の情報を学べない（長期依存性の問題）。消失には LSTM・GRU、爆発には勾配クリッピングで対処する

## 12-2 LSTM と GRU

### まとめ表

| | LSTM | GRU |
| :-: | :-: | :-: |
| 発表 | 1997年（ホッフライターとシュミットフーバー） | 2014年（Cho ら） |
| ゲート | 入力ゲート・忘却ゲート・出力ゲート | 更新ゲート・リセットゲート（出力ゲートなし） |
| 記憶 | 記憶セル（CEC）と隠れ状態 | 隠れ状態だけ |
| パラメータ | 多い | 少ない（計算が軽い） |

### ゲートつきの RNN

#### LSTM（えるえすてぃーえむ / long short-term memory）

- 意味：記憶セルと3つのゲート（入力・忘却・出力）を持ち、長い期間の情報を保てるようにした RNN。長・短期記憶
- ポイント：記憶セルの中を勾配がほぼそのまま流れるので、勾配消失を部分的に解決する。忘却ゲートは1999年にあとから加えられた
- 語の意味：long short-term memory＝長い短期記憶

#### ゲート機構（げーときこう / gating mechanism）

- 意味：0〜1 の値（シグモイド関数の出力）を掛けて、情報をどれだけ通すかを調整するしくみ
- ポイント：LSTM の入力ゲートはセルに新しい値を入れる度合い、忘却ゲートはセルに値を残す度合い、出力ゲートはセルの値を出力に使う度合いを決める

#### GRU（じーあーるゆー / gated recurrent unit）

- 意味：LSTM を簡単にした、更新ゲートとリセットゲートの2つのゲートを持つ RNN。ゲート付き回帰型ユニット
- ポイント：出力ゲートがなく、LSTM よりパラメータが少ない。性能は LSTM と同じくらいのことが多い

## 12-3 Seq2Seq と Attention

### まとめ表

| 方式 | 入力の文の伝え方 | 弱点・改良 |
| :-: | :-: | :-: |
| Seq2Seq（エンコーダ・デコーダ） | エンコーダが文全体を固定長のベクトル1つにまとめて渡す | 長い文で情報が入りきらない |
| Attention つき | デコーダが毎回、入力の各単語のどこに注目するかを重みで選んで取り込む | 長い文でも関係する部分を直接参照できる |

| Attention の要素 | 役割 |
| :-: | :-: |
| クエリ（Query） | 何を探しているか |
| キー（Key） | 各要素の見出し。クエリとの一致度を計算する |
| バリュー（Value） | 各要素の中身。一致度を重みにして足し合わせる |

### Seq2Seq

#### Seq2Seq（しーくえんすとぅしーくえんす / sequence to sequence）

- 意味：ある列（文など）を入力して、別の列を出力するモデル。エンコーダとデコーダの2つの RNN（LSTM）でできている
- ポイント：入力と出力の長さが違ってもよい。機械翻訳・要約・対話で使う
- 例：英語の文を入れてフランス語の文を出す

#### エンコーダ・デコーダ（えんこーだ・でこーだ / encoder-decoder）

- 意味：入力を内部の表現（ベクトル）に変えるエンコーダと、その表現から出力を作るデコーダを組み合わせた構造
- ポイント：初期の Seq2Seq は入力文を固定長のベクトル1つに押しこむので、長い文ほど性能が落ちた（ボトルネック）

### Attention

#### Attention（あてんしょん / attention）

- 意味：入力のどの部分に注目するかを重み（0〜1、合計 1）で表し、その重みで入力の情報を足し合わせるしくみ。注意機構
- ポイント：重みは入力に応じて毎回変わる（ソフトな重み）。クエリとキーの一致度をソフトマックス関数で重みにし、バリューの重み付き和をとる。Bahdanau ら（2014）が機械翻訳に使った

#### クエリ・キー・バリュー（くえり・きー・ばりゅー / query, key, value）

- 意味：Attention で使う3種類のベクトル。クエリとキーの内積などで一致度を計算し、それを重みにしてバリューを足し合わせる
- ポイント：「キーに対して値を返す、ぼんやりした辞書」とたとえられる

#### Source-Target Attention（そーすたーげっとあてんしょん / source-target attention, encoder-decoder attention）

- 意味：クエリをデコーダ側（出力側）から、キーとバリューをエンコーダ側（入力側）から取る Attention
- ポイント：出力の単語を作るときに、入力文のどの単語に注目するかを決める。Self-Attention と区別する

## 12-4 Transformer

### まとめ表

| 部品 | 役割 |
| :-: | :-: |
| Self-Attention | 同じ列の中の単語どうしの関係を重みづけする |
| Multi-Head Attention | 複数の Attention（ヘッド）を並べ、いろいろな関係を同時にとらえる |
| 位置エンコーディング | 単語の位置（順番）の情報を埋め込みに足す |
| マスク | デコーダの学習で、まだ出していない未来の単語を見ないようにする |
| エンコーダ | Self-Attention ＋ フィードフォワード層 |
| デコーダ | マスク付き Self-Attention ＋ Source-Target Attention ＋ フィードフォワード層 |

### Transformer

#### Transformer（とらんすふぉーまー / Transformer）

- 意味：RNN も畳み込みも使わず、Attention だけで作ったエンコーダ・デコーダのモデル。2017年に Google の研究者らが論文「Attention Is All You Need」で発表した
- ポイント：列を順番に処理する必要がないので並列に計算でき、学習がずっと速い。BERT や GPT のもとになった

#### Self-Attention（せるふあてんしょん / self-attention）

- 意味：クエリ・キー・バリューを同じ列から作り、列の中の各要素がほかのすべての要素とどれだけ関係するかを重みづけする Attention。自己注意
- ポイント：離れた単語どうしの関係も1回で直接とらえられる（RNN は何ステップもかかる）

#### Multi-Head Attention（まるちへっどあてんしょん / multi-head attention）

- 意味：クエリ・キー・バリューの重み行列の組（ヘッド）を複数用意し、並列に Attention を計算して、結果をつなげる方法
- ポイント：ヘッドごとに違う種類の関連（次の単語、動詞と目的語など）に注目できる

#### 位置エンコーディング（いちえんこーでぃんぐ / positional encoding）

- 意味：単語の位置の情報をベクトルにして、単語の埋め込みに足すこと
- ポイント：Attention そのものは順番を区別しないので、Transformer が語順を使うために欠かせない

#### マスク（ますく / masking）

- 意味：デコーダで、ある位置より後ろ（未来）の単語に注目できないように、Attention の重みを 0 にすること
- ポイント：学習のときに答えを先に見てしまうのを防ぐ

### 12-1

#### 問 gk-12-o01

- 問：回帰型ニューラルネットワーク（RNN）の説明として正しいものはどれか。
- ア：入力から出力へ一方向にだけ情報が流れるネットワーク

- 正解：ウ

- アの意味：順伝播型ニューラルネットワーク（FFN）。
- イの意味：CNN（#11）。
- ウの意味：正しい。
- エの意味：GAN（#16）。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「回帰型ニューラルネットワーク」（『このネットワーク内に循環が存在する、すなわちユニットの出力が何らかの経路で自身へ再び入力する場合、これを回帰型ニューラルネットワークという』））

#### 問 gk-12-o05

- イの意味：正しい。
- ウの意味：出力を作るとき、よさそうな候補を何本か残しながら探す方法（#15）。
- エの意味：学習済みモデルを別のタスクに使うこと（#17）。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Teacher forcing」（『Teacher forcing is an algorithm for training the weights of recurrent neural networks (RNNs).』））
