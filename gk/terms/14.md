## 14-1 画像認識のタスク

### まとめ表

| タスク | 出力 | 例 |
| :-: | :-: | :-: |
| 物体識別（画像分類） | 画像全体に1つのクラス | 「この写真は猫」 |
| 物体検出 | 物ごとの四角い枠（バウンディングボックス）とクラス | 「ここに猫、ここに犬」 |
| セマンティックセグメンテーション | 画素ごとのクラス（同じクラスの物は区別しない） | 道路・空・人の領域 |
| インスタンスセグメンテーション | 物ごとの領域（同じクラスでも1つずつ区別） | 人A・人Bを別々に |
| パノプティックセグメンテーション | 上の2つを合わせる（すべての画素にクラス、数えられる物は1つずつ） | 背景も人も全部 |
| 姿勢推定 | 人の関節の位置とつながり | 骨格の線 |

### タスク

#### 一般物体認識（いっぱんぶったいにんしき / generic object recognition）

- 意味：特定の物に限らず、身のまわりのいろいろな種類の物を認識するタスク
- ポイント：特定の顔や商品だけを見分ける特定物体認識と対比される

#### 物体識別（画像分類）（ぶったいしきべつ / image classification）

- 意味：画像に何が写っているかを、決まったクラスの中から1つ（または上位いくつか）答えるタスク
- ポイント：ImageNet のコンテスト（ILSVRC）でモデルが競われた

#### 物体検出（ぶったいけんしゅつ / object detection）

- 意味：画像の中のどこに何があるかを、物ごとの四角い枠（バウンディングボックス）とクラスで答えるタスク
- ポイント：候補の領域を選んでから分類する2段階の方式（R-CNN 系）と、1回で枠とクラスを出す1段階の方式（YOLO・SSD）がある

#### セマンティックセグメンテーション（せまんてぃっくせぐめんてーしょん / semantic segmentation）

- 意味：画像の画素1つ1つにクラスのラベルをつけるタスク
- ポイント：同じクラスの物が2つあっても区別しない（人が2人いてもまとめて「人」）

#### インスタンスセグメンテーション（いんすたんすせぐめんてーしょん / instance segmentation）

- 意味：物を1つずつ見つけ、それぞれの物の領域を画素単位で切り出すタスク
- ポイント：同じクラスでも1つずつ区別する。Mask R-CNN が代表

#### パノプティックセグメンテーション（ぱのぷてぃっくせぐめんてーしょん / panoptic segmentation）

- 意味：セマンティックセグメンテーション（すべての画素にクラス）とインスタンスセグメンテーション（物を1つずつ区別）を1つにまとめたタスク
- 語の意味：panoptic＝全体を一度に見わたす

#### 姿勢推定（しせいすいてい / pose estimation）

- 意味：画像の中の人の関節（肩・ひじ・ひざなど）の位置と、そのつながりを推定するタスク
- 例：OpenPose で、写真の中の何人もの人の骨格を同時に求める

## 14-2 画像分類のモデル

### まとめ表

| 年 | モデル | 工夫 |
| :-: | :-: | :-: |
| 2012 | AlexNet | ReLU・ドロップアウト・GPU。ILSVRC 2012 で圧勝 |
| 2014 | VGG | 3×3 の小さな畳み込みを重ねて 16〜19 層に深くする |
| 2014 | GoogLeNet | Inception モジュール（大きさの違う畳み込みを並列に）。ILSVRC 2014 優勝 |
| 2015 | ResNet | スキップ結合で 152 層。ILSVRC 2015 優勝 |
| 2016 | Wide ResNet | ResNet を浅く・幅広くする |
| 2016 | DenseNet | 各層を、それより後ろのすべての層につなぐ |
| 2017 | SENet | チャネルごとの重要度を学んで重みづけ（SE ブロック）。ILSVRC 2017 優勝 |
| 2017 | MobileNet | Depthwise Separable Convolution で軽量に |
| 2016〜 | NAS・MnasNet | ネットワークの構造を自動で探す（MnasNet は速度も考える） |
| 2019 | EfficientNet | 深さ・幅・解像度を、1つの係数でバランスよく大きくする |
| 2020 | Vision Transformer | 画像を小さなパッチに分け、Transformer で処理する |

### CNN の発展

#### AlexNet（あれっくすねっと / AlexNet）

- 意味：トロント大学のヒントンのチーム（クリジェフスキーら）が作った CNN。2012年の ILSVRC で、それまでの方法に大差をつけて優勝した
- ポイント：5つの畳み込み層と3つの全結合層。ReLU・ドロップアウト・GPU での学習を使った。ディープラーニングのブームのきっかけ（#03）

#### VGG（ぶいじーじー / VGG）

- 意味：3×3 の小さな畳み込みのフィルタだけを重ねて、16〜19 層まで深くした CNN。オックスフォード大学のグループが作った
- ポイント：深さが精度に効くことを示した。構造が単純で、特徴を取り出す部分としてよく使われる（VGG16 など）

#### GoogLeNet（ぐーぐるねっと / GoogLeNet）

- 意味：Inception モジュールを重ねた CNN。ILSVRC 2014 で優勝した
- ポイント：Inception モジュールは、1×1・3×3・5×5 の畳み込みとプーリングを並列に行って結果をつなぐ。1×1 畳み込みで計算量を抑え、深さと幅を増やしても計算の予算を一定に保った

#### ResNet（れずねっと / ResNet）

- 意味：スキップ結合（残差学習）で、152 層という深いネットワークを学習できるようにした CNN。ILSVRC 2015 で優勝（くわしくは #11）

#### Wide ResNet（わいどれずねっと / wide residual network）

- 意味：ResNet の層を減らして浅くし、そのかわりチャネル数（幅）を増やしたもの
- ポイント：とても深いだけの ResNet より、精度でも効率でもすぐれていた

#### DenseNet（でんすねっと / dense convolutional network）

- 意味：各層を、それより後ろのすべての層とつなぐ（前のすべての層の特徴マップを入力として使う）CNN
- ポイント：L 層なら L(L+1)/2 本の結合。勾配消失を和らげ、特徴を再利用し、パラメータを減らせる。ResNet は「足す」、DenseNet は「つなげる（連結）」
- 語の意味：dense＝密な

#### SENet（えすいーねっと / squeeze-and-excitation network）

- 意味：チャネルどうしの関係を学んで、チャネルごとの特徴の強さを調整し直す SE ブロックを入れた CNN
- ポイント：Squeeze（GAP でチャネルごとに1つの値に絞る）→ Excitation（チャネルごとの重みを出して掛ける）。少しの計算で精度が上がる。ILSVRC 2017 で優勝

#### MobileNet（もばいるねっと / MobileNet）

- 意味：Depthwise Separable Convolution を使って、スマートフォンなどでも動くように軽くした CNN（#11・#17）

#### NAS（ねっとわーくのこうぞうたんさく / neural architecture search）

- 意味：ニューラルネットワークの構造を、人が設計するのではなく自動で探す方法
- ポイント：Zoph と Le（2016）は、RNN で構造の記述を作り、検証データでの精度を報酬にして強化学習で学ばせた。人が設計した最良の構造に並ぶ構造を見つけた

#### MnasNet（えむなすねっと / MnasNet）

- 意味：モバイル向けに、精度だけでなく実際の端末での処理時間（レイテンシ）も目標に入れて、NAS で自動設計した CNN

#### EfficientNet（えふぃしぇんとねっと / EfficientNet）

- 意味：ネットワークの深さ・幅・入力画像の解像度の3つを、1つの係数（複合係数）でバランスよく大きくするモデル
- ポイント：少ないパラメータで高い精度。もとになる小さなモデルは NAS で探した

#### Vision Transformer（ViT）（びじょんとらんすふぉーまー / Vision Transformer）

- 意味：画像を小さなパッチ（例：16×16 画素）に分けて単語の列のように並べ、CNN を使わずに Transformer（#12）で分類するモデル
- ポイント：大量のデータで事前学習してから転移すると、CNN に負けない精度を、少ない計算資源で出せる

## 14-3 物体検出のモデル

### まとめ表

| 方式 | モデル | 特徴 |
| :-: | :-: | :-: |
| 2段階（領域の候補→分類） | R-CNN | 候補の領域ごとに CNN で特徴を取り出す。遅い |
| | Fast R-CNN | 画像全体を1回だけ CNN に通し、候補の領域を切り出して分類。速い |
| | Faster R-CNN | 領域の候補も CNN（RPN）で出す。ほぼ end-to-end |
| | Mask R-CNN | Faster R-CNN に、物ごとのマスクを出す枝を足す（インスタンスセグメンテーション） |
| 1段階（一度に出す） | YOLO | 画像全体を1回見て、枠とクラスの確率を回帰で出す。とても速い |
| | SSD | いくつもの大きさの特徴マップで、決まった形の枠（デフォルトボックス）ごとに予測 |
| 部品 | FPN | 深い層の意味の強い特徴を上から下へ流し、どの大きさの特徴マップでも検出しやすくする |

### 2段階の検出

#### R-CNN（あーるしーえぬえぬ / regions with CNN features）

- 意味：画像から物がありそうな領域の候補を選び、その候補ごとに CNN で特徴を取り出して分類する物体検出の方法
- ポイント：候補の領域ごとに CNN を通すので、とても時間がかかった。データが少ないときは、別のタスクで事前学習してから微調整するとよいことも示した

#### Fast R-CNN（ふぁすとあーるしーえぬえぬ / Fast R-CNN）

- 意味：画像全体を1回だけ CNN に通して特徴マップを作り、そこから候補の領域を切り出して分類する方法
- ポイント：R-CNN より学習が約9倍、テストが約213倍速く、精度も高い

#### Faster R-CNN（ふぁすたーあーるしーえぬえぬ / Faster R-CNN）

- 意味：領域の候補を出す部分も CNN（領域提案ネットワーク、RPN）にした方法
- ポイント：候補を出す部分が遅さの原因（ボトルネック）だったのを、検出のネットワークと特徴を共有する RPN で、ほぼコストなしにした

#### Mask R-CNN（ますくあーるしーえぬえぬ / Mask R-CNN）

- 意味：Faster R-CNN に、物ごとの領域（マスク）を予測する枝を並列に加えた、インスタンスセグメンテーションの方法

### 1段階の検出

#### YOLO（よろ / You Only Look Once）

- 意味：画像全体を1回見るだけで、枠の位置とクラスの確率を1つのネットワークで直接出す物体検出の方法
- ポイント：物体検出を「分類」ではなく「回帰」の問題として扱う。とても速く、リアルタイムで動く
- 語の意味：You Only Look Once＝1回見るだけ

#### SSD（えすえすでぃー / single shot multibox detector）

- 意味：1つのネットワークで、特徴マップの各位置に、いろいろな縦横比と大きさの決まった枠（デフォルトボックス）を置き、それぞれでクラスと枠のずれを予測する方法
- ポイント：解像度の違ういくつもの特徴マップの予測を組み合わせて、いろいろな大きさの物を見つける

#### FPN（えふぴーえぬ / feature pyramid network）

- 意味：CNN の層ごとの大きさの違う特徴マップを、上（深い層）から下へ横のつながりで組み合わせ、どの大きさでも意味の強い特徴マップを作る構造
- ポイント：小さな物も大きな物も見つけやすくなる。Faster R-CNN などの部品として使う

## 14-4 セグメンテーションと姿勢推定のモデル

### まとめ表

| モデル | 特徴 |
| :-: | :-: |
| FCN | 全結合層をなくし、すべて畳み込み層にする。どんな大きさの画像でも、同じ大きさの出力（画素ごとの分類）を出せる |
| SegNet | エンコーダ（VGG16 の畳み込み13層）とデコーダ。プーリングの位置を覚えてアップサンプリングに使う |
| U-Net | 縮小する経路と拡大する経路が U の字。同じ大きさどうしをスキップ結合でつなぐ。医療画像で少ない画像から学習 |
| PSPNet | ピラミッドプーリングモジュールで、大きさの違う範囲の全体の文脈を集める |
| DeepLab | Atrous Convolution（Dilated）で、解像度を保ったまま受容野を広げる |
| OpenPose | 部位どうしのつながり（PAF）を学び、複数の人の姿勢をリアルタイムに推定する |

### セグメンテーション

#### FCN（えふしーえぬ / fully convolutional network）

- 意味：全結合層を使わず、すべてを畳み込み層にしたネットワーク
- ポイント：どんな大きさの入力でも受け取れ、それに対応した大きさの出力（画素ごとの分類）を出せる。セマンティックセグメンテーションの基本

#### SegNet（せぐねっと / SegNet）

- 意味：エンコーダ（VGG16 の13の畳み込み層と同じ形）と、それに対応するデコーダ、画素ごとの分類層でできたセグメンテーションのネットワーク
- ポイント：デコーダは、エンコーダで最大値プーリングをした位置を覚えておき、それを使って特徴マップを元の解像度に戻す

#### U-Net（ゆーねっと / U-Net）

- 意味：画像を縮小しながら文脈をとらえる経路と、対称に拡大して位置を正確にする経路を、U の字に並べたネットワーク
- ポイント：同じ大きさの層どうしをスキップ結合でつなぐ。データ拡張を強く使い、少ない画像から学習できる。医療画像で広く使う

#### PSPNet（ぴーえすぴーねっと / pyramid scene parsing network）

- 意味：ピラミッドプーリングモジュールで、いろいろな大きさの領域ごとにプーリングして、画像全体の文脈を集めるセグメンテーションのネットワーク

#### DeepLab（でぃーぷらぼ / DeepLab）

- 意味：Atrous Convolution（Dilated Convolution、#11）を使い、特徴を計算する解像度を保ったまま視野を広げるセグメンテーションのモデル
- ポイント：大きさの違う Atrous Convolution を並べる ASPP も使う

### 姿勢推定

#### OpenPose（おーぷんぽーず / OpenPose）

- 意味：画像の中の複数の人の2次元の姿勢を、リアルタイムに推定する方法
- ポイント：体の部位どうしのつながりを表す Part Affinity Fields（PAF）を学び、どの部位がどの人のものかを結びつける。先に部位を見つけてから人にまとめる（ボトムアップ）ので、人数が増えても速い

## 問題演習

### 14-1

#### 問 gk-14-o01

- 問：画像の中のどこに何があるかを、物ごとの四角い枠（バウンディングボックス）とクラスで答えるタスクはどれか。
- ア：画像分類
- イ：セマンティックセグメンテーション
- ウ：物体検出
- エ：姿勢推定
- 正解：ウ
- 解説：物体検出は物の位置（枠）とクラスを答える。YOLO は、物体検出を空間的に分かれた枠とクラスの確率への回帰の問題として扱った。
- アの意味：画像全体に1つのクラスを答える。
- イの意味：画素ごとにクラスを答える。
- ウの意味：正しい。
- エの意味：人の関節の位置を答える。
- 出典：オリジナル問題（根拠：Redmon ほか「YOLO」（『Instead, we frame object detection as a regression problem to spatially separated bounding boxes and associated class probabilities.』））

#### 問 gk-14-o02

- 問：画像のすべての画素にクラスのラベルをつけ、同じクラスの物が複数あっても区別しないタスクはどれか。
- ア：インスタンスセグメンテーション
- イ：セマンティックセグメンテーション
- ウ：物体検出
- エ：パノプティックセグメンテーション
- 正解：イ
- 解説：セマンティックセグメンテーションは各画素にクラスのラベルを割り当てる。物を1つずつ区別して切り出すのはインスタンスセグメンテーション。
- アの意味：物を1つずつ区別する。
- イの意味：正しい。
- ウの意味：枠で答える。
- エの意味：両方を合わせたタスク。
- 出典：オリジナル問題（根拠：Kirillov ほか「Panoptic Segmentation」（『Panoptic segmentation unifies the typically distinct tasks of semantic segmentation (assign a class label to each pixel) and instance segmentation (detect and segment each object instance).』））

#### 問 gk-14-o03

- 問：セマンティックセグメンテーションとインスタンスセグメンテーションを1つにまとめたタスクはどれか。
- ア：パノプティックセグメンテーション
- イ：物体識別
- ウ：姿勢推定
- エ：一般物体認識
- 正解：ア
- 解説：パノプティックセグメンテーションは、すべての画素にクラスをつけるセマンティックセグメンテーションと、物を1つずつ見つけて切り出すインスタンスセグメンテーションをまとめたもの。
- アの意味：正しい。
- イの意味：画像全体のクラスを答えるタスク。
- ウの意味：人の関節の位置を答えるタスク。
- エの意味：いろいろな種類の物を認識すること一般。
- 出典：オリジナル問題（根拠：Kirillov ほか「Panoptic Segmentation」（『Panoptic segmentation unifies the typically distinct tasks of semantic segmentation (assign a class label to each pixel) and instance segmentation (detect and segment each object instance).』））

#### 問 gk-14-o04

- 問：写真に写った2人の人を「人A」「人B」と区別して、それぞれの領域を画素単位で切り出すタスクはどれか。
- ア：画像分類
- イ：セマンティックセグメンテーション
- ウ：物体検出
