## 03-1 機械学習

### まとめ表

| | ルールベース | 機械学習 | ディープラーニング |
| :-: | :-: | :-: | :-: |
| ルール | 人が書く | データから学ぶ | データから学ぶ |
| 特徴量 | 人が決める | 人が決める | 自分で学ぶ |
| 必要なデータ | 少ない | 多い | とても多い |
| 例 | エキスパートシステム | スパムフィルタ・レコメンド | 画像認識・生成AI |

### 機械学習とは

#### 機械学習（きかいがくしゅう / machine learning）

- 意味：コンピュータがデータ（経験）から学んで、仕事の成績を自動でよくしていくしくみと、その研究分野
- ポイント：ミッチェルの定義「タスク T の性能 P が経験 E で改善されるなら、E から学習したという」。名前は1959年にアーサー・サミュエルが作った
- 例：過去の売上（訓練データ）から明日の売上を予測する

#### ルールベースと機械学習（るーるべーすときかいがくしゅう / rule-based vs machine learning）

- 意味：ルールベースは人がルールを書き、機械学習はデータからルールを学ぶ
- ポイント：ルールベースは理由がわかりやすく少ないデータでも動くが、例外が多い問題に弱い。機械学習は複雑な問題に強いが、たくさんのデータが要り、理由が説明しにくい

#### 特徴量（とくちょうりょう / feature）

- 意味：対象を見分けるときに注目する特徴を、数値で表したもの
- ポイント：機械学習では人が特徴量を決めていた（特徴量設計）。ディープラーニングは特徴量も自分で学ぶ（特徴表現学習）

#### ビッグデータ（びっぐでーた / big data）

- 意味：量が多く、速く生まれ、種類もさまざまな、ふつうの方法では扱いにくい大きなデータ
- ポイント：量（Volume）・速度（Velocity）・多様性（Variety）の「3V」で表す。インターネットとスマートフォンで増え、機械学習が注目される背景になった

#### 次元の呪い（じげんののろい / curse of dimensionality）

- 意味：データの次元（特徴量の数）が増えると、学習に必要なデータや計算が爆発的に増え、うまく学習できなくなること
- ポイント：リチャード・ベルマンの言葉。特徴量を減らす次元削減（#05）で対策する

### 機械学習の応用

#### スパムフィルタ（すぱむふぃるた / spam filter）

- 意味：迷惑メールを自動で見分けて取り除くしくみ
- ポイント：単語の出現から迷惑メールの確率を学ぶ方法（ベイジアンフィルタ）が機械学習の代表的な応用

#### レコメンデーションエンジン（れこめんでーしょんえんじん / recommendation engine）

- 意味：利用者が好みそうな商品や作品をすすめるしくみ
- ポイント：商品の特徴から選ぶコンテンツベースフィルタリングと、似た利用者の行動から選ぶ協調フィルタリングがある（#05）

#### 統計的自然言語処理（とうけいてきしぜんげんごしょり / statistical natural language processing）

- 意味：大量の文章（コーパス）から、確率や統計で言葉のパターンを学んで言葉を処理する方法
- ポイント：ルールを書き切れない言葉の難しさを、データで補う。統計的機械翻訳もこの流れ

## 03-2 ニューラルネットワークからディープラーニングへ

### まとめ表

| 年 | 出来事 | 人物 |
| :-: | :-: | :-: |
| 1943 | 形式ニューロン | マカロックとピッツ |
| 1958 | パーセプトロン | ローゼンブラット |
| 1979 | ネオコグニトロン | 福島邦彦 |
| 1989 | LeNet（誤差逆伝播法で学ぶ CNN） | ルカン |
| 2006 | オートエンコーダで深い層の学習 | ヒントン |
| 2012 | AlexNet が ILSVRC で圧勝 | クリジェフスキー・ヒントンら |
| 2016 | AlphaGo がトップ棋士に勝つ | DeepMind |

### 神経回路をまねる

#### 人間の神経回路と形式ニューロン（にんげんのしんけいかいろとけいしきにゅーろん / neural circuits and formal neuron）

- 意味：脳の神経細胞（ニューロン）は、受けとった信号の合計がしきい値を超えると信号を出す。これを数式でまねたのが形式ニューロン
- ポイント：1943年にマカロックとピッツが発表。ニューラルネットワークの出発点

#### 単純パーセプトロン（たんじゅんぱーせぷとろん / simple perceptron）

- 意味：入力に重みを掛けて足し、しきい値で 0 か 1 を出す、学習できる1層のニューラルネットワーク
- ポイント：1958年にローゼンブラットが発表。線形分離できない問題（XOR など）は解けないとミンスキーらが指摘し、第1次ブームの冬につながった

#### ネオコグニトロン（ねおこぐにとろん / Neocognitron）

- 意味：1979年に福島邦彦が提唱した、視覚野の細胞をまねた多層のネットワーク。畳み込みニューラルネットワーク（CNN）の原型
- ポイント：特徴を取り出す S 細胞と、位置のずれを吸収する C 細胞を重ねる。学習は誤差逆伝播法ではない（add-if silent など）

#### LeNet（るねっと / LeNet）

- 意味：1989年にヤン・ルカンらが作った、誤差逆伝播法で学習する畳み込みニューラルネットワーク
- ポイント：手書きの郵便番号の数字の認識に使われた。ネオコグニトロンとの違いは学習方法

### ディープラーニングの躍進

#### ディープラーニング（でぃーぷらーにんぐ / deep learning）

- 意味：層を深く重ねたニューラルネットワークで、特徴量もデータから学ぶ機械学習の方法
- ポイント：2006年にヒントンらがオートエンコーダで深いネットワークを学習させたのがきっかけ。計算機の性能とインターネットのデータが追い風になった

#### ImageNet（いめーじねっと / ImageNet）

- 意味：2009年にフェイフェイ・リらが発表した、1400万枚を超える画像に写っている物の名前を付けたデータセット
- ポイント：画像認識の研究を大きく進めた

#### ILSVRC（あいえるえすぶいあーるしー / ImageNet Large Scale Visual Recognition Challenge）

- 意味：ImageNet を使った画像認識のコンテスト。2010〜2017年に毎年開かれた
- ポイント：2012年に AlexNet が圧勝し、ディープラーニングが注目されるきっかけになった。2015年には ResNet が人間の誤り率（約5%）を下回った
- 語の意味：Large Scale＝大規模、Visual Recognition＝視覚認識、Challenge＝競技会

#### AlexNet（あれっくすねっと / AlexNet）

- 意味：2012年の ILSVRC で、2位に大差をつけて優勝した畳み込みニューラルネットワーク
- ポイント：クリジェフスキーが、指導教官のヒントン、サツケバーと設計。GPU で学習し、ReLU とドロップアウトを使った

#### アルファ碁（AlphaGo）（あるふぁご / AlphaGo）

- 意味：Google DeepMind が作った囲碁のプログラム。2016年にトップ棋士の李世乭（イ・セドル）に4勝1敗で勝った
- ポイント：盤面を評価するバリューネットワークと、手を選ぶポリシーネットワーク（ディープラーニング）に、モンテカルロ木探索と強化学習を組み合わせた

#### 生成AI（せいせいえーあい / generative AI）

- 意味：文字などの入力（プロンプト）に対して、文章・画像・音声などを新しく作って返す AI
- ポイント：大規模言語モデル（#15）や拡散モデル（#16）が代表。いまは複数の種類のデータを扱えるマルチモーダルなものが増えた
