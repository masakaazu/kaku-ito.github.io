## 01-1 人工知能とは

### まとめ表

| レベル | 中身 | 例 |
| :-: | :-: | :-: |
| 1 単純な制御プログラム | 決められたとおりに動くだけ | エアコンの温度調整 |
| 2 古典的な人工知能 | 探索・推論・知識で、ふるまいの組み合わせが多い | 将棋のプログラム、エキスパートシステム |
| 3 機械学習 | データからルールや知識を学ぶ | 検索エンジン、スパムフィルタ |
| 4 深層学習（ディープラーニング） | 特徴量も自分で学ぶ | 画像認識、音声認識 |

### 定義と見方

#### 人工知能（じんこうちのう / Artificial Intelligence, AI）

- 意味：知的な機械、特に知的なコンピュータプログラムを作る科学と技術（マッカーシーの説明）
- ポイント：研究者によって定義が違い、決まった定義はない。「知能」そのものの定義がないため
- 語の意味：artificial＝人工の、intelligence＝知能

#### AIの4つのレベル（えーあいのよっつのれべる / four levels of AI）

- 意味：人工知能を「単純な制御プログラム」「古典的な人工知能」「機械学習」「深層学習」の4つに分ける見方
- ポイント：シラバスにある分け方。上のレベルほど、人が決めずに機械が自分で決める部分が増える
- 例：「温度が上がったら冷やす」だけのエアコンはレベル1

#### AI効果（えーあいこうか / AI effect）

- 意味：AIで実現できたことが「ただの計算で、本当の知能ではない」と見なされるようになる現象
- ポイント：そのため「AIはいつまでも完成しない」ように見える。チェスや音声認識がその例

#### エージェント（えーじぇんと / agent）

- 意味：まわりの環境をセンサーなどで感じとり、目的のために行動する主体。人工知能をエージェントとして捉える見方がある
- ポイント：ソフトウェアだけのエージェントもあり、ロボットのような体がなくてもよい

#### 人工知能とロボット（じんこうちのうとろぼっと / AI and robots）

- 意味：人工知能は「考える」部分の研究で、ロボットは体を動かす機械の研究。別の分野
- ポイント：人工知能がロボットに載っている必要はない。両者がまじわる研究もある

### AIブーム

#### 第1次AIブーム（だいいちじえーあいぶーむ / first AI boom）

- 意味：1950年代後半〜1960年代。「推論」と「探索」で特定の問題を解けるようになった時期
- ポイント：迷路や定理の証明のようなトイ・プロブレムは解けたが、現実の複雑な問題は解けず冬の時代へ

#### 第2次AIブーム（だいにじえーあいぶーむ / second AI boom）

- 意味：1980年代。「知識」を与えたエキスパートシステムが多く作られた時期
- ポイント：知識を人が全部書くのが大変（知識獲得のボトルネック）で、1995年ごろから再び冬の時代へ。日本の第五世代コンピュータもこの時期

#### 第3次AIブーム（だいさんじえーあいぶーむ / third AI boom）

- 意味：2000年代〜。ビッグデータで機械学習が実用化し、さらにディープラーニングが特徴量を自分で学ぶようになった時期
- ポイント：2016年のアルファ碁の勝利などで注目された

## 01-2 知能をどう確かめるか

### まとめ表

| 名前 | 年 | 中身 |
| :-: | :-: | :-: |
| チューリングテスト | 1950 | 文字の会話で人間と区別できなければ知能があるとみなす |
| ダートマス会議 | 1956 | 「人工知能」という言葉が初めて使われた |
| 中国語の部屋 | 1980 | 正しく答えても「理解」しているとは限らない |
| ローブナーコンテスト | 1991〜 | チューリングテストの形式で会話プログラムを競う |

### はじまりとテスト

#### ダートマス会議（だーとますかいぎ / Dartmouth Conference）

- 意味：1956年にジョン・マッカーシーらが開いた、人工知能という研究分野を確立した会議
- ポイント：提案書で初めて「artificial intelligence」という言葉が使われた。ミンスキー・シャノンらも構想に加わった

#### チューリングテスト（ちゅーりんぐてすと / Turing test）

- 意味：人間の判定者が、文字だけの会話で相手が人間か機械かを見分けられなければ、その機械は知的だとみなすテスト
- ポイント：アラン・チューリングが1950年の論文「Computing Machinery and Intelligence」で提案。声や見た目にまどわされないよう文字だけで行う

#### ローブナーコンテスト（ろーぶなーこんてすと / Loebner Prize）

- 意味：チューリングテストの形式で、最も人間らしいと判定された会話プログラムに賞を贈る大会
- ポイント：チューリングテストを実際に行う場の代表

### 理解と心

#### 中国語の部屋（ちゅうごくごのへや / Chinese Room）

- 意味：中国語がわからない人が、部屋の中でマニュアルどおりに記号を並べて返事をすれば、外からは中国語を理解しているように見えるという思考実験
- ポイント：哲学者ジョン・サールが1980年に発表。記号を正しく操作しても意味を理解しているとは限らない、と主張した。チューリングテストへの批判

#### 強いAIと弱いAI（つよいえーあいとよわいえーあい / strong AI and weak AI）

- 意味：強いAIは、正しくプログラムされたコンピュータには本当に心や理解が宿るという立場。弱いAIは、コンピュータは人間の知能のまねをする便利な道具だという立場
- ポイント：ジョン・サールが作った言葉。中国語の部屋は強いAIへの反論

## 01-3 人工知能の壁と未来

### まとめ表

| 問題 | 中身 |
| :-: | :-: |
| トイ・プロブレム | ルールが決まった簡単な問題しか解けない |
| フレーム問題 | 関係あることだけを選んで考えるのが難しい |
| シンボルグラウンディング問題 | 記号と現実の意味が結びつかない |
| 知識獲得のボトルネック | 知識を人が全部書き出すのが難しい |

### 人工知能の壁

#### トイ・プロブレム（といぷろぶれむ / toy problem）

- 意味：迷路やパズル、ゲームのように、ルールとゴールがはっきりした「おもちゃの問題」
- ポイント：第1次ブームのAIはトイ・プロブレムは解けたが、現実の問題は解けなかった

#### フレーム問題（ふれーむもんだい / frame problem）

- 意味：限られた処理能力の機械が、起こりうる無数の出来事の中から、いまの仕事に関係あることだけを選んで考えるのが難しいという問題
- ポイント：1969年にジョン・マッカーシーとパトリック・ヘイズが示した。「関係ないこと」を全部確かめていると時間がいくらあっても足りない

#### シンボルグラウンディング問題（しんぼるぐらうんでぃんぐもんだい / symbol grounding problem）

- 意味：コンピュータが扱う記号（シンボル）を、現実の世界の意味とどう結びつけるかという問題。記号接地問題とも呼ぶ
- ポイント：スティーブン・ハルナッド（ハーナッド）が命名。「シマウマ＝シマのある馬」と記号でわかっても、本物のシマウマを見てそれとわかるとは限らない

#### 身体性（しんたいせい / embodiment）

- 意味：知能には、体を通して世界とやりとりする経験が大事だという考え方
- ポイント：シンボルグラウンディング問題の解決には、体を持ち、感覚で世界を知ることが必要だという主張につながる

#### 知識獲得のボトルネック（ちしきかくとくのぼとるねっく / knowledge acquisition bottleneck）

- 意味：専門家の知識を聞き出し、コンピュータが扱える形に全部書き出すのにとても手間がかかるという問題
- ポイント：第2次ブームのエキスパートシステムが広がらなかった理由。機械学習で知識をデータから学ぶ方向へ進んだ

### 機械翻訳と未来

#### ルールベース機械翻訳（るーるべーすきかいほんやく / rule-based machine translation）

- 意味：文法や辞書のルールを人が書き、それに従って訳す方法
- ポイント：1980年代に一定の成果。ルールを書き切れないのが弱点

#### 統計的機械翻訳（とうけいてききかいほんやく / statistical machine translation）

- 意味：大量の対訳データから、単語や句の対応を確率として学んで訳す方法
- ポイント：1990年代の IBM のモデルから始まった。その後ニューラル機械翻訳に置きかわった

#### シンギュラリティ（しんぎゅらりてぃ / technological singularity）

- 意味：人工知能が人間の知能を大きく超え、技術の進歩が予測できないほど速くなる時点。技術的特異点
- ポイント：レイ・カーツワイルは2045年ごろと予想した。ヴァーナー・ヴィンジも1993年の論文で30年以内と述べた

## 問題演習

### 01-1

#### 問 gk-01-o01

- 問：人工知能学会が紹介しているマッカーシーの説明で、人工知能とは何とされているか。
- ア：人間の脳と同じしくみで動く機械
- イ：人間の代わりに体を動かすロボット
- ウ：知的な機械、特に知的なコンピュータプログラムを作る科学と技術
- エ：大量のデータから統計的に予測するソフトウェア
- 正解：ウ
- 解説：人工知能学会の「人工知能のFAQ」は、マッカーシーの説明を「知的な機械、特に、知的なコンピュータプログラムを作る科学と技術」と訳している。人の脳と同じしくみに限らない。
- アの意味：脳と同じしくみである必要はない。
- イの意味：ロボットの説明。AIはロボットに載っている必要はない。
- ウの意味：正しい。
- エの意味：機械学習の一部の説明で、AI全体の定義ではない。
- 出典：オリジナル問題（根拠：人工知能学会「人工知能のFAQ」（『知的な機械，特に，知的なコンピュータプログラムを作る科学と技術です．』））

#### 問 gk-01-o02

- 問：シラバスにある「人工知能の4つのレベル」の分け方はどれか。
- ア：弱いAI・強いAI・汎用AI・超知能
- イ：単純な制御プログラム・古典的な人工知能・機械学習・深層学習
- ウ：探索・推論・知識表現・学習
- エ：第1次ブーム・第2次ブーム・第3次ブーム・第4次ブーム
- 正解：イ
- 解説：シラバスは人工知能を「単純な制御プログラム」「古典的な人工知能」「機械学習」「深層学習」の4つのレベルに分けて説明できることを目標にしている。
- アの意味：AIの能力や心についての議論で使う言葉で、レベル分けではない。
- イの意味：正しい。
- ウの意味：AIの研究テーマの並びで、レベル分けではない。
- エの意味：歴史の区切りで、第4次ブームという区切りもシラバスにない。
- 出典：オリジナル問題（根拠：JDLA「G検定の試験出題範囲（シラバス）G2024#6～」1. 人工知能の定義（『人工知能のレベルを「単純な制御プログラム」「古典的な人工知能」「機械学習」「深層学習」の4つに分類し』））

#### 問 gk-01-o03

- 問：かつては知能の証明と考えられたチェスや音声認識が、実現されると「ただの計算」と見なされるようになる。この現象を何というか。
- ア：AI効果
- イ：フレーム問題
- ウ：シンギュラリティ
- エ：知識獲得のボトルネック

#### 問 gk-01-o04

- 問：人工知能とロボットの関係について、正しいものはどれか。
- ア：人工知能は必ずロボットの形をしている
- イ：ロボットは必ず人工知能を載せている
- ウ：人工知能とロボットは同じ研究分野の別名である

- イの意味：決められた動きだけをくり返す産業用ロボットもある。
- ウの意味：別の分野で、進歩も基本的には独立している。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：総務省「平成28年版 情報通信白書」人工知能（AI）とは（『人工知能（AI）がロボットなどの特定の形態に搭載されている必要はない』））

- 出典：オリジナル問題（根拠：人工知能学会「人工知能のFAQ」（『まだ無理です．どんな計算的な手続きが，我々人類が知能と呼びたいものであるかを一般的に特徴付けられないからです．』））

#### 問 gk-01-o08

- 問：第2次AIブームが1995年ごろに冬の時代を迎えた理由として、最もふさわしいものはどれか。
- ア：世の中の膨大な知識を、コンピュータが扱える形にすべて書き出すのが難しかった
