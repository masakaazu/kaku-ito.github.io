## 11-1 全結合層と畳み込み層

### まとめ表

| | 全結合層 | 畳み込み層 |
| :-: | :-: | :-: |
| つながり方 | 前の層のすべてのユニットとつながる | 前の層の狭い範囲（受容野）だけとつながる |
| 重み | ユニットの組ごとに別々 | 同じフィルタ（カーネル）を全体で共有 |
| パラメータ数 | 入力数×出力数＋出力数（バイアス） | カーネル縦×横×入力チャネル×出力チャネル＋出力チャネル |
| 得意なデータ | 位置関係のない特徴のベクトル | 画像・音声など、近くどうしに関係があるデータ |

| 出力の大きさ（1辺） | ＝（入力＋2×パディング−カーネル）÷ストライド＋1 |
| :-: | :-: |
| 例 | 入力 32、カーネル 3、パディング 1、ストライド 1 → 32 |

### 全結合層

#### 全結合層（ぜんけつごうそう / fully connected layer）

- 意味：前の層のすべてのユニットが、次の層のすべてのユニットとつながっている層。重み付き和（線形関数）を計算する
- ポイント：パラメータ数は「入力の数×出力の数＋バイアス（出力の数）」で、多くなりやすい。CNN では最後の分類の部分で使うことが多い
- 例：入力 100、出力 10 なら、100×10＋10＝1,010 個

### 畳み込み層

#### 畳み込みニューラルネットワーク（CNN）（たたみこみにゅーらるねっとわーく / convolutional neural network）

- 意味：畳み込み層を使うニューラルネットワーク。画像認識でよく使う
- ポイント：畳み込み層とプーリング層をくり返して特徴を取り出し、最後に全結合層などで分類する
- 語の意味：convolution＝畳み込み

#### 畳み込み操作（たたみこみそうさ / convolution）

- 意味：小さな重みの行列（カーネル）を入力の上でずらしながら重ね、重なった部分の積の和を計算していく操作
- ポイント：同じカーネルを画像全体に使う（重みの共有）ので、全結合層よりパラメータがずっと少ない。物の位置がずれても同じ特徴を見つけやすい

#### カーネル（フィルタ）（かーねる・ふぃるた / kernel, filter）

- 意味：畳み込みで使う小さな重みの行列。3×3 や 5×5 が多い
- ポイント：カーネルの値とバイアスが学習で決まる。カーネル1枚ごとに1枚の特徴マップができる

#### 特徴マップ（とくちょうまっぷ / feature map）

- 意味：畳み込み（やプーリング）の結果できる、特徴の強さの地図。次の層への入力になる
- ポイント：カーネルの枚数が出力の特徴マップの枚数（チャネル数）になる。活性化マップともいう

#### ストライド（すとらいど / stride）

- 意味：カーネル（やプーリングの窓）を1回にずらす幅
- ポイント：ストライドを大きくすると、出力の特徴マップが小さくなる（ダウンサンプリング）
- 語の意味：stride＝大またの一歩

#### パディング（ぱでぃんぐ / padding）

- 意味：入力のまわりに値（ふつうは 0）を足して、ふちを広げること。0 を足すのはゼロパディング
- ポイント：ふちの情報も使えるようになり、出力の大きさを入力と同じに保てる。ストライド 1、カーネル K のとき、パディング（K−1）÷2 で同じ大きさになる
- 語の意味：padding＝詰め物

#### 受容野（じゅようや / receptive field）

- 意味：あるユニットが、入力のどの範囲の影響を受けているか
- ポイント：畳み込み層は狭い受容野（局所的な結合）、全結合層は前の層全体が受容野。層を重ねるほど受容野は広がる

## 11-2 いろいろな畳み込み

### まとめ表

| 名前 | 中身 | ねらい |
| :-: | :-: | :-: |
| Dilated（Atrous）Convolution | カーネルの要素のあいだに間をあける | パラメータを増やさず受容野を広げる |
| Depthwise Separable Convolution | チャネルごとの空間の畳み込み＋1×1 の畳み込み | 計算量とパラメータを大きく減らす |
| 1×1 の畳み込み（pointwise） | 各点でチャネル方向だけを混ぜる | チャネル数を変える |

### 畳み込みの変種

#### Dilated Convolution（Atrous Convolution）（だいれいてっど・あとらすこんぼりゅーしょん / dilated convolution）

- 意味：カーネルの要素のあいだにすき間をあけて、広い範囲を見る畳み込み。膨張畳み込みともいう
- ポイント：パラメータの数を増やさず、解像度も落とさずに受容野を広げられる。セグメンテーション（DeepLab など）で使う
- 語の意味：dilated＝広げた、à trous（フランス語）＝穴のあいた

#### Depthwise Separable Convolution（でぷすわいずせぱらぶるこんぼりゅーしょん / depthwise separable convolution）

- 意味：ふつうの畳み込みを、チャネルごとに空間方向だけ畳み込む depthwise convolution と、1×1 でチャネル方向を混ぜる pointwise convolution の2段に分けたもの。深さ単位分離可能畳み込み
- ポイント：計算量とパラメータが大きく減る。MobileNet や Xception で使う（軽量化は #17）
- 語の意味：depthwise＝深さ（チャネル）ごとに、separable＝分けられる

#### 1×1 畳み込み（いちかけいちたたみこみ / 1×1 convolution, pointwise convolution）

- 意味：1×1 のカーネルでの畳み込み。各位置でチャネル方向の全結合をしているのと同じ
- ポイント：チャネル数を減らして計算を軽くするのに使う（GoogLeNet の Inception など）

## 11-3 正規化層

### まとめ表

| 正規化 | 平均と分散を計算する範囲 | 向いている場面 |
| :-: | :-: | :-: |
| バッチ正規化 | ミニバッチの中の全サンプルで、チャネルごと | 画像の CNN。バッチが大きいとき |
| レイヤー正規化 | 1サンプルの中の、その層の全部 | RNN・Transformer。バッチの大きさによらない |
| インスタンス正規化 | 1サンプルの、1チャネルごと | 画像のスタイル変換 |
| グループ正規化 | 1サンプルの、いくつかのチャネルのまとまりごと | バッチが小さいとき（物体検出など） |

### 正規化層

#### 正規化層（せいきかそう / normalization layer）

- 意味：層への入力の値を、平均 0・分散 1 などにそろえる層
- ポイント：学習が速く安定し、大きな学習率を使える。初期値にも敏感でなくなる

#### バッチ正規化（ばっちせいきか / batch normalization）

- 意味：ミニバッチごとに、各チャネル（ユニット）の値の平均と分散を求めて正規化する方法
- ポイント：前の層の重みが変わると次の層の入力の分布が変わる「内部共変量シフト」を抑える。正則化の効果もあり、ドロップアウトがいらなくなることもある。バッチが小さいと統計が不正確になり、誤差が増える
- 語の意味：batch＝ひとまとまり

#### レイヤー正規化（れいやーせいきか / layer normalization）

- 意味：1つのサンプルの中で、その層のすべてのユニットの値から平均と分散を求めて正規化する方法
- ポイント：ミニバッチの大きさに左右されず、RNN にも使える。Transformer（#12）で使う

#### インスタンス正規化（いんすたんすせいきか / instance normalization）

- 意味：1つのサンプル（画像）の、1つのチャネルごとに平均と分散を求めて正規化する方法
- ポイント：画像のスタイル変換で、バッチ正規化と入れかえると画像の質がよくなった

#### グループ正規化（ぐるーぷせいきか / group normalization）

- 意味：1つのサンプルの中で、チャネルをいくつかのグループに分け、グループごとに平均と分散を求めて正規化する方法
- ポイント：バッチの大きさに左右されず、小さいバッチでも精度が安定する。グループを1つにするとレイヤー正規化、チャネル数と同じにするとインスタンス正規化になる

## 11-4 プーリング層

### まとめ表

| プーリング | 窓の中から取り出す値 | 特徴 |
| :-: | :-: | :-: |
| 最大値プーリング | 一番大きい値 | いまの基本形。目立つ特徴を残す |
| 平均値プーリング | 平均 | ネオコグニトロンや LeNet で使われた |
| グローバルアベレージプーリング（GAP） | 特徴マップ全体の平均（1枚→1つの値） | 全結合層のかわりに使え、パラメータが減る |

### プーリング

#### プーリング層（ぷーりんぐそう / pooling layer）

- 意味：特徴マップの小さな範囲（窓）を1つの値にまとめて、特徴マップを小さくする層
- ポイント：学習するパラメータがない。位置が少しずれても同じ結果になりやすい（位置ずれへの不変性の獲得）。計算量も減る
- 語の意味：pool＝寄せ集める

#### 最大値プーリング（さいだいちぷーりんぐ / max pooling）

- 意味：窓の中の一番大きい値を取り出すプーリング
- ポイント：いまのプーリングの基本形

#### 平均値プーリング（へいきんちぷーりんぐ / average pooling）

- 意味：窓の中の値の平均を取り出すプーリング
- ポイント：ネオコグニトロンや LeNet で使われた

#### グローバルアベレージプーリング（GAP）（ぐろーばるあべれーじぷーりんぐ / global average pooling）

- 意味：1枚の特徴マップ全体の平均をとって、1つの値にするプーリング
- ポイント：特徴マップを平らにして全結合層に入れるかわりに使え、パラメータが大幅に減り過学習しにくい。Network In Network（NIN）で提案され、GoogLeNet や ResNet でも使う

## 11-5 スキップ結合

### まとめ表

| | ふつうの層 | 残差ブロック（スキップ結合あり） |
| :-: | :-: | :-: |
| 学ぶもの | 出力 H(x) そのもの | 残差 F(x)＝H(x)−x |
| 出力 | H(x) | F(x)＋x |
| 効果 | 深くすると学習しにくい | 勾配が近道を通って伝わり、100層以上でも学習できる |

### スキップ結合と ResNet

#### スキップ結合（すきっぷけつごう / skip connection）

- 意味：ある層への入力を、いくつかの層を飛びこえて、後ろの層の出力に足す（またはつなぐ）結合。ショートカット結合、残差接続ともいう
- ポイント：逆伝播で勾配が近道を通れるので、勾配消失が起きにくく、とても深いネットワークでも学習できる

#### ResNet（れずねっと / residual network）

- 意味：スキップ結合を使った残差ブロックを何層も重ねた CNN。2015年にマイクロソフトの He らが発表し、ILSVRC 2015 で優勝した
- ポイント：層は「入力との差（残差）」を学ぶ。152層という、それまでよりずっと深いネットワークを学習できた
- 語の意味：residual＝残り（残差）

## 問題演習

### 11-1

#### 問 gk-11-o01

- 問：畳み込み層と全結合層の違いとして正しいものはどれか。
- ア：畳み込み層は前の層のすべてのユニットとつながり、全結合層は狭い範囲だけとつながる
- イ：畳み込み層には学習するパラメータがない
- ウ：畳み込み層の各ユニットは前の層の狭い範囲（受容野）だけから入力を受け、全結合層では前の層全体が受容野になる
- エ：全結合層は画像にしか使えない
- 正解：ウ
- 解説：畳み込み層では、各ニューロンは前の層の受容野と呼ばれる限られた範囲だけから入力を受ける。全結合層では受容野は前の層全体になる。
- アの意味：説明が逆。
- イの意味：カーネルとバイアスを学習する。パラメータがないのはプーリング層。
- ウの意味：正しい。
- エの意味：全結合層はどんなベクトルにも使える。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Convolutional neural network」（『In a convolutional layer, each neuron receives input from only a restricted area of the previous layer called the neuron's receptive field.』））

#### 問 gk-11-o02

- 問：入力のユニットが 200 個、出力のユニットが 50 個の全結合層の、バイアスを含むパラメータの数はいくつか。
- ア：250
- イ：10,050
- ウ：10,000
- エ：10,200
- 正解：イ
- 解説：全結合層では、すべての入力とすべての出力がつながるので、重みは 200×50＝10,000 個。出力ごとにバイアスが1つずつで 50 個。合計 10,050 個。
- アの意味：ユニットの数を足しただけ。
- イの意味：正しい。
- ウの意味：バイアスを数えていない。
- エの意味：バイアスを入力の数だけ数えている。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Convolutional neural network」（『Fully connected layers connect every neuron in one layer to every neuron in another layer.』））

#### 問 gk-11-o03

- 問：畳み込み層で学習によって決まるものとして正しいものはどれか。
- ア：カーネル（フィルタ）の値とバイアス
- イ：ストライドの大きさ
- ウ：パディングの幅
- エ：入力画像の画素の値
- 正解：ア
- 解説：畳み込み層ではカーネルとバイアスが学習の対象になる。カーネルはフィルタとも呼ばれる。
- アの意味：正しい。
- イの意味：人が決めるハイパーパラメータ。
- ウの意味：人が決めるハイパーパラメータ。
- エの意味：入力のデータで、学習で変えるものではない。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「畳み込みニューラルネットワーク」（『カーネルとバイアスが学習対象である。』））

#### 問 gk-11-o04

- 問：3×3 のカーネルで、入力のチャネル数が 3、出力のチャネル数（カーネルの枚数）が 16 の畳み込み層の、バイアスを含むパラメータの数はいくつか。
- ア：144
- イ：160
- ウ：432
- エ：448
- 正解：エ
- 解説：カーネル1枚の重みは 3×3×3＝27 個で、それが 16 枚で 432 個。出力のチャネルごとにバイアスが1つで 16 個。合計 448 個。入力画像の大きさにはよらない。
- アの意味：入力チャネル数を掛けていない（3×3×16）。
- イの意味：入力チャネル数を掛けず、バイアスを足したもの。
- ウの意味：バイアスを数えていない。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Convolutional neural network」（『A distinguishing feature of CNNs is that many neurons can share the same filter.』））

#### 問 gk-11-o05

- 問：畳み込み層が全結合層に比べてパラメータを大きく減らせる理由として正しいものはどれか。
- ア：活性化関数を使わないから
- イ：同じフィルタの重みを、入力の全体で共有するから
- ウ：バイアスを使わないから
- エ：出力をいつも1つにするから
- 正解：イ
- 解説：CNN では多くのニューロンが同じフィルタを共有する。共有した重みを使うのでパラメータがずっと少なくなる。
- アの意味：畳み込み層のあとにも活性化関数（ReLU など）を使う。
- イの意味：正しい。
- ウの意味：バイアスも使う。
- エの意味：出力は特徴マップ。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Convolutional neural network」（『Using shared weights means there are many fewer parameters, which helps avoid the vanishing gradients and exploding gradients problems seen during backpropagation in earlier neural networks.』））

#### 問 gk-11-o06

- 問：縦横 28 の入力に、3×3 のカーネルで、ストライド 1、パディング 0 の畳み込みをしたときの出力の縦横の大きさはいくつか。
- ア：28
- イ：30
- ウ：26
- エ：9
- 正解：ウ
- 解説：出力の1辺＝（入力＋2×パディング−カーネル）÷ストライド＋1＝（28＋0−3）÷1＋1＝26。
- アの意味：パディング 1 のときの大きさ。
- イの意味：大きくはならない。
- ウの意味：正しい。
- エの意味：カーネルの要素の数（3×3）。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Convolutional neural network」（『In general, setting zero padding to be P=(K−1)/2 when the stride is S=1 ensures that the input volume and output volume will have the same size spatially.』））

#### 問 gk-11-o07

- 問：畳み込みで、入力のまわりに 0 の値の画素を足すことを何というか。
- ア：ストライド
- イ：プーリング
- ウ：ドロップアウト
- エ：パディング
- 正解：エ
- 解説：パディングは画像のふちに（ふつうは 0 の）画素を足すこと。ふちの情報も使え、出力の大きさを保てる。
- アの意味：カーネルをずらす幅。
- イの意味：小さな範囲を1つの値にまとめる操作。

- エ：活性化関数が不要になるから
- 正解：ウ
- 解説：出力が「F(x)＋x」なので、逆伝播では x の近道から勾配がそのまま流れる。そのため数十〜数百層の深いモデルも学習しやすくなる。
- アの意味：パラメータは 0 にならない。
- イの意味：画像の大きさは関係ない。
- ウの意味：正しい。
- エの意味：活性化関数（ReLU）は使う。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「残差ネットワーク」（『これにより、数十から数百のレイヤーを持つ深層モデルを容易に学習させることができ、より深く学習する際にはより高い精度に近づくことができる。』））

#### 問 gk-11-o30

- 問：ResNet の論文が出発点とした問題として正しいものはどれか。
- ア：浅いネットワークは学習データが多すぎる
- イ：深いニューラルネットワークほど学習させにくい
- ウ：全結合層はパラメータが少なすぎる
- エ：プーリング層は計算が重すぎる
- 正解：イ
- 解説：「深いネットワークほど学習が難しい」という問題に対し、残差学習の枠組みで、それまでよりずっと深いネットワークの学習を容易にした。
- アの意味：問題の出発点ではない。
- イの意味：正しい。
- ウの意味：全結合層はむしろパラメータが多い。
- エの意味：プーリングは軽い。
- 出典：オリジナル問題（根拠：He ほか「Deep Residual Learning for Image Recognition」（『Deeper neural networks are more difficult to train.』））
