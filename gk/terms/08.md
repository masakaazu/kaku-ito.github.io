## 08-1 ニューラルネットワークのしくみ

### まとめ表

| 名前 | 層 | できること |
| :-: | :-: | :-: |
| 単純パーセプトロン | 入力層と出力層だけ（中間層なし） | 線形分離可能な問題だけ（AND・OR はできるが XOR はできない） |
| 多層パーセプトロン | 入力層・隠れ層（1つ以上）・出力層 | 線形分離できない問題も解ける |
| ディープニューラルネットワーク | 隠れ層をたくさん重ねる | 細かい特徴から全体の概念まで階層的に学ぶ |

### パーセプトロン

#### ニューロン（人工ニューロン）（にゅーろん / artificial neuron）

- 意味：複数の入力に重みを掛けて足し、バイアスを加え、活性化関数を通して出力を決める計算の単位。脳の神経細胞をまねたもの
- ポイント：学習で調整するのは重みとバイアス
- 語の意味：neuron＝神経細胞

#### 単純パーセプトロン（たんじゅんぱーせぷとろん / simple perceptron）

- 意味：入力層と出力層だけで、中間層（隠れ層）がないパーセプトロン。ローゼンブラットが1958年に発表した
- ポイント：直線（平面）で分けられる線形分離可能な問題しか解けない。XOR（排他的論理和）は学習できない
- 語の意味：perceptron＝perception（知覚）からの造語

#### 多層パーセプトロン（MLP）（たそうぱーせぷとろん / multilayer perceptron）

- 意味：入力層と出力層のあいだに、中間層（隠れ層）が1つ以上あるニューラルネットワーク。順伝播型のもっとも基本的な形
- ポイント：隠れ層と非線形の活性化関数によって、線形分離できない問題も解ける
- 語の意味：multi＝多い、layer＝層

#### 入力層・隠れ層・出力層（にゅうりょくそう・かくれそう・しゅつりょくそう / input layer, hidden layer, output layer）

- 意味：入力層はデータを受け取る層、隠れ層（中間層）は入力と出力のあいだで特徴を変換する層、出力層は答えを出す層
- ポイント：層の数を数えるときは、ふつう入力層を数えない。隠れ層を深く（多く）重ねたものがディープラーニング

#### 線形分離可能（せんけいぶんりかのう / linearly separable）

- 意味：2つのクラスのデータを、1本の直線（高い次元では平面）で分けられること
- 例：AND・OR は線形分離可能、XOR は線形分離できない

### 深くする意味

#### ディープラーニング（深層学習）（でぃーぷらーにんぐ / deep learning）

- 意味：隠れ層を何層も重ねたニューラルネットワークで、細かい特徴から全体の概念までを階層的に学ぶ方法
- ポイント：特徴量を人が設計しなくても、データから自動で学ぶ（表現学習）。そのかわり大量のデータと計算資源が必要
- 語の意味：deep＝深い（層が多い）

#### 万能近似定理（ばんのうきんじていり / universal approximation theorem）

- 意味：条件を満たす活性化関数を使い、ユニット数を十分にすれば、隠れ層が1層のネットワークでも、どんな連続関数でも好きな精度で近似できるという定理
- ポイント：「表せる」ことの保証で、うまく学習できる保証ではない。実際には深くしたほうが少ないユニットで効率よく表せる

## 08-2 計算資源（CPU・GPU・TPU）

### まとめ表

| 装置 | 得意なこと | ディープラーニングでの位置づけ |
| :-: | :-: | :-: |
| CPU | 汎用。複雑な処理を順番に柔軟にこなす | 前処理や全体の制御 |
| GPU | 数千の演算器で単純な計算を同時に大量に | 行列演算を並列にこなし、学習を大きく速くする |
| TPU | 機械学習の行列演算だけに特化（Google の ASIC） | 大規模な学習・推論を効率よく |

### 装置

#### CPU（しーぴーゆー / central processing unit）

- 意味：コンピュータの中心で、演算や各装置の制御を行う汎用のプロセッサ
- ポイント：どんなソフトウェアも動かせる柔軟さが強み。コアの数が少なく、大量の同じ計算を同時にこなすのは苦手
- 語の意味：central＝中央の、processing＝処理、unit＝装置

#### GPU（じーぴーゆー / graphics processing unit）

- 意味：もとは画像処理用に作られた、たくさんの演算器（数千の ALU）で同じ種類の計算を並列に行うプロセッサ
- ポイント：ニューラルネットワークの行列の掛け算は、同じ計算の大量のくり返しなので、GPU の並列処理に向いている
- 語の意味：graphics＝画像

#### GPGPU（じーぴーじーぴーゆー / general-purpose computing on GPU）

- 意味：GPU を画像処理以外の一般的な計算に使うこと
- ポイント：ディープラーニングの学習を支えた。NVIDIA の CUDA が代表的な開発環境
- 語の意味：general-purpose＝汎用の

#### TPU（てぃーぴーゆー / tensor processing unit）

- 意味：Google が開発した、機械学習の計算に特化した集積回路（ASIC）
- ポイント：大規模な行列演算を、行列乗算ユニット（シストリックアレイ）で効率よく行う。AlphaGo でも使われた
- 語の意味：tensor＝多次元の数の配列（テンソル）

## 08-3 活性化関数

### まとめ表

| 関数 | 出力の範囲 | 主な使いどころ | 注意点 |
| :-: | :-: | :-: | :-: |
| ステップ関数 | 0 か 1 | 初期のパーセプトロン | 微分がほぼ 0 で、誤差逆伝播法に使えない |
| シグモイド関数 | 0〜1 | 2値分類の出力層 | 微分の最大が 0.25 で、勾配消失が起きやすい |
| tanh 関数 | −1〜1 | 隠れ層（RNN など） | 微分の最大は 1 で、シグモイドより消えにくいが消える |
| ReLU 関数 | 0 以上 | 隠れ層の定番 | 入力が負だと勾配 0（ニューロンが死ぬ） |
| Leaky ReLU 関数 | 制限なし | 隠れ層 | 負の側に小さな傾きを残す |
| ソフトマックス関数 | 0〜1（合計 1） | 多クラス分類の出力層 | ― |
| 恒等関数 | 制限なし | 回帰の出力層 | ― |

### 役割

#### 活性化関数（かっせいかかんすう / activation function）

- 意味：ニューロンが受け取った入力の重み付き和から、出力を決める関数
- ポイント：非線形の関数を使うことが大事。線形の関数だけだと、何層重ねても1層と同じ働きしかできない
- 語の意味：activation＝活性化（ニューロンが発火すること）

#### ステップ関数（すてっぷかんすう / step function）

- 意味：入力がしきい値より大きければ 1、そうでなければ 0 を出す関数。初期のパーセプトロンで使われた
- ポイント：ほとんどの場所で微分が 0 なので、勾配を使う学習（誤差逆伝播法）には使えない

### 隠れ層でよく使う関数

#### シグモイド関数（しぐもいどかんすう / sigmoid function）

- 意味：入力を 0〜1 のなめらかな S 字の曲線に変える関数
- ポイント：微分がなめらかで計算しやすく、1986年の誤差逆伝播法の発表以降よく使われた。微分の最大値が 0.25 しかないので、層を重ねると勾配が小さくなりやすい（勾配消失）。いまは主に2値分類の出力層で使う
- 語の意味：sigmoid＝シグマ（σ/ς）の形の

#### tanh 関数（たんえいち・はいぱぼりっくたんじぇんと / hyperbolic tangent）

- 意味：入力を −1〜1 の S 字の曲線に変える関数。双曲線正接関数
- ポイント：出力の中心が 0（原点を通る）で、微分の最大値が 1 なのでシグモイド関数より学習しやすい。それでも入力が大きいと微分が 0 に近づき、勾配消失は起きる

#### ReLU 関数（れるー / rectified linear unit）

- 意味：入力が正ならそのまま、0 以下なら 0 を出す関数。max(0, x)。ランプ関数、正規化線形関数ともいう
- ポイント：正の側の微分がいつも 1 なので勾配消失が起きにくく、計算も軽い。いまの隠れ層の定番。入力が負だと微分が 0 で、そのニューロンが学習しなくなることがある
- 語の意味：rectified＝整流された（負を切りすてた）、linear＝線形の

#### Leaky ReLU 関数（りーきーれるー / leaky ReLU）

- 意味：入力が負のときも 0 にせず、0.01 倍など小さな傾きを残す ReLU の改良版
- ポイント：負の側でも勾配が 0 にならないので、ニューロンが学習しなくなるのを防ぐ
- 語の意味：leaky＝漏れる（負の側に少し漏れる）

### 出力層で使う関数

#### ソフトマックス関数（そふとまっくすかんすう / softmax function）

- 意味：複数の出力を、それぞれ 0〜1 で合計が 1 の値（確率）に変える関数
- ポイント：多クラス分類の出力層で使い、誤差関数の交差エントロピー（#09）と組み合わせる。入力が大きいほど確率も大きくなる

#### 恒等関数（こうとうかんすう / identity function）

- 意味：入力をそのまま出力する関数
- ポイント：数値を予測する回帰の出力層で使う

### 活性化関数と学習の問題

#### 勾配消失問題（こうばいしょうしつもんだい / vanishing gradient problem）

- 意味：誤差逆伝播法で、出力層から入力層へ勾配をさかのぼるうちに勾配がとても小さくなり、入力に近い層の重みがほとんど更新されなくなる問題
- ポイント：シグモイド関数のような微分の小さい活性化関数を何層も重ねると起きやすい。対策は ReLU の利用、ResNet のスキップ結合（#11）、LSTM（#12）、重みの初期値の工夫、バッチ正規化（#11）など
- 語の意味：vanishing＝消えていく、gradient＝勾配

#### 勾配爆発問題（こうばいばくはつもんだい / exploding gradient problem）

- 意味：勾配消失とは逆に、勾配がとても大きくなって発散し、学習がうまくいかなくなる問題
- ポイント：RNN で起きやすい。勾配クリッピング（勾配の大きさに上限をつける）で防ぐ
