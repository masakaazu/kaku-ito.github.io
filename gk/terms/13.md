## 13-1 オートエンコーダ

### まとめ表

| 部分 | 役割 |
| :-: | :-: |
| エンコーダ | 入力を、次元の小さい表現（潜在変数・コード）に圧縮する |
| 中間層（ボトルネック） | 入力より小さい。ここに入力の要点が入る |
| デコーダ | 潜在変数から入力を復元する |
| 学習の目標 | 出力が入力と同じになる（再構成誤差を小さくする） |

| 使い方 | 中身 |
| :-: | :-: |
| 次元削減 | 中間層の値を、データの低次元の表現として使う |
| 事前学習 | 積層オートエンコーダで1層ずつ学習し、深いネットワークの初期値にする |
| 異常検知 | 正常データだけで学習し、うまく復元できない（差が大きい）ものを異常とする |
| ノイズ除去 | ノイズを加えた入力から元の入力を復元するように学習する（デノイジング） |

### オートエンコーダ

#### オートエンコーダ（自己符号化器）（おーとえんこーだ / autoencoder）

- 意味：入力層と出力層に同じデータを使い、入力を一度小さな中間層に圧縮してから元に戻すように学習するニューラルネットワーク
- ポイント：正解ラベルがいらない教師なし学習。中間層を入力より小さくしないと、そのまま写すだけで誤差 0 にできてしまう。2006年にヒントンらが提案した
- 語の意味：auto＝自分自身、encoder＝符号化するもの

#### エンコーダとデコーダ（えんこーだ・でこーだ / encoder, decoder）

- 意味：エンコーダは入力を小さな表現（潜在変数）に変える部分、デコーダはその表現から入力を復元する部分
- ポイント：#12 の Seq2Seq のエンコーダ・デコーダと同じ考え方

#### 潜在変数（せんざいへんすう / latent variable）

- 意味：データの背後にあって直接は見えない、データの特徴をまとめた変数。オートエンコーダでは中間層の値
- 語の意味：latent＝隠れた

#### 積層オートエンコーダ（せきそうおーとえんこーだ / stacked autoencoder）

- 意味：オートエンコーダを何層も重ね、入力に近い層から1層ずつ順に学習させるもの
- ポイント：学習した重みを深いネットワークの初期値にする（事前学習）と、深いネットワークもうまく学習できた。最後に全体を微調整する（ファインチューニング）。ディープラーニングの始まり（#03）につながる

#### 事前学習（じぜんがくしゅう / pre-training）

- 意味：本番の学習の前に、別の方法（オートエンコーダなど）で重みのよい初期値を作っておくこと
- ポイント：2006年ごろは勾配消失のため深いネットワークを直接学習しにくかったので、層ごとの事前学習が使われた。今は ReLU や正規化で直接学習できるので、こうした事前学習はあまり使わない（大規模モデルの事前学習とは意味が違う、#15・#17）

#### デノイジングオートエンコーダ（でのいじんぐおーとえんこーだ / denoising autoencoder）

- 意味：入力にわざとノイズを加え、ノイズのない元の入力を復元するように学習するオートエンコーダ
- ポイント：ノイズに強い特徴を学べる

## 13-2 変分オートエンコーダとその仲間

### まとめ表

| モデル | 特徴 |
| :-: | :-: |
| VAE | 潜在変数を確率分布（平均と分散）で表す。生成モデル |
| β-VAE | KL 情報量の項に β（1 より大きい）を掛け、要素ごとに意味の分かれた潜在変数（もつれをほどいた表現）を学ぶ |
| VQ-VAE | 潜在変数を連続ではなく離散的なコード（コードブックのどれか）にする。事前分布も学習する |
| InfoVAE | 潜在変数が無視される問題などを、学習の目的を変えて改善する |

### VAE

#### 変分オートエンコーダ（VAE）（へんぶんおーとえんこーだ / variational autoencoder）

- 意味：エンコーダが潜在変数を1つの値ではなく確率分布（平均と分散）として出し、そこから取り出した値をデコーダで復元するオートエンコーダ。2013年に Kingma と Welling が提案した
- ポイント：潜在変数の分布から新しい値を取り出してデコーダに入れると、新しいデータを作れる（生成モデル）。誤差は「再構成誤差＋KL 情報量（#09）」
- 語の意味：variational＝変分法の

#### Reparameterization Trick（りぱらめたらいぜーしょんとりっく / reparameterization trick）

- 意味：確率分布から値を取り出す操作を「平均＋標準偏差×乱数」の形に書きかえ、誤差逆伝播法で勾配を計算できるようにする工夫
- ポイント：そのままでは「ランダムに取り出す」部分で勾配が流れない。VAE を学習するための鍵

#### β-VAE（べーたぶいえーいー / beta-VAE）

- 意味：VAE の誤差の KL 情報量の項に、1 より大きい係数 β を掛けたもの
- ポイント：潜在変数の各要素が、物の向き・大きさなど別々の意味を表すように分かれやすくなる（もつれをほどいた表現、disentangled representation）。そのかわり復元の質は下がりやすい

#### VQ-VAE（ぶいきゅーぶいえーいー / vector quantised-variational autoencoder）

- 意味：エンコーダの出力を、用意したコードブックの中の一番近いベクトルに置きかえ（ベクトル量子化）、離散的な潜在変数にした VAE
- ポイント：連続ではなく離散的なコードを出し、事前分布を固定せずに学習する。強力なデコーダと組み合わせたときに潜在変数が無視される問題（posterior collapse）を避けられる
- 語の意味：vector quantisation＝ベクトル量子化

#### InfoVAE（いんふぉぶいえーいー / InfoVAE）

- 意味：VAE の学習の目的（誤差の式）を見直し、推論の不正確さや、柔軟すぎるデコーダで潜在変数が無視される問題を和らげたもの

## 13-3 データ拡張

### まとめ表

| 種類 | 手法 | 中身 |
| :-: | :-: | :-: |
| 幾何学的変換 | Random Flip・Rotate・Crop | 左右反転・回転・切り抜き |
| 色の変換 | Contrast・Brightness | コントラスト・明るさを変える |
| ノイズ | noising | ランダムなノイズを加える |
| 一部を消す | Cutout・Random Erasing | 四角い領域を隠す（0 や乱数で塗る） |
| 画像を混ぜる | Mixup | 2枚の画像とラベルを割合で重ね合わせる |
| 切り貼り | CutMix | ほかの画像の一部を貼り、ラベルを面積の割合で混ぜる |
| 自動で選ぶ | RandAugment | 変換をランダムに N 個選び、強さ M でかける（2つの値だけを調整） |
| 文章 | paraphrasing・EDA | 言いかえ・同義語に置きかえ・単語の挿入／入れかえ／削除 |

### 考え方

#### データ拡張（でーたかくちょう / data augmentation）

- 意味：手元の訓練データに、意味（ラベル）が変わらない程度の変換を加えて、データを水増しする方法
- ポイント：データの多様性が増え、過学習を防いで汎化性能を高める。変換は「その変換をしてもラベルが変わらない」という知識にもとづいて選ぶ。テストデータには使わない
- 例：手書き数字を ±15 度回転させるのはよいが、180 度回転させると 6 が 9 になってしまうので使わない

### 画像の基本の変換

#### Random Flip（らんだむふりっぷ / random flip）

- 意味：画像をランダムに左右（や上下）に反転させる変換
- ポイント：左右反転は一般の写真でよく使う。文字や標識のように向きに意味があるものには注意

#### Rotate（ろーてーと / rotation）

- 意味：画像をランダムな角度だけ回転させる変換

#### Crop（くろっぷ / cropping）

- 意味：画像の一部をランダムに切り抜く変換。切り抜いて元の大きさに戻すことが多い
- ポイント：物の位置や大きさの違いに強くなる

#### Contrast・Brightness（こんとらすと・ぶらいとねす / contrast, brightness）

- 意味：画像のコントラスト（明暗の差）や明るさをランダムに変える変換
- ポイント：撮影の光の条件の違いに強くなる

#### noising（のいじんぐ / noise injection）

- 意味：画像や音声などのデータに、ランダムなノイズを加える変換

### 新しい手法

#### Cutout（かっとあうと / cutout）

- 意味：学習中に、入力画像の四角い領域をランダムに隠す（マスクする）方法
- ポイント：正則化として働き、CNN の頑健さと性能を上げる

#### Random Erasing（らんだむいれーじんぐ / random erasing）

- 意味：画像の中の長方形の領域をランダムに選び、その画素をランダムな値で消す方法
- ポイント：物が隠れた（遮蔽された）画像を作り出すので、過学習を減らし、遮蔽に強くなる。Cutout とほぼ同じ時期に提案された

#### Mixup（みっくすあっぷ / mixup）

- 意味：2つの訓練データの画像とラベルを、同じ割合で重ね合わせた（凸結合した）データで学習する方法
- 例：犬の画像 70%＋猫の画像 30% に、ラベル「犬 0.7・猫 0.3」をつける

#### CutMix（かっとみっくす / CutMix）

- 意味：ある画像の一部を切り取って別の画像に貼りつけ、ラベルを貼った面積の割合で混ぜる方法
- ポイント：Cutout のように画素を黒やノイズで消して情報を失うことがなく、効率がよい

#### RandAugment（らんどおーぐめんと / RandAugment）

- 意味：たくさんの変換の中からランダムに N 個を選び、共通の強さ M でかける、データ拡張の自動化の方法
- ポイント：調整するのは N と M の2つだけで、探索の手間が少ない。それまでの自動化（AutoAugment）は探索に大きな計算が必要だった

### 文章のデータ拡張

#### paraphrasing（ぱらふれーじんぐ / paraphrasing）

- 意味：文の意味を変えずに、別の言い方に言いかえてデータを増やす方法
- 例：翻訳して戻す（逆翻訳）、同義語に置きかえる

#### EDA（いーでぃーえー / easy data augmentation）

- 意味：文章の分類のための簡単なデータ拡張。同義語の置きかえ・ランダムな挿入・ランダムな入れかえ・ランダムな削除の4つの操作を使う
- ポイント：とくにデータが少ないときに効果が大きい

#### 問 gk-13-o02

- 問：オートエンコーダで、中間層を入力層より小さくする理由として正しいものはどれか。
- ア：計算を遅くするため
- イ：中間層が入力と同じ大きさ以上だと、入力をそのまま写すだけで再構成誤差を 0 にでき、意味のある特徴を学ばないため
- ウ：出力層を不要にするため
- エ：ラベルをつけるため
- 正解：イ
- 解説：中間層の次元が入力以上だと、恒等変換（そのまま写す）だけで再構成誤差 0 を達成できてしまう。小さく絞ることで、データの要点を学ばせる。
- アの意味：理由ではない。
- イの意味：正しい。
- ウの意味：復元のための出力層は必要。
- エの意味：オートエンコーダはラベルを使わない。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「オートエンコーダ」（『の場合、オートエンコーダは恒等変換のみで再構成誤差ゼロを達成できてしまう』））

#### 問 gk-13-o03

- 問：オートエンコーダを異常検知に使う方法として正しいものはどれか。
- ア：正常なデータで学習し、入力と出力（復元）の差が大きいものを異常とみなす
- イ：異常なデータだけで学習し、復元できたものを異常とする
- ウ：正解ラベルの数を数える
- エ：出力層をソフトマックス関数にする
- 正解：ア
- 解説：正常なデータで学習したオートエンコーダは、見たことのない異常なデータをうまく復元できない。入力と出力の差分をとることで異常検知に使える。
- アの意味：正しい。
- イの意味：ふつうは異常のデータは少なく、正常データで学習する。
- ウの意味：異常検知のしかたではない。
- エの意味：多クラス分類の出力層。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「オートエンコーダ」（『実用上では、入力と出力の差分をとることで、異常検知に利用されている』））

#### 問 gk-13-o04

- 問：オートエンコーダで、中間層の活性化関数も恒等写像にした場合、結果がほぼ一致する手法はどれか。
- ア：k-means 法
- イ：サポートベクターマシン
- ウ：決定木
- エ：主成分分析
- 正解：エ
- 解説：中間層の活性化関数も恒等写像（線形）にすると、オートエンコーダの結果は主成分分析とほぼ一致する。非線形の活性化関数を使うと、主成分分析より柔軟に次元を減らせる。
- アの意味：クラスタリング（#05）。
- イの意味：分類の手法（#04）。
- ウの意味：分類・回帰の手法（#04）。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「オートエンコーダ」（『中間層の活性化関数も恒等写像を選ぶと結果は主成分分析とほぼ一致する。』））

#### 問 gk-13-o05

- 問：ヒントンとサラクディノフ（2006）が、深いオートエンコーダの学習を可能にした方法として正しいものはどれか。
- ア：重みをすべて大きな値で初期化した
- イ：1層ずつ特徴を学ぶ方法で、よい初期値を作ってから勾配降下法で微調整した
- ウ：活性化関数を使わなかった
- エ：学習データを使わなかった
- 正解：イ
- 解説：初期値が大きいと悪い局所解に、小さいと入力側の勾配が小さくなりすぎて、深いオートエンコーダは学習できなかった。よい初期値を1層ずつ学ぶ方法で作り、そのあと勾配降下法で微調整（ファインチューニング）した。
- アの意味：大きな初期値では悪い局所解に陥りやすい。
- イの意味：正しい。
- ウの意味：活性化関数は使う。
- エの意味：データを使って学習する。
- 出典：オリジナル問題（根拠：Hinton・Salakhutdinov「Reducing the Dimensionality of Data with Neural Networks」（『If the initial weights are close to a good solution, gradient descent works well, but finding such initial weights requires a very different type of algorithm that learns one layer of features at a time.』））

- アの意味：潜在変数を確率分布で表すオートエンコーダ。
- イの意味：オートエンコーダを重ねて1層ずつ学習するもの。
- ウの意味：正しい。
- エの意味：潜在変数を離散的なコードにする VAE。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「オートエンコーダ」（『入力層のデータにノイズを加えて学習させたもの。』））

- イ：EDA と逆翻訳

- 正解：エ

- イの意味：文章のデータ拡張。

#### 問 gk-13-o29

- 問：データ拡張の使い方として正しいものはどれか。
- ア：テストデータにもランダムな変換をかけて評価を上げる
- イ：どんなタスクでも、すべての変換を最大の強さでかける
- ウ：タスクやデータに合わせて、ラベルが変わらない変換を選んで訓練データにかける
- エ：データ拡張をすると必ず性能が下がる
- 正解：ウ
- 解説：データ拡張は、訓練データの多様性を豊かにして汎化能力を高める。どの変換を使うかは「その変換でラベルが変わらない」かどうかで、タスクやデータに合わせて選ぶ。
- アの意味：評価はふつう変換しないテストデータで行う。
- イの意味：強すぎる変換はラベルを壊すことがある。
- ウの意味：正しい。
- エの意味：適切に使えば性能が上がる。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「データ拡張」（『データ拡張は画像分類において基本となっており、訓練データセットの多様性を豊かにして、モデルの汎化能力と性能を向上させる。』））

#### 問 gk-13-o30

- 問：Mixup の論文が、大きなディープニューラルネットワークの望ましくない振る舞いとして挙げたものはどれか。
- ア：計算が遅いこと

- ウ：パラメータが少なすぎること

- 正解：イ
- 解説：大きなネットワークは強力だが、丸暗記（memorization）や敵対的な例（#24）に敏感といった望ましくない振る舞いを見せる。Mixup はこれを和らげる。
- アの意味：論文の挙げた問題ではない。
- イの意味：正しい。
- ウの意味：大きなネットワークはパラメータが多い。
- エの意味：論文は音声や表のデータでも実験している。
- 出典：オリジナル問題（根拠：Zhang ほか「mixup」（『Large deep neural networks are powerful, but exhibit undesirable behaviors such as memorization and sensitivity to adversarial examples.』））
