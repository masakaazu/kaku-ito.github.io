## 09-1 誤差関数の基本

### まとめ表

| タスク | 出力層の関数 | 誤差関数 |
| :-: | :-: | :-: |
| 回帰 | 恒等関数 | 平均二乗誤差（MSE） |
| 2値分類 | シグモイド関数 | 2値の交差エントロピー |
| 多クラス分類 | ソフトマックス関数 | 交差エントロピー |
| 分布を近づける（VAE など） | ― | KL 情報量 |
| 似ているかどうかを学ぶ | ― | Contrastive Loss・Triplet Loss |

### 誤差関数とは

#### 誤差関数（損失関数）（ごさかんすう / loss function）

- 意味：モデルの予測と正解のずれを1つの数で表す関数。学習では、この値が小さくなるように重みを調整する
- ポイント：タスク（回帰か分類か）に合わせて選ぶ。目的関数・コスト関数ともいう

#### 平均二乗誤差（MSE）（へいきんにじょうごさ / mean squared error）

- 意味：予測と正解の差を2乗して平均した誤差関数。二乗誤差損失ともいう
- ポイント：回帰でよく使う。大きく外れた予測ほど強く罰する
- 例：家の値段の予測

#### 交差エントロピー（こうさえんとろぴー / cross entropy）

- 意味：2つの確率分布（正解の分布と予測の分布）のずれをはかる尺度。分類の誤差関数として使う
- ポイント：ソフトマックス関数（多クラス）やシグモイド関数（2値）の出力と組み合わせる。正解のクラスに出した確率が低いほど大きくなる
- 例：正解が「猫」なのに、猫の確率を 0.1 と出すと誤差が大きい
- 語の意味：cross＝交差、entropy＝情報のあいまいさの量

#### カルバック・ライブラー情報量（KL 情報量）（かるばっくらいぶらーじょうほうりょう / Kullback-Leibler divergence）

- 意味：2つの確率分布がどれだけ違うかをはかる尺度。同じ分布なら 0
- ポイント：P から Q をはかるのと Q から P をはかるのとで値が違う（対称でない）ので、数学的な意味の距離ではない。交差エントロピー＝正解の分布のエントロピー＋KL 情報量の関係がある。VAE（#13）で使う
- 語の意味：divergence＝へだたり

## 09-2 距離を学ぶ誤差関数

### まとめ表

| 誤差関数 | 使うデータ | 学び方 |
| :-: | :-: | :-: |
| Contrastive Loss | 2つ組（似ている／似ていない） | 似ているペアは近く、似ていないペアは一定以上遠く |
| Triplet Loss | 3つ組（基準・同じもの・違うもの） | 基準と同じものの距離を、基準と違うものの距離よりマージンだけ小さく |

### 距離学習

#### 距離学習（きょりがくしゅう / metric learning）

- 意味：似ているデータは近く、似ていないデータは遠くになるように、データを埋め込む空間（特徴の空間）を学ぶ方法
- ポイント：クラスに分けるのではなく「似ているか」を学ぶ。顔認証や類似画像の検索で使う
- 例：FaceNet は、顔画像を、距離がそのまま顔の似ている度合いになる空間に写す

#### Contrastive Loss（こんとらすてぃぶろす / contrastive loss）

- 意味：2つのデータの組に「似ている／似ていない」のラベルをつけ、似ているペアは近く、似ていないペアは一定の距離（マージン）以上離すように学ぶ誤差関数
- ポイント：2つ組を使う。Hadsell・Chopra・LeCun（2006）が使った
- 語の意味：contrastive＝対比させる

#### Triplet Loss（とりぷれっとろす / triplet loss）

- 意味：基準（アンカー）、同じクラスのデータ（ポジティブ）、違うクラスのデータ（ネガティブ）の3つ組を使い、アンカーとポジティブの距離が、アンカーとネガティブの距離よりマージン以上小さくなるように学ぶ誤差関数
- ポイント：3つ組を使う。FaceNet（2015）の顔認証で有名
- 語の意味：triplet＝3つ組

## 09-3 正則化

### まとめ表

| 方法 | 罰の中身 | 効果 |
| :-: | :-: | :-: |
| L0 正則化 | 0 でないパラメータの数 | 使う特徴を減らす（計算は難しい） |
| L1 正則化（ラッソ回帰） | パラメータの絶対値の和 | 多くのパラメータがちょうど 0 になる（スパース・特徴選択） |
| L2 正則化（リッジ回帰） | パラメータの2乗の和 | パラメータ全体を小さくする（荷重減衰）。0 にはなりにくい |
| Elastic Net | L1 と L2 の両方 | 両方のよいところ |
| ドロップアウト | 学習中にユニットをランダムに無効にする | たくさんのネットワークの平均に近い効果 |
| 早期終了 | 検証誤差が上がり始めたら学習を止める | 過学習の前で止める |

### 正則化の考え方

#### 正則化（せいそくか / regularization）

- 意味：過学習を防いで汎化性能を高めるために、モデルの複雑さに罰則（ペナルティ）を加える方法
- ポイント：誤差関数に「パラメータの大きさ×係数 λ」を足す形が多い。λ を大きくするほど単純なモデルになる。考え方のよりどころはオッカムの剃刀（#07）
- 語の意味：regular＝規則正しい、なめらかな

#### L0 正則化（えるぜろせいそくか / L0 regularization）

- 意味：0 でないパラメータの数を罰とする正則化
- ポイント：使う特徴の数を直接減らせるが、組み合わせの問題になり計算が難しい。かわりに L1 正則化が使われる

#### L1 正則化（えるわんせいそくか / L1 regularization）

- 意味：パラメータの絶対値の和を罰とする正則化
- ポイント：いくつかのパラメータがちょうど 0 になる（スパースになる）ので、不要な特徴を取り除く特徴選択の効果がある

#### L2 正則化（えるつーせいそくか / L2 regularization）

- 意味：パラメータの2乗の和を罰とする正則化
- ポイント：パラメータを全体に小さくする（0 にはなりにくい）。ニューラルネットワークでは荷重減衰（weight decay）とも呼ぶ

### 回帰での名前

#### ラッソ回帰（らっそかいき / lasso regression）

- 意味：線形回帰に L1 正則化を加えたもの
- ポイント：係数の多くが 0 になるので、変数の選択と正則化を同時にでき、解釈しやすい
- 語の意味：LASSO＝least absolute shrinkage and selection operator（絶対値で縮めて選ぶ）

#### リッジ回帰（りっじかいき / ridge regression）

- 意味：線形回帰に L2 正則化を加えたもの
- ポイント：説明変数どうしが強く相関している（多重共線性がある）ときに、係数が不安定になるのを防ぐ

#### Elastic Net（えらすてぃっくねっと / elastic net）

- 意味：L1 正則化と L2 正則化の両方を加えた線形回帰
- ポイント：ラッソとリッジの中間。L1 の割合を変えて調整する
- 語の意味：elastic＝伸び縮みする、net＝網

### ニューラルネットワークでの正則化

#### ドロップアウト（どろっぷあうと / dropout）

- 意味：学習中に、ユニット（とその結合）を毎回ランダムに選んで無効にする方法
- ポイント：ユニットどうしが頼りあいすぎるのを防ぎ、たくさんの小さなネットワークを平均したような効果が出る。推論（テスト）のときは全部のユニットを使う
- 語の意味：drop out＝抜け落ちる

#### 早期終了（そうきしゅうりょう / early stopping）

- 意味：学習の途中で検証データの誤差を見ておき、誤差が下がらなくなった（上がり始めた）ところで学習を止める方法
- ポイント：くり返し学習する方法での正則化の一種。簡単で効果が高い
