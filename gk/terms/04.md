## 04-1 回帰と分類

### まとめ表

| 問題 | 出力 | 例 | 代表的なモデル |
| :-: | :-: | :-: | :-: |
| 回帰問題 | 連続した数値 | 家の価格、明日の気温 | 線形回帰 |
| 分類問題（2クラス） | どちらか | 迷惑メールか否か | ロジスティック回帰、SVM |
| 多クラス分類 | 3つ以上のどれか | 手書きの 0〜9 | 決定木、ソフトマックス |

### 教師あり学習の問題

#### 教師あり学習（きょうしありがくしゅう / supervised learning）

- 意味：入力（特徴量）と正解（教師データ、ラベル）の組をたくさん与えて、入力から正解を当てる関係を学ぶ方法
- ポイント：特徴量と教師データのペアが必要。代表的な問題は回帰と分類

#### 回帰問題（かいきもんだい / regression）

- 意味：連続した数値（量）を予測する問題
- 例：広さと駅からの距離から家の価格を当てる

#### 分類問題（ぶんるいもんだい / classification）

- 意味：決まった種類（カテゴリ）のどれに当てはまるかを予測する問題
- ポイント：2つに分ける2クラス分類（二値分類）と、3つ以上に分ける多クラス分類がある

#### 多クラス分類（たくらすぶんるい / multiclass classification）

- 意味：3つ以上のクラスに分ける分類
- ポイント：2クラスの分類器を組み合わせる方法に、1つのクラスとそれ以外を分ける one-vs-rest（one-vs-all）がある

### 線形のモデル

#### 線形回帰（せんけいかいき / linear regression）

- 意味：入力と出力の関係を直線（平面）で表し、予測と実際の差の2乗の合計が最小になるように係数を決める回帰
- ポイント：差の2乗の合計を最小にする方法を最小二乗法という（#19）

#### 単回帰分析と重回帰分析（たんかいきぶんせき・じゅうかいきぶんせき / simple and multiple regression）

- 意味：説明変数（入力）が1つなら単回帰、2つ以上なら重回帰
- ポイント：重回帰では説明変数どうしの相関が強いと結果が不安定になる（多重共線性）

#### ロジスティック回帰（ろじすてぃっくかいき / logistic regression）

- 意味：入力の重み付きの合計をシグモイド関数（ロジスティック関数）に通して 0〜1 の確率にし、しきい値で分類するモデル
- ポイント：名前に「回帰」が付くが、主に分類に使う。しきい値は既定で 0.5。多クラスにはソフトマックス関数を使う

## 04-2 サポートベクターマシンと決定木

### まとめ表

| モデル | しくみ | 長所 | 短所 |
| :-: | :-: | :-: | :-: |
| SVM | マージンが最大になる境界を引く | 高次元に強い、汎化性能が高い | データが多いと遅い |
| 決定木 | 条件で枝分かれしていく | 結果の理由がわかりやすい | 過学習しやすい |

### サポートベクターマシン

#### サポートベクターマシン（さぽーとべくたーましん / support vector machine, SVM）

- 意味：クラスの境界から一番近いデータ（サポートベクター）までの距離（マージン）が最大になるように境界を引く分類のモデル
- ポイント：境界は一部のデータ（サポートベクター）だけで決まる。ヴァプニクらが考案

#### マージン最大化（まーじんさいだいか / margin maximization）

- 意味：境界と、一番近いデータとの距離をできるだけ大きくすること
- ポイント：マージンが大きいほど未知のデータに強い（汎化誤差が小さい）。多少の誤りを許すのがソフトマージン、許さないのがハードマージン

#### カーネルとカーネルトリック（かーねる・かーねるとりっく / kernel, kernel trick）

- 意味：カーネル（カーネル関数）は、データを高次元の空間に移したときの内積を計算する関数。カーネルトリックは、高次元に移す計算をせずにカーネル関数だけで済ませる工夫
- ポイント：直線で分けられないデータも、高次元に移せば分けられる。ガウスカーネル（RBF）などがある

### 決定木

#### 決定木（けっていぎ / decision tree）

- 意味：「年齢が30以上か」のような条件で枝分かれをくり返して、分類や回帰をするモデル
- ポイント：理由がわかりやすい（ホワイトボックス）。データの前処理（標準化）が要らない。木を深くしすぎると過学習する

## 04-3 アンサンブル学習

### まとめ表

| 手法 | 学習器の作り方 | 主に減らすもの | 代表 |
| :-: | :-: | :-: | :-: |
| バギング | 並列に、ブートストラップしたデータで別々に | ばらつき（バリアンス） | ランダムフォレスト |
| ブースティング | 順番に、前の誤りを重視して | かたより（バイアス） | AdaBoost、勾配ブースティング |

### 組み合わせて強くする

#### アンサンブル学習（あんさんぶるがくしゅう / ensemble learning）

- 意味：複数のモデル（弱学習器）の予測を組み合わせて、1つのモデルより強く安定した予測をする方法
- ポイント：多数決や平均で組み合わせる。バギングとブースティングが代表

#### ブートストラップサンプリング（ぶーとすとらっぷさんぷりんぐ / bootstrap sampling）

- 意味：元のデータから、同じものを何度選んでもよい（復元抽出）ことにしてランダムにデータを選び、新しいデータの組を作ること
- ポイント：選ばれないデータ（OOB）も出る。バギングで使う

#### バギング（ばぎんぐ / bagging）

- 意味：ブートストラップで作った複数のデータでそれぞれモデルを学習し、予測を平均や多数決でまとめる方法
- ポイント：モデルは並列に作れる。予測のばらつきを減らす
- 語の意味：Bootstrap AGGregatING の略

#### ランダムフォレスト（らんだむふぉれすと / random forest）

- 意味：ブートストラップしたデータと、ランダムに選んだ一部の特徴量で多数の決定木を作り、多数決や平均で予測するバギングの方法
- ポイント：特徴量もランダムに選ぶことで、木どうしが似すぎるのを防ぐ。特徴量の重要度もわかる

#### ブースティング（ぶーすてぃんぐ / boosting）

- 意味：弱学習器を1つずつ順番に作り、前の学習器が間違えたデータの重みを大きくして、次の学習器がそこを重点的に学ぶ方法
- ポイント：順番に作るので並列にできず時間がかかる。AdaBoost が代表

#### 勾配ブースティング（こうばいぶーすてぃんぐ / gradient boosting）

- 意味：前のモデルの残りの誤差（損失の負の勾配）を次のモデルが学んで足していくブースティング
- ポイント：決定木を使う勾配ブースティング木は、多くの場合ランダムフォレストより精度が高い。XGBoost・LightGBM が有名

## 04-4 時系列のモデル

### まとめ表

| モデル | 扱う変数 | 中身 |
| :-: | :-: | :-: |
| AR モデル | 1つ | 自分の過去の値から今を予測 |
| VAR モデル | 複数 | 複数の変数の過去の値から、それぞれの今を予測 |

### 自己回帰

#### 自己回帰モデル（AR モデル）（じこかいきもでる / autoregressive model）

- 意味：ある時点の値を、同じ変数の過去の値の重み付きの合計（と誤差）で表す時系列のモデル
- 例：過去7日の売上から明日の売上を予測する

#### ベクトル自己回帰モデル（VAR モデル）（べくとるじこかいきもでる / vector autoregression）

- 意味：複数の変数の過去の値を使って、それぞれの変数の今の値を表す時系列のモデル。AR モデルを複数の変数に広げたもの
- 例：気温と電力需要を互いの過去の値も使って予測する
