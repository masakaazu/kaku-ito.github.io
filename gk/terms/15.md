## 15-1 文章の前処理と表現

### まとめ表

| 手法 | 中身 | 弱点 |
| :-: | :-: | :-: |
| ワンホットベクトル | 語彙の数だけの次元で、その単語の位置だけ 1、ほかは 0 | 次元がとても大きく、単語どうしの似ている度合いを表せない |
| BoW（Bag-of-Words） | 文書を、単語の出現回数の集まりで表す | 語順を無視する |
| n-gram | 隣り合う n 個の単語（文字）のまとまり | n が大きいと組み合わせが爆発する |
| TF-IDF | その文書でよく出て、ほかの文書にはあまり出ない単語ほど重くする | 意味の近さは表せない |
| 分散表現（単語埋め込み） | 単語を数百次元の実数のベクトルで表す | ― |

### 前処理

#### 形態素解析（けいたいそかいせき / morphological analysis）

- 意味：文を、意味を持つ最小の単位（形態素）に分け、それぞれの品詞を決める処理
- ポイント：日本語は単語のあいだに空白がないので、まず形態素解析で分ける必要がある
- 例：「私は走る」→「私（名詞）／は（助詞）／走る（動詞）」

#### 構文解析（こうぶんかいせき / parsing, syntactic analysis）

- 意味：形態素に分けたあと、単語どうしの関係（どれがどれを修飾するかなど）を、文法にしたがって明らかにする処理
- ポイント：形態素解析 → 構文解析 → 意味解析 → 文脈解析の順に進む

### 文章を数にする

#### ワンホットベクトル（わんほっとべくとる / one-hot vector）

- 意味：語彙の数だけの次元を持ち、その単語にあたる1か所だけが 1、ほかはすべて 0 のベクトル
- ポイント：どの2つの単語のベクトルも直交するので、意味が似ているかどうかを表せない

#### BoW（Bag-of-Words）（ばっぐおぶわーず / bag-of-words）

- 意味：文書を、どの単語が何回出たかの集まり（袋）として表す方法
- ポイント：語順（文法）は無視するが、出現回数はとらえる。文書の分類や情報検索で使う

#### n-gram（えぬぐらむ / n-gram）

- 意味：隣り合う n 個の記号（文字・単語など）を、順番どおりに並べたまとまり
- ポイント：n＝1 はユニグラム、2 はバイグラム、3 はトライグラム。BoW では失われる、近くの語順の情報を少し残せる

#### TF-IDF（てぃーえふあいでぃーえふ / term frequency-inverse document frequency）

- 意味：単語の重みを、その文書での出現回数（TF）と、その単語を含む文書の少なさ（IDF）を掛けて決める方法
- ポイント：どの文書にも出る「の」「は」のような単語は軽く、その文書に特有の単語は重くなる。もっとも有名な語の重みづけ
- 語の意味：term frequency＝単語の頻度、inverse document frequency＝文書の頻度の逆数

#### 分散表現（単語埋め込み）（ぶんさんひょうげん / distributed representation, word embedding）

- 意味：単語を、数十〜数百次元の実数のベクトルで表すこと。意味が近い単語ほどベクトルも近くなる
- ポイント：ワンホットベクトルの何万もの次元から、ずっと低い次元の連続の空間に埋め込む。「周りに出てくる単語が似ていれば意味も似ている」という分布仮説にもとづく
- 例：「王様 − 男 ＋ 女 ≒ 女王」のような計算ができる

## 15-2 単語の埋め込みと言語モデル

### まとめ表

| 年 | モデル | 特徴 |
| :-: | :-: | :-: |
| 2013 | word2vec | CBOW と skip-gram で単語ベクトルを効率よく学ぶ |
| 2016 | fastText | 単語を文字の n-gram の集まりとして表す。知らない単語・まれな単語に強い |
| 2018 | ELMo | 双方向の LSTM 言語モデルで、文脈によって変わる単語の表現を作る（多義語に対応） |
| 2018 | BERT | Transformer のエンコーダで、左右両方の文脈から事前学習。ファインチューニングで多くのタスクに |
| 2018〜 | GPT | Transformer のデコーダで、次の単語を予測する事前学習。GPT-3 は few-shot で多くのタスクをこなす |
| 2022 | PaLM | Google の 5,400 億パラメータの言語モデル |

### word2vec の仲間

#### word2vec（わーどつーべっく / word2vec）

- 意味：大量の文章から、単語の分散表現（ベクトル）を効率よく学ぶ方法。2013年に Google のミコロフらが発表した
- ポイント：CBOW と skip-gram の2つのモデルがある。浅いニューラルネットワークで速く学べる

#### CBOW（しーぼう / continuous bag-of-words）

- 意味：周りの単語（文脈）から、まん中の単語を予測するように学ぶ word2vec のモデル
- ポイント：「穴うめ問題」のようなもの。skip-gram より速い

#### スキップグラム（すきっぷぐらむ / skip-gram）

- 意味：まん中の単語から、その周りの単語（文脈）を予測するように学ぶ word2vec のモデル
- ポイント：CBOW と予測の向きが逆。まれな単語でよい表現を学びやすい。負例サンプリング（negative sampling）で学習を速くする

#### fastText（ふぁすとてきすと / fastText）

- 意味：単語を「文字の n-gram の集まり」として表し、その n-gram のベクトルの和を単語のベクトルにする方法。Facebook（現 Meta）が開発
- ポイント：単語の形（活用・語幹）を使えるので、語彙が多い言語やまれな単語、学習に出てこなかった単語にも強い。学習も速い

### 文脈を使う言語モデル

#### ELMo（えるも / Embeddings from Language Models）

- 意味：大きなコーパスで事前学習した双方向の LSTM 言語モデルの内部の状態から、文脈に応じた単語の表現を作る方法
- ポイント：同じ単語でも文脈によって違うベクトルになるので、多義語（「bank」が銀行か土手か）を区別できる。word2vec は1単語に1ベクトル

#### BERT（ばーと / Bidirectional Encoder Representations from Transformers）

- 意味：Transformer のエンコーダを使い、ラベルのない文章から、すべての層で左右両方の文脈を使って事前学習した言語モデル。2018年に Google が発表した
- ポイント：文中の単語を隠して当てる（Masked Language Model）、2つの文が続いているかを当てる（Next Sentence Prediction）で事前学習する。出力層を1つ足してファインチューニングするだけで、質問応答などの多くのタスクで高い性能を出す

#### GPT（じーぴーてぃー / Generative Pre-trained Transformer）

- 意味：Transformer のデコーダを使い、前の単語から次の単語を予測するように大量の文章で事前学習した言語モデル。OpenAI が開発した
- ポイント：GPT-3（1,750 億パラメータ）は、ファインチューニングしなくても、いくつかの例（few-shot）や指示だけで新しいタスクをこなせた

#### 大規模言語モデル（LLM）（だいきぼげんごもでる / large language model）

- 意味：億や兆のパラメータを持つ言語モデル。Transformer を使い、膨大なラベルなしの文章で自己教師あり学習などによって訓練する
- ポイント：2018年ごろに登場し、いろいろなタスクで高い性能を出している。ChatGPT などの対話 AI のもと

#### PaLM（ぱーむ / Pathways Language Model）

- 意味：Google が作った、5,400 億パラメータの Transformer の言語モデル。6,144 個の TPU v4 で学習した

#### GLUE（ぐるー / General Language Understanding Evaluation）

- 意味：自然言語理解のモデルを、いろいろなタスクでまとめて評価するためのベンチマーク
- ポイント：特定のタスクだけに合わせたモデルではなく、言語を一般的に理解できるかを測る。BERT は GLUE で高い成績を出した

#### CEC（しーいーしー / constant error carousel）

- 意味：LSTM の中で、誤差（勾配）を減らさずにぐるぐる回して長く保つしくみ。定誤差カルーセル
- ポイント：これによって LSTM は勾配消失・勾配爆発の問題を解決し、長い時系列を学べる（#12）

## 15-3 自然言語処理のタスク

### まとめ表

| タスク | 中身 |
| :-: | :-: |
| 機械翻訳 | ある言語の文を別の言語に訳す（統計的機械翻訳 → ニューラル機械翻訳） |
| 文書要約 | 長い文章を短くまとめる |
| 質問応答 | 質問に対して、文章などから答えを出す |
| 感情分析 | 文章が肯定的か否定的かなど、書き手の感情や意見を判定する |
| 情報検索 | 大量の文書から、質問に合うものを探す |

### タスク

#### 統計的機械翻訳（とうけいてききかいほんやく / statistical machine translation）

- 意味：2つの言語の対訳の文章を分析して作った統計モデルにもとづいて、訳を作る機械翻訳
- ポイント：ニューラルネットワークを使うニューラル機械翻訳（Seq2Seq・Transformer）が出るまでの主流

#### 感情分析（かんじょうぶんせき / sentiment analysis）

- 意味：文章などから、書き手の感情や意見（肯定的・否定的など）を判定するタスク。オピニオンマイニングともいう
- 例：商品のレビューの評判を調べる。音声の声の調子から感情を推定することもある

#### 質問応答・文書要約・情報検索（しつもんおうとう・ぶんしょようやく・じょうほうけんさく / question answering, summarization, information retrieval）

- 意味：質問応答は質問に答えるタスク、文書要約は文章を短くまとめるタスク、情報検索は大量の文書から必要なものを探すタスク
- ポイント：BERT や LLM で性能が大きく上がった

## 15-4 音声処理

### まとめ表

| 段階 | 用語 | 中身 |
| :-: | :-: | :-: |
| デジタル化 | A-D 変換・PCM | 音の波を、一定の間隔で取り出し（標本化）、段階の数値に丸めて（量子化）、数の列にする |
| 周波数に分ける | 高速フーリエ変換（FFT） | 音の波を、周波数ごとの強さ（スペクトル）に分ける |
| 特徴 | スペクトル包絡・フォルマント | スペクトルの大まかな形。山の部分がフォルマントで、母音の違いを決める |
| 特徴 | メル尺度・MFCC | 人の耳の感じ方に合わせた周波数の尺度・それを使った音声の特徴量 |
| 単位 | 音素・音韻 | 意味を区別する音の最小の単位 |
| 認識 | 隠れマルコフモデル・CTC | 音声と文字の対応をとる方法 |
| 合成 | WaveNet | 音の波形そのものを1サンプルずつ生成する |

### 音をデジタルにする

#### A-D 変換（えーでぃーへんかん / analog-to-digital conversion）

- 意味：マイクなどから入るアナログの信号（連続した波）を、デジタルの数値に変えること
- ポイント：デジタルにすると、コンピュータで処理できる

#### パルス符号変調（PCM）（ぱるすふごうへんちょう / pulse code modulation）

- 意味：アナログの信号に標本化（一定の時間ごとに値を取り出す）と量子化（段階の数値に丸める）をして、数の列にする方式
- ポイント：サンプリング周波数が高く、量子化のビット数が多いほど元に近い音になるが、データが大きくなる

#### 高速フーリエ変換（FFT）（こうそくふーりえへんかん / fast Fourier transform）

- 意味：離散フーリエ変換を計算機で速く計算する方法。音の波を周波数ごとの成分に分ける
- ポイント：時間の波形 → 周波数のスペクトルにする。音声の特徴を取り出す最初の一歩

### 音の特徴

#### スペクトル包絡（すぺくとるほうらく / spectral envelope）

- 意味：音のスペクトルの細かい山谷をならした、大まかな形
- ポイント：声道（のどや口）の形を表し、音色や母音の違いが出る

#### フォルマント・フォルマント周波数（ふぉるまんと / formant, formant frequency）

- 意味：音声のスペクトルで、まわりより強い周波数の帯（スペクトル包絡の山）。その周波数をフォルマント周波数という
- ポイント：低いほうから第1・第2フォルマントと呼び、その組み合わせで母音（あ・い・う・え・お）が区別できる

#### メル尺度（めるしゃくど / mel scale）

- 意味：人が感じる音の高さに合わせた周波数の尺度
- ポイント：人の耳は低い音の違いに敏感で、高い音の違いには鈍い。メル尺度の差が同じなら、人が感じる高さの差も同じになる

#### メル周波数ケプストラム係数（MFCC）（めるしゅうはすうけぷすとらむけいすう / mel-frequency cepstral coefficients）

- 意味：音のパワースペクトルの対数を、メル尺度の上でコサイン変換して作る、音声の特徴量
- ポイント：スペクトル包絡（声道の特徴）をよく表す。音声認識の特徴量として長く使われてきた

#### 音素・音韻（おんそ・おんいん / phoneme, phonology）

- 意味：音素は、その言語を話す人が同じと感じ、意味を区別する音の最小の単位。音韻はその言語の音のしくみ
- 例：「かた」と「さた」は /k/ と /s/ の音素の違いで意味が変わる

### 音声認識と音声合成

#### 音声認識（おんせいにんしき / speech recognition）

- 意味：声が持つ情報をコンピュータに認識させるタスク。自動音声認識（ASR）
- ポイント：文字起こしのほか、だれの声かを当てる話者識別（話者認識）もふくむ

#### 隠れマルコフモデル（HMM）（かくれまるこふもでる / hidden Markov model）

- 意味：直接は観測できない（隠れた）状態がマルコフ過程で移り変わり、状態から観測できる出力が出ると考える確率モデル
- ポイント：音声は短い区間ごとには定常と見なせるので HMM が使え、1980年代ごろから音声認識の主流になった

#### CTC（しーてぃーしー / connectionist temporal classification）

- 意味：入力（音声のフレーム）と出力（文字）の時間の対応がとれていない列のラベルづけのタスクで、ニューラルネットワークを学習させるための誤差関数と出力の表し方
- ポイント：音声のどの部分がどの文字かを人が細かく合わせなくても、まとめて学習できる（空白の記号を使う）

#### 音声合成（おんせいごうせい / speech synthesis）

- 意味：人の声を人工的に作り出すこと。文字から音声を作るものを TTS（text-to-speech）という

#### WaveNet（うぇーぶねっと / WaveNet）

- 意味：音声の波形そのものを、それまでのすべてのサンプルを条件に1サンプルずつ予測して生成する、DeepMind のニューラルネットワーク（自己回帰モデル）
- ポイント：音声合成に使うと、それまでの方式よりずっと自然に聞こえた。Dilated Convolution（#11）を使う

#### 話者識別（わしゃしきべつ / speaker identification）

- 意味：声から、話しているのがだれかを当てるタスク

## 問題演習

### 15-1

#### 問 gk-15-o01

- 問：日本語の文を意味を持つ最小の単位に分け、それぞれの品詞を決める処理はどれか。
- ア：構文解析
- イ：感情分析
- ウ：形態素解析
- エ：機械翻訳
- 正解：ウ
- 解説：形態素解析は、自然言語の文字列を意味にもとづく最小の単位に分け、その品詞を決める処理。日本語は単語の区切りがないので最初に必要になる。
- アの意味：単語どうしの関係（修飾など）を明らかにする処理。
- イの意味：書き手の感情や意見を判定するタスク。
- ウの意味：正しい。
- エの意味：別の言語に訳すタスク。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「形態素解析」（『形態素解析（けいたいそかいせき、（英: morphological analysis）は自然言語の文字列を意味に基づく最小単位へ分割しその品詞を特定する処理である』））

#### 問 gk-15-o02

- 問：文を形態素に分けたうえで、修飾と被修飾のような単語どうしの関係を明らかにする処理はどれか。
- ア：形態素解析
- イ：構文解析
- ウ：TF-IDF
- エ：音声認識
- 正解：イ
- 解説：構文解析は、自然言語なら形態素に分け、さらにそのあいだの関連（修飾・被修飾など）の統語論的な関係を明らかにする手続き。
- アの意味：最小の単位に分けて品詞を決める処理。
- イの意味：正しい。
