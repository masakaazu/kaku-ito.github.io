## 21-1 著作権法

### まとめ表

| | 著作権 | 特許権 |
| :-: | :-: | :-: |
| 守るもの | 思想または感情の創作的な「表現」 | 自然法則を利用した技術的な「アイデア」（発明） |
| 権利の発生 | 作った時点で自動（届け出・登録は不要） | 特許庁に出願し、審査を通って登録されてから |
| 期間 | 原則として著作者の死後70年 | 出願から20年 |
| 独自に作った似たもの | 依拠していなければ侵害にならない | 知らずに同じものを作っても侵害になる |

### 著作物と権利

#### 著作物（ちょさくぶつ / work）

- 意味：思想または感情を創作的に表現したもので、文芸・学術・美術・音楽の範囲に入るもの
- ポイント：単なる事実やデータ、だれが書いても同じになるありふれた表現、表現になっていないアイデア（作風・画風など）は著作物ではない。プログラムは著作物になるが、アルゴリズム（解き方の考え）やプログラム言語は保護されない

#### 創作性（そうさくせい / creativity）

- 意味：作った人の個性が何らかの形で表れていること。著作物であるための条件のひとつ
- ポイント：芸術的に高い水準である必要はない。だれが作っても同じになるものには創作性がない

#### 著作権（ちょさくけん / copyright）

- 意味：著作物を複製・公衆送信・翻案などする権利を、著作者が独占できる権利（財産権としての著作権）。著作者人格権（公表権・氏名表示権・同一性保持権）とは別
- ポイント：何の手続きもなしに、作った時点で生まれる（無方式主義）。保護期間は原則として著作者の死後70年

#### 職務著作（しょくむちょさく / work made for hire）

- 意味：会社などの発意にもとづき、その業務をする人が仕事として作り、会社の名義で公表する著作物は、契約などに別段の定めがない限り、会社が著作者になるというルール
- ポイント：プログラムは会社の名義で公表しなくても会社が著作者になる。特許の職務発明（発明者は従業者）とちがう

### 利用のルール

#### 著作権侵害（ちょさくけんしんがい / copyright infringement）

- 意味：権利者の許しなく、著作物を複製・公衆送信などして、著作権を侵すこと
- ポイント：既存の著作物との「類似性」（表現の本質的な特徴を感じとれる）と「依拠性」（既存の著作物をもとにした）の両方があると侵害になる。差止請求・損害賠償請求、故意なら刑事罰もある

#### 第30条の4（非享受目的の利用）（だいさんじゅうじょうのよん / exception for non-enjoyment purposes）

- 意味：著作物に表現された思想や感情を、自分で楽しんだり人に楽しませたりすること（享受）を目的としない利用なら、必要な限度で、権利者の許しなく利用できるという規定。AI の学習のための情報解析がふくまれる
- ポイント：2018年の改正で作られた。ただし、著作権者の利益を不当に害する場合は使えない（ただし書）。学習データの作品をそのまま出力させるなど、享受の目的もあわさっている場合も対象外

#### 利用規約（りようきやく / terms of use）

- 意味：サービスやデータを使うときの条件を、提供者が決めて示したもの。利用者が同意すると契約になる
- ポイント：著作権法上は自由に使えるデータでも、利用規約で学習への利用が禁止されていれば、契約違反になることがある。生成 AI サービスの生成物の権利の扱いも利用規約で確かめる

## 21-2 生成 AI と著作権

### まとめ表

| 段階 | 考え方（文化庁「AI と著作権に関する考え方」） |
| :-: | :-: |
| 開発・学習 | 情報解析などの非享受目的なら第30条の4で原則として許諾なく利用できる。ただし著作権者の利益を不当に害する場合、享受目的が併存する場合は別 |
| 生成・利用 | 人が AI を使わずに作るときと同じ。既存の著作物との類似性と依拠性があれば侵害 |
| AI 生成物の著作物性 | 人が道具として AI を使い、創作的寄与があれば著作物になりうる。簡単な指示だけ（アイデアどまり）なら著作物ではない |

### 考え方

#### AI 生成物（えーあいせいせいぶつ / AI-generated output）

- 意味：生成 AI が作った文章・画像・音楽などの生成物
- ポイント：AI が自律的に作ったもので、人の指示が表現に至らないアイデアにとどまる場合は著作物にならない。人が創作意図を持ち、指示の工夫・何度も生成して選ぶ・手を加えるなどの創作的寄与があれば、その人の著作物になりうる（個別に判断）

#### 類似性と依拠性（るいじせいといきょせい / similarity and reliance）

- 意味：類似性は、既存の著作物の表現上の本質的な特徴を直接感じとれるほど似ていること。依拠性は、既存の著作物をもとにして作ったこと
- ポイント：両方そろうと著作権侵害。作風やアイデアが似ているだけでは類似性はない。AI の学習データにその著作物が入っていた場合、利用者が知らなくても依拠性があると推認されうる

## 21-3 特許法

### まとめ表

| 要件・用語 | 中身 |
| :-: | :-: |
| 発明 | 自然法則を利用した技術的思想の創作のうち高度のもの |
| 新規性 | 出願の前に、知られていない・実施されていない・刊行物などに載っていない |
| 進歩性 | その分野のふつうの知識を持つ人が、すでにある発明から簡単に思いつけない |
| 職務発明 | 従業者が仕事としてした発明。会社は通常実施権を持ち、定めがあれば会社が特許を受ける権利を取得（従業者は相当の利益を受ける） |
| 存続期間 | 出願の日から20年 |

### 特許の要件

#### 知的財産権（ちてきざいさんけん / intellectual property rights）

- 意味：人の知的な創作や営業上の信用などを守る権利の総称
- ポイント：特許権・実用新案権・意匠権・商標権（産業財産権）、著作権などがある。営業秘密は権利ではなく、不正競争防止法で行為を規制して守る

#### 発明（はつめい / invention）

- 意味：自然法則を利用した技術的思想の創作のうち、高度のもの
- ポイント：計算の方法そのもの、数学の公式、ゲームのルールなどは自然法則を利用していないので発明ではない。AI の技術も、コンピュータの処理として具体的に書けば発明になりうる

#### 新規性（しんきせい / novelty）

- 意味：出願の前に、国内外で公然と知られた・公然と実施された・刊行物やインターネットで公開された発明でないこと
- ポイント：自分で学会やネットで発表したあとに出願すると新規性を失う（例外の手続きはある）

#### 進歩性（しんぽせい / inventive step）

- 意味：その技術の分野のふつうの知識を持つ人が、出願の前にあった発明から容易に発明できたものでないこと
- 例：既存の手法の組み合わせで、だれでも思いつく程度なら進歩性がない

#### 特許権（とっきょけん / patent right）

- 意味：特許を受けた発明を、業として独占的に実施できる権利
- ポイント：特許庁への出願と審査が必要。存続期間は出願の日から20年。試験・研究のための実施には効力が及ばない

### 発明する人

#### 発明者（はつめいしゃ / inventor）

- 意味：発明をした人。特許を受ける権利をもともと持つ
- ポイント：発明者は人（自然人）に限られる。日本では、AI を発明者とした出願は認められなかった

#### 職務発明（しょくむはつめい / employee invention）

- 意味：従業者が、会社の業務の範囲に属し、従業者の現在または過去の職務に属する発明
- ポイント：会社は通常実施権を持つ。契約や勤務規則で前もって決めておけば、特許を受ける権利ははじめから会社のものになる。そのとき従業者は相当の利益（お金など）を受ける権利を持つ

## 21-4 不正競争防止法と独占禁止法

### まとめ表

| | 営業秘密 | 限定提供データ |
| :-: | :-: | :-: |
| 対象 | 秘密として管理された、事業に役立つ、公然と知られていない情報 | 特定の者に提供するために、電子的に相当量ためて管理しているデータ（営業秘密を除く） |
| 例 | 学習済みモデルのパラメータ、顧客名簿、製造方法 | 会員だけに有料で提供する気象データ・地図データ |

### 不正競争防止法

#### 営業秘密（えいぎょうひみつ / trade secret）

- 意味：秘密として管理されている生産方法・販売方法などの事業活動に役立つ技術上・営業上の情報で、公然と知られていないもの
- ポイント：三要件は「秘密管理性・有用性・非公知性」。不正に取得・使用・開示すると差止めや損害賠償、刑事罰の対象。特許とちがい登録は不要で期間の制限もないが、自分で秘密に管理しないと守られない

#### 限定提供データ（げんていていきょうでーた / shared data with limited access）

- 意味：業として特定の者に提供する情報として、電磁的な方法で相当量ためられ、管理されている技術上・営業上の情報（営業秘密を除く）
- ポイント：2018年の改正で作られた。秘密ではないが、ID・パスワードなどで提供先を限っているデータを、不正な取得や使用から守る

### 独占禁止法

#### 独占禁止法（どくせんきんしほう / Antimonopoly Act）

- 意味：私的独占・不当な取引制限（カルテル）・不公正な取引方法を禁止して、公正で自由な競争を進める法律。公正取引委員会が運用する
- ポイント：AI では、データの独占や囲いこみ、アルゴリズムを使った価格の協調（デジタル・カルテル）などが論点

#### 競争制限（きょうそうせいげん / restriction of competition）

- 意味：ある取引の分野で、競争が実質的に制限されること。私的独占や不当な取引制限の要件
- 例：同業者どうしで価格を一緒に決める（カルテル）、ライバルの事業活動を排除する

#### 公正競争阻害性（こうせいきょうそうそがいせい / tendency to impede fair competition）

- 意味：公正な競争をさまたげるおそれのこと。不公正な取引方法にあたるかどうかの判断の基準
- 例：取引先に、ほかの会社とデータを共有しないよう不当にしばる、優越的な地位を利用して不当にデータを出させる

## 問題演習

### 21-1

#### 問 gk-21-o01

- 問：著作権法の「著作物」の定義として正しいものはどれか。
- ア：思想または感情を創作的に表現したもので、文芸・学術・美術・音楽の範囲に属するもの
- イ：自然法則を利用した技術的思想の創作のうち高度のもの
- ウ：秘密として管理された事業に役立つ情報
- エ：特許庁に登録された表現
- 正解：ア
- 解説：著作物は、思想または感情を創作的に表現したもので、文芸・学術・美術・音楽の範囲に属するもの。事実やアイデア、ありふれた表現は著作物ではない。
- アの意味：正しい。
- イの意味：特許法の「発明」の定義。
- ウの意味：不正競争防止法の「営業秘密」。
- エの意味：著作権に登録は不要。
- 出典：オリジナル問題（根拠：著作権法 第二条第一項第一号（『思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するものをいう。』））

#### 問 gk-21-o02

- 問：著作権法で保護されないものとして正しいものはどれか。
- ア：小説の文章
- イ：写真
- ウ：表現に至らないアイデア（作風・画風など）
- エ：プログラムのソースコード
- 正解：ウ
- 解説：著作権法は、著作物にあたる創作的な表現を保護し、思想・学説・作風などのアイデアは保護しない（表現・アイデア二分論）。
- アの意味：言語の著作物として保護される。
- イの意味：写真の著作物として保護される。
- ウの意味：正しい。
- エの意味：プログラムの著作物として保護される（アルゴリズムそのものは保護されない）。
- 出典：オリジナル問題（根拠：文化審議会著作権分科会法制度小委員会「AI と著作権に関する考え方について」（『著作権法は、著作物に該当する創作的表現を保護し、思想、学説、作風等のアイデアは保護しない』））

#### 問 gk-21-o03

- 問：著作者の権利（著作者人格権・著作権）が生まれるために必要な手続きとして正しいものはどれか。
- ア：文化庁への登録
- イ：特許庁への出願と審査
- ウ：© マークの表示
- エ：手続きは不要で、創作した時点で生まれる
- 正解：エ
- 解説：著作者人格権と著作権を持つのに、どんな方式も必要ない（無方式主義）。存続期間は創作の時に始まる。
- アの意味：登録の制度はあるが、権利の発生には不要。
- イの意味：特許権の手続き。
- ウの意味：表示しなくても権利はある。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：著作権法 第十七条第二項（『著作者人格権及び著作権の享有には、いかなる方式の履行をも要しない。』））

#### 問 gk-21-o04

- 問：日本の著作権法で、著作権の存続期間の原則はどれか。
- ア：著作者の死後50年
- イ：著作者の死後70年
- ウ：公表から20年
- エ：出願から20年
- 正解：イ
- 解説：著作権は、別段の定めがある場合を除き、著作者の死後70年を経過するまでのあいだ存続する（2018年に50年から延長）。
- アの意味：2018年までの期間。
- イの意味：正しい。
- ウの意味：そのような規定はない。
- エの意味：特許権の存続期間。
- 出典：オリジナル問題（根拠：著作権法 第五十一条第二項（『七十年を経過するまでの間、存続する。』））

#### 問 gk-21-o05

- 問：会社の発意にもとづいて従業員が仕事として作成したプログラムの著作物の著作者は、契約などに別段の定めがない限りだれになるか。
- ア：作成した従業員
- イ：従業員と会社の共有
- ウ：会社（法人等）
- エ：プログラムを使う顧客
- 正解：ウ
- 解説：法人等の発意にもとづき、その業務に従事する者が職務上作成するプログラムの著作物の著作者は、契約・勤務規則などに別段の定めがない限り、その法人等になる（職務著作）。
- アの意味：特許の職務発明では発明者は従業者だが、職務著作はちがう。
- イの意味：共有にはならない。
- ウの意味：正しい。
- エの意味：使う人は著作者ではない。
- 出典：オリジナル問題（根拠：著作権法 第十五条第二項（『法人等の発意に基づきその法人等の業務に従事する者が職務上作成するプログラムの著作物の著作者は、その作成の時における契約、勤務規則その他に別段の定めがない限り、その法人等とする。』））

#### 問 gk-21-o06

- 問：AI の学習のための情報解析のように、著作物に表現された思想や感情を享受することを目的としない利用について定めた著作権法の規定はどれか。
- ア：第30条の4
- イ：第32条（引用）
- ウ：第35条（教育機関での複製）
- エ：第30条（私的使用のための複製）
- 正解：ア
- 解説：第30条の4は、著作物に表現された思想または感情を自ら享受し、または他人に享受させることを目的としない場合には、必要と認められる限度で、どんな方法でも利用できると定める。情報解析の用に供する場合がふくまれる。
- アの意味：正しい。
- イの意味：報道・批評・研究などのために、決まった条件で引用できる規定。
- ウの意味：学校などの授業のための複製の規定。
- エの意味：個人や家庭の中で使うための複製の規定。
- 出典：オリジナル問題（根拠：著作権法 第三十条の四（『著作物は、次に掲げる場合その他の当該著作物に表現された思想又は感情を自ら享受し又は他人に享受させることを目的としない場合には、その必要と認められる限度において、いずれの方法によるかを問わず、利用することができる。』））

#### 問 gk-21-o07

- 問：第30条の4で AI の学習に著作物を使えない場合として、ただし書に定められているものはどれか。
- ア：学習に使うデータが1万件をこえる場合
- イ：著作物の種類・用途・利用の態様に照らして、著作権者の利益を不当に害することとなる場合

- エ：学習に GPU を使う場合

- アの意味：件数の制限はない。
- イの意味：正しい。

#### 問 gk-21-o29

- 問：AI を発明者とする特許出願についての日本での扱いとして正しいものはどれか。
- ア：AI も発明者として認められる
- イ：発明者は人（自然人）に限られ、AI を発明者とする出願は認められない

- エの意味：そのような規定はない。
- 出典：オリジナル問題（根拠：特許法 第二十九条第一項（『産業上利用することができる発明をした者は、次に掲げる発明を除き、その発明について特許を受けることができる。』））
