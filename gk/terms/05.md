## 05-1 クラスタリング

### まとめ表

| 種類 | 手法 | クラスタ数 | 特徴 |
| :-: | :-: | :-: | :-: |
| 非階層型 | k-means 法 | 先に k を決める | 速い。初期値で結果が変わる |
| 階層型 | ウォード法など | 後から決められる | デンドログラムで併合の過程が見える |

### クラスタリングの手法

#### 教師なし学習（きょうしなしがくしゅう / unsupervised learning）

- 意味：正解（ラベル）のないデータから、データの背後にある構造やまとまりを見つける学習。特徴量だけが必要
- ポイント：代表的な問題はクラスタリングと次元削減

#### クラスタリング（くらすたりんぐ / clustering）

- 意味：似たデータどうしを集めて、いくつかのグループ（クラスタ）に分けること。クラスター分析
- ポイント：分類（教師あり）とちがい、グループの意味は人が後から解釈する。階層型と非階層型がある
- 例：購買の傾向で顧客をグループに分ける（顧客セグメンテーション）

#### k-means 法（けーみーんずほう / k-means clustering）

- 意味：クラスタ数 k を先に決め、各データを一番近いクラスタの中心に割り当て、中心をクラスタの平均に動かす、をくり返す非階層型のクラスタリング
- ポイント：クラスタ内の2乗誤差の合計（イナーシャ）を小さくする。最初の中心の置き方で結果が変わる（初期値依存）。k-means++ で初期値を工夫する

#### ウォード法（うぉーどほう / Ward's method）

- 意味：クラスタを1つずつ併合していく階層型クラスタリングで、併合したときのクラスタ内の2乗誤差の増え方が最も小さい組を選ぶ方法
- ポイント：まとまりのよいクラスタになりやすい。最短距離法・最長距離法・群平均法なども階層型の方法

#### デンドログラム（樹形図）（でんどろぐらむ / dendrogram）

- 意味：階層型クラスタリングで、クラスタがまとまっていく順番と距離を木の形で表した図
- ポイント：根はすべてのデータを含む1つのクラスタ、葉は1つのデータだけのクラスタ。どの高さで切るかでクラスタ数を決める

## 05-2 次元削減

### まとめ表

| 手法 | 線形／非線形 | 主な使い道 |
| :-: | :-: | :-: |
| 主成分分析（PCA） | 線形 | 情報をなるべく残して変数を減らす |
| 特異値分解（SVD） | 線形 | 行列を分解して圧縮、推薦や文書の分析 |
| 多次元尺度構成法（MDS） | 線形（古典的） | 距離の関係を保って低次元に並べる |
| t-SNE | 非線形 | 高次元データを2・3次元で見る（可視化） |

### 次元を減らす

#### 次元削減（じげんさくげん / dimensionality reduction）

- 意味：データの意味ある特性をなるべく残したまま、高次元のデータを低次元に変換すること
- ポイント：次元の呪い（#03）を和らげ、計算を軽くし、可視化しやすくする

#### 主成分分析（PCA）（しゅせいぶんぶんせき / principal component analysis）

- 意味：相関のある多くの変数から、全体のばらつき（分散）を最もよく表す、相関のない少数の変数（主成分）を作る方法
- ポイント：第1主成分は分散が最大の方向。各主成分がどれだけ情報を持つかを寄与率という。主成分どうしは直交する

#### 特異値分解（SVD）（とくいちぶんかい / singular value decomposition）

- 意味：どんな形の行列でも、3つの行列の積に分解する方法
- ポイント：大きい特異値だけ残すと、行列を少ない情報で近似できる。文書×単語の行列に使うと潜在意味解析（LSA）

#### 多次元尺度構成法（MDS）（たじげんしゃくどこうせいほう / multidimensional scaling）

- 意味：データどうしの距離（似ていなさ）が、元の高次元での距離とできるだけ同じになるように、低次元に並べる方法
- ポイント：古典的 MDS でユークリッド距離を使うと主成分分析と同じになる

#### t-SNE（てぃーすにー / t-distributed Stochastic Neighbor Embedding）

- 意味：高次元のデータを、近いものは近くに並ぶように2次元や3次元に埋め込む、非線形の次元削減。主に可視化に使う
- ポイント：近さを確率で表し、低次元では t 分布を使う。ヒントンらの SNE をファン・デル・マーテンが t 分布にした
- 語の意味：t-distributed＝t分布の、Stochastic＝確率的、Neighbor＝近傍、Embedding＝埋め込み

## 05-3 推薦とトピックモデル

### まとめ表

| 手法 | 使う情報 | 弱点 |
| :-: | :-: | :-: |
| 協調フィルタリング | ほかの利用者の行動（評価・購入） | コールドスタート問題 |
| コンテンツベースフィルタリング | 商品そのものの特徴 | 似たものばかりすすめる |

### 推薦

#### 協調フィルタリング（きょうちょうふぃるたりんぐ / collaborative filtering）

- 意味：多くの利用者の好みの記録を集め、好みが似たほかの利用者の情報を使っておすすめを決める方法
- 例：「この商品を買った人はこんな商品も買っています」

#### コンテンツベースフィルタリング（こんてんつべーすふぃるたりんぐ / content-based filtering）

- 意味：商品そのものの特徴（ジャンル・作者など）と利用者の好みを比べておすすめを決める方法
- ポイント：ほかの利用者の記録がなくても使えるので、新しい商品のコールドスタートに強い

#### コールドスタート問題（こーるどすたーともんだい / cold start problem）

- 意味：新しい利用者や新しい商品には行動の記録がないため、協調フィルタリングでうまくすすめられない問題
- ポイント：新しいサービス・新しい商品・新しい利用者の3つの場合がある。コンテンツベースと組み合わせて補う

### 文書の話題

#### トピックモデル（とぴっくもでる / topic model）

- 意味：文書の集まりから、そこに隠れている話題（トピック）を見つける統計モデル
- 例：「犬」「骨」が多い文書は犬の話題、「猫」「ニャー」が多い文書は猫の話題

#### 潜在的ディリクレ配分法（LDA）（せんざいてきでぃりくれはいぶんほう / latent Dirichlet allocation）

- 意味：1つの文書は複数のトピックが混ざってできており、単語はそれぞれのトピックから出てくる、と考える代表的なトピックモデル
- ポイント：1つの文書に複数のトピックを割り当てられる（ソフトクラスタリング）。線形判別分析（これも LDA と略す）とは別物
