## 17-1 転移学習・ファインチューニング

### まとめ表

| 用語 | 中身 |
| :-: | :-: |
| 事前学習 | 大量のデータで、まず一般的な特徴を学ぶ |
| 転移学習 | ある問題で得た知識を、関連する別の問題に使う。学習済みの層は固定し、最後の層などだけ学ぶことが多い |
| ファインチューニング | 事前学習済みのモデルのパラメータを、新しいデータで追加学習して調整する |
| 自己教師あり学習 | データそのものから作った正解（隠した単語など）で学ぶ |
| 半教師あり学習 | 少しのラベルつきデータと、たくさんのラベルなしデータを組み合わせる |
| Few-shot／One-shot | 少しの例（1つの例）だけで学ぶ・こなす |
| 破滅的忘却 | 新しいことを学ぶと、前に学んだことを急に忘れる |

### 事前学習を生かす

#### 事前学習・事前学習済みモデル（じぜんがくしゅう / pre-training, pre-trained model）

- 意味：事前学習は、本来のタスクの前に、大量のデータでモデルに一般的な特徴を学ばせること。そうしてできたモデルを事前学習済みモデルという
- 例：ImageNet で学習した ResNet、大量の文章で学習した BERT・GPT

#### 転移学習（てんいがくしゅう / transfer learning）

- 意味：ある問題を解くときに得た知識をためておき、関連する別の問題に使う機械学習の考え方
- ポイント：乗用車の認識で得た知識を、トラックの認識に使うなど。データが少ない新しいタスクで効く。狭い意味では、学習済みの層の重みは固定し、出力に近い層だけを新しく学ぶことをいう

#### ファインチューニング（ふぁいんちゅーにんぐ / fine-tuning）

- 意味：事前学習済みのニューラルネットワークのパラメータに、新しいデータで追加の学習をして、別の（多くはより特定の）タスクに合わせること
- ポイント：ネットワーク全体を学び直すことも、一部の層だけを学び直すこともある。転移学習より多くのパラメータを動かすことが多い

### ラベルの少なさを補う

#### 自己教師あり学習（じこきょうしありがくしゅう / self-supervised learning）

- 意味：外から与えるラベルに頼らず、データそのものから作った教師信号でモデルを学習する方法
- ポイント：文の単語を隠して当てる（BERT）、次の単語を当てる（GPT）、画像の一部を隠して当てるなど。基盤モデルの事前学習の中心

#### 半教師あり学習（はんきょうしありがくしゅう / semi-supervised learning）

- 意味：少しの人手のラベルつきデータと、たくさんのラベルなしデータを組み合わせて学習する方法
- ポイント：ラベルづけは費用と時間がかかるので、ラベルなしデータも生かす

#### Few-shot・One-shot（ふゅーしょっと・わんしょっと / few-shot, one-shot）

- 意味：Few-shot は、クラスごとに少しのラベルつきの例だけでタスクをこなすこと。One-shot は、1つの例だけでこなすこと
- ポイント：GPT-3 は、プロンプトに例をいくつか書くだけで新しいタスクをこなした（#15）。例が0個なら Zero-shot（17-2）

#### 破滅的忘却（はめつてきぼうきゃく / catastrophic forgetting, catastrophic interference）

- 意味：ニューラルネットワークが新しい情報を学ぶと、前に学んだ情報を急に、完全に忘れてしまう傾向
- ポイント：ファインチューニングや、タスクを順に学ぶ継続学習で問題になる。前のタスクに大事な重みの学習をゆっくりにする EWC などの対策がある。「破壊的忘却」はシラバスの旧表記

## 17-2 マルチモーダル

### まとめ表

| モデル・タスク | 中身 |
| :-: | :-: |
| CLIP | 4億組の画像と文章で、どの説明文がどの画像に合うかを学ぶ。Zero-shot で分類 |
| DALL-E | 文章から画像を作る（Text-to-Image） |
| Flamingo | 画像・動画と文章がまざった入力で、少しの例から新しいタスクをこなす |
| Image Captioning | 画像の内容を説明する文を作る |
| VQA | 画像と質問から答えを出す |
| Unified-IO | 画像・言語の多くのタスクを、すべてトークンの列にして1つのモデルで |

### 基本の考え方

#### マルチモーダル（まるちもーだる / multimodal）

- 意味：画像・文章・音声など、種類（モダリティ）のちがう複数のデータをあわせて扱うこと
- 例：画像に説明文をつける、文章から画像を作る、画像について質問に答える

#### 基盤モデル（きばんもでる / foundation model）

- 意味：自己教師あり学習などで膨大なデータで学習し、さまざまな下流のタスクに合わせて使える大規模なモデル
- ポイント：2021年8月にスタンフォード大学の研究センターが名づけた。BERT・GPT-3・DALL-E などが例。言語に限らない点で、LLM より広い言葉

#### Zero-shot（ぜろしょっと / zero-shot learning）

- 意味：学習のときに見ていないクラスのデータを、テストのときに分類するなど、例を1つも見せずにタスクをこなすこと
- ポイント：「シマウマはしま模様の馬」という説明があれば、馬しか見ていないモデルでもシマウマを当てられる。CLIP は文章で書いたクラス名だけで画像を分類できる

#### マルチタスク学習（まるちたすくがくしゅう / multi-task learning）

- 意味：関連する複数のタスクを、共有の表現を使って同時に学習し、それぞれのタスクの汎化性能を上げる方法
- ポイント：あるタスクで学んだことがほかのタスクの学習を助ける

### 代表的なモデルとタスク

#### CLIP（くりっぷ / Contrastive Language-Image Pre-training）

- 意味：インターネットから集めた4億組の画像と文章を使い、どの説明文がどの画像に合うかを当てる事前学習で、画像の表現を学ぶ OpenAI のモデル
- ポイント：事前学習のあとは、文章で書いたクラス名を使って、追加の学習なし（Zero-shot）で画像を分類できる。対照学習

#### DALL-E（だりー / DALL-E）

- 意味：文章から画像を作る（Text-to-Image）OpenAI のモデル
- ポイント：最初の DALL-E は、文章と画像のトークンを1つの列として自己回帰の Transformer で扱った。DALL-E 2 は拡散モデルを使う（#16）

#### Text-To-Image（てきすとついめーじ / text-to-image generation）

- 意味：文章（プロンプト）から、それに合った画像を作るタスク
- 例：DALL-E、Stable Diffusion、Imagen

#### Flamingo（ふらみんご / Flamingo）

- 意味：DeepMind の視覚言語モデル（VLM）。学習済みの画像だけのモデルと言語だけのモデルをつなぎ、画像・動画と文章がまざった入力を扱う
- ポイント：少しの例（few-shot）をプロンプトに入れるだけで、新しいタスクにすぐ合わせられる

#### Image Captioning（いめーじきゃぷしょにんぐ / image captioning）

- 意味：画像の内容を説明する自然な文を自動で作るタスク
- ポイント：コンピュータビジョンと自然言語処理をつなぐ。CNN で画像を読み、RNN（LSTM）で文を作る Show and Tell が代表

#### VQA（ぶいきゅーえー / Visual Question Answering）

- 意味：画像と、その画像についての自然言語の質問から、正しい答えを自然言語で出すタスク
- ポイント：質問によって画像の別の部分を見る必要があるので、ただ説明文を作るより細かい理解と推論が要る。目の不自由な人の支援などに使える

#### Unified-IO（ゆないふぁいどあいおー / Unified-IO）

- 意味：姿勢推定・物体検出・画像生成・説明文・質問応答など、画像と言語のとても多くのタスクを1つのモデルでこなす方法
- ポイント：画像・マスク・枠・言語など、ちがう形の入力と出力を、すべて離散のトークンの列にそろえる

## 17-3 モデルの解釈性

### まとめ表

| 手法 | 中身 |
| :-: | :-: |
| CAM | 全体平均プーリングを使い、クラスの判断に効いた画像の場所を示す |
| Grad-CAM | 最後の畳み込み層に流れる勾配で、重要な場所を示す。構造を変えずに多くの CNN に使える |
| LIME | 予測の近くで、解釈しやすい簡単なモデルで近似して説明する（どんなモデルにも） |
| SHAP | シャープレイ値で、特徴量ごとの予測への貢献を出す |
| Permutation Importance | 特徴量の値をシャッフルしたときの性能の下がり方で、重要度を測る |

### 説明が必要なわけ

#### 説明可能 AI（XAI）（せつめいかのうえーあい / explainable artificial intelligence）

- 意味：AI が出した答えについて、人が納得できる根拠を示すための技術
- ポイント：深層学習はブラックボックスになりやすい。医療の診断・自動運転・融資の審査など、影響の大きい分野で、信頼・説明責任・誤りの発見のために必要

### 画像のどこを見たか

#### CAM（きゃむ / Class Activation Mapping）

- 意味：最後の畳み込み層のあとに全体平均プーリング（GAP）を置いたネットワークで、そのクラスの判断に効いた画像の場所をヒートマップで示す方法
- ポイント：画像単位のラベルだけで学習したのに、物の位置を示せる。ネットワークの構造が GAP のある形でないと使えない

#### Grad-CAM（ぐらっどきゃむ / Gradient-weighted Class Activation Mapping）

- 意味：あるクラスの値から最後の畳み込み層に流れこむ勾配を使って、予測に重要な画像の場所を示す方法
- ポイント：CAM とちがい、構造を変えたり学習し直したりせずに、全結合層のある CNN などの多くのモデルに使える

### 特徴量の重要さ

#### LIME（らいむ / Local Interpretable Model-agnostic Explanations）

- 意味：1つの予測のまわりで、解釈しやすい簡単なモデル（線形モデルなど）を学習して近似し、その予測の理由を説明する方法
- ポイント：どんな分類器にも使える（model-agnostic）。局所的（その予測の近く）な説明
- 語の意味：local＝局所の、interpretable＝解釈できる、model-agnostic＝モデルを問わない

#### SHAP（しゃっぷ / SHapley Additive exPlanations）

- 意味：ゲーム理論のシャープレイ値を使って、1つの予測に対する各特徴量の重要度（貢献）を出す、予測の解釈の統一的な枠組み
- ポイント：特徴量の貢献を足すと予測になる（加法的）。LIME など前からあった方法をまとめた

#### Permutation Importance（ぱーみゅてーしょんいんぽーたんす / permutation importance）

- 意味：ある特徴量の値を全サンプルのあいだでランダムに並べかえ（シャッフルし）、モデルの性能がどれだけ下がるかで、その特徴量の重要度を測る方法
- ポイント：大きく下がるほど、その特徴量が大事。モデル全体（大局的）の重要度

## 17-4 モデルの軽量化

### まとめ表

| 手法 | 中身 |
| :-: | :-: |
| 蒸留 | 大きなモデル（教師）の知識を、小さなモデル（生徒）に移す |
| プルーニング（枝刈り） | 大事でない重み（結合）を取り除く |
| 量子化 | 重みや活性化の数値の精度（ビット数）を下げる。32ビットの小数 → 8ビットの整数など |
| 宝くじ仮説 | ランダムに初期化した大きなネットワークの中に、単独で学んでも同じくらいの性能になる小さな部分ネットワーク（当たりくじ）がある |

### 軽くする理由

#### エッジ AI（えっじえーあい / edge AI）

- 意味：クラウドではなく、スマートフォン・カメラ・車など、利用者や端末の近く（ネットワークの端）で AI の推論を行うこと
- ポイント：応答が速い、通信が少なくて済む、データを外に出さないのでプライバシーを守りやすい。端末の計算力・メモリ・電力が限られるので軽量化が必要

#### モデル圧縮（もでるあっしゅく / model compression）

- 意味：学習済みのモデルを、性能をあまり落とさずに小さく、速くする技術の総称
- ポイント：蒸留・プルーニング・量子化などがある。スマートフォンや組みこみ機器などの資源が限られた機器で動かせるようになる

### 代表的な手法

#### 蒸留（知識蒸留）（じょうりゅう / knowledge distillation）

- 意味：大きなモデル（教師モデル）の知識を、小さなモデル（生徒モデル）に移す方法
- ポイント：生徒は正解ラベルだけでなく、教師の出力の確率の分布（ソフトターゲット）もまねて学ぶ。多数のモデルのアンサンブルの知識を1つのモデルにまとめることもできる

#### プルーニング（枝刈り）（ぷるーにんぐ / pruning）

- 意味：学習済みのニューラルネットワークから、大事でないパラメータ（結合）を取り除くこと
- ポイント：学習 → 大事でない結合を取り除く → 残りを再学習（ファインチューニング）の3段階。精度を落とさずに、パラメータを1けた減らせることもある

#### 量子化（りょうしか / quantization）

- 意味：重みや活性化の数値の精度を下げる（ビット数を減らす）こと
- ポイント：32ビットの浮動小数点を 8ビットの整数にすると、メモリが減り、整数の計算だけで速く推論できる。#15 の音声の「量子化」（アナログの値を段階に丸める）と考え方は同じ

#### 宝くじ仮説（たからくじかせつ / lottery ticket hypothesis）

- 意味：ランダムに初期化した大きなネットワークの中には、それだけを単独で学習しても、元のネットワークと同じくらいの性能になる部分ネットワーク（当たりくじ）がふくまれている、という仮説
- ポイント：その部分ネットワークは、学習のあとにプルーニングで見つけられる。2018年にフランクルらが発表した

## 問題演習

### 17-1

#### 問 gk-17-o01

- 問：ある問題を解くときに得た知識をためておき、関連する別の問題に使うことに焦点を当てた機械学習の考え方はどれか。
- ア：アンサンブル学習
- イ：強化学習
- ウ：転移学習
- エ：オンライン学習
- 正解：ウ
- 解説：転移学習は、ある問題で得た知識を、関連する別の問題に適用する。乗用車の認識で得た知識をトラックの認識に使うなど。
- アの意味：複数のモデルの予測を組み合わせる（#04）。
- イの意味：報酬を手がかりに行動を学ぶ（#06）。
- ウの意味：正しい。
- エの意味：データが届くたびに少しずつモデルを更新する学習。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「転移学習」（『ある問題を解決する際に得た知識を蓄積し、関連する別の問題にそれを適用することに焦点を当てた機械学習の研究領域である』））

#### 問 gk-17-o02

- 問：事前学習済みのニューラルネットワークのパラメータに、新しいデータで追加の学習をして、別のタスクに合わせることを何というか。
- ア：ファインチューニング
- イ：プルーニング
- ウ：蒸留
- エ：データ拡張
- 正解：ア
- 解説：ファインチューニングは、事前学習済みのネットワークのパラメータに追加の学習を行う。ネットワーク全体にも、一部の層だけにも行える。
- アの意味：正しい。
- イの意味：大事でない結合を取り除く軽量化。
- ウの意味：大きなモデルの知識を小さなモデルに移す。
- エの意味：画像を加工して学習データを増やす（#13）。
- 出典：オリジナル問題（根拠：ウィキペディア英語版「Fine-tuning (deep learning)」（『Fine-tuning involves applying additional training (e.g., on new data) to the parameters of a neural network that have been pre-trained.』））

#### 問 gk-17-o03

- 問：外から与えるラベルに頼らず、データそのものから作った教師信号でモデルを学習する方法はどれか。
- ア：教師あり学習
- イ：自己教師あり学習
- ウ：強化学習
- エ：半教師あり学習
- 正解：イ
- 解説：自己教師あり学習は、外部から提供されるラベルに依存せず、データ自体から生成される教師信号でモデルを訓練する。文の単語を隠して当てるなど。
- アの意味：人がつけた正解ラベルで学ぶ。
- イの意味：正しい。
