## 07-1 汎化と過学習

### まとめ表

| 状態 | 訓練データでの誤差 | 未知データでの誤差 | 原因の例 |
| :-: | :-: | :-: | :-: |
| 未学習（過少適合） | 大きい | 大きい | モデルが単純すぎる（バイアスが大きい） |
| ちょうどよい | 小さい | 小さい | ― |
| 過学習（過剰適合） | とても小さい | 大きい | モデルが複雑すぎる・データが少ない（バリアンスが大きい） |

### 汎化

#### 汎化性能（はんかせいのう / generalization performance）

- 意味：学習に使っていない未知のデータに対しても、正しく予測できる力
- ポイント：機械学習の本当の目的は、訓練データでの成績ではなく汎化性能を高めること

#### 訓練誤差（くんれんごさ / training error）

- 意味：学習に使った訓練データに対する、予測と正解のずれ
- ポイント：訓練誤差が小さくても、汎化誤差が小さいとは限らない（過学習）

#### 汎化誤差（はんかごさ / generalization error）

- 意味：未知のデータに対する予測と正解のずれ（の期待値）。実際にはテストデータでの誤差（テスト誤差）で見積もる
- ポイント：モデルの良し悪しは汎化誤差で決める

### 過学習と未学習

#### 過学習（かがくしゅう / overfitting）

- 意味：訓練データには合いすぎているが、未知のデータにはうまく合わない状態。過剰適合ともいう
- ポイント：モデルが訓練データの数に比べて複雑すぎる（パラメータが多すぎる）と起きやすい。訓練誤差は下がり続けるのに、検証誤差が上がり始めたら過学習のサイン
- 例：訓練データの点を全部通る、ぐねぐねの曲線
- 語の意味：over＝〜しすぎ、fit＝合わせる

#### 未学習（みがくしゅう / underfitting）

- 意味：モデルが単純すぎて、訓練データにさえうまく合わない状態。過少適合ともいう
- ポイント：訓練誤差も汎化誤差も大きい。過学習の反対
- 例：曲線のデータに直線を当てはめる

### バイアスとバリアンス

#### バイアス（ばいあす / bias）

- 意味：モデルの予測の平均が、本当の値からどれだけずれているか（かたより）
- ポイント：モデルが単純すぎるとバイアスが大きくなる（未学習）

#### バリアンス（ばりあんす / variance）

- 意味：訓練データが変わったときに、モデルの予測がどれだけばらつくか（分散）
- ポイント：モデルが複雑すぎるとバリアンスが大きくなる（過学習）

#### バイアス-バリアンスのトレードオフ（ばいあすばりあんすのとれーどおふ / bias-variance tradeoff）

- 意味：バイアスを減らそうとするとバリアンスが増え、バリアンスを減らそうとするとバイアスが増える関係
- ポイント：汎化誤差の期待値は「バイアス＋バリアンス＋ノイズ」に分けられる（バイアス-バリアンス分解）。ノイズはモデルでは減らせない
- 例：多項式の次数を上げると、バイアスは下がりバリアンスは上がる

## 07-2 データの分け方と検証

### まとめ表

| 方法 | 分け方 | 特徴 |
| :-: | :-: | :-: |
| ホールドアウト検証 | 訓練用と評価用に1回だけ分ける | 簡単。分け方しだいで結果がぶれる |
| k分割交差検証 | k 個に分け、1つを評価用・残りを訓練用にして k 回くり返す | k 回の平均で評価。計算は k 倍 |
| 一個抜き交差検証（LOOCV） | 1件だけを評価用、残り全部を訓練用 | k＝データ数の k 分割。データが少ないとき向き |
| 層化 k 分割 | 各分割のクラスの割合をそろえる | クラスの数がかたよったデータ向き |

### データの役割

#### 訓練データ・検証データ・テストデータ（くんれんでーた・けんしょうでーた・てすとでーた / training data, validation data, test data）

- 意味：訓練データはパラメータの学習に、検証データはハイパーパラメータの調整やモデルの選択に、テストデータは最後の性能評価に使う
- ポイント：テストデータは調整に使わず、最後に1回だけ使う。調整に使うとテストデータに合わせこんでしまい、評価が甘くなる

#### データリーケージ（でーたりーけーじ / data leakage）

- 意味：本来は予測の時点で使えない情報（正解やテストデータの情報）が、学習に紛れこむこと
- ポイント：評価は高く出るのに、本番では性能が出ない
- 例：前処理の標準化の平均を、テストデータもまぜて計算してしまう
- 語の意味：leakage＝漏れ

### 検証の方法

#### ホールドアウト検証（ほーるどあうとけんしょう / hold-out validation）

- 意味：データを訓練用と評価用に1回だけ分け、評価用のデータで性能をはかる方法
- ポイント：一般には交差検証に入れない。データが少ないと、分け方しだいで結果が大きく変わる
- 語の意味：hold out＝取っておく

#### 交差検証（こうさけんしょう / cross-validation）

- 意味：データを分け、一部で学習し、残りでテストすることを、組み合わせを変えてくり返し、性能を確かめる方法。交差確認ともいう
- ポイント：全部のデータが一度は評価に使われるので、少ないデータでも安定して評価できる

#### k分割交差検証（けーぶんかつこうさけんしょう / k-fold cross-validation）

- 意味：データを k 個のグループに分け、1つを評価用、残り k−1 個を訓練用にして学習・評価を k 回くり返し、平均をとる方法
- ポイント：k 回学習するので計算が k 倍かかる

#### 一個抜き交差検証（いっこぬきこうさけんしょう / leave-one-out cross-validation, LOOCV）

- 意味：1件だけを評価用、残りすべてを訓練用にして、全件についてくり返す方法
- ポイント：k 分割の k をデータ数にしたもの。計算量は一番多い

#### 層化 k 分割交差検証（そうかけーぶんかつこうさけんしょう / stratified k-fold cross-validation）

- 意味：各グループの中のクラスの割合が、全体とほぼ同じになるように分ける k 分割交差検証
- ポイント：陽性が少ないなど、クラスの数がかたよったデータで使う
- 語の意味：stratified＝層に分けた

## 07-3 分類の評価指標

### まとめ表

| | 予測：陽性 | 予測：陰性 |
| :-: | :-: | :-: |
| 実際：陽性 | 真陽性 TP | 偽陰性 FN |
| 実際：陰性 | 偽陽性 FP | 真陰性 TN |

| 指標 | 式 | 意味 |
| :-: | :-: | :-: |
| 正解率 | (TP＋TN)÷全体 | 全体のうち当たった割合 |
| 適合率 | TP÷(TP＋FP) | 陽性と予測したうち本当に陽性の割合 |
| 再現率 | TP÷(TP＋FN) | 本当の陽性のうち見つけられた割合 |
| F値 | 2×適合率×再現率÷(適合率＋再現率) | 適合率と再現率の調和平均 |
| 偽陽性率 | FP÷(FP＋TN) | 本当の陰性のうち陽性と誤った割合 |

### 混同行列

#### 混同行列（こんどうぎょうれつ / confusion matrix）

- 意味：分類の予測結果を、実際のクラスと予測したクラスの組み合わせごとに数えた表。2クラスなら2行2列
- ポイント：正解率・適合率・再現率などの指標は、すべて混同行列の4つの数から計算する

#### 真陽性・真陰性・偽陽性・偽陰性（しんようせい・しんいんせい・ぎようせい・ぎいんせい / true positive, true negative, false positive, false negative）

- 意味：真陽性（TP）は陽性を陽性と当てた数、真陰性（TN）は陰性を陰性と当てた数、偽陽性（FP）は陰性を陽性と誤った数、偽陰性（FN）は陽性を陰性と誤った数
- ポイント：「真/偽」は予測が当たったか、「陽性/陰性」は予測した側。偽陽性は第1種の誤り、偽陰性は第2種の誤り
- 例：病気の検査で、病気でない人を「病気」と判定するのが偽陽性、病気の人を見逃すのが偽陰性

### 指標

#### 正解率（せいかいりつ / accuracy）

- 意味：全データのうち、予測が当たった割合
- ポイント：クラスの数がかたよっていると役に立たない。陽性が1%なら、全部「陰性」と答えるだけで正解率99%になる

#### 適合率（てきごうりつ / precision）

- 意味：陽性と予測したもののうち、本当に陽性だった割合。精度ともいう
- ポイント：偽陽性を減らしたいとき（誤検知が困るとき）に重視する
- 例：迷惑メールのフィルタ（普通のメールを迷惑メールにしたくない）

#### 再現率（さいげんりつ / recall）

- 意味：本当に陽性のもののうち、陽性と予測できた割合。真陽性率・感度ともいう
- ポイント：偽陰性を減らしたいとき（見逃しが困るとき）に重視する。適合率とトレードオフの関係
- 例：病気の検査（病気の人を見逃したくない）

#### F値（えふち / F-measure, F1 score）

- 意味：適合率と再現率の調和平均
- ポイント：どちらか一方だけが高くても F 値は高くならない。両方のバランスを見る

#### ROC曲線（あーるおーしーきょくせん / ROC curve）

- 意味：分類のしきい値を変えながら、横軸に偽陽性率、縦軸に真陽性率（再現率）をとって描いた曲線
- ポイント：左上に近いほどよいモデル。ランダムな予測は対角線になる
- 語の意味：Receiver Operating Characteristic＝受信者操作特性（もとはレーダーの信号の検出から）

#### AUC（えーゆーしー / area under the curve）

- 意味：ROC曲線の下の面積。0〜1 の値をとる
- ポイント：1 が最良、ランダムなモデルは 0.5。しきい値によらずにモデルを比べられる
- 語の意味：Area Under the Curve＝曲線の下の面積

## 07-4 回帰の評価とモデルの選び方

### まとめ表

| 指標・規準 | 中身 | ポイント |
| :-: | :-: | :-: |
| MSE | 誤差の2乗の平均 | 大きな外れに敏感 |
| RMSE | MSE の平方根 | 単位が元のデータと同じ |
| MAE | 誤差の絶対値の平均 | 外れ値の影響が小さい |
| AIC | −2×最大対数尤度＋2×パラメータ数 | 小さいほどよい |
| BIC | −2×最大対数尤度＋パラメータ数×log(データ数) | AIC よりパラメータ数への罰が重い |

### 回帰の指標

#### 平均二乗誤差（MSE）（へいきんにじょうごさ / mean squared error）

- 意味：予測値と実際の値の差を2乗して平均した値
- ポイント：2乗するので、大きく外れた予測がとくに重く数えられる。小さいほどよい

#### 二乗平均平方根誤差（RMSE）（にじょうへいきんへいほうこんごさ / root mean squared error）

- 意味：MSE の平方根
- ポイント：元のデータと同じ単位になるので、誤差の大きさがわかりやすい
- 語の意味：root＝平方根、mean＝平均、squared＝2乗した

#### 平均絶対誤差（MAE）（へいきんぜったいごさ / mean absolute error）

- 意味：予測値と実際の値の差の絶対値を平均した値
- ポイント：2乗しないので、MSE より外れ値の影響を受けにくい

### モデルの選び方

#### 赤池情報量規準（AIC）（あかいけじょうほうりょうきじゅん / Akaike's information criterion）

- 意味：モデルのデータへの当てはまりのよさと、パラメータの数（複雑さ）の両方から、モデルのよさを評価する指標。赤池弘次が考案した
- ポイント：値が小さいモデルを選ぶ。パラメータを増やすと当てはまりはよくなるが、罰も増える

#### ベイズ情報量規準（BIC）（べいずじょうほうりょうきじゅん / Bayesian information criterion）

- 意味：AIC と同じく当てはまりと複雑さから評価する情報量規準。シュワルツ情報量規準ともいう
- ポイント：パラメータ数の罰にデータ数の対数がかかるので、データが多いと AIC より単純なモデルを選びやすい

#### オッカムの剃刀（おっかむのかみそり / Occam's razor）

- 意味：「ある事柄を説明するのに、必要以上に多くの仮定をおくべきでない」という考え方
- ポイント：同じくらい説明できるなら単純なモデルを選ぶ。AIC・BIC や正則化の考え方につながる
- 語の意味：14世紀の哲学者オッカムのウィリアムにちなむ。剃刀＝余計なものをそぎ落とすたとえ

## 問題演習

### 07-1

#### 問 gk-07-o01

- 問：過学習（過剰適合）の説明として正しいものはどれか。
- ア：訓練データにも未知のデータにもうまく合わない状態
- イ：訓練データの数を増やしすぎた状態
- ウ：訓練データには合っているが、未知のデータにはうまく合わない状態
- エ：学習率が小さすぎて学習が終わらない状態
- 正解：ウ
- 解説：過剰適合（過学習）は、訓練データに対しては学習されているが、未知のデータ（テストデータ）には適合できていない、汎化できていない状態をいう。
- アの意味：未学習（過少適合）。
- イの意味：データを増やすことは、むしろ過学習を防ぐ方法の一つ。
- ウの意味：正しい。
- エの意味：学習の収束が遅いことで、過学習とは別の話（#10）。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「過剰適合」（『過剰適合（かじょうてきごう、英: overfitting）や過適合（かてきごう）や過学習（かがくしゅう、英: overtraining）とは、統計学や機械学習において、訓練データに対して学習されているが、未知データ（テストデータ）に対しては適合できていない、汎化できていない状態を指す。』））

#### 問 gk-07-o02

- 問：過学習が起きやすい原因として最も適切なものはどれか。
- ア：モデルが単純すぎる
- イ：訓練データの個数に比べて、モデルが複雑でパラメータが多すぎる
- ウ：テストデータを最後に1回だけ使った
- エ：交差検証で評価した
- 正解：イ
- 解説：訓練データの個数に比べてモデルが複雑で自由度が高すぎると、訓練データのノイズまで覚えてしまい過学習が起きる。
- アの意味：単純すぎるモデルは未学習の原因。
- イの意味：正しい。
- ウの意味：テストデータの正しい使い方で、過学習の原因ではない。
- エの意味：交差検証は性能を確かめる方法で、過学習の原因ではない。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「過剰適合」（『その原因の一つとして、統計モデルへの適合の媒介変数が多すぎる等、訓練データの個数に比べて、モデルが複雑で自由度が高すぎることがある。』））

#### 問 gk-07-o03

- 問：過学習の反対の状態で、モデルが単純すぎて訓練データにもうまく合わない状態を何というか。
- ア：未学習（過少適合）
- イ：汎化
- ウ：データリーケージ
- エ：早期終了
- 正解：ア
- 解説：過剰適合の対義語は過少適合（underfitting）で、訓練誤差も汎化誤差も大きい。
- アの意味：正しい。
- イの意味：未知のデータにもうまく合うこと。めざす状態。
- ウの意味：使えないはずの情報が学習に紛れこむこと。
- エの意味：検証誤差が上がり始めたら学習を止め、過学習を防ぐ方法（#09）。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「過剰適合」（『対義語は過少適合（かしょうてきごう、英: underfitting）や過小学習（かしょうがくしゅう、英: undertraining）。』））

#### 問 gk-07-o04

- 問：学習の途中で、訓練誤差は下がり続けているのに、検証データでの誤差が上がり始めた。何が起きていると考えられるか。
- ア：未学習
- イ：勾配消失
- ウ：データ拡張
- エ：過学習
- 正解：エ
- 解説：訓練データにだけ合わせこみ、未知のデータに近い検証データで成績が悪くなるのは過学習のサイン。scikit-learn のガイドも、訓練に使ったデータでテストすると完璧な点が出るのに未知のデータでは役に立たない状況を overfitting と呼んでいる。
- アの意味：未学習なら訓練誤差も大きいまま。
- イの意味：深い層で勾配が小さくなり、学習が進まないこと（#08）。
- ウの意味：データを加工して水増しする方法（#13）。
- エの意味：正しい。
