## 19-1 代表値とばらつき

### まとめ表

| 用語 | 求め方 | 例（2, 3, 3, 4, 8） |
| :-: | :-: | :-: |
| 平均 | 合計 ÷ 個数 | 20 ÷ 5 ＝ 4 |
| 中央値 | 小さい順に並べてまん中 | 3 |
| 最頻値 | いちばん多く出る値 | 3 |
| 分散 | （平均との差）の2乗の平均 | (4＋1＋1＋0＋16) ÷ 5 ＝ 4.4 |
| 標準偏差 | 分散の平方根 | √4.4 ≒ 2.1 |

### 代表値

#### 平均（へいきん / mean）

- 意味：データの値をすべて足して、個数で割った値（算術平均）。データの平均的な値を表す
- ポイント：外れ値の影響を強く受ける。年収のように一部にとても大きな値があると、多くの人の感覚より大きくなる

#### 中央値（ちゅうおうち / median）

- 意味：データを小さい順に並べたとき、まん中の順位にある値。個数が偶数なら、まん中の2つの平均
- ポイント：外れ値の影響を受けにくい

#### 最頻値（さいひんち / mode）

- 意味：データや確率分布で、いちばん頻度（度数・確率）が大きい値。モード
- ポイント：数でない（カテゴリの）データにも使える

#### 度数分布（どすうぶんぷ / frequency distribution）

- 意味：データをいくつかの区間（階級）に分け、それぞれに入る個数（度数）を数えて表にしたもの。グラフにしたものがヒストグラム
- ポイント：データの分布の形（山がいくつか、かたよりがあるか）がひと目で分かる

#### 外れ値（はずれち / outlier）

- 意味：ほかの値から大きく外れた値
- ポイント：測りまちがいのこともあれば、本当にまれなできごと（不正など）のこともある。取り除くかどうかは理由を考えて決める。平均や分散を大きく動かす

### ばらつき

#### 分散（ぶんさん / variance）

- 意味：データの各値と平均との差（偏差）を2乗し、その平均をとった値。データの散らばりの大きさを表す
- ポイント：標準偏差の2乗。単位も元のデータの2乗になる（cm なら cm²）

#### 標準偏差（ひょうじゅんへんさ / standard deviation）

- 意味：分散の平方根。データの値が平均からどれくらい散らばっているかを表す
- ポイント：元のデータと単位が同じなので、ばらつきの大きさを直感的に比べやすい

#### 移動平均（いどうへいきん / moving average）

- 意味：時系列のデータで、ある長さの区間の平均を、区間を1つずつずらしながら計算していく方法
- ポイント：細かい上下の動きをならして（平滑化）、大きな傾向を見やすくする
- 例：株価の25日移動平均

## 19-2 2つの変数の関係と距離

### まとめ表

| 用語 | 中身 |
| :-: | :-: |
| 共分散 | 2つの変数の偏差の積の平均。正なら一緒に増える。単位に左右される |
| 相関係数 | 共分散を、2つの標準偏差の積で割ったもの。−1〜1 |
| 偏相関係数 | ほかの変数の影響を取り除いた相関 |
| 疑似相関 | 因果関係がないのに、第3の要因で相関があるように見える |
| ユークリッド距離 | 定規で測るような、ふつうの直線の距離 |
| コサイン類似度 | 2つのベクトルの向きの近さ（なす角のコサイン）。−1〜1 |
| マハラノビス距離 | データの相関（ばらつき）を考えた距離 |

### 関係の強さ

#### 共分散（きょうぶんさん / covariance）

- 意味：2つの変数の、それぞれの平均からの差（偏差）を掛け合わせ、その平均をとった値
- ポイント：正なら一方が大きいともう一方も大きい傾向、負なら逆。単位によって値の大きさが変わるので、関係の強さは比べにくい

#### 相関係数（そうかんけいすう / correlation coefficient）

- 意味：2つの変数の関係の強さを測る指標。共分散を、それぞれの標準偏差の積で割って求める（ピアソンの相関係数）
- ポイント：−1 から 1 の値をとる。1 に近いほど正の、−1 に近いほど負の直線的な関係が強く、0 なら直線的な関係がない。相関があっても因果関係があるとは限らない

#### 偏相関係数（へんそうかんけいすう / partial correlation coefficient）

- 意味：ほかの変数（第3の変数）の影響を取り除いたうえで、2つの変数の関係の強さを測る相関係数
- ポイント：疑似相関を見分けるのに使う

#### 疑似相関（ぎじそうかん / spurious correlation）

- 意味：2つのできごとに因果関係がないのに、見えない第3の要因（潜伏変数・交絡因子）によって、関係があるように見えること
- 例：アイスクリームの売り上げとプールでの事故はどちらも夏に増える（気温が共通の原因）

#### 相互情報量（そうごじょうほうりょう / mutual information）

- 意味：2つの確率変数がどれだけおたがいに依存しているかを表す量。一方を知ることで、もう一方の不確かさがどれだけ減るか
- ポイント：独立なら 0。相関係数とちがい、直線でない関係もとらえられる

### 距離と類似度

#### ユークリッド距離（ゆーくりっどきょり / Euclidean distance）

- 意味：人が定規で測るような、2点のあいだのふつうの距離。三平方の定理（ピタゴラスの公式）で求める
- 例：(0, 0) と (3, 4) のユークリッド距離は √(3²＋4²) ＝ 5

#### コサイン類似度（こさいんるいじど / cosine similarity）

- 意味：2つのベクトルのなす角のコサインで表す類似度。内積を、それぞれの長さの積で割る
- ポイント：向きが同じなら 1、直交なら 0、逆向きなら −1。ベクトルの長さに左右されないので、文書や単語のベクトル（#15）の似ている度合いによく使う

#### マハラノビス距離（まはらのびすきょり / Mahalanobis distance）

- 意味：データの散らばり方（変数どうしの相関や分散）を考えに入れた距離
- ポイント：ばらつきの大きい向きのずれは小さく、ばらつきの小さい向きのずれは大きく数える。ユークリッド距離とちがい、尺度によらない。異常検知に使う

## 19-3 確率と確率分布

### まとめ表

| 分布 | 種類 | 中身 |
| :-: | :-: | :-: |
| ベルヌーイ分布 | 離散 | 1回の試行で、確率 p で 1（成功）、1−p で 0 |
| 二項分布 | 離散 | 成功の確率 p の試行を n 回したときの成功の回数 |
| ポアソン分布 | 離散 | 一定の時間に、まれなできごとが起こる回数 |
| 正規分布 | 連続 | 平均を中心に左右対称の釣り鐘型。±1σ に約68%、±2σ に約95% |

### 確率の基本

#### 確率変数（かくりつへんすう / random variable）

- 意味：起こりうることがらに割り当てた値（ふつうは実数や整数）をとる変数
- 例：サイコロの出る目、明日の気温

#### 確率分布（かくりつぶんぷ / probability distribution）

- 意味：確率変数がそれぞれの値をとる確率の全体を表したもの
- ポイント：とる値がとびとびなら離散型（サイコロ）、連続なら連続型（身長）

#### 確率密度（関数）（かくりつみつど / probability density function）

- 意味：連続型の確率変数について、ある値のまわりの確率の濃さを表す関数
- ポイント：連続の値では「ちょうど 170.000…cm」の確率は 0 なので、ある範囲の確率を確率密度関数の積分（面積）で求める。全体を積分すると 1

#### 期待値（きたいち / expected value）

- 意味：確率変数のとる値に、それぞれの確率の重みをつけた平均
- 例：サイコロの目の期待値は (1＋2＋3＋4＋5＋6) × 1/6 ＝ 3.5

#### 条件付き確率（じょうけんつきかくりつ / conditional probability）

- 意味：あるできごと B が起こったという条件のもとで、別のできごと A が起こる確率。P(A|B) と書く
- ポイント：P(A|B) ＝ P(A かつ B) ÷ P(B)。ベイズの定理は、P(B|A) から P(A|B) を求める式（#04 のナイーブベイズ）

### 代表的な分布

#### ベルヌーイ分布（べるぬーいぶんぷ / Bernoulli distribution）

- 意味：確率 p で 1 を、確率 1−p で 0 をとる離散の確率分布。成功か失敗かの1回の試行（ベルヌーイ試行）を表す
- 例：コインを1回投げて表なら 1

#### 二項分布（にこうぶんぷ / binomial distribution）

- 意味：成功の確率が p のベルヌーイ試行を、独立に n 回行ったときの成功の回数が従う離散の確率分布
- ポイント：期待値は np、分散は np(1−p)

#### ポアソン分布（ぽあそんぶんぷ / Poisson distribution）

- 意味：あるできごとが一定の時間の中で起こる回数が従う離散の確率分布
- ポイント：まれにしか起こらないことを大量に観測すると、ポアソン分布に従うことが多い。期待値と分散がどちらも λ
- 例：1時間に窓口に来る客の数、1日の交通事故の件数

#### 正規分布（せいきぶんぷ / normal distribution）

- 意味：平均 μ を中心に左右対称の釣り鐘型をした、連続の確率分布。ガウス分布ともいう
- ポイント：平均 ±1σ（標準偏差）に約 68.27%、±2σ に約 95.45%、±3σ に約 99.73% が入る。平均 0・分散 1 のものを標準正規分布という

## 19-4 推定・検定・微分

### まとめ表

| 用語 | 中身 |
| :-: | :-: |
| 最小二乗法 | 誤差の2乗の和が最小になるようにパラメータを決める（線形回帰） |
| 最尤法 | 手元のデータが得られる確率（尤度）が最大になるようにパラメータを決める |
| 帰無仮説 H0 | 「差はない（偶然）」という、棄却したい仮説 |
| 対立仮説 H1 | 「差がある」という、本当に示したい仮説 |
| 微分・偏微分 | 変化の割合（傾き）。偏微分は1つの変数だけを動かしたときの傾き（勾配降下法で使う） |

### パラメータの決め方

#### 最小二乗法（さいしょうにじょうほう / least squares method）

- 意味：測った値とモデルの予測との誤差を2乗して足した値が最小になるように、関係式（パラメータ）を求める方法
- ポイント：線形回帰（#04）で使う。誤差を2乗するので、外れ値の影響を受けやすい。平均二乗誤差（#09）と考え方が同じ

#### 最尤法（最尤推定）（さいゆうほう / maximum likelihood estimation）

- 意味：手元のデータが、ある確率分布から得られたと考えたとき、そのデータが得られる確率（尤度）がいちばん大きくなるように、分布のパラメータ（母数）を推定する方法
- ポイント：交差エントロピー誤差の最小化は、最尤法と同じことになる（#09）
- 語の意味：尤（ゆう）＝もっともらしい

### 仮説検定

#### 帰無仮説（きむかせつ / null hypothesis）

- 意味：統計的な検定で、「2つのグループの差は偶然によるもの（差はない）」とする仮説。H0 と書く
- ポイント：棄てられる（無に帰す）ことを期待して立てるのでこの名がある。データから、帰無仮説のもとでは起こりにくい（p 値が有意水準より小さい）と分かれば棄却する

#### 対立仮説（たいりつかせつ / alternative hypothesis）

- 意味：帰無仮説に対立する仮説で、「差がある」などの、本当に示したいこと。H1 と書く
- ポイント：帰無仮説が棄却されたときに採択される

### 微分

#### 微分・偏微分（びぶん・へんびぶん / derivative, partial derivative）

- 意味：微分は、関数の入力を少し変えたときの出力の変化の割合（グラフの接線の傾き）。偏微分は、変数が複数ある関数で、1つの変数だけを動かし、ほかを固定したときの微分
- ポイント：ニューラルネットワークの学習では、誤差を各重みで偏微分した値（勾配）を使って重みを更新する（#10）
- 例：f(x) ＝ x² の微分は 2x。f(x, y) ＝ x²＋3xy の x での偏微分は 2x＋3y

## 問題演習

### 19-1

#### 問 gk-19-o01

- 問：データ 2, 3, 3, 4, 8 の平均・中央値・最頻値の組み合わせとして正しいものはどれか。
- ア：平均 3、中央値 4、最頻値 3
- イ：平均 4、中央値 3、最頻値 4
- ウ：平均 4、中央値 3、最頻値 3
- エ：平均 4、中央値 4、最頻値 3
- 正解：ウ
- 解説：平均は (2＋3＋3＋4＋8) ÷ 5 ＝ 4。小さい順のまん中（3番目）の 3 が中央値。いちばん多く出る 3 が最頻値。8 という大きな値に引っぱられて、平均だけ大きくなっている。
- アの意味：平均と中央値が逆。
- イの意味：最頻値がちがう（4 は1回だけ）。
- ウの意味：正しい。
- エの意味：中央値がちがう（4 は4番目）。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「中央値」（『データや集合の代表値の一つで、順位が中央である値のことである。』））

#### 問 gk-19-o02

- 問：一部の人がとても大きな値を持つ年収のデータで、多くの人の感覚に近い「ふつうの値」を表すのに、外れ値の影響を受けにくい代表値はどれか。
- ア：平均
- イ：分散
- ウ：最大値
- エ：中央値
- 正解：エ
- 解説：中央値は順位がまん中の値なので、とても大きな値があっても動きにくい。平均は大きな値に引っぱられる。
- アの意味：外れ値の影響を強く受ける。
- イの意味：ばらつきを表す値で、代表値ではない。
- ウの意味：いちばん大きな値そのもので、外れ値そのもの。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「外れ値」（『統計学において、他の値から大きく外れた値のこと。』））

#### 問 gk-19-o03

- 問：データ 2, 3, 3, 4, 8 の分散（データの個数で割るもの）はいくらか。
- ア：4.4
- イ：2.1
- ウ：4
- エ：22
- 正解：ア
- 解説：平均は 4。平均との差は −2, −1, −1, 0, 4 で、2乗すると 4, 1, 1, 0, 16。合計 22 を 5 で割って 4.4。
- アの意味：正しい。
- イの意味：標準偏差（√4.4 ≒ 2.1）。
- ウの意味：平均。
- エの意味：偏差の2乗の合計で、個数で割っていない。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「分散 (確率論)」（『データ（母集団、標本）、確率変数（確率分布）の標準偏差の自乗のことである。』））

#### 問 gk-19-o04

- 問：データの値が平均からどれくらい散らばっているかを表す指標で、分散の平方根であり、元のデータと単位が同じものはどれか。
- ア：分散
- イ：標準偏差
- ウ：共分散
- エ：平均偏差
- 正解：イ
- 解説：標準偏差は、データや確率変数の平均値からの散らばり具合を表す指標の一つ。分散の平方根なので、元のデータと単位がそろう。
- アの意味：標準偏差の2乗。単位も2乗になる。
- イの意味：正しい。
- ウの意味：2つの変数の関係を表す。
- エの意味：平均との差の絶対値の平均。平方根はとらない。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「標準偏差」（『データや確率変数の、平均値からの散らばり具合（ばらつき）を表す指標の一つである。』））

#### 問 gk-19-o05

- 問：時系列のデータで、ある長さの区間の平均を、区間を1つずつずらしながら計算し、細かい動きをならして傾向を見やすくする方法はどれか。
- ア：移動平均
- イ：最小二乗法
- ウ：標準化
- エ：度数分布
- 正解：ア
- 解説：移動平均は、時系列データ（一般には系列データ）を平滑化する手法。株価の25日移動平均など。
- アの意味：正しい。
- イの意味：誤差の2乗の和を最小にする関係式の求め方。
- ウの意味：平均 0・分散 1 にそろえる前処理（#18）。
- エの意味：区間ごとの個数を数えた表。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「移動平均」（『時系列データ（より一般的には時系列に限らず系列データ）を平滑化（英語版）する手法である』））

#### 問 gk-19-o06
