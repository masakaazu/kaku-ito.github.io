## 02-1 探索・推論

### まとめ表

| 手法 | 進み方 | 長所 | 短所 |
| :-: | :-: | :-: | :-: |
| 幅優先探索 | 根に近い順に横へ広げる | 最短の解が見つかる | 覚えておくノードが多くメモリを食う |
| 深さ優先探索 | 行けるところまで深く進み、行き止まりで戻る | メモリが少なくてすむ | 最短の解とは限らない |
| Mini-Max 法 | 自分は最大、相手は最小を選ぶと考える | ゲームの手を決められる | 全部読むと計算が多い |
| αβ法 | Mini-Max 法から不要な枝を刈る | 同じ答えをより速く | 枝の順番で効果が変わる |
| モンテカルロ法 | ランダムに最後まで打って勝率で評価 | 評価関数がいらない | 試行回数が必要 |

### 探索の基本

#### 探索木（たんさくぎ / search tree）

- 意味：問題の状態をノード、状態の移り変わりを枝として、木の形に並べたもの。迷路なら分かれ道ごとに枝分かれする
- ポイント：探索はこの木の中からゴールのノードを探すこと。進み方で幅優先と深さ優先がある

#### 幅優先探索（はばゆうせんたんさく / breadth-first search）

- 意味：スタートに近いノードから順に、同じ深さを全部調べてから次の深さへ進む探索
- ポイント：最短の解が必ず見つかるが、途中のノードを全部覚えるのでメモリを多く使う

#### 深さ優先探索（ふかさゆうせんたんさく / depth-first search）

- 意味：1つの枝を行けるところまで深く進み、行き止まりになったら戻って（バックトラック）別の枝を調べる探索
- ポイント：メモリは少なくてすむが、最初に見つかる解が最短とは限らない

#### ハノイの塔（はのいのとう / Tower of Hanoi）

- 意味：大きさの違う円盤を、小さいものの上に大きいものを置かずに、別の杭へ全部移すパズル
- ポイント：探索や再帰の例題によく使われる。円盤が n 枚なら最短 2ⁿ−1 回

#### ブルートフォース（ぶるーとふぉーす / brute-force search）

- 意味：考えられる解の候補を全部数え上げて、1つずつ解かどうか確かめる方法。力まかせ探索・しらみつぶし探索
- ポイント：単純で確実だが、組み合わせが増えると計算が爆発する

### 計画と言葉

#### STRIPS（すとりっぷす / Stanford Research Institute Problem Solver）

- 意味：1971年にフィケスとニルソンが作った自動計画（プランニング）のシステムと、その記述の言語
- ポイント：行動を「前提条件」「行動の結果加わること（追加）」「消えること（削除）」で書き、初期状態から目標状態への行動の順番を作る

#### SHRDLU（しゅるどぅるー / SHRDLU）

- 意味：1968〜1970年にテリー・ウィノグラードが作った、コンピュータの中の「積み木の世界」を英語の指示で動かすシステム
- ポイント：英語の命令を理解して積み木を動かした。のちの Cyc プロジェクトにつながる研究とされる

### ゲームの探索

#### Mini-Max 法（みにまっくすほう / minimax）

- 意味：自分の番では評価が最大になる手を、相手の番では自分の評価が最小になる手を相手が選ぶと考えて、手を決める方法
- ポイント：局面ごとに「自分にとってどれだけ有利か」を点数（評価関数）で表すのが前提

#### αβ法（あるふぁべーたほう / alpha-beta pruning）

- 意味：Mini-Max 法と同じ答えを出しながら、調べなくても結果が変わらない枝を刈り取って（枝刈り）計算を減らす方法
- ポイント：αカット（自分の番の枝刈り）とβカット（相手の番の枝刈り）がある

#### モンテカルロ法（もんてかるろほう / Monte Carlo method）

- 意味：乱数を使ったシミュレーションで答えを近似する方法の総称。ゲームでは、ある局面からランダムに最後まで打つ（プレイアウト）ことを何度も行い、勝率で手のよさを評価する
- ポイント：評価関数を人が作らなくてよい。囲碁で力を発揮し、モンテカルロ木探索は AlphaGo にも使われた

## 02-2 知識表現

### まとめ表

| 関係 | 意味 | 例 | 推移律 |
| :-: | :-: | :-: | :-: |
| is-a | 「〜は〜の一種である」（上位・下位） | 犬 is-a 動物 | 成り立つ |
| has-a | 「〜は〜を持っている」 | 車 has-a タイヤ | 場合による |
| part-of | 「〜は〜の一部である」 | タイヤ part-of 車 | 成り立たないことがある |

### 知識のつなぎ方

#### 意味ネットワーク（いみねっとわーく / semantic network）

- 意味：概念をノード、概念どうしの関係を矢印でつないだネットワークで知識を表す方法
- ポイント：is-a や part-of などの関係でつなぐ。is-a では上位の性質を下位が受け継ぐ（継承）

#### is-a の関係・has-a の関係・part-of の関係（いずあ・はずあ・ぱーとおぶのかんけい / is-a, has-a, part-of）

- 意味：is-a は「〜の一種」、has-a は「〜を持つ」、part-of は「〜の一部」という関係
- ポイント：is-a は推移律が成り立つ（犬→哺乳類→動物）。part-of は推移律が成り立たないこともある
- 例：「柴犬 is-a 犬」「犬 is-a 動物」なら「柴犬 is-a 動物」

#### オントロジー（おんとろじー / ontology）

- 意味：ある分野の概念と、その関係を、きちんと決めて明示的に書き表した仕様。哲学の「存在論」から来た言葉
- ポイント：知識を共有・再利用するための土台。概念をきっちり決めるヘビーウェイト・オントロジーと、データから自動で関係を作るライトウェイト・オントロジーという分け方もある

#### Cyc プロジェクト（さいくぷろじぇくと / Cyc project）

- 意味：人間の一般常識をすべてコンピュータに入れようとする長期のプロジェクト。1984年にダグラス・レナートが始めた
- ポイント：常識の知識を手で書き続けている。知識獲得のボトルネックの大きさを示す例

#### セマンティック Web（せまんてぃっくうぇぶ / Semantic Web）

- 意味：ウェブページに意味を表す情報（メタデータ）を付けて、コンピュータがページの意味を扱えるようにする構想
- ポイント：ティム・バーナーズ＝リーが提唱。RDF・OWL などで記述し、オントロジーを使う

### データから知識を取り出す

#### データマイニング（でーたまいにんぐ / data mining）

- 意味：統計学や人工知能などの手法を大量のデータに当てはめて、役に立つ知識やパターンを取り出す技術
- 例：「おむつを買う人はビールも買う」のような購買の組み合わせを見つける

#### ウェブマイニング（うぇぶまいにんぐ / web mining）

- 意味：ウェブサイトの構造やウェブ上のデータを使って行うデータマイニング
- 例：ブログや商品レビューから評判を取り出す

## 02-3 エキスパートシステムと知識の応用

### まとめ表

| システム | 年代 | 中身 |
| :-: | :-: | :-: |
| ELIZA | 1964〜1966 | パターンに合わせて返事をする対話プログラム |
| DENDRAL | 1960年代 | 質量分析の結果から有機化合物を推定 |
| MYCIN | 1970年代 | 血液の感染症を診断し抗生物質を勧める |
| ワトソン | 2011 | クイズ番組「ジェパディ!」で人間に勝った質問応答システム |
| 東ロボくん | 2011〜 | 東大合格を目指したが読解力の壁で凍結 |

### エキスパートシステム

#### エキスパートシステム（えきすぱーとしすてむ / expert system）

- 意味：専門家の知識を「もし〜ならば〜」のルールで知識ベースに入れ、推論エンジンで推論して、専門家のように判断するシステム
- ポイント：第2次AIブームの中心。知識ベースは入れ替えられ、推論エンジンは共通。知識を集めるのが大変（知識獲得のボトルネック）

#### DENDRAL（でんどらる / Dendral）

- 意味：1960年代にスタンフォード大学で作られた、質量分析のデータから未知の有機化合物を推定するエキスパートシステム
- ポイント：最初のエキスパートシステムとされる。MYCIN はここから派生した

#### MYCIN（まいしん / MYCIN）

- 意味：1970年代にスタンフォード大学で作られた、血液の感染症を診断して抗生物質を勧めるエキスパートシステム
- ポイント：約500のルールを持ち、正しさは65%で、専門でない医師よりよく、専門医（80%）よりは低かった

#### インタビューシステム（いんたびゅーしすてむ / interview system）

- 意味：専門家に質問して答えてもらうことで、知識をうまく引き出してエキスパートシステムの知識ベースを作るための仕組み
- ポイント：知識獲得のボトルネックを和らげる工夫

### 言葉で答えるシステム

#### イライザ（ELIZA）（いらいざ / ELIZA）

- 意味：1964〜1966年に MIT のワイゼンバウムが作った、相手の言葉のパターンに合わせて返事をする対話プログラム
- ポイント：DOCTOR というセラピスト役が有名。言葉の意味を理解していなくても、人間が本気で話しかけてしまう（イライザ効果）

#### Question-Answering（質問応答）（しつもんおうとう / question answering）

- 意味：自然言語の質問を受けつけ、答えを自然言語で返す仕組みと、その研究分野
- 例：ワトソン、検索エンジンの答えの表示

#### ワトソン（わとそん / IBM Watson）

- 意味：IBM が作った質問応答システム。2011年にクイズ番組「ジェパディ!」で人間のチャンピオンに勝った
- ポイント：大量の文書から答えの候補を探して選ぶ。IBM は「拡張知能（Augmented Intelligence）」と呼ぶ

#### 東ロボくん（とうろぼくん / Todai Robot Project）

- 意味：国立情報学研究所が中心となり2011年から行った「ロボットは東大に入れるか」プロジェクトの AI
- ポイント：模試で偏差値57.8まで上がったが、読解力の壁で東大合格はできないと判断され、2016年に区切りをつけた

- 問：迷路の探索で、スタートに近い分かれ道から順に、同じ深さのものを全部調べてから次の深さへ進む方法はどれか。
