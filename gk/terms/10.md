## 10-1 誤差逆伝播法

### まとめ表

| 用語 | 中身 |
| :-: | :-: |
| 順伝播 | 入力から出力へ計算して、予測と誤差を出す |
| 誤差逆伝播法 | 出力側から入力側へ、各重みについての誤差の偏微分（勾配）を求める |
| 連鎖律 | 合成関数の微分は、それぞれの微分の積になる。逆伝播の計算のもと |
| 勾配降下法 | 求めた勾配を使って重みを更新する |

### 逆伝播のしくみ

#### 誤差逆伝播法（ごさぎゃくでんぱほう / backpropagation）

- 意味：ニューラルネットワークの誤差関数を、各パラメータ（重み）で偏微分した値を、出力側から入力側へさかのぼって効率よく計算する方法。バックプロパゲーションともいう
- ポイント：逆伝播は「勾配を求める」方法で、重みを「更新する」のは確率的勾配降下法などの最適化手法。ただし両方まとめて誤差逆伝播法と呼ぶことも多い。1986年のラメルハートらの論文で広まった
- 語の意味：back＝後ろへ、propagation＝伝わること

#### 連鎖律（れんさりつ / chain rule）

- 意味：いくつかの関数を合成した関数を微分すると、それぞれの関数の微分の積になるという関係。合成関数の微分公式
- ポイント：ニューラルネットワークは層ごとの関数を合成したものなので、出力側から微分を掛け合わせていけば各層の勾配が求まる。掛け算が重なるので、小さい値が続くと勾配消失、大きい値が続くと勾配爆発が起きる

#### 信用割当問題（しんようわりあてもんだい / credit assignment problem）

- 意味：最終的な結果（誤差）に対して、ネットワークの中のどの重みがどれだけ責任を持つのかを決める問題
- ポイント：誤差逆伝播法は、各重みの勾配を求めることで、多層ネットワークの信用割当問題を解いた

#### 勾配消失問題・勾配爆発問題（こうばいしょうしつもんだい・こうばいばくはつもんだい / vanishing / exploding gradient problem）

- 意味：逆伝播で入力側へさかのぼるうちに、勾配がとても小さくなる（消失）、またはとても大きくなる（爆発）問題
- ポイント：くわしくは #08。消失は ReLU・スキップ結合・LSTM など、爆発は勾配クリッピングで防ぐ

## 10-2 勾配降下法と学習の単位

### まとめ表

| 学び方 | 1回の更新に使うデータ | 特徴 |
| :-: | :-: | :-: |
| バッチ学習（最急降下法） | 訓練データ全部 | 安定するが、1回の計算が重い |
| ミニバッチ学習 | 数十〜数百件ずつ | いまの標準。両方のよいところ |
| オンライン学習（確率的勾配降下法） | 1件ずつ | 速いが、ばらつく。新しいデータを次々に学べる |

| 用語 | 意味 |
| :-: | :-: |
| イテレーション | 重みを1回更新すること（の回数） |
| エポック | 訓練データ全体を1回使い切ること |
| 例 | データ 1,000 件、ミニバッチ 100 件なら、1 エポック＝10 イテレーション |

### 勾配降下法

#### 勾配降下法（こうばいこうかほう / gradient descent）

- 意味：関数の傾き（勾配）を計算し、下る方向へ少しずつ進んで、関数が最小になる点を探す方法。最急降下法ともいう
- ポイント：誤差関数を重みで微分した勾配の逆向きに重みを動かす。動かす大きさを学習率で決める
- 語の意味：gradient＝勾配、descent＝下ること

#### 学習率（がくしゅうりつ / learning rate）

- 意味：勾配降下法で、1回の更新で重みをどれだけ動かすかを決める数
- ポイント：大きすぎると発散し、小さすぎると収束が遅い。ハイパーパラメータ。学習が進むにつれて小さくしていく（学習率の減衰）こともある

#### 確率的勾配降下法（SGD）（かくりつてきこうばいこうかほう / stochastic gradient descent）

- 意味：訓練データの一部（1件やミニバッチ）だけで勾配を見積もって重みを更新する勾配降下法
- ポイント：全部のデータを使うより1回の計算が軽く、ばらつきのおかげで浅い谷（局所最適解）から抜け出しやすい
- 語の意味：stochastic＝確率的な

### 学習の単位

#### バッチ学習・ミニバッチ学習・オンライン学習（ばっちがくしゅう・みにばっちがくしゅう・おんらいんがくしゅう / batch, mini-batch, online learning）

- 意味：重みの1回の更新に、訓練データ全部を使うのがバッチ学習、一部（ミニバッチ）を使うのがミニバッチ学習、1件ずつ使うのがオンライン学習
- ポイント：ニューラルネットワークの学習ではミニバッチ学習が標準。ミニバッチの大きさ（バッチサイズ）はハイパーパラメータ

#### エポック（えぽっく / epoch）

- 意味：訓練データ全体を1回ひととおり学習に使うこと。その回数
- ポイント：ふつう何エポックもくり返して学習する。多すぎると過学習するので、早期終了（#09）で止める

#### イテレーション（いてれーしょん / iteration）

- 意味：重みを1回更新すること。その回数
- ポイント：1 エポックのイテレーション数＝データ数÷バッチサイズ

### 勾配降下法の落とし穴

#### 局所最適解と大域最適解（きょくしょさいてきかい・たいいきさいてきかい / local optimum, global optimum）

- 意味：大域最適解は関数全体で一番小さい点、局所最適解はまわりよりは小さいが一番ではない点
- ポイント：勾配降下法は勾配だけを見るので、局所最適解にとらわれやすい

#### 鞍点（あんてん / saddle point）

- 意味：ある方向から見ると極小、別の方向から見ると極大になっている点。馬の鞍の形
- ポイント：勾配が 0 になるので、学習が止まったように見える（停滞＝プラトー）。次元の高いニューラルネットワークでは局所最適解より鞍点が問題になりやすい。モーメンタムなどで抜け出す
- 語の意味：saddle＝鞍

## 10-3 最適化アルゴリズム

### まとめ表

| 名前 | 工夫 | 覚え方 |
| :-: | :-: | :-: |
| モーメンタム | 前の更新の向きを引きつぐ（慣性） | 坂を転がる重い球 |
| AdaGrad | パラメータごとに、これまでの勾配の2乗の合計で学習率を割る | 学習率がだんだん小さくなり、最後は止まる |
| RMSprop | 勾配の2乗の指数移動平均で割る | AdaGrad の「止まる」を改良 |
| AdaDelta | 学習率そのものを決めなくてよい | AdaGrad の改良 |
| Adam | モーメンタム＋RMSprop（勾配と2乗の2つの移動平均） | いまの定番 |
| AdaBound・AMSBound | 学習率に上限と下限をつけ、だんだん SGD に近づける | Adam・AMSGrad の改良 |

### アルゴリズム

#### モーメンタム（もーめんたむ / momentum）

- 意味：前回の更新の向きと大きさを一部引きつぎ、今回の勾配と足して重みを更新する方法
- ポイント：同じ向きが続くと加速し、向きがばらつくと打ち消しあう。鞍点や谷の振動に強い
- 語の意味：momentum＝勢い・運動量

#### AdaGrad（あだぐらど / adaptive gradient）

- 意味：パラメータごとに、これまでの勾配の2乗の合計を使って学習率を調整する方法
- ポイント：よく更新されるパラメータの学習率は小さく、まれにしか更新されないパラメータの学習率は大きくなる。合計が増え続けるので、学習率がだんだん 0 に近づき更新が止まるのが弱点
- 語の意味：adaptive＝適応する

#### RMSprop（あーるえむえすぷろっぷ / root mean square propagation）

- 意味：AdaGrad の「合計」のかわりに、勾配の2乗の指数移動平均（最近の値を重く見る平均）を使う方法
- ポイント：昔の勾配の影響が薄れるので、学習率が 0 に近づいて止まる問題を防ぐ。ヒントンのグループで考えられた

#### AdaDelta（あだでるた / ADADELTA）

- 意味：AdaGrad を改良し、学習率を人が決めなくてもよいようにした方法
- ポイント：パラメータの次元ごとに学習率が自動で調整される

#### Adam（あだむ / adaptive moment estimation）

- 意味：勾配の移動平均（モーメンタムの考え方）と、勾配の2乗の移動平均（RMSprop の考え方）の両方を使う方法
- ポイント：実装が簡単で計算が軽く、ハイパーパラメータの調整もあまりいらない。いまよく使われる
- 語の意味：moment＝（統計の）モーメント、estimation＝推定

#### AdaBound・AMSBound（あだばうんど・えーえむえすばうんど / AdaBound, AMSBound）

- 意味：Adam と AMSGrad の学習率に、時間とともに狭まる上限と下限をつけ、はじめは Adam のように、後半は SGD のように動くようにした方法
- ポイント：Adam などは学習は速いが汎化が SGD に劣ることがある。その差をなくすねらい

## 10-4 ハイパーパラメータの調整

### まとめ表

| 方法 | やり方 | 特徴 |
| :-: | :-: | :-: |
| グリッドサーチ | 候補の値を格子状に並べ、すべての組み合わせを試す | もれがないが、数が増えると組み合わせが爆発する |
| ランダムサーチ | 範囲の中からランダムに組み合わせを選んで試す | 同じ計算量で、グリッドサーチと同じかよい結果が出やすい |
| ベイズ最適化 | これまでの結果から次に試す値を賢く選ぶ | 試す回数を減らせる |

### ハイパーパラメータ

#### ハイパーパラメータ（はいぱーぱらめーた / hyperparameter）

- 意味：学習の前に人が決めておく設定の値。学習率・バッチサイズ・エポック数・層の数・正則化の強さなど
- ポイント：重みやバイアスのようにデータから学習で決まる「パラメータ」とは区別する。検証データで調整する
- 語の意味：hyper＝上の、超えた

#### グリッドサーチ（ぐりっどさーち / grid search）

- 意味：ハイパーパラメータの候補を人が決め、その組み合わせをすべて試して、一番よいものを選ぶ方法
- ポイント：ハイパーパラメータの種類が増えると、試す数が掛け算で増える

#### ランダムサーチ（らんだむさーち / random search）

- 意味：ハイパーパラメータの組み合わせを、決めた範囲からランダムに選んで試す方法
- ポイント：大事なハイパーパラメータはいくつかに限られることが多いので、同じ回数ならランダムのほうがいろいろな値を試せる

### 学習のふしぎ

#### 二重降下現象（にじゅうこうかげんしょう / double descent）

- 意味：モデルを大きくしていくと、テストの誤差がいったん悪くなってから、また良くなる現象。エポック数を増やしたときにも起きる
- ポイント：「複雑にしすぎると過学習する」という従来のバイアスとバリアンスの考え方（#07）だけでは説明できない。データを増やすとかえって悪くなる範囲もある

#### ノーフリーランチ定理（のーふりーらんちていり / no free lunch theorem）

- 意味：あらゆる問題に対して、ほかのどの方法よりもすぐれた万能の最適化の方法（アルゴリズム）はない、という定理
- ポイント：問題に合わせて方法を選ぶ必要がある。Wolpert と Macready が示した
- 語の意味：free lunch＝ただの昼食（ただのものなどない、のたとえ）

#### 問 gk-10-o03

- 問：誤差逆伝播法で各層の勾配を求めるときに使う、合成関数の微分はそれぞれの微分の積になるという関係を何というか。

- エの意味：隠れ層1層でも連続関数を近似できるという定理（#08）。
- 出典：オリジナル問題（根拠：ウィキペディア日本語版「連鎖律」（『微分法において連鎖律（れんさりつ、英: chain rule）あるいは合成関数の微分公式とは、複数の関数が合成された合成関数を微分するとき、その導関数がそれぞれの導関数の積で与えられるという関係式のこと。』））

#### 問 gk-10-o05

- 問：誤差逆伝播法で勾配消失問題や勾配爆発問題が起きる主な原因として最も適切なものはどれか。
- ア：訓練データが多すぎること
- イ：連鎖律で層ごとの微分を何度も掛け合わせるため、1より小さい値が続くと勾配が消え、大きい値が続くと爆発すること
- ウ：出力層にソフトマックス関数を使うこと

#### 問 gk-10-o29

- 出典：オリジナル問題（根拠：Nakkiran ほか「Deep Double Descent」（『Moreover, we show that double descent occurs not just as a function of model size, but also as a function of the number of training epochs.』））
