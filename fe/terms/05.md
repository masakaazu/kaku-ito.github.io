## 5-1 オペレーティングシステム

### まとめ表

**タスクの3つの状態**

| 状態 | 意味 | 次に移るとき |
| :-: | :-: | :-: |
| 実行可能状態 | CPUが空くのを待っている | ディスパッチされると実行状態へ |
| 実行状態 | CPUを使って処理している | 時間切れで実行可能へ、入出力待ちで待機へ |
| 待機状態 | 入出力の完了などを待っている | 完了すると実行可能へ |

**ページ置換アルゴリズム**

| 方式 | 追い出すページ |
| :-: | :-: |
| FIFO | 最も前に主記憶に入ったページ |
| LRU | 最も長い間使われていないページ |
| LFU | 使われた回数が最も少ないページ |


### OSの役割

#### OS（おーえす / Operating System）

- 意味：ハードウェアを管理し、アプリケーションが動く土台になる基本ソフトウェア
- 語の意味：Operating＝動かす・運用する／System＝仕組み

#### ソフトウェアの分類（Software Classification）

- 意味：システムソフトウェア（OS・ミドルウェア）と応用ソフトウェア（業務ソフト・表計算など）に分かれる
- ポイント：表計算やワープロは応用ソフトウェア

#### カーネル（Kernel）

- 意味：OSの中核部分。タスク管理・記憶管理・入出力管理などを行う

#### スプーリング（Spooling）

- 意味：プリンタなど遅い装置への出力をいったん補助記憶にためて、CPUを早く解放する仕組み


### タスク管理

#### タスク（プロセス / Task, Process）

- 意味：OSから見た処理の単位
- ポイント：実行可能・実行・待機の3つの状態を行き来する

#### ディスパッチャ（Dispatcher）

- 意味：実行可能状態のタスクに、実際にCPUを割り当てる機能

#### 到着順方式（FCFS / First Come First Served）

- 意味：実行可能になった順にCPUを割り当てる方式
- 語の意味：First Come＝先に来た／First Served＝先に扱われる

#### 優先度順方式（Priority Scheduling）

- 意味：優先度の高いタスクからCPUを割り当てる方式
- ポイント：低い優先度のタスクがずっと待たされることがある

#### ラウンドロビン方式（Round Robin）

- 意味：一定の時間（タイムクウォンタム）ずつ順番にCPUを割り当てる方式
- ポイント：時間切れになると実行可能状態の最後に並び直す

#### 処理時間順方式（SPT / Shortest Processing Time First）

- 意味：処理時間の短いタスクから実行する方式
- ポイント：平均の待ち時間が短くなる
- 語の意味：Shortest＝最も短い／Processing Time＝処理時間／First＝先に

#### プリエンプティブ方式（Preemptive）

- 意味：実行中のタスクを途中で止めて、ほかのタスクにCPUを渡せる方式
- ポイント：止められないのはノンプリエンプティブ方式

#### マルチタスク（Multitask）

- 意味：複数のタスクを切り替えながら、同時に動いているように処理すること

#### デッドロック（Deadlock）

- 意味：複数のタスクがお互いに相手の持つ資源を待って、どれも進めなくなる状態
- ポイント：資源を確保する順序をそろえると防げる


### 記憶管理

#### 固定区画方式（Fixed Partition）

- 意味：主記憶をあらかじめ決めた大きさの区画に分けて割り当てる方式
- ポイント：区画内の使われない部分（内部断片化）が生じる

#### 可変区画方式（Variable Partition）

- 意味：プログラムの大きさに合わせて区画を割り当てる方式
- ポイント：空きが細切れになる（外部断片化）ので、詰め直す（コンパクション）

#### オーバレイ方式（Overlay）

- 意味：主記憶より大きいプログラムを部分に分け、必要な部分を入れ替えながら実行する方式

#### スワッピング（Swapping）

- 意味：実行していないタスクを丸ごと補助記憶へ退避（スワップアウト）し、必要なときに戻す（スワップイン）方式

#### 仮想記憶（かそうきおく / Virtual Memory）

- 意味：補助記憶を使って、主記憶より大きな記憶空間があるように見せる仕組み

#### ページング方式（Paging）

- 意味：仮想記憶を一定の大きさのページに分け、ページ単位で主記憶と補助記憶を入れ替える方式
- ポイント：必要なページが主記憶にないことをページフォールトという

#### ページイン・ページアウト（Page In, Page Out）

- 意味：ページインは補助記憶から主記憶へ読み込むこと、ページアウトは主記憶から補助記憶へ追い出すこと

#### スラッシング（Thrashing）

- 意味：ページインとページアウトが頻繁に起きて、処理がほとんど進まなくなる状態
- ポイント：主記憶を増やす、同時に動かすタスクを減らすなどで防ぐ

#### LRU（えるあーるゆー / Least Recently Used）

- 意味：最も長い間使われていないページを追い出す方式
- 語の意味：Least＝最も少なく／Recently＝最近／Used＝使われた

#### LFU（えるえふゆー / Least Frequently Used）

- 意味：使われた回数が最も少ないページを追い出す方式
- 語の意味：Least＝最も少なく／Frequently＝頻繁に／Used＝使われた

#### メモリリーク（Memory Leak）

- 意味：使い終わったメモリが解放されず、使える量がだんだん減っていく現象
- ポイント：ガーベジコレクションは使わなくなった領域を自動で回収する


## 5-2 ミドルウェア


### OSとアプリの間

#### ミドルウェア（Middleware）

- 意味：OSとアプリケーションの間で、多くのアプリが使う共通の機能を提供するソフトウェア
- 例：DBMS、Webサーバソフト

#### API（えーぴーあい / Application Programming Interface）

- 意味：ソフトウェアの機能をほかのプログラムから呼び出すための窓口
- 語の意味：Application＝アプリケーション／Programming＝プログラムから使う／Interface＝窓口

#### シェル（Shell）

- 意味：利用者が入力したコマンドを解釈して、OSに伝えるプログラム


## 5-3 ファイルシステム


### ファイルの管理

#### ディレクトリ（Directory）

- 意味：ファイルを分類して入れておく入れ物。階層（木構造）にできる
- ポイント：いちばん上がルートディレクトリ

#### 絶対パス・相対パス（Absolute / Relative Path）

- 意味：絶対パスはルートから、相対パスは今いる場所（カレントディレクトリ）からファイルの場所を示す
- ポイント：..は1つ上の階層を表す

#### アクセス権（Access Right）

- 意味：ファイルを読む・書く・実行する権限を、利用者ごとに設定するもの


## 5-4 開発ツール


### 言語処理

#### コンパイラ（Compiler）

- 意味：ソースプログラムを実行前にまとめて機械語（目的プログラム）に翻訳するプログラム
- ポイント：翻訳後は直接実行できるので速い

#### インタプリタ（Interpreter）

- 意味：ソースプログラムを1行ずつ解釈しながら実行するプログラム
- ポイント：すぐ試せるが、実行は遅め

#### リンカ（Linker）

- 意味：複数の目的プログラム（オブジェクトファイル）やライブラリを結合して、実行できる形にするプログラム
- ポイント：結合することをリンクという

#### ローダ（Loader）

- 意味：実行できるプログラムを主記憶に読み込むプログラム

#### IDE（あいでぃーいー / Integrated Development Environment）

- 意味：エディタ・コンパイラ・デバッガなどを1つにまとめた開発環境
- 語の意味：Integrated＝統合された／Development＝開発／Environment＝環境

#### デバッガ（Debugger）

- 意味：プログラムを止めながら変数の値を見るなどして、誤り（バグ）を探す道具


## 5-5 オープンソースソフトウェア


### OSS

#### OSS（おーえすえす / Open Source Software）

- 意味：ソースコードが公開され、決まったライセンスのもとで自由に使い・変え・配れるソフトウェア
- 例：Linux、Apache、MySQL
- 語の意味：Open＝公開された／Source＝ソースコード／Software＝ソフトウェア

#### GPL（じーぴーえる / GNU General Public License）

- 意味：OSSの代表的なライセンス。改変したものを配るときもソースを公開する必要がある（コピーレフト）
- 語の意味：GNU＝プロジェクト名／General Public＝一般に公開する／License＝利用許諾
