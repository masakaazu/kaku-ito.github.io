## 22-1 経営・組織論


### 企業と組織

#### 企業の社会的責任（CSR / Corporate Social Responsibility）

- 意味：企業が利益だけでなく、環境や社会に対しても責任を果たすこと

#### SDGs（えすでぃーじーず / Sustainable Development Goals）

- 意味：国連が決めた、2030年までの持続可能な開発目標。17の目標がある
- 語の意味：Sustainable＝持続可能な／Development＝開発／Goals＝目標

#### 職能別組織（Functional Organization）

- 意味：営業・製造・経理など、仕事の種類ごとに分けた組織

#### 事業部制組織（Divisional Organization）

- 意味：製品や地域ごとに事業部を作り、それぞれが利益に責任をもつ組織

#### マトリックス組織（Matrix Organization）

- 意味：職能別と事業部別など、2つの軸を組み合わせた組織
- ポイント：1人が2人の上司をもつ

#### プロジェクト組織（Project Organization）

- 意味：決まった目的のために、いろいろな部門から人を集めて一時的に作る組織

#### OJT（おーじぇいてぃー / On the Job Training）

- 意味：実際の職場で、仕事をしながら教育すること
- ポイント：職場を離れて行う研修はOff-JT
- 語の意味：On the Job＝仕事をしながら／Training＝訓練

#### ワークシェアリング（Work Sharing）

- 意味：1人あたりの労働時間を短くして仕事を分け合い、雇用を守ること

#### BCP（びーしーぴー / Business Continuity Plan）

- 意味：災害などが起きても、大事な業務を続けたり早く再開したりするための計画。事業継続計画
- 語の意味：Business＝事業／Continuity＝継続／Plan＝計画


## 22-2 OR・IE

### まとめ表

**QC七つ道具（よく出るもの）**

| 道具 | 何に使うか |
| :-: | :-: |
| パレート図 | 大きい順に並べた棒グラフと累積比率の折れ線。重点を見つける |
| 特性要因図 | 結果と原因の関係を魚の骨の形で整理する |
| 散布図 | 2つの量の関係（相関）を見る |
| ヒストグラム | データのばらつき（分布）を見る |
| 管理図 | 工程が安定しているかを見る |


### 分析の道具

#### OR（おーあーる / Operations Research）

- 意味：数学や統計を使って問題を分析し、最もよい答え（最適解）を見つける方法
- ポイント：線形計画法・在庫問題・待ち行列など
- 語の意味：Operations＝業務／Research＝研究

#### IE（あいいー / Industrial Engineering）

- 意味：作業のやり方や時間を分析して、生産の効率を上げる方法
- 語の意味：Industrial＝産業の／Engineering＝工学

#### 線形計画法（Linear Programming）

- 意味：制約の条件の中で、利益などを最大（または最小）にする組合せを求める方法
- ポイント：制約の式で囲まれた範囲の角（頂点）の値を調べる

#### 経済的発注量（EOQ / Economic Order Quantity）

- 意味：発注の費用と保管の費用の合計が最も小さくなる、1回の発注量
- ポイント：EOQ＝√（2×年間需要量×1回の発注費÷1個の年間保管費）

#### パレート図（Pareto Chart）

- 意味：項目を大きい順に並べた棒グラフと、累積の比率の折れ線を組み合わせた図
- ポイント：ABC分析に使う

#### ABC分析（ABC Analysis）

- 意味：売上などの大きい順にA・B・Cのグループに分け、重点的に管理する対象を決める方法

#### 特性要因図（Cause and Effect Diagram）

- 意味：結果（特性）と、それに影響する原因（要因）の関係を、魚の骨のような形で整理した図

#### 散布図（Scatter Diagram）

- 意味：2つの量を縦と横にとって点を打ち、関係（相関）を見る図

#### 管理図（Control Chart）

- 意味：時間ごとのデータの変化に、上と下の管理限界線を引いて、工程が安定しているかを見る図

#### 親和図法（Affinity Diagram）

- 意味：集めた意見や情報を、似たものどうしでまとめて整理する方法

#### ブレーンストーミング（Brainstorming）

- 意味：人の意見を否定せず、自由にたくさんのアイデアを出し合う方法

#### OC曲線（検査特性曲線 / Operating Characteristic Curve）

- 意味：ロットの不良率と、そのロットが検査に合格する確率の関係を表したグラフ

#### デルファイ法（Delphi Method）

- 意味：専門家にアンケートを何回も繰り返し、意見をまとめて将来を予測する方法


## 22-3 会計・財務

### まとめ表

**損益分岐点の式**

| 項目 | 式 |
| :-: | :-: |
| 変動費率 | 変動費 ÷ 売上高 |
| 限界利益 | 売上高 − 変動費 |
| 利益 | 売上高 − 変動費 − 固定費 |
| 損益分岐点売上高 | 固定費 ÷（1 − 変動費率） |

**財務諸表**

| 財務諸表 | 表すもの |
| :-: | :-: |
| 貸借対照表（B/S） | ある時点の資産・負債・純資産 |
| 損益計算書（P/L） | ある期間の収益・費用・利益 |
| キャッシュフロー計算書（C/F） | ある期間の現金の増減 |


### 利益の計算

#### 固定費（Fixed Cost）

- 意味：売上の量にかかわらず、決まってかかる費用
- 例：家賃、人件費

#### 変動費（Variable Cost）

- 意味：売上の量に比例して増える費用
- 例：材料費

#### 変動費率（Variable Cost Ratio）

- 意味：売上高に対する変動費の割合
- ポイント：変動費 ÷ 売上高

#### 限界利益（Marginal Profit）

- 意味：売上高から変動費を引いたもの
- ポイント：固定費を回収するための利益

#### 損益分岐点（BEP / Break-Even Point）

- 意味：利益がちょうど0になる売上高（または販売数量）
- ポイント：損益分岐点売上高＝固定費÷（1−変動費率）。例: 固定費300万・変動費率0.6なら750万


### 財務諸表

#### 貸借対照表（B/S / Balance Sheet）

- 意味：ある時点の会社の財産の状態（資産・負債・純資産）を表す表
- ポイント：資産＝負債＋純資産

#### 損益計算書（P/L / Profit and Loss Statement）

- 意味：ある期間の収益・費用と、その差の利益を表す表

#### キャッシュフロー計算書（C/F / Cash Flow Statement）

- 意味：ある期間の現金の増減を、営業・投資・財務の活動に分けて表す表

#### 減価償却（Depreciation）

- 意味：長く使う設備の買った金額を、使う年数に分けて少しずつ費用にすること
- ポイント：定額法: 毎年の償却額＝（取得価額−残存価額）÷耐用年数

#### ROE（あーるおーいー / Return On Equity）

- 意味：自己資本（株主のお金）でどれだけの利益をあげたかを表す指標。自己資本利益率
- ポイント：当期純利益 ÷ 自己資本
- 語の意味：Return＝利益／On＝〜に対する／Equity＝自己資本

#### 流動比率（Current Ratio）

- 意味：1年以内に現金になる資産（流動資産）が、1年以内に返す借金（流動負債）の何倍あるか
- ポイント：高いほど短い期間の支払いに強い
