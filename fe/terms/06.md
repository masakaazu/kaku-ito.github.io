## 6-1 電気・電子回路

### まとめ表

**論理回路の記号と働き**

| 回路 | 出力が1になるとき |
| :-: | :-: |
| AND | 入力がすべて1 |
| OR | 入力のどれかが1 |
| NOT | 入力が0 |
| NAND | ANDの反対（すべて1のときだけ0） |
| XOR | 入力が異なるとき |


### 電子回路

#### 論理回路（ろんりかいろ / Logic Circuit）

- 意味：AND・OR・NOTなどの論理演算を電気信号で行う回路
- ポイント：NAND回路だけで、ほかのすべての論理回路を作れる

#### 組合せ回路（くみあわせかいろ / Combinational Circuit）

- 意味：出力が、今の入力だけで決まる回路
- 例：半加算器、全加算器

#### 順序回路（じゅんじょかいろ / Sequential Circuit）

- 意味：出力が、今の入力と過去の状態（記憶）で決まる回路
- ポイント：フリップフロップが代表例

#### フリップフロップ（Flip-flop）

- 意味：0か1の状態を保持できる回路。1ビットを記憶する
- ポイント：SRAMやレジスタに使われる

#### 半加算器（はんかさんき / Half Adder）

- 意味：1桁の2進数どうしを足し、和と桁上がりを出す回路
- ポイント：和はXOR、桁上がりはANDで作る。全加算器は下の桁からの桁上がりも足す

#### 半導体（はんどうたい / Semiconductor）

- 意味：電気を通す導体と通さない絶縁体の中間の性質を持つ物質
- ポイント：シリコンが代表。トランジスタやICの材料

#### IC（あいしー / Integrated Circuit）

- 意味：多数のトランジスタなどを1つのチップにまとめた集積回路
- 語の意味：Integrated＝集積した／Circuit＝回路

#### SoC（えすおーしー / System on a Chip）

- 意味：CPU・メモリ・入出力など、システムに必要な機能を1つのチップにまとめたもの
- ポイント：スマートフォンなどに使う
- 語の意味：System＝システム／on a Chip＝1つのチップの上に

#### FPGA（えふぴーじーえー / Field Programmable Gate Array）

- 意味：製造した後に、利用者が回路の内容を書き換えられるIC
- 語の意味：Field＝現場で／Programmable＝書き換えられる／Gate Array＝ゲート（論理素子）の並び


## 6-2 機械・制御


### 組込みシステムの部品

#### 組込みシステム（くみこみしすてむ / Embedded System）

- 意味：家電や自動車などの機器に組み込まれ、特定の機能を実現するコンピュータシステム
- ポイント：決められた時間内に処理を終えるリアルタイム性が求められる

#### センサ（Sensor）

- 意味：温度・光・加速度などの状態を測って、電気信号に変える部品
- 例：加速度センサ、ジャイロセンサ（角速度）、照度センサ

#### アクチュエータ（Actuator）

- 意味：電気信号を、回転や移動などの物理的な動きに変える部品
- 例：モータ、ソレノイド

#### ステッピングモータ（Stepping Motor）

- 意味：パルス信号1回ごとに一定の角度だけ回るモータ
- ポイント：回転角をパルスの数で正確に制御できる

#### サーボモータ（Servo Motor）

- 意味：位置や速度を検出しながら、指示どおりに動くよう制御されるモータ

#### PWM制御（ぴーだぶりゅーえむせいぎょ / Pulse Width Modulation）

- 意味：信号のオンとオフの時間の比率を変えて、モータの速さや明るさを調整する方式
- 語の意味：Pulse＝パルス／Width＝幅／Modulation＝変調

#### D/A変換器（でぃーえーへんかんき / Digital-to-Analog Converter）

- 意味：ディジタルの値をアナログの電圧などに変える装置
- ポイント：逆はA/D変換器


## 6-3 論理設計


### 回路の設計

#### 真理値表（しんりちひょう / Truth Table）

- 意味：入力のすべての組合せと、そのときの出力を表にしたもの

#### カルノー図（Karnaugh Map）

- 意味：論理式を簡単にするための図
- ポイント：隣り合う1をまとめて項を減らす

#### 回路の簡単化（Simplification）

- 意味：同じ働きをする、より少ない部品の回路にすること
- 例：A・B＋A・(NOT B)＝A


## 6-4 構成部品・消費電力


### 電力と部品

#### 消費電力（しょうひでんりょく / Power Consumption）

- 意味：機器が動くのに使う電力
- ポイント：動いていない部分の電源やクロックを止めると減らせる

#### クロックゲーティング（Clock Gating）

- 意味：使っていない回路へのクロックの供給を止めて、消費電力を減らす技術

#### DVFS（でぃーぶいえふえす / Dynamic Voltage and Frequency Scaling）

- 意味：処理の重さに合わせて電圧とクロック周波数を下げ、消費電力を減らす技術
- 語の意味：Dynamic＝動的に／Voltage＝電圧／Frequency＝周波数／Scaling＝調整する

#### バッテリ（Battery）

- 意味：電気をためて供給する部品
- ポイント：リチウムイオン電池は繰り返し充電できる二次電池


## 問題演習

- 書式：「#### 問 問題ID」の下に、問・ア〜エ・正解・解説を書く。「###」は小分類（クイズの範囲に使う）

### 6-1 電気・電子回路

#### 問 fe-6-q01

- 問：出力が、現在の入力だけでなく過去の状態にも依存する回路はどれか。
- ア：組合せ回路
- イ：順序回路
- ウ：半加算器
- エ：NAND回路
- 正解：イ
- 解説：順序回路は状態を記憶する。フリップフロップが代表例。

#### 問 fe-6-q02

- 問：半加算器で、桁上がりの出力を得るために使う論理回路はどれか。
- ア：AND
- イ：OR
- ウ：XOR
- エ：NOT
- 正解：ア
- 解説：2つの入力がともに1のときだけ桁上がりが出るのでAND。和はXORで求める。

#### 問 fe-6-q03

- 問：製造後に利用者が回路の構成を書き換えられるICはどれか。
- ア：DRAM
- イ：FPGA
- ウ：SoC
- エ：CPU
- 正解：イ
- 解説：FPGA（Field Programmable Gate Array）は現場で回路を書き換えられる。

### 6-2 機械・制御

#### 問 fe-6-q04

- 問：入力パルス1つごとに一定の角度だけ回転するモータはどれか。
- ア：サーボモータ
- イ：ステッピングモータ
- ウ：リニアモータ
- エ：DCモータ
- 正解：イ
- 解説：ステッピングモータはパルスの数で回転角を正確に決められる。

#### 問 fe-6-q05

- 問：オンとオフの時間の比率を変えて、モータの回転速度などを制御する方式はどれか。
- ア：PCM
- イ：PWM
- ウ：DMA
- エ：DVFS
- 正解：イ
- 解説：PWM（Pulse Width Modulation）はパルスの幅を変えて平均の電力を調整する。

#### 問 fe-6-q06

- 問：電気信号を回転や移動などの物理的な動作に変換する装置はどれか。
- ア：センサ
- イ：アクチュエータ
- ウ：A/D変換器
- エ：フリップフロップ
- 正解：イ
- 解説：アクチュエータは電気信号を動きに変える。状態を測るのはセンサ。

### 6-3 論理設計

#### 問 fe-6-q07

- 問：次の論理式と同じ値になるものはどれか。NOT(A AND B)
- ア：(NOT A) AND (NOT B)
- イ：(NOT A) OR (NOT B)
- ウ：A OR B
- エ：A AND B
- 正解：イ
- 解説：ド・モルガンの法則により、NOT(A AND B)＝(NOT A) OR (NOT B)。

### 6-4 構成部品・消費電力

#### 問 fe-6-q08

- 問：処理の負荷に応じて電源電圧とクロック周波数を下げ、消費電力を抑える技術はどれか。
- ア：DVFS
- イ：RAID
- ウ：PWM
- エ：DMA
- 正解：ア
- 解説：DVFS（Dynamic Voltage and Frequency Scaling）は電圧と周波数を動的に調整する。
