## 19-1 経営戦略手法

### まとめ表

**PPMの4つの区分**

| 区分 | 市場成長率 | 市場占有率 | 方針 |
| :-: | :-: | :-: | :-: |
| 花形 | 高い | 高い | 投資を続ける |
| 金のなる木 | 低い | 高い | 稼いだ資金をほかへ回す |
| 問題児 | 高い | 低い | 投資して花形に育てるか判断 |
| 負け犬 | 低い | 低い | 撤退を考える |

**SWOT分析**

| | よい面 | 悪い面 |
| :-: | :-: | :-: |
| 内部環境 | 強み（S） | 弱み（W） |
| 外部環境 | 機会（O） | 脅威（T） |


### 分析の手法

#### SWOT分析（Strengths, Weaknesses, Opportunities, Threats）

- 意味：内部の強み・弱みと、外部の機会・脅威を整理して戦略を考える方法
- 語の意味：Strengths＝強み／Weaknesses＝弱み／Opportunities＝機会／Threats＝脅威

#### PPM（ぴーぴーえむ / Product Portfolio Management）

- 意味：市場成長率と市場占有率で事業を4つに分け、資金の配分を決める方法
- 語の意味：Product＝製品／Portfolio＝組合せ／Management＝管理

#### 3C分析（Customer, Competitor, Company）

- 意味：顧客・競合・自社の3つの面から状況を分析する方法
- 語の意味：Customer＝顧客／Competitor＝競合／Company＝自社

#### バリューチェーン分析（Value Chain Analysis）

- 意味：事業の活動を主活動と支援活動に分け、どこで価値が生まれているかを調べる方法

#### ファイブフォース分析（Five Forces Analysis）

- 意味：業界の競争の強さを、5つの力（新規参入・代替品・売り手・買い手・競合）で分析する方法

#### PEST分析（Politics, Economy, Society, Technology）

- 意味：政治・経済・社会・技術の面から、外部の環境を分析する方法


### 戦略

#### コアコンピタンス（Core Competence）

- 意味：ほかの会社がまねできない、自社の中心となる強み

#### ベンチマーキング（Benchmarking）

- 意味：優れた他社のやり方を目標（基準）にして、自社を改善する方法

#### アウトソーシング（Outsourcing）

- 意味：自社の業務の一部を、外部の専門業者に任せること

#### M&A（えむあんどえー / Mergers and Acquisitions）

- 意味：企業の合併や買収
- 語の意味：Mergers＝合併／Acquisitions＝買収

#### アライアンス（Alliance）

- 意味：企業どうしが協力して事業を行うこと。業務提携

#### 競争地位別戦略（Competitive Position Strategy）

- 意味：市場での立場で戦略を変える考え方
- ポイント：リーダ（全体を押さえる）・チャレンジャ（リーダに挑む）・フォロワ（まねする）・ニッチャ（すき間に集中）

#### プロダクトライフサイクル（Product Life Cycle）

- 意味：製品が市場に出てから消えるまでを、導入期・成長期・成熟期・衰退期に分けた考え方


## 19-2 マーケティング

### まとめ表

**4Pと4C**

| 4P（売り手の見方） | 4C（買い手の見方） |
| :-: | :-: |
| Product（製品） | Customer Value（顧客にとっての価値） |
| Price（価格） | Customer Cost（顧客の負担） |
| Place（流通） | Convenience（入手のしやすさ） |
| Promotion（販売促進） | Communication（対話） |


### マーケティング

#### マーケティングミックス（Marketing Mix）

- 意味：4Pなどの要素を組み合わせて、売るための戦略を立てること

#### 4P（Product, Price, Place, Promotion）

- 意味：売り手から見たマーケティングの4つの要素
- 語の意味：Product＝製品／Price＝価格／Place＝流通／Promotion＝販売促進

#### 4C（Customer Value, Customer Cost, Convenience, Communication）

- 意味：買い手から見たマーケティングの4つの要素
- 語の意味：Customer Value＝顧客価値／Customer Cost＝顧客の負担／Convenience＝利便性／Communication＝対話

#### セグメンテーション・ターゲティング・ポジショニング（STP）

- 意味：市場を分け（S）、狙う相手を決め（T）、自社の立ち位置を決める（P）こと

#### コストプラス価格決定法（Cost-plus Pricing）

- 意味：原価に決まった利益を上乗せして価格を決める方法

#### オピニオンリーダ（Opinion Leader）

- 意味：周りの人の買い物に影響を与える人


## 19-3 ビジネス戦略と目標・評価


### 目標と評価

#### KGI（けーじーあい / Key Goal Indicator）

- 意味：最終的な目標をどれだけ達成したかを表す指標
- 例：売上高を10％増やす
- 語の意味：Key＝重要な／Goal＝目標／Indicator＝指標

#### CSF（しーえすえふ / Critical Success Factor）

- 意味：目標を達成するために、特に重要な成功の要因
- 語の意味：Critical＝決定的に重要な／Success＝成功／Factor＝要因

#### KPI（けーぴーあい / Key Performance Indicator）

- 意味：目標に向かって進んでいるかを途中で測る指標
- ポイント：KGIを決め、CSFを見つけ、KPIで測る
- 語の意味：Key＝重要な／Performance＝成果／Indicator＝指標

#### BSC（びーえすしー / Balanced Scorecard）

- 意味：財務・顧客・業務プロセス・学習と成長の4つの視点で業績を評価する方法
- ポイント：財務だけに偏らない
- 語の意味：Balanced＝バランスのとれた／Scorecard＝成績表


## 19-4 経営管理システム


### 経営を支える仕組み

#### ERP（いーあーるぴー / Enterprise Resource Planning）

- 意味：会計・販売・生産・人事などの基幹業務をまとめて管理し、経営資源を有効に使う仕組み
- 語の意味：Enterprise＝企業／Resource＝資源／Planning＝計画

#### CRM（しーあーるえむ / Customer Relationship Management）

- 意味：顧客の情報をまとめて管理し、顧客との関係をよくして満足度を上げる仕組み
- 語の意味：Customer＝顧客／Relationship＝関係／Management＝管理

#### SCM（えすしーえむ / Supply Chain Management）

- 意味：材料の調達から生産・物流・販売までの流れを全体で管理し、在庫や納期を最適にする仕組み
- 語の意味：Supply＝供給／Chain＝連鎖／Management＝管理

#### SFA（えすえふえー / Sales Force Automation）

- 意味：営業の活動や商談の情報を共有して、営業を効率化する仕組み
- 語の意味：Sales Force＝営業部隊／Automation＝自動化

#### ナレッジマネジメント（Knowledge Management）

- 意味：社員の知識やノウハウを組織で共有し、活用すること

### 19-3 ビジネス戦略と目標・評価

#### 問 913no3-q1

- 問：KGI・CSF・KPIの関係として最も適切なものはどれか。
- ア：KPIを達成するとCSFが決まり、その結果KGIが決まる
- イ：KGI（最終目標）を達成するためのCSF（重要成功要因）を定め、その達成度をKPI（重要業績評価指標）で測る
- ウ：KGI・CSF・KPIはすべて同じ指標を指す別名である
- エ：CSFはKPIを達成した後に事後的に決める指標である
- 正解：イ
- 解説：KGIが最終目標、CSFがそのための重要成功要因、KPIはCSFの達成度を測る指標です。

#### 問 927no11-1
