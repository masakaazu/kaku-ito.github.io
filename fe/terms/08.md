## 8-1 マルチメディア技術

### まとめ表

**画像・音声・動画の形式**

| 形式 | 種類 | 圧縮 | 特徴 |
| :-: | :-: | :-: | :-: |
| BMP | 静止画 | なし | 画素をそのまま記録 |
| GIF | 静止画 | 可逆 | 256色まで。簡単なアニメーション |
| PNG | 静止画 | 可逆 | フルカラー、透過 |
| JPEG | 静止画 | 非可逆 | 写真向け |
| MPEG | 動画 | 非可逆 | 動画と音声の圧縮規格 |
| MP3 | 音声 | 非可逆 | 音楽配信など |


### 画像と色

#### 画素（ピクセル / Pixel）

- 意味：画像を構成するいちばん小さな点

#### 画像データ量（がぞうでーたりょう / Image Data Size）

- 意味：横の画素数 × 縦の画素数 × 1画素あたりのビット数
- 例：800×600画素・24ビットなら 11,520,000ビット

#### 光の三原色（RGB / Red, Green, Blue）

- 意味：赤・緑・青の光を混ぜて色を作る方法。画面の表示に使う
- ポイント：全部混ぜると白。印刷は色の三原色（シアン・マゼンタ・イエロー）で、全部混ぜると黒に近くなる

#### フルカラー（Full Color）

- 意味：RGBそれぞれ8ビット、計24ビットで約1,677万色を表す方式

#### ベクター形式・ラスター形式（Vector / Raster）

- 意味：ベクターは線や図形を数式で記録、ラスターは画素の並びで記録
- ポイント：ベクターは拡大しても粗くならない

#### 解像度（かいぞうど / Resolution）

- 意味：画像の細かさ。画素の数で表す


### 圧縮

#### 可逆圧縮（かぎゃくあっしゅく / Lossless Compression）

- 意味：元のデータに完全に戻せる圧縮
- 例：PNG、GIF、ZIP

#### 非可逆圧縮（ひかぎゃくあっしゅく / Lossy Compression）

- 意味：元のデータに完全には戻らないが、大きく小さくできる圧縮
- 例：JPEG、MPEG、MP3

#### BMP（びっとまっぷ / Bitmap）

- 意味：画素の情報を圧縮せずにそのまま記録する静止画の形式
- 語の意味：Bit＝ビット／Map＝配置図

#### GIF（じふ / Graphics Interchange Format）

- 意味：256色までの可逆圧縮の静止画形式。簡単なアニメーションもできる
- 語の意味：Graphics＝画像／Interchange＝交換用の／Format＝形式

#### PNG（ぴんぐ / Portable Network Graphics）

- 意味：フルカラーを扱える可逆圧縮の静止画形式。透過もできる
- 語の意味：Portable＝持ち運べる／Network＝ネットワーク向けの／Graphics＝画像

#### JPEG（じぇいぺぐ / Joint Photographic Experts Group）

- 意味：写真に向く非可逆圧縮の静止画形式
- ポイント：圧縮率を選べる
- 語の意味：Joint＝合同の／Photographic＝写真の／Experts Group＝専門家の会（規格を作った団体名）

#### MPEG（えむぺぐ / Moving Picture Experts Group）

- 意味：動画と音声を圧縮する国際標準規格
- ポイント：MPEG-2はDVD・放送、MPEG-4はネット配信など
- 語の意味：Moving Picture＝動く画像（動画）／Experts Group＝専門家の会

#### MP3（えむぴーすりー / MPEG-1 Audio Layer-3）

- 意味：音声を圧縮する形式。聞こえにくい音を省いて小さくする
- 語の意味：MPEG-1＝動画規格の名前／Audio＝音声／Layer-3＝第3層


### 音

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：アナログの音を標本化・量子化・符号化してディジタルにする方式
- ポイント：量子化ビット数が多いほど、標本化周波数が高いほど音質がよく、データ量も増える
- 語の意味：Pulse＝パルス／Code＝符号／Modulation＝変調

#### 音声のデータ量（おんせいのでーたりょう / Audio Data Size）

- 意味：標本化周波数 × 量子化ビット数 × チャンネル数 × 秒数
- 例：44.1kHz・16ビット・ステレオ・1秒 ＝ 約1.4Mビット

#### MIDI（みでぃ / Musical Instrument Digital Interface）

- 意味：電子楽器の演奏情報（音の高さ・長さなど）をやり取りする規格
- ポイント：音そのものではなく演奏の命令を記録するので、データ量が小さい
- 語の意味：Musical Instrument＝楽器／Digital＝ディジタル／Interface＝接続規格


## 8-2 マルチメディア応用


### 仮想と現実

#### AR（えーあーる / Augmented Reality）

- 意味：現実の風景に、コンピュータで作った情報を重ねて見せる技術。拡張現実
- 例：カメラ越しに道案内を表示
- 語の意味：Augmented＝拡張された／Reality＝現実

#### VR（ぶいあーる / Virtual Reality）

- 意味：コンピュータで作った仮想の世界に、入り込んだように感じさせる技術。仮想現実
- 語の意味：Virtual＝仮想の／Reality＝現実

#### MR（えむあーる / Mixed Reality）

- 意味：現実と仮想を融合させ、仮想の物に触れるように操作できる技術。複合現実
- 語の意味：Mixed＝混ぜ合わせた／Reality＝現実

#### CG（しーじー / Computer Graphics）

- 意味：コンピュータで画像や映像を作る技術
- ポイント：レンダリングは、データから画像を作り出す処理
- 語の意味：Computer＝コンピュータ／Graphics＝画像

#### メタバース（Metaverse）

- 意味：インターネット上に作られた、多くの人が参加できる3次元の仮想空間

#### ストリーミング（Streaming）

- 意味：動画や音声を、受け取りながら同時に再生する方式
- ポイント：全部ダウンロードし終わるのを待たずに見られる

#### 問 d2

- 問：横800ドット、縦600ドット、1画素当たり24ビットの非圧縮画像データ量は何bitか。
- ア：1,440,000bit
- イ：11,520,000bit

- エ：57,600,000bit
- 正解：イ

#### 問 927no9-media-0

- イ：PNG

- 正解：イ

#### 問 927no9-media-1

- イ：PNG

- 正解：ウ
- 解説：JPEGはフルカラーの静止画向けで、非可逆圧縮を用いる。

#### 問 927no9-media-3

- ア：GIF
- イ：MPEG
- ウ：BMP
- エ：PNG
- 正解：イ
- 解説：MPEGは動画圧縮の国際標準規格群である。

#### 問 fe-8-q01

- 問：標本化周波数44.1kHz、量子化ビット数16ビット、ステレオ（2チャンネル）で1秒間録音したときのデータ量に最も近いものはどれか。
- ア：約0.7Mビット
- イ：約1.4Mビット
- ウ：約2.8Mビット
- エ：約14Mビット
- 正解：イ
- 解説：44,100×16×2＝1,411,200ビットで約1.4Mビット。

#### 問 fe-8-q02

- 問：画面表示に使われる光の三原色をすべて最大の強さで重ねたときの色はどれか。
- ア：黒
- イ：白
- ウ：灰色
- エ：赤
- 正解：イ
- 解説：光の三原色（RGB）は加法混色なので、すべて重ねると白になる。

#### 問 fe-8-q03

- 問：電子楽器の演奏情報をやり取りする規格で、音そのものではなく音の高さや長さなどを記録するものはどれか。

- イ：MIDI
- ウ：PCM
- エ：MPEG
- 正解：イ
- 解説：MIDIは演奏の命令を記録するのでデータ量が小さい。
