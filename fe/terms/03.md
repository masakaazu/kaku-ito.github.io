## 3-1 プロセッサ

### まとめ表

**性能の計算**

| 求めるもの | 公式 |
| :-: | :-: |
| 実行時間 | 命令数 × CPI ÷ クロック周波数 |
| MIPS | クロック周波数 ÷ (CPI × 10の6乗) |
| 実効アクセス時間 | ヒット率×キャッシュの時間 ＋ (1−ヒット率)×主記憶の時間 |


### CPUの仕組み

#### CPU（しーぴーゆー / Central Processing Unit）

- 意味：命令を読み取って実行する、コンピュータの中心の装置。制御装置と演算装置からなる
- 語の意味：Central＝中心の／Processing＝処理／Unit＝装置

#### プログラム内蔵方式（ノイマン型 / Stored Program）

- 意味：プログラムとデータを主記憶装置に入れておき、順に読み出して実行する方式
- ポイント：今のコンピュータの基本の形

#### 命令実行サイクル（めいれいじっこうさいくる / Instruction Cycle）

- 意味：命令の取出し（フェッチ）→ 解読 → オペランドの読出し → 実行、を繰り返す流れ
- ポイント：フェッチは主記憶から命令を取り出すこと

#### レジスタ（Register）

- 意味：CPUの中にある、命令や計算途中のデータを一時的に置く高速な記憶場所
- ポイント：プログラムカウンタは次に実行する命令のアドレスを持つ

#### 逐次制御方式（ちくじせいぎょほうしき / Sequential Control）

- 意味：命令を1つずつ順番に実行する方式
- ポイント：分岐命令で実行順序を変えられる

#### クロック周波数（Clock Frequency）

- 意味：CPUが動作のタイミングに使う信号の、1秒あたりの回数
- 例：1GHz は1秒に10億回

#### CPI（しーぴーあい / Cycles Per Instruction）

- 意味：1つの命令の実行にかかる平均のクロック数
- ポイント：小さいほど速い
- 語の意味：Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令

#### MIPS（みっぷす / Million Instructions Per Second）

- 意味：1秒間に何百万個の命令を実行できるかを表す性能の値
- 例：800MHz・CPI 4 なら 800÷4＝200MIPS
- 語の意味：Million＝100万／Instructions＝命令／Per Second＝1秒あたり

#### CISC（しすく / Complex Instruction Set Computer）

- 意味：複雑で多機能な命令をたくさん持つCPU
- ポイント：命令ごとに長さや実行時間がまちまち
- 語の意味：Complex＝複雑な／Instruction Set＝命令の一式／Computer＝計算機

#### RISC（りすく / Reduced Instruction Set Computer）

- 意味：単純な命令に絞り、1命令を短い時間で実行するCPU
- ポイント：パイプライン処理と相性がよい
- 語の意味：Reduced＝減らした／Instruction Set＝命令の一式／Computer＝計算機

#### パイプライン（Pipeline）

- 意味：命令の各段階をずらして重ねて実行し、処理を速くする方式
- ポイント：分岐があると先読みした命令が無駄になる（ハザード）

#### マルチコアプロセッサ（Multi-core Processor）

- 意味：1つのCPUの中に複数の演算の中核（コア）を持つプロセッサ
- ポイント：複数の処理を同時に進められる

#### GPU（じーぴーゆー / Graphics Processing Unit）

- 意味：画像処理用に作られた、単純な計算を大量に並列で行うプロセッサ
- ポイント：AIの学習にも使われる
- 語の意味：Graphics＝画像／Processing＝処理／Unit＝装置

#### 割込み（わりこみ / Interrupt）

- 意味：実行中の処理を一時中断して、別の処理を優先して行う仕組み
- ポイント：外部割込み＝タイマや入出力の完了など外からの要因。内部割込み＝0での割り算やページフォールトなどプログラムが原因


## 3-2 メモリ

### まとめ表

**半導体メモリの分類**

| 種類 | 電源を切ると | 例 |
| :-: | :-: | :-: |
| RAM（読み書き） | 消える（揮発性） | DRAM（主記憶）、SRAM（キャッシュ） |
| ROM（主に読出し） | 残る（不揮発性） | マスクROM、EEPROM、フラッシュメモリ |


### 半導体メモリ

#### 主記憶装置（しゅきおくそうち / Main Memory）

- 意味：CPUが直接読み書きする記憶装置。実行中のプログラムとデータを置く
- ポイント：一般にDRAMを使う

#### DRAM（でぃーらむ / Dynamic RAM）

- 意味：コンデンサの電荷で記憶するRAM。定期的なリフレッシュが必要
- ポイント：安くて大容量なので主記憶に使う
- 語の意味：Dynamic＝動的な（電荷が抜けるので書き直す）／RAM＝読み書きできるメモリ

#### SRAM（えすらむ / Static RAM）

- 意味：フリップフロップ回路で記憶するRAM。リフレッシュ不要で高速
- ポイント：高価なのでキャッシュメモリに使う
- 語の意味：Static＝静的な（書き直し不要）／RAM＝読み書きできるメモリ

#### SDRAM（えすでぃーらむ / Synchronous DRAM）

- 意味：クロックに同期して動くDRAM
- ポイント：揮発性でリフレッシュが必要
- 語の意味：Synchronous＝同期した／DRAM＝ダイナミックRAM

#### リフレッシュ（Refresh）

- 意味：DRAMの電荷が抜けて内容が消えないよう、定期的に書き直す動作

#### ROM（ろむ / Read Only Memory）

- 意味：電源を切っても内容が消えない（不揮発性の）メモリ
- ポイント：マスクROMは製造時に書き込み、書き換え不可
- 語の意味：Read Only＝読むだけの／Memory＝記憶装置

#### EEPROM（いーいーぴーろむ / Electrically Erasable Programmable ROM）

- 意味：電気で内容を消して書き換えられる不揮発性のROM
- ポイント：フローティングゲートに電荷をためて記憶する
- 語の意味：Electrically＝電気で／Erasable＝消せる／Programmable＝書き込める／ROM＝不揮発性メモリ

#### フラッシュメモリ（Flash Memory）

- 意味：EEPROMの一種で、ブロック単位でまとめて消去・書換えするメモリ
- ポイント：USBメモリ、SDカード、SSDに使う

#### キャッシュメモリ（Cache Memory）

- 意味：CPUと主記憶の速度差を埋めるために間に置く、小さくて高速なメモリ
- ポイント：よく使うデータを置く。1次・2次と階層にする

#### ヒット率（ひっとりつ / Hit Ratio）

- 意味：読みたいデータがキャッシュにある割合
- 例：キャッシュ10ns・主記憶100ns・ヒット率90%なら 0.9×10＋0.1×100＝19ns

#### ライトスルー方式（Write Through）

- 意味：キャッシュに書くと同時に、主記憶にも書き込む方式
- ポイント：主記憶と常に一致するが遅い

#### ライトバック方式（Write Back）

- 意味：キャッシュだけに書き、追い出されるときに主記憶へ書き戻す方式
- ポイント：速いが、主記憶と一時的に不一致になる

#### メモリインタリーブ（Memory Interleave）

- 意味：主記憶をいくつかのバンクに分け、並行して読み出して速くする方式


## 3-3 バス


### データの通り道

#### バス（Bus）

- 意味：CPU・メモリ・入出力装置の間でデータを運ぶ共通の通り道
- ポイント：アドレスバス・データバス・制御バスがある

#### バス幅（ばすはば / Bus Width）

- 意味：一度に運べるビット数
- ポイント：幅が広いほど一度にたくさん運べる


## 3-4 入出力デバイス


### 入出力インタフェース

#### シリアルインタフェース（Serial Interface）

- 意味：データを1ビットずつ順に送るインタフェース
- 例：USB、SATA。今の主流

#### パラレルインタフェース（Parallel Interface）

- 意味：複数のビットを同時に並べて送るインタフェース
- ポイント：速度を上げると信号のずれが問題になる

#### USB（ゆーえすびー / Universal Serial Bus）

- 意味：パソコンと周辺機器をつなぐシリアルインタフェースの規格
- ポイント：ハブで多くの機器をつなげ、電源も供給できる
- 語の意味：Universal＝汎用の／Serial＝1ビットずつ順に／Bus＝通り道

#### 無線インタフェース（Wireless Interface）

- 意味：ケーブルを使わずにデータをやり取りする方式
- 例：Bluetooth、IrDA（赤外線）、NFC

#### プラグアンドプレイ（Plug and Play）

- 意味：機器をつなぐだけで、OSが自動で認識して設定する仕組み

#### ホットプラグ（Hot Plug）

- 意味：電源を入れたまま機器を抜き差しできる仕組み

#### デバイスドライバ（Device Driver）

- 意味：OSが周辺機器を動かすためのソフトウェア

#### DMA（でぃーえむえー / Direct Memory Access）

- 意味：CPUを通さず、入出力装置と主記憶の間で直接データを転送する方式
- ポイント：CPUの負担が減る
- 語の意味：Direct＝直接の／Memory＝主記憶／Access＝読み書き


## 3-5 入出力装置


### 補助記憶装置

#### HDD（えいちでぃーでぃー / Hard Disk Drive）

- 意味：回転する磁気ディスクにデータを記録する補助記憶装置
- 語の意味：Hard Disk＝硬い円盤／Drive＝駆動装置

#### HDDのアクセス時間（Access Time）

- 意味：位置決め時間（シーク時間）＋ 回転待ち時間 ＋ データ転送時間
- ポイント：平均回転待ち時間は1回転の半分

#### セクタ・トラック（Sector, Track）

- 意味：トラックはディスク上の同心円の記録場所、セクタはトラックを分けた最小の記録単位

#### フラグメンテーション（断片化 / Fragmentation）

- 意味：ファイルのデータがディスク上のあちこちに散らばった状態
- ポイント：読み書きが遅くなる。デフラグで並べ直す

#### SSD（えすえすでぃー / Solid State Drive）

- 意味：フラッシュメモリを使った補助記憶装置
- ポイント：可動部がなく、HDDより速くて衝撃に強い
- 語の意味：Solid State＝半導体の／Drive＝記憶装置

#### 磁気テープ（Magnetic Tape）

- 意味：テープに磁気で記録する装置。先頭から順にしか読めない
- ポイント：大容量で安いのでバックアップの保管に使う


### 表示・入力装置

#### 解像度（かいぞうど / Resolution）

- 意味：画面や画像を構成する点（画素）の数
- 例：1920×1080

#### dpi（でぃーぴーあい / dots per inch）

- 意味：1インチの中に点がいくつあるか。プリンタやスキャナの細かさ
- 語の意味：dots＝点／per inch＝1インチあたり

- 解説：高速でリフレッシュ不要なSRAMは、CPU近くのキャッシュに適します。

#### 問 925no1-storage-0

- 問：EEPROMの特徴として適切なものはどれか。
- ア：電気的に書換え可能な不揮発性メモリ

- エ：磁気を使う補助記憶
- 正解：ア

#### 問 925no1-storage-1

- 問：SDRAMの説明として適切なものはどれか。

- 正解：ア
- 解説：SDRAMはSynchronous DRAMの略で、クロック同期型のDRAMです。

#### 問 925no1-storage-2

- 正解：ア
- 解説：EEPROMやフラッシュメモリでは、フローティングゲートに蓄積した電荷を利用します。

#### 問 fe-3-q03

### 3-5 入出力装置

#### 問 915no2-storage-2

- 問：HDDのアクセス時間に通常含まれないものはどれか。
- ア：位置決め時間
- イ：回転待ち時間
- ウ：データ転送時間

- 正解：エ
- 解説：アクセス時間は媒体上のデータへ到達し転送する時間であり、コンパイル時間は含みません。

#### 問 915no2-storage-3

- 問：HDD上でファイルのデータが分散して配置された状態はどれか。

- イ：ミラーリング
- ウ：スワッピング
- エ：パリティ
- 正解：ア
- 解説：フラグメンテーション（断片化）です。HDDでは性能低下の要因になり得ます。

- ア：磁気テープ
- イ：フラッシュメモリ
- ウ：紙テープ
- エ：光ディスクのみ
- 正解：イ
- 解説：SSDはフラッシュメモリを記憶媒体として内蔵する補助記憶装置です。

#### 問 fe-3-q05

- 問：磁気テープ装置の特徴として適切なものはどれか。

- エ：CPUの中にある
- 正解：イ
- 解説：磁気テープは順次アクセスのみ。安価で大容量なのでバックアップの保管に向く。
