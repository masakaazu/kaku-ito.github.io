### 数の表し方

#### 基数（きすう / Radix）

- 意味：何進数かを表す数。2進数なら2、16進数なら16
- ポイント：2進数1桁は0と1、16進数1桁は0〜9とA〜F

#### 2進数（にしんすう / Binary Number）

- 意味：0と1の2種類の数字で表す数。コンピュータ内部の表し方
- ポイント：2進数4桁が16進数1桁にあたる

#### 16進数（じゅうろくしんすう / Hexadecimal）

- 意味：0〜9とA〜Fの16種類で表す数
- 例：2進数 1010 1100 ＝ 16進数 AC

#### 補数（ほすう / Complement）

- 意味：負の数を表すための考え方。1の補数は全ビット反転、2の補数はさらに1を足したもの
- ポイント：減算を「2の補数を足す」加算で実現できる。nビットで −2のn−1乗 〜 2のn−1乗−1 を表せる
- 例：8ビットで −5 は 11111011

#### 固定小数点数（こていしょうすうてんすう / Fixed-point Number）

- 意味：小数点の位置を決めておいて数を表す方式
- ポイント：整数の表現に使う

#### 浮動小数点数（ふどうしょうすうてんすう / Floating-point Number）

- 意味：符号・仮数部・指数部で数を表す方式。大きな数も小さな数も表せる
- 例：0.75 ＝ 1.1（2進）× 2の−1乗
- 注：IEEE 754 では指数部にバイアス値を足して格納する

#### 誤差（ごさ / Error）

- 意味：計算で生じる本当の値とのずれ
- ポイント：桁あふれ（オーバフロー）、丸め誤差、桁落ち（近い値の引き算で有効桁が減る）、情報落ち（大きい数に小さい数を足すと消える）を区別

#### シフト演算（しふとえんざん / Shift Operation）

- 意味：ビット列を左右にずらす演算
- ポイント：左にnビットで2のn乗倍、右にnビットで2のn乗分の1（符号なし）


### 論理演算と集合

#### 論理演算（ろんりえんざん / Logical Operation）

- 意味：真（1）と偽（0）を使う演算。AND・OR・NOT・XORなど
- ポイント：XORは「どちらか一方だけ1」のとき1

#### ド・モルガンの法則（De Morgan's Laws）

- 意味：NOT(A AND B) ＝ (NOT A) OR (NOT B)、NOT(A OR B) ＝ (NOT A) AND (NOT B)
- ポイント：否定を分配すると AND と OR が入れ替わる

#### ベン図（べんず / Venn Diagram）

- 意味：集合どうしの関係を円の重なりで表した図
- ポイント：論理式とベン図の対応がよく問われる

#### 逆ポーランド表記法（ぎゃくぽーらんどひょうきほう / Reverse Polish Notation）

- 意味：演算子を後ろに書く表し方。スタックを使って左から計算できる
- 例：a+(b×(c−d)) → abcd−×+ 、 3 4 + 5 × → 35

#### BNF記法（びーえぬえふきほう / Backus-Naur Form）

- 意味：プログラム言語などの文法を定義するための記法
- ポイント：::= で定義、｜ で「または」を表す
- 語の意味：Backus＝考案者の名前／Naur＝考案者の名前／Form＝記法

### 確率と統計

#### 順列（じゅんれつ / Permutation）

- 意味：いくつかのものを、順序を区別して並べる並べ方の数
- 例：3人を1位・2位・3位に並べる ＝ 3P3 ＝ 6通り

#### 組合せ（くみあわせ / Combination）

- 意味：順序を区別せずに選ぶ選び方の数
- 例：5人から2人を選ぶ ＝ 5C2 ＝ 10通り

#### 期待値（きたいち / Expected Value）

- 意味：起こりうる値に、それぞれの確率を掛けて足したもの。平均的に見込める値
- 例：20%で1万円のくじの期待値は2,000円

#### 平均値・中央値・最頻値（へいきんち・ちゅうおうち・さいひんち / Mean, Median, Mode）

- 意味：平均値は合計÷個数、中央値は並べた真ん中、最頻値は最も多い値
- ポイント：外れ値の影響を受けにくいのは中央値

#### 分散・標準偏差（ぶんさん・ひょうじゅんへんさ / Variance, Standard Deviation）

- 意味：データが平均からどれだけ散らばっているかを表す値。標準偏差は分散の平方根
- ポイント：値が大きいほどばらつきが大きい

#### 正規分布（せいきぶんぷ / Normal Distribution）

- 意味：平均を中心に左右対称の釣り鐘型になる分布
- ポイント：平均±1標準偏差に約68%、±2標準偏差に約95%が入る

#### 相関係数（そうかんけいすう / Correlation Coefficient）

- 意味：2つの値の関係の強さを −1〜1 で表す値
- ポイント：1に近いほど正の相関、−1に近いほど負の相関。相関があっても因果関係とは限らない

#### 回帰分析（かいきぶんせき / Regression Analysis）

- 意味：ある値から別の値を予測する式を求める分析
- 例：広告費から売上を予測する

#### 主成分分析（しゅせいぶんぶんせき / Principal Component Analysis）

- 意味：多くの変数を、少数の総合的な指標にまとめる分析
- ポイント：クラスター分析は似たもの同士をグループ分けする

#### 待ち行列理論（まちぎょうれつりろん / Queueing Theory）

- 意味：窓口などで待ち時間がどれくらいになるかを計算する理論。M/M/1モデルが基本
- ポイント：利用率 ρ ＝ 平均到着率 × 平均サービス時間。平均待ち時間 ＝ ρ÷(1−ρ) × サービス時間

#### グラフ理論（ぐらふりろん / Graph Theory）

- 意味：点（ノード）と線（エッジ）で、ものどうしのつながりを表す数学
- ポイント：最短経路問題などに使う


## 1-3 情報に関する理論


### 符号化と単位

#### SI接頭語（えすあいせっとうご / SI Prefix）

- 意味：大きさを表す単位の頭につける記号
- ポイント：k＝10の3乗、M＝10の6乗、G＝10の9乗、T＝10の12乗。m＝10の−3乗、μ＝10の−6乗、n＝10の−9乗、p＝10の−12乗
- 語の意味：SI＝Système International（国際単位系）

#### ビット・バイト（Bit, Byte）

- 意味：ビットは0か1の1桁、バイトは8ビット
- ポイント：nビットで2のn乗通りを表せる

#### ハフマン符号化（はふまんふごうか / Huffman Coding）

- 意味：よく出る文字に短いビット列、まれな文字に長いビット列を割り当てて、平均のデータ量を減らす符号化
- ポイント：可逆圧縮の一種

#### 文字コード（もじこーど / Character Code）

- 意味：文字に割り当てた番号の決まり
- ポイント：ASCII（英数字7ビット）、Unicode（世界の文字を1つの体系に）、UTF-8 は Unicode の符号化方式の1つ

#### アナログデータ・ディジタルデータ（Analog / Digital Data）

- 意味：アナログは連続した量、ディジタルは飛び飛びの数値で表したデータ
- ポイント：音や画像をディジタル化して扱う


### AI（人工知能）

#### 機械学習（きかいがくしゅう / Machine Learning）

- 意味：データから規則やパターンをコンピュータに学ばせる技術
- ポイント：教師あり学習・教師なし学習・強化学習の3つに分かれる

#### 教師あり学習（きょうしありがくしゅう / Supervised Learning）

- 意味：正解ラベルの付いたデータで学習する方法
- 例：迷惑メールかどうかの分類、売上の予測

#### 教師なし学習（きょうしなしがくしゅう / Unsupervised Learning）

- 意味：正解ラベルのないデータから、構造や似たまとまりを見つける方法
- 例：似た顧客のグループ分け（クラスタリング）

#### 強化学習（きょうかがくしゅう / Reinforcement Learning）

- 意味：試行錯誤して、報酬が最大になる行動を学ぶ方法
- 例：ゲームやロボットの制御

#### 過学習（かがくしゅう / Overfitting）

- 意味：学習データには合いすぎるが、新しいデータでは精度が低くなる状態
- ポイント：学習データを増やす、モデルを単純にするなどで防ぐ

#### 転移学習（てんいがくしゅう / Transfer Learning）

- 意味：ある課題で学習したモデルを、別の関連する課題に使い回す方法
- ポイント：少ないデータでも学習しやすい

#### ディープラーニング（Deep Learning）

- 意味：何層にも重ねたニューラルネットワークで学習する機械学習
- ポイント：特徴を人が決めなくても自動で見つけられる

#### ニューラルネットワーク（Neural Network）

- 意味：人の脳の神経細胞のつながりをまねた計算の仕組み
- ポイント：入力層・中間層（隠れ層）・出力層からなる

#### 活性化関数（かっせいかかんすう / Activation Function）

- 意味：ニューロンで、入力の重み付き和を次へ渡す出力値に変換する関数
- ポイント：非線形にすることで、直線では分けられない複雑な境界を学習できる

#### ReLU関数（れるかんすう / Rectified Linear Unit）

- 意味：負の入力は0、正の入力はそのまま出す活性化関数
- ポイント：f(x)＝max(0, x)。例: x＝−2 なら 0
- 語の意味：Rectified＝整流された（負を切る）／Linear＝線形の／Unit＝素子

#### シグモイド関数（Sigmoid Function）

- 意味：出力を0〜1に収めるS字の活性化関数
- ポイント：確率のように扱いやすい。tanh関数は−1〜1に収める


## 1-4 通信に関する理論


### 信号の変換

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：音などのアナログ信号を、標本化・量子化・符号化の3段階でディジタルにする方式
- ポイント：標本化＝一定間隔で値を取る、量子化＝段階的な数値に丸める、符号化＝2進数にする
- 語の意味：Pulse＝パルス（信号の山）／Code＝符号／Modulation＝変調

#### 標本化定理（ひょうほんかていり / Sampling Theorem）

- 意味：元の信号の最高周波数の2倍以上の頻度で標本化すれば、元の信号を再現できるという定理
- ポイント：サンプリング周波数を考える問題で使う

#### 伝送誤り（でんそうあやまり / Transmission Error）

- 意味：通信の途中でビットが変わってしまうこと
- ポイント：パリティチェックやCRCで検出、ハミング符号は1ビットの誤りを訂正できる


## 1-5 計測・制御に関する理論


### 制御の方式

#### フィードバック制御（Feedback Control）

- 意味：結果を測って目標との差を求め、その差がなくなるように調整する制御
- 例：室温を測ってエアコンの出力を調整する

#### フィードフォワード制御（Feedforward Control）

- 意味：外からの乱れを先に予測し、結果に影響が出る前に調整する制御
- ポイント：フィードバックは「後から直す」、フィードフォワードは「先回りする」

#### シーケンス制御（Sequence Control）

- 意味：あらかじめ決めた順序に従って、段階的に動作を進める制御
- 例：洗濯機、信号機

#### センサ・アクチュエータ（Sensor, Actuator）

- 意味：センサは温度や光などの状態を測る部品、アクチュエータは電気信号を動きに変える部品
- ポイント：IoT機器の基本の組合せ

#### A/D変換（えーでぃーへんかん / Analog-to-Digital Conversion）

- 意味：センサが測ったアナログの値をディジタルの値に変えること
- ポイント：逆はD/A変換

- ウ：110101
- エ：111011
- 正解：イ

- 正解：ウ

- ウ：20
- エ：25
- 正解：ウ

#### 問 fe-1-q04

- ウ：1110

- 正解：イ
- 解説：XORはビットが異なる桁だけ1になる。1010と0110は上の2桁が異なり、下の2桁は同じなので1100。

#### 問 fe-1-q05

- ア：A
- イ：B
- ウ：A＋B
- エ：1
- 正解：ア
- 解説：A・(B ＋ NOT B)＝A・1＝A。

#### 問 fe-1-q06

### 1-4 通信に関する理論

### 1-5 計測・制御に関する理論

#### 問 d4

- 問：室温を測定し、設定温度との差に応じてエアコンの出力を調整する制御はどれか。
- ア：シーケンス制御
- イ：フィードバック制御
- ウ：フィードフォワード制御
- エ：バッチ制御
- 正解：イ
- 解説：結果（室温）を測って差を補正するのでフィードバック制御。

#### 問 fe-1-q13

- 問：外乱を事前に予測し、結果に影響が出る前に操作量を調整する制御はどれか。

- イ：フィードフォワード制御
- ウ：シーケンス制御
- エ：オン・オフ制御
- 正解：イ
- 解説：先回りして調整するのがフィードフォワード制御。結果を測って直すのがフィードバック制御。
