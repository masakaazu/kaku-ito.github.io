## 11-1 情報セキュリティ

### まとめ表

**情報セキュリティの3要素（CIA）**

| 要素 | 意味 | 損なわれる例 |
| :-: | :-: | :-: |
| 機密性 | 許された人だけが見られる | 情報漏えい |
| 完全性 | 正しく、改ざんされていない | 改ざん |
| 可用性 | 必要なときに使える | DoS攻撃でサービス停止 |

**暗号方式の比べ方**

| | 共通鍵暗号 | 公開鍵暗号 |
| :-: | :-: | :-: |
| 鍵 | 暗号化と復号に同じ鍵 | 公開鍵と秘密鍵のペア |
| 速さ | 速い | 遅い |
| 鍵の数（n人） | n(n−1)/2 個 | 2n 個 |
| 例 | AES | RSA、楕円曲線暗号 |


### 基本の考え方

#### 情報セキュリティの3要素（CIA）

- 意味：機密性・完全性・可用性の3つ
- ポイント：JIS Q 27000では、これに真正性・責任追跡性・否認防止・信頼性を加えることもある
- 語の意味：Confidentiality＝機密性／Integrity＝完全性／Availability＝可用性

#### 脅威（きょうい / Threat）

- 意味：情報資産に損害を与えるおそれのあるもの
- ポイント：物理的脅威・技術的脅威・人的脅威に分かれる

#### 脆弱性（ぜいじゃくせい / Vulnerability）

- 意味：脅威に付け込まれる弱点
- ポイント：ソフトウェアの不具合（セキュリティホール）や管理の甘さ


### 攻撃の手口

#### マルウェア（Malware）

- 意味：悪意のあるソフトウェアの総称
- ポイント：ウイルス・ワーム・トロイの木馬・スパイウェア・ランサムウェアなど

#### ワーム（Worm）

- 意味：自分を複製し、ネットワークを通じて広がるマルウェア
- ポイント：ウイルスと違い、宿主のファイルを必要としない

#### トロイの木馬（Trojan Horse）

- 意味：役に立つソフトを装って入り込み、裏で悪い動きをするマルウェア

#### ランサムウェア（Ransomware）

- 意味：データを暗号化するなどして使えなくし、元に戻すための身代金を要求するマルウェア
- ポイント：オフラインのバックアップが有効な対策

#### ボット（Bot）

- 意味：外部のC&Cサーバからの指令で遠隔操作されるマルウェア
- ポイント：感染した端末の集まりをボットネットという

#### ソーシャルエンジニアリング（Social Engineering）

- 意味：人の心理的な隙や油断を突いて、パスワードなどの情報を盗む手口
- 例：電話でなりすまして聞き出す、肩越しに盗み見る

#### フィッシング（Phishing）

- 意味：本物そっくりの偽サイトに誘導し、IDやパスワードを入力させて盗む手口

#### 標的型攻撃（ひょうてきがたこうげき / Targeted Attack）

- 意味：特定の組織を狙い、業務を装ったメールなどでマルウェアに感染させる攻撃

#### 水飲み場型攻撃（Watering Hole Attack）

- 意味：標的がよく見るWebサイトを改ざんし、訪れた人を感染させる攻撃

#### ゼロデイ攻撃（Zero-day Attack）

- 意味：脆弱性が見つかってから修正プログラムが出るまでの間に、その脆弱性を突く攻撃

#### ブルートフォース攻撃（総当たり攻撃 / Brute Force Attack）

- 意味：パスワードとして考えられるすべての組合せを試す攻撃
- ポイント：辞書攻撃はよく使われる単語を順に試す

#### パスワードリスト攻撃（Password List Attack）

- 意味：ほかのサービスから漏れたIDとパスワードの組を使ってログインを試す攻撃
- ポイント：パスワードの使い回しが原因になる

#### リバースブルートフォース攻撃（Reverse Brute Force Attack）

- 意味：パスワードを1つに固定し、IDを次々に変えて試す攻撃
- ポイント：一定回数の失敗でロックする対策が効きにくい

#### SQLインジェクション（SQL Injection）

- 意味：入力欄に不正なSQLの一部を入れて、データベースを不正に操作する攻撃
- ポイント：対策はプレースホルダ（バインド機構）でSQL文と値を分けること

#### クロスサイトスクリプティング（XSS / Cross Site Scripting）

- 意味：Webページに悪意のあるスクリプトを埋め込み、閲覧者のブラウザで実行させる攻撃
- ポイント：対策は出力時のエスケープ処理

#### CSRF（しーさーふ / Cross Site Request Forgery）

- 意味：ログイン中の利用者に、意図しない操作の要求を送らせる攻撃
- ポイント：対策は正規の画面から送られたか確かめるトークン
- 語の意味：Cross Site＝サイトをまたいだ／Request＝要求／Forgery＝偽造

#### DoS攻撃・DDoS攻撃（ドスこうげき / Denial of Service）

- 意味：大量の通信を送りつけて、サービスを使えなくする攻撃。多数の端末から行うのがDDoS
- 語の意味：Denial of Service＝サービスの妨害／Distributed＝分散した（DDoS）

#### DNSキャッシュポイズニング（DNS Cache Poisoning）

- 意味：DNSサーバに偽の情報を覚えさせ、正しいドメイン名でも偽サイトへ誘導する攻撃

#### 中間者攻撃（MITM / Man-in-the-Middle Attack）

- 意味：通信の間に入り込んで、盗聴や改ざんをする攻撃

#### 敵対的サンプル（Adversarial Example）

- 意味：画像などに人には分からない小さな変化を加え、AIに誤認識させる攻撃

#### モデル反転攻撃（Model Inversion Attack）

- 意味：AIの出力をもとに、学習に使ったデータ（個人情報など）を推測する攻撃

#### 適応的選択平文攻撃（Adaptive Chosen-plaintext Attack）

- 意味：攻撃者が選んだ平文と暗号文の組を、結果を見ながら次々に入手して鍵を推測する暗号解読の手法


## 11-2 情報セキュリティ管理


### 組織での管理

#### ISMS（あいえすえむえす / Information Security Management System）

- 意味：情報セキュリティを組織として管理し、PDCAで継続的に改善する仕組み
- ポイント：規格は JIS Q 27001（ISO/IEC 27001）
- 語の意味：Information Security＝情報セキュリティ／Management System＝管理の仕組み

#### 情報セキュリティポリシー（Information Security Policy）

- 意味：組織の情報セキュリティの方針や決まりをまとめたもの
- ポイント：基本方針・対策基準・実施手順の3階層

#### リスクアセスメント（Risk Assessment）

- 意味：リスクを特定し、分析し、評価すること

#### リスク対応（Risk Treatment）

- 意味：評価したリスクにどう対処するかを決めること
- ポイント：回避（やめる）・低減（対策で小さくする）・移転（保険などで他者へ）・保有（受け入れる）

#### リスク移転（Risk Transfer）

- 意味：保険に入るなどして、損失の負担を第三者に移すこと

#### リスク保有（Risk Retention）

- 意味：リスクを受け入れ、損失が出たら自分で負担すること
- ポイント：小さなリスクに選ぶ

#### CSIRT（しーさーと / Computer Security Incident Response Team）

- 意味：セキュリティ事故（インシデント）が起きたときに、分析・対応・再発防止を担う組織
- 語の意味：Computer Security＝コンピュータセキュリティ／Incident＝事故／Response＝対応／Team＝チーム

#### SOC（そっく / Security Operation Center）

- 意味：ネットワークや機器を24時間監視し、攻撃を見つけて分析する組織
- 語の意味：Security＝セキュリティ／Operation＝運用／Center＝拠点

#### 個人情報保護（Personal Information Protection）

- 意味：個人情報を適切に扱うこと
- ポイント：プライバシーマーク制度は、適切に扱う事業者を認定する


## 11-3 セキュリティ技術評価


### 評価と検査

#### ペネトレーションテスト（Penetration Test）

- 意味：実際の攻撃と同じ手順でシステムに侵入を試み、弱点を確かめる検査

#### ファジング（Fuzzing）

- 意味：予想外のデータを大量に入力して、ソフトウェアの脆弱性を見つける検査

#### CVSS（しーぶいえすえす / Common Vulnerability Scoring System）

- 意味：脆弱性の深刻さを、0〜10の点数で表す共通の評価方法
- 語の意味：Common＝共通の／Vulnerability＝脆弱性／Scoring System＝点数の付け方


## 11-4 情報セキュリティ対策


### 人と物の対策

#### 多要素認証（たようそにんしょう / Multi-factor Authentication）

- 意味：知識（パスワード）・所持（スマートフォン）・生体（指紋）のうち、2種類以上を組み合わせる認証
- ポイント：同じ種類を2回使うのは二段階認証であっても多要素ではない

#### ワンタイムパスワード（One-time Password）

- 意味：1回使うと無効になるパスワード
- ポイント：盗まれても再利用されにくい

#### 生体認証（せいたいにんしょう / Biometrics）

- 意味：指紋・顔・静脈など、体の特徴で本人を確認する方法
- ポイント：本人を拒否する率と、他人を受け入れる率のバランスが大切

#### シングルサインオン（SSO / Single Sign-On）

- 意味：一度の認証で、複数のシステムを使えるようにする仕組み

#### セキュアブート（Secure Boot）

- 意味：起動時に電子署名を確かめ、信頼できるOSだけを起動させる仕組み

#### BIOSパスワード・HDDパスワード（BIOS / HDD Password）

- 意味：BIOSパスワードはPCの起動や設定の変更を制限し、HDDパスワードは記憶装置そのものの読み出しを制限する


### 技術的な対策

#### ファイアウォール（Firewall）

- 意味：決めたルールに従って、通信を通すか止めるかを判断する仕組み
- ポイント：パケットフィルタリングはIPアドレスやポート番号で判断する

#### DMZ（でぃーえむぜっと / DeMilitarized Zone）

- 意味：社内ネットワークとインターネットの間に置く、外部に公開するサーバ用の区域
- ポイント：Webサーバやメールサーバを置く
- 語の意味：DeMilitarized＝非武装の／Zone＝地帯

#### WAF（わふ / Web Application Firewall）

- 意味：Webアプリケーションへの攻撃（SQLインジェクションやXSSなど）を見つけて防ぐ仕組み
- 語の意味：Web Application＝Webアプリ／Firewall＝防火壁

#### IDS（あいでぃーえす / Intrusion Detection System）

- 意味：不正な侵入を見つけて知らせる仕組み
- ポイント：止めるところまで行うのがIPS（Intrusion Prevention System）
- 語の意味：Intrusion＝侵入／Detection＝検知／System＝仕組み

#### マルウェア対策ソフト（Anti-malware Software）

- 意味：マルウェアを見つけて取り除くソフト
- ポイント：パターンマッチング法は定義ファイルと照合、ヒューリスティック法は怪しい振る舞いから検出、コンペア法は正常な状態と比べる

#### サンドボックス（Sandbox）

- 意味：隔離した環境で怪しいプログラムを動かし、振る舞いを観察する仕組み

#### WORM（わーむ / Write Once Read Many）

- 意味：一度だけ書き込め、何度でも読める記録媒体や機能
- ポイント：ログなどの改ざん防止に使う
- 語の意味：Write Once＝一度だけ書く／Read Many＝何度も読む

#### バックアップ（Backup）

- 意味：データの複製を別の場所に保存しておくこと
- ポイント：ランサムウェア対策ではネットワークから切り離した保管が有効


## 11-5 セキュリティ実装技術


### 暗号と認証の技術

#### 共通鍵暗号方式（きょうつうかぎあんごうほうしき / Symmetric-key Cryptography）

- 意味：暗号化と復号に同じ鍵を使う方式
- ポイント：速いが、鍵を安全に渡す方法が課題。代表はAES

#### 公開鍵暗号方式（こうかいかぎあんごうほうしき / Public-key Cryptography）

- 意味：公開鍵と秘密鍵のペアを使う方式
- ポイント：受信者の公開鍵で暗号化し、受信者の秘密鍵で復号する。代表はRSA

#### AES（えーいーえす / Advanced Encryption Standard）

- 意味：米国の標準になっている共通鍵暗号
- 語の意味：Advanced＝高度な／Encryption＝暗号化／Standard＝標準

#### RSA（あーるえすえー / Rivest-Shamir-Adleman）

- 意味：大きな数の素因数分解が難しいことを安全性の根拠にする公開鍵暗号
- 語の意味：考案した3人（Rivest・Shamir・Adleman）の頭文字

#### 楕円曲線暗号（だえんきょくせんあんごう / Elliptic Curve Cryptography）

- 意味：楕円曲線の性質を使う公開鍵暗号
- ポイント：RSAより短い鍵で同じくらいの強さを出せる

#### ハッシュ関数（Hash Function）

- 意味：データから決まった長さの値（ハッシュ値）を作る関数
- ポイント：元に戻せず、少しでも違うと値が変わるので改ざんの検出に使う。例: SHA-256

#### ディジタル署名（Digital Signature）

- 意味：送信者が自分の秘密鍵で署名し、受信者が送信者の公開鍵で検証する仕組み
- ポイント：本人であることと、改ざんされていないことを確かめられる

#### PKI（ぴーけーあい / Public Key Infrastructure）

- 意味：認証局（CA）が発行するディジタル証明書で、公開鍵が本人のものだと保証する仕組み
- 語の意味：Public Key＝公開鍵／Infrastructure＝基盤

#### TLS（てぃーえるえす / Transport Layer Security）

- 意味：Webなどの通信を暗号化し、相手を認証するプロトコル
- ポイント：前身はSSL。HTTPSで使う
- 語の意味：Transport Layer＝トランスポート層の／Security＝安全

#### IPsec（あいぴーせっく / IP Security）

- 意味：ネットワーク層でIP通信を暗号化・認証するプロトコル群
- ポイント：VPNで使われる

#### VPN（ぶいぴーえぬ / Virtual Private Network）

- 意味：共用の回線の上に、暗号化で仮想的な専用線を作る技術
- 語の意味：Virtual＝仮想の／Private＝専用の／Network＝網

#### WPA（だぶりゅーぴーえー / Wi-Fi Protected Access）

- 意味：無線LANの暗号化と認証の規格
- ポイント：今はWPA3が新しい
- 語の意味：Wi-Fi＝無線LAN／Protected＝守られた／Access＝接続

#### DMARC（でぃーまーく / Domain-based Message Authentication, Reporting and Conformance）

- 意味：SPFやDKIMの送信元認証の結果をもとに、なりすましメールをどう扱うかを送信側が示す仕組み
- 語の意味：Domain-based＝ドメインに基づく／Message Authentication＝メールの認証／Reporting＝報告／Conformance＝適合

#### SPF・DKIM（えすぴーえふ・でぃーきむ）

- 意味：送信元のメールサーバが正しいかを確かめる仕組み。SPFは送信元IPアドレス、DKIMは電子署名で確かめる

#### プロキシサーバ（Proxy Server）

- 意味：社内の端末に代わって外部のサーバに接続する中継サーバ
- ポイント：アクセスの記録や制限に使う

### 11-1 情報セキュリティ

#### 問 913no2-security-3

- 問：標的がよく訪れるWebサイトを改ざんして感染を狙う攻撃はどれか。
- ア：ゼロデイ攻撃
- イ：水飲み場型攻撃
- ウ：モデル反転攻撃
- エ：総当たり攻撃
- 正解：イ
- 解説：水飲み場型攻撃は、標的が水飲み場へ集まるように、利用サイトで待ち伏せします。

#### 問 913no2-ai-0

- 問：画像をわずかに改変し、AIに誤認識させる攻撃はどれか。
- ア：モデル反転攻撃
- イ：敵対的サンプル攻撃
- ウ：水飲み場型攻撃
- エ：ゼロデイ攻撃
- 正解：イ
- 解説：敵対的サンプル攻撃は、AIを誤判定させるよう入力を加工します。

#### 問 913no2-ai-1

- 問：AIの出力を手掛かりに、学習データの個人情報等を推測する攻撃はどれか。
- ア：モデル反転攻撃
- イ：敵対的サンプル攻撃
- ウ：フィッシング
- エ：DoS攻撃
- 正解：ア
- 解説：モデル反転攻撃は、モデルから学習データの特徴を推測することを狙います。

#### 問 916no1-security-1

- 問：漏えいした他サービスのID・パスワードの組を使う攻撃は？
- ア：辞書攻撃
- イ：パスワードリスト攻撃
- ウ：SQLインジェクション
- エ：標的型攻撃
- 正解：イ
- 解説：パスワードの使い回しを狙うのがパスワードリスト攻撃。

#### 問 925no1-security-4

- 問：トロイの木馬の説明として適切なものはどれか。
- ア：有用なソフトを装い、裏で悪意ある動作をする
- イ：自分自身を複製して拡散することが必須である
- ウ：DRAMの内容を保持する回路である
- エ：暗号文を復号する公開鍵である
- 正解：ア
- 解説：トロイの木馬は正規・有用なソフトに見せかける手口が特徴です。

#### 問 927no6-0

- 問：SQLインジェクションへの対策として最も適切なものはどれか。
- ア：入力値をSQL文に文字列連結する
- イ：プレースホルダを利用してSQL文と値を分離する
- ウ：パスワードを定期的に変更するだけにする
- エ：DNSキャッシュを削除する
- 正解：イ
- 解説：プレースホルダ（バインド変数）により、入力値をSQLの命令として解釈させにくくする。

#### 問 927no6-1

- 問：DDoS攻撃の説明として適切なものはどれか。
- ア：1台の端末が秘密鍵を盗む攻撃
- イ：多数の端末から大量通信を送りサービスを妨害する攻撃
- ウ：DNS名を暗号化する技術
