## 7-1 ヒューマンインタフェース技術


### 操作の仕組み

#### ヒューマンインタフェース（Human Interface）

- 意味：人とコンピュータが情報をやり取りする接点
- ポイント：画面・キーボード・音声など

#### GUI（じーゆーあい / Graphical User Interface）

- 意味：アイコンやボタンなどの図を、マウスやタッチで操作する方式
- ポイント：文字でコマンドを打つのはCUI
- 語の意味：Graphical＝図を使った／User＝利用者／Interface＝接点

#### CUI（しーゆーあい / Character User Interface）

- 意味：キーボードから文字でコマンドを入力して操作する方式
- 語の意味：Character＝文字の／User＝利用者／Interface＝接点

#### マルチタッチ（Multi-touch）

- 意味：画面の複数の点に同時に触れて操作できる仕組み
- 例：2本指で広げて拡大（ピンチアウト）

#### 音声認識（おんせいにんしき / Speech Recognition）

- 意味：人の話す声を、コンピュータが文字や命令として理解する技術


### 画面の部品

#### ラジオボタン（Radio Button）

- 意味：いくつかの選択肢から1つだけを選ぶ部品
- ポイント：複数を選べるのはチェックボックス

#### チェックボックス（Check Box）

- 意味：選択肢から複数を選べる部品

#### プルダウンメニュー（Pull-down Menu）

- 意味：押すと選択肢の一覧が下に開くメニュー
- ポイント：画面の広さを節約できる

#### ツールチップ（Tooltip）

- 意味：部品にマウスを重ねると出る、短い説明


## 7-2 インタフェース設計

### まとめ表

**画面設計の原則**

| 観点 | やること |
| :-: | :-: |
| 一貫性 | 同じ操作は同じ場所・同じ見た目にそろえる |
| 視認性 | 大事な情報を目立たせ、見やすくする |
| エラー防止 | 誤った入力をしにくくし、間違えたら直し方を示す |
| 利用者に合わせる | 初心者にも慣れた人にも使いやすくする（ショートカットなど） |


### 使いやすさの考え方

#### ユーザビリティ（Usability）

- 意味：特定の利用者が、目的を効果的・効率的・満足して達成できる度合い
- ポイント：JIS Z 8521（ISO 9241-11）で定義されている

#### アクセシビリティ（Accessibility）

- 意味：高齢者や障害のある人を含め、だれもが情報やサービスを使えること
- 例：画像に代わりの文章を付ける、色だけで区別しない

#### ユニバーサルデザイン（Universal Design）

- 意味：年齢や能力にかかわらず、はじめからできるだけ多くの人が使えるように設計する考え方

#### UX（ゆーえっくす / User Experience）

- 意味：製品やサービスを使うことで利用者が得る体験全体
- ポイント：使いやすさだけでなく、楽しさや満足も含む
- 語の意味：User＝利用者／Experience＝体験

#### 人間中心設計（にんげんちゅうしんせっけい / Human-centred Design）

- 意味：利用者の立場を中心に、評価と改善を繰り返しながら設計する考え方
- ポイント：JIS Z 8530（ISO 9241-210）

#### ヒューリスティック評価（Heuristic Evaluation）

- 意味：専門家が経験則（ガイドライン）に照らして、使いにくい点を見つける評価方法

#### 画面設計（がめんせっけい / Screen Design）

- 意味：入力画面や表示画面の項目・配置を決めること
- ポイント：入力の順番を、もとの伝票などの並びに合わせると入力しやすい

#### 帳票設計（ちょうひょうせっけい / Form Design）

- 意味：印刷する書類の項目や配置を決めること

#### コード設計（こーどせっけい / Code Design）

- 意味：商品番号などのコード（識別番号）の付け方を決めること
- 例：区分ごとに桁を割り当てる、入力ミスを見つけるチェックディジットを付ける

#### チェックディジット（Check Digit）

- 意味：コードの数字から計算して末尾に付ける検査用の数字
- ポイント：入力ミスを見つけられる

#### Webデザイン（Web Design）

- 意味：Webページの見た目や構成を設計すること
- ポイント：レスポンシブデザインは、画面の大きさに合わせて表示を変える

### 7-1 ヒューマンインタフェース技術

#### 問 fe-7-q01

- 問：複数の選択肢から1つだけを選ばせるときに適した画面部品はどれか。
- ア：チェックボックス
- イ：ラジオボタン
- ウ：テキストボックス
- エ：スクロールバー
- 正解：イ
- 解説：ラジオボタンは1つだけ選ぶ。複数選べるのはチェックボックス。

#### 問 fe-7-q02

- 問：GUIの説明として適切なものはどれか。
- ア：文字でコマンドを入力して操作する
- イ：アイコンやボタンなどを、マウスやタッチで操作する
- ウ：音声だけで操作する
- エ：プログラムを機械語に翻訳する
- 正解：イ
- 解説：GUIは図を使った操作方式。文字で操作するのはCUI。

### 7-2 インタフェース設計

#### 問 fe-7-q03

- 問：年齢や障害の有無などにかかわらず、だれもが利用しやすいように最初から設計する考え方はどれか。
- ア：ユニバーサルデザイン
- イ：ユーザビリティテスト
- ウ：プロトタイピング
- エ：フールプルーフ
- 正解：ア
- 解説：はじめから多くの人が使えるように作るのがユニバーサルデザイン。

#### 問 fe-7-q04

- 問：コードの入力誤りを検出するために、コードの数字から計算して付加する数字はどれか。
- ア：パリティビット
- イ：チェックディジット
- ウ：ハッシュ値
- エ：シーケンス番号
- 正解：イ
- 解説：チェックディジットはコードの末尾に付ける検査用の数字。

#### 問 fe-7-q05

- 問：専門家が経験則に基づいて、画面などの使いにくい点を洗い出す評価方法はどれか。
- ア：ヒューリスティック評価
- イ：回帰テスト
- ウ：ベンチマーク
- エ：ABCテスト
- 正解：ア
- 解説：ヒューリスティック評価はガイドラインに照らして専門家が評価する。

#### 問 fe-7-q06

- 問：画面の大きさに応じて、Webページのレイアウトを自動で変える手法はどれか。
- ア：レスポンシブデザイン
- イ：シングルサインオン
- ウ：CGI
- エ：Cookie
- 正解：ア
- 解説：レスポンシブデザインはスマートフォンやPCなど画面幅に合わせて表示を変える。
