## 10-1 ネットワーク方式

### まとめ表

**有線と無線のアクセス制御**

| 方式 | 使う場所 | 考え方 |
| :-: | :-: | :-: |
| CSMA/CD | 有線LAN（共有型） | 送ってから衝突を検出し、再送する |
| CSMA/CA | 無線LAN | 衝突を避けるため、空いていても待ってから送る |

### ネットワークの種類

#### LAN（らん / Local Area Network）

- 意味：建物や敷地内など、限られた範囲のコンピュータをつなぐネットワーク
- 語の意味：Local＝局所的な・その場の／Area＝範囲／Network＝網
- ポイント：自前で敷設・管理する。WANは通信事業者の回線を使って離れた拠点をつなぐ

#### WAN（わん / Wide Area Network）

- 意味：通信事業者の回線を使い、離れた拠点どうしをつなぐ広域ネットワーク
- 語の意味：Wide＝広い／Area＝範囲／Network＝網
- ポイント：本社と支店をつなぐなど。LANとの違いは範囲と回線の持ち主

#### インターネット（Internet）

- 意味：世界中のネットワークをTCP/IPで相互につないだネットワーク
- ポイント：イントラネットは同じ技術を組織の中だけで使うもの

#### イントラネット（Intranet）

- 意味：インターネットの技術（TCP/IP・Web）を使って作った、組織内だけのネットワーク
- ポイント：社内ポータルや社内Webシステムが例。エクストラネットは取引先など組織外の特定相手まで広げたもの

#### 回線交換方式（かいせんこうかんほうしき / Circuit Switching）

- 意味：通信の間、送信者と受信者の間に専用の通信路を確保し続ける方式
- ポイント：品質は安定するが、使っていない時間も回線を占有する。従来の固定電話が例

#### パケット交換方式（ぱけっとこうかんほうしき / Packet Switching）

- 意味：データをパケットという小さな単位に分けて送り、回線を複数の通信で共有する方式
- ポイント：回線を効率よく使える。インターネットはこの方式

#### FTTH（えふてぃーてぃーえいち / Fiber To The Home）

- 意味：光ファイバを家庭まで引き込む高速なインターネット接続サービス
- 語の意味：Fiber＝光ファイバ／To The Home＝家庭まで
- ポイント：いわゆる「光回線」

### 無線通信

#### 無線LAN（むせんらん / Wireless LAN）

- 意味：電波を使ってLANに接続する仕組み。規格はIEEE 802.11シリーズ
- ポイント：Wi-Fiは、無線LAN機器の相互接続を認定するブランド名

#### アクセスポイント（Access Point）

- 意味：無線LANの端末を、有線のネットワークにつなぐ中継装置
- ポイント：端末はアクセスポイントのSSIDを選んで接続する

#### SSID（えすえすあいでぃー / Service Set Identifier）

- 意味：無線LANのネットワークを区別するための名前。ESSIDとも呼ぶ
- 語の意味：Service＝サービス／Set＝まとまり／Identifier＝識別子
- ポイント：SSIDを隠すステルス機能だけでは、十分なセキュリティ対策にならない

#### CSMA/CA（しーえすえむえー・しーえー / Carrier Sense Multiple Access with Collision Avoidance）

- 意味：無線LANで使うアクセス制御。通信路が空いていても、ランダムな時間待ってから送信し衝突を避ける
- 語の意味：Carrier Sense＝通信路（搬送波）を感知／Multiple Access＝複数が共有して使う／Collision Avoidance＝衝突の回避
- ポイント：有線のCSMA/CDは衝突を「検出」、無線のCSMA/CAは衝突を「回避」

#### Bluetooth（ぶるーとぅーす）

- 意味：数m〜数十m程度の近い距離で、機器どうしを無線でつなぐ規格
- ポイント：BLE（Bluetooth Low Energy）は消費電力を抑えた規格で、IoT機器に使われる

#### LPWA（えるぴーだぶりゅーえー / Low Power Wide Area）

- 意味：消費電力が小さく、広い範囲（数km〜）で通信できる無線通信技術の総称
- 語の意味：Low Power＝低消費電力／Wide Area＝広い範囲
- ポイント：通信速度は遅いが、電池で長く動くIoTセンサ向き

#### 5G（ふぁいぶじー / 5th Generation）

- 意味：第5世代の移動通信システム
- 語の意味：5th＝5番目の／Generation＝世代
- ポイント：「超高速・大容量」「超低遅延」「多数同時接続」が3つの特徴

#### テザリング（Tethering）

- 意味：スマートフォンなどのモバイル回線を経由して、PCなどをインターネットに接続すること

#### ハンドオーバ（Handover）

- 意味：移動中の端末が、通信を続けたまま接続先の基地局やアクセスポイントを切り替えること
- ポイント：ローミングは、契約している事業者のサービスエリア外で他の事業者の設備を使うこと

#### MVNO（えむぶいえぬおー / Mobile Virtual Network Operator）

- 意味：自分では無線設備を持たず、他の通信事業者の設備を借りて移動通信サービスを提供する事業者
- 語の意味：Mobile＝移動体（携帯）／Virtual＝仮想の／Network Operator＝通信事業者
- ポイント：いわゆる「格安SIM」の事業者

#### PoE（ぴーおーいー / Power over Ethernet）

- 意味：LANケーブルを使って、データと一緒に電力も供給する技術
- 語の意味：Power＝電力／over＝〜に乗せて／Ethernet＝イーサネット（LANケーブル）
- ポイント：電源のない天井などに、アクセスポイントやネットワークカメラを置ける

## 10-2 データ通信と制御

### まとめ表

| 第6層 | プレゼンテーション層 | 文字コード・暗号化・圧縮 | アプリケーション層 | |

| 第4層 | トランスポート層 | 端末間の信頼性ある配送 | トランスポート層 | TCP・UDP |
| 第3層 | ネットワーク層 | ネットワーク間の宛先配送 | インターネット層 | IP・ICMP・ARP |
| 第2層 | データリンク層 | 同じネットワーク内の通信 | ネットワークインタフェース層 | イーサネット |

**LAN間接続装置**

| 機器 | 層 | 判断材料 |
| :-: | :-: | :-: |
| リピータ／リピータハブ | 第1層 物理層 | 見ない（信号を増幅して全ポートへ） |
| ブリッジ／レイヤ2スイッチ | 第2層 データリンク層 | MACアドレス |
| ルータ／レイヤ3スイッチ | 第3層 ネットワーク層 | IPアドレス |
| ゲートウェイ | 第4〜7層 | プロトコルの変換 |

### 通信の階層モデル

#### OSI基本参照モデル（おーえすあいきほんさんしょうもでる / OSI Reference Model）

- 意味：通信の機能を7つの層に分けて整理した、ISOの標準モデル
- ポイント：上から「アプセトネデブ」（アプリケーション・プレゼンテーション・セッション・トランスポート・ネットワーク・データリンク・物理）

#### TCP/IPモデル（てぃーしーぴーあいぴーもでる / TCP/IP Model）

- 意味：インターネットで使う4層のモデル。アプリケーション層・トランスポート層・インターネット層・ネットワークインタフェース層
- ポイント：アプリケーション層はOSIの第5〜7層、ネットワークインタフェース層は第1〜2層にあたる

#### プレゼンテーション層（ぷれぜんてーしょんそう / Presentation Layer）

- 意味：OSIの第6層。データの表現形式をそろえる層
- ポイント：文字コードの変換、暗号化、圧縮がこの層

#### データリンク層（でーたりんくそう / Data Link Layer）

- 意味：OSIの第2層。同じネットワーク内で、隣の機器へ確実にデータ（フレーム）を届ける層
- ポイント：MACアドレスを使う。レイヤ2スイッチ（スイッチングハブ）はこの層の機器

### LAN間接続装置

#### NIC（にっく / Network Interface Card）

- 意味：コンピュータをLANにつなぐための部品
- 語の意味：Network＝網／Interface＝接続部分／Card＝基板
- ポイント：NICごとにMACアドレスが割り当てられている

#### MACアドレス（まっくあどれす / MAC Address）

- 意味：NICなどに割り当てられた48ビットの固有の番号。物理アドレスとも呼ぶ
- ポイント：先頭24ビットはメーカーを表すOUI。IPアドレスは論理アドレスで、MACアドレスは物理アドレス

#### OUI（おーゆーあい / Organizationally Unique Identifier）

- 意味：MACアドレスの先頭24ビット。NICのメーカー（ベンダ）を識別する番号
- 語の意味：Organizationally＝組織ごとに／Unique＝一意な／Identifier＝識別子

#### リピータ（Repeater）

- 意味：弱くなった電気信号を増幅・整形して中継する、物理層の装置
- ポイント：リピータハブは受け取った信号をすべてのポートへそのまま流す。宛先は判断しない

#### ブリッジ（Bridge）

- 意味：MACアドレスを見て、フレームを必要な側にだけ中継するデータリンク層の装置

#### レイヤ2スイッチ（れいやつーすいっち / Layer 2 Switch）

- 意味：MACアドレスを見て、宛先の機器がつながるポートにだけフレームを送る装置。スイッチングハブとも呼ぶ
- ポイント：判断材料はMACアドレス。IPアドレスは見ない

#### ルータ（Router）

- 意味：IPアドレスを見て、異なるネットワークの間でパケットを中継するネットワーク層の装置
- ポイント：宛先までの経路を選ぶことをルーティングという

#### レイヤ3スイッチ（れいやすりーすいっち / Layer 3 Switch）

- 意味：ルータと同じくIPアドレスで転送先を決める機能を持ったスイッチ
- ポイント：ハードウェアで処理するので高速。社内LANの中心でよく使う

#### ゲートウェイ（Gateway）

- 意味：プロトコルが異なるネットワークどうしを、変換してつなぐ装置やソフトウェア
- ポイント：トランスポート層より上の層で動く

#### デフォルトゲートウェイ（Default Gateway）

- 意味：自分のネットワークの外へ通信するとき、最初にパケットを渡す出口のルータ
- ポイント：DHCPでIPアドレスと一緒に配られる設定の1つ

#### VLAN（ぶいらん / Virtual LAN）

- 意味：スイッチの設定で、物理的な配線とは関係なくLANを論理的なグループに分ける技術
- 語の意味：Virtual＝仮想の／LAN＝構内ネットワーク
- ポイント：部署ごとにネットワークを分けるときなどに使う

### アクセス制御と伝送

#### CSMA/CD（しーえすえむえー・しーでぃー / Carrier Sense Multiple Access with Collision Detection）

- 意味：共有型の有線LANで、通信路が空いているか確かめてから送信し、衝突を検出したら時間をおいて再送する方式
- 語の意味：Carrier Sense＝通信路（搬送波）を感知／Multiple Access＝複数が共有して使う／Collision Detection＝衝突の検出
- ポイント：端末が増えると衝突が増えて効率が下がる。スイッチによる全二重通信では衝突が起きないため、ふつう使われない

#### 全二重通信（ぜんにじゅうつうしん / Full Duplex）

- 意味：送信と受信を同時に行える通信
- ポイント：半二重通信は、送信と受信を切り替えながら片方ずつ行う

#### bps（びーぴーえす / bits per second）

- 意味：1秒間に送れるビット数。通信速度の単位
- 語の意味：bits＝ビット／per second＝1秒あたり
- ポイント：データ量はバイトで出されることが多い。1バイト＝8ビットにそろえてから計算する

#### 回線利用率（かいせんりようりつ / Line Utilization）

- 意味：回線の最大速度のうち、実際にデータの伝送に使える割合
- ポイント：伝送時間＝データ量÷（回線速度×回線利用率）

#### 伝送時間（でんそうじかん / Transmission Time）

- 意味：データを送り終えるまでにかかる時間
- 例：100Mbpsの回線を利用率50%で使い、500Mバイトを送ると、4,000Mビット÷50Mbps＝80秒

### 誤り検出

#### パリティチェック（Parity Check）

- 意味：ビット列中の1の個数が偶数（または奇数）になるようにパリティビットを付け、誤りを検出する方法
- ポイント：垂直パリティ・水平パリティ・水平垂直パリティがある。2ビット同時の誤りは見逃すことがある

#### CRC（しーあーるしー / Cyclic Redundancy Check）

- 意味：データを生成多項式で割った余りを検査用データとして付け、受信側で同じ計算をして誤りを検出する方式
- ポイント：連続した誤り（バースト誤り）に強く、通信で広く使われる

### TCP/IPの基本

#### TCP/IP（てぃーしーぴーあいぴー）

- 意味：インターネットで標準的に使われるプロトコル群の総称

#### IP（あいぴー / Internet Protocol）

- 意味：IPアドレスをもとに、ネットワーク間でパケットを宛先へ届けるインターネット層のプロトコル
- 語の意味：Internet＝インターネット／Protocol＝通信の約束ごと
- ポイント：届いたかどうかの確認はしない。確実さはTCPが補う

#### TCP（てぃーしーぴー / Transmission Control Protocol）

- 意味：相手との接続を確立し、確認応答・再送・順序制御で信頼性を確保するトランスポート層のプロトコル
- 語の意味：Transmission＝伝送／Control＝制御／Protocol＝約束ごと
- ポイント：Web・メール・ファイル転送など、データの欠落が困る通信で使う

#### UDP（ゆーでぃーぴー / User Datagram Protocol）

- 意味：接続を確立せず、軽量にデータを送るトランスポート層のプロトコル
- 語の意味：User＝利用者の／Datagram＝データの小包／Protocol＝約束ごと
- ポイント：信頼性よりリアルタイム性を優先する音声・動画などで使う。「速いから優れている」わけではない

#### ポート番号（ぽーとばんごう / Port Number）

- 意味：1台のコンピュータの中で、どのアプリケーション宛ての通信かを区別する番号
- ポイント：TCP・UDPのヘッダに入る。トランスポート層の話

#### ICMP（あいしーえむぴー / Internet Control Message Protocol）

- 意味：IP通信のエラーや状態を通知するためのプロトコル
- 語の意味：Internet＝インターネット／Control＝制御／Message＝通知／Protocol＝約束ごと
- ポイント：pingコマンドはICMPを使う

#### ARP（あーぷ / Address Resolution Protocol）

- 意味：IPアドレスから、同じネットワーク内にある機器のMACアドレスを調べるプロトコル
- 語の意味：Address＝アドレス／Resolution＝解決（調べること）／Protocol＝約束ごと
- ポイント：DNSは名前→IPアドレス、ARPはIPアドレス→MACアドレス

### IPアドレス

#### IPアドレス（あいぴーあどれす / IP Address）

- 意味：ネットワーク上の機器を識別する番号。IPv4は32ビット
- ポイント：ネットワーク部とホスト部に分かれる。MACアドレスと違い、論理アドレス

#### IPv6（あいぴーぶいしっくす / Internet Protocol version 6）

- 意味：アドレスを128ビットに広げた新しいIP。16ビットずつ8つに区切り、16進数で表す
- 語の意味：Internet Protocol＝IP／version 6＝第6版
- ポイント：IPv4のアドレス不足を解消するために作られた

#### グローバルIPアドレス（Global IP Address）

- 意味：インターネット上で重複しないように割り当てられるIPアドレス

#### プライベートIPアドレス（Private IP Address）

- 意味：LANの中だけで自由に使えるIPアドレス
- ポイント：別の組織のLANで同じ値が使われていてもよい。例：192.168.0.0〜192.168.255.255

#### IPアドレスのクラス（あいぴーあどれすのくらす / IP Address Class）

- 意味：IPv4アドレスのネットワーク部の長さで分けた従来の分類
- ポイント：クラスA＝ネットワーク部8ビット、B＝16ビット、C＝24ビット。今はCIDRが主流だが試験の基礎として覚える

#### サブネットマスク（Subnet Mask）

- 意味：IPアドレスのうち、どこまでがネットワーク部かを示す値。1が並ぶ部分がネットワーク部
- 例：255.255.255.0 は先頭24ビットがネットワーク部（/24）

#### CIDR（さいだー / Classless Inter-Domain Routing）

- 意味：クラスにとらわれず、ネットワーク部の長さを自由に決める方式。「/24」のように書く
- 語の意味：Classless＝クラスを使わない／Inter-Domain＝ドメイン間の／Routing＝経路制御
- ポイント：接続できるホスト数は、ホスト部がnビットなら 2のn乗−2 台

#### ブロードキャストアドレス（Broadcast Address）

- 意味：ホスト部のビットがすべて1のアドレス。同じネットワーク内の全機器に一斉に送るときに使う
- ポイント：ホスト部がすべて0はネットワークアドレス。どちらも機器には割り当てられないので、ホスト数は「−2」する

#### NAT（なっと / Network Address Translation）

- 意味：プライベートIPアドレスとグローバルIPアドレスを変換する仕組み
- 語の意味：Network＝網／Address＝アドレス／Translation＝変換

#### NAPT（なぷと / Network Address Port Translation）

- 意味：IPアドレスに加えてポート番号も変換し、1つのグローバルIPアドレスを複数の端末で共有する仕組み。IPマスカレードとも呼ぶ
- 語の意味：Network Address＝ネットワークのアドレス／Port＝ポート番号／Translation＝変換
- ポイント：NATはアドレスだけ、NAPTはポート番号も使う

### 設定と名前解決

#### DHCP（でぃーえいちしーぴー / Dynamic Host Configuration Protocol）

- 意味：IPアドレス・サブネットマスク・デフォルトゲートウェイ・DNSサーバなどの設定を、端末に自動で割り当てるプロトコル
- 語の意味：Dynamic＝動的な（その都度の）／Host＝端末／Configuration＝設定／Protocol＝約束ごと

#### DNS（でぃーえぬえす / Domain Name System）

- 意味：ドメイン名とIPアドレスの対応を管理し、名前からIPアドレスを調べる仕組み
- 語の意味：Domain＝ドメイン（名前の区画）／Name＝名前／System＝仕組み
- ポイント：名前からIPアドレスを調べることを名前解決という

### アプリケーション層のプロトコル

#### HTTP（えいちてぃーてぃーぴー / Hypertext Transfer Protocol）

- 意味：WebブラウザとWebサーバの間で、Webページを送受信するプロトコル
- 語の意味：Hypertext＝リンクでつながる文書／Transfer＝転送／Protocol＝約束ごと
- ポイント：ポート番号80

#### HTTPS（えいちてぃーてぃーぴーえす / HTTP Secure）

- 意味：HTTPの通信をTLSで暗号化したもの
- 語の意味：HTTP＝Webの通信／Secure＝安全な
- ポイント：ポート番号443。盗聴・改ざん・なりすましを防ぐ

#### FTP（えふてぃーぴー / File Transfer Protocol）

- 意味：ファイルを転送するためのプロトコル
- 語の意味：File＝ファイル／Transfer＝転送／Protocol＝約束ごと
- ポイント：データ用（20）と制御用（21）の2つのポートを使う

#### NTP（えぬてぃーぴー / Network Time Protocol）

- 意味：ネットワーク上のコンピュータの時刻を合わせるプロトコル
- 語の意味：Network＝網／Time＝時刻／Protocol＝約束ごと
- ポイント：ログの時刻をそろえるのに大切

#### SSH（えすえすえいち / Secure Shell）

- 意味：通信を暗号化して、離れたコンピュータを安全に操作するプロトコル
- 語の意味：Secure＝安全な／Shell＝コマンドを受け付ける窓口

### 電子メール

#### SMTP（えすえむてぃーぴー / Simple Mail Transfer Protocol）

- 意味：メールを送信し、メールサーバ間で転送するプロトコル
- 語の意味：Simple＝簡易な／Mail Transfer＝メール転送／Protocol＝約束ごと
- ポイント：ポート番号25。送る側はSMTP、受け取る側はPOP3かIMAP

#### POP3（ぽっぷすりー / Post Office Protocol version 3）

- 意味：メールサーバから、自分の端末へメールを取り込むプロトコル
- 語の意味：Post Office＝郵便局／Protocol＝約束ごと／version 3＝第3版
- ポイント：ポート番号110。ふつう端末に保存して読む

#### IMAP（あいまっぷ / Internet Message Access Protocol）

- 意味：メールをサーバに置いたまま、閲覧・管理するプロトコル
- 語の意味：Internet＝インターネット／Message＝メッセージ／Access＝読み出し／Protocol＝約束ごと
- ポイント：ポート番号143。複数の端末で既読などの状態をそろえやすい

#### MIME（まいむ / Multipurpose Internet Mail Extensions）

- 意味：電子メールで日本語・画像・音声・添付ファイルなどを扱えるようにする規格
- 語の意味：Multipurpose＝多目的な／Internet Mail＝電子メール／Extensions＝拡張

#### S/MIME（えすまいむ / Secure MIME）

- 意味：MIMEに暗号化と電子署名の機能を加え、メールの盗み見・改ざん・なりすましを防ぐ規格
- 語の意味：Secure＝安全な／MIME＝メールの拡張規格

## 10-4 ネットワーク管理

### ネットワークの監視と確認

#### SNMP（えすえぬえむぴー / Simple Network Management Protocol）

- 意味：ネットワーク機器の状態を、管理用のコンピュータから監視・設定するプロトコル
- 語の意味：Simple＝簡易な／Network Management＝ネットワーク管理／Protocol＝約束ごと
- ポイント：機器の情報はMIBという形で管理する。異常は機器からトラップで通知できる

#### ping（ぴん）

- 意味：相手の機器にICMPのパケットを送り、返事が来るかで通信できるかを確かめるコマンド

#### traceroute（とれーするーと）

- 意味：宛先までにどのルータを経由しているかを調べるコマンド。Windowsでは tracert
- ポイント：どこで通信が止まっているかの切り分けに使う

#### ipconfig（あいぴーこんふぃぐ）

- 意味：WindowsでIPアドレス・サブネットマスク・デフォルトゲートウェイなどの設定を確認するコマンド
- ポイント：arpコマンドはARPの対応表（キャッシュ）を表示・操作する

### ネットワークの仮想化

#### SDN（えすでぃーえぬ / Software-Defined Networking）

- 意味：ネットワークの設定や制御をソフトウェアで行う考え方。制御する機能と、パケットを転送する機能を分ける
- 語の意味：Software＝ソフトウェアで／Defined＝定義される／Networking＝ネットワーク
- ポイント：コントローラ（制御プレーン）が全体を見て経路を決め、スイッチ（データプレーン）は転送だけする

#### OpenFlow（おーぷんふろー）

- 意味：SDNで、コントローラがスイッチの転送動作を指示するためのプロトコル

#### NFV（えぬえふぶい / Network Functions Virtualization）

- 意味：ルータやファイアウォールなどのネットワーク機器の機能を、汎用サーバ上のソフトウェアで実現すること
- 語の意味：Network Functions＝ネットワーク機能／Virtualization＝仮想化

## 10-5 ネットワーク応用

### インターネットの仕組み

#### URL（ゆーあーるえる / Uniform Resource Locator）

- 意味：インターネット上の情報のありかを示す書き方
- 語の意味：Uniform＝統一された／Resource＝資源（情報）／Locator＝場所を示すもの
- 例：https://www.example.com/index.html（スキーム・ホスト名・パス）

#### Cookie（くっきー）

- 意味：Webサーバがブラウザに保存させる小さなデータ。ログイン状態などを覚えておくのに使う

#### CGI（しーじーあい / Common Gateway Interface）

- 意味：Webサーバがリクエストに応じてプログラムを動かし、その結果で動的なページを作る仕組み
- 語の意味：Common＝共通の／Gateway＝橋渡し／Interface＝接続の決まり

#### プロキシサーバ（Proxy Server）

- 意味：社内の端末に代わってインターネット上のサーバへアクセスする中継サーバ
- ポイント：アクセスの記録・制限や、よく見るページのキャッシュに使う

#### CDN（しーでぃーえぬ / Content Delivery Network）

- 意味：Webの内容を世界中のサーバに分散して置き、利用者に近いサーバから配信する仕組み
- 語の意味：Content＝コンテンツ／Delivery＝配信／Network＝網
- ポイント：アクセスの集中を分散し、表示を速くする

### 通信サービス

#### VPN（ぶいぴーえぬ / Virtual Private Network）

- 意味：インターネットなどの共用の回線の上に、暗号化などで仮想的な専用線を作る技術
- 語の意味：Virtual＝仮想の／Private＝専用の／Network＝網
- ポイント：インターネットVPNは安価、IP-VPNは通信事業者の閉じた網を使うので品質が安定

#### VoIP（ぼいっぷ / Voice over IP）

- 意味：音声をIPパケットにしてネットワークで送る技術。IP電話に使われる
- 語の意味：Voice＝音声／over IP＝IPネットワークに乗せて

### 10-4 ネットワーク管理
