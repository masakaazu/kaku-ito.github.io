## 2-1 データ構造

### まとめ表

**スタックとキュー**

| 構造 | 取り出す順 | 主な用途 |
| :-: | :-: | :-: |
| スタック | 後に入れたものから（LIFO） | 関数の戻り先、Undo、逆ポーランドの計算 |
| キュー | 先に入れたものから（FIFO） | 印刷待ち、処理の順番待ち |


### 基本のデータ構造

#### 配列（はいれつ / Array）

- 意味：同じ型のデータを連続した領域に並べ、番号（添字）で取り出す構造
- ポイント：添字で直接読めるが、途中への挿入・削除は後ろをずらす必要がある

#### リスト（連結リスト / Linked List）

- 意味：各データが次のデータの場所（ポインタ）を持ち、数珠つなぎにした構造
- ポイント：挿入・削除はポインタの付け替えだけで済む。双方向リストは前後両方のポインタを持つ

#### スタック（Stack）

- 意味：後に入れたデータを先に取り出す（LIFO）構造。入れるのがpush、出すのがpop
- ポイント：関数呼出しの戻り先の管理やUndoに使う
- 語の意味：LIFO＝Last In First Out（後入れ先出し）

#### キュー（待ち行列 / Queue）

- 意味：先に入れたデータを先に取り出す（FIFO）構造
- ポイント：入れるのがエンキュー、出すのがデキュー
- 語の意味：FIFO＝First In First Out（先入れ先出し）

#### 木構造（きこうぞう / Tree）

- 意味：根から枝分かれして節（ノード）をつなぐ階層構造
- ポイント：一番上が根、子を持たない節が葉

#### 二分木（にぶんぎ / Binary Tree）

- 意味：各節の子が2つ以下の木
- ポイント：完全二分木は、根から葉までの深さがそろった（最下段以外がすべて埋まった）二分木

#### 二分探索木（にぶんたんさくぎ / Binary Search Tree）

- 意味：「左の子 ＜ 親 ＜ 右の子」が常に成り立つ二分木
- ポイント：中間順になぞると小さい順に並ぶ

#### ヒープ（Heap）

- 意味：親が子より常に大きい（または小さい）完全二分木
- ポイント：最大値（最小値）がいつも根にある。ヒープソートで使う

#### ハッシュ表（はっしゅひょう / Hash Table）

- 意味：ハッシュ関数でキーから格納場所を計算して置く表
- ポイント：違うキーが同じ場所になることを衝突（シノニム）という
- 例：17 mod 5 ＝ 2 の位置に格納


## 2-2 アルゴリズム

### まとめ表

**探索と整列の計算量**

| 方法 | 計算量の目安 | ポイント |
| :-: | :-: | :-: |
| 線形探索 | O(n) | 先頭から順に調べる |
| 二分探索 | O(log n) | 整列済みが前提 |
| ハッシュ探索 | O(1) | 衝突がなければ1回で見つかる |
| バブル・選択・挿入ソート | O(n²) | 単純だが遅い |
| クイック・ヒープ・マージソート | O(n log n) | 速い整列法 |


### 探索

#### 線形探索法（せんけいたんさくほう / Linear Search）

- 意味：先頭から1つずつ順に比べて探す方法
- ポイント：データが整列していなくても使える。番兵を置くと終了判定を減らせる

#### 二分探索法（にぶんたんさくほう / Binary Search）

- 意味：整列済みのデータで、中央の値と比べて探す範囲を半分ずつに絞る方法
- ポイント：n個なら最大で約 log₂n 回の比較で済む

#### ハッシュ探索法（はっしゅたんさくほう / Hash Search）

- 意味：ハッシュ関数で格納場所を計算して、一度で取り出す方法
- ポイント：衝突がなければ探索回数はデータ量に関係なく一定


### 整列（ソート）

#### バブルソート（交換法 / Bubble Sort）

- 意味：隣り合う要素を比べて、順序が逆なら交換することを繰り返す整列法
- ポイント：計算量は O(n²)

#### 選択ソート（基本選択法 / Selection Sort）

- 意味：未整列の部分から最小値を選び、未整列部分の先頭と交換する整列法
- ポイント：計算量は O(n²)

#### 挿入ソート（基本挿入法 / Insertion Sort）

- 意味：整列済みの部分の正しい位置に、次の要素を差し込んでいく整列法
- ポイント：ほぼ整列済みのデータには速い

#### クイックソート（Quick Sort）

- 意味：基準値（ピボット）より小さいグループと大きいグループに分けることを繰り返す整列法
- ポイント：平均の計算量は O(n log n)。最悪は O(n²)

#### ヒープソート（Heap Sort）

- 意味：ヒープを作って最大値（最小値）を取り出すことを繰り返す整列法
- ポイント：計算量は O(n log n)

#### マージソート（Merge Sort）

- 意味：データを半分ずつに分けて、整列しながら併合（マージ）していく整列法
- ポイント：計算量は O(n log n)

#### シェルソート（Shell Sort）

- 意味：一定の間隔ごとの要素で挿入ソートをし、間隔を狭めていく整列法
- ポイント：挿入ソートの改良版


### アルゴリズムの評価

#### オーダ記法（おーだきほう / Big O Notation）

- 意味：データ量 n が増えたとき、処理量がどのくらい増えるかを表す書き方
- ポイント：増え方は O(1) ＜ O(log n) ＜ O(n) ＜ O(n log n) ＜ O(n²) の順に大きい

#### ダイクストラ法（Dijkstra's Algorithm）

- 意味：グラフの最短経路を求める代表的なアルゴリズム
- ポイント：出発点から近い点を順に確定していく

#### 流れ図（フローチャート / Flowchart）

- 意味：処理の流れを記号で表した図
- ポイント：端子・処理・判断・ループ端などの記号を使う


## 2-3 プログラミング


### プログラムの性質

#### 再帰（リカーシブ / Recursive）

- 意味：プログラムが自分自身を呼び出して処理を進める性質
- 例：階乗 n! ＝ n × (n−1)! 。呼び出しのたびにスタックを使う

#### 再入可能（リエントラント / Reentrant）

- 意味：実行中に別のタスクから呼び出されても、正しく動く性質
- ポイント：共有する変数を書き換えず、データをタスクごとに分ける

#### 再使用可能（リユーザブル / Reusable）

- 意味：一度実行した後、読み込み直さずにもう一度使える性質
- ポイント：実行のたびに初期化される

#### 再配置可能（リロケータブル / Relocatable）

- 意味：主記憶のどこに置いても実行できる性質

#### 構造化プログラミング（Structured Programming）

- 意味：順次・選択・繰返しの3つの基本構造だけで処理を組み立てる考え方
- ポイント：goto文をなるべく使わず、読みやすくする

#### 変数のスコープ（Scope）

- 意味：変数を使える範囲
- ポイント：関数の中だけで使えるのがローカル変数、どこからでも使えるのがグローバル変数

#### 引数（ひきすう / Argument）

- 意味：関数を呼び出すときに渡す値
- ポイント：値渡しは値のコピー、参照渡しは場所を渡すので呼び出し先で元の値が変わる


## 2-4 プログラム言語


### 言語の種類

#### 手続型言語（てつづきがたげんご / Procedural Language）

- 意味：処理の手順を順に書く言語
- 例：C、COBOL、Fortran

#### オブジェクト指向言語（Object-oriented Language）

- 意味：データと処理をまとめたオブジェクトを組み合わせてプログラムを作る言語
- 例：Java、C++、Python

#### スクリプト言語（Script Language）

- 意味：簡単に書けて、すぐに実行できるように作られた言語
- 例：JavaScript、Python。多くはインタプリタで動く


## 2-5 その他の言語


### マークアップ言語とデータ形式

#### HTML（えいちてぃーえむえる / HyperText Markup Language）

- 意味：Webページの構造をタグで書くマークアップ言語
- ポイント：決められたタグを使う。見た目はCSSで指定する
- 語の意味：HyperText＝リンクでつながる文書／Markup＝目印（タグ）を付ける／Language＝言語

#### XML（えっくすえむえる / Extensible Markup Language）

- 意味：用途に合わせて独自のタグを定義できるマークアップ言語
- ポイント：データの記述や交換に向く
- 語の意味：Extensible＝拡張できる／Markup Language＝タグを付ける言語

#### CSS（しーえすえす / Cascading Style Sheets）

- 意味：Webページの色・大きさ・配置などの見た目を指定する言語
- ポイント：HTMLは構造、CSSは見た目
- 語の意味：Cascading＝段階的に引き継がれる／Style Sheets＝見た目の指定書

#### JSON（じぇいそん / JavaScript Object Notation）

- 意味：名前と値の組を { } で書く、軽いデータの書式
- ポイント：Web APIのデータ交換でよく使う
- 語の意味：JavaScript＝言語の名前／Object＝まとまり／Notation＝書き方
