# 資格学習支援サイト

資格ごとに、分野別のノート・用語集・問題演習をまとめて管理する学習サイト。
GitHub Pages（https://kaku-ito.github.io/）で公開している。

## 考え方

- 基本情報・応用情報とも、シラバスの中分類（全23分野）で整理する
- 資格ページの「分野マップ」に23分野を並べ、教材のない分野も空きマスとして見せる
- 教材の型は3つ：**ノート**（読み物）／**用語集**（一覧・カード・クイズ）／**問題演習**（回答を記録）
- ログイン中は、分野マップと教材カードに正答率を出す

## デザインを変える

色・書体・文字の大きさ・余白・角の丸み・動きの速さは `assets/css/theme.css` にまとめてある。
ここの値を書き換えると、トップ・一覧・ノート・用語集・ナビバー・ログインページの見た目がまとめて変わる。

Apple公式サイトのような、白・黒・グレーを基本にした余白の多いデザイン。
アクセント色（青）はリンク・主要ボタン・選択中の表示だけに使い、
ほかに色を使うのは正解（緑）・不正解（赤）・注意（橙）だけ。枠線はできるだけ使わず、面の明るさと余白で区切る。

- 暗い色（ダークモード）にしたいとき：theme.css のいちばん下の `color-scheme: light;` を
  `dark`（いつも暗い）または `light dark`（端末の設定に合わせる）に変える。暗いときの色も theme.css に書いてある
- 本文を明朝体に戻したいとき：`--theme-font-body` を `var(--theme-font-serif)` に変える
- ボタンは `.button`（青）・`.button.is-secondary`（グレー）・`.text-link`（文字リンク）の3種類だけ

共通教材（`common/`）は色が各HTMLに直接書かれている。
`tools/lighten.pl` で `light-dark(明るい色, 暗い色)` の形に変換済みなので、上の color-scheme の切り替えには従う。

## 教材を追加する

1. 教材HTMLを資格フォルダに置く（ノートは `ap/notes/`）
2. `</body>` の直前で `site.js` を読み込む（`../` の数はフォルダの深さに合わせる）
3. 問題演習なら `study-sync.js` も読み込み、回答のたびに `recordAnswer(問題ID, カテゴリ, 正解か)` を呼ぶ
4. `assets/js/catalog.js` の `materials` に1行登録する（`type`・`file`・`title`・`desc`・`fields`）

登録した教材は、トップ・分野マップ・中分類ページ・ナビバー（パンくず・前後移動）に自動で反映される。
戻るリンクは教材HTMLに書かない（ナビバーが表示する）。

試験日は `catalog.js` の `topics` にある `exams` に書く。

### 用語集を追加する

1. md を `ap/terms/分野番号.md` に置く（例：`19.md`）
2. 既存の `ap/terms/20.html` をコピーして同じ番号の名前にし、`<title>` と `data-field` を書き換える
3. `catalog.js` に `{ type: "terms", file: "terms/19.html", ... fields: [19] }` を登録する

md は次のどちらの書き方でも読める（混ぜてもよい）。

```markdown
## 大きな区切り
### テーマ
#### 用語名（よみ / English）⚠要確認
- 意味：一言での定義
- ポイント：試験で押さえる点

| 用語 | 英語 | 解説 |      ← 1行1用語の表でもよい
| :-: | :-: | :-: |
| NPV | Net Present Value | 正味現在価値。… |
```

- `### まとめ` の下に書いた表や文は「まとめ表」として折りたたみで出る
- 略語は見出しに正式名称を書く（例：`#### RPA（Robotic Process Automation）`）。`- 語の意味：Robotic＝ロボットによる／…` を足すと、カードは1回目のタップで正式名称、2回目で意味と語の意味が出る
- 最後に `## 問題演習` を置くと、手作りの4択問題もクイズに出せる。`### 小分類名`（上の ## と同じ名前）の下に `#### 問 問題ID`、`- 問：` `- ア：`〜`- エ：` `- 正解：イ` `- 解説：` を書く。回答は問題IDのまま記録する
- ほかのページから問題を移したときは、`catalog.js` の `ids` に元の問題IDを書くと、これまでの回答記録が新しいページに引き継がれる（例：`fe/terms/10.md`）
- 図解スライドは `tools/slides/` のHTMLから `node tools/slides/topdf.js tools/slides/fe-10.html fe/terms/10.pdf` でPDFにできる
- 「意味」がない用語（名前だけの一覧）は札の形で並び、カード・クイズには出ない
- `⚠重複` を付けた用語は一覧にだけ出す
- 図解スライドのPDFは `data-pdf="ファイル名.pdf"` を `<main>` に付けるとボタンが出る
- クイズの回答は `ap-分野番号-用語名` のIDで記録され、分野マップの正答率に入る

回答記録（Supabase）の詳しい手順は [REVIEW_OPERATION.md](REVIEW_OPERATION.md) を参照。

## スマホのホーム画面に追加する

1. iPhone の Safari で https://kaku-ito.github.io/ を開く
2. 共有ボタン →「ホーム画面に追加」
3. アドレスバーのない全画面で開き、一度開いたページは圏外でも表示できる

## ページタイトルの形式

| --- | --- |
| トップ | `資格学習支援サイト` |

| 共通教材 | `教材名｜共通教材` |
