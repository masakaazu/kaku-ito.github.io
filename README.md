# 資格学習支援サイト

資格ごとに、分野別のノート・用語集・問題演習をまとめて管理する学習サイト。
GitHub Pages（https://kaku-ito.github.io/）で公開している。

## 考え方

- 基本情報・応用情報とも、シラバスの中分類（全23分野）で整理する
- 資格ページの「分野マップ」に23分野を並べ、教材のない分野も空きマスとして見せる
- 教材の型は3つ：**ノート**（読み物）／**用語集**（一覧・カード・クイズ）／**問題演習**（回答を記録）
- ログイン中は、分野マップと教材カードに正答率を出す

## デザインを変える

色・書体・角の丸み・粒子の強さは `assets/css/theme.css` にまとめてある。
ここの値を書き換えると、トップ・一覧・ノート・ナビバー・ログインページの見た目がまとめて変わる。

夜の部屋に吊るしたランプの光がモチーフ。チャコール（`#1e1f21`）×クリーム（`#e8e2d6`）の2色で、
正解（緑）・不正解（赤）・注意（黄）だけ色相を残す。

基本情報の日別復習（`fe/review/`）は色が各HTMLに直接書かれているため、theme.css の変更は書体と質感だけに効く。

## 教材を追加する

1. 教材HTMLを資格フォルダに置く（ノートは `ap/notes/`）
2. `</body>` の直前で `site.js` を読み込む（`../` の数はフォルダの深さに合わせる）
3. 問題演習なら `study-sync.js` も読み込み、回答のたびに `recordAnswer(問題ID, カテゴリ, 正解か)` を呼ぶ
4. `assets/js/catalog.js` の `materials` に1行登録する（`type`・`file`・`title`・`desc`・`fields`）

登録した教材は、トップ・分野マップ・中分類ページ・ナビバー（パンくず・前後移動）に自動で反映される。
戻るリンクは教材HTMLに書かない（ナビバーが表示する）。

試験日は `catalog.js` の `topics` にある `exams` に書く。

回答記録（Supabase）の詳しい手順は [REVIEW_OPERATION.md](REVIEW_OPERATION.md) を参照。

## スマホのホーム画面に追加する

1. iPhone の Safari で https://kaku-ito.github.io/ を開く
2. 共有ボタン →「ホーム画面に追加」
3. アドレスバーのない全画面で開き、一度開いたページは圏外でも表示できる

| トップ | `資格学習支援サイト` |

| 一覧ページ | `ノート一覧｜応用情報技術者試験` |
| 基本情報の復習教材 | `教材名｜基本情報 復習教材` |
| 応用情報のノート | `ノート名｜応用情報 知識ストック` |
| 共通教材 | `教材名｜共通教材` |
