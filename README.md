# 資格学習支援サイト

資格ごとに、学習計画・復習教材・知識ノートをまとめて管理する学習サイト。
GitHub Pages（https://kaku-ito.github.io/）で公開している。

## 構成

```text
kaku-ito.github.io/
├── index.html              トップ（資格トピックと共通教材の入口）
├── 404.html                旧URLから新URLへの自動転送
├── ap/                     応用情報技術者試験（学習中）
│   ├── index.html          トピックページ
│   └── notes/              知識ストック（apno1.html〜）
├── fe/                     基本情報技術者試験（受験済み）
│   ├── index.html          トピックページ
│   ├── wbs/                学習WBS・カレンダー
│   └── review/             日別復習教材（YYYY-MM-DD/ごと）
├── common/                 資格を問わず使う教材（英単語帳・略語帳）
├── tools/
│   └── darken.pl           教材HTMLの色をサイト共通の夜テーマへ変換する
└── assets/
    ├── css/
    │   ├── site.css        トップ・トピック・一覧ページの共通デザイン
    │   ├── content.css     教材ページ共通の書体・質感（site.js が自動で読み込む）
    │   └── note.css        独自スタイルを持たないノートの読み物デザイン
    └── js/
        ├── catalog.js      教材の一覧データ（教材を追加したらここに登録）
        ├── site.js         共通ナビバーと一覧ページの描画
        ├── fe-study-sync.js        復習教材の回答をSupabaseへ記録
        └── review-answer-toggle.js 「答えを表示」ボタン
```

## デザイン

夜の部屋に吊るしたランプの光をモチーフにした、チャコール（`#1e1f21`）×クリーム（`#e8e2d6`）の2色デザイン。
見出し・本文は明朝（Shippori Mincho B1）。全ページに粒子の質感をかける。

- トップ・トピック・一覧ページ: `site.css`
- 教材ページ: 各教材の `<style>` を `tools/darken.pl` で夜テーマに変換したうえで、`content.css` で書体と質感をそろえる
- 正解（緑）・不正解（赤）・注意（黄）だけは色相を残し、それ以外の色はクリームとチャコールに寄せる

## 教材を追加する

1. 教材HTMLを該当フォルダに置く
2. `</body>` の直前で `site.js` を読み込む（`../` の数はフォルダの深さに合わせる）
3. Git Bash で `perl tools/darken.pl 教材のパス.html` を実行し、色を夜テーマに変換する
   （変換済みのファイルは自動で飛ばすので、何度実行しても二重には変換されない）
4. `assets/js/catalog.js` に1行登録する

登録した教材は、トップ・トピック・一覧ページとナビバー（パンくず・前後移動）に自動で反映される。
戻るリンクは教材HTMLに書かない（ナビバーが表示する）。

試験日が決まったら `catalog.js` の `topics` にある `examDate` を `"YYYY-MM-DD"` で入力する。

基本情報の復習教材とSupabase連携の詳しい手順は [REVIEW_OPERATION.md](REVIEW_OPERATION.md) を参照。
