データベース・SQL

ノートの「外部データベースシステム」「関係演算子」「DDL/DML」「SQLの実行順序」を復習します。

SQLの実行順序

SQLは書く順と内部で処理される順が異なります。基本形は次の順です。

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

FROMで表を決め、WHEREで行を絞り、GROUP BYでグループ化し、HAVINGでグループを絞り、SELECTで表示列を決め、ORDER BYで並べ替えます。

例：部署ごとの平均給与が30万円以上の部署名と平均給与 
SELECT department, AVG(salary)
FROM employee
GROUP BY department
HAVING AVG(salary) >= 300000
ORDER BY AVG(salary) DESC;

ネットワーク機器・LAN

有線LAN（イーサネット）と、機器が扱うOSI層を整理します。

CSMA/CD方式

一言でいうと：共有型の有線LANで、通信路が空いているか確認してから送信し、衝突を検出したら送信をやり直す方式です。

流れ 内容
Carrier Sense 通信路を監視する
Multiple Access 複数の端末が同じ通信路を共有する
Collision Detection 衝突を検出し、再送する

要確認：ノートには「空いているタイミングで通信する」とあります。現在主流のスイッチングハブによる全二重通信では、通常CSMA/CDは使われません。

OSI基本参照モデル

通信の機能を7層に分けて考えるモデルです。上ほどアプリケーションに近く、下ほど物理的な通信に近くなります。

層 役割 ノートの要点
第7層 アプリケーション 利用者向けの通信サービス アプリケーション固有のルール
第6層 プレゼンテーション データ表現の変換 文字コード、暗号化、圧縮、解凍
第5層 セッション 通信の開始・維持・終了 接続確認、切断時の対応
第4層 トランスポート 端末間の信頼性ある配送 データを送る際の信頼性
第3層 ネットワーク ネットワーク間の宛先配送 送信元IPから送信先IPへ
第2層 データリンク 同一ネットワーク内の通信 ノード間の通信
第1層 物理 ビットを物理媒体で伝える 電圧レベル、ケーブル

TCP/IPモデルとの対応

TCP/IPモデル OSI参照モデル 例
アプリケーション層 第5〜7層 HTTP、DNS
トランスポート層 第4層 TCP、UDP
インターネット層 第3層 IP
ネットワークインタフェース層 第1〜2層 Ethernet
