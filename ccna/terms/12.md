## 12-1 ルーティングテーブルの読み方

### まとめ表

**1行の読み方**

```
O    10.1.30.0/24 [110/3] via 10.1.12.2, 00:05:12, GigabitEthernet0/1
```

| 部分 | 例 | 意味 |
| :-: | :-: | :-: |
| コード | O | どうやって覚えた経路か（O＝OSPF） |
| 宛先（プレフィックス） | 10.1.30.0/24 | 宛先のネットワークとマスクの長さ |
| [AD/メトリック] | [110/3] | アドミニストレーティブディスタンス 110、メトリック 3 |
| ネクストホップ | via 10.1.12.2 | 次に渡すルーターのアドレス |
| 時間 | 00:05:12 | 最後に更新されてからの時間 |
| 出口のインタフェース | GigabitEthernet0/1 | パケットを出すインタフェース |

**よく出るコード**

| コード | 意味 | AD の初期値 |
| :-: | :-: | :-: |
| C | 直接つながったネットワーク | 0 |
| L | ルーター自身のインタフェースのアドレス（/32） | 0 |
| S | スタティックルート | 1 |
| D | EIGRP（内部） | 90 |
| O | OSPF | 110 |
| R | RIP | 120 |
| B | BGP | 外部 20／内部 200 |
| * | デフォルトルートの候補 | ― |

### 経路の出どころ（コード）

#### ルーティングテーブル（るーてぃんぐてーぶる / routing table, RIB）

- 意味：ルーターが「この宛先へはどこに渡すか」を覚えている表。直接つながったネットワーク・スタティックルート・ルーティングプロトコルで覚えた経路が入る。RIB とも呼ぶ
- ポイント：`show ip route` で見る。各プロトコルがそれぞれの一番良い経路を出し合い、アドミニストレーティブディスタンスで1つに決めて入れる。パケットを送るときは、ここから作った転送用の表（FIB）を引く
- 例：`show ip route`
- 語の意味：RIB＝Routing Information Base（経路の情報の入れ物）

#### コネクテッドルート（こねくてっどるーと / connected route, C）

- 意味：ルーターのインタフェースに IP アドレスを付け、そのインタフェースが up のときに自動で入る、直接つながったネットワークの経路
- ポイント：コードは C、AD は 0（いちばん信用できる）。インタフェースが down になると消える。「is directly connected」と表示される
- 例：`C 10.1.12.0/24 is directly connected, GigabitEthernet0/1`

#### ローカルルート（ろーかるるーと / local route, L）

- 意味：ルーター自身のインタフェースの IP アドレスそのもの（/32）を表す経路
- ポイント：コードは L。C（ネットワーク全体）とセットで入る。ルーター宛てのパケット（ping・SSH など）を自分で受け取るためのもの
- 例：`L 10.1.12.1/32 is directly connected, GigabitEthernet0/1`

#### スタティックルート（すたてぃっくるーと / static route, S）

- 意味：管理者が `ip route` コマンドで手で書いた経路
- ポイント：コードは S、AD の初期値は 1。自動では変わらないので、経路が切れても別の道に切り替わらない（AD を大きくした予備のスタティックルートを除く）。設定は #13 で詳しく
- 例：`S 10.1.40.0/24 [1/0] via 10.1.12.2`

#### ダイナミックルート（だいなみっくるーと / dynamic route）

- 意味：OSPF・EIGRP・RIP・BGP などのルーティングプロトコルで、ルーターどうしが教え合って覚えた経路
- ポイント：コードはプロトコルごと（O・D・R・B）。ネットワークが変わると自動で作り直される。どのプロトコルの経路も [AD/メトリック] が付く
- 例：`O 10.1.30.0/24 [110/3] via 10.1.12.2, 00:05:12, GigabitEthernet0/1`

#### デフォルトルート（でふぉるとるーと / default route）

- 意味：0.0.0.0/0 の経路。ほかのどの経路にも当てはまらない宛先のパケットを送る先
- ポイント：マスクの長さが0なので、どの宛先にも当てはまるが、いちばん短い（いちばん弱い）。テーブルにあると「Gateway of last resort is …」に表示され、コードに `*`（候補）が付く
- 例：`S* 0.0.0.0/0 [1/0] via 203.0.113.1`

#### Gateway of last resort（げーとうぇいおぶらすとりぞーと / gateway of last resort）

- 意味：show ip route の最初に出る、デフォルトルートの行き先（最後の手段の出口）
- ポイント：「Gateway of last resort is not set」なら、デフォルトルートがない。テーブルにない宛先のパケットは捨てられる
- 例：`Gateway of last resort is 203.0.113.1 to network 0.0.0.0`

### 1行の中身

#### プレフィックス（ぷれふぃっくす / prefix）

- 意味：経路の宛先のネットワーク。アドレスと、前から何ビットがネットワーク部か（プレフィックス長＝マスク）で表す
- ポイント：10.1.0.0/16 と 10.1.1.0/24 は、アドレスが重なっていても長さが違うので別の経路として両方入る
- 例：`10.1.30.0/24`（10.1.30.0〜10.1.30.255）

#### アドミニストレーティブディスタンス（あどみにすとれーてぃぶでぃすたんす / administrative distance, AD）

- 意味：経路を教えてくれた出どころ（プロトコル）をどれだけ信用するかの値。0〜255 で、小さいほど信用する
- ポイント：同じ宛先（同じプレフィックス長）を別々のプロトコルから覚えたとき、AD が小さいほうをテーブルに入れる。ルーターの中だけの値で、ほかのルーターには伝わらない。255 は「信用しない」で、テーブルに入らない
- 例：`[110/3]` の 110 が AD（OSPF）
- 語の意味：Administrative＝管理上の／Distance＝距離（信用の遠さ）

#### メトリック（めとりっく / metric）

- 意味：1つのルーティングプロトコルの中で、同じ宛先への道どうしを比べる値。小さいほど良い
- ポイント：プロトコルごとに中身が違う（RIP＝ホップ数、OSPF＝コスト、EIGRP＝帯域と遅延から計算）。だから違うプロトコルどうしのメトリックは比べられない（そのために AD がある）
- 例：`[110/3]` の 3 がメトリック（OSPF のコストの合計）

#### ネクストホップ（ねくすとほっぷ / next hop）

- 意味：パケットを次に渡すルーターの IP アドレス。`via` の後ろに書かれる
- ポイント：ふつうは直接つながったネットワークの中のアドレス。出口のインタフェースと組で表示される
- 例：`via 10.1.12.2`

#### 出口のインタフェース（でぐちのいんたふぇーす / outgoing interface）

- 意味：パケットを出すルーターのインタフェース。行の最後に書かれる
- ポイント：ネクストホップだけの経路（スタティックなど）は、ネクストホップのアドレスをもう一度テーブルで引いて、出口を決める（再帰検索）
- 例：`…, GigabitEthernet0/1`

#### is subnetted と is variably subnetted（いずさぶねってぃど / is subnetted, is variably subnetted）

- 意味：同じ大きなネットワーク（クラスのネットワーク）の中の経路をまとめて表示するときの見出し。subnetted＝マスクが1種類、variably subnetted＝マスクが何種類か
- ポイント：見出しの行そのものは経路ではない。下に字下げして並ぶ行が経路
- 例：`10.0.0.0/8 is variably subnetted, 4 subnets, 2 masks`

## 12-2 経路の選び方

### まとめ表

**2つの段階**

| 段階 | いつ | 使うもの |
| :-: | :-: | :-: |
| ① テーブルに入れる | 経路を覚えたとき | 同じプロトコルの中 → メトリック／プロトコルどうし → AD |
| ② パケットを送る | パケットが来たとき | 当てはまる経路のうち、プレフィックスがいちばん長いもの（最長一致） |

**AD の初期値（Cisco）**

| 出どころ | AD |
| :-: | :-: |
| コネクテッド | 0 |
| スタティック | 1 |
| EIGRP の集約 | 5 |
| eBGP | 20 |
| EIGRP（内部） | 90 |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | 120 |
| EIGRP（外部） | 170 |
| iBGP | 200 |
| 信用しない | 255 |

### パケットを送るとき

#### 最長一致（さいちょういっち / longest prefix match）

- 意味：パケットの宛先に当てはまる経路が何本もあるとき、プレフィックス（マスク）がいちばん長い、いちばん細かい経路を使う決まり
- ポイント：AD やメトリックより先ではなく「別の段階」。AD とメトリックはテーブルに入れるときに使い終わっていて、送るときは長さだけで決まる。だから AD が大きい経路でも、プレフィックスが長ければそちらが使われる
- 例：10.1.1.0/24（OSPF）と 10.1.0.0/16（スタティック）がある → 宛先 10.1.1.5 は /24 の OSPF の経路で送る

#### FIB（えふあいびー / Forwarding Information Base）

- 意味：ルーティングテーブル（RIB）から作る、パケットを速く送るための表。Cisco では CEF が使う
- ポイント：テーブルに入れる（RIB）段階では AD とメトリック、送る（FIB）段階では最長一致、と分けて考える
- 例：`show ip cef 10.1.1.5`
- 語の意味：Forwarding＝転送／Information＝情報／Base＝入れ物。CEF＝Cisco Express Forwarding

#### 再帰検索（さいききけんさく / recursive lookup）

- 意味：ネクストホップのアドレスだけが書かれた経路を使うとき、そのネクストホップへ行く経路をもう一度テーブルで探し、出口のインタフェースを決めること
- ポイント：ネクストホップへ行く経路が見つからないと、その経路はテーブルに入らない
- 例：`S 10.1.40.0/24 via 10.1.12.2` → 10.1.12.2 は C 10.1.12.0/24 の中 → 出口は Gi0/1

### テーブルに入れるとき

#### AD による選択（えーでぃーによるせんたく / route selection by AD）

- 意味：同じ宛先・同じプレフィックス長の経路を、別々のプロトコルから覚えたとき、AD が小さいほうだけをテーブルに入れること
- ポイント：入らなかった経路は予備として残り、入った経路が消えると代わりに入る。AD を大きくしたスタティックルート（フローティングスタティック）はこのしくみを使う
- 例：10.1.30.0/24 を EIGRP（90）と OSPF（110）から覚えた → テーブルには D の経路だけ

#### メトリックによる選択（めとりっくによるせんたく / route selection by metric）

- 意味：同じプロトコルの中で、同じ宛先への道が何本もあるとき、メトリックが小さい道を選ぶこと
- ポイント：メトリックが同じ道が何本もあれば、全部をテーブルに入れて負荷分散する（ECMP）
- 例：OSPF で 10.1.30.0/24 への道がコスト3 とコスト5 → コスト3 の道だけが入る

#### ECMP（いーしーえむぴー / Equal-Cost Multi-Path）

- 意味：同じプロトコルで、メトリックが同じ複数の道を全部テーブルに入れ、パケットを分けて送ること
- ポイント：show ip route では、1つの宛先の下に via の行が何行も並ぶ。何本まで入れるかは maximum-paths で変えられる
- 例：

```
O    10.1.30.0/24 [110/3] via 10.1.12.2, 00:01:10, Gi0/1
                  [110/3] via 10.1.13.3, 00:01:10, Gi0/2
```
- 語の意味：Equal＝同じ／Cost＝コスト／Multi-Path＝複数の道

#### 各プロトコルのメトリック（かくぷろとこるのめとりっく / protocol metrics）

- 意味：RIP＝ホップ数（通るルーターの数、16 で届かない）、OSPF＝コスト（基準の帯域÷インタフェースの帯域、基準は初期100Mbps）、EIGRP＝いちばん細い帯域と遅延の合計から計算した値
- ポイント：RIP は速さを見ないので、遅い近道を選ぶことがある。OSPF の基準が100Mbps のままだと、100Mbps も1Gbps もコスト1 になる
- 例：RIP `[120/2]`（2ホップ）、OSPF `[110/3]`（コスト3）、EIGRP `[90/130816]`

#### AD 255（えーでぃーにひゃくごじゅうご / administrative distance 255）

- 意味：「この出どころは信用しない」という値。AD が 255 の経路はテーブルに入らない
- ポイント：ほかの経路があるときだけ使う予備にしたいなら、255 ではなく「本物より少し大きい値」（例：OSPF の予備なら 111 以上 254 以下）にする
- 例：`ip route 10.1.40.0 255.255.255.0 10.1.99.2 255` → テーブルに入らない

### 12-1 ルーティングテーブルの読み方

#### 問 ccna-12-o01

- 問：次の行で、110 が表しているものはどれか。
```
O    10.1.30.0/24 [110/3] via 10.1.12.2, 00:05:12, GigabitEthernet0/1
```
- ア：メトリック
- イ：プレフィックス長
- ウ：アドミニストレーティブディスタンス
- エ：経路を覚えてからの秒数
- 正解：ウ
- 解説：かっこの中は [AD/メトリック] の順。110 は OSPF の AD の初期値で、3 がメトリック（コスト）。
- アの意味：メトリックは後ろの 3。
- イの意味：プレフィックス長は /24。
- ウの意味：正しい。
- エの意味：時間は 00:05:12 の部分。
- 出典：オリジナル問題（根拠：Cisco IP Routing Protocol-Independent Command Reference「show ip route」Field Descriptions（The first number in brackets is the administrative distance…the second number is the metric））

#### 問 ccna-12-o02

- 問：問1 の行で、パケットを次に渡すルーターのアドレスはどれか。
- ア：10.1.30.0
- イ：10.1.12.2
- ウ：GigabitEthernet0/1
- エ：0.0.0.0
- 正解：イ
- 解説：via の後ろがネクストホップ（次のルーター）のアドレス。行の最後が出口のインタフェース。
- アの意味：宛先のネットワーク。
- イの意味：正しい。
- ウの意味：出口のインタフェースで、アドレスではない。
- エの意味：デフォルトルートの宛先の書き方で、この行とは関係ない。
- 出典：オリジナル問題（根拠：Cisco Command Reference「show ip route」Field Descriptions（via…Specifies the address of the next device to the remote network））

#### 問 ccna-12-o03

- 問：ルーターのインタフェース Gi0/1 に 10.1.12.1/24 を付けて up にした。テーブルに入る行の組み合わせとして正しいものはどれか。
- ア：C 10.1.12.1/24 だけ
- イ：C 10.1.12.0/24 と L 10.1.12.1/32
- ウ：S 10.1.12.0/24 と L 10.1.12.0/32
- エ：L 10.1.12.0/24 と C 10.1.12.1/32
- 正解：イ
- 解説：インタフェースのネットワーク（C、/24）と、ルーター自身のアドレス（L、/32）の2行が入る。
- アの意味：C の行はホストのアドレスではなくネットワークのアドレス（10.1.12.0）で表示され、L の行も入る。
- イの意味：正しい。
- ウの意味：手で書いていないので S にはならない。L はネットワークのアドレスではない。
- エの意味：C と L が逆。
- 出典：オリジナル問題（根拠：Cisco「What Is Administrative Distance?」の show ip route の出力例（C 172.16.1.0/24 is directly connected／L 172.16.1.100/32 is directly connected））

#### 問 ccna-12-o04

- 問：次の出力から言えることはどれか。
```
R1# show ip route
...
Gateway of last resort is not set

      10.0.0.0/8 is variably subnetted, 3 subnets, 2 masks
C        10.1.12.0/24 is directly connected, GigabitEthernet0/1
L        10.1.12.1/32 is directly connected, GigabitEthernet0/1
O        10.1.30.0/24 [110/3] via 10.1.12.2, 00:05:12, GigabitEthernet0/1
```
- ア：宛先 8.8.8.8 のパケットは捨てられる
- イ：宛先 8.8.8.8 のパケットは 10.1.12.2 へ送られる
- ウ：10.0.0.0/8 への経路がある
- エ：デフォルトルートは OSPF で覚えている
- 正解：ア
- 解説：Gateway of last resort is not set なのでデフォルトルートがない。8.8.8.8 に当てはまる経路もないので、パケットは捨てられる。
- アの意味：正しい。
- イの意味：10.1.30.0/24 の経路は 8.8.8.8 には当てはまらない。
- ウの意味：10.0.0.0/8 の行は見出しで、経路ではない。
- エの意味：デフォルトルートはない。
- 出典：オリジナル問題（根拠：Cisco Command Reference「show ip route」の出力例（Gateway of last resort is not set・is variably subnetted））

#### 問 ccna-12-o05

- 問：show ip route で、OSPF で覚えた経路に付くコードはどれか。
- ア：D
- イ：R
- ウ：B
- エ：O
- 正解：エ
- 解説：O が OSPF。D は EIGRP、R は RIP、B は BGP。
- アの意味：EIGRP（D は DUAL から）。
- イの意味：RIP。
- ウの意味：BGP。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：Cisco Command Reference「show ip route」Field Descriptions Codes（O—OSPF derived・D—EIGRP・R—RIP・B—BGP））

#### 問 ccna-12-o06

- 問：次の行の説明として正しいものはどれか。
```
S*   0.0.0.0/0 [1/0] via 203.0.113.1
```
- ア：OSPF で覚えたデフォルトルート
- イ：203.0.113.1 への /32 の経路
- ウ：AD が 0 のコネクテッドルート
- エ：管理者が書いたデフォルトルートで、Gateway of last resort は 203.0.113.1 になる
- 正解：エ
- 解説：S はスタティック、* はデフォルトルートの候補、0.0.0.0/0 はデフォルトルート。AD 1・メトリック 0。
- アの意味：コードは S なので OSPF ではない。
- イの意味：宛先は 0.0.0.0/0（全部）で、203.0.113.1 はネクストホップ。
- ウの意味：AD は 1（スタティックの初期値）。

- 問：R1 は 10.1.50.0/24 を OSPF から覚えてテーブルに入れている。同じ宛先を RIP からも覚えているが、テーブルには入っていない。OSPF の経路が消えたらどうなるか。
- ア：10.1.50.0/24 へは届かなくなる
- イ：デフォルトルートで送られる
- ウ：RIP の経路がテーブルに入る
- エ：OSPF の経路が戻るまで待つ
- 正解：ウ
- 解説：テーブルに入らなかったほかのプロトコルの経路は予備として残っていて、入っていた経路が消えると、次に AD が小さい経路がテーブルに入る。

- イの意味：RIP の /24 のほうがデフォルトルートより長いので、RIP の経路が使われる。
- ウの意味：正しい。
- エの意味：待たずに RIP の経路が入る。

#### 問 ccna-12-o30

- 問：OSPF の基準の帯域を初期値（100Mbps）のまま使っている。100Mbps と 1Gbps のインタフェースのコストについて正しいものはどれか。
- ア：どちらも 1 になり、区別できない
- イ：100Mbps は 10、1Gbps は 1
- ウ：100Mbps は 1、1Gbps は 0.1
- エ：100Mbps は 100、1Gbps は 1000
- 正解：ア
- 解説：コスト＝基準の帯域÷インタフェースの帯域で、1 より小さくはならない。100Mbps 以上はすべてコスト1 になるので、速いリンクを区別したいなら auto-cost reference-bandwidth で基準を上げる。
- アの意味：正しい。
- イの意味：基準が1Gbps のときの値。
- ウの意味：コストは1 より小さくならない（整数）。
- エの意味：割り算が逆。
- 出典：オリジナル問題（根拠：Cisco IP Routing: OSPF Configuration Guide IOS XE（auto-cost reference-bandwidth・Reference bandwidth unit is 100 mbps））
