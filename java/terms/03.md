## 03-1 String のしくみ

### まとめ表

| 書き方 | 結果 | 理由 |
| :-- | :-- | :-- |
| `s.toUpperCase();`（戻り値を使わない） | s は変わらない | String は不変。新しい String を返すだけ |
| `"hi" == "hi"` | true | 同じ文字列リテラルは同じオブジェクト（インターン） |
| `"hi" == new String("hi")` | false | new は必ず新しいオブジェクト |
| `"hi".equals(new String("hi"))` | true | equals は中身を比べる |
| `h == "Hel" + "lo"`（h は "Hello"） | true | 定数どうしの連結はコンパイル時に 1 つのリテラルになる |
| `h == "Hel" + lo`（lo は final でない変数） | false | 実行時の連結は新しいオブジェクト |
| `1 + 2 + "3" + 4 + 5` | "3345" | + は左から。文字列が出てから後は連結 |
| `null + "a"` の形（s は null） | "nulla" | null は "null" という文字列になる |

### 不変と比較

#### String（すとりんぐ / String）

- 意味：文字の並びを表すクラス（java.lang.String）。基本データ型ではなく参照型
- ポイント：java.lang なので import なしで使える。文字列リテラル（"..."）は String のオブジェクト（JLS 3.10.5）
- 例：`String s = "Java";`

#### 不変（ふへん / immutable）

- 意味：一度作ったオブジェクトの中身が、あとから変わらないこと
- ポイント：String は不変（API：Strings are constant）。toUpperCase・concat・replace などは、元の文字列を変えずに新しい String を返す。戻り値を代入しないと何も変わらない
- 例：`s.toUpperCase();` のあとも s は "java"。`s = s.toUpperCase();` なら "JAVA"

#### 文字列リテラルのプール（もじれつりてらるのぷーる / interned string literals）

- 意味：同じ内容の文字列リテラルを、1 つのオブジェクトにまとめて使い回すしくみ（インターン）
- ポイント：同じ内容のリテラルは、クラスやパッケージがちがっても同じオブジェクト。定数式（"Hel" + "lo" や final の変数どうし）の結果も同じ扱い。intern() を呼ぶとプールのものが返る（JLS 3.10.5）
- 例：`"hi" == "hi"` は true

#### == と equals（いこーるいこーるといこーるず / reference equality and equals）

- 意味：== は「同じオブジェクトか」、equals は「中身が同じか」を比べる
- ポイント：文字列の中身を比べるときは equals を使う。new String("hi") は必ず新しいオブジェクトなので、リテラルと == すると false。equals は String 以外（StringBuilder など）を渡すと false（API：is a String object that represents the same sequence）
- 例：`a.equals(c)` は true、`a == c` は false（c は new String("hi")）

#### new String（にゅーすとりんぐ / String constructor）

- 意味：コンストラクタで String のオブジェクトを作ること
- ポイント：中身が同じリテラルがあっても、別のオブジェクトができる。プールには入らない
- 例：`String c = new String("hi");`

#### 定数式（ていすうしき / constant expression）

- 意味：コンパイルのときに値が決まる式。リテラルや、定数で初期化した final の変数だけでできた式
- ポイント：文字列の定数式どうしの連結はコンパイル時に計算され、リテラルと同じオブジェクトになる。final でない変数が 1 つでも入ると実行時の連結になり、新しいオブジェクト（JLS 3.10.5 の例・15.29）
- 例：`final String lo = "lo";` なら `"Hello" == "Hel" + lo` は true

### 文字列の連結

#### 文字列連結演算子（もじれつれんけつえんざんし / string concatenation operator +）

- 意味：片方が String のときの +。もう片方を文字列に変えてつなぐ
- ポイント：+ は左から順に計算する。`1 + 2 + "3"` は先に 1 + 2 ＝ 3 を計算してから "3" をつなぐので "33"。いったん文字列になると、後ろの数は足されずにつながる（JLS 15.18.1）
- 例：`1 + 2 + "3" + 4 + 5` は "3345"

#### 文字列への変換（もじれつへのへんかん / string conversion）

- 意味：連結のとき、String でない値を文字列に変えること
- ポイント：数はそのまま、char は文字、boolean は "true"・"false"、null は "null" になる（JLS 5.1.11）。null の String に += しても例外にならず "null" がつく
- 例：`String s = null; s += "a";` → "nulla"

#### char と連結（きゃらとれんけつ / char in concatenation）

- 意味：char が + の左右にあるとき、文字としてつながるか、数として足されるか
- ポイント：左に String があれば文字としてつながる（"" + 'a' + 1 は "a1"）。char と int だけなら数の足し算（'a' + 1 は 98）
- 例：`'a' + 1 + ""` は "98"

#### += と連結（ぷらすいこーるとれんけつ / += with strings）

- 意味：`s += x` は `s = s + (x)` と同じで、右辺を先に計算する
- ポイント：`t += 1 + 2;` は右辺の 1 + 2 ＝ 3 が先なので "ab3"。`s = s + 1 + 2;` は左から "ab1" → "ab12"
- 例：`String t = "ab"; t += 1 + 2;` → "ab3"

## 03-2 String のメソッド

### まとめ表

| メソッド | 例（s は "Hello World"） | 結果 |
| :-- | :-- | :-- |
| length() | `s.length()` | 11（配列は length、String は length()） |
| charAt(i) | `s.charAt(4)` | 'o'。範囲外は StringIndexOutOfBoundsException |
| indexOf・lastIndexOf | `"banana".indexOf('a')`・`.lastIndexOf("an")` | 1・3。ないときは -1 |
| substring(b)・substring(b, e) | `s.substring(6)`・`s.substring(2, 4)` | "World"・"ll"（e は含まない） |
| replace | `"aaa".replace("aa", "b")` | "ba"（左から重ならずに置きかえる） |
| trim・strip | `"  Hi  ".trim()` | "Hi" |
| isEmpty・isBlank | `"  ".isEmpty()`・`"  ".isBlank()` | false・true |
| startsWith・endsWith・contains | `"abcabc".contains("ca")` | true |
| concat | `"a".concat("b")` | "ab" |
| repeat・join | `"ab".repeat(3)`・`String.join("-", "a", "b")` | "ababab"・"a-b" |
| split | `"a,b,,c".split(",").length` | 4（末尾の空の要素は消える） |
| equalsIgnoreCase・compareTo | `"Java".equalsIgnoreCase("JAVA")` | true |

### 調べる

#### length（れんぐす / String.length）

- 意味：文字列の長さ（char の数）を返すメソッド
- ポイント：String は length()、配列は length（かっこなし）。`s.length` や `s.size()` は「cannot find symbol」。size() は ArrayList（#04）
- 例：`"Hello World".length()` は 11

#### charAt（きゃらあっと / charAt）

- 意味：指定した位置の 1 文字を char で返すメソッド。位置は 0 から数える
- ポイント：最後の文字の位置は length() - 1。範囲外は StringIndexOutOfBoundsException（ArrayIndexOutOfBoundsException ではない）
- 例：`"abc".charAt(3)` → 例外

#### indexOf（いんでっくすおぶ / indexOf）

- 意味：文字や文字列が最初に出てくる位置を返すメソッド。lastIndexOf は最後に出てくる位置
- ポイント：見つからなければ -1。第 2 引数で探し始める位置を指定できる（`"abcabc".indexOf("c", 3)` は 5）
- 例：`"banana".indexOf('a')` は 1

#### substring（さぶすとりんぐ / substring）

- 意味：文字列の一部を取り出すメソッド
- ポイント：`substring(b, e)` は b から e - 1 まで（e は含まない）で、長さは e - b（API）。`substring(b)` は最後まで。b が length() と同じなら空文字列。b ＞ e や範囲外は StringIndexOutOfBoundsException
- 例：`"Hello World".substring(2, 4)` は "ll"

#### startsWith・endsWith・contains（すたーつうぃず / startsWith, endsWith, contains）

- 意味：指定した文字列で始まるか・終わるか・含むかを boolean で返すメソッド
- ポイント：startsWith は第 2 引数で調べ始める位置を指定できる。空文字列 "" はどの文字列にも含まれる扱い（endsWith("") は true）
- 例：`"abcabc".startsWith("bc", 1)` は true

#### isEmpty と isBlank（いずえんぷてぃといずぶらんく / isEmpty, isBlank）

- 意味：isEmpty は長さが 0 か、isBlank は空か空白だけかを調べるメソッド
- ポイント：空白 2 つの "  " は isEmpty が false、isBlank が true。isBlank は Java 11 から（API）
- 例：`"".isEmpty()` は true

### 作りかえる

#### replace（りぷれいす / replace）

- 意味：文字や文字列を置きかえた新しい String を返すメソッド
- ポイント：すべて置きかえる。左から順に、重ならないように置きかえるので `"aaa".replace("aa", "b")` は "ba"。char 版（`replace('a', 'o')`）もある
- 例：`"banana".replace('a', 'o')` は "bonono"

#### trim と strip（とりむとすとりっぷ / trim, strip）

- 意味：前後の空白を取り除いた新しい String を返すメソッド
- ポイント：真ん中の空白は残る。strip は Java 11 からで、全角スペースなど Unicode の空白も取り除く（trim は文字コード 32 以下の文字だけ）。元の文字列は変わらない
- 例：`"  Hi  ".trim()` は "Hi"、元の長さは 6 のまま

#### toUpperCase・toLowerCase（とぅーあっぱーけーす / toUpperCase, toLowerCase）

- 意味：大文字・小文字に変えた新しい String を返すメソッド
- ポイント：呼ぶたびに新しいオブジェクトを返すので、`s.toUpperCase() == s.toUpperCase()` は false
- 例：`"java".toUpperCase()` は "JAVA"

#### concat（こんかっと / concat）

- 意味：後ろに文字列をつないだ新しい String を返すメソッド
- ポイント：+ と同じく元の文字列は変わらない。戻り値を使わないと何も起きない
- 例：`"a".concat("b")` は "ab"

#### repeat と join（りぴーととじょいん / repeat, join）

- 意味：repeat は同じ文字列を指定回数くり返す（Java 11〜）、String.join は区切り文字をはさんでつなぐ static メソッド
- ポイント：repeat(0) は空文字列。join の第 1 引数は区切り文字
- 例：`String.join("-", "a", "b", "c")` は "a-b-c"

#### split（すぷりっと / split）

- 意味：区切り文字（正規表現）で分けて、String の配列を返すメソッド
- ポイント：途中の空の要素は残るが、末尾の空の要素は消える（API：Trailing empty strings are therefore not included）。先頭の空の要素は残る
- 例：`"a,b,,c".split(",")` は 4 つ、`"a,b,c,,".split(",")` は 3 つ

#### compareTo と equalsIgnoreCase（こんぺあとぅー / compareTo, equalsIgnoreCase）

- 意味：compareTo は辞書順で比べて差を int で返す。equalsIgnoreCase は大文字・小文字を区別せずに中身を比べる
- ポイント：compareTo は前なら負、同じなら 0、後なら正。大文字は小文字より前（"Apple".compareTo("apple") は負）。片方がもう片方の先頭部分なら長さの差（"ab".compareTo("abcd") は -2）
- 例：`"b".compareTo("a")` は 1

## 03-3 StringBuilder

### まとめ表

| メソッド | 例（sb は "abcdef"） | 結果 |
| :-- | :-- | :-- |
| append | `sb.append(1).append('x')` | 末尾につなぐ。sb 自身を返すのでつなげて書ける |
| insert | `sb.insert(0, "X")` | 指定位置に入れる |
| delete(b, e) | `sb.delete(1, 3)` | b から e - 1 まで消す → "adef" |
| deleteCharAt(i) | `sb.deleteCharAt(0)` | 1 文字消す |
| replace(b, e, str) | `sb.replace(1, 4, "Z")` | 範囲を置きかえる → "aZef" |
| reverse | `sb.reverse()` | 逆順 |
| setCharAt・setLength | `sb.setLength(2)` | 1 文字を変える・長さを変える（void） |
| toString | `sb.toString()` | 中身の String を作る |
| equals | `sb.equals(sb2)` | 中身ではなく同じオブジェクトかを比べる |

### 変えられる文字列

#### StringBuilder（すとりんぐびるだー / StringBuilder）

- 意味：中身を変えられる文字列のクラス（java.lang.StringBuilder）
- ポイント：append や insert で、同じオブジェクトの中身が変わる（API：A mutable sequence of characters）。同じ機能のスレッドセーフ版が StringBuffer
- 例：`StringBuilder sb = new StringBuilder("ab");`

#### append（あぺんど / append）

- 意味：末尾にどんな型の値でもつなぐメソッド
- ポイント：戻り値は sb 自身なので、`sb.append("a").append(1)` とつなげて書ける（メソッドチェーン）。boolean は true、double の 2.0 は "2.0" とつながる
- 例：`new StringBuilder().append("a").append(1).append('b').append(true)` → "a1btrue"

#### insert（いんさーと / insert）

- 意味：指定した位置に値を入れるメソッド
- ポイント：位置は 0〜length()。length() をこえると StringIndexOutOfBoundsException
- 例：`new StringBuilder("adef").insert(0, "X")` → "Xadef"

#### delete と deleteCharAt（でりーと / delete, deleteCharAt）

- 意味：delete(b, e) は b から e - 1 まで、deleteCharAt(i) は 1 文字を消すメソッド
- ポイント：substring と同じく e は含まない。どちらも sb 自身を返す
- 例：`new StringBuilder("abcdef").delete(1, 3)` → "adef"

#### StringBuilder の replace（すとりんぐびるだーのりぷれいす / StringBuilder.replace）

- 意味：位置の範囲（b から e - 1）を、指定した文字列に置きかえるメソッド
- ポイント：String の replace（文字列を探して置きかえる）とは引数がちがう。`sb.replace(1, 4, "Z")` は 3 文字を 1 文字に置きかえる
- 例："abcdef" → "aZef"

#### reverse（りばーす / reverse）

- 意味：文字の並びを逆にするメソッド
- ポイント：String には reverse がない。sb 自身が変わる
- 例：`new StringBuilder("ello").reverse()` → "olle"

#### setCharAt と setLength（せっときゃらあっと / setCharAt, setLength）

- 意味：setCharAt は 1 文字を置きかえ、setLength は長さを変えるメソッド
- ポイント：どちらも戻り値は void なので、そのあとにメソッドをつなげられない。setLength で短くすると後ろが切れる
- 例：`sb.setLength(2)`（"abc" → "ab"）

#### toString（とぅーすとりんぐ / toString）

- 意味：StringBuilder の今の中身から String を作るメソッド
- ポイント：String と中身を比べるときは `s.equals(sb.toString())`。`s.equals(sb)` は型がちがうので false。`s == sb` は「incomparable types」でコンパイルエラー
- 例：`String r = sb.toString();`

#### StringBuilder の equals（すとりんぐびるだーのいこーるず / StringBuilder.equals）

- 意味：StringBuilder どうしを equals で比べたときの動き
- ポイント：StringBuilder は equals をオーバーライドしていないので、== と同じく同じオブジェクトかどうかだけを見る（API：does not override equals）。中身を比べるなら toString して比べるか compareTo
- 例：`new StringBuilder("ab").equals(new StringBuilder("ab"))` は false

#### 容量（ようりょう / capacity）

- 意味：StringBuilder が内部に用意している、文字を入れられる場所の大きさ
- ポイント：足りなくなると自動で広がるので、ふだんは気にしなくてよい。長さ（length）とは別。引数なしで作ると 16、文字列を渡すと「その長さ＋16」（API）
- 例：`new StringBuilder("abc").capacity()` は 19

## 03-4 テキストブロック

### まとめ表

| 決まり | 例 | 結果 |
| :-- | :-- | :-- |
| 開始の """ のあとは改行が必要 | `"""abc"""` | エラー（missing line terminator） |
| 終了の """ を行末に置く | `"""` 改行 `abc"""` | "abc"（最後の改行なし） |
| 終了の """ を次の行に置く | `"""` 改行 `abc` 改行 `"""` | "abc\n"（最後に改行あり） |
| 左の共通の空白は消える | いちばん浅い行（終了の """ の行を含む）が左端 | 相対的な字下げだけ残る |
| 行末の空白は消える | — | 残したいなら \s |
| 行末の \ | `one \` 改行 `two` | 改行せずにつながる |
| " はそのまま書ける | `He said "Hi".` | エスケープ不要（""" が続くときだけ要る） |
| 中身は String | `"""` 改行 `hi` 改行 `"""` == "hi\n" | true（インターンされる） |

### テキストブロックの形

#### テキストブロック（てきすとぶろっく / text block）

- 意味：""" と """ ではさみ、複数行の文字列をそのまま書ける String のリテラル。Java 15 から正式機能
- ポイント：型は String（JLS 3.10.6）。改行やダブルクォートをエスケープせずに書ける。普通の "..." のリテラルは途中で改行すると「unclosed string literal」
- 例：HTML や JSON、SQL を見たままの形で書く

#### 開始の区切り（かいしのくぎり / opening delimiter）

- 意味：テキストブロックの始まりの """。そのあとに空白（任意）と改行が必要
- ポイント：`"""abc"""` のように 1 行には書けない。「illegal text block open delimiter sequence, missing line terminator」。""" のあとの空白は OK。中身は改行の次の行から始まる
- 例：`String s = """`（ここで改行）

#### 終了の区切り（しゅうりょうのくぎり / closing delimiter）

- 意味：テキストブロックの終わりの """
- ポイント：最後の行の末尾に置くと、最後に改行が付かない。次の行に単独で置くと、最後に改行が付く（Oracle Text Blocks ガイド）。終了の """ の行の位置は、左の空白をどこまで消すかにも効く
- 例：`abc"""` なら長さ 3、`abc` 改行 `"""` なら長さ 4

#### 付随的な空白（ふずいてきなくうはく / incidental white space）

- 意味：ソースの字下げのために入っていて、文字列の中身には含めない左側の空白
- ポイント：中身の行（と終了の """ だけの行）のうち、いちばん左の行に合わせて全体を左に寄せる。終了の """ を中身より左に置くと、その分の空白が中身に残る。行末の空白も取り除かれる（JLS 3.10.6・String.stripIndent）
- 例：中身が 10 字と 12 字下げ、終了の """ が 8 字下げなら、2 字と 4 字の空白が残る

#### 改行の取り消し（かいぎょうのとりけし / line continuation escape）

- 意味：行末に \ を書くと、その改行を中身に入れない（次の行につながる）エスケープ
- ポイント：テキストブロックの中だけで使える。\ の前の空白は行末ではないので残る
- 例：`one \` 改行 `two` → "one two"

#### \s（えすけーぷえす / space escape）

- 意味：1 つの空白（スペース）を表すエスケープ。Java 15 から
- ポイント：エスケープは空白の除去のあとで変換されるので、行末の空白を残すのに使える（Oracle Text Blocks ガイド）
- 例：`two\s` → "two "（後ろの空白が残る）

#### formatted（ふぉーまってぃど / String.formatted）

- 意味：文字列を書式として使い、%s などを引数で埋めた新しい String を返すメソッド
- ポイント：`String.format(書式, 引数)` と同じ動き。テキストブロックのあとに直接つなげて書ける
- 例：`"""` 改行 `Hello, %s!` 改行 `""".formatted("Java")` → "Hello, Java!\n"
