## 07-1 while 文と do-while 文

### まとめ表

| 書き方 | 結果（JDK 17） | 理由 |
| :-- | :-- | :-- |
| `while (i < 3)`（i は 5） | 1 回も実行しない | 先に条件を調べる |
| `do { … } while (i < 3);`（i は 5） | 1 回だけ実行する | 後で条件を調べる |
| `} while (i < 3)`（; なし） | ';' expected | do-while の最後は ; が必要 |
| `{ }` なしで 2 行を字下げ | 1 行目だけがループの中 | i++ がループの外なら無限ループ |
| `while (false) { … }` | unreachable statement | 中身が絶対に実行されない |
| `while (true) { }` のあとの文 | unreachable statement | ループが終わらない |
| `if (false) { … }` | OK | if だけは特別に許されている |

### 前判定と後判定

#### 繰り返し文（くりかえしぶん / iteration statement）

- 意味：同じ処理を条件が満たされるあいだ何度も実行する文。while・do・for の 3 種類（拡張 for は for の仲間）
- ポイント：continue が使えるのは繰り返し文の中だけ（JLS 14.16：statements of these three kinds are called iteration statements）。条件は boolean か Boolean
- 例：`while (i < 3) i++;`

#### while 文（ほわいるぶん / while statement）

- 意味：条件が true のあいだ、文をくり返す。最初に条件を調べる（前判定）
- ポイント：最初から条件が false なら 1 回も実行しない。対象は直後の 1 文（{ } で複数）。`while (i++ < 3)` のように条件の中で変数を変えると、比べるのは増やす前の値で、ループのあとは 1 つ多くなる
- 例：i が 0 のとき `while (i++ < 3) print(i);` → 1 2 3、終わったとき i は 4

#### do-while 文（どぅーほわいるぶん / do statement）

- 意味：先に文を実行してから条件を調べる（後判定）くり返し文。`do 文 while (条件);`
- ポイント：条件が最初から false でも必ず 1 回は実行する。最後の ; を忘れるとコンパイルエラー（';' expected）。{ } がなくても 1 文なら書ける：`do x++; while (x < 3);`
- 例：`do { System.out.print("d"); } while (false);` → d

#### 無限ループ（むげんるーぷ / infinite loop）

- 意味：条件がずっと true のままで終わらないループ
- ポイント：`while (true)`・`for (;;)` は break で抜けるのがふつう。{ } を忘れて i++ がループの外に出ると、条件が変わらず無限ループになる（コンパイルエラーにはならない）
- 例：`while (true) { if (++n > 4) break; }`

### 到達できない文

#### 到達できない文（とうたつできないぶん / unreachable statement）

- 意味：どんな実行でも絶対に実行されない文。Java ではコンパイルエラー（unreachable statement）
- ポイント：`while (true) { }`（break なし）のあとの文、break・continue・return の直後の文、`while (false)` の中身がこれに当たる（JLS 14.22）。if だけは例外で、`if (false) { … }` はエラーにならない（デバッグ用の切りかえに使えるよう、わざと許されている）
- 例：`for (…) { break; System.out.println(i); }` → unreachable statement

#### 定数式の条件（ていすうしきのじょうけん / constant condition）

- 意味：条件がコンパイル時に値の決まる式（true・false のリテラルや final の定数）になっていること
- ポイント：到達できるかの判断は定数式の値だけを見る。`boolean b = false; while (b) { }` は b が定数ではないのでコンパイルできる。`final boolean F = false; while (F) { }` は定数なので unreachable statement
- 例：`for (int i = 0; false; i++) { }` も中身が到達不能でエラー

## 07-2 for 文

### まとめ表

| 書き方 | 結果（JDK 17） | 理由 |
| :-- | :-- | :-- |
| `for (int i = 0, j = 10; …; i += 3, j -= 3)` | OK | 同じ型なら複数宣言できる。更新部はカンマで並べる |
| `for (int i = 0, long j = 0; …)` | コンパイルエラー | 宣言は 1 つの型だけ |
| ループのあとで `i` を使う（for の中で宣言） | cannot find symbol | i のスコープは for 文の中だけ |
| 外で宣言した i を for で使う | ループのあとも使える | 終わったときの値（条件が false になった値）が残る |
| `for (;;)` | 無限ループ | 3 つの部分はどれも省略できる |
| 外に i があるのに `for (int i = 0; …)` | already defined | ローカル変数の名前は重ねられない |

### for 文の 3 つの部分

#### 基本の for 文（きほんのふぉーぶん / basic for statement）

- 意味：`for (初期化; 条件; 更新) 文` の形のくり返し文
- ポイント：実行の順は「初期化 → 条件 → 文 → 更新 → 条件 → 文 → 更新 …」。条件が false になったら終わる。初期化は最初の 1 回だけ（JLS 14.14.1）
- 例：`for (int i = 0; i < 3; i++) System.out.print(i);` → 012

#### 初期化部（しょきかぶ / ForInit）

- 意味：for のかっこの 1 つめ。最初に 1 回だけ実行する
- ポイント：ローカル変数の宣言か、式文をカンマで並べたもののどちらか。宣言は 1 つの型だけ（`int i = 0, j = 10` は OK、`int i = 0, long j = 0` はエラー）。宣言と式文はまぜられない。メソッド呼び出しも書ける
- 例：`for (System.out.print("init "); i < 2; …)`

#### 条件部（じょうけんぶ / for condition）

- 意味：for のかっこの 2 つめ。毎回、文を実行する前に調べる boolean の式
- ポイント：省略すると true と同じ（無限ループ）。`i < 0` のように最初から false なら 1 回も実行しない。定数の false を書くと中身が到達不能でコンパイルエラー
- 例：`for (;;) { … break; }`

#### 更新部（こうしんぶ / ForUpdate）

- 意味：for のかっこの 3 つめ。文を実行したあと、毎回実行する式
- ポイント：式文をカンマで並べられる（`i += 3, j -= 3`）。宣言は書けない。continue したときも更新部は実行される
- 例：`for (int i = 10; i > 0; i -= 3)` → 10・7・4・1

#### for の変数のスコープ（ふぉーのへんすうのすこーぷ / scope of a for loop variable）

- 意味：初期化部で宣言した変数を使える範囲。for 文の中（条件・更新・本体）だけ
- ポイント：ループのあとで使うと cannot find symbol。続けて別の for で同じ名前を宣言するのは OK。外側にすでにある名前と同じ変数を宣言すると already defined。ループのあとも値を使いたいなら、for の前で宣言する
- 例：`int i; for (i = 0; i < 3; i++) { }` のあと i は 3

#### 入れ子のループ（いれこのるーぷ / nested loops）

- 意味：ループの中にさらにループを書くこと
- ポイント：内側のループは、外側の 1 回ごとに最初から全部回る。内側の初期値が外側の変数に依存する（`j = i`）と、回数が毎回変わる。break・continue は内側のループだけに効く（外側にはラベルを使う）
- 例：`for (i 0〜3) for (j = i〜3) count++;` → 4 + 3 + 2 + 1 = 10

## 07-3 拡張 for 文

### まとめ表

| 書き方 | 結果（JDK 17） | 理由 |
| :-- | :-- | :-- |
| `for (var x : a)`・`for (final int x : a)` | OK | ループの変数に var・final が使える |
| `int x; for (x : a)` | bad initializer for for-loop | 必ずその場で変数を宣言する |
| `for (char c : "abc")` | for-each not applicable to expression type | String は配列でも Iterable でもない |
| `for (char c : s.toCharArray())` | OK | char[] に変える |
| `for (int n : list)`（List&lt;Integer&gt;） | OK | アンボクシングされる |
| ループの変数に代入 | 配列・リストは変わらない | 変数は要素のコピー |

### 拡張 for のしくみ

#### 拡張 for 文（かくちょうふぉーぶん / enhanced for statement）

- 意味：`for (型 変数 : 配列やコレクション) 文` の形で、先頭から順に全要素を 1 つずつ取り出すくり返し文
- ポイント：: の左は必ずその場で宣言する（既にある変数は使えない：bad initializer for for-loop）。添字は使えない。順番は配列なら 0 から、List なら先頭から
- 例：`for (String s : list) System.out.print(s);`

#### 拡張 for に使える型（かくちょうふぉーにつかえるかた / array or Iterable）

- 意味：拡張 for の : の右に書けるのは、配列か java.lang.Iterable を実装した型（ArrayList など）
- ポイント：String・StringBuilder・int は使えない（for-each not applicable to expression type）。String の文字を回すなら `s.toCharArray()`。Map はそのままでは使えず、keySet() などを使う
- 例：`for (char c : "abc".toCharArray())`

#### ループ変数（るーぷへんすう / loop variable of an enhanced for）

- 意味：拡張 for で、各回に要素の値が入る変数
- ポイント：要素の値のコピーなので、代入しても配列やリストは変わらない（#04）。var も final も付けられる。List&lt;Integer&gt; から int で受けるとアンボクシングされる
- 例：`for (final int x : a) System.out.print(x * 2);`

#### Iterable（いてらぶる / java.lang.Iterable）

- 意味：「拡張 for で回せる」ことを表すインタフェース。iterator() メソッドを持つ
- ポイント：Collection（List・Set など）は Iterable を継承しているので拡張 for で回せる。拡張 for の中でリストに add・remove すると ConcurrentModificationException（#04）
- 例：`for (Integer n : new ArrayList<>(List.of(1, 2)))`

## 07-4 break・continue・ラベル

### まとめ表

| 書き方 | 動き | 効く相手 |
| :-- | :-- | :-- |
| `break;` | ループを抜ける | いちばん内側の for・while・do・switch |
| `continue;` | 今回の残りを飛ばして次の回へ | いちばん内側の for・while・do |
| `break ラベル;` | ラベルの付いた文を抜ける | ループ以外の文（if やブロック）にも使える |
| `continue ラベル;` | ラベルの付いたループの次の回へ | ラベルはループに付いていなければエラー |
| break・continue の直後の文 | unreachable statement | その文には絶対に届かない |

### break と continue

#### break 文（ぶれいくぶん / break statement）

- 意味：switch・while・do・for を途中で抜ける文
- ポイント：ラベルなしの break は、いちばん内側の switch・while・do・for を抜ける（JLS 14.15）。入れ子のループでは内側だけを抜け、外側は続く。ループの中の switch で break すると、抜けるのは switch だけ
- 例：`for (…) { if (i == 3) break; }`

#### continue 文（こんてぃにゅーぶん / continue statement）

- 意味：ループの今回の残りを飛ばして、次の回に進む文
- ポイント：for では continue のあとも更新部が実行される。while では更新を continue より前に書かないと無限ループになることがある。switch だけの中では使えない（ループの中の switch なら使える）
- 例：`if (i == 1) continue;` で i が 1 の回だけ飛ばす

### ラベル

#### ラベル（らべる / statement label）

- 意味：`名前:` を文の前に付けて、break・continue の行き先を名前で指すもの
- ポイント：Java に goto はなく、ラベルは break と continue だけで使う（JLS 14.7）。ラベル名は変数名と同じでもよい。ラベルの有効範囲は付けた文の中だけ
- 例：`outer: for (…) { for (…) { … } }`

#### ラベル付き break（らべるつきぶれいく / labeled break）

- 意味：`break ラベル;` で、そのラベルが付いた文をまるごと抜ける
- ポイント：入れ子の外側のループまで一気に抜けられる。ループでない文（if・ブロック）に付けたラベルにも break できる（JLS 14.15：the break target need not be a switch, while, do, or for statement）
- 例：`a: for (…) { switch (i) { case 1: break a; } }` → for まで抜ける

#### ラベル付き continue（らべるつきこんてぃにゅー / labeled continue）

- 意味：`continue ラベル;` で、そのラベルが付いたループの次の回へ進む
- ポイント：内側のループの残りも飛ばして、外側のループの更新部へ進む。ラベルがループ以外に付いていると not a loop label でコンパイルエラー（JLS 14.16：the continue target must be a while, do, or for statement）
- 例：`outer: for (i…) for (j…) { if (j == 1) continue outer; }`

### 07-1 while 文と do-while 文

#### 問 java-07-o01

- 問：main メソッドの中の次のコードを実行した。表示されるものはどれか。

  ```
  int i = 0;
  while (i < 3) {
    System.out.print(i + " ");
    i++;
  }
  System.out.println("end " + i);
  ```

- ア：0 1 2 3 end 3
- イ：1 2 3 end 3
- ウ：0 1 2 end 3
- エ：0 1 2 end 2
- 正解：ウ
- 解説：i が 0・1・2 のあいだ表示して 1 増やす。i が 3 になると条件 i < 3 が false でループを終える。ループのあとの i は 3。
- アの意味：i が 3 のときも 1 回実行すると考えたまちがい。
- イの意味：表示より先に i が増えると考えたまちがい。
- ウの意味：正しい。
- エの意味：ループを終えた時点の i を、最後に表示した値と考えたまちがい。
- 出典：オリジナル問題（根拠：JLS 14.12（executes an Expression and a Statement repeatedly until the value of the Expression is false）／JDK 17 での実行結果）

#### 問 java-07-o02

- 問：main メソッドの中の次のコードを実行した。表示されるものはどれか。

  ```
  int i = 5;
  while (i < 3) {
    System.out.print("w ");
  }
  do {
    System.out.print("d ");
  } while (i < 3);
  ```

- ア：何も表示されない
- イ：w d
- ウ：d が無限に表示される
- エ：d
- 正解：エ
- 解説：while は先に条件を調べるので、i が 5 だと 1 回も実行しない。do-while は先に本体を実行してから条件を調べるので、1 回だけ d を表示して終わる。
- アの意味：do-while も先に条件を調べると考えたまちがい。
- イの意味：while も最低 1 回は実行すると考えたまちがい。
- ウの意味：条件 i < 3 は false なので、do-while は 2 回目に進まない。
- エの意味：正しい。
- 出典：オリジナル問題（根拠：JLS 14.12・14.13（The do statement executes a Statement and an Expression repeatedly until the value of the Expression is false）／JDK 17 での実行結果）

#### 問 java-07-o03

- 問：main メソッドの中の次のコードをコンパイルした。結果として正しいものはどれか。

  ```
  int i = 0;
  do {
    i++;
  } while (i < 3)
  System.out.println(i);
  ```

- ア：コンパイルでき、3 と表示される
- イ：';' expected のコンパイルエラーになる
- ウ：コンパイルでき、1 と表示される
- エ：do-while の本体に { } は使えないのでコンパイルエラーになる
- 正解：イ
- 解説：do-while 文は `do 文 while (条件);` の形で、最後の ; が必要。while (i < 3) のあとに ; がないのでコンパイルエラーになる。
- アの意味：; がなければコンパイルできない。; があれば 3 と表示される。
- イの意味：正しい。
- ウの意味：コンパイルの段階で止まる。
- エの意味：do-while の本体にはブロックを書ける。
- 出典：オリジナル問題（根拠：JLS 14.13（DoStatement: do Statement while ( Expression ) ;）／JDK 17 でのコンパイル結果）

#### 問 java-07-o04

- 問：main メソッドの中の次のコードを実行した。結果として正しいものはどれか。

  ```
  int i = 0;
  while (i < 3)
    System.out.print(i);
    i++;
  ```

- ア：0 が止まらずに表示され続ける（無限ループ）
- イ：012 と表示される
- ウ：0 と表示される
- エ：コンパイルエラーになる
- 正解：ア
- 解説：{ } がないので、while の対象は直後の print の 1 文だけ。i++ はループの外なので実行されず、i は 0 のまま。条件はずっと true で、0 を表示し続ける。
- アの意味：正しい。
- イの意味：字下げで i++ もループの中に入ると考えたまちがい。
- ウの意味：1 回で終わると考えたまちがい。
- エの意味：無限ループになるコードもコンパイルはできる（i < 3 は定数式ではない）。
- 出典：オリジナル問題（根拠：JLS 14.12（WhileStatement: while ( Expression ) Statement）／JDK 17 での実行結果）

#### 問 java-07-o05

- 問：main メソッドの中の次のコードを実行した。表示されるものはどれか。

  ```
  int i = 0;
  while (i++ < 3) System.out.print(i + " ");
  System.out.println("/" + i);
  ```

- ア：1 2 3 /4
- イ：0 1 2 /3
- ウ：1 2 3 /3
- エ：1 2 /3
- 正解：ア
- 解説：i++ < 3 は増やす前の値で比べる。0・1・2 のとき true で、本体では増えたあとの 1・2・3 を表示する。i が 3 のとき 3 < 3 が false で終わるが、そのときも i++ が実行されて i は 4。
- アの意味：正しい。
- イの意味：本体でも増やす前の値が表示されると考えたまちがい。
- ウの意味：条件が false になった最後の i++ を見落としたまちがい。
- エの意味：++i < 3 のように、増やしたあとの値で比べると考えたまちがい。
- 出典：オリジナル問題（根拠：JLS 14.12・15.14.2（The value of the postfix increment expression is the value of the variable before the new value is stored）／JDK 17 での実行結果）

#### 問 java-07-o06

- 問：main メソッドの中の次のコードを実行した。表示されるものはどれか。

  ```
  int i = 0;
  do System.out.print(i + " "); while (++i < 3);
  System.out.println("/" + i);
  ```

- ア：0 1 2 3 /3
- イ：1 2 /3
- ウ：コンパイルエラーになる（do の本体に { } がない）

  ```
    for (int j = 0; j < 3; j++) {
      if (j == 1) break;
      System.out.print(i + "" + j + " ");
    }
  }
  ```

- ア：00
- イ：00 10 20
- ウ：00 01 02
- エ：00 10
- 正解：イ
- 解説：ラベルのない break は、いちばん内側のループ（j のループ）だけを抜ける。外側の i のループは続くので、i = 0・1・2 のそれぞれで j = 0 のときだけ表示する。
- アの意味：break で外側のループまで抜けると考えたまちがい。
- イの意味：正しい。
- ウの意味：break を見落としたまちがい。
- エの意味：外側のループが 2 回で終わると考えたまちがい。
- 出典：オリジナル問題（根拠：JLS 14.15（A break statement with no label attempts to transfer control to the innermost enclosing switch, while, do, or for statement）／JDK 17 での実行結果）

#### 問 java-07-o30

- 問：main メソッドの中の次のコードを実行した。表示されるものはどれか。

  ```
  int k = 0;
  a: for (int i = 0; i < 3; i++) {
    switch (i) {
      case 1: break a;
      default: k += 10;
    }
  }
  int m = 0;
  for (int i = 0; i < 3; i++) {
    switch (i) {
      case 1: break;
      default: m += 10;
    }
  }

  ```

- イ：10 10
- ウ：20 20

- イの意味：ラベルなしの break も for を抜けると考えたまちがい。
- ウの意味：break a も switch だけを抜けると考えたまちがい。
- エの意味：break がどこにも効かないと考えたまちがい。
- 出典：オリジナル問題（根拠：JLS 14.15（A break statement with no label … innermost enclosing switch, while, do, or for statement／A break statement with label Identifier … the enclosing labeled statement）／JDK 17 での実行結果）
