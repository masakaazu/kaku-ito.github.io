## 17-1 Locale

### まとめ表

| 書き方 | 結果（toString） |
| :-: | :-: |
| new Locale("fr") | fr |
| new Locale("en", "GB")・Locale.UK | en_GB |
| new Locale("EN", "us") | en_US（言語は小文字、国は大文字にそろう） |
| Locale.JAPAN・Locale.forLanguageTag("ja-JP") | ja_JP |
| Locale.JAPANESE・Locale.ENGLISH | ja・en（言語だけ） |
| new Locale.Builder().setLanguage("de").setRegion("CH").build() | de_CH |

### ロケール

#### Locale（ろけーる / Locale）

- 意味：言語・国（地域）などの組合せで、地域ごとの表示のしかたを表すクラス（java.util）
- ポイント：作り方は、コンストラクタ（new Locale(言語[, 国[, バリアント]])）、定数（Locale.US・Locale.JAPAN）、Locale.forLanguageTag("ja-JP")、Locale.Builder の 4 つ。引数なしのコンストラクタはない。Locale.of は Java 19 からなので Java 17 にはない。toString は「言語_国」、toLanguageTag は「言語-国」
- 例：`Locale l = new Locale("en", "GB"); l.getLanguage(); // en  l.getCountry(); // GB`

#### 言語コードと国コード（げんごこーど・くにこーど / language code, country code）

- 意味：言語は ISO 639 の小文字 2 文字（ja・en・fr）、国は ISO 3166 の大文字 2 文字（JP・US・FR）
- ポイント：new Locale("EN", "us") のように大文字・小文字をまちがえても、言語は小文字、国は大文字に直される。知らないコード（xx_YY）でも例外にならず、そのまま Locale ができる

#### 既定のロケール（きていのろけーる / default locale）

- 意味：JVM が起動時に OS などから決める、何も指定しないときに使われるロケール。Locale.getDefault() で取り、Locale.setDefault(l) で変える
- ポイント：setDefault は、その JVM の中だけで変わる（OS の設定は変わらない）

#### Locale.Category（ろけーるかてごり / Locale.Category）

- 意味：既定のロケールを、用途ごとに分けて設定するための列挙型。DISPLAY（言語や国の名前の表示）と FORMAT（数値・日付などの書式）の 2 つ
- ポイント：setDefault(l) は両方を変える。setDefault(Locale.Category.FORMAT, l) は FORMAT だけを変え、getDefault() と DISPLAY は変わらない

## 17-2 リソース・バンドル

### まとめ表

| 求めたロケール（既定は en_US） | 探す順 |
| :-: | :-: |
| fr_CA | Msg_fr_CA → Msg_fr →（既定）Msg_en_US → Msg_en → Msg |
| ja_JP（Msg_ja がない） | Msg_ja_JP → Msg_ja → Msg_en_US → Msg_en → Msg |

| 見つかったバンドル | キーを探す範囲（親） |
| :-: | :-: |
| Msg_fr_CA | Msg_fr_CA → Msg_fr → Msg（既定のロケールのバンドルは親にならない） |

### バンドル

#### ResourceBundle（りそーすばんどる / ResourceBundle）

- 意味：ロケールごとの文字列などを、キーと値の組で集めておき、ロケールに合わせて取り出すしくみ（java.util）。ResourceBundle.getBundle(基底名, ロケール) で取る
- ポイント：getString(キー) で String、getObject(キー) で Object を取る。キーがなければ MissingResourceException、バンドルが 1 つも見つからなくても MissingResourceException（どちらも非チェック例外）。値が String でないキーを getString すると ClassCastException。keySet は親のキーも含む

#### バンドルの名前（ばんどるのなまえ / bundle name）

- 意味：「基底名_言語_国」の形の名前。プロパティ・ファイルなら Msg_fr_CA.properties、クラスなら Msg_fr_CA
- ポイント：基底名だけの Msg.properties は、どのロケールでも最後に使われる「基底バンドル」。getLocale() で、実際に見つかったバンドルのロケールが分かる（基底バンドルなら空のロケール）

#### バンドルを探す順（ばんどるをさがすじゅん / bundle search order）

- 意味：求めたロケールのバンドルがないとき、国を外す → 既定のロケール（国あり → 国なし）→ 基底バンドルの順に探す
- ポイント：ja_JP を求めて Msg_ja がなく、既定が en_US で Msg_en があると、基底の Msg ではなく Msg_en が使われる。既定のロケールを fr_FR に変えると Msg_fr が使われる。ResourceBundle.Control.getNoFallbackControl を渡すと、既定のロケールを使わずに基底バンドルへ進む

#### 親のバンドル（おやのばんどる / parent bundle）

- 意味：見つかったバンドルにキーがないとき、次に探すバンドル。Msg_fr_CA の親は Msg_fr、その親は Msg
- ポイント：親のつながりは、見つかったバンドルの名前から国・言語を外したものだけ。既定のロケールのバンドル（Msg_en など）は親にならない

#### ListResourceBundle と PropertyResourceBundle（りすとりそーすばんどる / ListResourceBundle, PropertyResourceBundle）

- 意味：ListResourceBundle は Java のクラスで getContents() に Object[][] でキーと値を書く。PropertyResourceBundle は .properties ファイルから作られる
- ポイント：同じ名前のクラスとプロパティ・ファイルがあると、クラスが先に使われる。クラスなら値に String 以外（数値など）も入れられる。.properties は Java 9 から UTF-8 で読まれる

#### Properties（ぷろぱてぃーず / Properties）

- 意味：キーも値も文字列の、設定を入れておくクラス。Hashtable<Object, Object> のサブクラス
- ポイント：getProperty(キー) はなければ null、getProperty(キー, 既定値) はなければ既定値を返す。load・store でファイルと読み書きする

## 17-3 数値のフォーマット

### まとめ表

| メソッド（Locale.US） | 1234567.891 の結果など |
| :-: | :-: |
| NumberFormat.getInstance | 1,234,567.891（小数は 3 けたまで） |
| getCurrencyInstance | $1,234,567.89 |
| getPercentInstance | 0.256 → 26% |
| getIntegerInstance | 2.5 → 2、3.5 → 4（HALF_EVEN） |
| getCompactNumberInstance(US, SHORT) | 1234 → 1K、1500000 → 2M |
| getCompactNumberInstance(US, LONG) | 1500000 → 2 million |

### 数値

#### NumberFormat（なんばーふぉーまっと / NumberFormat）

- 意味：数値をロケールに合わせた文字列にする（format）、文字列を数値に戻す（parse）抽象クラス（java.text）
- ポイント：new できず、getInstance・getNumberInstance・getCurrencyInstance・getPercentInstance・getIntegerInstance・getCompactNumberInstance で取る。引数のロケールを省くと既定のロケール（FORMAT）。ドイツでは 1.234.567,891 のように区切りが逆になる。丸めの既定は HALF_EVEN（偶数への丸め）

#### parse（ぱーす / parse）

- 意味：文字列を数値（Number）に戻すメソッド
- ポイント：先頭から読めるところまで読み、残りは無視する（"1,234.5abc" → 1234.5、"12x3" → 12）。先頭から読めないと ParseException（チェック例外）。結果が整数なら Long、小数なら Double

#### DecimalFormat（でしまるふぉーまっと / DecimalFormat）

- 意味：パターンで書式を決める NumberFormat のサブクラス
- ポイント：0 はけたがなくても 0 を出し、# はけたがなければ何も出さない。, は区切り、. は小数点。"#,##0.00" で 1234.5 → 1,234.50、"000.#" で 5.25 → 005.2（HALF_EVEN）、"#.##" で 0.5 → .5 ではなく 0.5

#### CompactNumberFormat（こんぱくとなんばーふぉーまっと / CompactNumberFormat）

- 意味：大きな数を「1K」「2 million」「1万」のように短く書く書式（Java 12〜）。NumberFormat.getCompactNumberInstance(ロケール, NumberFormat.Style.SHORT または LONG) で取る
- ポイント：既定では小数を出さずに丸める（1500000 → 2M）。setMaximumFractionDigits(1) で 1.2K のように小数を出せる。1000 未満はそのまま（999）

#### 通貨とパーセント（つうかとぱーせんと / currency, percent）

- 意味：getCurrencyInstance は通貨の記号と小数けた（ドルは 2 けた、円は 0 けた）を付ける。getPercentInstance は 100 倍して % を付ける
- ポイント：US の 1234567.891 は $1,234,567.89。UK の -3.5 は -£3.50。0.256 は 26%、1.5 は 150%

## 17-4 日付・時刻とメッセージのフォーマット

### まとめ表

| パターン文字 | 意味 | 2026-03-05 14:07:09 での例 |
| :-: | :-: | :-: |
| y・yyyy | 年 | 2026 |
| M・MM・MMM・MMMM | 月 | 3・03・Mar・March |
| d・dd | 日 | 5・05 |
| E・EEEE | 曜日 | Thu・Thursday |
| H・HH／h・hh＋a | 時（0〜23）／時（1〜12）と午前午後 | 14／02 PM |
| m・mm | 分 | 07 |
| s・ss | 秒 | 09 |
| '文字' | そのまま出す文字 | 'at' → at |

### 日付・時刻

#### DateTimeFormatter（でいとたいむふぉーまったー / DateTimeFormatter）

- 意味：日付・時刻を文字列にする（format）、文字列から戻す（parse）ためのクラス（java.time.format）。不変でスレッドセーフ
- ポイント：ofPattern("yyyy/MM/dd") で自分で決める。ofPattern(パターン, ロケール) か withLocale で、月や曜日の名前の言語が決まる。M（月）と m（分）、H（24 時間）と h（12 時間）を取りちがえやすい。知らないパターン文字は IllegalArgumentException

#### UnsupportedTemporalTypeException（あんさぽーてっどてんぽらるたいぷえくせぷしょん / UnsupportedTemporalTypeException）

- 意味：持っていない項目を書式に使ったときの実行時例外。DateTimeException のサブクラス
- ポイント：LocalDate を "HH:mm" で format すると「Unsupported field: HourOfDay」。LocalTime を "yyyy" で format しても同じ。コンパイルでは分からない

#### FormatStyle（ふぉーまっとすたいる / FormatStyle）

- 意味：ofLocalizedDate・ofLocalizedTime・ofLocalizedDateTime に渡す、ロケールに合わせた書式の長さ。SHORT・MEDIUM・LONG・FULL
- ポイント：US の 2026-03-05 は SHORT 3/5/26、MEDIUM Mar 5, 2026、LONG March 5, 2026、FULL Thursday, March 5, 2026。日本は SHORT 2026/03/05、FULL 2026年3月5日木曜日。時刻の LONG・FULL はタイムゾーンが要るので、LocalDateTime では DateTimeException（Unable to extract ZoneId）

### メッセージ

#### MessageFormat（めっせーじふぉーまっと / MessageFormat）

- 意味：{0}・{1} のような番号の場所に値を入れて、文を作るクラス（java.text）。MessageFormat.format(パターン, 値…) で使う
- ポイント：同じ番号は何度でも使える。値のない番号は {2} のまま残る。数値はロケールに合わせて区切られる（1234 → 1,234）。{0,number,percent} のように書式も指定できる。' は特別な文字で、'{1}' はそのまま {1}、'' で ' を 1 つ出す
