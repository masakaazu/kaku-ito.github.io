## 08-1 集計

### まとめ表

| メソッド | Stream<T> | IntStream |
| :-: | :-: | :-: |
| count() | long | long |
| max・min | 引数に Comparator、Optional<T> | 引数なし、OptionalInt |
| sum() | なし | int（0 個なら 0） |
| average() | なし | OptionalDouble（0 個なら empty） |
| summaryStatistics() | なし | IntSummaryStatistics |

### 集計の終端操作

#### count（かうんと / count）

- 意味：要素の数を long で返す終端操作
- ポイント：Java 9 から、要素の数がソースから分かるとき（List や Stream.of など、filter がない場合）は、パイプラインを実行せずに数を返すことがある。その場合 peek や map のラムダ式は呼ばれない（API の注記）

#### max・min（まっくす・みん / max, min）

- 意味：最大・最小の要素を返す終端操作
- ポイント：Stream<T> の max・min は Comparator が必須（引数なしは「method max in interface Stream<T> cannot be applied to given types」）。戻り値は Optional<T>。IntStream の max・min は引数なしで OptionalInt。同じ大きさの要素が複数あるときは先に出たものが選ばれる

#### sum・average（さむ・あべれーじ / sum, average）

- 意味：IntStream・LongStream・DoubleStream の合計と平均を返す終端操作
- ポイント：Stream<Integer> には sum はない（cannot find symbol）。mapToInt してから使う。sum は 0 個なら 0、average は 0 個なら OptionalDouble.empty。IntStream の average も OptionalDouble

#### summaryStatistics（さまりーすたてぃすてぃくす / summaryStatistics）

- 意味：件数・合計・最小・平均・最大を 1 回でまとめて求める、基本データ型のストリームの終端操作
- ポイント：toString は「IntSummaryStatistics{count=2, sum=3, min=1, average=1.500000, max=2}」。Collectors.summarizingInt と同じ中身（#07）

## 08-2 探索とマッチ

### まとめ表

| メソッド | 戻り値 | 要素 0 個のとき | 短絡 |
| :-: | :-: | :-: | :-: |
| findFirst() | Optional<T> | empty | する |
| findAny() | Optional<T> | empty | する |
| anyMatch(p) | boolean | false | true が見つかったら止まる |
| allMatch(p) | boolean | true | false が見つかったら止まる |
| noneMatch(p) | boolean | true | true が見つかったら止まる |

### 探す

#### findFirst（ふぁいんどふぁーすと / findFirst）

- 意味：ストリームの最初の要素を Optional で返す終端操作
- ポイント：順序のあるストリームなら、並列でも必ず最初の要素。要素が null だと NullPointerException

#### findAny（ふぁいんどえにー / findAny）

- 意味：ストリームのどれか 1 つの要素を Optional で返す終端操作
- ポイント：どの要素が返るかは決まっていない。逐次ストリームではたいてい最初の要素だが、並列では変わりうる（#09）。並列で速くしたいときに使う

#### anyMatch（えにーまっち / anyMatch）

- 意味：条件を満たす要素が 1 つでもあれば true を返す終端操作
- ポイント：true が見つかった時点で止まる。要素 0 個なら false

#### allMatch（おーるまっち / allMatch）

- 意味：すべての要素が条件を満たせば true を返す終端操作
- ポイント：false が見つかった時点で止まる。要素 0 個なら true（反例がないので）

#### noneMatch（なんまっち / noneMatch）

- 意味：条件を満たす要素が 1 つもなければ true を返す終端操作
- ポイント：条件を満たす要素が見つかった時点で false で止まる。要素 0 個なら true。無限ストリームで、条件を満たす要素が現れれば終わる

## 08-3 Optional

### まとめ表

| メソッド | 値があるとき | 空のとき |
| :-: | :-: | :-: |
| get()・orElseThrow() | 値 | NoSuchElementException（No value present） |
| orElse(x) | 値（x も評価はされる） | x |
| orElseGet(supplier) | 値（supplier は呼ばれない） | supplier の結果 |
| orElseThrow(supplier) | 値 | supplier の例外 |
| isPresent()・isEmpty() | true・false | false・true |
| ifPresent(c) | c を実行 | 何もしない |
| ifPresentOrElse(c, r) | c を実行 | r を実行 |
| map(f) | f の結果を Optional で（null なら empty） | empty |
| flatMap(f) | f が返した Optional | empty |
| filter(p) | 満たせばそのまま、満たさなければ empty | empty |
| or(supplier) | そのまま | supplier の Optional |
| stream() | 要素 1 つ | 要素 0 個 |

### 作る

#### Optional（おぷしょなる / Optional）

- 意味：値が「あるかもしれないし、ないかもしれない」ことを表す入れ物のクラス。null の代わりに戻り値に使う
- ポイント：toString は値があれば「Optional[x]」、空なら「Optional.empty」。equals は中身どうしを比べる
- 語の意味：optional＝任意の、あってもなくてもよい

#### Optional.of・ofNullable・empty（おぷしょなるおぶ・おぶなられぶる・えんぷてぃ / of, ofNullable, empty）

- 意味：of は null でない値から、ofNullable は null なら空・そうでなければ値ありで、empty は空の Optional を作る static メソッド
- ポイント：Optional.of(null) は NullPointerException。null かもしれない値には ofNullable

#### OptionalInt（おぷしょなるいんと / OptionalInt）

- 意味：int の値を持つかもしれない Optional。IntStream の max・min・findFirst・reduce などが返す。OptionalLong・OptionalDouble もある
- ポイント：値を取り出すのは getAsInt（get はない：cannot find symbol）。map・filter・flatMap はない。orElse・orElseGet・orElseThrow・ifPresent はある

### 取り出す

#### get・orElseThrow（げっと・おあえるすすろー / get, orElseThrow）

- 意味：値を取り出すメソッド。空なら NoSuchElementException（No value present）を投げる
- ポイント：引数なしの orElseThrow（Java 10〜）は get と同じ動き。orElseThrow(IllegalArgumentException::new) のように Supplier を渡すと、その例外を投げる

#### orElse（おあえるす / orElse）

- 意味：値があればその値、空なら引数の値を返すメソッド
- ポイント：引数は「ふつうの引数」なので、値があってもなくても先に評価される。orElse(def()) は値があっても def() を呼ぶ

#### orElseGet（おあえるすげっと / orElseGet）

- 意味：値があればその値、空なら Supplier を呼んでその結果を返すメソッド
- ポイント：値があるときは Supplier を呼ばない。重い処理や副作用のある処理には orElseGet

#### ifPresent・ifPresentOrElse（いふぷれぜんと・いふぷれぜんとおあえるす / ifPresent, ifPresentOrElse）

- 意味：値があれば Consumer を実行するメソッド。ifPresentOrElse（Java 9〜）は空のときの Runnable も渡せる
- ポイント：isPresent は boolean を返すだけ、ifPresent は処理を実行する（戻り値は void）。isEmpty は Java 11〜

### 変換する

#### Optional.map（おぷしょなるまっぷ / Optional.map）

- 意味：値があれば Function で変換し、その結果を Optional に包んで返すメソッド
- ポイント：関数が null を返すと Optional.empty になる。関数が Optional を返すと Optional<Optional<U>> と入れ子になる

#### Optional.flatMap（おぷしょなるふらっとまっぷ / Optional.flatMap）

- 意味：値があれば、Optional を返す Function を呼び、その Optional をそのまま返すメソッド
- ポイント：入れ子にしたくないときに使う。map に Optional を返す関数を渡して Optional<Integer> に代入するとコンパイルエラー

#### Optional.filter（おぷしょなるふぃるた / Optional.filter）

- 意味：値が条件を満たせばそのまま、満たさなければ空の Optional を返すメソッド
- ポイント：map・filter をつなげて、途中で空になればそのあとは全部空のまま流れる

#### Optional.or・stream（おぷしょなるおあ・すとりーむ / or, stream）

- 意味：or は空のとき別の Optional を返す（Java 9〜）。stream は値があれば要素 1 つ、空なら 0 個の Stream を返す（Java 9〜）
- ポイント：orElse は値（T）を返し、or は Optional を返す。`list.stream().flatMap(Optional::stream)` で、空の Optional を除いて中身だけ取り出せる

#### 問 jgold-08-o11

- 問：findFirst と findAny の説明として正しいものはどれか。
- ア：findAny は、逐次ストリームでも毎回ちがう要素を返す
