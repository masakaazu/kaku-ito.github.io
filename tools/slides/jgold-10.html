ディレクティブの一覧

ディレクティブ意味コンパイル時実行時
requires MM を読む必要必要（ないと FindException）
requires transitive M自分を読むモジュールにも M を読ませる必要必要
requires static M任意の依存必要なくてよい（自動では解決されない）
exports PP の public 型を公開効く効く
exports P to MM にだけ公開効く効く
opens P（to M）深いリフレクションを許す効かない効く
open module全パッケージを opens中に opens は書けない
uses・provides … withサービス（#11）
出典：JLS 7.7.1 Dependences・7.7.2 Exported and Opened Packages

requires transitive と requires static

module a.core { exports a.core; } module b.api { requires transitive a.core; exports b.api; } module c.app { requires b.api; } // c.app から a.core.Core を使える（暗黙の読み取り） // transitive なし → package a.core is not visible // (… but module c.app does not read it)
java.sql は java.logging・java.xml・java.transaction.xa を requires transitive。requires java.sql だけで java.util.logging も使える。
module use.it { requires static opt.dep; } java -p only -m use.it/use.it.Main // NoClassDefFoundError java -p out -m use.it/use.it.Main // NoClassDefFoundError java -p out --add-modules opt.dep -m use.it/use.it.Main // dep
ふつうの requires で依存がない：起動時に FindException「Module a.core not found, required by b.api」。
出典：JLS 7.7.1、JEP 261（implied readability）、java（--add-modules）／JDK 17 でのコンパイルと実行の結果

本番での問われ方

ねらい見るところ
使えるか相手のモジュールを読んでいるか（requires・transitive）＋相手が exports しているか
ディレクティブの意味transitive は受け渡し、static はコンパイル時だけ、to は限定、opens は実行時リフレクション
エラーになる宣言循環・重複・クラス名の exports・open module に opens・ハイフン
コマンド-p と -m の書き方、モジュール名/メインクラス、java の -d は describe
出力先out/モジュール名/パッケージ/クラス
実行時のエラー依存なし → FindException、static の依存なし → NoClassDefFoundError、opens なし → InaccessibleObjectException
