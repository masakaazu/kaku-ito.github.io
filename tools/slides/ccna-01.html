ルーター・L2 スイッチ・L3 スイッチ

機器見るもの仕事
ルーター宛先 IP別々のネットワークをつなぎ、最適な経路を選ぶ
L2 スイッチ宛先 MAC同じ LAN の中で、必要なポートにだけ送る
L3 スイッチMAC と IPスイッチの働き＋ VLAN の間などのルーティング
L3 スイッチの L3 インタフェース：SVI（「interface vlan 10」）、ルーテッドポート（物理ポートを 「no switchport」）、L3 の EtherChannel。IP ルーティングは既定で無効なので 「ip routing」 を入れる。
落とし穴：エッジルーター（ゲートウェイ）＝ネットワークのいちばん外側で、インターネットなど外とつなぐルーター。家庭の無線ルーターは、エッジと配布の役を1台にまとめたもの。
出典：Cisco「What Is a Router?」（chooses the best route／An edge router, also called a gateway router … is a network's outermost point of connection with external networks／Wireless routers, or residential gateways, combine the functions of edge routers and distribution routers）／Cisco「Different Types of Network Switches」（operates at the data link layer … forwarding data packets based on their destination MAC addresses）／Catalyst 9300 IP Routing CG 17.9「Configuring IP Unicast Routing」（By default, IP routing is disabled／A routed port … no switchport／A switch virtual interface (SVI) … interface vlan）

見るものできること
ファイアウォール5 タプル（送信元・宛先の IP とポート、プロトコル）＋状態許可した通信だけ通す（ステートフル）
NGFW＋アプリ・ユーザーアプリの制御・IPS・マルウェア対策・TLS の復号
IDSパケットの中身（ルール）受け身で見張り、知らせる
IPSパケットの中身（ルール）検知＋止める・変える
NGFW：従来の「ステートフルな検査」に、アプリの識別と制御・組み込みの IPS・高度な脅威の検知・ユーザーの識別を足したもの。
出典：Cisco「What Is a Next-Generation Firewall?」（combines traditional stateful firewall functions with application awareness and control, integrated intrusion prevention, advanced threat detection, and user identity awareness／filters traffic on the 5-tuple）／Secure Firewall Management Center「Intrusion Prevention Overview」（passively monitoring … "Intrusion Detection System (IDS)"／adds the ability to block or alter malicious traffic … "Intrusion Prevention System (IPS)"）

AP・WLC・エンドポイント・サーバー

部品役割

キャンパスの 3 つの層

層役割
アクセス端末や利用者がつながる入口（有線と無線）。セキュリティ・PoE・QoS
ディストリ
ビューション		アクセス層を集約し、サービス（WAN・WLC など）へつなぐ。障害を小さい範囲にとどめる
コア大きな LAN でディストリビューション層どうしをつなぐ。止まらず、単純に、L3 だけ
集約の理由：アクセススイッチが 2〜3 台を超えると、全部を互いにつなぐのは現実的でない。だからディストリビューションでまとめる。
出典：Cisco「Campus LAN and Wireless LAN Solution Design Guide」（Access layer —Provides endpoints and users direct access to the network／Distribution layer —Aggregates access layers and provides connectivity to services／Core layer —Provides connectivity between distribution layers for large LAN environments／At any site with more than two or three access-layer devices, it is impractical to interconnect all access switches／Connectivity to and from the core is Layer 3–only）

オンプレミスとクラウド

誰が管理するか（NIST SP 800-145 をもとに Claude が図にした）
SaaS でも利用者ごとの設定は少しできる。IaaS では一部のネットワーク部品（ホストのファイアウォールなど）を利用者が扱えることがある。
NIST の 5 つの特徴意味
オンデマンド・セルフサービス人を通さず自分で資源を用意できる
幅広いネットワーク利用ネットワーク越しに、いろいろな端末から使える
資源の共有提供者の資源を多くの利用者で分け合う
すばやい伸び縮み必要に応じてすぐ増やし、すぐ減らす
従量（測定）使った分を測って管理する
置き方：パブリック（誰でも）・プライベート（1 つの組織だけ。社内にあっても社外にあってもよい）・ハイブリッド（2 つ以上を組み合わせ）・コミュニティ。
出典：NIST SP 800-145（Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources／On-demand self-service／Broad network access／Resource pooling／Rapid elasticity／Measured service／SaaS … the consumer does not manage or control the underlying cloud infrastructure … with the possible exception of limited user-specific application configuration settings／IaaS … has control over operating systems, storage, and deployed applications; and possibly limited control of select networking components (e.g., host firewalls)／Private cloud … may exist on or off premises）

仮想マシンとコンテナ

コンテナイメージ：コンテナを動かすのに要るファイル（実行ファイル・ライブラリ・設定）をまとめたもの。OS の働きはホストのカーネルが受け持つ。層で作り、レジストリに置いて共有する。
仮想マシンコンテナ
分け方ハイパーバイザーでハードのレベル同じ OS カーネルを共有して分ける
中身ゲスト OS＋アプリアプリと必要なライブラリだけ
違う OSLinux と Windows を同時にホストと同じ系統だけ
分離の強さ強いVM より弱い

出典：NIST SP 800-190 2.2（Examples of runtimes include Docker／VMs use a hypervisor that provides hardware-level isolation … includes a complete guest OS … VMs allow different OSs, such as Linux and Windows, to share the same physical hardware／With containers, multiple apps share the same OS kernel instance／a Linux host can only run containers built for Linux）・2.3（An image is a package that contains all the files required to run a container／Images are typically stored in central locations）・3.5.2（the level of isolation provided by container runtimes is not as high as that provided by hypervisors）

よくあるひっかけ

よくある思い込み正しくは
L2 スイッチは IP アドレスで転送する宛先 MAC。IP で経路を選ぶのはルーター（と L3 スイッチ）
IDS は悪い通信を止めるIDS は見張って知らせるだけ。止めるのは IPS
従来のファイアウォールでアプリを見分けるアプリやユーザーまで見るのは NGFW
PoE+（802.3at）は 15.4 W802.3at は 30 W。15.4 W は 802.3af
2 層構成はアクセスとコアの 2 つアクセスとディストリビューション（ディストリビューションがコアを兼ねる）
スパインにサーバーをつなぐサーバーはリーフ。全リーフが全スパインにつながる
SaaS では OS を利用者が管理するOS から管理するのは IaaS。SaaS は提供者のアプリを使うだけ
Type 1 ハイパーバイザーは Windows の上で動くType 1 はハードの上に直接。OS の上は Type 2
VLAN を分ければ同じ IP を重ねて使えるルーティングテーブルを分ける VRF が要る
