イテレータと変更できないコレクション

回しながら消すときと、変えられない List の見分け方。

Java Gold #01 コレクション・フレームワーク試験内容 1

回しながら消す

for (String s : list) { // [a, b, c] if (s.equals("a")) list.remove(s); } // → ConcurrentModificationException for (String s : list) { if (s.equals("b")) list.remove(s); } // → [a, c]（例外なし）
最後から2番目を消すと hasNext が false になり、next が呼ばれない。フェイルファストは保証ではない。
安全な消し方
Iterator<Integer> it = list.iterator(); while (it.hasNext()) { if (it.next() % 2 == 0) it.remove(); } list.removeIf(n -> n > 4);
[1, 2, 3, 4, 5] → 偶数を消して [1, 3, 5] → 4 より大きいものを消して [1, 3]。
出典：API Iterator・ConcurrentModificationException・Collection.removeIf／JDK 17 での実行結果
