UTP ケーブルと RJ-45

UTP の中身：より合わせた 2 本の線が 4 対（Claude が作成）
長さ：銅線のツイストペアは 1 区間 100 m（328 フィート）まで。それより遠い所は光ファイバー。
規格使う対ケーブル
10BASE-T2 対カテゴリ 3・4・5
100BASE-TX2 対カテゴリ 5 が必要
1000BASE-T4 対すべて4 対のカテゴリ 5 以上
10GBASE-T4 対Cisco の SFP+ 品は Cat6A で 30 m
落とし穴：10/100 は 2 対で動くが、1000BASE-T は 4 対すべてを使う。2 対しかつながっていない配線ではギガビットにならない。
カテゴリ＝UTP の品質の等級。数字が大きいほど速い通信に耐える。

SFP（差し込むトランシーバー）ポートに差すモジュールで、光・銅線の種類を選べる。光は LC コネクタ、銅線の 1000BASE-T SFP は RJ-45。

共有メディアと CSMA/CD

ハブ＝受けた信号を全ポートへそのまま出す（Claude が作成）
  1. 聞く（Carrier Sense）：線に信号があれば送らない
  2. 空いていれば送る（Multiple Access：だれでも送れる）
  3. 最初の 64 バイトを送る間に別の信号が聞こえたら衝突と判断（Collision Detection）
  4. バックオフ：ランダムな時間待って送り直す
共有メディア：何台もの機器が 1 本の通り道を分け合う。一度に送れるのは 1 台だけ（半二重）。昔の同軸のバス（10Base5・10Base2）や、ハブを中心にした 10BaseT のスター。
全二重では CSMA/CD を使わない。ポイントツーポイントで衝突が起きないから。
出典：Internetworking Troubleshooting Handbook Ch.4 Troubleshooting Ethernet（Before sending data, CSMA/CD stations "listen" … A collision occurs when two stations listen for network traffic, "hear" none, and transmit simultaneously／If a station "hears" another signal on the wire while transmitting the first 64 bytes of a frame, it should recognize that its frame has collided／When Ethernet is operated in full-duplex mode, CSMA/CD is not used／表 4-3 Topology: Bus・Star）

衝突の回数 n2ⁿ待つスロットタイム

なぜランダム？全員が同じだけ待つと、また同時に送って衝突するから。衝突が重なるほど範囲を広げる。
16 回続けて衝突すると、そのフレームはあきらめて捨てる（Excess-Col）。

半二重全二重

つなぎ方ハブ（共有）1 対 1（スイッチ、またはクロスで直結）

speed・duplex の設定と確かめ方

Switch(config)# interface gigabitethernet1/0/3
Switch(config-if)# speed 100        ! 速度を固定
Switch(config-if)# duplex full      ! 二重モードを固定
! 元に戻すなら
Switch(config-if)# speed auto
Switch(config-if)# duplex auto
書き方意味
speed auto自動交渉（既定）
speed auto 100 1000並べた速度の中でだけ交渉
speed nonegotiateSFP ポート用：交渉しない
duplex half10・100 Mbps のときだけ
Switch# show interfaces fa6/1 status
Port   Name  Status     Vlan  Duplex  Speed  Type
Fa6/1        connected  1     a-full  a-100  10/100BaseTX
「a-」の意味：auto の設定で決まった値。a がなければ手で固定した値。「show interfaces」だけでは、自動で決まったかどうか分からない。
落とし穴：速度を固定すると、速度と二重モードの自動交渉が止まる（Doc 10561）。片側だけ速度を固定すると、もう片側の二重モードが半二重に落ちうる。
設定を変えると、インタフェースが一度落ちて上がることがある（9300 CG の Caution）。
出典：9300 CG 17.9「Setting the Interface Speed and Duplex Parameters」（If you specify a speed and also set the auto keyword, the port autonegotiates only at the specified speeds／The nonegotiate keyword is available only for SFP module ports／Enables half-duplex mode (for interfaces operating only at 10 or 100 Mb/s)／Changing the interface speed and duplex mode configuration might shut down and re-enable the interface）／Doc 10561（If you hard code the speed on a port, it disables all auto-negotiation functionality on the port for speed and duplex／Look for the a prefix）
