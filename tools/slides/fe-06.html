6-1 電気・電子回路電子回路

論理回路ろんりかいろ / Logic Circuit
AND・OR・NOTなどの論理演算を電気信号で行う回路
ポイントNAND回路だけで、ほかのすべての論理回路を作れる
組合せ回路くみあわせかいろ / Combinational Circuit
出力が、今の入力だけで決まる回路
例半加算器、全加算器
順序回路じゅんじょかいろ / Sequential Circuit
出力が、今の入力と過去の状態（記憶）で決まる回路
ポイントフリップフロップが代表例
フリップフロップFlip-flop
0か1の状態を保持できる回路。1ビットを記憶する
ポイントSRAMやレジスタに使われる
半加算器はんかさんき / Half Adder
1桁の2進数どうしを足し、和と桁上がりを出す回路
ポイント和はXOR、桁上がりはANDで作る。全加算器は下の桁からの桁上がりも足す
半導体はんどうたい / Semiconductor
電気を通す導体と通さない絶縁体の中間の性質を持つ物質
ポイントシリコンが代表。トランジスタやICの材料

6-1 電気・電子回路電子回路

ICあいしー / Integrated Circuit
多数のトランジスタなどを1つのチップにまとめた集積回路
Integrated＝集積した／Circuit＝回路
SoCえすおーしー / System on a Chip
CPU・メモリ・入出力など、システムに必要な機能を1つのチップにまとめたもの
ポイントスマートフォンなどに使う
System＝システム／on a Chip＝1つのチップの上に
FPGAえふぴーじーえー / Field Programmable Gate Array
製造した後に、利用者が回路の内容を書き換えられるIC
Field＝現場で／Programmable＝書き換えられる／Gate Array＝ゲート（論理素子）の並び

6-2 機械・制御組込みシステムの部品

組込みシステムくみこみしすてむ / Embedded System
家電や自動車などの機器に組み込まれ、特定の機能を実現するコンピュータシステム
ポイント決められた時間内に処理を終えるリアルタイム性が求められる
センサSensor
温度・光・加速度などの状態を測って、電気信号に変える部品
例加速度センサ、ジャイロセンサ（角速度）、照度センサ
アクチュエータActuator
電気信号を、回転や移動などの物理的な動きに変える部品
例モータ、ソレノイド
ステッピングモータStepping Motor
パルス信号1回ごとに一定の角度だけ回るモータ
ポイント回転角をパルスの数で正確に制御できる
サーボモータServo Motor
位置や速度を検出しながら、指示どおりに動くよう制御されるモータ
PWM制御ぴーだぶりゅーえむせいぎょ / Pulse Width Modulation
信号のオンとオフの時間の比率を変えて、モータの速さや明るさを調整する方式
Pulse＝パルス／Width＝幅／Modulation＝変調

6-3 論理設計回路の設計

真理値表しんりちひょう / Truth Table
入力のすべての組合せと、そのときの出力を表にしたもの
カルノー図Karnaugh Map
論理式を簡単にするための図
ポイント隣り合う1をまとめて項を減らす
回路の簡単化Simplification
同じ働きをする、より少ない部品の回路にすること
例A・B＋A・(NOT B)＝A

6-4 構成部品・消費電力電力と部品

消費電力しょうひでんりょく / Power Consumption
機器が動くのに使う電力
ポイント動いていない部分の電源やクロックを止めると減らせる
クロックゲーティングClock Gating
使っていない回路へのクロックの供給を止めて、消費電力を減らす技術
DVFSでぃーぶいえふえす / Dynamic Voltage and Frequency Scaling
処理の重さに合わせて電圧とクロック周波数を下げ、消費電力を減らす技術
Dynamic＝動的に／Voltage＝電圧／Frequency＝周波数／Scaling＝調整する
バッテリBattery
電気をためて供給する部品
ポイントリチウムイオン電池は繰り返し充電できる二次電池
