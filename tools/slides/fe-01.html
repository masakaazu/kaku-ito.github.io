1-1 離散数学数の表し方

基数きすう / Radix
何進数かを表す数。2進数なら2、16進数なら16
ポイント2進数1桁は0と1、16進数1桁は0〜9とA〜F
2進数にしんすう / Binary Number
0と1の2種類の数字で表す数。コンピュータ内部の表し方
ポイント2進数4桁が16進数1桁にあたる
16進数じゅうろくしんすう / Hexadecimal
0〜9とA〜Fの16種類で表す数
例2進数 1010 1100 ＝ 16進数 AC
補数ほすう / Complement
負の数を表すための考え方。1の補数は全ビット反転、2の補数はさらに1を足したもの
ポイント減算を「2の補数を足す」加算で実現できる。nビットで −2のn−1乗 〜 2のn−1乗−1 を表せる
例8ビットで −5 は 11111011
固定小数点数こていしょうすうてんすう / Fixed-point Number
小数点の位置を決めておいて数を表す方式
ポイント整数の表現に使う
浮動小数点数ふどうしょうすうてんすう / Floating-point Number
符号・仮数部・指数部で数を表す方式。大きな数も小さな数も表せる
例0.75 ＝ 1.1（2進）× 2の−1乗
注IEEE 754 では指数部にバイアス値を足して格納する

1-1 離散数学数の表し方・論理演算と集合

誤差ごさ / Error
計算で生じる本当の値とのずれ
ポイント桁あふれ（オーバフロー）、丸め誤差、桁落ち（近い値の引き算で有効桁が減る）、情報落ち（大きい数に小さい数を足すと消える）を区別
シフト演算しふとえんざん / Shift Operation
ビット列を左右にずらす演算
ポイント左にnビットで2のn乗倍、右にnビットで2のn乗分の1（符号なし）
論理演算ろんりえんざん / Logical Operation
真（1）と偽（0）を使う演算。AND・OR・NOT・XORなど
ポイントXORは「どちらか一方だけ1」のとき1
ド・モルガンの法則De Morgan's Laws
NOT(A AND B) ＝ (NOT A) OR (NOT B)、NOT(A OR B) ＝ (NOT A) AND (NOT B)
ポイント否定を分配すると AND と OR が入れ替わる
ベン図べんず / Venn Diagram
集合どうしの関係を円の重なりで表した図
ポイント論理式とベン図の対応がよく問われる

1-1 離散数学論理演算と集合

逆ポーランド表記法ぎゃくぽーらんどひょうきほう / Reverse Polish Notation
演算子を後ろに書く表し方。スタックを使って左から計算できる
例a+(b×(c−d)) → abcd−×+ 、 3 4 + 5 × → 35
BNF記法びーえぬえふきほう / Backus-Naur Form
プログラム言語などの文法を定義するための記法
ポイント::= で定義、｜ で「または」を表す
Backus＝考案者の名前／Naur＝考案者の名前／Form＝記法

1-2 応用数学確率と統計

順列じゅんれつ / Permutation
いくつかのものを、順序を区別して並べる並べ方の数
例3人を1位・2位・3位に並べる ＝ 3P3 ＝ 6通り
組合せくみあわせ / Combination
順序を区別せずに選ぶ選び方の数
例5人から2人を選ぶ ＝ 5C2 ＝ 10通り
期待値きたいち / Expected Value
起こりうる値に、それぞれの確率を掛けて足したもの。平均的に見込める値
例20%で1万円のくじの期待値は2,000円
平均値・中央値・最頻値へいきんち・ちゅうおうち・さいひんち / Mean, Median, Mode
平均値は合計÷個数、中央値は並べた真ん中、最頻値は最も多い値
ポイント外れ値の影響を受けにくいのは中央値
分散・標準偏差ぶんさん・ひょうじゅんへんさ / Variance, Standard Deviation
データが平均からどれだけ散らばっているかを表す値。標準偏差は分散の平方根
ポイント値が大きいほどばらつきが大きい
正規分布せいきぶんぷ / Normal Distribution
平均を中心に左右対称の釣り鐘型になる分布
ポイント平均±1標準偏差に約68%、±2標準偏差に約95%が入る

1-2 応用数学確率と統計

相関係数そうかんけいすう / Correlation Coefficient
2つの値の関係の強さを −1〜1 で表す値
ポイント1に近いほど正の相関、−1に近いほど負の相関。相関があっても因果関係とは限らない
回帰分析かいきぶんせき / Regression Analysis
ある値から別の値を予測する式を求める分析
例広告費から売上を予測する
主成分分析しゅせいぶんぶんせき / Principal Component Analysis
多くの変数を、少数の総合的な指標にまとめる分析
ポイントクラスター分析は似たもの同士をグループ分けする
待ち行列理論まちぎょうれつりろん / Queueing Theory
窓口などで待ち時間がどれくらいになるかを計算する理論。M/M/1モデルが基本
ポイント利用率 ρ ＝ 平均到着率 × 平均サービス時間。平均待ち時間 ＝ ρ÷(1−ρ) × サービス時間
グラフ理論ぐらふりろん / Graph Theory
点（ノード）と線（エッジ）で、ものどうしのつながりを表す数学
ポイント最短経路問題などに使う

1-3 情報に関する理論符号化と単位

SI接頭語えすあいせっとうご / SI Prefix
大きさを表す単位の頭につける記号
ポイントk＝10の3乗、M＝10の6乗、G＝10の9乗、T＝10の12乗。m＝10の−3乗、μ＝10の−6乗、n＝10の−9乗、p＝10の−12乗
SI＝Système International（国際単位系）
ビット・バイトBit, Byte
ビットは0か1の1桁、バイトは8ビット
ポイントnビットで2のn乗通りを表せる
ハフマン符号化はふまんふごうか / Huffman Coding
よく出る文字に短いビット列、まれな文字に長いビット列を割り当てて、平均のデータ量を減らす符号化
ポイント可逆圧縮の一種
文字コードもじこーど / Character Code
文字に割り当てた番号の決まり
ポイントASCII（英数字7ビット）、Unicode（世界の文字を1つの体系に）、UTF-8 は Unicode の符号化方式の1つ
アナログデータ・ディジタルデータAnalog / Digital Data
アナログは連続した量、ディジタルは飛び飛びの数値で表したデータ
ポイント音や画像をディジタル化して扱う

1-3 情報に関する理論AI（人工知能）

機械学習きかいがくしゅう / Machine Learning
データから規則やパターンをコンピュータに学ばせる技術
ポイント教師あり学習・教師なし学習・強化学習の3つに分かれる
教師あり学習きょうしありがくしゅう / Supervised Learning
正解ラベルの付いたデータで学習する方法
例迷惑メールかどうかの分類、売上の予測
教師なし学習きょうしなしがくしゅう / Unsupervised Learning
正解ラベルのないデータから、構造や似たまとまりを見つける方法
例似た顧客のグループ分け（クラスタリング）
強化学習きょうかがくしゅう / Reinforcement Learning
試行錯誤して、報酬が最大になる行動を学ぶ方法
例ゲームやロボットの制御
過学習かがくしゅう / Overfitting
学習データには合いすぎるが、新しいデータでは精度が低くなる状態
ポイント学習データを増やす、モデルを単純にするなどで防ぐ
転移学習てんいがくしゅう / Transfer Learning
ある課題で学習したモデルを、別の関連する課題に使い回す方法
ポイント少ないデータでも学習しやすい

1-3 情報に関する理論AI（人工知能）

ディープラーニングDeep Learning
何層にも重ねたニューラルネットワークで学習する機械学習
ポイント特徴を人が決めなくても自動で見つけられる
ニューラルネットワークNeural Network
人の脳の神経細胞のつながりをまねた計算の仕組み
ポイント入力層・中間層（隠れ層）・出力層からなる
活性化関数かっせいかかんすう / Activation Function
ニューロンで、入力の重み付き和を次へ渡す出力値に変換する関数
ポイント非線形にすることで、直線では分けられない複雑な境界を学習できる
ReLU関数れるかんすう / Rectified Linear Unit
負の入力は0、正の入力はそのまま出す活性化関数
ポイントf(x)＝max(0, x)。例: x＝−2 なら 0
Rectified＝整流された（負を切る）／Linear＝線形の／Unit＝素子
シグモイド関数Sigmoid Function
出力を0〜1に収めるS字の活性化関数
ポイント確率のように扱いやすい。tanh関数は−1〜1に収める

1-4 通信に関する理論信号の変換

PCMぴーしーえむ / Pulse Code Modulation
音などのアナログ信号を、標本化・量子化・符号化の3段階でディジタルにする方式
ポイント標本化＝一定間隔で値を取る、量子化＝段階的な数値に丸める、符号化＝2進数にする
Pulse＝パルス（信号の山）／Code＝符号／Modulation＝変調
標本化定理ひょうほんかていり / Sampling Theorem
元の信号の最高周波数の2倍以上の頻度で標本化すれば、元の信号を再現できるという定理
ポイントサンプリング周波数を考える問題で使う
伝送誤りでんそうあやまり / Transmission Error
通信の途中でビットが変わってしまうこと
ポイントパリティチェックやCRCで検出、ハミング符号は1ビットの誤りを訂正できる

1-5 計測・制御に関する理論制御の方式

フィードバック制御Feedback Control
結果を測って目標との差を求め、その差がなくなるように調整する制御
例室温を測ってエアコンの出力を調整する
フィードフォワード制御Feedforward Control
外からの乱れを先に予測し、結果に影響が出る前に調整する制御
ポイントフィードバックは「後から直す」、フィードフォワードは「先回りする」
シーケンス制御Sequence Control
あらかじめ決めた順序に従って、段階的に動作を進める制御
例洗濯機、信号機
センサ・アクチュエータSensor, Actuator
センサは温度や光などの状態を測る部品、アクチュエータは電気信号を動きに変える部品
ポイントIoT機器の基本の組合せ
A/D変換えーでぃーへんかん / Analog-to-Digital Conversion
センサが測ったアナログの値をディジタルの値に変えること
ポイント逆はD/A変換
