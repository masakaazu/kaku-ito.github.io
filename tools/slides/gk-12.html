LSTM と GRU

LSTM（1997年）GRU（2014年）
ゲート入力・忘却（1999年に追加）・出力更新・リセット（出力ゲートなし）

Seq2Seq から Attention へ

Seq2Seq（2014）エンコーダの LSTM → 固定長ベクトル → デコーダの LSTM
固定長のベクトルがボトルネック。長い文で性能が落ちる。
↓ Bahdanau ほか（2014）
Attention つき出力を作るたびに、入力のどこに注目するかを重みで選ぶ
要素役割
クエリ Q何を探しているか
キー K見出し。Q との一致度 → ソフトマックスで重み
バリュー V中身。重み付き和をとる
重みは入力ごとに変わる「ソフトウェイト」。
出典：Bahdanau ほか『we conjecture that the use of a fixed-length vector is a bottleneck in improving the performance of this basic encoder-decoder architecture』／ウィキペディア「アテンション」
