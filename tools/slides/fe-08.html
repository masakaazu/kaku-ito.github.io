8-1 マルチメディア技術画像と色

画素ピクセル / Pixel
画像を構成するいちばん小さな点
画像データ量がぞうでーたりょう / Image Data Size
横の画素数 × 縦の画素数 × 1画素あたりのビット数
例800×600画素・24ビットなら 11,520,000ビット
光の三原色RGB / Red, Green, Blue
赤・緑・青の光を混ぜて色を作る方法。画面の表示に使う
ポイント全部混ぜると白。印刷は色の三原色（シアン・マゼンタ・イエロー）で、全部混ぜると黒に近くなる
フルカラーFull Color
RGBそれぞれ8ビット、計24ビットで約1,677万色を表す方式
ベクター形式・ラスター形式Vector / Raster
ベクターは線や図形を数式で記録、ラスターは画素の並びで記録
ポイントベクターは拡大しても粗くならない
解像度かいぞうど / Resolution
画像の細かさ。画素の数で表す

8-1 マルチメディア技術圧縮

可逆圧縮かぎゃくあっしゅく / Lossless Compression
元のデータに完全に戻せる圧縮
例PNG、GIF、ZIP
非可逆圧縮ひかぎゃくあっしゅく / Lossy Compression
元のデータに完全には戻らないが、大きく小さくできる圧縮
例JPEG、MPEG、MP3
BMPびっとまっぷ / Bitmap
画素の情報を圧縮せずにそのまま記録する静止画の形式
Bit＝ビット／Map＝配置図
GIFじふ / Graphics Interchange Format
256色までの可逆圧縮の静止画形式。簡単なアニメーションもできる
Graphics＝画像／Interchange＝交換用の／Format＝形式
PNGぴんぐ / Portable Network Graphics
フルカラーを扱える可逆圧縮の静止画形式。透過もできる
Portable＝持ち運べる／Network＝ネットワーク向けの／Graphics＝画像
JPEGじぇいぺぐ / Joint Photographic Experts Group
写真に向く非可逆圧縮の静止画形式
ポイント圧縮率を選べる
Joint＝合同の／Photographic＝写真の／Experts Group＝専門家の会（規格を作った団体名）
基本情報 情報メディア5

8-1 マルチメディア技術圧縮・音

MPEGえむぺぐ / Moving Picture Experts Group
動画と音声を圧縮する国際標準規格
ポイントMPEG-2はDVD・放送、MPEG-4はネット配信など
Moving Picture＝動く画像（動画）／Experts Group＝専門家の会
MP3えむぴーすりー / MPEG-1 Audio Layer-3
音声を圧縮する形式。聞こえにくい音を省いて小さくする
MPEG-1＝動画規格の名前／Audio＝音声／Layer-3＝第3層
PCMぴーしーえむ / Pulse Code Modulation
アナログの音を標本化・量子化・符号化してディジタルにする方式
ポイント量子化ビット数が多いほど、標本化周波数が高いほど音質がよく、データ量も増える
Pulse＝パルス／Code＝符号／Modulation＝変調
音声のデータ量おんせいのでーたりょう / Audio Data Size
標本化周波数 × 量子化ビット数 × チャンネル数 × 秒数
例44.1kHz・16ビット・ステレオ・1秒 ＝ 約1.4Mビット

8-1 マルチメディア技術音

MIDIみでぃ / Musical Instrument Digital Interface
電子楽器の演奏情報（音の高さ・長さなど）をやり取りする規格
ポイント音そのものではなく演奏の命令を記録するので、データ量が小さい
Musical Instrument＝楽器／Digital＝ディジタル／Interface＝接続規格

8-2 マルチメディア応用仮想と現実

ARえーあーる / Augmented Reality
現実の風景に、コンピュータで作った情報を重ねて見せる技術。拡張現実
例カメラ越しに道案内を表示
Augmented＝拡張された／Reality＝現実
VRぶいあーる / Virtual Reality
コンピュータで作った仮想の世界に、入り込んだように感じさせる技術。仮想現実
Virtual＝仮想の／Reality＝現実
MRえむあーる / Mixed Reality
現実と仮想を融合させ、仮想の物に触れるように操作できる技術。複合現実
Mixed＝混ぜ合わせた／Reality＝現実
CGしーじー / Computer Graphics
コンピュータで画像や映像を作る技術
ポイントレンダリングは、データから画像を作り出す処理
Computer＝コンピュータ／Graphics＝画像
メタバースMetaverse
インターネット上に作られた、多くの人が参加できる3次元の仮想空間
ストリーミングStreaming
動画や音声を、受け取りながら同時に再生する方式
ポイント全部ダウンロードし終わるのを待たずに見られる
