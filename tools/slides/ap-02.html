2-1 データ構造データ構造

配列Array
同じ型のデータを連続した場所に並べたもの
ポイント添字で直接アクセスできるが、途中への挿入は遅い
スタックStack
最後に入れたデータを最初に取り出す構造（LIFO）
ポイント関数呼出しの戻り先や、逆ポーランド記法の計算に使う
キューQueue
最初に入れたデータを最初に取り出す構造（FIFO）
ポイント待ち行列やバッファに使う
連結リストLinked List
各要素が次の要素へのポインタを持つ構造
ポイント単方向・双方向・循環がある
2分探索木Binary Search Tree
左の部分木の値＜節の値＜右の部分木の値となる2分木
ポイント偏ると探索が遅くなるため、AVL木など平衡木を使う
完全2分木Complete Binary Tree
最下段以外がすべて埋まり、最下段は左から詰まっている2分木
応用情報 アルゴリズムとプログラミング4

2-1 データ構造データ構造・木のなぞり方

ヒープHeap
親の値が子の値以上（または以下）になる完全2分木
ポイント最大値（最小値）がすぐ取り出せる
B木B-tree
1つの節に多くのキーを持つ平衡多分木
ポイントディスク上のデータベースの索引に使う
ハッシュ表Hash Table
ハッシュ関数でキーから格納位置を決める表
ポイント位置がぶつかること（衝突・シノニム）への対策が必要
グラフGraph
頂点と辺で、ものどうしのつながりを表す構造
ポイント隣接行列や隣接リストで表す
深さ優先探索DFS / Depth-First Search
行けるところまで深く進み、行き止まりで戻る探索
ポイント前順・間順・後順のなぞり方がある
幅優先探索BFS / Breadth-First Search
出発点に近い頂点から順に調べる探索
ポイント最短の手数を求めるのに向く

2-2 アルゴリズム探索と整列

線形探索Linear Search
先頭から順に1つずつ調べる探索
ポイント計算量 O(n)。番兵を置くと終了判定が減る
2分探索Binary Search
整列済みのデータを半分に分けながら調べる探索
ポイント計算量 O(log n)。最大の比較回数は約 log2 n ＋1
クイックソートQuick Sort
基準値（ピボット）より小さいグループと大きいグループに分け、再帰的に整列する
ポイント平均は速いが、最悪 O(n²)
マージソートMerge Sort
データを半分ずつに分けて整列し、併合（マージ）する
ポイント常に O(n log n)。安定な整列
安定な整列Stable Sort
同じ値のデータの並び順が、整列の前後で変わらない整列
計算量Computational Complexity
アルゴリズムの処理の手間を、データ量nの関数で表したもの
ポイントO記法で表す

2-2 アルゴリズムいろいろなアルゴリズム

再帰Recursion
関数が自分自身を呼び出すこと
ポイント終了条件が必要。例: 階乗、ハノイの塔
動的計画法Dynamic Programming
小さな問題の答えを表に記録し、それを使って大きな問題を解く方法
ポイント同じ計算を繰り返さない
ダイクストラ法Dijkstra's Algorithm
重みが0以上のグラフで、最短経路を求める方法
ポイントネットワークの経路選択（OSPF）にも使う
ユークリッドの互除法Euclidean Algorithm
2つの数の最大公約数を、割り算の余りを繰り返して求める方法
逆ポーランド記法後置記法 / Reverse Polish Notation
演算子を後ろに書く記法
例(A＋B)×C は AB＋C×。スタックで計算できる
応用情報 アルゴリズムとプログラミング8

2-3 プログラミングプログラムの性質

再入可能リエントラント / Reentrant
複数のプロセスから同時に呼ばれても正しく動くプログラム
ポイントデータをプロセスごとに分けて持つ
再使用可能Reusable
一度実行したあと、読み込み直さずに再び実行できるプログラム
再帰的Recursive
実行中に自分自身を呼び出せるプログラム
再配置可能Relocatable
主記憶のどこに置いても実行できるプログラム
コーディング規約Coding Standards
プログラムの書き方をそろえるための決まり
ポイント読みやすさと保守のしやすさを上げる

2-4 プログラム言語言語の種類

手続型言語Procedural Language
処理の手順を順に書いていく言語
例C、COBOL
オブジェクト指向言語Object-Oriented Language
データと処理をまとめたオブジェクトを組み合わせて作る言語
例Java、C++、Python
関数型言語Functional Language
関数の組合せでプログラムを作る言語
ポイント副作用を避ける。例: Haskell
論理型言語Logic Programming Language
事実と規則を書き、問合せに答えを推論させる言語
例Prolog
スクリプト言語Script Language
コンパイルせずにインタプリタで手軽に実行できる言語
例JavaScript、Python
