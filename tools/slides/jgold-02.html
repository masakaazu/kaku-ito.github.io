ジェネリック型を実装する

interface Animal<T> { T speak(T t); } class Dog implements Animal<String> { public String speak(String s) { // ○ return s + s; } }
型引数を当てはめた形 speak(String) で書く。speak(Object) との橋渡しはコンパイラのブリッジメソッド。
class Dog implements Animal<String> { public Object speak(Object s) { ... } // × }
speak(String) を実装していない＋同じイレイジャで衝突（name clash）の 2 つのエラー。
record Pair<K, V>(K first, V second) { Pair<V, K> swap() { return new Pair<>(second, first); } }

読むなら extends、入れるなら super。

ワイルドカードでできること

型add できるものget の型代入できる List
List<Number>Number とその子NumberList<Number> だけ
List<? extends Number>null だけNumberList<Integer>・List<Double>…
List<? super Integer>Integer とその子ObjectList<Integer>・<Number>・<Object>
List<?>null だけObjectどの List でも
static void copy(List<? super Number> dst, List<? extends Number> src) { dst.addAll(src); }
PECS：Producer Extends, Consumer Super。値を出す引数は extends、値を入れる引数は super。両方するなら List<T>。
