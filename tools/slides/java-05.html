整数の / は 0 の方向に切り捨てる（Claude が作成）
余りの決まり：(a / b) * b + (a % b) が a に戻る。だから余りの符号は左（割られる数）と同じ。

評価の順序 ― 左のオペランドが先

三項演算子

int x = 7;
String s = x > 5 ? "big" : x > 2 ? "mid" : "small";
// x > 5 ? "big" : (x > 2 ? "mid" : "small") → big

int y = 0;
int z = true ? y++ : y--;   // y-- は計算しない
// y は 1、z は 0
NG（JDK 17 の表示）
x > 2 ? System.out.println("a") : System.out.println("b");
// not a statement
String t = x > 2 ? "ok" : 5;
// bad type in conditional expression
2 つの値の型式全体の型（例と結果）
同じ型その型
int と doubledouble：true ? 1 : 2.0 → 1.0
char と char に入る int の定数char：false ? 'a' : 98 → b
String と intObject などの参照型（String の変数には入らない）
式なので値が必要。単独の文にできず、void のメソッドも書けない。処理を分けるなら if 文。
選ばれなかった側は計算されない。++ や メソッド呼び出しがあっても実行されない。
出典：JLS 15.25 Conditional Operator ? :（The conditional operator is syntactically right-associative／It is a compile-time error for either the second or the third operand expression to be an invocation of a void method／The operand expression not chosen is not evaluated）・15.25.2 Numeric Conditional Expressions／結果は JDK 17 で確かめたもの

問われ方とまちがえやすい点
