ファイル名から作る手順
① .jar を取る
② 末尾の「-数字…」をバージョンとして外す
③ 英数字以外をドットに
④ ドットの連続を 1 つに、前後のドットを取る
マニフェストの Automatic-Module-Name があれば、そちらが優先。

ボトムアップとトップダウン

ボトムアップ（依存される側から）
app.jarまだ → クラスパス（無名）
↓ 使う

↓ 使う
util最初にモジュール化

トップダウン（アプリから）
com.appmodule-info を足した
↓ requires my.util;
my-util.jarまだ → モジュール・パスに置いて自動モジュール
自分で直せないライブラリがあるときに向く。

3 つのモジュールの役割

module svc.api { // SPI exports svc.api; } module svc.impl { // プロバイダ requires svc.api; provides svc.api.Greeter with svc.impl.Polite, svc.impl.Casual; } module svc.app { // 使う側 requires svc.api; uses svc.api.Greeter; }
svc.apiGreeter（インタフェース）
svc.impl実装を provides
svc.appuses して ServiceLoader で取り出す
svc.app は svc.impl を requires しない。svc.impl は実装のパッケージを exports しない（contains svc.impl）。
出典：JLS 7.7.3 Service Consumption・7.7.4 Service Provision／java --describe-module の結果

ServiceLoader

ServiceLoader<Greeter> sl = ServiceLoader.load(Greeter.class); for (Greeter g : sl) println(g.greet("A") + " " + simpleName); // Hello, A Polite // [provider]Hi A Casual ← provider() が呼ばれた sl.stream().map(p -> p.type().getSimpleName()).toList() // [Polite, Casual] ← type() はインスタンスを作らない ServiceLoader.load(Greeter.class).findFirst() // Optional
