21-1 ビジネスシステム身近なシステム

POSシステムPoint Of Sale System
商品が売れたときに、その情報をその場で集める仕組み
ポイント売れ筋の分析や在庫の管理に使う
Point＝地点／Of Sale＝販売の
トレーサビリティTraceability
商品が、いつ・どこで・誰によって作られ運ばれたかを追いかけられること
例食品の産地の確認
RFIDあーるえふあいでぃー / Radio Frequency Identification
電波を使って、ICタグの情報を触れずに読み書きする技術
Radio Frequency＝無線の周波数／Identification＝識別
GISじーあいえす / Geographic Information System
地図の上に、位置と結びついたいろいろな情報を重ねて表示・分析する仕組み
Geographic＝地理の／Information＝情報／System＝仕組み
HRテックHR Tech
AIやクラウドを使って、採用・人事評価・勤怠などの人事の仕事を効率化すること
HR＝Human Resources（人材）／Tech＝技術
フィンテックFinTech
ITを使った新しい金融サービス
例スマートフォン決済
Finance＝金融／Technology＝技術

21-2 エンジニアリングシステム生産の仕組み

CADきゃど / Computer Aided Design
コンピュータを使って設計や製図をすること
Computer＝コンピュータ／Aided＝助けられた／Design＝設計
CAMきゃむ / Computer Aided Manufacturing
CADの設計データをもとに、コンピュータで工作機械を動かして製造すること
Aided＝助けられた／Manufacturing＝製造
MRPえむあーるぴー / Material Requirements Planning
生産計画と部品表（BOM）から、必要な資材の量と時期を計算する方法。資材所要量計画
Material＝資材／Requirements＝必要量／Planning＝計画
JITじぇいあいてぃー / Just In Time
必要な物を、必要なときに、必要なだけ作ったり届けたりする考え方
ポイント在庫を減らせる。かんばん方式で実現する
Just＝ちょうど／In Time＝間に合って
かんばん方式Kanban System
後の工程が、使った分だけ前の工程に「かんばん」で注文する方式
ポイントJITを実現する方法
セル生産方式Cell Production
1人または少人数のチームが、製品の組立てを最初から最後まで行う方式
ポイント多品種少量の生産に向く
基本情報 ビジネスインダストリ5

21-3 e-ビジネス電子商取引

ECいーしー / Electronic Commerce
インターネットを使って商品やサービスを売買すること。電子商取引
ポイントBtoB・BtoC・CtoCなどの形がある
Electronic＝電子の／Commerce＝商取引
EDIいーでぃーあい / Electronic Data Interchange
企業どうしの受発注や請求などの取引データを、決まった形式で電子的にやり取りすること
Electronic＝電子の／Data＝データ／Interchange＝交換
ロングテールLong Tail
あまり売れない多くの商品の売上を合わせると、売れ筋の商品の売上より大きくなること
ポイントネットショップは在庫の場所の制約が小さいので起こりやすい
オムニチャネルOmni-channel
店舗・ネット・アプリなどの販売の経路をつなげ、顧客がどこからでも同じように買えるようにすること
O2Oおーつーおー / Online to Offline
ネット上での情報やクーポンで、実際の店に客を呼ぶこと
Online＝ネット上／to＝〜へ／Offline＝実店舗
基本情報 ビジネスインダストリ7

21-3 e-ビジネス電子商取引

シェアリングエコノミーSharing Economy
個人が持っている物や場所、スキルを、ネットを通じてほかの人と共有する経済の仕組み
クラウドファンディングCrowdfunding
ネットを通じて、多くの人から少しずつ資金を集めること
エスクローサービスEscrow Service
売り手と買い手の間に第三者が入り、代金の受け渡しを仲介する仕組み
ポイント取引を安全にする

21-4 民生機器家庭の機器

IoTあいおーてぃー / Internet of Things
いろいろな物がインターネットにつながり、情報をやり取りする仕組み
例設備にセンサを付けて遠くから監視する
Internet＝インターネット／of Things＝物の
組込みシステムEmbedded System
家電や機械に組み込まれて、特定の機能を制御するコンピュータシステム
HEMSへむす / Home Energy Management System
家庭の電気の使用量を見える化し、家電を制御して省エネをする仕組み
Home＝家庭／Energy＝エネルギー／Management＝管理／System＝仕組み
スマートグリッドSmart Grid
ITを使って電気の流れを需要と供給の両方から制御する、次世代の送電網
