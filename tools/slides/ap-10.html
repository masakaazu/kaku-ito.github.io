10-1 ネットワーク方式ネットワークの形

LAN・WANLocal / Wide Area Network
LANは建物の中などの狭い範囲、WANは離れた場所をつなぐ広い範囲のネットワーク
Local＝構内の／Wide＝広い／Area＝範囲／Network＝網
無線LANWireless LAN
電波でつなぐLAN
ポイントIEEE 802.11。暗号化はWPA3。衝突を避けるCSMA/CA方式
5G第5世代移動通信システム
高速大容量・超低遅延・多数同時接続が特徴の移動通信
ポイントローカル5Gは企業が自分の敷地で使う
LPWAえるぴーだぶりゅーえー / Low Power Wide Area
少ない電力で広い範囲を通信できる方式。速度は遅い
ポイントIoTのセンサに向く
Low Power＝低消費電力／Wide Area＝広い範囲
SDNえすでぃーえぬ / Software-Defined Networking
ネットワークの制御をソフトウェアで集中して行う考え方
ポイント制御（コントロールプレーン）と転送（データプレーン）を分ける。OpenFlowが代表
Software＝ソフトウェア／Defined＝定義された／Networking＝ネットワーク

10-2 データ通信と制御通信の制御

伝送時間Transmission Time
データ量 ÷（回線速度 × 伝送効率）
CSMA/CDCarrier Sense Multiple Access with Collision Detection
送信前に回線を確かめ、衝突したら待って送り直す有線LANの方式
CSMA/CACarrier Sense Multiple Access with Collision Avoidance
衝突を避けるために、待ち時間をおいて送る無線LANの方式
MACアドレスMedia Access Control Address
ネットワーク機器に付けられた48ビットの固有の番号
ポイント先頭24ビットはメーカーの番号（OUI）
VLANぶいらん / Virtual LAN
物理的なつながりとは別に、論理的にLANを分ける技術
Virtual＝仮想の／LAN＝構内網
スパニングツリープロトコルSTP / Spanning Tree Protocol
スイッチのループ（輪）を見つけて、一部のポートを止めてループを防ぐ方式

10-3 通信プロトコルTCP/IP

TCP/IPTransmission Control Protocol / Internet Protocol
インターネットで使う4階層のプロトコル群
ポイントアプリケーション層・トランスポート層・インターネット層・ネットワークインタフェース層
TCP・UDPTransmission Control Protocol / User Datagram Protocol
TCPはコネクションを作り、届いたかを確かめる信頼性の高い通信。UDPは確認をせず速い通信で、動画・音声やDNSに使う
3ウェイハンドシェイク3-way Handshake
TCPで接続を始めるときの3回のやり取り（SYN → SYN/ACK → ACK）
IPv4アドレスとサブネットマスクSubnet Mask
IPアドレスのうちネットワーク部とホスト部の境目を示す値
ポイント/24なら使えるホストは 2^8 − 2 ＝ 254台
CIDRさいだー / Classless Inter-Domain Routing
クラスにとらわれず、ネットワーク部の長さを自由に決める方式
例192.168.1.0/24
Classless＝クラスのない／Inter-Domain＝ドメイン間の／Routing＝経路制御
応用情報 ネットワーク7

10-3 通信プロトコルTCP/IP

IPv6Internet Protocol version 6
128ビットのアドレスを使うIP
ポイントアドレスが足りない問題を解決する。16ビットずつ16進数で8つに区切って書く
NAT・NAPTNetwork Address Translation / Network Address Port Translation
プライベートIPアドレスとグローバルIPアドレスを変換するしくみ
ポイントNAPTはポート番号も変換し、1つのグローバルアドレスを複数の端末で使える
ARPあーぷ / Address Resolution Protocol
IPアドレスからMACアドレスを調べるプロトコル
Address＝アドレス／Resolution＝解決／Protocol＝通信規約
ICMPあいしーえむぴー / Internet Control Message Protocol
通信の誤りや状態を知らせるプロトコル
ポイントping や traceroute が使う
Internet＝インターネット／Control＝制御／Message＝通知
DHCPでぃーえいちしーぴー / Dynamic Host Configuration Protocol
端末にIPアドレスなどの設定を自動で配るプロトコル
Dynamic＝動的な／Host＝端末／Configuration＝設定

10-3 通信プロトコルTCP/IP

DNSでぃーえぬえす / Domain Name System
ドメイン名とIPアドレスを対応付けるしくみ
Domain Name＝ドメイン名／System＝仕組み
HTTP・HTTPSHyperText Transfer Protocol / Secure
Webのやり取りのプロトコル。HTTPSはHTTPをTLSで暗号化したもの
ポイント要求（リクエスト）と応答（レスポンス）を繰り返す。状態を持たないのでCookieで状態を管理する
SMTP・POP3・IMAP4
SMTPはメールの送信と転送、POP3はメールを端末に取り込む受信、IMAP4はメールをサーバに置いたまま見る受信
カプセル化Encapsulation
送信するとき、上の層のデータに下の層のヘッダを順に付けていくこと
ポイント受け取る側は逆に外していく

10-4 ネットワーク管理管理の道具

SNMPえすえぬえむぴー / Simple Network Management Protocol
ネットワーク機器の状態を集めて管理するプロトコル
ポイントマネージャがエージェントに問い合わせる。異常はトラップで知らせる
Simple＝簡単な／Network Management＝ネットワーク管理／Protocol＝規約
ping・traceroute
ping はICMPで相手に届くかを確かめるコマンド、traceroute は経路上のルータを調べるコマンド
NTPえぬてぃーぴー / Network Time Protocol
機器の時刻を合わせるプロトコル
ポイントログの時刻をそろえるのに大事
Network＝ネットワーク／Time＝時刻／Protocol＝規約
障害の切り分けTroubleshooting
層ごとに確かめて原因の場所を絞ること
ポイントping（3層）が通るのにWebだけ見られないなら、4層以上（ポートやファイアウォール）を疑う

10-5 ネットワーク応用応用

VPNぶいぴーえぬ / Virtual Private Network
公衆の回線の上に、暗号化した専用線のような通信路を作る技術
ポイントIPsec VPN・SSL/TLS VPNがある
Virtual＝仮想の／Private＝専用の／Network＝網
CDNしーでぃーえぬ / Content Delivery Network
利用者の近くのサーバ（キャッシュ）からコンテンツを配信して、速くするしくみ
Content＝内容／Delivery＝配送／Network＝網
プロキシサーバProxy Server
内部の端末の代わりに外部のWebサーバへアクセスするサーバ
ポイントキャッシュやアクセス制限に使う
IoTネットワークIoT Network
多くの機器をつなぐネットワーク
ポイントMQTTなど軽いプロトコルを使う
