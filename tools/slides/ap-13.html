ウォーターフォールモデルWaterfall Model

プロトタイピングモデルPrototyping Model

スパイラルモデルSpiral Model

13-1 開発プロセス・手法開発モデルと手法

ベロシティVelocity
1回のスプリントで終えた作業の量
ポイント次の計画に使う
DevOpsでぶおぷす / Development and Operations
開発と運用が協力し、速く確実にリリースする考え方
Development＝開発／Operations＝運用
CI/CDContinuous Integration / Continuous Delivery
変更を頻繁に統合して自動でテストし、いつでもリリースできる状態に保つこと
Continuous＝継続的な／Integration＝統合／Delivery＝提供
共通フレームSLCP-JCF
ソフトウェアの開発から廃棄までの作業と用語の意味をそろえた枠組み
CMMIしーえむえむあい / Capability Maturity Model Integration
組織の開発プロセスの成熟度を5段階で評価するモデル
Capability＝能力／Maturity＝成熟度／Model＝模型／Integration＝統合
マッシュアップMashup
公開されている複数のWeb APIを組み合わせて、新しいサービスを作ること

13-2 知的財産適用管理権利の管理

ソフトウェアの著作権Copyright of Software
プログラムは著作物として守られる
ポイントアルゴリズムやプログラム言語、規約は守られない
特許とソフトウェアSoftware Patent
ソフトウェアのアイデアも、条件を満たせば特許になる
ライセンス管理License Management
使っているソフトウェアのライセンスの数や条件を管理すること
ポイントOSSのライセンス条件も確かめる
