文章の表し方

手法中身弱点
ワンホット語彙の数の次元で、その単語だけ 1次元が巨大。意味の近さを表せない
BoW単語の出現回数の袋語順を無視
n-gram隣り合う n 個のまとまりn が大きいと組み合わせが爆発
TF-IDFその文書で多く、ほかの文書で少ない語を重く意味の近さは表せない
分散表現低い次元の実数ベクトル。近い意味は近いベクトル―

word2vec：CBOW と skip-gram

CBOW周りの単語 → まん中の単語（穴うめ）。速い
skip-gramまん中の単語 → 周りの単語。まれな単語に強い
負例サンプリングで学習を速くする。
fastText単語＝文字 n-gram の袋。知らない単語・まれな単語に強い
skip-gram と n-gram は名前が似ているが別物。
出典：ウィキペディア英語版「Word2vec」『In the continuous skip-gram architecture, the model uses the current word to predict the surrounding window of context words.』／Bojanowski ほか（fastText）

文脈を使う言語モデル

モデル中身
ELMo（2018）双方向 LSTM の言語モデル。文脈で変わる表現（多義語）
BERT（2018）Transformer エンコーダ。左右両方の文脈。MLM・NSP で事前学習 → ファインチューニング
GPTTransformer デコーダ。次の単語を予測。GPT-3 は few-shot
LLM億・兆のパラメータ。PaLM は 5,400 億
GLUE自然言語理解をいろいろなタスクで評価するベンチマーク
出典：Devlin ほか（BERT）『BERT is designed to pre-train deep bidirectional representations from unlabeled text by jointly conditioning on both left and right context in all layers.』
