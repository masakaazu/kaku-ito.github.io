Comparator の向きに注意
s = Stream.of(5,3,8) s.max(Integer::compare) // 8 s.max((x, y) -> y - x) // 3 s.min(Comparator.reverseOrder()) // 8 Stream.of("a","b") .max(comparing(String::length)) // a（同点は先）

anyMatch・allMatch・noneMatch

メソッド止まるとき0 個のとき
anyMatchtrue の要素が見つかったfalse
allMatchfalse の要素が見つかったtrue
noneMatchtrue の要素が見つかったtrue
0 個のとき：「全部が条件を満たす」「1 つもない」は反例がないので true。
Stream.of(1,2,3,4).peek(print).anyMatch(n -> n > 1) // 12true Stream.of(1,2,3,4).peek(print).allMatch(n -> n < 3) // 123false Stream.iterate(1, n -> n + 1).anyMatch(n -> n > 3) // true（無限でも終わる） Stream.iterate(1, n -> n + 1).noneMatch(n -> n == 5) // false（5 で止まる）

作る・調べる

Optional.of("x") // Optional[x] Optional.of((String) null) // NullPointerException Optional.ofNullable(null) // Optional.empty Optional.empty() // Optional.empty Optional.empty().isPresent() // false Optional.empty().isEmpty() // true（Java 11〜） Optional.empty().get() // NoSuchElementException
Optional.of("a").ifPresentOrElse( s -> print("has " + s), // 値あり → Consumer () -> print("none")); // 空 → Runnable Optional.empty().ifPresent(s -> print("X")); // 何もしない
isPresent は boolean を返す。ifPresent は void で処理を実行する。
ifPresentOrElse・or・stream は Java 9、orElseThrow() は Java 10、isEmpty は Java 11。

取り出す：orElse と orElseGet

変換する：map・flatMap・filter・or・stream

Optional<String> o = Optional.of(" ab "); o.map(String::trim) .filter(s -> s.length() > 1) .map(String::length) // Optional[2] o.filter(String::isEmpty).map(String::length) // Optional.empty Optional.of("x").map(s -> null) // Optional.empty Optional<Integer> r = o2.map(s -> Optional.of(1)); // × 結果は Optional<Optional<Integer>> Optional<Integer> r = o2.flatMap(s -> Optional.of(1)); // ○
Optional.empty() .or(() -> Optional.of("b")) // Optional[b] Optional.of("a") .or(() -> Optional.of("b")) // Optional[a] List.of(Optional.of("a"), Optional.empty(), Optional.of("c")) .stream() .flatMap(Optional::stream) // a, c
