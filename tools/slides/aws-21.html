DataSync の 4 つの設定と働き

しくみ内容選ぶ言葉

出典：Amazon S3 ファイルゲートウェイとは（「Amazon S3 のデータには、任意の AWS クラウドアプリケーションまたはサービスから直接アクセスできます。」）／Amazon FSx ファイルゲートウェイとは（「VPN または Direct Connect 接続を介して、FSx for Windows File Server へのオンプレミスアクセスも必要です。」）／テープゲートウェイについて（「テープゲートウェイは、クラウドベースの仮想テープストレージを提供します。」）

ボリュームゲートウェイ：キャッシュ型 と 保管型

スナップショット：前回から変わったデータだけを保存する増分のバックアップ。S3 に EBS スナップショットとしても保存されるので、オンプレミスにも EC2 にも復元できる。
ひっかけ：「オンプレミスの容量が足りない」→ キャッシュ型。「データ全体に低いレイテンシー」→ 保管型。逆にすると要件を満たさない。
出典：ボリュームゲートウェイについて（「**キャッシュ型ボリューム** – データを Amazon Simple Storage Service (Amazon S3) に保存し、頻繁にアクセスするデータのサブセットのコピーはローカルに保持します。」「次に、このデータのポイントインタイムスナップショットを非同期的に Amazon S3 にバックアップします。」）／ボリュームゲートウェイの仕組み（「これらのポイントインタイムのスナップショットは、Amazon S3 において Amazon EBS スナップショットとしても保存されます。」）
