つなぐ・比べる

Path b = Path.of("/a/b"); b.resolve("c/d") // /a/b/c/d b.resolve("/x/y") // /x/y（絶対パスはそのまま） b.resolveSibling("z") // /a/z Path.of("/a/b").relativize(Path.of("/a/c/d")) // ../c/d Path.of("a/b").relativize(Path.of("a")) // .. Path.of("/a").relativize(Path.of("b")) // IllegalArgumentException: 'other' is different type of Path b.resolve("c"); b // /a/b（不変、元は変わらない）
Path.of("/a/./b/../c").normalize() // /a/c Path.of("../x/./y/..").normalize() // ../x Path.of("a/../..").normalize() // .. Path p = Path.of("/a/b/c.txt"); p.startsWith("/a") // true p.startsWith("/a/b/c") // false p.endsWith("c.txt") // true p.endsWith("txt") // false（要素の単位）
startsWith・endsWith は文字列の比較ではなく、名前の要素で比べる。

本番での問われ方

ねらい見るところ
Path の分解ルートは数えない、番号は 0 から、subpath の終わりは含まない
resolve・relativize絶対パスの resolve は引数そのもの、種類ちがいの relativize は例外
normalize・startsWith先頭の .. は残る、要素の単位で比べる、Path は不変
例外NoSuchFile・FileAlreadyExists・DirectoryNotEmpty の使い分け
読み書きreadAllLines は List、lines は Stream、APPEND・CREATE_NEW
走査walk は自分を含む、list はすぐ下、find は BiPredicate
