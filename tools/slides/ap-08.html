8-1 マルチメディア技術データ量と形式

画像のデータ量Image Data Size
横の画素数×縦の画素数×1画素のビット数
例1,920×1,080画素・24ビットで約6Mバイト
音声のデータ量Audio Data Size
標本化周波数×量子化ビット数×チャンネル数×秒数
可逆圧縮・非可逆圧縮Lossless / Lossy Compression
可逆は元に完全に戻せる圧縮、非可逆は戻らないが大きく小さくできる圧縮
JPEGじぇいぺぐ / Joint Photographic Experts Group
写真向けの非可逆圧縮の静止画形式
Joint＝合同の／Photographic＝写真の／Experts Group＝専門家の会
MPEGえむぺぐ / Moving Picture Experts Group
動画と音声を圧縮する国際規格
ポイントフレーム間の差分だけを記録して小さくする
Moving Picture＝動画／Experts Group＝専門家の会
H.264・H.265HEVC
動画の圧縮規格。H.265はH.264の約2倍の圧縮効率で、4K・8K放送に使う

8-1 マルチメディア技術データ量と形式

PCMぴーしーえむ / Pulse Code Modulation
アナログ音声を標本化・量子化・符号化してディジタルにする方式
Pulse＝パルス／Code＝符号／Modulation＝変調
フレームレートFrame Rate
動画で1秒間に表示するコマ（フレーム）の数
ポイント単位はfps
ビットレートBit Rate
1秒あたりのデータ量
例映像の配信は数Mbps
色の表現Color Model
光の三原色RGB（加法混色・画面）と、色の三原色CMY（減法混色・印刷）。印刷ではK（黒）を加えたCMYKを使う
ベクタ形式・ラスタ形式Vector / Raster
ベクタは図形を数式で表し拡大しても粗くならない。ラスタは画素の並びで表す

8-2 マルチメディア応用表現の技術

CGしーじー / Computer Graphics
コンピュータで作る画像や映像
Computer＝コンピュータ／Graphics＝画像
レンダリングRendering
3Dのデータから、光や影を計算して画像を作る処理
レイトレーシングRay Tracing
光の道筋を追いかけて、反射や屈折をリアルに描く方法
モーフィングMorphing
ある画像から別の画像へ、なめらかに変形させる技術
モーションキャプチャMotion Capture
人の動きをセンサやカメラで読み取り、データにする技術
AR・VR・MRAugmented / Virtual / Mixed Reality
ARは現実に情報を重ねる拡張現実、VRは仮想空間に入り込む仮想現実、MRは現実と仮想を融合させる複合現実
Augmented＝拡張された／Virtual＝仮想の／Mixed＝混ぜた／Reality＝現実
