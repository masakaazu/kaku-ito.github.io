KL 情報量

KL 情報量 D(P‖Q)2つの確率分布 P と Q の違い。同じなら 0
D(P‖Q) と D(Q‖P) は一般に違う（対称でない）→ 数学的な距離ではない。
交差エントロピー H(P, Q)
＝
P のエントロピー H(P) ＋ KL 情報量 D(P‖Q)
P（正解）は決まっているので、交差エントロピーを下げる＝KL を下げる。VAE（#13）でも使う。
出典：ウィキペディア「カルバック・ライブラー情報量」『ただしこの計量は距離の公理を満たさないので、数学的な意味での距離ではない。』

Contrastive Loss と Triplet Loss

Contrastive Loss2つ組＋「似ている／似ていない」ラベル
似ているペア → 近づける
似ていないペア → マージン以上離す
Hadsell・Chopra・LeCun（2006）
Triplet Loss3つ組：アンカー・ポジティブ・ネガティブ
d(アンカー, ポジティブ) ＋ マージン ≦ d(アンカー, ネガティブ) をめざす
FaceNet（2015）の顔認証
学んだ埋め込みで、顔の照合・認識・クラスタリングを距離だけで行える。
出典：Hadsell ほか『neighbors are pulled together and non-neighbors are pushed apart.』／FaceNet『directly learns a mapping from face images to a compact Euclidean space where distances directly correspond to a measure of face similarity.』

正則化

複雑さに罰をかけて、過学習を防ぐ。よりどころはオッカムの剃刀。

G検定 #09 誤差関数と正則化シラバス 13・14

L0・L1・L2 正則化

名前罰の中身効果回帰での名前
L0 正則化0 でないパラメータの数特徴を直接減らす（計算が難しい）―
L1 正則化絶対値の和 Σ|w|一部がちょうど 0 → スパース・特徴選択ラッソ回帰
L2 正則化2乗の和 Σw²全体を小さく（0 になりにくい）＝荷重減衰リッジ回帰
L1＋L2両方中間Elastic Net
誤差関数 ＋ λ×罰。λ が大きいほど単純なモデル（大きすぎると未学習）。λ はハイパーパラメータ。
出典：ウィキペディア「正則化」『L1 正則化を使用すると、いくつかのパラメータを 0 にすることができる。』『ニューラルネットワークの世界では、L2 正則化は荷重減衰（英: weight decay）とも呼ばれる。』

ドロップアウトと早期終了

ドロップアウト学習中、ユニットと結合をランダムに落とす
ユニットの頼りあい（共適応）を防ぐ。たくさんの細いネットワークの平均に近い。テストでは落とさず、重みを小さくした1つのネットワークで近似。
早期終了検証誤差が上がり始めたら止める
くり返し学習する方法での正則化の一種。どこまで学習するかの目安。
