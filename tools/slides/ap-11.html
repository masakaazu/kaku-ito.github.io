11-1 情報セキュリティまとめ表

情報セキュリティの3要素（CIA）
要素意味
機密性（Confidentiality）許された人だけが使える
完全性（Integrity）正しく、改ざんされていない
可用性（Availability）必要なときに使える
暗号方式の比較
方式鍵特徴
共通鍵暗号（AES）送る側と受ける側で同じ鍵速い。鍵の受け渡しが課題
公開鍵暗号（RSA・楕円曲線）公開鍵で暗号化、秘密鍵で復号遅いが鍵の配送が楽

11-1 情報セキュリティ基本と暗号

共通鍵暗号方式Symmetric Key Cryptography
暗号化と復号に同じ鍵を使う方式
ポイントn人がお互いに通信するには n(n−1)/2 個の鍵が要る。代表はAES
公開鍵暗号方式Public Key Cryptography
公開鍵と秘密鍵の組を使う方式
ポイント受信者の公開鍵で暗号化し、受信者の秘密鍵で復号する。n人なら2n個
ハイブリッド暗号Hybrid Encryption
共通鍵を公開鍵暗号で送り、データ本体は共通鍵で暗号化する方式
ポイントTLSで使う
ハッシュ関数Hash Function
データから決まった長さの値を作る関数
ポイント元に戻せない、同じ値になる別のデータを見つけにくい。改ざんの検出に使う。例: SHA-256
ディジタル署名Digital Signature
送信者が自分の秘密鍵で署名し、受信者が送信者の公開鍵で確かめるしくみ
ポイント送信者の本人確認と改ざんの検出ができる
PKIぴーけーあい / Public Key Infrastructure
認証局（CA）が公開鍵の持ち主を証明するしくみ
ポイントディジタル証明書は認証局の秘密鍵で署名される。失効した証明書はCRLやOCSPで確かめる
Public Key＝公開鍵／Infrastructure＝基盤

11-1 情報セキュリティ基本と暗号・攻撃の手口

MACめっく / Message Authentication Code
共通鍵とデータから作る値で、改ざんを検出する符号
Message＝メッセージ／Authentication＝認証／Code＝符号
標的型攻撃Targeted Attack
特定の組織をねらい、本物らしいメールでマルウェアを送り込む攻撃
ポイントAPT（長い期間にわたる攻撃）もある
ランサムウェアRansomware
データを暗号化して使えなくし、元に戻す代わりに金銭を要求するマルウェア
ポイント対策はオフラインのバックアップ
SQLインジェクションSQL Injection
入力にSQL文の一部を入れて、データベースを不正に操作する攻撃
ポイント対策はプレースホルダ（バインド機構）
クロスサイトスクリプティングXSS / Cross-Site Scripting
Webページに不正なスクリプトを埋め込み、閲覧者のブラウザで実行させる攻撃
ポイント対策は出力時のエスケープ処理
CSRFしーさーふ / Cross-Site Request Forgery
ログイン中の利用者に、意図しない処理の要求を送らせる攻撃
ポイント対策はトークンの確認
Cross-Site＝サイトをまたいだ／Request＝要求／Forgery＝偽造

11-1 情報セキュリティ攻撃の手口

DDoS攻撃Distributed Denial of Service Attack
多くの機器から大量の通信を送り、サービスを止める攻撃
Distributed＝分散した／Denial of Service＝サービス妨害
DNSキャッシュポイズニングDNS Cache Poisoning
DNSサーバに偽の情報を覚えさせ、偽のサイトに誘導する攻撃
中間者攻撃MITM / Man-in-the-Middle Attack
通信の間に割り込んで、盗み見や改ざんをする攻撃
ゼロデイ攻撃Zero-day Attack
修正プログラムが出る前に、その弱点（脆弱性）をねらう攻撃
パスワードリスト攻撃Password List Attack
ほかのサイトから漏れたIDとパスワードの組で、ログインを試す攻撃
ポイントパスワードの使い回しが原因
ソーシャルエンジニアリングSocial Engineering
人の心のすきをついて、パスワードなどを聞き出す手口
例電話でなりすます、肩越しにのぞく

Common＝共通の／Vulnerability＝脆弱性／Scoring＝点数付け／System＝方式

11-4 情報セキュリティ対策技術的な対策

多要素認証Multi-factor Authentication
知識（パスワード）・所持（スマホ）・生体（指紋）のうち、2種類以上を組み合わせる認証
ファイアウォールFirewall
通信を、決めたルールで通したり止めたりする装置
DMZでぃーえむぜっと / DeMilitarized Zone
外部と内部のネットワークの間に置く、公開サーバ用の区域
DeMilitarized＝非武装の／Zone＝地帯
WAFわふ / Web Application Firewall
Webアプリへの攻撃（SQLインジェクションやXSS）を、通信の中身を見て防ぐ装置
Web Application＝Webアプリ／Firewall＝防火壁
IDS・IPSIntrusion Detection / Prevention System
IDSは不正な侵入を見つけて知らせる、IPSは見つけて止める
Intrusion＝侵入／Detection＝検知／Prevention＝防止
EDRいーでぃーあーる / Endpoint Detection and Response
パソコンなどの端末で不審な動きを見つけ、すぐに対応するしくみ
Endpoint＝端末／Detection＝検知／Response＝対応

11-4 情報セキュリティ対策技術的な対策・管理的・物理的な対策

SIEMしーむ / Security Information and Event Management
いろいろな機器のログをまとめて分析し、攻撃を見つけるしくみ
Security＝安全／Information＝情報／Event＝出来事／Management＝管理

セキュアブートSecure Boot

TPMてぃーぴーえむ / Trusted Platform Module

Trusted＝信頼された／Platform＝基盤／Module＝部品

11-5 セキュリティ実装技術安全な通信と開発

TLSてぃーえるえす / Transport Layer Security
通信を暗号化し、サーバの正しさを証明書で確かめるプロトコル
ポイントHTTPSで使う。ハンドシェイクで暗号方式と鍵を決める
Transport Layer＝トランスポート層／Security＝安全
IPsecあいぴーせっく / IP Security
IPの層で暗号化と認証を行うプロトコル
ポイントVPNに使う。トンネルモードとトランスポートモード
SPF・DKIM・DMARC
送信元のなりすましを防ぐメールの認証技術
ポイントSPFは送信元のIPアドレス、DKIMは電子署名で確かめる。DMARCは結果に応じた扱いを決める
S/MIMEえすまいむ / Secure MIME
公開鍵を使って、メールを暗号化・署名する方式
Secure＝安全な／MIME＝メールの形式の規格
セキュアプログラミングSecure Programming
脆弱性を作らないようにプログラムを書くこと
ポイント入力のチェック、エスケープ、プレースホルダなど
無線LANのセキュリティWPA3
無線LANの暗号化の規格
ポイントWEPは弱く使ってはいけない
