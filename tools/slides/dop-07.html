SAM CLI のコマンド

コマンドすること使う場面
sam initひな形を作るはじめ
sam build依存関係を入れて .aws-sam にまとめる（--use-container）local・deploy の前
sam local invoke／start-apiDocker で関数・API を手元で動かす手元のテスト
sam deploy --guided設定を聞いて samconfig.toml に保存、変更セットでデプロイ初回・本番
sam sync --watch変更をすぐにクラウドへ（コードは直接更新）開発環境だけ
sam pipeline initCI/CD パイプラインのひな形本番の自動化
sam sync は開発向け。本番は sam deploy か CI/CD パイプライン。
