3-1 プロセッサCPUの仕組み

CPUしーぴーゆー / Central Processing Unit
命令を読み取って実行する、コンピュータの中心の装置。制御装置と演算装置からなる
Central＝中心の／Processing＝処理／Unit＝装置
プログラム内蔵方式ノイマン型 / Stored Program
プログラムとデータを主記憶装置に入れておき、順に読み出して実行する方式
ポイント今のコンピュータの基本の形
命令実行サイクルめいれいじっこうさいくる / Instruction Cycle
命令の取出し（フェッチ）→ 解読 → オペランドの読出し → 実行、を繰り返す流れ
ポイントフェッチは主記憶から命令を取り出すこと
レジスタRegister
CPUの中にある、命令や計算途中のデータを一時的に置く高速な記憶場所
ポイントプログラムカウンタは次に実行する命令のアドレスを持つ
逐次制御方式ちくじせいぎょほうしき / Sequential Control
命令を1つずつ順番に実行する方式
ポイント分岐命令で実行順序を変えられる
クロック周波数Clock Frequency
CPUが動作のタイミングに使う信号の、1秒あたりの回数
例1GHz は1秒に10億回
基本情報 コンピュータ構成要素4

3-1 プロセッサCPUの仕組み

CPIしーぴーあい / Cycles Per Instruction
1つの命令の実行にかかる平均のクロック数
ポイント小さいほど速い
Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令
MIPSみっぷす / Million Instructions Per Second
1秒間に何百万個の命令を実行できるかを表す性能の値
例800MHz・CPI 4 なら 800÷4＝200MIPS
Million＝100万／Instructions＝命令／Per Second＝1秒あたり
CISCしすく / Complex Instruction Set Computer
複雑で多機能な命令をたくさん持つCPU
ポイント命令ごとに長さや実行時間がまちまち
Complex＝複雑な／Instruction Set＝命令の一式／Computer＝計算機
RISCりすく / Reduced Instruction Set Computer
単純な命令に絞り、1命令を短い時間で実行するCPU
ポイントパイプライン処理と相性がよい
Reduced＝減らした／Instruction Set＝命令の一式／Computer＝計算機
パイプラインPipeline
命令の各段階をずらして重ねて実行し、処理を速くする方式
ポイント分岐があると先読みした命令が無駄になる（ハザード）

3-1 プロセッサCPUの仕組み

マルチコアプロセッサMulti-core Processor
1つのCPUの中に複数の演算の中核（コア）を持つプロセッサ
ポイント複数の処理を同時に進められる
GPUじーぴーゆー / Graphics Processing Unit
画像処理用に作られた、単純な計算を大量に並列で行うプロセッサ
ポイントAIの学習にも使われる
Graphics＝画像／Processing＝処理／Unit＝装置
割込みわりこみ / Interrupt
実行中の処理を一時中断して、別の処理を優先して行う仕組み
ポイント外部割込み＝タイマや入出力の完了など外からの要因。内部割込み＝0での割り算やページフォールトなどプログラムが原因

RAM（読み書き）消える（揮発性）DRAM（主記憶）、SRAM（キャッシュ）

3-2 メモリ半導体メモリ

主記憶装置しゅきおくそうち / Main Memory
CPUが直接読み書きする記憶装置。実行中のプログラムとデータを置く
ポイント一般にDRAMを使う
DRAMでぃーらむ / Dynamic RAM
コンデンサの電荷で記憶するRAM。定期的なリフレッシュが必要
ポイント安くて大容量なので主記憶に使う
Dynamic＝動的な（電荷が抜けるので書き直す）／RAM＝読み書きできるメモリ
SRAMえすらむ / Static RAM
フリップフロップ回路で記憶するRAM。リフレッシュ不要で高速
ポイント高価なのでキャッシュメモリに使う
Static＝静的な（書き直し不要）／RAM＝読み書きできるメモリ
SDRAMえすでぃーらむ / Synchronous DRAM
クロックに同期して動くDRAM
ポイント揮発性でリフレッシュが必要
Synchronous＝同期した／DRAM＝ダイナミックRAM
リフレッシュRefresh
DRAMの電荷が抜けて内容が消えないよう、定期的に書き直す動作
基本情報 コンピュータ構成要素8

3-2 メモリ半導体メモリ

ROMろむ / Read Only Memory
電源を切っても内容が消えない（不揮発性の）メモリ
ポイントマスクROMは製造時に書き込み、書き換え不可
Read Only＝読むだけの／Memory＝記憶装置
EEPROMいーいーぴーろむ / Electrically Erasable Programmable ROM
電気で内容を消して書き換えられる不揮発性のROM
ポイントフローティングゲートに電荷をためて記憶する
Electrically＝電気で／Erasable＝消せる／Programmable＝書き込める／ROM＝不揮発性メモリ
フラッシュメモリFlash Memory
EEPROMの一種で、ブロック単位でまとめて消去・書換えするメモリ
ポイントUSBメモリ、SDカード、SSDに使う
キャッシュメモリCache Memory
CPUと主記憶の速度差を埋めるために間に置く、小さくて高速なメモリ
ポイントよく使うデータを置く。1次・2次と階層にする
ヒット率ひっとりつ / Hit Ratio
読みたいデータがキャッシュにある割合
例キャッシュ10ns・主記憶100ns・ヒット率90%なら 0.9×10＋0.1×100＝19ns
基本情報 コンピュータ構成要素9

3-2 メモリ半導体メモリ

ライトスルー方式Write Through
キャッシュに書くと同時に、主記憶にも書き込む方式
ポイント主記憶と常に一致するが遅い
ライトバック方式Write Back
キャッシュだけに書き、追い出されるときに主記憶へ書き戻す方式
ポイント速いが、主記憶と一時的に不一致になる
メモリインタリーブMemory Interleave
主記憶をいくつかのバンクに分け、並行して読み出して速くする方式

バスBus

バス幅ばすはば / Bus Width

3-4 入出力デバイス入出力インタフェース

シリアルインタフェースSerial Interface
データを1ビットずつ順に送るインタフェース
例USB、SATA。今の主流
パラレルインタフェースParallel Interface
複数のビットを同時に並べて送るインタフェース
ポイント速度を上げると信号のずれが問題になる
USBゆーえすびー / Universal Serial Bus
パソコンと周辺機器をつなぐシリアルインタフェースの規格
ポイントハブで多くの機器をつなげ、電源も供給できる
Universal＝汎用の／Serial＝1ビットずつ順に／Bus＝通り道
無線インタフェースWireless Interface
ケーブルを使わずにデータをやり取りする方式
例Bluetooth、IrDA（赤外線）、NFC
プラグアンドプレイPlug and Play
機器をつなぐだけで、OSが自動で認識して設定する仕組み
ホットプラグHot Plug
電源を入れたまま機器を抜き差しできる仕組み
基本情報 コンピュータ構成要素12

3-4 入出力デバイス入出力インタフェース

デバイスドライバDevice Driver

DMAでぃーえむえー / Direct Memory Access
CPUを通さず、入出力装置と主記憶の間で直接データを転送する方式
ポイントCPUの負担が減る
Direct＝直接の／Memory＝主記憶／Access＝読み書き

3-5 入出力装置補助記憶装置

HDDえいちでぃーでぃー / Hard Disk Drive
回転する磁気ディスクにデータを記録する補助記憶装置
Hard Disk＝硬い円盤／Drive＝駆動装置
HDDのアクセス時間Access Time
位置決め時間（シーク時間）＋ 回転待ち時間 ＋ データ転送時間
ポイント平均回転待ち時間は1回転の半分
セクタ・トラックSector, Track
トラックはディスク上の同心円の記録場所、セクタはトラックを分けた最小の記録単位
フラグメンテーション断片化 / Fragmentation
ファイルのデータがディスク上のあちこちに散らばった状態
ポイント読み書きが遅くなる。デフラグで並べ直す
SSDえすえすでぃー / Solid State Drive
フラッシュメモリを使った補助記憶装置
ポイント可動部がなく、HDDより速くて衝撃に強い
Solid State＝半導体の／Drive＝記憶装置
磁気テープMagnetic Tape
テープに磁気で記録する装置。先頭から順にしか読めない
ポイント大容量で安いのでバックアップの保管に使う
基本情報 コンピュータ構成要素14
