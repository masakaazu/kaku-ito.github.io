22-1 経営・組織論企業と組織

企業の社会的責任CSR / Corporate Social Responsibility
企業が利益だけでなく、環境や社会に対しても責任を果たすこと
SDGsえすでぃーじーず / Sustainable Development Goals
国連が決めた、2030年までの持続可能な開発目標。17の目標がある
Sustainable＝持続可能な／Development＝開発／Goals＝目標
職能別組織Functional Organization
営業・製造・経理など、仕事の種類ごとに分けた組織
事業部制組織Divisional Organization
製品や地域ごとに事業部を作り、それぞれが利益に責任をもつ組織
マトリックス組織Matrix Organization
職能別と事業部別など、2つの軸を組み合わせた組織
ポイント1人が2人の上司をもつ
プロジェクト組織Project Organization
決まった目的のために、いろいろな部門から人を集めて一時的に作る組織

22-2 OR・IE分析の道具

ORおーあーる / Operations Research
数学や統計を使って問題を分析し、最もよい答え（最適解）を見つける方法
ポイント線形計画法・在庫問題・待ち行列など
Operations＝業務／Research＝研究
IEあいいー / Industrial Engineering
作業のやり方や時間を分析して、生産の効率を上げる方法
Industrial＝産業の／Engineering＝工学
線形計画法Linear Programming
制約の条件の中で、利益などを最大（または最小）にする組合せを求める方法
ポイント制約の式で囲まれた範囲の角（頂点）の値を調べる
経済的発注量EOQ / Economic Order Quantity
発注の費用と保管の費用の合計が最も小さくなる、1回の発注量
ポイントEOQ＝√（2×年間需要量×1回の発注費÷1個の年間保管費）
パレート図Pareto Chart
項目を大きい順に並べた棒グラフと、累積の比率の折れ線を組み合わせた図
ポイントABC分析に使う
ABC分析ABC Analysis
売上などの大きい順にA・B・Cのグループに分け、重点的に管理する対象を決める方法

22-2 OR・IE分析の道具

特性要因図Cause and Effect Diagram
結果（特性）と、それに影響する原因（要因）の関係を、魚の骨のような形で整理した図
散布図Scatter Diagram
2つの量を縦と横にとって点を打ち、関係（相関）を見る図
管理図Control Chart
時間ごとのデータの変化に、上と下の管理限界線を引いて、工程が安定しているかを見る図
親和図法Affinity Diagram
集めた意見や情報を、似たものどうしでまとめて整理する方法
ブレーンストーミングBrainstorming
人の意見を否定せず、自由にたくさんのアイデアを出し合う方法
OC曲線検査特性曲線 / Operating Characteristic Curve
ロットの不良率と、そのロットが検査に合格する確率の関係を表したグラフ

22-3 会計・財務利益の計算・財務諸表

固定費Fixed Cost
売上の量にかかわらず、決まってかかる費用
例家賃、人件費
変動費Variable Cost
売上の量に比例して増える費用
例材料費
変動費率Variable Cost Ratio
売上高に対する変動費の割合
ポイント変動費 ÷ 売上高
限界利益Marginal Profit
売上高から変動費を引いたもの
ポイント固定費を回収するための利益
損益分岐点BEP / Break-Even Point
利益がちょうど0になる売上高（または販売数量）
ポイント損益分岐点売上高＝固定費÷（1−変動費率）。例: 固定費300万・変動費率0.6なら750万
貸借対照表B/S / Balance Sheet
ある時点の会社の財産の状態（資産・負債・純資産）を表す表
ポイント資産＝負債＋純資産

22-3 会計・財務財務諸表

損益計算書P/L / Profit and Loss Statement
ある期間の収益・費用と、その差の利益を表す表
キャッシュフロー計算書C/F / Cash Flow Statement
ある期間の現金の増減を、営業・投資・財務の活動に分けて表す表
減価償却Depreciation
長く使う設備の買った金額を、使う年数に分けて少しずつ費用にすること
ポイント定額法: 毎年の償却額＝（取得価額−残存価額）÷耐用年数
ROEあーるおーいー / Return On Equity
自己資本（株主のお金）でどれだけの利益をあげたかを表す指標。自己資本利益率
ポイント当期純利益 ÷ 自己資本
Return＝利益／On＝〜に対する／Equity＝自己資本
流動比率Current Ratio
1年以内に現金になる資産（流動資産）が、1年以内に返す借金（流動負債）の何倍あるか
ポイント高いほど短い期間の支払いに強い
