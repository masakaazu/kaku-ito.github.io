Lambda と API Gateway

設定何をする
同時実行の上限リージョン全体で既定 1,000。超えるとスロットリング
予約済み同時実行関数の分を確保し上限にもする（0 で停止）。追加料金なし
プロビジョニング初期化済みの環境でコールドスタートなし。料金あり
API Gateway のスロットリングトークンバケット（レートとバースト）。超えると 429。使用量プラン＋API キーで利用者ごとのレートとクォータ
API キャッシュステージで有効化。TTL 既定 300 秒・最大 3600 秒

SQS の設定と Lambda

設定ポイント
可視性タイムアウト既定 30 秒・上限 12 時間。処理時間より長く（短いと二重処理）
DLQmaxReceiveCount を超えたら移す。同じアカウント・リージョン
ロングポーリング最大 20 秒待つ。空の応答と費用が減る
FIFO順序・重複なし。メッセージグループごとに並行

↓ イベントソースマッピング（バッチ）
Lambda
1 件失敗で全件が戻る → ReportBatchItemFailures（部分的なバッチレスポンス）。
