外側のインスタンスを持つか、持たないか。

Java Gold #04 ネストしたクラス試験内容 2

内部クラス（メンバー）

class Outer { private int x = 10; class Inner { int get() { return x * 2; } } public static void main(String[] a) { Outer o = new Outer(); Outer.Inner in = o.new Inner(); o.x = 7; in.get(); // 14（今の x を読む） new Inner(); // エラー：this がない } }
名前が重なったとき
class Outer { int x = 1; class Inner { int x = 2; void show(int x) { x // 3 引数 this.x // 2 Inner Outer.this.x // 1 外側 } } }
Java 16 から内部クラスも static メンバーを持てる。class Inner { static int count; } は Java 17 で○。
出典：JLS 8.1.3・15.8.4・15.9.2、JEP 395／JDK 17 でのコンパイルと実行の結果
