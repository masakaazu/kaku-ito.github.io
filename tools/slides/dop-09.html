マネージドノードになる条件

① SSM Agent多くの AMI に入っている。オンプレは手で入れる
② 権限インスタンスプロファイル（AmazonSSMManagedInstanceCore）または DHMC。オンプレはハイブリッドアクティベーション（mi-）
③ 経路（外向き 443）NAT ゲートウェイ または VPC エンドポイント
フリートに出ない → この 3 つのどれかが欠けている。

ssmmessagesSession Manager・Agent のメッセージ
ec2messagesRun Command などの指示
s3（ゲートウェイ）・logs・kmsログの出力・暗号化をするなら

実行と構成の自動化

今すぐ・保ち続ける・手順を組む・時間枠で。

AWS DevOps #09 Systems Managerタスク 2.3

どのツールで動かすか

ツールいつ何を例
Run Command今すぐ 1 回ノードでコマンド（Command ドキュメント）タグ Role=web で一斉にキャッシュ削除
State Manager繰り返し関連付けで決めた状態に保つCloudWatch エージェントを常に入れる
Automation必要なとき・イベントランブックで AWS の API を含む手順AMI 作成、S3 の公開を直す（EventBridge・Config）
Maintenance Windows決めた時間枠止まりうる作業をまとめて毎週日曜 2 時にパッチ
Distributor配るときソフトのパッケージ自社エージェントを配布
レート制御：同時実行（例 10%）とエラーのしきい値（例 5%）。aws:approve で人の承認、aws:executeScript で Python。
出典：Run Command／State Manager／Automation／自動オペレーションを大規模に実行する／承認が必要なオートメーション／Maintenance Windows／Distributor
