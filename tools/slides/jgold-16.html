commit・rollback・Savepoint

// t は 1 行 c.getAutoCommit() // true（既定） c.setAutoCommit(false); insert(2); Savepoint sp = c.setSavepoint(); insert(3); c.rollback(sp); // 3 だけ取り消し → 2 行 c.commit(); // 2 行で確定 insert(4); c.rollback(); // 4 を取り消し → 2 行 insert(5); c.setAutoCommit(true); // ここで commit c.rollback(); // 戻らない → 3 行
自動コミット（既定）SQL を 1 つ実行するたびに確定
setAutoCommit(false)commit まで確定しない。rollback で最後の commit 以降を取り消す
Savepointrollback(sp) は印のあとだけ。トランザクションは続く
