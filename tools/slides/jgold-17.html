探す順と親のつながり

ファイル中身
Msg.propertieshello=Hello(base)、bye=Bye(base)、only=base-only
Msg_en.propertieshello=Hello(en)
Msg_fr.propertieshello=Bonjour(fr)、bye=Au revoir(fr)
Msg_fr_CA.propertieshello=Allo(fr_CA)
↓ 既定のロケールは en_US
求めた見つかるhello / bye / only
fr_CAfr_CAAllo / Au revoir / base-only
fr_FRfrBonjour / Au revoir / base-only
ja_JPenHello(en) / Bye(base) / base-only
Locale.ROOT（基底）Hello(base) / …
① バンドルを探す求めた（国あり → 国なし）→ 既定のロケール（国あり → 国なし）→ 基底
② キーを探す見つかったバンドル → 国を外した親 → 基底（既定のロケールのバンドルは親にならない）
ja_JP で Msg_ja がないと、基底ではなく既定のロケールの Msg_en が使われる。既定を fr_FR にすると Msg_fr。
getNoFallbackControl を渡すと、既定のロケールを飛ばして基底へ。
出典：API ResourceBundle.getBundle・ResourceBundle.Control／JDK 17 での実行結果

NumberFormat の種類

メソッド（Locale.US）例

getCurrencyInstance1234567.891 → $1,234,567.89

NumberFormat は抽象クラス（new できない）。丸めの既定は HALF_EVEN。

DecimalFormat のパターン

記号意味
0数字（なければ 0 を出す）
#数字（なければ出さない）
.小数点
,けた区切り
%100 倍してパーセント
'文字'そのまま出す
new DecimalFormat("#,##0.00").format(1234.5) // 1,234.50 new DecimalFormat("000.#").format(5.25) // 005.2 new DecimalFormat("#.##").format(0.5) // 0.5 new DecimalFormat("0.0").format(2.25) // 2.2（HALF_EVEN） new DecimalFormat("$#,###").format(1234567) // $1,234,567 String.format(Locale.GERMANY, "%,.2f", 1234567.891) // 1.234.567,89
