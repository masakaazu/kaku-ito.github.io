1-1 離散数学数と表現

基数変換Radix Conversion
ある進数で表した数を、別の進数で表し直すこと
ポイント10進→2進は2で割った余りを下から並べる。小数部は2を掛けて整数部を取り出す
例0.1（10進）は2進で循環小数になり、正確に表せない
2の補数Two's Complement
負の数を表す方法。全ビットを反転して1を足す
ポイント引き算を足し算の回路で行える
浮動小数点数Floating Point Number
数を「符号・仮数・指数」に分けて表す方法
ポイントIEEE 754の単精度は指数部8ビット（バイアス127）、仮数部23ビット。正規化で仮数の先頭の1を省く（けち表現）
桁落ちCancellation
ほぼ等しい2つの数の差を求めたとき、有効数字の桁数が大きく減ること
情報落ちLoss of Information
絶対値が大きく違う数を足し引きしたとき、小さい方の値が結果に反映されないこと
ポイント対策は小さい数から順に足すこと
シフト演算Shift Operation
ビット列を左右にずらす演算
ポイント論理シフトは空いた所に0を入れる。算術シフトは符号ビットを保つ。左にnビットで2^n倍

1-1 離散数学集合と論理

ベン図Venn Diagram
集合の関係を円の重なりで表した図
ド・モルガンの法則De Morgan's Laws
NOT(A AND B) ＝ (NOT A) OR (NOT B)、NOT(A OR B) ＝ (NOT A) AND (NOT B)
排他的論理和XOR / Exclusive OR
2つの入力が異なるときだけ1になる演算
ポイント同じ値でXORを2回すると元に戻る。パリティや暗号に使う
Exclusive＝排他的な／OR＝または
カルノー図Karnaugh Map
論理式を簡単にするための表
ポイント隣り合う1をまとめて項を減らす
BNFびーえぬえふ / Backus-Naur Form
プログラム言語などの文法を、記号を使って定義する書き方
ポイント::= は定義、| は「または」
Backus・Naur＝考案者の名前／Form＝記法
有限オートマトンFinite Automaton
有限個の状態と、入力による状態の移り変わりで表すモデル
ポイント状態遷移表・状態遷移図で表す。文字列の受理の判定に使う

1-2 応用数学確率と統計

順列・組合せPermutation / Combination
順列は並べ方の数 nPr ＝ n!÷(n−r)!、組合せは選び方の数 nCr ＝ n!÷(r!(n−r)!)
条件付き確率Conditional Probability
Bが起きたときにAが起きる確率 P(A|B) ＝ P(A∩B)÷P(B)
ポイントベイズの定理で原因の確率を逆算できる
期待値Expected Value
起こりうる値に、その確率を掛けて足し合わせたもの
標準偏差Standard Deviation
データのばらつきの大きさ。分散の正の平方根
正規分布Normal Distribution
平均を中心にした左右対称のつりがね形の分布
ポイント平均±1σに約68％、±2σに約95％、±3σに約99.7％が入る
ポアソン分布Poisson Distribution
一定の時間にまれな出来事が何回起こるかを表す分布
ポイント待ち行列で到着の数に使う

1-2 応用数学確率と統計・数値計算とOR

相関係数Correlation Coefficient
2つの量の直線的な関係の強さ。−1から1の値
ポイント0に近いと相関がない。相関があっても因果関係があるとは限らない
回帰分析Regression Analysis
ある量を、ほかの量の式で説明・予測する方法
ポイント最小二乗法で直線を当てはめる
待ち行列理論Queueing Theory
窓口に客が並ぶ様子を数式で分析する理論
ポイントM/M/1で利用率ρ、平均待ち時間 ＝ ρ÷(1−ρ) × 平均サービス時間
ニュートン法Newton's Method
接線を使って、方程式の解に近い値を繰り返し求める方法
行列Matrix
数を縦横に並べたもの
ポイントAIの計算（ベクトルの演算）で多く使う

1-3 情報に関する理論情報量と符号・人工知能

情報量Amount of Information
起きる確率がpの出来事の情報量は −log2 p ビット
ポイントめったに起きないことほど情報量が大きい
平均情報量エントロピー / Entropy
情報源から出る1記号あたりの情報量の平均
ハフマン符号Huffman Code
よく出る記号に短い符号、まれな記号に長い符号を割り当てて、平均の符号長を短くする方法
ポイント可逆圧縮に使う
ランレングス符号化Run-Length Encoding
同じ記号の連続を「記号＋個数」で表して圧縮する方法
機械学習Machine Learning
データからコンピュータが規則やパターンを学ぶ技術
ポイント教師あり学習・教師なし学習・強化学習がある
教師あり学習Supervised Learning
正解（ラベル）付きのデータで学習する方法
ポイント分類と回帰に使う

1-4 通信に関する理論伝送と誤り

変調Modulation
ディジタルの信号を、伝送に向いた波（搬送波）にのせること
ポイント振幅・周波数・位相を変える方式がある
PCMぴーしーえむ / Pulse Code Modulation
アナログ信号を標本化・量子化・符号化してディジタルにする方式
ポイント標本化定理: 最高周波数の2倍以上で標本化すれば元に戻せる
Pulse＝パルス／Code＝符号／Modulation＝変調
パリティチェックParity Check
1の数が偶数（奇数）になるように1ビット足して、誤りを検出する方法
ポイント1ビットの誤りは見つかるが、2ビットの誤りは見つからない
CRCしーあーるしー / Cyclic Redundancy Check
生成多項式で割った余りを付けて、誤りを検出する方法
ポイント連続した誤り（バースト誤り）に強い
Cyclic＝巡回／Redundancy＝冗長／Check＝検査
ハミング符号Hamming Code
検査ビットを付けて、1ビットの誤りを訂正できる符号
ポイント2ビットの誤りは検出だけできる

1-5 計測・制御に関する理論制御

フィードバック制御Feedback Control
結果を測って目標との差をなくすように操作する制御
例エアコンの温度調節
フィードフォワード制御Feedforward Control
乱れ（外乱）を前もって予測し、結果が変わる前に操作する制御
PID制御Proportional-Integral-Derivative Control
目標との差の大きさ（P）・積み重ね（I）・変化の速さ（D）を組み合わせる制御
Proportional＝比例／Integral＝積分／Derivative＝微分
シーケンス制御Sequence Control
あらかじめ決めた順番どおりに動作を進める制御
例信号機、洗濯機
A/D変換Analog to Digital Conversion
センサのアナログ信号をディジタルの値に変えること
ポイント分解能はビット数で決まる
