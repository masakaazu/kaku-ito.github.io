14-6 プロジェクトの時間日程

アローダイアグラムPERT図 / Arrow Diagram
作業の順序と日数を矢印で表した図
ポイントダミー作業（点線）は順序だけを表す
クリティカルパスCritical Path
所要日数が最も長く、余裕（フロート）がない経路
ポイントここが遅れると全体が遅れる
最早結合点時刻・最遅結合点時刻Earliest / Latest Node Time
最早は前から計算して最大値、最遅は後ろから計算して最小値
ポイント両者の差が余裕日数
プレシデンスダイアグラム法PDM / Precedence Diagramming Method
作業を四角で表し、FS・SS・FF・SFの依存関係で結ぶ図
クラッシング・ファストトラッキングCrashing / Fast Tracking
クラッシングは資源を追加して期間を縮める、ファストトラッキングは作業を並行させて縮める
三点見積法Three-point Estimating
楽観値・最可能値・悲観値から見積もる方法
ポイントPERTでは（楽観＋4×最可能＋悲観）÷6

14-7 プロジェクトのコストコスト

EVMいーぶいえむ / Earned Value Management
計画（PV）・出来高（EV）・実コスト（AC）で、進み具合とコストを管理する方法
Earned＝得られた／Value＝価値／Management＝管理
BAC・EACBudget At Completion / Estimate At Completion
BACは完成までの予算の合計、EACは完成時の総コストの見込み
ファンクションポイント法Function Point Method
入出力・ファイルなどの機能の数と複雑さから規模を見積もる方法
COCOMOここも / Constructive Cost Model
プログラムの行数などから、工数を式で見積もる方法
Constructive＝構造的な／Cost＝費用／Model＝模型
類推見積法Analogous Estimating
似た過去のプロジェクトの実績をもとに見積もる方法
コンティンジェンシー予備Contingency Reserve
特定したリスクに備えて取っておく予算や時間

14-8 プロジェクトのリスクリスク

リスク対応戦略Risk Response Strategies
マイナスのリスクには回避・転嫁・軽減・受容、プラスのリスク（好機）には活用・共有・強化・受容
定性的・定量的リスク分析Qualitative / Quantitative Risk Analysis
定性的は発生確率と影響度で優先順位を付ける、定量的は金額や日数で数値にする
EMVいーえむぶい / Expected Monetary Value
リスクの影響額×発生確率で求める期待金額
ポイントデシジョンツリーで使う
Expected＝期待される／Monetary＝金銭の／Value＝値
リスク登録簿Risk Register
特定したリスクと、その分析・対応策を記録した表
