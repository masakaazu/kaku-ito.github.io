22-1 経営・組織論経営と組織

経営理念・ビジョンCorporate Philosophy / Vision
経営理念は会社の存在意義や価値観、ビジョンは目指す将来の姿
CSR・SDGs・ESGCorporate Social Responsibility / Sustainable Development Goals / Environment, Social, Governance
CSRは企業の社会的責任、SDGsは国連の17の目標、ESGは環境・社会・企業統治に配慮しているかで企業を評価する投資の考え方
コーポレートガバナンスCorporate Governance
株主などが経営を監視し、健全な経営を保つしくみ
ポイント社外取締役の設置など
組織形態Organization Structures
職能別組織・事業部制組織・マトリックス組織・プロジェクト組織・カンパニー制など
ポイントマトリックス組織は2人の上司を持つ
BCP・BCMBusiness Continuity Plan / Management
BCPは災害時に重要な業務を続けるための計画、BCMはそれを作って運用・改善する管理
ポイント目標復旧時間（RTO）と目標復旧時点（RPO）を決める
Business＝事業／Continuity＝継続／Plan＝計画／Management＝管理

22-2 OR・IE分析の手法

線形計画法Linear Programming
制約条件のもとで目的の値を最大（最小）にする組合せを求める方法
ポイント制約の直線が交わる頂点を調べる
在庫管理Inventory Control
定量発注方式（在庫が発注点を下回ったら決まった量を注文）と定期発注方式（決まった時期に必要な量を注文）
経済的発注量EOQ / Economic Order Quantity
発注の費用と保管の費用の合計が最も小さくなる発注量
ポイント√(2×年間需要×1回の発注費÷1個の年間保管費)
発注点Reorder Point
1日の使用量×調達期間＋安全在庫
ゲーム理論Game Theory
相手の行動を考えて最適な戦略を選ぶ理論
ポイントマクシミン原理（最悪の場合の利益が最大になる案を選ぶ）など
デシジョンツリーDecision Tree
選択と、その結果の確率・利益を木の形で表し、期待値で案を選ぶ方法

22-2 OR・IE分析の手法

PERT・CPMProgram Evaluation and Review Technique / Critical Path Method
日程の計画と管理の手法
パレート図・ABC分析Pareto Chart / ABC Analysis
大きい順に並べて累積比率を見て、重点的に管理するもの（A群）を決める
特性要因図Cause and Effect Diagram
結果と、それに影響する要因を魚の骨の形で整理した図
管理図Control Chart
上下の管理限界線で、工程が安定しているかを見る図
連関図法Relations Diagram
原因と結果がからみ合う問題を、矢印でつないで整理する方法
PDPC法Process Decision Program Chart
計画を進めるうえで起こりうる事態を予測し、対策を考えておく方法

22-3 会計・財務会計

損益分岐点BEP / Break-Even Point
利益がちょうど0になる売上高
ポイント固定費÷（1−変動費率）
貸借対照表・損益計算書・キャッシュフロー計算書B/S・P/L・C/F
B/Sはある時点の資産・負債・純資産、P/Lはある期間の収益・費用・利益、C/Fはある期間の現金の増減
損益計算書の利益Profits
売上総利益（粗利）→営業利益（本業のもうけ）→経常利益（金利などを含む）→税引前当期純利益→当期純利益
減価償却Depreciation
設備の取得額を、耐用年数にわたって少しずつ費用にすること
ポイント定額法は毎年同じ額、定率法は残りの額に一定の率を掛ける
先入先出法・移動平均法FIFO / Moving Average Method
在庫の単価の決め方
ポイント先入先出法は古いものから払い出したとみなす
ROE・ROAReturn On Equity / Return On Assets
ROEは自己資本に対する利益率、ROAは総資産に対する利益率
Return＝利益／On＝〜に対する／Equity＝自己資本／Assets＝資産

22-3 会計・財務会計

正味現在価値NPV / Net Present Value
将来の収入を、利率で割り引いて今の価値にし、投資額を引いたもの
ポイントプラスなら投資する価値がある
Net＝正味の／Present＝現在の／Value＝価値
回収期間法Payback Period Method
投資額を何年で回収できるかで判断する方法
管理会計・財務会計Management / Financial Accounting
管理会計は社内の意思決定のため、財務会計は株主など外部への報告のための会計
IFRSいふぁーす / International Financial Reporting Standards
国際的な会計の基準
International＝国際的な／Financial Reporting＝財務報告／Standards＝基準
