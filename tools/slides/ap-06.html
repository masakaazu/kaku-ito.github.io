6-1 ハードウェア（電気・電子回路）回路の基本

NAND回路NAND Gate
ANDの結果を反転させる回路
ポイントNANDだけでどんな論理回路も作れる
フリップフロップFlip-flop
1ビットの情報を保持できる順序回路
ポイントSRAMやレジスタに使う
組合せ回路・順序回路Combinational / Sequential Circuit
組合せ回路は今の入力だけで出力が決まる回路、順序回路は過去の状態も出力に影響する回路
半加算器・全加算器Half Adder / Full Adder
半加算器は2ビットを足して和と桁上がりを出す回路（XORとAND）、全加算器は下の桁からの桁上がりも足す回路
半導体Semiconductor
電気を通す導体と通さない絶縁体の中間の性質をもつ物質
ポイントトランジスタやICの材料

6-2 機械・制御機械を動かす

アクチュエータActuator
電気などの信号を受けて、実際に動きを生み出す装置
例モータ、油圧シリンダ
センサSensor
温度・光・加速度などの物理量を測って、電気信号に変える装置
ステッピングモータStepping Motor
パルス信号1つで決まった角度だけ回るモータ
ポイント位置を正確に決めやすい
PWMぴーだぶりゅーえむ / Pulse Width Modulation
パルスのオンの時間の割合を変えて、モータの速さなどを調整する方式
Pulse＝パルス／Width＝幅／Modulation＝変調

6-3 論理設計論理の組立て

論理式の簡単化Logic Simplification
ブール代数やカルノー図を使って、論理式を短くすること
ポイント回路の部品が減る
FPGAえふぴーじーえー / Field Programmable Gate Array
買った後に利用者が論理回路を書き換えられるIC
Field＝現場で／Programmable＝プログラムできる／Gate Array＝ゲートの並び
ASICえーしっく / Application Specific Integrated Circuit
特定の用途向けに設計されたIC
ポイント大量生産すると安く速い
Application Specific＝特定用途向け／Integrated Circuit＝集積回路
SoCえすおーしー / System on a Chip
CPU・メモリ・入出力などシステムの主な機能を1つのチップにまとめたもの
System＝システム／on a Chip＝1つのチップの上に

6-4 構成部品及び要素と実装部品と実装

組込みシステムEmbedded System
家電や機械に組み込まれ、特定の機能を制御するコンピュータシステム
ポイントリアルタイムOSを使うことが多い
ウォッチドッグタイマWatchdog Timer
一定時間内にプログラムから信号が来ないと、異常とみなしてシステムをリセットするしくみ
ポイント組込みシステムの暴走対策
ファームウェアFirmware
機器のROMやフラッシュメモリに書き込まれ、ハードウェアを直接制御するソフトウェア
IoTデバイスIoT Device
ネットワークにつながり、センサの情報を送ったり制御を受けたりする機器
ポイント省電力・小型が求められる

6-5 消費電力電力を減らす

低消費電力化Low Power Design
回路が使う電力を減らす工夫
ポイント動的電力は「電圧の2乗×周波数」に比例するので、電圧を下げる効果が大きい
DVFSでぃーぶいえふえす / Dynamic Voltage and Frequency Scaling
負荷に合わせて電圧とクロック周波数を変え、電力を減らす技術
Dynamic＝動的な／Voltage＝電圧／Frequency＝周波数／Scaling＝調整
クロックゲーティングClock Gating
使っていない回路へのクロックを止めて、電力を減らす技術
パワーゲーティングPower Gating
使っていない回路への電源そのものを切る技術
ポイント漏れ電流も減らせる
