第1章

Comparable と自然順序

クラス自身が持つ、ただ 1 つの標準の並び順。

Java Gold #03 ソートと便利なメソッド試験内容 1

Comparable を実装する

record Item(String name, int price) implements Comparable<Item> { public int compareTo(Item o) { return Integer.compare(price, o.price); } } Collections.sort(list); // price の安い順
Comparable でない要素の List を Collections.sort に渡すとコンパイルエラー、TreeSet に add すると実行時に ClassCastException。
equals と一貫していないと
pen(100)・cup(100)・box(50) TreeSet → 2 個 // pen と cup は compareTo が 0 HashSet → 3 個 // equals は name も見る
null を含む List
Collections.sort([b, null, a]) // NullPointerException nullsFirst(naturalOrder()) // [null, a, b] nullsLast(reverseOrder()) // [b, a, null]
出典：API Comparable（consistent with equals）・Collections.sort・TreeSet・Comparator.nullsFirst／JDK 17 での実行結果

つなぐ順と reversed のかかり方

["bb", "a", "ccc", "dd"] を並べる
Comparator結果
comparing(String::length).thenComparing(reverseOrder())[a, dd, bb, ccc]

comparingInt(P::age).reversed() .thenComparing(P::name) // [Abe, Sato, Ito] 名前は逆にならない

ソートの道具と、安定なソート

呼び方順
list.sort(null)自然順序
list.sort(String.CASE_INSENSITIVE_ORDER)大小文字を区別しない
Arrays.sort(a, 1, 3)添字 1・2 だけ
Arrays.sort(int[], Comparator)コンパイルエラー
List.of(...) を sortUnsupportedOperationException
Arrays.asList(...) を sortできる（set だけ使う）
安定（stable）：同じ順位は元の順を保つ
[b, C, a, B].sort(null) // [B, C, a, b] .sort(CASE_INSENSITIVE_ORDER) // [a, B, b, C] B と b は元の順
TreeSet に Comparator
new TreeSet<>(comparing(String::length)) addAll(ab, cd, e, fgh) // [e, ab, fgh]

探す・数える

binarySearch（昇順の List で）
1[0]
3[1]
5[2]

並んでいない List では結果は保証されない。
メソッド例
frequency(list, "a")a の個数
disjoint(c1, c2)共通なし → true
max(list)自然順序の最大
min(list, reverseOrder())自然順序の最大
[3, 1, 2] を reverse → [2, 1, 3]（逆に並べるだけ）。大きい順は sort(list, reverseOrder())。
出典：API Collections.binarySearch・frequency・disjoint・max・min・reverse／JDK 17 での実行結果

並べる・作る・包む

list = [a, b, c] Collections.swap(list, 0, 2); // [c, b, a] Collections.addAll(list, "d", "e"); // [c, b, a, d, e] Collections.fill(list.subList(0, 2), "x"); // [x, x, a, d, e] Collections.nCopies(3, "z"); // [z, z, z]
メソッド返すもの
emptyList()空の変更できない List（add で UOE）
unmodifiableList(l)読み取り専用のビュー
synchronizedList(l)同期化したビュー
ビューは元とつながる。syn に add した "c" は un からも見える。
出典：API Collections.swap・addAll・fill・nCopies・emptyList・unmodifiableList・synchronizedList、List.subList／JDK 17 での実行結果
