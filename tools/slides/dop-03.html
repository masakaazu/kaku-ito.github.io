CodeArtifact

パッケージは社内のリポジトリから取る。

AWS DevOps #03 アーティファクトとイメージの構築タスク 1.3

ドメイン・リポジトリ・外部接続

npmjs.com・Maven Central公開リポジトリ
↓ 外部接続（1 リポジトリに 1 つ）
npm-store（外部接続を持つリポジトリ）取ったパッケージは保存される
↓ アップストリーム（最大 10 個）
team-a-repo ／ team-b-repoパッケージマネージャーの接続先は 1 つ
単位役目
ドメインアセットを 1 回だけ保存（重複排除）・1 つの KMS キーで暗号化・組織のポリシー
リポジトリポリグロット。どの形式も入る。別のドメインに移せない
パッケージ＞ パッケージバージョン ＞ アセット（.tgz・JAR）
外部接続はドメインに 1 つのリポジトリに付け、他はそれをアップストリームに。

認証とアクセスの制御

aws codeartifact login --tool npm \ --domain corp --domain-owner 111122223333 \ --repository team-a-repo # 既定 12 時間 # login 非対応のツールは aws codeartifact get-authorization-token ...
トークンは 15 分〜12 時間。切れたら取り直す（ビルドのたびに login）。
ルートユーザーは GetAuthorizationToken を呼べない。
ポリシー決めること
ドメインポリシー別アカウントに GetAuthorizationToken・CreateRepository
リポジトリポリシー読み取り・公開の許可（既定は所有者だけ）
オリジンコントロール直接の公開・アップストリームからの取り込みを許可／ブロック
社内名と同じ公開パッケージが混ざる → オリジンコントロールで取り込みをブロック。

ECR の困りごとと機能

困りごと機能覚えどころ
タグが上書きされるタグのイミュータビリティ同じタグでプッシュ → ImageTagAlreadyExistsException
古いイメージがたまるライフサイクルポリシー数値が小さいほど優先。適用前にプレビュー
OS の脆弱性基本スキャンCVE データベース。手動・プッシュ時
言語パッケージも継続的に拡張スキャンAmazon Inspector。プッシュ時・継続的
別リージョン・別アカウントレプリケーション設定後のプッシュだけ複製。送信先のレジストリポリシー
Docker Hub の制限プルスルーキャッシュ定期的に最新化。認証は Secrets Manager
別アカウントから取るリポジトリポリシーecr:BatchGetImage などを許可

イメージパイプラインの部品
