ReentrantLock と AtomicInteger

ReentrantLock l = new ReentrantLock(); l.unlock(); // IllegalMonitorStateException l.lock(); l.lock(); l.getHoldCount() // 2 l.tryLock() // true（同じスレッド）→ 3 // 3 回 unlock して外れる l.lock(); try { /* 処理 */ } finally { l.unlock(); } // 別スレッドが持っているとき l.tryLock() // すぐ false l.tryLock(100, TimeUnit.MILLISECONDS) // 100ms 後 false
AtomicInteger c = new AtomicInteger(400000); c.getAndIncrement() // 400000（→400001） c.incrementAndGet() // 400002 c.addAndGet(5) // 400007 c.compareAndSet(400007, 0) // true → 0
ReentrantReadWriteLock：読み込みロックは共有できる。読み込み中は書き込みロックを取れない（read true write false）。
