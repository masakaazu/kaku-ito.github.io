else if は上から 1 つだけ

x = 75 のときの流れ（Claude が作成）
// 正しい順：範囲のせまい条件から
if (x >= 80)      System.out.println("A");
else if (x >= 70) System.out.println("B");
else if (x >= 60) System.out.println("C");
else               System.out.println("F");
else if は特別な文法ではない。else のあとの文が、たまたま次の if 文になっているだけ。だから上から順に、最初に true になった枝だけを実行する。
else だけの枝：上のどれにも当てはまらないとき。else のあとに条件は書けない。

k = 2 のとき（Claude が作成）
ケース結果（JDK 17）
上の switch で k = 2two three other
k = 9（合う case なし）other

default は「合う case がないときの入口」。どこに書いても、合う case があれば使われない。入ったあとは break まで落ちる。1 つの switch に 1 つまで。

セレクタの型と case 定数の決まり

セレクタの型使えるか
char・byte・short・int使える
Character・Byte・Short・Integer使える（アンボクシング）
String・enum使える

case の書き方結果（JDK 17）

final int y = 2; … case y:OK（定数変数）

第3章

アロー形式と switch 式

-> は落ちない。switch 式は必ず値を返す。

Java Silver #06 分岐と switch試験内容 3

アロー形式（switch ルール）

int day = 6;
switch (day) {
  case 1, 7 -> System.out.println("holiday");
  case 2, 3, 4, 5, 6 -> System.out.println("weekday");
  default -> System.out.println("?");
}
// weekday だけ（下へ落ちない）
右側の形例
式case 1 -> count++;
ブロックcase 1 -> { … }
throw 文case 1 -> throw new …;
書き方結果（JDK 17）
case 1 -> …; case 2: …different case kinds used in the switch
switch 文で case 2 -> "two";not a statement
default -> を先頭、k は 2case 2 だけ実行
ブロックごとに int a を宣言OK（スコープが別）
switch 文の -> の右は「式文」だけ：メソッド呼び出し・代入・++/-- ・new。値だけの式（"two" や 1 + 2）は文にならない。
出典：JLS 14.11.1（SwitchRule: SwitchLabel -> Expression ; | SwitchLabel -> Block | SwitchLabel -> ThrowStatement）・14.11.2（Every switch rule expression in the switch block is a statement expression）・14.11.3（the switch rule expression or statement introduced by the switch label is executed, and nothing else）・14.8 Expression Statements／結果は JDK 17 で確かめたもの

switch 式 ― 値を返し、すべての値を処理する

String s = switch (day) {
  case 1, 7 -> "holiday";
  default -> {
    System.out.print("calc ");
    yield "weekday";     // ブロックから値を返す
  }
};                            // 代入文の終わりの ;
ブロックの最後に書けないもの（JDK 17 の表示）
"weekday";not a statement
return "weekday";attempt to return out of a switch expression
break "weekday";';' expected
セレクタ網羅性の満たし方
int・String などdefault が必須（ちょうど 1 つ）
enum全定数を case に書けば default 不要
足りないと：the switch expression does not cover all possible input values。実際に来る値が書いてあっても、型で判断される。
switch 文との差：switch 文は、合うものがなければ何もせず終わる。switch 式は必ず値が必要なので、コンパイル時に全部を処理しているか調べる。
出典：JLS 15.28.1 The Switch Block of a switch Expression（If the type of the selector expression is not an enum type, then there is exactly one default label／If the type … is an enum type, then (i) the set of the case constants … includes every enum constant … A default label is permitted, but not required）／JLS 14.21 The yield Statement／結果は JDK 17 で確かめたもの

コロン形式の switch 式・式の型・throw

コロン形式でも書ける（yield まで落ちる）
int k = 2;
int r = switch (k) {
  case 1: yield 10;
  case 2: System.out.print("x ");
  case 3: yield 30;
  default: yield 0;
};
System.out.println(r);         // x 30
throw の枝
int r = switch (k) {
  case 2 -> throw new IllegalStateException("no");
  default -> 1;
};                       // k が 2 なら例外
結果の式switch 式の型（var で受けたとき）
全部 StringString
int と doubledouble（1 は 1.0）
boolean と Booleanboolean
String と int共通の参照型（Object など）
var r = switch (1) {
  case 1 -> 1;  case 2 -> 2.5;  default -> 0;
};   // 1.0
代入先がある場合（int r = switch…）は、各結果の式が int に代入できればよい。
出典：JLS 15.28.1（If the switch block consists of switch labeled statement groups, then every expression immediately contained in a yield statement … is a result expression／The type of a standalone switch expression … general numeric promotion／The type of a poly switch expression is the same as its target type）／JLS 14.11.1（SwitchLabel -> ThrowStatement）／結果は JDK 17 で確かめたもの

問われ方とまちがえやすい点

こう聞かれたら答えの考え方
if の表示結果字下げを無視し、{ } と ; で範囲を読む。else はいちばん近い if
else if の結果上から順に、最初に true の枝だけ
