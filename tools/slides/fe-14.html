14-3 資源・時間・コスト日程・見積りとコスト

アローダイアグラムPERT図 / Arrow Diagram
作業の順序と所要日数を矢印で表した図
ポイント最早結合点時刻は「先行作業の終了の最大値」、最遅結合点時刻は「後ろから求めた候補の最小値」
クリティカルパスCritical Path
開始から終了までで、所要日数の合計が最も長い経路
ポイントこの経路の作業が遅れると全体が遅れる（余裕日数0）
ガントチャートGantt Chart
作業を縦に、時間を横にとり、作業の予定と実績を横棒で表した図
クラッシングCrashing
人や費用を追加して、クリティカルパス上の作業の期間を縮めること
ファストトラッキングFast Tracking
本来は順番に行う作業を並行して進め、期間を縮めること
ファンクションポイント法Function Point Method
画面や帳票、ファイルなどの機能の数と複雑さから、開発の規模を見積もる方法

14-3 資源・時間・コスト見積りとコスト

類推見積法Analogous Estimating
過去の似たプロジェクトの実績をもとに見積もる方法
EVMいーぶいえむ / Earned Value Management
計画（PV）・出来高（EV）・実コスト（AC）を比べて、進み具合とコストを管理する方法
Earned＝得られた／Value＝価値／Management＝管理
PV・EV・ACPlanned Value / Earned Value / Actual Cost
PVは計画した作業の予算、EVは終わった作業の予算での価値（出来高）、ACは実際にかかった費用
例PV100万・EV80万・AC90万なら SV＝−20万（遅れ）、CV＝−10万（予算オーバー）
Planned＝計画された／Earned＝得られた／Actual＝実際の／Cost＝費用
人月にんげつ / Man-month
1人が1か月で行う作業の量
例6人月の作業を3人で行うと2か月

14-4 リスク・品質・調達・コミュニケーションその他の管理

リスク管理Risk Management
起こるかもしれない不確かな出来事を見つけ、分析して対策をとること
ポイント対応は回避・転嫁・軽減・受容の4つ
リスクの転嫁Risk Transfer
保険や外部委託で、リスクの影響を第三者に移すこと
品質管理Quality Management
成果物が求められる品質を満たすように計画し、確かめること
調達管理Procurement Management
外部から製品やサービスを買う計画・契約・管理を行うこと
コミュニケーション管理Communications Management
関係者の間で、必要な情報を適切に伝え合えるようにすること
責任分担表RAM / Responsibility Assignment Matrix
作業ごとに、誰がどんな役割をもつかを表にしたもの
例RACIチャート
