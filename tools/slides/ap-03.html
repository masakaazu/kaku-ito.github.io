3-1 プロセッサCPUのしくみ

CPUしーぴーゆー / Central Processing Unit
命令を読み取って解読し、計算や制御を行う装置
ポイント制御装置と演算装置からなる
Central＝中央の／Processing＝処理／Unit＝装置
レジスタRegister
CPUの中にある、とても速い小さな記憶場所
ポイントプログラムカウンタ・命令レジスタ・汎用レジスタなど
アドレス指定方式Addressing Mode
命令の中のアドレス部から、データの場所を決める方法
ポイント即値・直接・間接・指標（インデックス）・基底・相対など
パイプラインPipeline
命令の実行をいくつかの段階に分け、少しずつずらして同時に進める方式
ポイント分岐やデータの依存で流れが止まること（ハザード）がある
スーパスカラSuperscalar
パイプラインを複数持ち、同時に複数の命令を実行する方式
分岐予測Branch Prediction
分岐先を予測して先に命令を進め、パイプラインの乱れを減らす方法
ポイント外れたら投機実行した結果を捨てる

3-1 プロセッサCPUのしくみ

CISC・RISCComplex / Reduced Instruction Set Computer
CISCは複雑で多機能な命令を持つCPU、RISCは単純で長さのそろった命令を持つCPU
ポイントRISCはパイプラインに向き、ワイヤードロジックで制御する
Complex＝複雑な／Reduced＝減らした／Instruction Set＝命令の集まり
マルチコアプロセッサMulti-core Processor
1つのチップに複数のコア（処理の中心）を載せたCPU
GPUじーぴーゆー / Graphics Processing Unit
画像処理向けのプロセッサ。大量の単純な計算を並列に行える
ポイントAIの学習にも使う
Graphics＝画像／Processing＝処理／Unit＝装置
CPIしーぴーあい / Cycles Per Instruction
1命令の実行に必要なクロック数の平均
Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令
MIPSみっぷす / Million Instructions Per Second
1秒間に何百万の命令を実行できるかを表す性能の指標
Million＝百万／Instructions＝命令／Per Second＝毎秒

3-2 メモリ記憶装置

DRAM・SRAMDynamic / Static RAM
DRAMはコンデンサに電荷をためて記憶し、リフレッシュが必要。安く大容量で主記憶に使う。SRAMはフリップフロップで記憶し、速いが高価でキャッシュに使う
Dynamic＝動的／Static＝静的／RAM＝読み書きできる記憶装置
フラッシュメモリFlash Memory
電源を切っても内容が消えず、電気的に書き換えられるメモリ
ポイントSSDやUSBメモリに使う。書換えの回数に上限がある
キャッシュメモリCache Memory
CPUと主記憶の速さの差を埋める、小さく速いメモリ
ポイント1次・2次・3次と階層になっている
実効アクセス時間Effective Access Time
キャッシュを使うときの平均のアクセス時間
ポイントヒット率×キャッシュの時間 ＋（1−ヒット率）×主記憶の時間
参照の局所性Locality of Reference
最近使ったデータや、その近くのデータは、また使われやすいという性質
ポイントキャッシュが効く理由
メモリインタリーブMemory Interleave
主記憶を複数のバンクに分け、同時にアクセスして速くする方式
応用情報 コンピュータ構成要素8

3-3 バスデータの通り道

バスBus
装置どうしをつなぎ、データをやり取りする共通の通り道
ポイントアドレスバス・データバス・制御バスがある
バス幅Bus Width
一度に送れるビット数
ポイント転送速度 ＝ バス幅 × クロック周波数
PCI ExpressPeripheral Component Interconnect Express
拡張カードをつなぐシリアル転送のバスの規格
ポイントレーン数を増やすと速くなる
Peripheral＝周辺の／Component＝部品／Interconnect＝相互接続

3-4 入出力デバイスつなぐ規格

USBゆーえすびー / Universal Serial Bus
パソコンと周辺機器をつなぐシリアルの規格
ポイントバスパワーで電源も送れる。ホットプラグに対応
Universal＝汎用の／Serial＝直列の／Bus＝伝送路
DMAでぃーえむえー / Direct Memory Access
CPUを通さずに、入出力装置と主記憶の間で直接データを転送する方式
ポイントCPUの負担が減る
Direct＝直接の／Memory＝記憶装置／Access＝読み書き
割込みInterrupt
実行中の処理を中断して、別の処理を先に行うしくみ
ポイント内部割込み（0での割り算・ページフォールトなど）と外部割込み（入出力の完了・タイマなど）
デバイスドライバDevice Driver
OSが周辺機器を動かすためのソフトウェア
Bluetoothブルートゥース
近くの機器を無線でつなぐ規格
ポイントBLEは消費電力が少なくIoTに向く

3-5 入出力装置装置

SSDえすえすでぃー / Solid State Drive
フラッシュメモリを使った補助記憶装置
ポイントHDDより速く衝撃に強い。ウェアレベリングで書込みを分散する
Solid State＝半導体の／Drive＝装置
HDDのアクセス時間Access Time
平均シーク時間 ＋ 平均回転待ち時間 ＋ データ転送時間
ポイント平均回転待ち時間は1回転の時間の半分
有機ELOrganic Electro-Luminescence
電気を流すと自ら光る材料を使ったディスプレイ
ポイントバックライトがいらず、薄く曲げられる
