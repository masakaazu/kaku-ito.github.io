7-1 ヒューマンインタフェース技術操作の仕組み・画面の部品

ヒューマンインタフェースHuman Interface
人とコンピュータが情報をやり取りする接点
ポイント画面・キーボード・音声など
GUIじーゆーあい / Graphical User Interface
アイコンやボタンなどの図を、マウスやタッチで操作する方式
ポイント文字でコマンドを打つのはCUI
Graphical＝図を使った／User＝利用者／Interface＝接点
CUIしーゆーあい / Character User Interface
キーボードから文字でコマンドを入力して操作する方式
Character＝文字の／User＝利用者／Interface＝接点
マルチタッチMulti-touch
画面の複数の点に同時に触れて操作できる仕組み
例2本指で広げて拡大（ピンチアウト）
音声認識おんせいにんしき / Speech Recognition
人の話す声を、コンピュータが文字や命令として理解する技術
ラジオボタンRadio Button
いくつかの選択肢から1つだけを選ぶ部品
ポイント複数を選べるのはチェックボックス

7-2 インタフェース設計まとめ表

画面設計の原則
観点やること
一貫性同じ操作は同じ場所・同じ見た目にそろえる
視認性大事な情報を目立たせ、見やすくする
エラー防止誤った入力をしにくくし、間違えたら直し方を示す
利用者に合わせる初心者にも慣れた人にも使いやすくする（ショートカットなど）

7-2 インタフェース設計使いやすさの考え方

ユーザビリティUsability
特定の利用者が、目的を効果的・効率的・満足して達成できる度合い
ポイントJIS Z 8521（ISO 9241-11）で定義されている
アクセシビリティAccessibility
高齢者や障害のある人を含め、だれもが情報やサービスを使えること
例画像に代わりの文章を付ける、色だけで区別しない
ユニバーサルデザインUniversal Design
年齢や能力にかかわらず、はじめからできるだけ多くの人が使えるように設計する考え方
UXゆーえっくす / User Experience
製品やサービスを使うことで利用者が得る体験全体
ポイント使いやすさだけでなく、楽しさや満足も含む
User＝利用者／Experience＝体験
人間中心設計にんげんちゅうしんせっけい / Human-centred Design
利用者の立場を中心に、評価と改善を繰り返しながら設計する考え方
ポイントJIS Z 8530（ISO 9241-210）
ヒューリスティック評価Heuristic Evaluation
専門家が経験則（ガイドライン）に照らして、使いにくい点を見つける評価方法
基本情報 ユーザーインタフェース6

7-2 インタフェース設計使いやすさの考え方

画面設計がめんせっけい / Screen Design
入力画面や表示画面の項目・配置を決めること
ポイント入力の順番を、もとの伝票などの並びに合わせると入力しやすい
帳票設計ちょうひょうせっけい / Form Design
印刷する書類の項目や配置を決めること
コード設計こーどせっけい / Code Design
商品番号などのコード（識別番号）の付け方を決めること
例区分ごとに桁を割り当てる、入力ミスを見つけるチェックディジットを付ける
チェックディジットCheck Digit
コードの数字から計算して末尾に付ける検査用の数字
ポイント入力ミスを見つけられる
WebデザインWeb Design
Webページの見た目や構成を設計すること
ポイントレスポンシブデザインは、画面の大きさに合わせて表示を変える
