## 23-1 知的財産権

### まとめ表

**知的財産権の種類（何を守るか・手続・期間）**

| 権利 | 守るもの | 権利の発生 | 保護期間 |
| :-: | :-: | :-: | :-: |
| 著作権 | 思想又は感情を創作的に表現したもの（プログラムも含む） | 創作した時点で自動的に発生（無方式主義） | 原則、著作者の死後70年（法人名義は公表後70年） |
| 特許権 | 自然法則を利用した技術的思想の創作のうち高度なもの（発明） | 出願→審査→登録 | 出願から20年 |
| 実用新案権 | 物品の形状・構造・組合せに関する考案（小発明） | 出願→登録（実体審査なし） | 出願から10年 |
| 意匠権 | 物品・建築物・画像の形状・模様・色彩など、視覚を通じて美感を起こさせるデザイン | 出願→審査→登録 | 出願から25年 |
| 商標権 | 商品やサービスに使う文字・図形・記号などのマーク | 出願→審査→登録 | 登録から10年（更新できる） |
| 営業秘密 | 秘密管理性・有用性・非公知性を満たす情報（不正競争防止法） | 登録不要 | 期間の定めなし |

**プログラムの著作権は誰のものか（契約で決めていないとき）**

| 状況 | 著作権の帰属 |
| :-: | :-: |
| 社員が職務として作り、会社名義で公表 | 会社（職務著作） |
| 他社に開発を委託（請負） | 実際に作った受託側の会社（R4春 問77） |
| 再委託（A→B→C） | 実際に作ったC社。C社の社員が職務で作ればC社（R4秋 問78） |
| 派遣社員が派遣先の指揮命令で作成 | 派遣先の会社 |

### 知的財産権の全体像

#### 知的財産権（ちてきざいさんけん / Intellectual Property Rights）

- 意味：人間の知的な創作活動から生まれたもの（発明・デザイン・著作物・マークなど）について、創作した人に一定期間与えられる独占的な権利の総称
- ポイント：大きく、著作権・産業財産権（特許・実用新案・意匠・商標）・その他（回路配置利用権・営業秘密など）に分かれる
- 語の意味：Intellectual＝知的な／Property＝財産／Rights＝権利

#### 産業財産権（さんぎょうざいさんけん / Industrial Property Rights）

- 意味：特許権・実用新案権・意匠権・商標権の四つの権利の総称。特許庁に出願して登録されることで権利が発生する
- ポイント：産業の発達を目的とする権利。著作権は文化の発展が目的で、登録は不要（無方式主義）
- 語の意味：Industrial＝産業の／Property＝財産

#### 知的財産基本法（ちてきざいさんきほんほう）

- 意味：知的財産の創造・保護・活用に関する基本理念と、国などの責務を定めた法律。内閣に知的財産戦略本部を置くことを定める
- ポイント：個々の権利の内容は特許法・著作権法などの個別の法律で定める。この法律は国の方針の土台
- 語の意味：基本法＝国の政策の基本方針を定める法律

#### 回路配置利用権（かいろはいちりようけん）

- 意味：半導体集積回路（IC）の回路の配置（レイアウト）を保護する権利。半導体集積回路の回路配置に関する法律に基づき、登録で発生する
- ポイント：保護期間は登録から10年。回路の「配置」を守るもので、回路の機能のアイディアは特許の対象
- 語の意味：回路配置＝ICの中の素子や配線の並べ方

### 著作権の中身

#### 著作物（ちょさくぶつ / Work）

- 意味：思想又は感情を創作的に表現したものであって、文芸・学術・美術・音楽の範囲に属するもの。プログラムやデータベース（情報の選択や体系的な構成に創作性があるもの）も含まれる
- ポイント：表現が守られ、アイディアは守られない。プログラム言語・規約（プロトコル）・解法（アルゴリズム）は、著作権法でプログラムの著作物の保護の対象外と明記されている（R6秋 問78、R7秋 問78）
- 語の意味：著作＝書物などを書き著すこと

#### 無方式主義（むほうしきしゅぎ）

- 意味：著作権は、登録や表示などの手続をしなくても、著作物を創作した時点で自動的に発生するという考え方
- ポイント：日本やベルヌ条約加盟国が採用。©表示は権利の発生に必要ない。産業財産権は出願・登録が必要な方式主義
- 語の意味：方式＝手続・形式

#### 著作者人格権（ちょさくしゃじんかくけん / Moral Rights）

- 意味：著作者の人格的な利益（こだわりや名誉）を守る権利。公表権・氏名表示権・同一性保持権からなる
- ポイント：他人に譲渡したり相続したりできない（一身専属）。財産としての著作権（著作財産権）は譲渡できる
- 語の意味：人格＝その人自身に結び付いたもの

#### 公表権（こうひょうけん）

- 意味：まだ公表されていない自分の著作物を、公表するかどうか、いつ・どのように公表するかを決める権利
- ポイント：著作者人格権の一つ
- 語の意味：公表＝世の中に発表すること

#### 氏名表示権（しめいひょうじけん）

- 意味：著作物を公表するときに、著作者名を表示するかどうか、実名かペンネームかを決める権利
- ポイント：著作者人格権の一つ
- 語の意味：氏名表示＝名前を示すこと

#### 同一性保持権（どういつせいほじけん）

- 意味：著作物の内容や題名を、著作者の意に反して勝手に改変されない権利
- ポイント：プログラムを特定のコンピュータで使えるようにするための改変や、より効果的に使うための改変（バグ修正・高速化）は、やむを得ない改変として認められる（R5秋 問78 のエ）
- 語の意味：同一性＝同じであること／保持＝保つこと

#### 著作財産権（ちょさくざいさんけん / Copyright）

- 意味：著作物の利用による経済的な利益を守る権利の集まり。複製権・公衆送信権・展示権・頒布権・譲渡権・貸与権・翻案権などがある
- ポイント：譲渡・相続ができる。狭い意味で「著作権」と言えばこちら
- 語の意味：財産＝経済的な価値のあるもの

#### 複製権（ふくせいけん / Right of Reproduction）

- 意味：著作物を印刷・コピー・録音・録画などの方法で複製することを独占する権利
- ポイント：購入したプログラムを、社内の各部門に配るためにコピーするのは複製権の侵害（R5秋 問78 のイ）。自分で使うためのバックアップは認められる
- 語の意味：Reproduction＝複製

#### 公衆送信権（こうしゅうそうしんけん）

- 意味：著作物を、放送・有線放送・インターネットなどで公衆に送信することを独占する権利。サーバに置いていつでも送信できる状態にする「送信可能化」も含む
- ポイント：他人の著作物を無断で Web に掲載するのは、アクセスがなくても送信可能化の時点で侵害になる
- 語の意味：公衆＝不特定多数の人

#### 貸与権・譲渡権・頒布権（たいよけん・じょうとけん・はんぷけん）

- 意味：著作物の複製物を公衆に貸す権利（貸与権）、売るなどして譲り渡す権利（譲渡権）、映画の著作物の複製物を配る権利（頒布権）
- ポイント：一度適法に販売された複製物の転売には、譲渡権は及ばない（消尽）。レンタルには貸与権が及ぶ
- 語の意味：貸与＝貸すこと／譲渡＝譲り渡すこと／頒布＝広く配ること

#### 職務著作（しょくむちょさく / Work for Hire）

- 意味：会社の発意に基づき、社員が職務として作成し、会社の名義で公表する著作物。契約や就業規則に別の定めがなければ、著作者は会社（法人）になる
- ポイント：プログラムは公表しないものでも会社が著作者になる。作った社員が独断で複製して他社に貸すのは侵害（R5秋 問78 のウ）
- 語の意味：職務＝仕事として担当する務め

#### 二次的著作物（にじてきちょさくぶつ / Derivative Work）

- 意味：元の著作物を翻訳・編曲・変形・映画化などして新たに作った著作物
- ポイント：作るには元の著作者の許諾が必要（翻案権）。二次的著作物を利用するときは、元の著作者の権利も及ぶ
- 語の意味：二次的＝元のものから派生した

#### 引用（いんよう / Quotation）

- 意味：公表された著作物を、自分の著作物の中で、報道・批評・研究などの目的で、正当な範囲で利用すること。許諾は不要
- ポイント：自分の文章が主で引用部分が従であること、引用部分がはっきり区別されていること、出所を明示することが条件
- 語の意味：引用＝他人の言葉を引いて用いること

#### 私的使用のための複製（してきしようのためのふくせい）

- 意味：個人的に、または家庭内など限られた範囲で使う目的なら、著作物を許諾なく複製できるという例外
- ポイント：会社の業務での利用は私的使用ではない。違法にアップロードされたものと知りながらダウンロードするのは対象外
- 語の意味：私的＝個人的な

#### 非享受利用（ひきょうじゅりよう / 情報解析）

- 意味：著作物に表現された思想や感情を人が楽しむ（享受する）ことを目的としない利用。AIの学習のための情報解析などが当たり、原則として許諾なく利用できる（著作権法30条の4）
- ポイント：ただし著作権者の利益を不当に害する場合は除く。学習が適法でも、生成物が既存の著作物に似ていて（類似性）、それをもとに作った（依拠性）なら、公開すると侵害になりうる（R7春 問78）
- 語の意味：享受＝味わい楽しむこと

#### フェアユース（Fair Use）

- 意味：米国の著作権法の考え方で、公正な利用と認められれば、許諾なく著作物を利用できるという一般的な規定
- ポイント：日本にはフェアユースのような一般規定はなく、引用・私的使用・情報解析など個別に例外を定めている
- 語の意味：Fair＝公正な／Use＝利用

#### 差止請求権（さしとめせいきゅうけん）

- 意味：権利を侵害している、または侵害するおそれのある者に対して、その行為をやめるよう（予防するよう）求める権利
- ポイント：著作権・特許権・商標権・不正競争防止法などで認められる。過去の損害の補償を求めるのは損害賠償請求
- 語の意味：差し止める＝やめさせる

### 産業財産権の4つ

#### 特許権（とっきょけん / Patent）

- 意味：発明（自然法則を利用した技術的思想の創作のうち高度なもの）を、出願から20年間、独占的に実施できる権利
- ポイント：新規性・進歩性・産業上の利用可能性などが必要。特許庁の審査を経て登録で発生する（R6春 問78）
- 語の意味：Patent＝公開された（独占の許可状）

#### 実用新案権（じつようしんあんけん / Utility Model Right）

- 意味：物品の形状・構造・組合せに関する考案（発明ほど高度でなくてよい小発明）を保護する権利。保護期間は出願から10年
- ポイント：実体審査をせずに登録されるので早く権利が取れる。方法やプログラムそのものは対象外
- 語の意味：Utility＝実用／Model＝型

#### 意匠権（いしょうけん / Design Right）

- 意味：物品・建築物・画像の形状・模様・色彩などで、視覚を通じて美感を起こさせるデザイン（意匠）を保護する権利。保護期間は出願から25年
- ポイント：2020年の改正で、物品に表示されない画像（操作画面・GUI）も保護の対象になった（R7秋 問79）
- 語の意味：意匠＝工夫を凝らしたデザイン

#### 商標権（しょうひょうけん / Trademark Right）

- 意味：商品やサービス（役務）に使う文字・図形・記号・立体形状・色彩・音などのマーク（商標）を保護する権利。登録から10年で、更新を続ければ何度でも延長できる
- ポイント：他の権利と違い、更新で半永久的に保護できる。使われている信用を守ることが目的
- 語の意味：Trademark＝商標（取引の印）

#### ソフトウェア特許（Software Patent）

- 意味：ソフトウェアによる情報処理が、ハードウェアを使って具体的に実現されている発明として、特許の対象となったもの
- ポイント：プログラムは著作権でも保護されるが、著作権は表現、特許はアイディア（技術的思想）を守る点が違う
- 語の意味：Software＝ソフトウェア／Patent＝特許

#### ビジネスモデル特許（ビジネス方法の特許 / Business Method Patent）

- 意味：ITを利用したビジネスの方法（仕組み）について認められた特許
- ポイント：ビジネスのアイディアそのものではなく、情報技術を使って実現する具体的な仕組みでなければ特許にならない。意匠法の対象にはならない（R7秋 問79 の誤りの選択肢エ）
- 語の意味：Business＝事業／Method＝方法

#### 先願主義（せんがんしゅぎ / First-to-file）

- 意味：同じ発明について複数の出願があった場合、先に出願した人に権利を与える考え方
- ポイント：日本・欧州・米国（2013年から）が採用。先に発明した人に与えるのは先発明主義
- 語の意味：先願＝先に出願すること

#### 職務発明（しょくむはつめい / Employee Invention）

- 意味：従業員が、会社の業務の範囲内で、職務として行った発明
- ポイント：特許を受ける権利は原則として従業員にあるが、就業規則などで定めれば最初から会社に帰属させられる。その場合、従業員は相当の利益（報奨）を受けられる
- 語の意味：職務＝仕事として担当する務め

### 不正競争防止法と営業秘密

#### 不正競争防止法（ふせいきょうそうぼうしほう / Unfair Competition Prevention Act）

- 意味：事業者間の公正な競争を確保するため、他人の商品表示をまねる行為・営業秘密の不正取得・ドメイン名の不正取得・コピープロテクト外しの提供などを禁止する法律
- ポイント：登録がなくても保護される。広く知られた他人の商品表示に似せて誤認させる行為は禁止（R3春 問78）。価格の不当な拘束は独占禁止法の対象
- 語の意味：Unfair＝不公正な／Competition＝競争

#### 営業秘密（えいぎょうひみつ / Trade Secret）

- 意味：秘密として管理されている（秘密管理性）、事業に有用な（有用性）、公然と知られていない（非公知性）、技術上または営業上の情報
- ポイント：三つの要件を全て満たす必要がある。顧客名簿やソースコードなど。アクセス制限や「秘」表示がないと秘密管理性を満たさない
- 語の意味：Trade＝商売／Secret＝秘密

#### 周知表示混同惹起行為（しゅうちひょうじこんどうじゃっきこうい）

- 意味：需要者の間に広く知られている他人の商品表示や営業表示と同じか似た表示を使い、他人の商品や営業と混同させる行為
- ポイント：不正競争行為の一つ。全国的に有名である必要はなく、一定の地域で広く知られていればよい
- 語の意味：周知＝広く知られている／惹起＝引き起こすこと

#### ドメイン名の不正取得（ドメインめいのふせいしゅとく）

- 意味：不正な利益を得る目的や、他人に損害を与える目的で、他人の商品名・社名などと同じか似たドメイン名を取得・保有・使用する行為
- ポイント：「目的」が要件。偶然に似たドメインを取った場合や、正当な目的がある場合は該当しない。コピー商品を売るために商品名のドメインを取るのは該当する（R6春 問79）
- 語の意味：Domain＝ドメイン（インターネット上の住所）

#### 技術的制限手段の回避（ぎじゅつてきせいげんしゅだんのかいひ）

- 意味：コピープロテクトやアクセス制御（ライセンス認証など）を無効にする装置・プログラム・サービスを提供する行為
- ポイント：不正競争防止法と著作権法の両方で規制されている。「コピープロテクト外し」と呼ばれる
- 語の意味：回避＝避けてすり抜けること

### 国際条約と機関

#### パリ条約（Paris Convention）

- 意味：特許・実用新案・意匠・商標などの工業所有権（産業財産権）を国際的に保護するための条約
- ポイント：外国人にも自国民と同じ保護を与える「内国民待遇」と、最初の出願から一定期間内なら他国での出願日を最初の日とみなす「優先権」が柱
- 語の意味：Paris＝締結地パリ／Convention＝条約

#### PCT（Patent Cooperation Treaty / 特許協力条約）

- 意味：一つの国際出願をすれば、加盟している複数の国に同時に出願したのと同じ効果が得られる仕組みを定めた条約
- ポイント：手続を一本化するもの。特許を与えるかは各国がそれぞれ審査する（世界共通の特許はない）
- 語の意味：Patent＝特許／Cooperation＝協力／Treaty＝条約

#### ベルヌ条約（Berne Convention）

- 意味：文学的・美術的著作物を国際的に保護するための条約。無方式主義を原則とする
- ポイント：著作権の国際条約の中心。方式主義の国との橋渡しのために作られたのが万国著作権条約（©表示を定めた）
- 語の意味：Berne＝締結地ベルン（スイス）

#### TRIPS協定（Agreement on Trade-Related Aspects of Intellectual Property Rights）

- 意味：WTO（世界貿易機関）の加盟国に、知的財産権の最低限の保護水準と、権利行使の手続を義務付けた協定
- ポイント：貿易と結び付けて知的財産を守る。違反すると WTO の紛争解決手続の対象になる
- 語の意味：Trade-Related＝貿易に関連する

#### WIPO（World Intellectual Property Organization / 世界知的所有権機関）

- 意味：知的財産権の国際的な保護を進める国際連合の専門機関。パリ条約・ベルヌ条約・PCTなどを管理する
- ポイント：本部はジュネーブ。貿易と結び付けた保護は WTO の TRIPS協定
- 語の意味：World＝世界／Intellectual Property＝知的財産／Organization＝機関

## 23-2 セキュリティ関連法規

### まとめ表

**コンピュータ犯罪の法律の分担**

| 行為 | 罰する法律 |
| :-: | :-: |
| 他人のID・パスワードを使ってネットワーク経由でログインする | 不正アクセス禁止法（不正アクセス行為） |
| 他人のID・パスワードを、正当な理由なく第三者に教える | 不正アクセス禁止法（助長する行為） |
| フィッシングサイトを作ってIDとパスワードの入力を求める | 不正アクセス禁止法（識別符号の入力を不正に要求する行為） |
| データを消去・改ざんして業務を妨害する（媒体経由でも） | 刑法（電子計算機損壊等業務妨害罪）（R3秋 問78） |
| 正当な理由なくウイルスを作成・提供・保管する | 刑法（不正指令電磁的記録に関する罪） |
| 虚偽のデータを入力して不正に利益を得る | 刑法（電子計算機使用詐欺罪） |

**個人情報の加工の種類**

| 種類 | どこまで加工するか | 主な使い道 | 第三者提供 |
| :-: | :-: | :-: | :-: |
| 仮名加工情報 | 他の情報と照合しなければ本人が分からない程度（氏名を削るなど） | 社内での分析 | 原則できない |
| 匿名加工情報 | 本人を特定できず、元に戻せない程度 | 他社への提供・データ流通 | 本人の同意なしでできる（項目と方法を公表）（R5秋 問79） |
| 統計情報 | 個人と結び付かない集計値 | 公表など | 個人情報ではない |

### サイバーセキュリティ基本法

#### サイバーセキュリティ基本法（Basic Act on Cybersecurity）

- 意味：サイバーセキュリティに関する施策を総合的・効果的に進めるため、基本理念と、国・地方公共団体・重要社会基盤事業者・サイバー関連事業者・教育研究機関の責務、国民の努力などを定めた法律
- ポイント：内閣にサイバーセキュリティ戦略本部を置き、サイバーセキュリティ戦略を定める。個別の罰則を定める法律ではない
- 語の意味：Cybersecurity＝電子的な情報やシステムの安全

#### 重要社会基盤事業者（じゅうようしゃかいきばんじぎょうしゃ）

- 意味：国民生活や経済活動の基盤となるサービス（電力・ガス・水道・金融・通信・交通など）を提供する事業者。重要インフラ事業者ともいう
- ポイント：サイバーセキュリティ基本法で、自主的・積極的に対策に取り組み、国の施策に協力する責務が定められている
- 語の意味：社会基盤＝インフラ

#### サイバーセキュリティ協議会（Cybersecurity Council）

- 意味：国の機関・地方公共団体・重要社会基盤事業者・セキュリティ事業者などが、サイバー攻撃に関する情報を共有し、対策を協議する組織。サイバーセキュリティ基本法に基づく
- ポイント：構成員には守秘義務と、求めに応じた情報提供の義務がある
- 語の意味：協議会＝話し合いのための会

#### 電磁的記録（でんじてききろく / Electromagnetic Record）

- 意味：電子的方式・磁気的方式など、人の知覚では認識できない方式で作られ、コンピュータで処理するための記録
- ポイント：刑法・電子署名法・e-文書法など多くの法律で使われる用語。電子データのこと
- 語の意味：電磁的＝電気や磁気を使った

### 不正アクセス禁止法と刑法

#### 不正アクセス禁止法（ふせいアクセスきんしほう / Act on the Prohibition of Unauthorized Computer Access）

- 意味：ネットワークを通じて、アクセス制御機能のあるコンピュータに、他人のID・パスワードを使うなどして不正に侵入する行為や、それを助長する行為を禁止する法律
- ポイント：データの改ざんや破壊がなくても、侵入しただけで罰せられる。データの消去や業務妨害は刑法の対象
- 語の意味：Unauthorized＝許可のない／Access＝接続・利用

#### 不正アクセス行為（ふせいアクセスこうい）

- 意味：アクセス制御機能のあるコンピュータに、ネットワーク経由で、他人の識別符号（ID・パスワード）を入力したり、脆弱性を突いて制御をすり抜けたりして、利用できる状態にする行為
- ポイント：ネットワークを経由しない（直接その場で操作する）場合は不正アクセス行為に当たらない
- 語の意味：識別符号＝本人を見分けるための符号

#### 不正アクセス行為を助長する行為（ふせいアクセスこういをじょちょうするこうい）

- 意味：業務その他正当な理由なく、他人のID・パスワードを、正規の利用者や管理者以外の者に提供する行為
- ポイント：「教える・提供する」がキーワード（R4春 問78）。不正に取得する・保管する・フィッシングサイトで入力を求める行為は、それぞれ別の禁止規定
- 語の意味：助長＝ある傾向を強めること

#### アクセス制御機能（アクセスせいぎょきのう / Access Control Function）

- 意味：ID・パスワード・生体情報などで利用者を識別し、正規の利用者だけがコンピュータを利用できるようにする機能
- ポイント：この機能がないコンピュータへの侵入は、不正アクセス禁止法の対象にならない
- 語の意味：Access Control＝利用の制限

#### 不正指令電磁的記録に関する罪（ふせいしれいでんじてききろくにかんするつみ / ウイルス作成罪）

- 意味：正当な理由なく、利用者の意図に反して動作するプログラム（ウイルスなど）を作成・提供・取得・保管・実行させる行為を罰する刑法の罪
- ポイント：ウイルスを実際に使わなくても、作ったり保管したりするだけで罪になる
- 語の意味：不正指令＝不正な命令

#### 電子計算機損壊等業務妨害罪（でんしけいさんきそんかいとうぎょうむぼうがいざい）

- 意味：コンピュータやそのデータを壊したり、虚偽の情報や不正な指令を与えたりして、コンピュータを正しく動かなくし、業務を妨害する罪（刑法）
- ポイント：マルウェアでデータを消去して業務を妨げる行為は、記憶媒体経由でも刑法で罰せられる（R3秋 問78）
- 語の意味：損壊＝壊すこと

#### 電子計算機使用詐欺罪（でんしけいさんきしようさぎざい）

- 意味：コンピュータに虚偽の情報や不正な指令を与えて、財産上の不法な利益を得る罪（刑法）
- ポイント：人をだますのではなく、コンピュータに不正な処理をさせて利益を得る。不正な送金処理などが例
- 語の意味：詐欺＝だまして利益を得ること

#### 電磁的記録不正作出及び供用罪（でんじてききろくふせいさくしゅつおよびきょうようざい）

- 意味：人の事務処理を誤らせる目的で、権利・義務・事実の証明に関する電磁的記録を不正に作ったり、それを使ったりする罪（刑法）
- ポイント：データの偽造に当たる。クレジットカードの磁気情報の偽造は、支払用カード電磁的記録不正作出等罪
- 語の意味：作出＝作り出すこと／供用＝使えるように差し出すこと

### 個人情報保護法

#### 個人情報（こじんじょうほう / Personal Information）

- 意味：生存する個人に関する情報で、氏名・生年月日など特定の個人を識別できるもの、または個人識別符号を含むもの
- ポイント：他の情報と容易に照合して個人を特定できるものも含む。死者の情報は対象外
- 語の意味：Personal＝個人の

#### 個人識別符号（こじんしきべつふごう）

- 意味：それだけで特定の個人を識別できる文字・番号・記号。顔や指紋などの身体の特徴をデータ化したものと、旅券番号・運転免許証番号・マイナンバーなど公的な番号がある
- ポイント：クレジットカード番号や電話番号は個人識別符号ではない（ただし他の情報と組み合わせて個人情報になりうる）
- 語の意味：識別＝見分けること／符号＝記号や番号

#### 要配慮個人情報（ようはいりょこじんじょうほう）

- 意味：本人の人種・信条・社会的身分・病歴・犯罪の経歴・犯罪被害の事実など、不当な差別や偏見などの不利益が生じないように特に配慮が必要な個人情報
- ポイント：取得には原則として本人の同意が必要で、オプトアウトによる第三者提供は禁止（R6春 問80）
- 語の意味：配慮＝心を配ること

#### 個人情報取扱事業者（こじんじょうほうとりあつかいじぎょうしゃ）

- 意味：個人情報データベース等を事業に使っている者。取り扱う人数にかかわらず、ほぼ全ての事業者が該当する
- ポイント：2017年の改正で、5,000人以下の事業者を除外する規定がなくなった。国の機関・地方公共団体なども同じ法律の対象
- 語の意味：取扱い＝扱うこと

#### 安全管理措置（あんぜんかんりそち）

- 意味：個人データの漏えい・滅失・毀損を防ぐために、事業者が講じなければならない組織的・人的・物理的・技術的な措置
- ポイント：漏えい等で個人の権利利益を害するおそれが大きい場合は、個人情報保護委員会への報告と本人への通知が義務
- 語の意味：措置＝必要な手当て

#### 第三者提供（だいさんしゃていきょう）

- 意味：個人データを本人と事業者以外の者に渡すこと。原則として本人の同意が必要
- ポイント：委託・事業承継・共同利用は「第三者」に当たらない。法令に基づく場合や人の生命の保護に必要な場合などは同意なしで提供できる
- 語の意味：第三者＝当事者以外の者

#### オプトアウト（Opt-out）

- 意味：本人が拒否しない限り同意したものとみなし、本人から求められたら停止する方式。個人情報保護法では、所定の事項を本人に通知し個人情報保護委員会に届け出れば、同意なしで第三者提供できる
- ポイント：要配慮個人情報や、不正に取得された個人データ、オプトアウトで提供された個人データは、オプトアウトで提供できない
- 語の意味：Opt＝選ぶ／Out＝外へ（抜けることを選ぶ）

#### オプトイン（Opt-in）

- 意味：本人が事前に同意した場合にだけ、情報の利用やメールの送信などを行う方式
- ポイント：特定電子メール法の広告宣伝メールは、原則としてオプトイン（R3秋 問79）
- 語の意味：Opt＝選ぶ／In＝中へ（参加することを選ぶ）

#### 匿名加工情報（とくめいかこうじょうほう）

- 意味：特定の個人を識別できないように個人情報を加工し、元の個人情報に復元できないようにした情報
- ポイント：本人の同意なしで第三者に提供できるが、含まれる項目と提供方法を公表し、提供先に匿名加工情報であることを明示する必要がある（R5秋 問79）
- 語の意味：匿名＝名前を隠すこと

#### 仮名加工情報（かめいかこうじょうほう）

- 意味：他の情報と照合しない限り特定の個人を識別できないように加工した情報。氏名などを削除・置き換えたもの
- ポイント：社内の分析で使うためのもの。第三者提供は原則禁止。匿名加工情報より加工の程度が軽く、データの有用性が高い
- 語の意味：仮名＝仮の名前

#### 個人関連情報（こじんかんれんじょうほう）

- 意味：生存する個人に関する情報のうち、個人情報・仮名加工情報・匿名加工情報のいずれにも当たらないもの（Cookie・閲覧履歴・位置情報など）
- ポイント：提供先で個人データとして取得されると想定される場合は、提供元が、本人の同意が得られていることを確認する必要がある
- 語の意味：関連＝かかわりがある

#### 個人情報保護委員会（Personal Information Protection Commission）

- 意味：個人情報保護法やマイナンバー法に基づき、個人情報の適正な取扱いを監督する独立した国の機関（内閣府の外局）
- ポイント：事業者への報告徴収・立入検査・指導・勧告・命令を行う。漏えい等の報告先
- 語の意味：委員会＝合議制の機関

#### マイナンバー法（番号法）

- 意味：行政手続で、国民一人一人に12桁の個人番号（マイナンバー）を割り当て、社会保障・税・災害対策などの分野で、効率的に情報を管理・利用するための法律
- ポイント：マイナンバーを含む個人情報を特定個人情報といい、法律で定められた事務以外での利用・提供・収集は禁止。個人情報保護法より厳しい
- 語の意味：番号＝ナンバー

#### 特定個人情報保護評価（とくていこじんじょうほうほごひょうか）

- 意味：マイナンバーを扱うシステムを導入・変更する行政機関などが、事前にプライバシーへの影響やリスクを評価し、対策を公表する仕組み
- ポイント：プライバシー影響評価（PIA）を、マイナンバー制度で義務化したもの
- 語の意味：保護評価＝保護の状況を評価すること

### プライバシー保護の枠組み

#### プライバシーマーク（Privacy Mark）

- 意味：JIS Q 15001 に基づいて個人情報を適切に管理する体制を整えた事業者に、JIPDEC などが使用を認めるマーク
- ポイント：事業者単位で認定され、有効期間は2年（更新あり）。ISMS認証（JIS Q 27001）は情報セキュリティ全般の認証
- 語の意味：Privacy＝私生活・個人の情報

#### JIS Q 15001

- 意味：個人情報保護マネジメントシステムの要求事項を定めた日本産業規格
- ポイント：プライバシーマーク制度の審査基準。PDCAで個人情報の保護を継続的に改善する仕組みを求める
- 語の意味：JIS＝日本産業規格／Q＝管理システム部門

#### OECDプライバシーガイドライン（OECD Privacy Guidelines）

- 意味：OECD（経済協力開発機構）が示した、プライバシー保護と個人データの国際流通についての指針。収集制限・データ内容・目的明確化・利用制限・安全保護・公開・個人参加・責任の8原則
- ポイント：日本の個人情報保護法の土台になった
- 語の意味：OECD＝Organisation for Economic Co-operation and Development（経済協力開発機構）

#### GDPR（General Data Protection Regulation / 一般データ保護規則）

- 意味：EU（欧州連合）の個人データ保護の規則。EU域内の個人データの処理と、域外への移転について厳しいルールを定める
- ポイント：EU域内に拠点がなくても、EUの人に商品やサービスを提供する企業には適用される。違反には高額の制裁金がある
- 語の意味：General＝一般／Data Protection＝データ保護／Regulation＝規則

#### PIA（Privacy Impact Assessment / プライバシー影響評価）

- 意味：個人情報を扱うシステムや事業を始める前に、プライバシーへの影響やリスクを分析・評価し、対策を検討する手法
- ポイント：事後に対策するのではなく、設計の段階でプライバシーを組み込む（プライバシーバイデザイン）ための手段
- 語の意味：Privacy＝プライバシー／Impact＝影響／Assessment＝評価

### 電子署名・メール・ネットの法律

#### 電子署名法（電子署名及び認証業務に関する法律）

- 意味：電子署名が手書きの署名や押印と同じように通用するための法的な基盤と、電子証明書を発行する認証業務について定めた法律
- ポイント：本人による一定の要件を満たす電子署名がある電磁的記録は、本人が作ったもの（真正に成立したもの）と推定される。押印と同様の効力（R3春 問80）。認証業務は民間の事業者もでき、一定の基準を満たせば国の認定を受けられる（認定認証事業者）
- 語の意味：署名＝自分の名前を書き記すこと

#### 認定認証事業者（にんていにんしょうじぎょうしゃ）

- 意味：電子署名法に基づき、一定の基準を満たして主務大臣の認定を受けた、電子証明書を発行する民間の事業者
- ポイント：認定は任意。認定がなくても認証業務は行える。政府が運営する認証局に限られるわけではない（R3春 問80 のウ）
- 語の意味：認定＝基準を満たすと認めること／認証＝本人であることを証明すること

#### 特定電子メール法（特定電子メールの送信の適正化等に関する法律）

- 意味：広告や宣伝を目的とする営業目的の電子メール（特定電子メール）について、原則として事前に同意した人にだけ送れる（オプトイン）とし、送信者の表示や受信拒否の方法の表示を義務付けた法律
- ポイント：電子メールだけでなく SMS も対象。外国から送られるものも対象。政治団体などの非営利団体のメールや、取引上の事務連絡は対象外（R3春 問79）
- 語の意味：特定＝特に定めた

#### 情報流通プラットフォーム対処法（じょうほうりゅうつうプラットフォームたいしょほう）

- 意味：インターネット上で権利侵害があった場合のプロバイダの損害賠償責任の範囲と、被害者が発信者情報の開示を請求できる権利を定め、さらに大規模なプラットフォーム事業者に削除対応の迅速化と運用の透明化を義務付けた法律
- ポイント：2025年4月にプロバイダ責任制限法から改正・改称された。旧名で出ることもあるので両方覚える
- 語の意味：Platform＝基盤（SNSや掲示板など）／対処＝適切に対応すること

#### 発信者情報開示請求（はっしんしゃじょうほうかいじせいきゅう）

- 意味：インターネット上の投稿で権利を侵害された人が、プロバイダなどに対して、投稿した人（発信者）の氏名・住所・IPアドレスなどの開示を求めること
- ポイント：情報流通プラットフォーム対処法で定められている。裁判所の非訟手続で、一回の手続で開示まで進められるようになった
- 語の意味：発信者＝情報を送り出した人／開示＝明らかにすること

#### 送信防止措置（そうしんぼうしそち）

- 意味：権利を侵害する投稿などについて、プロバイダやプラットフォーム事業者が、その情報を削除するなどして送信を防ぐこと
- ポイント：適切に削除した場合、発信者に対する損害賠償責任が制限される。大規模事業者は、削除の申出に一定期間内に対応する義務がある
- 語の意味：送信防止＝送信を止めること

## 23-3 労働関連・取引関連法規

### まとめ表

**請負・準委任・派遣・出向（誰が指揮命令するか）**

| 形態 | 雇用関係 | 指揮命令 | 完成の責任 |
| :-: | :-: | :-: | :-: |
| 請負契約 | 受注者と作業者 | 受注者（発注者は指示できない） | ある（仕事の完成） |
| 準委任契約 | 受注者と作業者 | 受注者 | ない（作業の遂行。善管注意義務） |
| 労働者派遣 | 派遣元と労働者 | 派遣先 | ない |
| 出向（在籍出向） | 出向元と出向先の両方 | 出向先（R5秋 問80） | ない |

**偽装請負の見分け方（R4春 問79）**

| 契約 | 作業場所 | 誰が指揮命令しているか | 判定 |
| :-: | :-: | :-: | :-: |
| 請負 | 発注者の事業所 | 受注者の責任者 | 適法（場所は問わない）（R4秋 問79） |
| 請負 | 発注者の事業所 | 発注者の責任者 | 偽装請負（実態は派遣） |

### 労働基準法と働き方

#### 労働基準法（ろうどうきじゅんほう / Labor Standards Act）

- 意味：賃金・労働時間・休日・休暇・解雇など、労働条件の最低基準を定めた法律
- ポイント：法定労働時間は原則1日8時間・週40時間。これを超えて働かせるには36協定が必要
- 語の意味：Labor＝労働／Standards＝基準

#### 36協定（さぶろくきょうてい）

- 意味：法定労働時間を超える時間外労働や休日労働をさせるために、使用者と労働者の過半数代表が結び、労働基準監督署に届け出る協定。労働基準法36条に基づく
- ポイント：上限は原則 月45時間・年360時間。臨時的な特別の事情がある場合だけ、特別条項で年720時間などまで延長できる（R3秋 問80）
- 語の意味：36＝労働基準法の第36条

#### 特別条項（とくべつじょうこう）

- 意味：36協定で、臨時的に限度時間（月45時間・年360時間）を超えて働かせる必要がある場合に、その事情や上限を定めておく条項
- ポイント：使えるのは「予見できない業務量の大幅な増加」など臨時的な場合だけ。慢性的な人手不足や期限を定めない適用は認められない。年6回（6か月）まで、単月100時間未満、複数月平均80時間以内
- 語の意味：条項＝契約などの個々の取決め

#### フレックスタイム制（Flextime System）

- 意味：一定の期間（清算期間、最長3か月）の総労働時間を決めておき、日々の始業・終業の時刻を労働者が自分で決められる制度
- ポイント：実際の労働時間で管理する。決めた時間を働いたと「みなす」のは裁量労働制
- 語の意味：Flex＝柔軟な

#### 変形労働時間制（へんけいろうどうじかんせい）

- 意味：一定の期間（1か月・1年など）を平均して週40時間以内であれば、繁忙期に1日8時間・週40時間を超えて働かせることができる制度
- ポイント：繁忙期と閑散期がはっきりした業務に向く。日々の時刻を労働者が決めるのはフレックスタイム制
- 語の意味：変形＝形を変えること

#### 就業規則（しゅうぎょうきそく）

- 意味：労働時間・賃金・服務規律など、職場のルールを使用者が定めた規則。常時10人以上の労働者がいる事業場は、作成して労働基準監督署に届け出る義務がある
- ポイント：作成・変更のときは労働者の過半数代表の意見を聴く必要がある（同意までは不要）
- 語の意味：就業＝仕事に就くこと

#### 労働契約法（ろうどうけいやくほう）

- 意味：労働契約の成立・変更・終了などの基本的なルールを定めた法律。解雇は、客観的に合理的な理由と社会通念上の相当性がなければ無効（解雇権濫用法理）
- ポイント：有期労働契約が更新されて通算5年を超えた場合、労働者の申込みで無期労働契約に転換できる（無期転換ルール）
- 語の意味：契約＝約束を取り交わすこと

#### 労働安全衛生法（ろうどうあんぜんえいせいほう）

- 意味：職場での労働者の安全と健康を確保し、快適な職場環境を作るための法律。安全衛生管理体制・健康診断・ストレスチェックなどを定める
- ポイント：常時50人以上の事業場ではストレスチェックが義務。産業用ロボットの安全規則もこの法律に基づく
- 語の意味：安全衛生＝安全と健康

#### 労働施策総合推進法（ろうどうしさくそうごうすいしんほう / パワハラ防止法）

- 意味：労働施策を総合的に進めるための法律。パワーハラスメントの防止のため、相談体制の整備など雇用管理上の措置を事業主に義務付けている
- ポイント：「パワハラ防止法」と呼ばれる（R7秋 問80）。セクハラ・マタハラは男女雇用機会均等法・育児介護休業法で定める
- 語の意味：施策＝政策として行う具体的な取組み

#### 公益通報者保護法（こうえきつうほうしゃほごほう）

- 意味：事業者の法令違反などを、組織の内部や行政機関などに通報した労働者（公益通報者）を、解雇などの不利益な取扱いから守る法律
- ポイント：従業員301人以上の事業者には、内部通報の体制整備が義務。内部告発を正当な行為として保護する
- 語の意味：公益＝社会全体の利益／通報＝知らせること

#### 男女雇用機会均等法（だんじょこようきかいきんとうほう）

- 意味：募集・採用・配置・昇進などで、性別を理由とする差別を禁止し、セクシュアルハラスメントや妊娠・出産を理由とする不利益な取扱いの防止を事業主に求める法律
- ポイント：派遣の依頼で「20代男性」のように性別を指定するのも、この法律の趣旨に反する（R6秋 問79 のウ）
- 語の意味：均等＝等しいこと

#### 育児・介護休業法（いくじ・かいごきゅうぎょうほう）

- 意味：育児や家族の介護をする労働者が、休業や短時間勤務などを取れるようにして、仕事と家庭を両立できるよう支援する法律
- ポイント：父親が子の出生後に取れる産後パパ育休（出生時育児休業）も定められている
- 語の意味：休業＝仕事を休むこと

#### フリーランス法（フリーランス・事業者間取引適正化等法）

- 意味：企業がフリーランス（従業員を使わない個人の受託事業者）に業務を委託するときに、取引条件の明示・報酬の60日以内の支払・ハラスメント対策などを義務付けた法律（2024年11月施行）
- ポイント：資本金の要件がなく、小さな企業がフリーランスに委託する場合も対象になる点が、中小受託取引適正化法と違う
- 語の意味：Freelance＝組織に属さず仕事を請け負う人

### 労働者派遣

#### 労働者派遣（ろうどうしゃはけん / Worker Dispatching）

- 意味：派遣元が雇用している労働者を、派遣先の指揮命令を受けて、派遣先のために働かせること
- ポイント：雇用関係は派遣元との間にだけあり、派遣先とは指揮命令関係だけ。派遣先と労働者の間に雇用関係は生じない（R5秋 問80 のウ）
- 語の意味：派遣＝差し向けること

#### 派遣元の義務（はけんもとのぎむ）

- 意味：派遣元事業主が講じるべき措置。派遣労働者の教育訓練の機会の確保・福祉の増進、派遣元責任者の選任、派遣元管理台帳の作成、労働条件の明示など
- ポイント：派遣先管理台帳の作成、派遣先責任者の選任、指揮命令者への契約内容の周知は派遣先の義務（R5春 問79）
- 語の意味：派遣元＝労働者を雇って送り出す会社

#### 派遣期間の制限（はけんきかんのせいげん）

- 意味：同じ派遣労働者を、派遣先の同じ組織単位（課など）で受け入れられる期間は原則3年まで。派遣先の事業所単位でも原則3年まで（労働組合などの意見を聴けば延長できる）
- ポイント：3年の派遣契約を結ぶこと自体は適法（R6秋 問79）
- 語の意味：期間制限＝続けられる長さの上限

#### 事前面接の禁止（じぜんめんせつのきんし / 特定目的行為の禁止）

- 意味：派遣先が、派遣労働者を特定する目的で、派遣の前に面接をしたり、履歴書を求めたり、年齢・性別を指定したりすることの禁止
- ポイント：派遣先は人を選べない。誰を派遣するかは派遣元が決める（R6秋 問79 のイ）
- 語の意味：特定＝この人と決めること

#### 二重派遣（にじゅうはけん）

- 意味：派遣先が、受け入れた派遣労働者を、さらに別の会社に派遣して、その会社の指揮命令の下で働かせること
- ポイント：職業安定法で禁止されている。雇用関係がないのに労働者を供給することになるため
- 語の意味：二重＝二回重なる

#### 偽装請負（ぎそううけおい）

- 意味：契約は請負や準委任なのに、実態は発注者が受注者の労働者に直接指揮命令している状態。実質的に労働者派遣であり、違法
- ポイント：作業場所がどこかではなく、「誰が指揮命令しているか」で判断する（R4春 問79）
- 語の意味：偽装＝見せかけること

#### 派遣先の苦情処理（はけんさきのくじょうしょり）

- 意味：派遣労働者から、派遣先での指揮命令や職場環境についての苦情の申出があったとき、派遣先が派遣元と連携して、遅滞なく適切に処理する義務
- ポイント：派遣先が自ら対応せず、派遣元に任せきりにするのは不適切（R6秋 問79 のエ）
- 語の意味：苦情＝不満の申し立て

### 取引の法律

#### 中小受託取引適正化法（ちゅうしょうじゅたくとりひきてきせいかほう / 取適法）

- 意味：資本金や従業員数が大きい委託事業者が、中小の受託事業者に製造・修理・情報成果物の作成・役務の提供などを委託するときに、発注内容の明示や代金の支払期日などを義務付け、買いたたきなどを禁止する法律
- ポイント：2026年1月に下請法（下請代金支払遅延等防止法）から改正・改称された。親事業者→委託事業者、下請事業者→中小受託事業者と呼び方が変わった。過去問は「下請法」の名前で出ている
- 語の意味：適正化＝正しく適切にすること

#### 委託事業者の義務（いたくじぎょうしゃのぎむ）

- 意味：発注内容（給付の内容・代金・支払期日など）の明示、代金の支払期日（受領から60日以内）の設定、書類の作成・保存、遅延利息の支払
- ポイント：発注時に必要事項を明示しなければならない。仕様が決まっていなくても、決まった時点で直ちに明示する必要があり、口頭で伝えるだけでは違反（R5春 問78）。明示は書面のほか、電子メールなどの電磁的方法でもできる
- 語の意味：明示＝はっきり示すこと

#### 委託事業者の禁止行為（いたくじぎょうしゃのきんしこうい）

- 意味：受領拒否・代金の支払遅延・代金の減額・返品・買いたたき・購入や利用の強制・不当な経済上の利益の提供要請・不当な給付内容の変更ややり直しなど
- ポイント：改正で、協議に応じずに一方的に代金を決めることや、手形での支払が禁止された。事前の合意があっても代金の減額は禁止。振込手数料の実費の差引きは、旧下請法では書面の合意があれば認められていた（R5春 問78 のエ）が、取適法では受託側に負担させることも減額として扱われるので、最新の運用基準を確認する
- 語の意味：買いたたき＝通常より著しく低い代金を一方的に決めること

#### 情報成果物作成委託（じょうほうせいかぶつさくせいいたく）

- 意味：プログラム・設計書・映像・デザインなど、情報成果物の作成を委託すること
- ポイント：ソフトウェア開発の委託は、中小受託取引適正化法の対象取引の一つ
- 語の意味：成果物＝作業の結果としてできたもの

#### 請負契約（うけおいけいやく / Contract for Work）

- 意味：受注者（請負人）が仕事の完成を約束し、発注者がその結果に対して報酬を支払う契約（民法）
- ポイント：完成責任があり、成果物が契約に適合しないときは契約不適合責任を負う。作業者への指揮命令は受注者が行う（R4秋 問79）
- 語の意味：請け負う＝仕事を引き受ける

#### 準委任契約（じゅんいにんけいやく / Quasi-mandate Contract）

- 意味：法律行為以外の事務（作業）を行うことを委託する契約。受注者は善良な管理者の注意（善管注意義務）をもって作業を遂行する（民法）
- ポイント：仕事の完成義務はない。要件定義や運用支援のように、成果が確定しにくい作業に使う。成果に対して報酬を払う「成果完成型」もある
- 語の意味：準＝それに準じる／委任＝任せること

#### 契約不適合責任（けいやくふてきごうせきにん）

- 意味：引き渡した目的物が、種類・品質・数量などについて契約の内容に適合しない場合に、売主や請負人が負う責任。追完（修補）・代金減額・損害賠償・契約解除を請求される
- ポイント：2020年の民法改正で「瑕疵担保責任」から変わった。買主は不適合を知ってから1年以内に通知する必要がある
- 語の意味：不適合＝合っていないこと

#### 実費償還契約（じっぴしょうかんけいやく / Cost-reimbursable Contract）

- 意味：受注者にかかった実際の費用（実費）を発注者が支払い、それに加えて報酬（フィー）を支払う契約。CPIF（インセンティブフィー付き）・CPFF（定額フィー付き）などがある
- ポイント：仕様が固まっていない場合に使う。費用が膨らむリスクは発注者が負う。総額を固定するのは定額契約
- 語の意味：償還＝返すこと

#### タイムアンドマテリアル契約（T&M / Time and Material）

- 意味：作業時間（人の単価×時間）と、使った材料・資材の費用に基づいて、代金を支払う契約
- ポイント：作業範囲がはっきりしない小規模な作業に向く。実費償還契約と定額契約の中間の性格
- 語の意味：Time＝時間／Material＝材料

#### 特定商取引法（とくていしょうとりひきほう）

- 意味：訪問販売・通信販売・電話勧誘販売など、トラブルが起きやすい取引について、事業者が守るべきルールと、クーリングオフなど消費者を守るルールを定めた法律
- ポイント：通信販売にはクーリングオフはないが、返品の可否や条件（返品特約）を表示する義務がある。最終確認画面での表示義務もある
- 語の意味：特定＝特に定めた／商取引＝商売の取引

#### 電子消費者契約法（でんししょうひしゃけいやくほう）

- 意味：インターネットでの契約で、消費者が操作ミスで意図しない申込みをした場合に、事業者が確認画面を設けていなければ、契約を無効にできる（錯誤の主張ができる）ことなどを定めた法律
- ポイント：事業者が申込み内容の確認画面を用意していれば、この特例は適用されない
- 語の意味：電子＝インターネットを通じた

#### 景品表示法（けいひんひょうじほう）

- 意味：商品やサービスの品質・価格について、実際より著しく良いと見せる表示（優良誤認・有利誤認）や、過大な景品を禁止する法律
- ポイント：2023年10月から、広告であることを隠した宣伝（ステルスマーケティング）も不当表示として規制された
- 語の意味：景品＝おまけ／表示＝示すこと

#### 資金決済法（しきんけっさいほう）

- 意味：前払式支払手段（プリペイドカード・電子マネー）・資金移動業（銀行以外の送金サービス）・暗号資産交換業などについて定めた法律
- ポイント：暗号資産は、不特定の者に使え、電子的に記録・移転でき、法定通貨ではないが法定通貨と交換できるもの（R7春 問79）。暗号資産交換業は登録制で、財務的な規制も受ける
- 語の意味：資金決済＝お金の支払と受取り

#### 割賦販売法（かっぷはんばいほう）

- 意味：分割払いやクレジットカードによる取引について、事業者が守るべきルールを定めた法律
- ポイント：カード情報を扱う加盟店などに、クレジットカード番号等の適切な管理（PCI DSS 準拠や非保持化）を義務付けている
- 語の意味：割賦＝分割払い

#### 取引DPF法（とりひきデジタルプラットフォームほう / 特定デジタルプラットフォーム透明化法）

- 意味：特に大規模なオンラインモールやアプリストアなどの運営者（特定デジタルプラットフォーム提供者）に、取引条件の開示や、出店者との公正な関係のための体制整備、運営状況の報告を義務付けた法律
- ポイント：利用する事業者（出店者など）との取引の透明性と公正性を高めるのが目的
- 語の意味：Digital Platform＝取引の場となるインターネット上の基盤

### 企業間の契約

#### NDA（Non-Disclosure Agreement / 守秘義務契約）

- 意味：取引の中で開示した秘密情報を、相手が第三者に漏らしたり目的外に使ったりしないよう約束する契約
- ポイント：業務を委託する前、見積りや検討のために情報を見せる段階で結ぶことが多い。秘密情報の範囲・期間・返却や廃棄の方法を定める
- 語の意味：Non-Disclosure＝開示しないこと／Agreement＝契約

#### ソフトウェア使用許諾契約（ソフトウェアしようきょだくけいやく / ライセンス契約）

- 意味：ソフトウェアの権利者が、利用者に一定の条件のもとで使うことを許す契約。ソフトウェアの権利そのものを渡すのではない
- ポイント：使える台数・人数・期間・複製や改変の可否などを決める
- 語の意味：License＝許可

#### ボリュームライセンス契約（Volume License）

- 意味：一つのソフトウェアを多数のコンピュータで使う企業向けに、まとめて使用権を購入する契約
- ポイント：本数に応じて割引されることが多い。台数を数えずに、ある場所（組織）の中なら自由に使えるのはサイトライセンス
- 語の意味：Volume＝量

#### サイトライセンス契約（Site License）

- 意味：特定の企業や大学などの組織（サイト）の中であれば、台数や人数を問わずにソフトウェアを使えるようにする契約
- ポイント：使う本数を数える手間がない。決まった本数分を買うのはボリュームライセンス
- 語の意味：Site＝場所・拠点

#### シュリンクラップ契約（Shrink-wrap Contract）

- 意味：パッケージソフトの包装（シュリンクラップ）を破ると、使用許諾の条件に同意したとみなす契約の方式
- ポイント：ダウンロード版で、画面の「同意する」ボタンを押すと契約が成立するのはクリックオン契約
- 語の意味：Shrink-wrap＝収縮させてぴったり包むフィルム

#### CAL（Client Access License）

- 意味：サーバのソフトウェアに、クライアント（端末や利用者）が接続して使うための権利。接続する端末や利用者の数だけ必要になる
- ポイント：サーバ本体のライセンスとは別に必要。端末ごとに数えるデバイスCALと、利用者ごとに数えるユーザーCALがある
- 語の意味：Client＝利用する側／Access＝接続／License＝許可

#### ソフトウェア開発委託モデル契約（ソフトウェアかいはついたくモデルけいやく）

- 意味：経済産業省やIPAが公開している、システム開発の委託契約のひな形。工程ごとに請負か準委任かを選べるように、多段階契約の考え方を示している
- ポイント：要件定義や運用テストは準委任、設計から結合テストまでは請負が適しているとされる。AI開発には「AI・データの利用に関する契約ガイドライン」がある
- 語の意味：Model＝ひな形

### OSSとソフトウェアの配布形態

#### OSS（Open Source Software / オープンソースソフトウェア）

- 意味：ソースコードが公開され、利用・改変・再配布が許されたソフトウェア。著作権は放棄されておらず、ライセンスの条件に従って使う
- ポイント：OSD（オープンソースの定義）では、特定の個人や分野での利用を差別してはならない。無償であることは必須ではない
- 語の意味：Open Source＝ソースコードが公開された

#### GPL（GNU General Public License）

- 意味：コピーレフトの考え方に基づく代表的なOSSのライセンス。GPLのソフトウェアを改変・組み込んで配布する場合は、そのソフトウェア全体もGPLでソースコードを公開しなければならない
- ポイント：社内だけで使い、配布しなければ公開の義務はない。ライブラリとして動的にリンクするだけなら公開を求めない緩いものが LGPL
- 語の意味：GNU＝フリーソフトウェアのプロジェクト名／General Public＝一般公衆向け

#### LGPL（GNU Lesser General Public License）

- 意味：主にライブラリ向けの GPL を緩めたライセンス。LGPLのライブラリにリンクして使うだけなら、自分のプログラムのソースコードは公開しなくてよい
- ポイント：ライブラリそのものを改変して配布する場合は、その部分のソースコードを公開する必要がある
- 語の意味：Lesser＝より制約の少ない

#### BSDライセンス（BSD License）

- 意味：著作権表示と免責の文を残せば、改変・再配布・商用利用・ソースコードを非公開にすることも自由にできる、制約の少ないOSSのライセンス
- ポイント：コピーレフトではない。似たものに MIT ライセンス、Apache ライセンスがある
- 語の意味：BSD＝Berkeley Software Distribution（カリフォルニア大学バークレー校の配布ソフト）

#### コピーレフト（Copyleft）

- 意味：著作権を保持したまま、改変して配布する派生物にも、元と同じ自由（利用・改変・再配布）を引き継がせる考え方
- ポイント：GPLが代表。著作権（Copyright）をもじった言葉で、著作権を放棄するわけではない
- 語の意味：Copy＋left（right の反対）

#### パブリックドメイン（Public Domain）

- 意味：著作権の保護期間が終わったり、権利者が権利を放棄したりして、誰でも自由に利用できる状態の著作物
- ポイント：OSSは著作権があったうえでライセンスで利用を許すもので、パブリックドメインとは違う
- 語の意味：Public＝公共の／Domain＝領域

#### クリエイティブ・コモンズ（Creative Commons）

- 意味：著作者が「表示」「非営利」「改変禁止」「継承」などの条件を組み合わせて、作品の利用を事前に許可する意思を示すライセンスの仕組み（CCライセンス）
- ポイント：著作権を保持したまま、条件付きで自由な利用を認める。CC0 はできる限り権利を放棄する宣言
- 語の意味：Creative＝創造的な／Commons＝共有地

#### シェアウェア（Shareware）

- 意味：一定期間は無料で試用でき、使い続ける場合は料金を払う形で配布されるソフトウェア
- ポイント：無料で使え、再配布もできるが著作権は作者にあるのはフリーソフトウェア（フリーウェア）
- 語の意味：Share＝共有する／ware＝製品

## 23-4 その他の法律・ガイドライン・技術者倫理

### まとめ表

**似た目的の法律の見分け方**

| 法律 | ひと言で |
| :-: | :-: |
| デジタル社会形成基本法 | デジタル社会の形成の基本理念（誰もが恩恵を受ける・信頼ある情報の自由で安全な流通）とデジタル庁の設置（R6秋 問80） |
| 官民データ活用推進基本法 | 国・自治体・事業者のデータ活用と、行政手続のオンライン化の原則 |
| 情報流通プラットフォーム対処法 | ネット上の権利侵害のプロバイダ責任と発信者情報開示 |
| 特定電子メール法 | 広告宣伝メールのオプトイン |
| 特定商取引法 | 通信販売・訪問販売などの消費者保護 |
| e-文書法 | 保存義務のある文書を電子データで保存してよい |
| 電子帳簿保存法 | 国税関係の帳簿・書類の電子保存 |

**情報の質の問題（誤情報の3分類）**

| 用語 | 内容が正しいか | 害する意図 |
| :-: | :-: | :-: |
| ミスインフォメーション | 誤っている | ない（勘違いなど） |
| ディスインフォメーション | 誤っている | ある（意図的な偽情報） |
| マルインフォメーション | 正しい | ある（私的な情報の暴露など） |

### 情報社会の基本法

#### デジタル社会形成基本法（デジタルしゃかいけいせいきほんほう）

- 意味：デジタル社会の形成について、基本理念、国・地方公共団体・事業者の責務、施策の基本方針を定めた法律。デジタル庁の設置の根拠
- ポイント：基本理念には「全ての国民が情報通信技術の恵沢を享受できる社会」「信頼性のある情報の自由かつ安全な流通の確保」などがある（R6秋 問80）。IT基本法に代わる法律
- 語の意味：形成＝形づくること

#### デジタル庁（Digital Agency）

- 意味：デジタル社会の形成のための施策を、政府全体で迅速・重点的に進める司令塔となる国の行政機関
- ポイント：デジタル社会形成基本法に基づき2021年に発足した。ベースレジストリ（公的基礎情報データベース）の整備なども担う
- 語の意味：Agency＝行政機関

#### 官民データ活用推進基本法（かんみんデータかつようすいしんきほんほう）

- 意味：国・地方公共団体・事業者が持つデータ（官民データ）の活用を進めるための基本法。行政手続のオンライン利用の原則化や、情報通信技術の利用の格差の是正などを定める
- ポイント：国と都道府県に、官民データ活用推進計画の策定を義務付けている
- 語の意味：官民＝官（行政）と民（民間）

#### ベースレジストリ（Base Registry）

- 意味：住所・法人・不動産など、社会の様々な場面で参照される、公的機関が登録・公開する基本的なデータベース
- ポイント：正確で最新の基本データを、行政や民間が共通で使えるようにするもの。デジタル社会形成基本法で整備が定められた
- 語の意味：Base＝基本／Registry＝登録簿

### コンプライアンスと関連する法律

#### コンプライアンス（Compliance / 法令遵守）

- 意味：企業が法令を守ることに加え、社内規則や企業倫理、社会の規範に沿って公正に行動すること
- ポイント：違反すると罰則だけでなく、信用の失墜（レピュテーションリスク）や取引停止などの損害を受ける
- 語の意味：Comply＝従う

#### ビジネスと人権（Business and Human Rights）

- 意味：企業が、自社だけでなくサプライチェーン全体で、強制労働や児童労働などの人権侵害を防ぎ、対応する責任があるという考え方
- ポイント：人権への悪い影響を特定し、防止・軽減し、その取組みを開示する「人権デューデリジェンス」が求められる
- 語の意味：Human Rights＝人権

#### 金融商品取引法（きんゆうしょうひんとりひきほう）

- 意味：有価証券の発行・取引の公正を確保し、投資者を保護するための法律。上場企業に有価証券報告書と内部統制報告書の提出を義務付ける
- ポイント：財務報告に係る内部統制の評価（J-SOX）の根拠になっている
- 語の意味：金融商品＝株式・債券など

#### 会社法（かいしゃほう）

- 意味：会社の設立・機関（株主総会・取締役会・監査役など）・組織再編などの制度を定めた法律
- ポイント：大会社の取締役会に、内部統制システムの整備に関する基本方針の決定を義務付けている
- 語の意味：会社＝営利を目的とする法人

#### 製造物責任法（せいぞうぶつせきにんほう / PL法）

- 意味：製造物の欠陥によって、人の生命・身体・財産に損害が生じた場合、製造業者などが過失の有無にかかわらず損害を賠償する責任を負うと定めた法律
- ポイント：対象の製造物は「製造又は加工された動産」。ソフトウェア単体は無体物なので対象外だが、ROM化したソフトを組み込んだ機器は対象（R4秋 問80）
- 語の意味：PL＝Product Liability（製造物責任）

#### 情報公開法（じょうほうこうかいほう）

- 意味：国の行政機関が持つ行政文書について、誰でも開示を請求できることを定めた法律。独立行政法人には別に独立行政法人等情報公開法がある
- ポイント：請求する人の国籍や目的は問われない。個人情報など不開示情報は除かれる
- 語の意味：公開＝広く見せること

#### e-文書法（イーぶんしょほう）

- 意味：法令で保存が義務付けられている文書を、紙ではなく電子データ（電磁的記録）で保存することを認める法律
- ポイント：紙の文書をスキャンして保存することも認める。国税関係の帳簿・書類の電子保存は電子帳簿保存法で定める
- 語の意味：e＝electronic（電子の）

#### 電子帳簿保存法（でんしちょうぼほぞんほう）

- 意味：国税関係の帳簿や書類を、電子データで保存するための要件を定めた法律
- ポイント：電子メールやWebで受け取った請求書などの電子取引のデータは、紙に印刷せず電子データのまま保存する義務がある（2024年から）
- 語の意味：帳簿＝お金の出入りを記録した帳面

#### インボイス制度（適格請求書等保存方式）

- 意味：消費税の仕入税額控除を受けるために、登録番号・適用税率・税率ごとの消費税額などを記載した適格請求書（インボイス）の保存を必要とする制度（2023年10月から）
- ポイント：インボイスを発行できるのは税務署に登録した適格請求書発行事業者だけ
- 語の意味：Invoice＝請求書

### ネットワークと機器の法律

#### 電気通信事業法（でんきつうしんじぎょうほう）

- 意味：電気通信事業の公正な競争と利用者の保護のため、通信事業者の登録・届出、通信の秘密の保護、利用者への説明義務などを定めた法律
- ポイント：通信の秘密を侵してはならない。Cookie などの利用者情報を外部に送る場合の通知・公表（外部送信規律）も定めている
- 語の意味：電気通信＝電気的な方法での通信

#### 電波法（でんぱほう）

- 意味：電波の公平で能率的な利用を確保するため、無線局の免許や、無線設備の技術基準などを定めた法律
- ポイント：技術基準に適合した機器には技適マークが付く。技適マークのない無線機器を国内で使うのは原則として違法
- 語の意味：電波＝電磁波のうち無線通信に使うもの

#### 通信傍受法（つうしんぼうじゅほう）

- 意味：組織的な重大犯罪の捜査のため、裁判官の令状に基づいて、捜査機関が電話などの通信を傍受することを認める法律
- ポイント：通信の秘密の例外として、厳しい要件のもとで認められている
- 語の意味：傍受＝他人の通信を受信すること

#### 航空法（ドローンの規制）

- 意味：航空機の安全な運航のための法律。無人航空機（ドローン）について、飛行禁止空域や飛行の方法、機体登録などを定める
- ポイント：100g以上の機体は登録が必要。重要施設の周辺の飛行は小型無人機等飛行禁止法でも禁止される
- 語の意味：航空＝空を飛ぶこと

#### 道路運送車両法（どうろうんそうしゃりょうほう）

- 意味：自動車の安全基準や検査（車検）などを定めた法律。自動運転装置（自動運行装置）の保安基準も定めている
- ポイント：レベル3以上の自動運転を可能にするため改正された。運転者の義務は道路交通法で定める
- 語の意味：運送車両＝人や物を運ぶ車

### 環境と輸出の規制

#### RoHS指令（ローズしれい / Restriction of Hazardous Substances）

- 意味：EUの指令で、電気・電子機器に鉛・水銀・カドミウムなどの特定の有害物質を使うことを制限し、製品の生産から処分までの全段階で、人の健康と環境への危険を最小にすることを目的とする
- ポイント：リサイクルは WEEE指令、電磁妨害は EMC指令、兵器関連の輸出は安全保障貿易管理（R4春 問80、R7春 問80）
- 語の意味：Restriction＝制限／Hazardous＝有害な／Substances＝物質

#### WEEE指令（ウィー指令 / Waste Electrical and Electronic Equipment）

- 意味：EUの指令で、廃棄された電気・電子機器の回収とリサイクルを製造者に義務付け、廃棄物を減らすもの
- ポイント：有害物質の使用を制限するのは RoHS指令。こちらは廃棄後のリサイクル
- 語の意味：Waste＝廃棄物／Equipment＝機器

#### EMC指令（イーエムシーしれい / Electromagnetic Compatibility）

- 意味：EUの指令で、電気・電子機器が出す電磁妨害が他の機器の動作を妨げないこと、また外からの電磁妨害に耐えることを求めるもの
- ポイント：電磁妨害は EMC指令、有害物質は RoHS指令、廃棄・リサイクルは WEEE指令（R4春 問80 の誤りの選択肢）
- 語の意味：Electromagnetic＝電磁気の／Compatibility＝両立性

#### CEマーク（CE Marking）

- 意味：EU域内で販売する製品が、EUの安全・健康・環境保護の基準（指令）に適合していることを示すマーク
- ポイント：製造者が自ら適合を宣言して付ける場合が多い。RoHS指令への適合も CEマークの要件に含まれる
- 語の意味：CE＝フランス語の Conformité Européenne（欧州適合）

#### 外為法（外国為替及び外国貿易法）

- 意味：外国との資金や物・技術の取引を規制する法律。安全保障のため、兵器や大量破壊兵器の開発に使われるおそれのある貨物・技術の輸出や提供には、経済産業大臣の許可が必要
- ポイント：リストに載った品目を規制する「リスト規制」と、リスト外でも用途や需要者に懸念がある場合に規制する「キャッチオール規制」がある。暗号技術を使った製品やソフトも対象になりうる
- 語の意味：外為＝外国為替

#### 資源有効利用促進法（リサイクル法）

- 意味：製品の設計から廃棄までを通じて、廃棄物の発生を抑え（リデュース）、部品を再使用し（リユース）、資源として再利用する（リサイクル）ことを進める法律
- ポイント：パソコンのメーカーによる回収・リサイクルを義務付けている。家電4品目は家電リサイクル法で別に定める
- 語の意味：有効利用＝無駄なく使うこと

#### GX推進法（ジーエックスすいしんほう）

- 意味：脱炭素社会への移行（グリーントランスフォーメーション）を進めるため、GX経済移行債の発行やカーボンプライシングの導入などを定めた法律
- ポイント：2050年のカーボンニュートラルの実現と、経済成長の両立が目的
- 語の意味：GX＝Green Transformation

### 情報倫理と技術者倫理

#### 技術者倫理（ぎじゅつしゃりんり / Engineering Ethics）

- 意味：専門的な技術者が、公衆の安全・健康・福祉を最優先し、誠実に業務を行うために守るべき倫理
- ポイント：技術者の団体（情報処理学会など）は倫理綱領を定めている。法律で決まっていなくても、社会への影響を考えて行動する責任がある
- 語の意味：Ethics＝倫理

#### 集団思考（しゅうだんしこう / Groupthink）

- 意味：強い連帯性をもつチームが、まとまりを優先するあまり自らへの批判的な思考を欠き、不合理な合意に達してしまうこと
- ポイント：技術者倫理の遵守を妨げる要因の一つ（R5春 問80）。権威への無批判な服従、自己中心的な視点、勇気の欠如とは別の要因
- 語の意味：Group＝集団／Think＝考える

#### 内部告発（ないぶこくはつ / Whistleblowing）

- 意味：組織の内部の人が、組織の不正や法令違反を、組織の内外の適切な窓口に知らせること
- ポイント：公益通報者保護法で、一定の要件を満たす通報者は解雇などから守られる
- 語の意味：Whistle＝笛／Blow＝吹く（警笛を鳴らす）

#### インフォームドコンセント（Informed Consent）

- 意味：十分な説明を受けて理解したうえで、本人が自らの意思で同意すること
- ポイント：医療から広がった考え方。個人データの取得や研究への協力などでも求められる
- 語の意味：Informed＝説明を受けた／Consent＝同意

#### ELSI（エルシー / Ethical, Legal and Social Issues）

- 意味：新しい科学技術（AI・ゲノムなど）を社会で使うときに生じる、倫理的・法的・社会的な課題
- ポイント：技術の開発の段階から ELSI を考え、社会に受け入れられる形を探ることが求められる
- 語の意味：Ethical＝倫理的／Legal＝法的／Social＝社会的／Issues＝課題

#### ミスインフォメーション（Misinformation）

- 意味：内容が誤っているが、害を与える意図はなく広がる情報。勘違いや誤解による誤情報
- ポイント：意図的に作られた偽情報はディスインフォメーション、内容は正しいが害を与える目的で広げるのはマルインフォメーション
- 語の意味：Mis＝誤った

#### ディスインフォメーション（Disinformation）

- 意味：人をだましたり害を与えたりする目的で、意図的に作られて広められる偽の情報
- ポイント：選挙への介入などに使われる。誤りであり、かつ悪意がある点で他と区別する
- 語の意味：Dis＝否定・反対

#### マルインフォメーション（Malinformation）

- 意味：内容は事実だが、個人や組織に害を与える目的で広められる情報（私的な情報の暴露など）
- ポイント：真実であっても、悪意で広めれば問題になる
- 語の意味：Mal＝悪い

#### フェイクニュース（Fake News）

- 意味：事実ではない内容を、ニュースのように見せかけて広める情報
- ポイント：SNSで急速に拡散しやすい。真偽を確かめるファクトチェックが対策
- 語の意味：Fake＝偽物の

#### ファクトチェック（Fact Check）

- 意味：社会に広がっている情報やニュースが事実に基づいているかを調べ、その結果を公表すること
- ポイント：フェイクニュースや誤情報への対策
- 語の意味：Fact＝事実／Check＝確認

#### エコーチェンバー（Echo Chamber）

- 意味：SNSなどで、自分と似た意見の人とばかりつながることで、同じ意見が反響し合い、それが正しいと思い込んでしまう現象
- ポイント：利用者のつながり方で起きる。アルゴリズムが好みの情報だけを見せる結果、情報が偏るのはフィルターバブル
- 語の意味：Echo＝反響／Chamber＝部屋

#### フィルターバブル（Filter Bubble）

- 意味：検索エンジンやSNSのアルゴリズムが、利用者の好みに合う情報を優先して表示するため、利用者が自分の見たい情報の泡の中に閉じこもってしまう現象
- ポイント：システムの推薦（パーソナライズ）が原因。人のつながり方による反響はエコーチェンバー
- 語の意味：Filter＝ふるい分け／Bubble＝泡

#### デジタルタトゥー（Digital Tattoo）

- 意味：インターネット上に一度公開された書込みや写真などが、拡散・保存されて、完全に消すことが難しくなること
- ポイント：入れ墨（タトゥー）のように消せないことのたとえ
- 語の意味：Tattoo＝入れ墨

#### ヘイトスピーチ（Hate Speech）

- 意味：人種・民族・国籍などを理由に、特定の集団を排除したり、差別や憎悪をあおったりする言動
- ポイント：日本ではヘイトスピーチ解消法で、解消に向けた取組みが定められている
- 語の意味：Hate＝憎しみ／Speech＝言論

#### フィルタリング（Filtering）

- 意味：有害なWebサイトなどへのアクセスを制限する仕組み。保護者が子どもの利用を管理するのはペアレンタルコントロール
- ポイント：青少年インターネット環境整備法で、携帯電話事業者などに、青少年へのフィルタリングの提供が義務付けられている
- 語の意味：Filter＝ふるい分ける

## 23-5 標準化関連

### まとめ表

### 標準の種類

#### デジュレスタンダード（De Jure Standard）

- 意味：ISO・IEC・JIS など、公的な標準化機関が、決められた手続で合意して作った標準
- ポイント：公的に定めた「法律上の」標準。市場で広く使われて事実上の標準になったものはデファクトスタンダード
- 語の意味：De jure＝ラテン語で「法律上の」

#### デファクトスタンダード（De Facto Standard）

- 意味：公的機関が定めたものではなく、市場での競争の結果、多くの人に使われることで事実上の標準になった規格や製品
- ポイント：特定の企業の製品が広く普及した場合など。公的機関が作るのはデジュレスタンダード
- 語の意味：De facto＝ラテン語で「事実上の」

#### フォーラム標準（Forum Standard）

- 意味：関心のある複数の企業や団体が集まって組織（フォーラム）を作り、合意して決めた標準
- ポイント：W3C・OMG・IETF などが作る標準。公的機関よりも速く標準を作れる
- 語の意味：Forum＝集まって議論する場

#### 国際規格（IS / International Standard）

- 意味：ISO や IEC などの国際標準化機関が定めた、世界共通の規格
- ポイント：各国の規格をできるだけ国際規格に合わせることで、貿易の障壁を減らす（WTO の TBT協定）
- 語の意味：International＝国際的な／Standard＝規格

### 標準化団体

#### ISO（International Organization for Standardization / 国際標準化機構）

- 意味：各国の代表的な標準化機関が参加し、電気・電子技術分野を除く工業製品や、マネジメントシステムなどの国際規格を作る機関
- ポイント：日本からは JISC が参加。情報技術の分野は IEC と合同の委員会（ISO/IEC JTC 1）で規格を作る
- 語の意味：International＝国際的な／Standardization＝標準化

#### IEC（International Electrotechnical Commission / 国際電気標準会議）

- 意味：電気・電子技術分野の国際規格を作る機関
- ポイント：ISO と役割を分担している。情報セキュリティの ISO/IEC 27001 のように、共同で作る規格もある
- 語の意味：Electrotechnical＝電気技術の／Commission＝会議・委員会

#### ITU（International Telecommunication Union / 国際電気通信連合）

- 意味：電気通信の国際的な標準化や、電波の周波数の割当てなどを行う国際連合の専門機関
- ポイント：通信の標準を作る部門が ITU-T。動画圧縮の H.264 などは ITU-T の勧告
- 語の意味：Telecommunication＝電気通信／Union＝連合

#### IETF（Internet Engineering Task Force）

- 意味：インターネットで使われる技術（TCP/IP・HTTP・電子メールなど）の標準を作る団体。成果は RFC として公開される
- ポイント：誰でも参加できる開かれた組織。Webのページの記述などの標準は W3C
- 語の意味：Internet Engineering＝インターネット技術／Task Force＝特別な作業部会

#### IEEE（Institute of Electrical and Electronics Engineers / 電気電子学会）

- 意味：米国に本部をもつ、電気・電子・通信分野の技術者の学会。LAN などの標準規格も作る
- ポイント：IEEE 802.3（イーサネット）、IEEE 802.11（無線LAN）、IEEE 754（浮動小数点数）などが有名
- 語の意味：Institute＝協会・学会／Engineers＝技術者

#### W3C（World Wide Web Consortium）

- 意味：HTML・CSS・XML など、Webで使われる技術の標準化を進める国際的な団体
- ポイント：インターネットの通信の仕組みは IETF、Webのページの記述は W3C
- 語の意味：World Wide Web＝ウェブ／Consortium＝共同事業体

#### OMG（Object Management Group）

- 意味：UML・CORBA など、オブジェクト指向技術の標準化を進める団体
- ポイント：分散したオブジェクトどうしが連携する仕組みの CORBA、モデルを図で表す UML を策定した
- 語の意味：Object＝オブジェクト／Management＝管理／Group＝団体

#### NIST（National Institute of Standards and Technology / 米国国立標準技術研究所）

- 意味：米国の技術標準を作る国の研究機関。暗号（AES など）やサイバーセキュリティのフレームワーク（CSF）などを公開している
- ポイント：米国の国家規格を承認するのは ANSI。NIST は政府の標準や指針を作る
- 語の意味：National＝国立の／Institute＝研究所／Standards＝標準／Technology＝技術

#### ANSI（American National Standards Institute / 米国規格協会）

- 意味：米国の工業規格の標準化を行い、米国の国家規格を承認する民間の団体。ISO に米国の代表として参加している
- ポイント：日本の JISC に当たる立場。文字コードの ASCII も ANSI の規格
- 語の意味：American＝米国の／National Standards＝国家規格

#### JIS（Japanese Industrial Standards / 日本産業規格）

- 意味：日本の産業標準化法に基づき、JISC（日本産業標準調査会）の審議を経て、主務大臣が制定する国家規格
- ポイント：情報処理は JIS X、管理システムは JIS Q の部門。JIS の原案作成や規格票の発行は JSA（日本規格協会）などが行う
- 語の意味：Japanese＝日本の／Industrial＝産業の／Standards＝規格

#### JISC（Japanese Industrial Standards Committee / 日本産業標準調査会）

- 意味：経済産業省に置かれた審議会で、JIS の制定や改正を審議し、主務大臣に答申する
- ポイント：ISO・IEC に日本を代表して参加する機関でもある
- 語の意味：Committee＝委員会

### 開発・評価の標準

#### 共通フレーム（SLCP-JCF / Software Life Cycle Process - Japan Common Frame）

- 意味：ソフトウェアの企画・開発・運用・保守までの作業内容と用語を体系的にまとめた、発注者と受注者の共通の物差し。IPAが公開している
- ポイント：国際規格 ISO/IEC 12207（JIS X 0160）に基づく。契約の範囲や役割分担をはっきりさせるのに使う
- 語の意味：Life Cycle＝一生／Common Frame＝共通の枠組み

#### JIS X 0160（ソフトウェアライフサイクルプロセス）

- 意味：ソフトウェアの開発・運用・保守などのライフサイクル全体のプロセスと作業を定めた規格（ISO/IEC 12207 の JIS 版）
- ポイント：システム全体のライフサイクルプロセスは JIS X 0170（ISO/IEC 15288）
- 語の意味：Life Cycle Process＝一生の作業の流れ

#### ISO/IEC 15408（コモンクライテリア / Common Criteria）

- 意味：IT製品やシステムのセキュリティ機能と、その実装の確かさを評価するための国際規格。評価保証レベル（EAL）で評価の厳しさを表す
- ポイント：製品の評価の基準。組織の情報セキュリティの管理の仕組みは ISO/IEC 27001
- 語の意味：Common Criteria＝共通の評価基準

#### ISO 14001（環境マネジメントシステム）

- 意味：組織が環境への負荷を減らすための仕組み（環境マネジメントシステム）の要求事項を定めた国際規格。JIS 版は JIS Q 14001
- ポイント：ISO 14000 シリーズの中心。品質は ISO 9001、情報セキュリティは ISO/IEC 27001
- 語の意味：Environmental＝環境の

### 文字コードとデータ形式

#### Unicode（ユニコード）

- 意味：世界中の文字を一つの文字コード体系で表すための国際的な規格。符号化方式には UTF-8・UTF-16 などがある
- ポイント：UTF-8 は英数字を1バイト、日本語の多くを3バイトで表す。Webで最も広く使われている
- 語の意味：Uni＝一つの／Code＝符号

#### シフトJISコード（Shift JIS）

- 意味：英数字・半角カナの1バイトコードと、漢字などの2バイトコードを混在させて使えるように、JIS漢字コードの位置をずらした（シフトした）文字コード
- ポイント：Windows などで長く使われてきた。日本語だけを扱う文字コードで、世界の文字には Unicode を使う
- 語の意味：Shift＝ずらす

#### EBCDIC（Extended Binary Coded Decimal Interchange Code）

- 意味：IBM が汎用コンピュータ（メインフレーム）用に作った、8ビットの文字コード
- ポイント：ASCII とは文字の割当てが違うので、メインフレームとPCでデータをやり取りするときは変換が必要
- 語の意味：Extended＝拡張された／Binary Coded Decimal＝2進化10進

#### JANコード（Japanese Article Number）

- 意味：商品を識別するためのバーコードで、国・事業者・商品・チェックデジットからなる。13桁の標準タイプと8桁の短縮タイプがある
- ポイント：国際的には EAN（GTIN）と共通。POS システムで使う。物流の梱包単位は ITF コード
- 語の意味：Article＝品物／Number＝番号

#### ITFコード（Interleaved Two of Five）

- 意味：段ボール箱など、物流の梱包単位を識別するためのバーコード（14桁）
- ポイント：段ボールのような印刷の粗い素材でも読み取りやすい。個々の商品の識別は JAN コード
- 語の意味：Interleaved＝交互に組み込まれた／Two of Five＝5本中2本が太い

#### QRコード（Quick Response Code）

- 意味：縦と横の2方向に情報をもつ2次元コード。数字なら最大約7,000文字を表せ、汚れや欠けがあっても誤り訂正機能で読み取れる
- ポイント：三つの角にある切り出しシンボル（位置検出パターン）で、どの向きからでも高速に読み取れる。日本のデンソーウェーブが開発
- 語の意味：Quick Response＝素早い応答

#### ISBNコード（International Standard Book Number）

- 意味：書籍を国際的に識別するための番号（13桁）
- ポイント：書籍のバーコードにも使われる。雑誌などの逐次刊行物は ISSN
- 語の意味：International Standard＝国際標準／Book Number＝書籍番号

#### CSV形式（Comma-Separated Values）

- 意味：データの項目をコンマで区切り、1行に1件のレコードを書くテキスト形式。表計算ソフトやデータベースのデータの受け渡しに広く使われる
- ポイント：単純なテキストなので多くのソフトで読み書きできる。表計算ソフト間で書式や数式まで交換する形式には SYLK がある
- 語の意味：Comma-Separated＝コンマで区切られた／Values＝値

#### XML（Extensible Markup Language）

- 意味：タグを利用者が自由に定義でき、データの構造と意味を表せるマークアップ言語。W3C が標準化した
- ポイント：SGML を簡略化して作られた。表示のための HTML と違い、データの交換や保存に向く
- 語の意味：Extensible＝拡張可能な／Markup＝印を付けること／Language＝言語

#### Exif（Exchangeable image file format）

- 意味：デジタルカメラで撮った画像（JPEG など）に、撮影日時・カメラの機種・露出・位置情報（GPS）などのメタデータを埋め込むための規格
- ポイント：位置情報が残ったまま SNS に写真を載せると、撮影場所が分かってしまう危険がある
- 語の意味：Exchangeable＝交換できる／image file format＝画像ファイル形式

### 適合性評価と認証

#### 適合性評価（てきごうせいひょうか / Conformity Assessment）

- 意味：製品・サービス・マネジメントシステムなどが、規格や基準の要求事項を満たしているかを確かめる活動の総称。試験・検査・認証などを含む
- ポイント：評価する機関（認証機関・試験機関）が信頼できるかを、さらに認定機関が確かめる二段階の仕組みになっている
- 語の意味：Conformity＝適合／Assessment＝評価

#### 認定機関（にんていきかん / Accreditation Body）

- 意味：認証機関や試験機関が、適合性評価を行う能力をもっているかを審査し、認める機関
- ポイント：ISMS認証の場合、日本では ISMS-AC が認定機関。認定機関が「認定」し、認証機関が「認証」する
- 語の意味：Accreditation＝能力の公式な承認

#### 認証機関（にんしょうきかん / Certification Body）

- 意味：組織のマネジメントシステムや製品が規格の要求事項に適合しているかを審査し、適合していれば認証（登録）する機関
- ポイント：認定機関から認定を受けた認証機関が審査を行う。審査に合格した組織が認証を受ける
- 語の意味：Certification＝証明・認証

#### 試験機関（しけんきかん / Testing Laboratory）

- 意味：製品やサンプルが規格の要求事項を満たしているかを、試験や測定によって確かめる機関
- ポイント：試験の結果は、認証機関の判断の材料になる
- 語の意味：Testing＝試験／Laboratory＝研究所・試験所
