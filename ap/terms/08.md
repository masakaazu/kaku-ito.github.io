## 8-1 マルチメディア技術

### まとめ表

**データ量の計算（圧縮しない場合）**

| 対象 | 式 | 例 |
| :-: | :-: | :-: |
| 音（PCM） | 標本化周波数 × 量子化ビット数 × チャネル数 × 秒数 | CDの音質 44.1kHz・16ビット・ステレオ1秒 ＝ 1,411,200ビット ≒ 176kバイト |
| 静止画 | 横の画素数 × 縦の画素数 × 1画素のビット数 | 1,920×1,080・24ビット ≒ 6.2Mバイト |
| 動画 | 1フレームのデータ量 × フレームレート × 秒数 | R6秋 問26：800×600×24ビット×30 ≒ 350Mビット／秒 |

**静止画の形式**

| 形式 | 色数 | 圧縮 | 特徴 |
| :-: | :-: | :-: | :-: |
| JPEG | フルカラー | 非可逆（DCT） | 写真向き。圧縮率を選べる |
| GIF | 256色まで | 可逆（LZW） | アニメーション・透過ができる。イラスト・ロゴ向き |
| PNG | フルカラー | 可逆 | 半透明（アルファチャネル）も表せる。GIFの後継 |
| BMP | フルカラー | 通常は圧縮しない | Windows標準。データ量が大きい |
| TIFF | フルカラー | 選べる | タグで形式を記述。印刷・スキャナーで使う |
| HEIF | フルカラー | 非可逆（HEVC） | JPEGの約半分の容量。スマートフォンの写真 |
| SVG | ― | ― | 図形をXMLで記述するベクター形式（R3春 問27） |

**圧縮の方式**

| 種類 | 元に戻せるか | 代表例 |
| :-: | :-: | :-: |
| 可逆圧縮 | 完全に戻せる | ZIP・PNG・GIF・ランレングス・ハフマン符号化・MH/MR/MMR（ファクシミリ） |
| 非可逆圧縮 | 戻せない（人が気づきにくい部分を捨てる） | JPEG・MPEG・MP3・H.264・H.265 |

### マルチメディアの基礎

#### マルチメディア（Multimedia）

- 意味：文字・音声・静止画・動画など、複数の種類のメディアをデジタルデータとして統合して扱うこと
- ポイント：全部をデジタル化することで、1台のコンピュータで同時に扱い、利用者の操作に応じて反応する（インタラクティブ性）ことができる
- 語の意味：Multi＝複数の／Media＝媒体

#### ハイパーメディア（Hypermedia）

- 意味：文字だけでなく画像・音声・動画などにもリンクを張り、関連する情報を自由にたどれるようにしたもの
- ポイント：文字どうしをリンクでつなぐハイパーテキストを、マルチメディアに広げたもの。WWWが代表
- 語の意味：Hyper＝超えた／Media＝媒体

#### Webコンテンツ（うぇぶこんてんつ / Web Content）

- 意味：Webページで提供される文章・画像・音声・動画などの情報の中身
- ポイント：HTML・CSS・画像形式・動画形式などの技術を組み合わせて作る。アクセシビリティの指針（WCAG）の対象でもある

#### メディア統合（めでぃあとうごう / Media Integration）

- 意味：文字・音声・画像・動画などの別々のメディアを、1つの作品やシステムの中で組み合わせて扱うこと
- ポイント：動画に字幕と音声を合わせる、教材に図と音声解説を入れる、など

#### オーサリング（Authoring）

- 意味：文字・画像・音声・動画などの素材を編集・統合して、1つのマルチメディア作品（Webページ・DVD・教材など）にまとめる作業
- ポイント：そのためのソフトウェアや環境をオーサリングツール（オーサリング環境）と呼ぶ。プログラムを書かずに画面の配置や動きを指定できる
- 語の意味：Author＝作者・作る

### 配信と入れ物

#### ストリーミング（Streaming）

- 意味：音声や動画のデータを受信しながら、同時に再生していく配信方式
- ポイント：全部をダウンロードし終えるのを待たずに再生できる。途中で通信が遅くなると止まらないように、少し先までためておく（バッファリング）
- 語の意味：Stream＝流れ

#### コンテナフォーマット（Container Format）

- 意味：映像・音声・字幕などの別々に圧縮されたデータを、1つのファイルにまとめて入れる「入れ物」の形式
- ポイント：MP4・AVI・MOV（QuickTime）・MKVなど。中の映像をどの方式（H.264など）で圧縮するかは、入れ物とは別に決まる
- 語の意味：Container＝容器／Format＝形式

#### コーデック（Codec）

- 意味：音声や動画のデータを圧縮（符号化）し、再生のときに伸長（復号）する方式や、そのためのソフトウェア
- ポイント：H.264・H.265・MP3・AACなど。コンテナフォーマット（入れ物）とは別のもので、同じMP4の中でもコーデックは違うことがある
- 語の意味：Coder＝符号化するもの／Decoder＝復号するもの

#### ビデオオンデマンド（Video On Demand）

- 意味：利用者が見たいときに、見たい動画を選んで、サーバーから配信を受けて視聴できるサービス
- ポイント：VODと略す。決まった時刻に一斉に流す放送と違い、一時停止や巻戻しもできる
- 語の意味：On Demand＝要求に応じて

#### インターネット放送（いんたーねっとほうそう / Internet Broadcasting）

- 意味：インターネットを使って、番組を多くの人に同時に配信すること
- ポイント：決まった時刻に生で流すライブ配信など。ストリーミングの技術を使う

### 文書と高精細映像

#### PDF（ぴーでぃーえふ / Portable Document Format）

- 意味：文字・図・画像のレイアウトを、どの機器や環境でも同じ見た目で表示・印刷できるようにした文書ファイルの形式
- ポイント：アドビ社が開発し、ISO 32000として国際規格になった。フォントを埋め込めるので、受け取った側に同じ書体がなくても崩れない
- 語の意味：Portable＝持ち運べる／Document＝文書／Format＝形式

#### DTP（でぃーてぃーぴー / Desktop Publishing）

- 意味：パソコンで文字や画像のレイアウトを行い、印刷用の版下（原稿）まで作ること
- ポイント：パンフレット・雑誌・書籍の制作に使う。机の上（デスクトップ）で出版の作業ができる、という意味
- 語の意味：Desktop＝机の上／Publishing＝出版

#### 4K・8K（よんけー・はちけー / 4K・8K）

- 意味：横の画素数がおよそ4,000（3,840×2,160）や8,000（7,680×4,320）ある、高精細な映像の規格
- ポイント：フルハイビジョン（1,920×1,080）の4倍・16倍の画素数。データ量が大きいので、H.265（HEVC）などの効率の良い圧縮を使う。Kは1,000（キロ）の意味

#### HDR（えいちでぃーあーる / High Dynamic Range）

- 意味：明るい部分から暗い部分まで、従来より広い明るさの幅を表現できる映像の技術
- ポイント：4K・8Kの放送や動画配信で使われる。まぶしい光と暗い影を同時につぶさずに表示できる
- 語の意味：High＝高い／Dynamic Range＝表せる明るさの幅

### 音のデジタル化

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：アナログの音の波を、一定の時間ごとに区切って値を測り（標本化）、その値を段階に当てはめ（量子化）、2進数に直す（符号化）デジタル化の方式。パルス符号変調
- ポイント：音楽CDやWAVファイルの方式。データ量＝標本化周波数×量子化ビット数×チャネル数×秒数
- 語の意味：Pulse＝パルス／Code＝符号／Modulation＝変調

#### 標本化（ひょうほんか / Sampling）

- 意味：連続したアナログ信号の値を、一定の時間の間隔ごとに取り出すこと。サンプリング
- ポイント：PCMの最初の手順。取り出す間隔が細かいほど元の波に近いが、データ量は増える

#### 量子化（りょうしか / Quantization）

- 意味：標本化で取り出した値を、決められた数の段階のどれかに当てはめて整数にすること
- ポイント：PCMの2番目の手順。段階の数を決めるのが量子化ビット数。段階に丸めるときの誤差を量子化誤差（量子化雑音）と呼ぶ

#### 符号化（ふごうか / Encoding）

- 意味：量子化した値を、決められたビット数の2進数（符号）で表すこと
- ポイント：PCMの3番目の手順。標本化→量子化→符号化の順番がよく問われる

#### 標本化周波数（ひょうほんかしゅうはすう / Sampling Frequency）

- 意味：1秒間に何回標本化するかを表す値。単位はHz（ヘルツ）
- ポイント：CDは44.1kHz（1秒に44,100回）。標本化周期（間隔）は標本化周波数の逆数で、44.1kHzなら約22.7マイクロ秒
- 例：R7秋 問25（20kHzまでの音を変換する最大のサンプリング周期）

#### 量子化ビット数（りょうしかびっとすう / Quantization Bit Depth）

- 意味：量子化で1つの標本を何ビットで表すか。nビットなら2のn乗の段階に分けられる
- ポイント：CDは16ビット（65,536段階）。ビット数が多いほど細かい音の大きさの違いを表せる

#### 標本化定理（ひょうほんかていり / Sampling Theorem）

- 意味：元の信号に含まれる最も高い周波数の2倍以上の周波数で標本化すれば、元の信号を復元できるという定理。シャノンの標本化定理
- ポイント：人が聞こえる上限は約20kHzなので、その2倍強の44.1kHzがCDで使われる。20kHzまでなら40kHz以上で標本化、つまり周期は 1÷40,000秒＝25マイクロ秒以下
- 例：R7秋 問25

### 音声のファイル形式

#### WAV（うぇーぶ / Waveform Audio Format）

- 意味：WindowsでよくPCMの音声をそのまま（多くは圧縮せずに）保存するファイル形式
- ポイント：音質が劣化しないがデータ量は大きい。Macで同じ役割の形式がAIFF
- 語の意味：Waveform＝波形／Audio＝音声／Format＝形式

#### AIFF（えーあいえふえふ / Audio Interchange File Format）

- 意味：アップル社が定めた、PCMの音声を圧縮せずに保存するファイル形式
- ポイント：Macで標準的に使われる。WindowsのWAVに当たる
- 語の意味：Audio＝音声／Interchange＝交換／File Format＝ファイル形式

#### AU（えーゆー / Audio or mu-law）

- 意味：サン・マイクロシステムズ社のUNIXで使われていた音声ファイル形式
- ポイント：電話の音声などで使うμ-law（ミュー・ロー）という方式で、音を少ないビット数に圧縮して記録できる
- 語の意味：Audio＝音声／mu-law＝μ則（音の大きさを対数的に量子化する方式）

#### MP3（えむぴーすりー / MPEG-1 Audio Layer-3）

- 意味：人の耳に聞こえにくい音の成分を削って、音声データを約10分の1に小さくする非可逆圧縮の形式
- ポイント：大きな音のすぐそばの小さな音は聞こえにくい（マスキング効果）など、耳の特性を利用する。元には戻せない。後継にAACがある
- 語の意味：MPEG-1＝動画の規格の名前／Audio Layer-3＝その音声部分の第3層

#### AAC（えーえーしー / Advanced Audio Coding）

- 意味：MP3の後継として作られた、非可逆圧縮の音声の形式
- ポイント：同じデータ量ならMP3より高音質。動画配信や地上デジタル放送の音声で使われる
- 語の意味：Advanced＝進んだ／Audio Coding＝音声の符号化

#### MIDI（みでぃ / Musical Instrument Digital Interface）

- 意味：電子楽器とコンピュータの間で演奏の情報をやり取りするための規格。音そのものではなく、どの音を・いつ・どの強さで鳴らすかという命令を送る
- ポイント：音の波形を持たないので、データ量がとても小さい。実際の音はMIDI音源が作るので、音源によって聞こえ方が変わる
- 語の意味：Musical Instrument＝楽器／Digital Interface＝デジタルの接続方式

#### MIDI音源（みでぃおんげん / MIDI Sound Module）

- 意味：MIDIの演奏情報を受け取り、それに従って実際の楽器の音を合成して鳴らす装置やソフトウェア
- ポイント：同じMIDIデータでも、音源が違えば音色が変わる。シンセサイザーやパソコンのソフト音源など

### 画像の表し方

#### ラスターデータ（Raster Data）

- 意味：画像を、色の付いた小さな点（画素）の並びとして表すデータ。ビットマップデータとも呼ぶ
- ポイント：写真のような複雑な色の変化を表せるが、拡大するとギザギザ（ジャギー）が目立つ。JPEG・PNG・GIF・BMPなど
- 語の意味：Raster＝走査線の並び

#### ベクターデータ（Vector Data）

- 意味：画像を、点の座標と、それを結ぶ線・曲線・塗りの色などの図形の情報として表すデータ
- ポイント：計算して描くので、拡大・縮小しても線がなめらか。図形やロゴ、地図・CADに向く。SVGが代表
- 語の意味：Vector＝向きと大きさを持つ量

#### ジャギー（Jaggies）

- 意味：ラスター形式の画像で、斜めの線や曲線の輪郭に現れる階段状のギザギザ
- ポイント：画素が四角い点なので起きる。拡大すると目立つ。アンチエイリアシングで目立たなくでき、ベクター形式ならそもそも起きにくい
- 語の意味：Jagged＝ぎざぎざの

#### 画像のデータ量（がぞうのでーたりょう / Image Data Size）

- 意味：圧縮しない画像の大きさ。横の画素数×縦の画素数×1画素のビット数で求める
- ポイント：1,920×1,080画素・24ビットなら約6.2Mバイト。動画ならこれにフレームレートと秒数を掛ける。ベクター形式は画素数ではなく図形の数で大きさが決まる

### 静止画の形式

#### JPEG（じぇいぺぐ / Joint Photographic Experts Group）

- 意味：写真などのフルカラーの静止画を、非可逆圧縮で小さくする形式。作った団体の名前でもある
- ポイント：画像を8×8画素のブロックに分け、DCT（離散コサイン変換）で周波数の成分に直し、細かい変化（高い周波数）の情報を多く捨てる。圧縮率を上げるとブロック状のノイズが出る
- 語の意味：Joint＝共同の／Photographic＝写真の／Experts Group＝専門家の団体

#### GIF（じふ / Graphics Interchange Format）

- 意味：256色までの画像を可逆圧縮（LZW）で保存する形式
- ポイント：アニメーションと透過ができるので、イラストやアイコンに使われてきた。色数が少ないので写真には向かない
- 語の意味：Graphics＝画像／Interchange＝交換／Format＝形式

#### PNG（ぴんぐ / Portable Network Graphics）

- 意味：フルカラーの画像を可逆圧縮で保存でき、半透明（アルファチャネル）も表せる形式
- ポイント：GIFの後継としてWeb向けに作られた。劣化しないので、文字や線を含むスクリーンショットに向く。写真ではJPEGよりデータ量が大きくなりやすい
- 語の意味：Portable＝持ち運べる／Network＝ネットワーク／Graphics＝画像

#### BMP（びーえむぴー / Bitmap）

- 意味：Windowsで標準的に使われる、画素の色をそのまま並べて保存する静止画の形式
- ポイント：通常は圧縮しないので、画質は劣化しないがデータ量が大きい
- 語の意味：Bit＝ビット／Map＝配置図

#### TIFF（てぃふ / Tagged Image File Format）

- 意味：画像の大きさや色の形式などの情報を「タグ」で記述し、さまざまな形式の画像を1つの仕組みで保存できる形式
- ポイント：1つのファイルに複数の画像を入れられ、圧縮の有無も選べる。印刷・スキャナー・ファクシミリの画像で使われる
- 語の意味：Tagged＝タグの付いた／Image＝画像／File Format＝ファイル形式

#### HEIF（ひーふ / High Efficiency Image File Format）

- 意味：動画の圧縮方式HEVC（H.265）の技術を使って、静止画を高い効率で圧縮して保存する形式
- ポイント：同じ画質でJPEGの約半分のデータ量。スマートフォンの写真の保存形式として使われる。拡張子は .heic など
- 語の意味：High Efficiency＝高効率／Image File Format＝画像ファイル形式

#### SVG（えすぶいじー / Scalable Vector Graphics）

- 意味：矩形・円・直線・文字列などの図形を、XMLの形式で記述するベクター画像の形式
- ポイント：W3Cが仕様を定めた。拡大しても劣化せず、Webページの図形描画に使える。テキストなので検索や編集もできる
- 例：R3春 問27・R7春 問23
- 語の意味：Scalable＝拡大・縮小できる／Vector＝ベクター形式の／Graphics＝画像

#### Exif（いぐじふ / Exchangeable Image File Format）

- 意味：デジタルカメラで撮った画像に、撮影日時・カメラの機種・露出・位置情報（GPS）などの情報を付けて保存するための規格
- ポイント：JPEGなどの画像の中にメタデータとして埋め込まれる。写真を公開するとき、位置情報から住所が分かってしまうことに注意
- 語の意味：Exchangeable＝交換できる／Image File Format＝画像ファイル形式

### 動画の表示と編集

#### フレーム（動画）（Frame）

- 意味：動画を作っている1枚1枚の静止画
- ポイント：少しずつ違うフレームを素早く切り替えて表示することで、動いて見える

#### フレームレート（Frame Rate）

- 意味：1秒間に何枚のフレームを表示するかを表す値。単位はfps（frames per second）
- ポイント：テレビ放送は約30fps、映画は24fps。フレームレートが高いほど動きがなめらかだが、データ量は増える
- 例：R6秋 問26（30フレーム／秒の動画の帯域幅）
- 語の意味：Frame＝こま／Rate＝割合・速さ

#### インターレース方式（いんたーれーすほうしき / Interlaced Scan）

- 意味：1枚の画面を奇数番目の走査線と偶数番目の走査線に分け、交互に表示する方式
- ポイント：1回に半分の行だけ送るので、少ない帯域でちらつきを抑えられる。昔のテレビ放送の方式。速い動きでは横じまが出ることがある
- 語の意味：Interlace＝織り交ぜる

#### プログレッシブ方式（ぷろぐれっしぶほうしき / Progressive Scan）

- 意味：1枚の画面の全部の走査線を、上から順に1回で表示する方式
- ポイント：インターレース方式よりなめらかで、パソコンの画面や今の動画配信で使われる。「1080p」のpがプログレッシブ、「1080i」のiがインターレース
- 語の意味：Progressive＝順に進む

#### リニア編集（りにあへんしゅう / Linear Editing）

- 意味：テープに記録された映像を、頭から順番に再生しながら、別のテープにつなぎ合わせて編集する方法
- ポイント：途中を直すと、そこから後ろを全部作り直す必要がある
- 語の意味：Linear＝直線的な・順番どおりの

#### ノンリニア編集（のんりにあへんしゅう / Non-linear Editing）

- 意味：映像をデジタルデータとしてハードディスクなどに取り込み、コンピュータ上で好きな場所を自由な順番で切り貼りして編集する方法
- ポイント：途中の場面だけ入れ替えたり、何度でもやり直したりできる。今の動画編集ソフトはこの方式
- 語の意味：Non＝ない／Linear＝直線的な

### 動画の形式

#### MPEG（えむぺぐ / Moving Picture Experts Group）

- 意味：動画と音声の圧縮方式の規格群。作った団体の名前でもある
- ポイント：MPEG-1（ビデオCD）・MPEG-2（DVD・デジタル放送）・MPEG-4（携帯機器・ネット配信）と用途ごとにある。前後のフレームとの差分だけを記録するフレーム間予測で大きく圧縮する（非可逆）
- 語の意味：Moving Picture＝動画／Experts Group＝専門家の団体

#### H.264（えいち・にろくよん / H.264/MPEG-4 AVC）

- 意味：ITU-TとISOが共同で定めた、動画の圧縮符号化方式。MPEG-4 AVCとも呼ぶ
- ポイント：MPEG-2の約2倍の効率。ワンセグ放送・ブルーレイ・インターネットの動画配信で広く使われる
- 例：R4秋 問25
- 語の意味：AVC＝Advanced Video Coding（進んだ動画の符号化）

#### H.265（えいち・にろくご / HEVC: High Efficiency Video Coding）

- 意味：H.264の後継の動画の圧縮符号化方式。HEVCとも呼ぶ
- ポイント：H.264の約2倍の圧縮効率で、4K・8Kの放送や配信に使う。静止画の形式HEIFにもこの技術が使われる
- 語の意味：High Efficiency＝高効率／Video Coding＝動画の符号化

#### Motion JPEG（もーしょんじぇいぺぐ / Motion JPEG）

- 意味：動画の各フレームを、それぞれ独立したJPEG画像として圧縮する方式
- ポイント：フレーム間の差分を使わないので圧縮率はMPEGより低いが、どのフレームからでも編集しやすい。監視カメラやデジタルカメラの動画で使われる

#### AVI（えーぶいあい / Audio Video Interleave）

- 意味：マイクロソフト社が定めた、映像と音声を1つのファイルに入れるコンテナフォーマット
- ポイント：中に入れる映像・音声の圧縮方式（コーデック）は自由に選べる。Windowsで古くから使われる
- 語の意味：Audio＝音声／Video＝映像／Interleave＝交互に入れる

#### QuickTime（くいっくたいむ / QuickTime）

- 意味：アップル社が開発した、動画・音声を扱うための技術と、そのファイル形式（.mov）
- ポイント：映像・音声・字幕などをまとめて入れるコンテナフォーマットとして使われる。MP4のもとになった

### 圧縮の考え方

#### 可逆圧縮（かぎゃくあっしゅく / Lossless Compression）

- 意味：圧縮したデータを伸長すると、元のデータと完全に同じものに戻せる圧縮
- ポイント：プログラムや文書、医療画像など、1ビットも変わっては困るデータに使う。ZIP・PNG・GIF・ランレングス・ハフマン符号化など。圧縮率は非可逆圧縮より低い

#### 非可逆圧縮（ひかぎゃくあっしゅく / Lossy Compression）

- 意味：人が気づきにくい情報を捨てることで大きく圧縮し、伸長しても元のデータには完全には戻らない圧縮
- ポイント：音声・画像・動画に使う。JPEG・MPEG・MP3・H.264など。圧縮をやり直すたびに劣化が重なる

#### 圧縮率（あっしゅくりつ / Compression Ratio）

- 意味：圧縮後のデータ量が、元のデータ量に対してどれだけの割合になったかを表す値
- ポイント：「圧縮後÷圧縮前」で表すことが多く、その場合は値が小さいほどよく縮んでいる。逆に「元の何分の1か」で言うこともあるので、問題文の定義を確かめる

#### 伸長（しんちょう / Decompression）

- 意味：圧縮したデータを、使える形（元のデータ、又はそれに近いもの）に戻すこと。解凍・展開とも呼ぶ
- ポイント：圧縮の目的は、保存の容量を減らす（効率の良いデータ保存）ことと、通信で送る量を減らす（ネットワーク負荷の軽減）こと

#### フレーム間予測（ふれーむかんよそく / Inter-frame Prediction）

- 意味：動画で、前後のフレームとの違い（動いた部分）だけを記録して、データ量を減らす圧縮の手法
- ポイント：MPEGやH.264が使う。動いた量と向きを記録する動き補償と組み合わせる。1枚の中だけで縮めるのはフレーム内圧縮（Motion JPEGなど）

### 圧縮の方式

#### ランレングス符号化（らんれんぐすふごうか / Run-length Encoding）

- 意味：同じ値が続く部分を「値と、それが続く個数」の組に置き換えて圧縮する方式
- ポイント：「AAAAABBB」→「A5B3」。白と黒が長く続くファクシミリの画像に向く。値がばらばらだとかえって大きくなる
- 語の意味：Run＝連続／Length＝長さ

#### ハフマン符号化（はふまんふごうか / Huffman Coding）

- 意味：よく出てくる文字には短い符号を、まれな文字には長い符号を割り当てて、全体のビット数を減らす可逆圧縮の方式
- ポイント：文字の出現の頻度から符号の木（ハフマン木）を作る。ZIPやJPEGの最後の段階でも使われる

#### MH（えむえいち / Modified Huffman）

- 意味：ファクシミリで使う1次元の符号化方式。1本の走査線ごとに、白と黒が続く長さ（ランレングス）をハフマン符号で表す
- ポイント：G3ファクシミリの基本の方式。ほかの行との関係は使わない
- 語の意味：Modified＝改良した／Huffman＝ハフマン符号

#### MR（えむあーる / Modified READ）

- 意味：ファクシミリで使う2次元の符号化方式。1つ前の走査線との違い（白黒の変わり目の位置のずれ）を使って符号化する
- ポイント：隣の行はよく似ているので、MHより圧縮率が高い。誤りが伝わり続けないよう、何行かおきにMHで送る
- 語の意味：Modified＝改良した／READ＝Relative Element Address Designate（相対的な位置の指定）

#### MMR（えむえむあーる / Modified Modified READ）

- 意味：MRをさらに改良し、途中でMHの行をはさまずに、全ての行を前の行との違いで符号化するファクシミリの方式
- ポイント：誤りの訂正ができる通信路（G4ファクシミリ）を前提にして、圧縮率を最も高くした
- 語の意味：Modified Modified＝さらに改良した／READ＝相対的な位置の指定

#### ZIP（じっぷ / ZIP）

- 意味：複数のファイルを1つにまとめ（アーカイブ）、可逆圧縮して保存するファイル形式
- ポイント：LZ77とハフマン符号化を組み合わせたDeflateという方式で圧縮する。展開すれば元のファイルが完全に戻る

### 色の表し方

#### 光の3原色（ひかりのさんげんしょく / RGB）

- 意味：赤（Red）・緑（Green）・青（Blue）の3つの色の光。これを混ぜる割合で、ほとんどの色の光を作れる
- ポイント：ディスプレイの画素はRGBの3つの点の明るさで色を出す。各色8ビット（256段階）なら24ビットで約1,677万色（フルカラー）

#### 色の3原色（いろのさんげんしょく / CMY）

- 意味：シアン（Cyan）・マゼンタ（Magenta）・イエロー（Yellow）の3つのインクの色。これを混ぜる割合で色を作る
- ポイント：インクは光を吸収して色を出すので、混ぜるほど暗くなる。印刷やプリンターで使う

#### キープレート（Key Plate）

- 意味：印刷で、CMYの3色に加えて使う黒（K）のインクの版
- ポイント：CMYを全部重ねても純粋な黒にならず、インクも多く使うので、黒は別のインクで刷る。CMYKのKはこのKey Plate（墨版）のこと
- 語の意味：Key＝主となる／Plate＝版

#### 加法混色（かほうこんしょく / Additive Color Mixing）

- 意味：光を重ねて色を作る方法。重ねるほど明るくなり、RGBを全部同じ強さで重ねると白になる
- ポイント：ディスプレイ・プロジェクター・照明の色の作り方。赤＋緑＝黄、緑＋青＝シアン、青＋赤＝マゼンタ

#### 減法混色（げんぽうこんしょく / Subtractive Color Mixing）

- 意味：インクや絵の具を重ねて色を作る方法。光を吸収する色が増えるので、重ねるほど暗くなる
- ポイント：印刷の色の作り方。CMYを全部重ねると黒に近い色になる

#### 色相（しきそう / Hue）

- 意味：赤・黄・緑・青など、色みの種類の違い
- ポイント：色相を円の形に並べたものを色相環と呼ぶ。明度・彩度と合わせて色の三属性

#### 明度（めいど / Lightness）

- 意味：色の明るさの度合い
- ポイント：明度が最も高いのが白、最も低いのが黒。色の三属性の1つ

#### 彩度（さいど / Saturation）

- 意味：色の鮮やかさの度合い
- ポイント：彩度が高いほど鮮やかな純色に近く、低いほど灰色に近い。白・灰・黒は彩度がない（無彩色）。色の三属性の1つ

#### コントラスト（Contrast）

- 意味：画像の明るい部分と暗い部分の明るさの差
- ポイント：コントラストが高いと、くっきりはっきり見える。文字と背景のコントラストが低いと読みにくい（アクセシビリティの観点）

### YUVフォーマット

#### YUV（わいゆーぶい / YUV）

- 意味：色を、明るさ（輝度Y）と、色の違い（色差U・V）の3つの成分で表す方式
- ポイント：人の目は明るさの変化には敏感だが、色の細かい変化には鈍い。そこで色差の情報を間引いてデータ量を減らす。テレビ放送や動画の圧縮で使う
- 語の意味：Y＝輝度／U・V＝色差（青と赤の成分の差）

#### YUV444（わいゆーぶいよんよんよん / YUV444）

- 意味：全ての画素について、輝度Yと色差U・Vを全部持つ形式
- ポイント：色差を間引かないので最も高画質だが、データ量はRGBと同じ。1画素あたり3つの値

#### YUV422（わいゆーぶいよんにーにー / YUV422）

- 意味：横に並んだ2画素で色差U・Vを1組だけ共有する形式
- ポイント：色差が横方向に半分になる。データ量はYUV444の3分の2（1画素あたり2つの値）。業務用の映像で使われる

#### YUV420（わいゆーぶいよんにーぜろ / YUV420）

- 意味：縦2×横2の4画素で色差U・Vを1組だけ共有する形式
- ポイント：色差が縦にも横にも半分になる。データ量はYUV444の半分（1画素あたり1.5個の値）。DVD・デジタル放送・動画配信など最もよく使われる

#### YUV411（わいゆーぶいよんいちいち / YUV411）

- 意味：横に並んだ4画素で色差U・Vを1組だけ共有する形式
- ポイント：データ量はYUV420と同じくYUV444の半分だが、色差を横方向だけで4分の1に間引く。DVなどの家庭用ビデオで使われた

### 画像の品質

#### 画素（がそ / Pixel）

- 意味：デジタル画像を作っている、色の付いた最小の点。ピクセル
- ポイント：画像の大きさは「横の画素数×縦の画素数」で表す。1画素のビット数（色深度）が多いほど多くの色を表せる
- 語の意味：Picture＝画像／Element＝要素

#### 解像度（かいぞうど / Resolution）

- 意味：画像や表示・印刷の細かさの度合い。画素の数や、1インチあたりの点の数で表す
- ポイント：ディスプレイでは「1,920×1,080」のように画素数で、プリンターやスキャナーではdpiで表すことが多い

#### dpi（でぃーぴーあい / dots per inch）

- 意味：1インチ（約2.54cm）の長さに、いくつの点（ドット）を打てるかを表す単位
- ポイント：主にプリンターやスキャナーの細かさに使う。600dpiで幅5インチに印刷するなら、横に3,000個の点が必要
- 語の意味：dots＝点／per＝あたり／inch＝インチ

#### ppi（ぴーぴーあい / pixels per inch）

- 意味：1インチの長さに、いくつの画素（ピクセル）があるかを表す単位
- ポイント：主にディスプレイや画像データの細かさに使う。同じ画素数でも、画面が小さいほどppiは高く、きめ細かく見える
- 語の意味：pixels＝画素／per＝あたり／inch＝インチ

#### 色深度（いろしんど / Color Depth）

- 意味：1画素の色を何ビットで表すか。ビット深度とも呼ぶ
- ポイント：8ビットなら256色、24ビットなら約1,677万色（フルカラー）。画像のデータ量＝画素数×色深度

### グラフィックスソフトウェア

#### ペイント系ソフトウェア（ぺいんとけいそふとうぇあ / Paint Software）

- 意味：画像を画素の集まり（ラスター形式）として扱い、画素の色を塗るように描いたり直したりするソフトウェア
- ポイント：写真の加工や、筆で塗るような絵に向く。拡大するとギザギザになる

#### ドロー系ソフトウェア（どろーけいそふとうぇあ / Drawing Software）

- 意味：画像を線・曲線・図形の組合せ（ベクター形式）として扱い、図形を配置して描くソフトウェア
- ポイント：ロゴ・イラスト・図面に向く。拡大しても線がなめらかで、図形ごとに後から形や色を変えられる

#### フォトレタッチ（Photo Retouch）

- 意味：撮影した写真の明るさ・色合いを調整したり、傷やごみを消したりして修整すること
- ポイント：ペイント系ソフトウェアで行う。修整用のソフトウェアをフォトレタッチソフトと呼ぶ
- 語の意味：Photo＝写真／Retouch＝修整する

#### レイヤー（Layer）

- 意味：画像を透明なシートを何枚も重ねたように扱い、シートごとに描いたり編集したりする機能
- ポイント：背景・人物・文字を別のレイヤーにすれば、ほかの部分を壊さずに1つだけ直せる
- 語の意味：Layer＝層

#### トリミング（Trimming）

- 意味：画像の必要な部分だけを残し、周りの不要な部分を切り取ること
- ポイント：写真の構図を整えるときに使う。切り取った分、画素数は減る
- 語の意味：Trim＝切りそろえる

### 画質を整える処理

#### アンチエイリアシング（Anti-aliasing）

- 意味：斜めの線や文字の輪郭に出るギザギザ（ジャギー）を、境目に中間の色の画素を置いて目立たなくする処理
- ポイント：画素という四角い点の並びで斜めの線を描くと階段状になる。それをなめらかに見せる。ディザリングと混同しない
- 語の意味：Anti＝防ぐ／Aliasing＝標本化による折り返しのゆがみ

#### ディザリング（Dithering）

- 意味：使える色の数が少ないとき、色の違う点を細かく混ぜて並べることで、見かけ上の中間の色を表す処理
- ポイント：白と黒の点の密度で灰色に見せる新聞の写真などが例。GIFのように色数が限られた形式で写真を表すときにも使う
- 語の意味：Dither＝ためらう・ちらつかせる

#### ルックアップテーブル（Lookup Table）

- 意味：入力の値に対応する出力の値を、計算せずに表から引いて求めるための対応表
- ポイント：画像処理では、色番号と実際の色の対応表（カラーパレット）や、明るさの変換表として使う。表を書き換えるだけで、画像全体の色を一度に変えられる
- 語の意味：Look up＝調べる／Table＝表

#### ガンマ補正（がんまほせい / Gamma Correction）

- 意味：ディスプレイなどの入力の信号と実際の明るさの関係（ガンマ特性）のずれを補正し、意図どおりの明るさで表示されるようにすること
- ポイント：機器によって中間の明るさの出方が違うので、そのままだと暗すぎたり明るすぎたりする。中間調の明るさを調整する

### 3次元CGの作り方

#### CG（しーじー / Computer Graphics）

- 意味：コンピュータを使って画像や映像を作ること。作られた画像そのものも指す
- ポイント：3次元CGは、物体の形を作る（モデリング）→光や質感を計算して画像にする（レンダリング）の順で作る
- 語の意味：Computer＝計算機／Graphics＝画像

#### モデリング（Modeling）

- 意味：3次元CGで、物体の形を座標や多角形（ポリゴン）の組合せとしてコンピュータの中に作ること
- ポイント：形を作る段階。色や光の当たり方の計算はこの後のレンダリングで行う

#### レンダリング（Rendering）

- 意味：コンピュータの中に作った3次元の物体や仮想世界の情報を、光の当たり方などを計算して、ディスプレイに表示できる2次元の画像に変換する処理
- ポイント：隠面消去・シェーディング・テクスチャマッピングなどを含む。VRではこれを毎秒何十回も行う
- 例：R5秋 問25（バーチャルリアリティにおけるレンダリング）
- 語の意味：Render＝表現する・描く

#### 隠面消去（いんめんしょうきょ / Hidden Surface Removal）

- 意味：視点から見て、ほかの物体の陰に隠れて見えない面を描かないようにする処理
- ポイント：Zバッファ法・スキャンライン法・Zソート法・レイトレーシングなどの方法がある

#### Zバッファ法（ぜっとばっふぁほう / Z-buffer Method）

- 意味：画素ごとに、それまでに描いた面のうち視点に一番近い面までの距離（奥行きZ）を記録しておき、それより近い面が来たときだけ描き直す隠面消去の方法
- ポイント：奥行きを記録する作業領域（Zバッファ）を使う。仕組みが単純で、GPUで高速に処理できる
- 例：R4春 問25の誤答（エ）

#### スキャンライン法（すきゃんらいんほう / Scan-line Method）

- 意味：画面の走査線（横1行）ごとに、視点と走査線を含む面と物体との交わりを調べ、奥行きを比べて見える部分を決めて描く隠面消去の方法
- ポイント：1行ずつ処理するので、作業に使う記憶領域が少なくて済む
- 例：R4春 問25の誤答（イ）

#### Zソート法（ぜっとそーとほう / Z-sort Method）

- 意味：物体を視点から遠い順に並べ、遠くのものから描いて、近くのものを上から重ね書きする隠面消去の方法。画家のアルゴリズムとも呼ぶ
- ポイント：絵を描くときに背景から描くのと同じ。物体どうしが交差していると正しく描けない
- 例：R4春 問25の誤答（ウ）

### 光と質感の表現

#### レイトレーシング（Ray Tracing）

- 意味：視点からスクリーンの画素ごとに光線（視線）を飛ばし、物体との交点を、反射・屈折・透過の性質も含めて追いかけて、画素の色を決める描画の方法
- ポイント：鏡の写り込みやガラスの屈折をリアルに表せるが、計算量が非常に多い。最も視点に近い交点を選ぶので隠面消去もできる
- 例：R4春 問25（正解）、R3秋・R5春 問25の誤答（エ）
- 語の意味：Ray＝光線／Tracing＝たどる

#### ラジオシティ法（Radiosity）

- 意味：物体の面どうしの間で、光が拡散反射を繰り返す効果（相互反射）を計算して、拡散反射面の明るさを決める方法
- ポイント：壁に当たった光が部屋全体をぼんやり明るくする、柔らかい間接光を表すのが得意。鏡のような反射はレイトレーシングが得意
- 例：R3秋 問25・R5春 問25（正解）
- 語の意味：Radiosity＝放射の度合い

#### テクスチャマッピング（Texture Mapping）

- 意味：形が定義された物体の表面に、別に用意した模様の画像（テクスチャ）を貼り付けて、質感を表す方法
- ポイント：細かい凹凸を形として作らなくても、木目やレンガの見た目を出せる。凹凸の陰影を付ける方法はバンプマッピング
- 例：R3秋・R5春 問25の誤答（ア）
- 語の意味：Texture＝質感・模様／Mapping＝貼り付け

#### メタボール（Metaball）

- 意味：空間に置いた球などの周りの濃度の分布を足し合わせ、濃度が一定になる面を表面とすることで、なめらかにつながる曲面を作る方法
- ポイント：2つの球が近づくと、くっついて1つになるような形を表せる。液体や生き物の体の表現に使う
- 例：R3秋・R5春 問25の誤答（イ）
- 語の意味：Meta＝超えた／Ball＝球

#### シェーディング（Shading）

- 意味：光源の位置と面の向きから、物体の面の明るさ（陰影）を計算して付けること
- ポイント：立体感を出す処理。面ごとに1色のフラットシェーディング、頂点の明るさを補間するグローシェーディング、法線を補間するフォンシェーディングがある
- 語の意味：Shade＝陰

#### フラットシェーディング（Flat Shading）

- 意味：多角形（ポリゴン）の面ごとに1つの明るさで塗る、最も単純なシェーディング
- ポイント：計算は速いが、面と面の境目がはっきり見えて、角張った見た目になる
- 語の意味：Flat＝平らな

#### グローシェーディング（Gouraud Shading）

- 意味：多角形の各頂点で明るさを計算し、面の内側の明るさはその値を補間して求めるシェーディング
- ポイント：面の境目がなめらかに見える。ただし面の中ほどに出るはずの鋭いハイライトはうまく表せない。考案者グローの名前から

#### フォンシェーディング（Phong Shading）

- 意味：多角形の各頂点の法線（面の向き）を補間して画素ごとの法線を求め、画素ごとに明るさを計算するシェーディング
- ポイント：グローシェーディングより計算は多いが、光沢のある面のハイライトをきれいに表せる。考案者フォンの名前から

### XRと3次元映像

#### VR（ぶいあーる / Virtual Reality）

- 意味：コンピュータが作った仮想の世界を、ゴーグルなどで視界全体に表示し、その中にいるように感じさせる技術。仮想現実
- ポイント：頭の動きに合わせて映像をすぐ描き直す（レンダリング）必要がある。現実の景色は見えない
- 例：R5秋 問25
- 語の意味：Virtual＝仮想の／Reality＝現実

#### AR（えーあーる / Augmented Reality）

- 意味：カメラで写した現実の世界の映像などに、コンピュータが作った情報や画像を重ねて表示する技術。拡張現実
- ポイント：現実が主で、そこに情報を足す。スマートフォンで道案内の矢印を景色に重ねる、家具を部屋に置いてみる、など
- 語の意味：Augmented＝拡張された／Reality＝現実

#### MR（えむあーる / Mixed Reality）

- 意味：現実の世界と仮想の世界を、位置や奥行きを合わせて融合させ、仮想の物体に現実の物のように触れたり回り込んだりできる技術。複合現実
- ポイント：ARより強く現実と仮想が結び付く。現実の空間を認識して、仮想の物体を机の上に置いたままにできる。そのために両方の世界の3次元座標を一致させる処理（位置合わせ）が要る
- 語の意味：Mixed＝混ざった／Reality＝現実

#### XR（えっくすあーる / Cross Reality）

- 意味：VR・AR・MRなど、現実と仮想を組み合わせる技術をまとめた呼び方。クロスリアリティ
- ポイント：XのところにV・A・Mなどが入る、という意味でも使われる
- 語の意味：Cross＝交差する（又は X＝何でも入る）／Reality＝現実

#### メタバース（Metaverse）

- 意味：インターネット上に作られた3次元の仮想空間で、利用者が自分の分身（アバター）を通じて、ほかの人と交流したり、売買したりできる世界
- ポイント：ゲームだけでなく、会議・イベント・買い物にも使われる
- 語の意味：Meta＝超えた／Universe＝世界

#### ホログラム（Hologram）

- 意味：光の干渉を利用して、物体の立体の像を記録し、見る角度によって見え方が変わるように再現したもの
- ポイント：紙幣やクレジットカードの偽造防止のシールにも使われている
- 語の意味：Holo＝全体の／Gram＝記録

#### 3次元映像（さんじげんえいぞう / 3D Video）

- 意味：右目と左目に少しずれた映像を見せることなどで、奥行きのある立体に見えるようにした映像
- ポイント：左右の目の見え方の違い（両眼視差）を利用する。専用の眼鏡を使う方式と、眼鏡のいらない方式がある

### マルチメディアの応用システム

#### CAD（きゃど / Computer Aided Design）

- 意味：コンピュータを使って、機械・建築・電子回路などの設計図を作成する仕組み
- ポイント：図形をベクター形式で扱うので、寸法を正確に保ったまま拡大・修正できる。3次元のモデルを作り、強度などのシミュレーションにもつなげられる
- 語の意味：Computer＝計算機／Aided＝支援された／Design＝設計

#### シミュレーター（Simulator）

- 意味：現実の装置や環境の動きをコンピュータで再現し、操作の訓練や実験をする装置やソフトウェア
- ポイント：飛行機の操縦訓練や運転の練習など。物理法則に当てはめて物の動きを計算する（物理シミュレーション）
- 語の意味：Simulate＝まねる

#### モーションキャプチャ（Motion Capture）

- 意味：人や物の体に付けたマーカーやセンサーの動きを読み取り、その動きをデジタルデータとして記録する技術
- ポイント：記録した動きをCGのキャラクターに当てはめると、自然な動きのアニメーションが作れる。スポーツの動作分析にも使う
- 語の意味：Motion＝動き／Capture＝取り込む

#### バーチャルサラウンド（Virtual Surround）

- 意味：2つのスピーカーやヘッドホンだけで、前後左右から音が聞こえるように感じさせる音響の技術
- ポイント：本物のサラウンドはスピーカーを周りに何台も置くが、音の届き方の違いを計算で作って、少ないスピーカーで再現する
- 語の意味：Virtual＝仮想の／Surround＝囲む

#### DSP（でぃーえすぴー / Digital Signal Processor）

- 意味：音声や画像などのデジタル信号の処理（フィルタ・圧縮など）に特化したプロセッサ
- ポイント：積和演算（掛けて足す計算）を高速に繰り返せる。マルチメディア機器や通信機器の中で、音の加工や映像の圧縮をその場で行う
- 語の意味：Digital＝デジタル／Signal＝信号／Processor＝処理装置

#### デジタル放送（でじたるほうそう / Digital Broadcasting）

- 意味：映像や音声をデジタルデータに圧縮して送るテレビやラジオの放送
- ポイント：アナログ放送より多くのチャネルを送れ、データ放送や電子番組表（EPG）も使える。ワンセグ（携帯機器向けの放送）の映像はH.264で圧縮している

#### マルチメディアデータ合成処理（まるちめでぃあでーたごうせいしょり / Multimedia Data Composition）

- 意味：別々に作った映像・音声・CG・文字などのデータを重ね合わせ、1つの映像や作品に合成する処理
- ポイント：実写の映像にCGのキャラクターを合成する、ニュースの映像にテロップを入れる、など

### 8-1 マルチメディア技術

#### 問 ap-8-r07a-q25

- 問：0kHz〜20kHzの帯域幅のオーディオ信号をデジタル信号に変換するのに必要な最大のサンプリング周期を標本化定理によって求めると，何マイクロ秒か。
- ア：2.5
- イ：5
- ウ：25
- エ：50
- 正解：ウ
- 解説：標本化定理では、信号に含まれる最も高い周波数（20kHz）の2倍以上、つまり40kHz以上で標本化すればよい。周期は周波数の逆数なので、1÷40,000秒＝0.000025秒＝25マイクロ秒。これより長い間隔で標本化すると元の音を復元できないので、25マイクロ秒が「最大の周期」。
- アの意味：20kHzの20倍（400kHz）で標本化したときの周期。必要以上に細かい。
- イの意味：20kHzの10倍（200kHz）で標本化したときの周期。必要以上に細かい。
- ウの意味：正しい。2倍の40kHzの周期。
- エの意味：20kHzそのもので標本化したときの周期。2倍にするのを忘れている。これでは元の信号を復元できない。
- 出典：IPA 令和7年度秋期 応用情報技術者試験 午前 問25

#### 問 ap-8-r06a-q26

- 問：800×600ピクセル，24ビットカラーで30フレーム／秒の動画像の配信に最小限必要な帯域幅はおよそ幾らか。ここで，通信時にデータ圧縮は行わないものとする。
- ア：350kビット／秒
- イ：3.5Mビット／秒
- ウ：35Mビット／秒
- エ：350Mビット／秒
- 正解：エ
- 解説：1フレームは 800×600×24ビット＝11,520,000ビット。1秒に30フレームなので、11,520,000×30＝345,600,000ビット／秒 ≒ 350Mビット／秒。
- アの意味：正しい値の1,000分の1。kとMの桁を取り違えている。
- イの意味：正しい値の100分の1。
- ウの意味：正しい値の10分の1。24ビットを3バイトとして、ビットとバイトを混同すると近い値になる。
- エの意味：正しい。画素数×ビット数×フレーム数。
- 出典：IPA 令和6年度秋期 応用情報技術者試験 午前 問26

#### 問 ap-8-r03h-q27

- 問：W3Cで仕様が定義され，矩形や円，直線，文字列などの図形オブジェクトをXML形式で記述し，Webページでの図形描画にも使うことができる画像フォーマットはどれか。
- ア：OpenGL
- イ：PNG
- ウ：SVG
- エ：TIFF
- 正解：ウ
- 解説：図形をXMLで記述するベクター形式の画像がSVG（Scalable Vector Graphics）。拡大しても劣化せず、Webブラウザでそのまま表示できる。
- アの意味：2次元・3次元のグラフィックスを描くためのプログラムのインタフェース（API）。画像のファイル形式ではない。
- イの意味：画素の並びで表すラスター形式の画像で、可逆圧縮。XMLで図形を記述するものではない。
- ウの意味：正しい。W3Cが定めたXMLのベクター画像形式。
- エの意味：タグで形式を記述するラスター形式の画像。印刷やスキャナーで使う。
- 出典：IPA 令和3年度春期 応用情報技術者試験 午前 問27／令和7年度春期 午前 問23（同じ問題）

#### 問 ap-8-r04a-q25

- 問：H.264/MPEG-4 AVCの説明として，適切なものはどれか。
- ア：インターネットで動画や音声データのストリーミング配信を制御するための通信方式
- イ：テレビ会議やテレビ電話で双方向のビデオ配信を制御するための通信方式
- ウ：テレビの電子番組案内で使用される番組内容のメタデータを記述する方式
- エ：ワンセグやインターネットで用いられる動画データの圧縮符号化方式
- 正解：エ
- 解説：H.264は動画の圧縮符号化方式（コーデック）。MPEG-2の約2倍の効率で、ワンセグ放送・ブルーレイ・動画配信で使われる。通信を制御する方式や、番組の情報を記述する方式ではない。
- アの意味：RTSP（Real Time Streaming Protocol）などの、ストリーミングを制御する通信方式（プロトコル）の説明。
- イの意味：H.323やSIPなどの、テレビ会議の呼び出しや接続を制御する方式の説明。
- ウの意味：電子番組表（EPG）などで番組の内容を記述するメタデータの方式の説明。
- エの意味：正しい。動画データの圧縮符号化方式。
- 出典：IPA 令和4年度秋期 応用情報技術者試験 午前 問25

#### 問 ap-8-o01

- 問：標本化周波数44.1kHz，量子化ビット数16ビット，ステレオ（2チャネル）の音声を，圧縮せずに1分間記録したときのデータ量はおよそ何Mバイトか。ここで，1Mバイト＝10⁶バイトとする。
- ア：1.4
- イ：5.3
- ウ：10.6
- エ：84.7
- 正解：ウ
- 解説：1秒あたり 44,100×16ビット×2＝1,411,200ビット＝176,400バイト。1分（60秒）では 176,400×60＝10,584,000バイト ≒ 10.6Mバイト。
- アの意味：1秒あたりのビット数（1,411,200ビット）をMの単位で読んだ値。秒数を掛けず、ビットとバイトも取り違えている。
- イの意味：モノラル（1チャネル）で計算した値。ステレオの2を掛け忘れている。
- ウの意味：正しい。周波数×ビット数×チャネル数×秒数を8で割ってバイトにした値。
- エの意味：ビットのままでバイトに直していない値（84,672,000ビット）。
- 出典：オリジナル問題（音声のデータ量）

#### 問 ap-8-o02

- 問：MIDIの説明として，適切なものはどれか。
- ア：電子楽器の演奏情報（音の高さ，長さ，強さなど）を送るための規格であり，実際の音は受け取った側の音源が合成する。
- イ：音の波形をPCMで標本化・量子化し，そのまま記録する音声ファイルの形式である。
- ウ：人の耳に聞こえにくい音の成分を削ることによって，音声データを非可逆圧縮する形式である。

- イの意味：少ないスピーカーで、周りから音が聞こえるように感じさせる音響の技術。
- ウの意味：光の干渉を使って、立体の像を記録・再現したもの。
- エの意味：正しい。人の動きを読み取ってデータにする。
- 出典：オリジナル問題（マルチメディアの応用システム）

#### 問 ap-8-o16

- 問：解像度600dpiのプリンターで，横4インチ×縦6インチの写真を，プリンターの解像度を落とさずに印刷したい。必要な画像の画素数は，横何画素×縦何画素か。ここで，1画素をプリンターの1ドットで印刷するものとする。
- ア：150×100
- イ：2,400×3,600
- ウ：4,000×6,000
- エ：24,000×36,000
- 正解：イ
- 解説：600dpiは1インチに600ドット。横は 600×4＝2,400、縦は 600×6＝3,600 なので、2,400×3,600画素が必要。
- アの意味：600をインチ数で割った値。掛けるべきところを割っている。
- イの意味：正しい。dpi×インチ数。
- ウの意味：1インチを1,000ドットとした値。600dpiを使っていない。
- エの意味：正しい値の10倍。桁を取り違えている。
- 出典：オリジナル問題（解像度）
