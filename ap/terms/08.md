## 8-1 マルチメディア技術

### まとめ表

**主な形式**

| 形式 | 種類 | 圧縮 |
| :-: | :-: | :-: |
| PNG・GIF | 静止画 | 可逆 |
| JPEG | 静止画 | 非可逆 |
| MPEG-2・H.264・H.265 | 動画 | 非可逆 |
| MP3・AAC | 音声 | 非可逆 |


### データ量と形式

#### 画像のデータ量（Image Data Size）

- 意味：横の画素数×縦の画素数×1画素のビット数
- 例：1,920×1,080画素・24ビットで約6Mバイト

#### 音声のデータ量（Audio Data Size）

- 意味：標本化周波数×量子化ビット数×チャンネル数×秒数

#### 可逆圧縮・非可逆圧縮（Lossless / Lossy Compression）

- 意味：可逆は元に完全に戻せる圧縮、非可逆は戻らないが大きく小さくできる圧縮

#### JPEG（じぇいぺぐ / Joint Photographic Experts Group）

- 意味：写真向けの非可逆圧縮の静止画形式
- 語の意味：Joint＝合同の／Photographic＝写真の／Experts Group＝専門家の会

#### MPEG（えむぺぐ / Moving Picture Experts Group）

- 意味：動画と音声を圧縮する国際規格
- ポイント：フレーム間の差分だけを記録して小さくする
- 語の意味：Moving Picture＝動画／Experts Group＝専門家の会

#### H.264・H.265（HEVC）

- 意味：動画の圧縮規格。H.265はH.264の約2倍の圧縮効率で、4K・8K放送に使う

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：アナログ音声を標本化・量子化・符号化してディジタルにする方式
- 語の意味：Pulse＝パルス／Code＝符号／Modulation＝変調

#### フレームレート（Frame Rate）

- 意味：動画で1秒間に表示するコマ（フレーム）の数
- ポイント：単位はfps

#### ビットレート（Bit Rate）

- 意味：1秒あたりのデータ量
- 例：映像の配信は数Mbps

#### 色の表現（Color Model）

- 意味：光の三原色RGB（加法混色・画面）と、色の三原色CMY（減法混色・印刷）。印刷ではK（黒）を加えたCMYKを使う

#### ベクタ形式・ラスタ形式（Vector / Raster）

- 意味：ベクタは図形を数式で表し拡大しても粗くならない。ラスタは画素の並びで表す


### 静止画（発展）

#### BMP（びっとまっぷ / Bitmap）

- 意味：画素の情報を圧縮せずに記録する静止画の形式

#### GIF（じふ / Graphics Interchange Format）

- 意味：256色までの可逆圧縮の形式
- ポイント：簡単なアニメーションや透過ができる
- 語の意味：Graphics＝画像／Interchange＝交換用の／Format＝形式

#### PNG（ぴんぐ / Portable Network Graphics）

- 意味：フルカラーを扱える可逆圧縮の形式
- ポイント：透過ができる
- 語の意味：Portable＝持ち運べる／Network＝ネットワーク／Graphics＝画像

#### TIFF（てぃふ / Tagged Image File Format）

- 意味：タグで色々な情報を持てる画像の形式
- ポイント：印刷やスキャナで使う

#### WebP（うぇっぴー）

- 意味：Web向けに作られた、小さくできる画像の形式
- ポイント：可逆・非可逆の両方に対応

#### RAW形式（RAW Format）

- 意味：カメラのセンサの情報をほぼそのまま記録した形式
- ポイント：後で細かく調整できる

#### 画素数・解像度（Pixels / Resolution）

- 意味：画像を作る点の数と、点の細かさ
- ポイント：dpiは1インチあたりの点の数

#### 色深度（Color Depth）

- 意味：1画素で表せる色の数を決めるビット数
- ポイント：24ビットなら約1,677万色

#### 階調（Gradation）

- 意味：明るさや色の段階の数

#### アルファチャンネル（Alpha Channel）

- 意味：画素ごとの透明度の情報

#### HDR（えいちでぃーあーる / High Dynamic Range）

- 意味：明るい所から暗い所まで、広い範囲を表現できる技術
- 語の意味：High＝広い／Dynamic Range＝明暗の幅

#### 色空間（Color Space）

- 意味：色を数値で表すための範囲と方式
- ポイント：sRGBなど

#### YUV（YCbCr）

- 意味：明るさ（Y）と色の差（U・V）で色を表す方式
- ポイント：人の目は明るさに敏感なので、色の情報を減らして圧縮できる

#### DCT（でぃーしーてぃー / Discrete Cosine Transform）

- 意味：画像を周波数の成分に分ける計算
- ポイント：JPEGで細かい成分を削って圧縮する
- 語の意味：Discrete＝離散的な／Cosine＝余弦／Transform＝変換

#### エイリアシング・アンチエイリアシング（Aliasing / Anti-aliasing）

- 意味：斜めの線がギザギザに見えることと、それをなめらかに見せる処理

#### ディザリング（Dithering）

- 意味：少ない色の点を並べて、中間の色があるように見せる技術


### 動画（発展）

#### フレーム（Frame）

- 意味：動画を作る1枚1枚の静止画

#### フレーム間予測（Inter-frame Prediction）

- 意味：前後のフレームとの違いだけを記録して、動画を小さくする方法
- ポイント：Iフレーム・Pフレーム・Bフレーム

#### MPEG-1・MPEG-2・MPEG-4（MPEG Standards）

- 意味：MPEG-1はVideo CD、MPEG-2はDVD・ディジタル放送、MPEG-4はネット配信や携帯向け

#### コーデック（Codec）

- 意味：映像や音声を圧縮（符号化）・伸張（復号）する方式やソフト
- 語の意味：Coder＝符号化器／Decoder＝復号器

#### コンテナフォーマット（Container Format）

- 意味：映像・音声・字幕などをまとめて1つのファイルにする形式
- 例：MP4

#### 4K・8K（4K / 8K）

- 意味：横の画素数が約4,000、約8,000の高精細な映像

#### インタレース・プログレッシブ（Interlace / Progressive）

- 意味：1行おきに2回に分けて表示する方式と、1回で全部の行を表示する方式

#### 可変ビットレート（VBR / Variable Bit Rate）

- 意味：場面の複雑さに合わせて、1秒あたりのデータ量を変える方式

#### アダプティブストリーミング（Adaptive Streaming）

- 意味：通信の速さに合わせて、配信する映像の画質を自動で切り替える方式


### 音声（発展）

#### 標本化周波数（Sampling Frequency）

- 意味：1秒間に何回音の大きさを測るか
- ポイント：CDは44.1kHz

#### 量子化ビット数（Quantization Bits）

- 意味：測った値を何段階で表すか
- ポイント：CDは16ビット（65,536段階）

#### AAC（えーえーしー / Advanced Audio Coding）

- 意味：MP3より効率のよい音声の圧縮形式
- 語の意味：Advanced＝進んだ／Audio＝音声／Coding＝符号化

#### FLAC（ふらっく / Free Lossless Audio Codec）

- 意味：可逆圧縮の音声形式
- ポイント：音質を落とさずに小さくできる

#### サラウンド（Surround Sound）

- 意味：複数のスピーカーで、周りから音が聞こえるようにする方式
- ポイント：5.1chなど

#### 音声合成（Speech Synthesis）

- 意味：文字から人の声を作る技術

#### ノイズキャンセリング（Noise Canceling）

- 意味：周りの雑音と逆の波の音を出して、雑音を打ち消す技術

#### 音のマスキング効果（Auditory Masking）

- 意味：大きな音があると、近くの小さな音が聞こえなくなる性質
- ポイント：MP3などで聞こえない音を省くのに使う


### 情報の保護（発展）

#### DRM（でぃーあーるえむ / Digital Rights Management）

- 意味：音楽や映像の不正なコピーを防ぐ技術
- 語の意味：Digital＝ディジタル／Rights＝権利／Management＝管理

#### 電子透かし（Digital Watermark）

- 意味：画像や音声に、見えない（聞こえない）情報を埋め込む技術
- ポイント：著作権者の表示や不正コピーの追跡に使う

#### CPRM（しーぴーあーるえむ / Content Protection for Recordable Media）

- 意味：放送を録画したDVDなどのコピーを制限するしくみ

#### HDCP（えいちでぃーしーぴー / High-bandwidth Digital Content Protection）

- 意味：HDMIなどで送る映像を暗号化して、不正な録画を防ぐしくみ


### 文字とデータ

#### 文字コードとフォント（Character Code and Font）

- 意味：文字の番号と、その形のデータ

#### アウトラインフォント・ビットマップフォント（Outline / Bitmap Font）

- 意味：輪郭を数式で表すので拡大しても粗くならないフォントと、点の集まりで表すフォント

#### プロポーショナルフォント（Proportional Font）

- 意味：文字ごとに幅が違うフォント
- ポイント：等幅フォントはすべて同じ幅

#### 圧縮率（Compression Ratio）

- 意味：圧縮した後のデータ量と元のデータ量の比

#### ZIP（じっぷ）

- 意味：ファイルをまとめて可逆圧縮する形式

#### メタデータ（Metadata）

- 意味：データについての情報
- 例：写真の撮影日時や場所（Exif）

#### Exif（いぐじふ / Exchangeable image file format）

- 意味：写真に撮影の条件や位置などを記録する規格
- ポイント：位置情報の公開に注意

#### PDF（ぴーでぃーえふ / Portable Document Format）

- 意味：どの環境でも同じ見た目で表示できる文書の形式
- 語の意味：Portable＝持ち運べる／Document＝文書／Format＝形式

#### 電子書籍の形式（EPUB）

- 意味：画面の大きさに合わせて文字を流し込める電子書籍の形式


## 8-2 マルチメディア応用


### 表現の技術

#### CG（しーじー / Computer Graphics）

- 意味：コンピュータで作る画像や映像
- 語の意味：Computer＝コンピュータ／Graphics＝画像

#### レンダリング（Rendering）

- 意味：3Dのデータから、光や影を計算して画像を作る処理

#### レイトレーシング（Ray Tracing）

- 意味：光の道筋を追いかけて、反射や屈折をリアルに描く方法

#### モーフィング（Morphing）

- 意味：ある画像から別の画像へ、なめらかに変形させる技術

#### モーションキャプチャ（Motion Capture）

- 意味：人の動きをセンサやカメラで読み取り、データにする技術

#### AR・VR・MR（Augmented / Virtual / Mixed Reality）

- 意味：ARは現実に情報を重ねる拡張現実、VRは仮想空間に入り込む仮想現実、MRは現実と仮想を融合させる複合現実
- 語の意味：Augmented＝拡張された／Virtual＝仮想の／Mixed＝混ぜた／Reality＝現実

#### メタバース（Metaverse）

- 意味：多くの人が参加できるネット上の3次元の仮想空間

#### ストリーミング（Streaming）

- 意味：受け取りながら同時に再生する配信方式


### CGと立体（発展）

#### 3次元CG（3D CG）

- 意味：立体のデータから画像を作るCG

#### モデリング（Modeling）

- 意味：物の形を3次元のデータで作ること
- ポイント：ワイヤーフレーム・サーフェス・ソリッドモデル

#### ワイヤーフレームモデル（Wireframe Model）

- 意味：線だけで形を表すモデル

#### サーフェスモデル（Surface Model）

- 意味：面で形を表すモデル

#### ソリッドモデル（Solid Model）

- 意味：中身の詰まった立体として形を表すモデル
- ポイント：体積や重さを計算できる

#### ポリゴン（Polygon）

- 意味：立体の表面を作る小さな多角形（三角形など）

#### テクスチャマッピング（Texture Mapping）

- 意味：立体の表面に画像を貼り付けて、質感を出す技術

#### シェーディング（Shading）

- 意味：光の当たり方に合わせて、面に陰影を付ける処理

#### 隠面消去（Hidden Surface Removal）

- 意味：手前の物に隠れて見えない面を描かないようにする処理
- ポイント：Zバッファ法など

#### ラジオシティ法（Radiosity）

- 意味：物どうしで光が反射し合う様子を計算して、やわらかな明るさを表す方法

#### メタボール（Metaball）

- 意味：球などを溶け合わせるようにつないで、なめらかな形を作る方法

#### フォトリアリスティック（Photorealistic）

- 意味：写真のように本物そっくりに描くこと

#### 3Dスキャナ（3D Scanner）

- 意味：物の形を読み取って3次元のデータにする装置

#### フォトグラメトリ（Photogrammetry）

- 意味：たくさんの写真から3次元のモデルを作る技術

#### ボリュームレンダリング（Volume Rendering）

- 意味：CTなどの立体のデータの中身を、透かして見せる表示方法


### 応用（発展）

#### バーチャルリアリティの要素（Elements of VR）

#### ヘッドマウントディスプレイ（HMD / Head Mounted Display）

#### マルチメディアオーサリング（Multimedia Authoring）

### 体験と応用

#### ハプティクス（Haptics）

#### 立体音響（Spatial Audio）

- 意味：音がいろいろな方向から聞こえるように感じさせる技術

- 意味：画像に何が写っているかをコンピュータが判断する技術

#### 顔認識（Face Recognition）

- 意味：画像の中の顔を見つけ、誰かを判断する技術

#### 生成AIによる画像・動画の生成（AI-generated Media）

- 意味：文章の指示から画像や動画を作ること

#### 遠隔会議の映像技術（Video Conferencing）

- 意味：映像と音声を圧縮して送り、離れた所と会議をする技術

### 8-1 マルチメディア技術

#### 問 ap-8-q01

- 問：1,000×1,000画素、1画素24ビットのフルカラー画像1枚のデータ量はおよそいくらか。
- ア：1Mバイト
- イ：3Mバイト
- ウ：24Mバイト
- エ：3Gバイト
- 正解：イ
- 解説：1,000×1,000×24÷8＝3,000,000バイト＝約3Mバイト。

#### 問 ap-8-q02

- 問：標本化周波数8kHz、量子化ビット数8ビットでモノラル録音したとき、1秒間のデータ量はいくらか。
- ア：8kビット
- イ：16kビット
- ウ：64kビット
- エ：128kビット
- 正解：ウ
- 解説：8,000×8＝64,000ビット＝64kビット。

#### 問 ap-8-q03

- 問：印刷で使われ、混ぜるほど暗くなる色の表現方法はどれか。
- ア：RGB
- イ：CMY
- ウ：YUV
- エ：HSV
- 正解：イ
- 解説：CMYは減法混色で印刷に使う。

#### 問 ap-8-q04

- ア：PNG
- イ：GIF
- ウ：ZIP
- エ：JPEG
- 正解：エ
- 解説：JPEGは非可逆。ほかは可逆。

#### 問 ap-8-q07

- 正解：ア
