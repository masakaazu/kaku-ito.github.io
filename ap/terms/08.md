## 8-1 マルチメディア技術

### まとめ表

**主な形式**

| 形式 | 種類 | 圧縮 |
| :-: | :-: | :-: |
| PNG・GIF | 静止画 | 可逆 |
| JPEG | 静止画 | 非可逆 |
| MPEG-2・H.264・H.265 | 動画 | 非可逆 |
| MP3・AAC | 音声 | 非可逆 |


### データ量と形式

#### 画像のデータ量（Image Data Size）

- 意味：横の画素数×縦の画素数×1画素のビット数
- 例：1,920×1,080画素・24ビットで約6Mバイト

#### 音声のデータ量（Audio Data Size）

- 意味：標本化周波数×量子化ビット数×チャンネル数×秒数

#### 可逆圧縮・非可逆圧縮（Lossless / Lossy Compression）

- 意味：可逆は元に完全に戻せる圧縮、非可逆は戻らないが大きく小さくできる圧縮

#### JPEG（じぇいぺぐ / Joint Photographic Experts Group）

- 意味：写真向けの非可逆圧縮の静止画形式
- 語の意味：Joint＝合同の／Photographic＝写真の／Experts Group＝専門家の会

#### MPEG（えむぺぐ / Moving Picture Experts Group）

- 意味：動画と音声を圧縮する国際規格
- ポイント：フレーム間の差分だけを記録して小さくする
- 語の意味：Moving Picture＝動画／Experts Group＝専門家の会

#### H.264・H.265（HEVC）

- 意味：動画の圧縮規格。H.265はH.264の約2倍の圧縮効率で、4K・8K放送に使う

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：アナログ音声を標本化・量子化・符号化してディジタルにする方式
- 語の意味：Pulse＝パルス／Code＝符号／Modulation＝変調

#### フレームレート（Frame Rate）

- 意味：動画で1秒間に表示するコマ（フレーム）の数
- ポイント：単位はfps

#### ビットレート（Bit Rate）

- 意味：1秒あたりのデータ量
- 例：映像の配信は数Mbps

#### 色の表現（Color Model）

- 意味：光の三原色RGB（加法混色・画面）と、色の三原色CMY（減法混色・印刷）。印刷ではK（黒）を加えたCMYKを使う

#### ベクタ形式・ラスタ形式（Vector / Raster）

- 意味：ベクタは図形を数式で表し拡大しても粗くならない。ラスタは画素の並びで表す


## 8-2 マルチメディア応用


### 表現の技術

#### CG（しーじー / Computer Graphics）

- 意味：コンピュータで作る画像や映像
- 語の意味：Computer＝コンピュータ／Graphics＝画像

#### レンダリング（Rendering）

- 意味：3Dのデータから、光や影を計算して画像を作る処理

#### レイトレーシング（Ray Tracing）

- 意味：光の道筋を追いかけて、反射や屈折をリアルに描く方法

#### モーフィング（Morphing）

- 意味：ある画像から別の画像へ、なめらかに変形させる技術

#### モーションキャプチャ（Motion Capture）

- 意味：人の動きをセンサやカメラで読み取り、データにする技術

#### AR・VR・MR（Augmented / Virtual / Mixed Reality）

- 意味：ARは現実に情報を重ねる拡張現実、VRは仮想空間に入り込む仮想現実、MRは現実と仮想を融合させる複合現実
- 語の意味：Augmented＝拡張された／Virtual＝仮想の／Mixed＝混ぜた／Reality＝現実

#### メタバース（Metaverse）

- 意味：多くの人が参加できるネット上の3次元の仮想空間

#### ストリーミング（Streaming）

- 意味：受け取りながら同時に再生する配信方式

### 8-1 マルチメディア技術

#### 問 ap-8-q01

- 問：1,000×1,000画素、1画素24ビットのフルカラー画像1枚のデータ量はおよそいくらか。
- ア：1Mバイト
- イ：3Mバイト
- ウ：24Mバイト
- エ：3Gバイト
- 正解：イ
- 解説：1,000×1,000×24÷8＝3,000,000バイト＝約3Mバイト。

#### 問 ap-8-q02

- 問：標本化周波数8kHz、量子化ビット数8ビットでモノラル録音したとき、1秒間のデータ量はいくらか。
- ア：8kビット
- イ：16kビット
- ウ：64kビット
- エ：128kビット
- 正解：ウ
- 解説：8,000×8＝64,000ビット＝64kビット。

#### 問 ap-8-q03

- 問：印刷で使われ、混ぜるほど暗くなる色の表現方法はどれか。
- ア：RGB
- イ：CMY
- ウ：YUV
- エ：HSV
- 正解：イ
- 解説：CMYは減法混色で印刷に使う。

#### 問 ap-8-q04

- 問：元のデータに完全には戻らない非可逆圧縮の形式はどれか。
- ア：PNG
- イ：GIF
- ウ：ZIP
- エ：JPEG
- 正解：エ
- 解説：JPEGは非可逆。ほかは可逆。

### 8-2 マルチメディア応用

#### 問 ap-8-q05

- 問：光源からの光の反射や屈折を追跡して、写実的な画像を作る手法はどれか。
- ア：モーフィング
- イ：レイトレーシング
- ウ：テクスチャマッピング
- エ：アンチエイリアシング
- 正解：イ
- 解説：光の道筋を追うのがレイトレーシング。

#### 問 ap-8-q06

- 問：現実の風景にコンピュータが作った情報を重ねて表示する技術はどれか。
- ア：AR
- イ：VR
- ウ：CG
- エ：CAD
- 正解：ア
- 解説：ARは拡張現実。
