### ネットワークの形

#### LAN・WAN（Local / Wide Area Network）

- 意味：LANは建物の中などの狭い範囲、WANは離れた場所をつなぐ広い範囲のネットワーク
- 語の意味：Local＝構内の／Wide＝広い／Area＝範囲／Network＝網

#### 無線LAN（Wireless LAN）

- 意味：電波でつなぐLAN
- ポイント：IEEE 802.11。暗号化はWPA3。衝突を避けるCSMA/CA方式

#### 5G（第5世代移動通信システム）

- 意味：高速大容量・超低遅延・多数同時接続が特徴の移動通信
- ポイント：ローカル5Gは企業が自分の敷地で使う

#### LPWA（えるぴーだぶりゅーえー / Low Power Wide Area）

- 意味：少ない電力で広い範囲を通信できる方式。速度は遅い
- ポイント：IoTのセンサに向く
- 語の意味：Low Power＝低消費電力／Wide Area＝広い範囲

#### SDN（えすでぃーえぬ / Software-Defined Networking）

- 意味：ネットワークの制御をソフトウェアで集中して行う考え方
- ポイント：制御（コントロールプレーン）と転送（データプレーン）を分ける。OpenFlowが代表
- 語の意味：Software＝ソフトウェア／Defined＝定義された／Networking＝ネットワーク


## 10-2 データ通信と制御


### 通信の制御

#### 伝送時間（Transmission Time）

- 意味：データ量 ÷（回線速度 × 伝送効率）

#### CSMA/CD（Carrier Sense Multiple Access with Collision Detection）

- 意味：送信前に回線を確かめ、衝突したら待って送り直す有線LANの方式

#### CSMA/CA（Carrier Sense Multiple Access with Collision Avoidance）

- 意味：衝突を避けるために、待ち時間をおいて送る無線LANの方式

#### MACアドレス（Media Access Control Address）

- 意味：ネットワーク機器に付けられた48ビットの固有の番号
- ポイント：先頭24ビットはメーカーの番号（OUI）

#### VLAN（ぶいらん / Virtual LAN）

- 意味：物理的なつながりとは別に、論理的にLANを分ける技術
- 語の意味：Virtual＝仮想の／LAN＝構内網

#### スパニングツリープロトコル（STP / Spanning Tree Protocol）

- 意味：スイッチのループ（輪）を見つけて、一部のポートを止めてループを防ぐ方式

### TCP/IP

#### TCP/IP（Transmission Control Protocol / Internet Protocol）

- 意味：インターネットで使う4階層のプロトコル群
- ポイント：アプリケーション層・トランスポート層・インターネット層・ネットワークインタフェース層

#### TCP・UDP（Transmission Control Protocol / User Datagram Protocol）

- 意味：TCPはコネクションを作り、届いたかを確かめる信頼性の高い通信。UDPは確認をせず速い通信で、動画・音声やDNSに使う

#### 3ウェイハンドシェイク（3-way Handshake）

- 意味：TCPで接続を始めるときの3回のやり取り（SYN → SYN/ACK → ACK）

#### IPv4アドレスとサブネットマスク（Subnet Mask）

- 意味：IPアドレスのうちネットワーク部とホスト部の境目を示す値
- ポイント：/24なら使えるホストは 2^8 − 2 ＝ 254台

#### CIDR（さいだー / Classless Inter-Domain Routing）

- 意味：クラスにとらわれず、ネットワーク部の長さを自由に決める方式
- 例：192.168.1.0/24
- 語の意味：Classless＝クラスのない／Inter-Domain＝ドメイン間の／Routing＝経路制御

#### IPv6（Internet Protocol version 6）

- 意味：128ビットのアドレスを使うIP
- ポイント：アドレスが足りない問題を解決する。16ビットずつ16進数で8つに区切って書く

#### NAT・NAPT（Network Address Translation / Network Address Port Translation）

- 意味：プライベートIPアドレスとグローバルIPアドレスを変換するしくみ
- ポイント：NAPTはポート番号も変換し、1つのグローバルアドレスを複数の端末で使える

#### ARP（あーぷ / Address Resolution Protocol）

- 意味：IPアドレスからMACアドレスを調べるプロトコル
- 語の意味：Address＝アドレス／Resolution＝解決／Protocol＝通信規約

#### ICMP（あいしーえむぴー / Internet Control Message Protocol）

- 意味：通信の誤りや状態を知らせるプロトコル
- ポイント：ping や traceroute が使う
- 語の意味：Internet＝インターネット／Control＝制御／Message＝通知

#### DHCP（でぃーえいちしーぴー / Dynamic Host Configuration Protocol）

- 意味：端末にIPアドレスなどの設定を自動で配るプロトコル
- 語の意味：Dynamic＝動的な／Host＝端末／Configuration＝設定

#### DNS（でぃーえぬえす / Domain Name System）

- 意味：ドメイン名とIPアドレスを対応付けるしくみ
- 語の意味：Domain Name＝ドメイン名／System＝仕組み

#### HTTP・HTTPS（HyperText Transfer Protocol / Secure）

- 意味：Webのやり取りのプロトコル。HTTPSはHTTPをTLSで暗号化したもの
- ポイント：要求（リクエスト）と応答（レスポンス）を繰り返す。状態を持たないのでCookieで状態を管理する

#### SMTP・POP3・IMAP4

- 意味：SMTPはメールの送信と転送、POP3はメールを端末に取り込む受信、IMAP4はメールをサーバに置いたまま見る受信

#### カプセル化（Encapsulation）

- 意味：送信するとき、上の層のデータに下の層のヘッダを順に付けていくこと
- ポイント：受け取る側は逆に外していく


## 10-4 ネットワーク管理


### 管理の道具

#### SNMP（えすえぬえむぴー / Simple Network Management Protocol）

- 意味：ネットワーク機器の状態を集めて管理するプロトコル
- ポイント：マネージャがエージェントに問い合わせる。異常はトラップで知らせる
- 語の意味：Simple＝簡単な／Network Management＝ネットワーク管理／Protocol＝規約

#### ping・traceroute

- 意味：ping はICMPで相手に届くかを確かめるコマンド、traceroute は経路上のルータを調べるコマンド

#### NTP（えぬてぃーぴー / Network Time Protocol）

- 意味：機器の時刻を合わせるプロトコル
- ポイント：ログの時刻をそろえるのに大事
- 語の意味：Network＝ネットワーク／Time＝時刻／Protocol＝規約

#### 障害の切り分け（Troubleshooting）

- 意味：層ごとに確かめて原因の場所を絞ること
- ポイント：ping（3層）が通るのにWebだけ見られないなら、4層以上（ポートやファイアウォール）を疑う


## 10-5 ネットワーク応用


### 応用

#### VPN（ぶいぴーえぬ / Virtual Private Network）

- 意味：公衆の回線の上に、暗号化した専用線のような通信路を作る技術
- ポイント：IPsec VPN・SSL/TLS VPNがある
- 語の意味：Virtual＝仮想の／Private＝専用の／Network＝網

#### CDN（しーでぃーえぬ / Content Delivery Network）

- 意味：利用者の近くのサーバ（キャッシュ）からコンテンツを配信して、速くするしくみ
- 語の意味：Content＝内容／Delivery＝配送／Network＝網

#### プロキシサーバ（Proxy Server）

- 意味：内部の端末の代わりに外部のWebサーバへアクセスするサーバ
- ポイント：キャッシュやアクセス制限に使う

#### IoTネットワーク（IoT Network）

- 意味：多くの機器をつなぐネットワーク
- ポイント：MQTTなど軽いプロトコルを使う
