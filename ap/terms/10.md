## 10-1 ネットワーク方式

### まとめ表

| :-: | :-: | :-: |

### ネットワークの形

#### LAN・WAN（Local / Wide Area Network）

- 意味：LANは建物の中などの狭い範囲、WANは離れた場所をつなぐ広い範囲のネットワーク
- 語の意味：Local＝構内の／Wide＝広い／Area＝範囲／Network＝網

#### 無線LAN（Wireless LAN）

- 意味：電波でつなぐLAN
- ポイント：IEEE 802.11。暗号化はWPA3。衝突を避けるCSMA/CA方式

#### 5G（第5世代移動通信システム）

- 意味：高速大容量・超低遅延・多数同時接続が特徴の移動通信
- ポイント：ローカル5Gは企業が自分の敷地で使う

#### LPWA（えるぴーだぶりゅーえー / Low Power Wide Area）

- 意味：少ない電力で広い範囲を通信できる方式。速度は遅い
- ポイント：IoTのセンサに向く
- 語の意味：Low Power＝低消費電力／Wide Area＝広い範囲

#### SDN（えすでぃーえぬ / Software-Defined Networking）

- 意味：ネットワークの制御をソフトウェアで集中して行う考え方
- ポイント：制御（コントロールプレーン）と転送（データプレーン）を分ける。OpenFlowが代表
- 語の意味：Software＝ソフトウェア／Defined＝定義された／Networking＝ネットワーク


### 機器と形（発展）

#### OSI基本参照モデル（OSI Reference Model）

- 意味：通信の働きを7つの層に分けたモデル
- ポイント：物理・データリンク・ネットワーク・トランスポート・セッション・プレゼンテーション・アプリケーション

#### リピータ（Repeater）

- 意味：物理層で信号を増幅して、遠くまで届ける機器

#### ブリッジ・スイッチングハブ（Bridge / Switching Hub）

- 意味：データリンク層でMACアドレスを見て、必要なポートだけに送る機器
- ポイント：L2スイッチ

#### ルータ（Router）

- 意味：ネットワーク層でIPアドレスを見て、別のネットワークへ中継する機器
- ポイント：経路表を使う

#### L3スイッチ（Layer 3 Switch）

- 意味：ルータの働きを持つスイッチ
- ポイント：LAN内の中継を高速に行う

#### ゲートウェイ（Gateway）

- 意味：層の違うプロトコルどうしを変換して、つなぐ機器やソフトウェア

#### スター型・バス型・リング型（Star / Bus / Ring Topology）

- 意味：中心の機器に集める形、1本の線につなぐ形、輪の形につなぐ形

#### メッシュ型（Mesh Topology）

- 意味：機器どうしを網の目のようにつなぐ形
- ポイント：1か所が壊れても別の道を通れる

#### PoE（ぴーおーいー / Power over Ethernet）

- 意味：LANケーブルで電気も送る仕組み
- ポイント：無線LANのアクセスポイントやカメラに使う

#### アクセスポイント（Access Point）

- 意味：無線LANの端末を有線のネットワークにつなぐ機器

#### SSID（えすえすあいでぃー / Service Set Identifier）

- 意味：無線LANのネットワークを見分ける名前

#### メッシュWi-Fi（Mesh Wi-Fi）

- 意味：複数のアクセスポイントが連携して、広い範囲をカバーする無線LAN

#### FTTH（えふてぃーてぃーえいち / Fiber To The Home）

- 意味：家庭まで光ファイバを引く通信サービス
- 語の意味：Fiber＝光ファイバ／To The Home＝家まで

#### MVNO（えむぶいえぬおー / Mobile Virtual Network Operator）

- 意味：ほかの会社の携帯電話の回線を借りてサービスを出す事業者
- ポイント：格安SIMなど

#### テザリング（Tethering）

- 意味：スマートフォンを中継にして、パソコンなどをインターネットにつなぐこと

#### ローカル5G（Local 5G）

- 意味：企業や自治体が、自分の敷地の中で使う5G

#### NFV（えぬえふぶい / Network Functions Virtualization）

- 意味：ルータやファイアウォールなどの機能を、専用の機器ではなく汎用サーバのソフトウェアで動かすこと


## 10-2 データ通信と制御


### 通信の制御

#### 伝送時間（Transmission Time）

- 意味：データ量 ÷（回線速度 × 伝送効率）

#### CSMA/CD（Carrier Sense Multiple Access with Collision Detection）

- 意味：送信前に回線を確かめ、衝突したら待って送り直す有線LANの方式

#### CSMA/CA（Carrier Sense Multiple Access with Collision Avoidance）

- 意味：衝突を避けるために、待ち時間をおいて送る無線LANの方式

#### MACアドレス（Media Access Control Address）

- 意味：ネットワーク機器に付けられた48ビットの固有の番号
- ポイント：先頭24ビットはメーカーの番号（OUI）

#### VLAN（ぶいらん / Virtual LAN）

- 意味：物理的なつながりとは別に、論理的にLANを分ける技術
- 語の意味：Virtual＝仮想の／LAN＝構内網

#### スパニングツリープロトコル（STP / Spanning Tree Protocol）

- 意味：スイッチのループ（輪）を見つけて、一部のポートを止めてループを防ぐ方式


### 伝送の仕組み（発展）

#### 回線交換・パケット交換（Circuit / Packet Switching）

- 意味：通信の間だけ回線を占有する方式と、データを小さく分けて送る方式
- ポイント：インターネットはパケット交換

#### 伝送効率（Transmission Efficiency）

- 意味：回線の速さのうち、実際にデータを送るのに使える割合

#### ビット誤り率（Bit Error Rate）

- 意味：送ったビットのうち、誤って届いたビットの割合

#### パリティチェック（Parity Check）

- 意味：1の数が偶数か奇数かを決めておき、1ビットの誤りを見つける方法

#### CRC（しーあーるしー / Cyclic Redundancy Check）

- 意味：データを決まった式で割った余りを付けて、誤りを見つける方法
- ポイント：連続した誤り（バースト誤り）も見つけやすい

#### ハミング符号（Hamming Code）

- 意味：誤りを見つけるだけでなく、1ビットの誤りを直せる符号

#### 全二重・半二重通信（Full / Half Duplex）

- 意味：送信と受信を同時にできる通信と、交互にしかできない通信

#### フロー制御（Flow Control）

- 意味：受け手が処理しきれないとき、送り手の送る速さを抑えること
- ポイント：TCPのウィンドウ制御

#### 輻輳制御（ふくそうせいぎょ / Congestion Control）

- 意味：ネットワークが混み合ったとき、送る量を減らして混雑を和らげること

#### QoS（きゅーおーえす / Quality of Service）

- 意味：通信の種類によって優先度を付け、品質を保つこと
- 例：音声通話を優先する
- 語の意味：Quality＝品質／Service＝サービス

#### MTU（えむてぃーゆー / Maximum Transmission Unit）

- 意味：1回で送れるデータの最大の大きさ
- ポイント：イーサネットは1500バイト

#### フレーム・パケット・セグメント（Frame / Packet / Segment）

- 意味：データリンク層・ネットワーク層・トランスポート層で扱うデータのまとまりの呼び名

### TCP/IP

#### TCP/IP（Transmission Control Protocol / Internet Protocol）

- 意味：インターネットで使う4階層のプロトコル群
- ポイント：アプリケーション層・トランスポート層・インターネット層・ネットワークインタフェース層

#### TCP・UDP（Transmission Control Protocol / User Datagram Protocol）

- 意味：TCPはコネクションを作り、届いたかを確かめる信頼性の高い通信。UDPは確認をせず速い通信で、動画・音声やDNSに使う

#### 3ウェイハンドシェイク（3-way Handshake）

- 意味：TCPで接続を始めるときの3回のやり取り（SYN → SYN/ACK → ACK）

#### IPv4アドレスとサブネットマスク（Subnet Mask）

- 意味：IPアドレスのうちネットワーク部とホスト部の境目を示す値
- ポイント：/24なら使えるホストは 2^8 − 2 ＝ 254台

#### CIDR（さいだー / Classless Inter-Domain Routing）

- 意味：クラスにとらわれず、ネットワーク部の長さを自由に決める方式
- 例：192.168.1.0/24
- 語の意味：Classless＝クラスのない／Inter-Domain＝ドメイン間の／Routing＝経路制御

#### IPv6（Internet Protocol version 6）

- 意味：128ビットのアドレスを使うIP
- ポイント：アドレスが足りない問題を解決する。16ビットずつ16進数で8つに区切って書く

#### NAT・NAPT（Network Address Translation / Network Address Port Translation）

- 意味：プライベートIPアドレスとグローバルIPアドレスを変換するしくみ
- ポイント：NAPTはポート番号も変換し、1つのグローバルアドレスを複数の端末で使える

#### ARP（あーぷ / Address Resolution Protocol）

- 意味：IPアドレスからMACアドレスを調べるプロトコル
- 語の意味：Address＝アドレス／Resolution＝解決／Protocol＝通信規約

#### ICMP（あいしーえむぴー / Internet Control Message Protocol）

- 意味：通信の誤りや状態を知らせるプロトコル
- ポイント：ping や traceroute が使う
- 語の意味：Internet＝インターネット／Control＝制御／Message＝通知

#### DHCP（でぃーえいちしーぴー / Dynamic Host Configuration Protocol）

- 意味：端末にIPアドレスなどの設定を自動で配るプロトコル
- 語の意味：Dynamic＝動的な／Host＝端末／Configuration＝設定

#### DNS（でぃーえぬえす / Domain Name System）

- 意味：ドメイン名とIPアドレスを対応付けるしくみ
- 語の意味：Domain Name＝ドメイン名／System＝仕組み

#### HTTP・HTTPS（HyperText Transfer Protocol / Secure）

- 意味：Webのやり取りのプロトコル。HTTPSはHTTPをTLSで暗号化したもの
- ポイント：要求（リクエスト）と応答（レスポンス）を繰り返す。状態を持たないのでCookieで状態を管理する

#### SMTP・POP3・IMAP4

- 意味：SMTPはメールの送信と転送、POP3はメールを端末に取り込む受信、IMAP4はメールをサーバに置いたまま見る受信

#### カプセル化（Encapsulation）

- 意味：送信するとき、上の層のデータに下の層のヘッダを順に付けていくこと
- ポイント：受け取る側は逆に外していく


### いろいろなプロトコル（発展）

#### ポート番号（Port Number）

- 意味：1台のコンピュータの中で、どのアプリケーションに届けるかを表す番号
- 例：HTTPは80、HTTPSは443

#### ウェルノウンポート（Well-known Port）

- 意味：よく使うサービスにあらかじめ決められた0〜1023番のポート番号

#### IPアドレスのクラス（IP Address Class）

- 意味：昔のIPアドレスの分け方（A・B・C）
- ポイント：今はCIDRで柔軟に分ける

#### プライベートIPアドレス（Private IP Address）

- 意味：組織の中だけで自由に使えるIPアドレス
- 例：192.168.0.0/16

#### ブロードキャストアドレス（Broadcast Address）

- 意味：同じネットワーク内のすべての機器に送るためのアドレス
- ポイント：ホスト部がすべて1

#### ルーティング（Routing）

- 意味：パケットを送り先まで届ける経路を選ぶこと
- ポイント：静的ルーティングと動的ルーティングがある

#### RIP・OSPF・BGP（Routing Protocols）

- 意味：経路を決めるプロトコル
- ポイント：RIPはホップ数、OSPFはコスト、BGPは組織どうしの経路に使う

#### デフォルトゲートウェイ（Default Gateway）

- 意味：ほかのネットワークへ送るときに、まず送る先のルータ

#### FTP（えふてぃーぴー / File Transfer Protocol）

- 意味：ファイルを送ったり受け取ったりするプロトコル
- ポイント：制御用とデータ用の2つの接続を使う

#### SSH（えすえすえいち / Secure Shell）

- 意味：遠くのコンピュータに暗号化して安全にログインするプロトコル

#### MIME（まいむ / Multipurpose Internet Mail Extensions）

- 意味：電子メールで、日本語や画像などを送れるようにする規格
- ポイント：暗号化して署名するのがS/MIME

#### WebSocket（うぇぶそけっと）

- 意味：Webブラウザとサーバがつながったままで、双方向に通信できるプロトコル
- ポイント：チャットなどに使う

#### マルチキャスト（Multicast）

- 意味：決められたグループの機器に、まとめて同じデータを送ること
- ポイント：ユニキャストは1対1、ブロードキャストは全員

#### IPsec（あいぴーせっく / IP Security）

- 意味：IP層でデータを暗号化し、改ざんを防ぐプロトコル
- ポイント：VPNで使う

#### PPP（ぴーぴーぴー / Point-to-Point Protocol）

- 意味：2点間をつなぐためのデータリンク層のプロトコル

#### TLS（てぃーえるえす / Transport Layer Security）

- 意味：通信を暗号化し、相手が本物かを証明書で確かめるプロトコル
- ポイント：HTTPSで使う。SSLの後継

#### HTTP/2・HTTP/3

- 意味：1つの接続で複数のやり取りを同時に行えるHTTPと、UDPをもとにしたQUICで動くHTTP
- ポイント：表示が速くなる

#### Cookie（くっきー）

- 意味：Webサーバがブラウザに保存させる小さなデータ
- ポイント：ログイン状態などを覚えておく

#### URL（ゆーあーるえる / Uniform Resource Locator）

- 意味：Web上の場所を表す書き方
- ポイント：スキーム・ホスト名・パスなどからなる

#### DNSのレコード（DNS Record）

- 意味：ドメイン名とIPアドレスなどの対応を書いた情報
- ポイント：Aはアドレス、MXはメールサーバ、CNAMEは別名

#### IPv6のアドレス表記（IPv6 Notation）

- 意味：128ビットを16ビットずつ8つに分け、16進数で書く
- ポイント：0が続く所は「::」で一度だけ省略できる


## 10-4 ネットワーク管理


### 管理の道具

#### SNMP（えすえぬえむぴー / Simple Network Management Protocol）

- 意味：ネットワーク機器の状態を集めて管理するプロトコル
- ポイント：マネージャがエージェントに問い合わせる。異常はトラップで知らせる
- 語の意味：Simple＝簡単な／Network Management＝ネットワーク管理／Protocol＝規約

#### ping・traceroute

- 意味：ping はICMPで相手に届くかを確かめるコマンド、traceroute は経路上のルータを調べるコマンド

#### NTP（えぬてぃーぴー / Network Time Protocol）

- 意味：機器の時刻を合わせるプロトコル
- ポイント：ログの時刻をそろえるのに大事
- 語の意味：Network＝ネットワーク／Time＝時刻／Protocol＝規約

#### 障害の切り分け（Troubleshooting）

- 意味：層ごとに確かめて原因の場所を絞ること
- ポイント：ping（3層）が通るのにWebだけ見られないなら、4層以上（ポートやファイアウォール）を疑う


### 監視と運用（発展）

#### MIB（みぶ / Management Information Base）

- 意味：SNMPで管理する機器の情報をまとめたもの

#### SNMPトラップ（SNMP Trap）

- 意味：機器に異常が起きたとき、機器の方から管理装置へ知らせる仕組み

#### syslog（しすろぐ）

- 意味：機器のログを集めて送る仕組み

#### パケットキャプチャ（Packet Capture）

- 意味：ネットワークを流れるパケットを取り込んで中身を調べること
- 例：Wireshark

#### 帯域（Bandwidth）

- 意味：回線で一度に送れるデータの量
- ポイント：bpsで表す

#### スループット（Throughput）

- 意味：実際に一定時間で送れたデータの量

#### 冗長化（Redundancy）

- 意味：機器や回線を二重にして、片方が壊れても通信を続けられるようにすること

#### リンクアグリゲーション（Link Aggregation）

- 意味：複数の回線を束ねて、1本の太い回線として使うこと
- ポイント：速くなり、1本が切れても続けられる


## 10-5 ネットワーク応用


### 応用

#### VPN（ぶいぴーえぬ / Virtual Private Network）

- 意味：公衆の回線の上に、暗号化した専用線のような通信路を作る技術
- ポイント：IPsec VPN・SSL/TLS VPNがある
- 語の意味：Virtual＝仮想の／Private＝専用の／Network＝網

#### CDN（しーでぃーえぬ / Content Delivery Network）

- 意味：利用者の近くのサーバ（キャッシュ）からコンテンツを配信して、速くするしくみ
- 語の意味：Content＝内容／Delivery＝配送／Network＝網

#### プロキシサーバ（Proxy Server）

- 意味：内部の端末の代わりに外部のWebサーバへアクセスするサーバ
- ポイント：キャッシュやアクセス制限に使う

#### IoTネットワーク（IoT Network）

- 意味：多くの機器をつなぐネットワーク
- ポイント：MQTTなど軽いプロトコルを使う


### サービスと応用（発展）

#### インターネットVPN・IP-VPN（Internet VPN / IP-VPN）

- 意味：インターネットを通る仮想の専用線と、通信事業者の閉じた網を使う仮想の専用線
- ポイント：IP-VPNの方が品質を保ちやすい

#### 広域イーサネット（Wide Area Ethernet）

- 意味：離れた拠点どうしを、同じLANのようにつなぐサービス

#### SD-WAN（えすでぃーわん / Software-Defined WAN）

- 意味：拠点をつなぐWANを、ソフトウェアでまとめて制御する技術

#### VoIP（ぶいおいっぷ / Voice over IP）

- 意味：音声をIPのネットワークで送る技術
- ポイント：IP電話に使う

#### SIP（しっぷ / Session Initiation Protocol）

- 意味：IP電話で、通話を始めたり終わらせたりするためのプロトコル

#### エッジコンピューティング（Edge Computing）

- 意味：利用者や機器の近くで処理を行い、遅れを小さくする考え方

#### Webサーバ・アプリケーションサーバ（Web / Application Server）

- 意味：画面を返すサーバと、業務の処理を行うサーバ

#### ロードバランサ（Load Balancer）

- 意味：複数のサーバに通信を振り分けて、負荷を分ける機器

#### 無線LANの暗号化（WPA3）

- 意味：無線LANの通信を暗号化する規格
- ポイント：WPA2の後継で、より安全

#### ゼロトラストネットワーク（Zero Trust Network）

- 意味：社内のネットワークでも信用せず、通信ごとに確かめる考え方

#### CATV（Cable Television）

- 意味：ケーブルテレビの回線を使ったインターネット接続

### 10-2 データ通信と制御

#### 問 ap-10-q03

- 問：100Mビット/秒の回線で、伝送効率80％のとき、200Mバイトのデータを送るのに何秒かかるか。

- イ：16
- ウ：20
- エ：25
- 正解：ウ
- 解説：200Mバイト＝1,600Mビット。1,600÷(100×0.8)＝20秒。

#### 問 ap-10-q16

- 解説：QoSは通信品質を保つ。
