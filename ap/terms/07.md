## 7-1 ユーザーインタフェース技術

### まとめ表

**画面の部品**

| 部品 | 使いどころ |
| :-: | :-: |
| ラジオボタン | 選択肢から1つだけ選ぶ |
| チェックボックス | 当てはまるものをいくつでも選ぶ |
| プルダウンメニュー | 多くの選択肢から1つを選び、画面を節約する |
| テキストボックス | 自由に文字を入れる |


### 画面と入力

#### GUI（じーゆーあい / Graphical User Interface）

- 意味：アイコンやボタンなど、図で操作する画面
- 語の意味：Graphical＝図による／User＝利用者／Interface＝接点

#### CUI（しーゆーあい / Character User Interface）

- 意味：文字で命令を打ち込んで操作する画面
- 語の意味：Character＝文字／User＝利用者／Interface＝接点

#### ラジオボタン（Radio Button）

- 意味：いくつかの選択肢から1つだけを選ばせる部品

#### チェックボックス（Check Box）

- 意味：当てはまる項目をいくつでも選ばせる部品

#### 音声認識（Speech Recognition）

- 意味：人の話す声をコンピュータが文字や命令に変える技術

#### ジェスチャーインタフェース（Gesture Interface）

- 意味：手や体の動きで機器を操作するしくみ

#### 帳票設計（Form Design）

- 意味：印刷する伝票や報告書の項目・配置を決めること
- ポイント：よく使う項目を左上にまとめる

#### コード設計（Code Design）

- 意味：商品番号などのコードの付け方を決めること
- ポイント：チェックディジットで入力の誤りを見つける

#### チェックディジット（Check Digit）

- 意味：コードの数字から計算した検査用の数字を付けて、入力の誤りを見つけるしくみ


## 7-2 UX/UIデザイン


### 使いやすさ

#### ユーザビリティ（Usability）

- 意味：利用者が目的を、効果的・効率的・満足して達成できる度合い
- ポイント：JIS Z 8521 などで定義

#### UX（ゆーえっくす / User Experience）

- 意味：製品やサービスを使うことで得られる体験の全体
- 語の意味：User＝利用者／Experience＝体験

#### アクセシビリティ（Accessibility）

- 意味：高齢者や障害のある人も含め、誰でも使えること
- ポイント：JIS X 8341 が規格

#### ユニバーサルデザイン（Universal Design）

- 意味：年齢や能力に関係なく、はじめから誰もが使いやすいように設計すること

#### ヒューリスティック評価（Heuristic Evaluation）

- 意味：専門家が経験則（ガイドライン）にもとづいて使いやすさの問題を見つける評価

#### 思考発話法（Think-aloud Protocol）

- 意味：利用者に考えていることを声に出しながら操作してもらい、問題点を見つける評価

#### 認知的ウォークスルー（Cognitive Walkthrough）

- 意味：専門家が利用者になったつもりで操作の手順をたどり、つまずく所を見つける評価

#### ペルソナ（Persona）

- 意味：典型的な利用者を、名前や生活まで具体的に描いた架空の人物
- ポイント：設計の判断をそろえるのに使う

#### カスタマージャーニーマップ（Customer Journey Map）

- 意味：利用者がサービスを知ってから使うまでの行動や気持ちの変化を時間の順に表した図

#### 人間中心設計（HCD / Human Centred Design）

- 意味：利用者の立場に立って、調査・設計・評価を繰り返す設計の進め方
- ポイント：JIS Z 8530（ISO 9241-210）


## 問題演習

- 書式：「#### 問 問題ID」の下に、問・ア〜エ・正解・解説を書く。「###」は小分類（クイズの範囲に使う）

### 7-1 ユーザーインタフェース技術

#### 問 ap-7-q01

- 問：複数の選択肢の中から1つだけを選ばせる画面部品として適切なものはどれか。
- ア：チェックボックス
- イ：ラジオボタン
- ウ：テキストボックス
- エ：スライダ
- 正解：イ
- 解説：1つだけ選ぶのはラジオボタン。複数選択はチェックボックス。

#### 問 ap-7-q02

- 問：コードに検査用の数字を付加して、入力時の誤りを検出する仕組みはどれか。
- ア：チェックディジット
- イ：パリティビット
- ウ：ハッシュ値
- エ：シーケンスコード
- 正解：ア
- 解説：チェックディジットは入力ミスを見つけるために付ける。

### 7-2 UX/UIデザイン

#### 問 ap-7-q03

- 問：利用者に考えていることを声に出しながら操作してもらう評価手法はどれか。
- ア：ヒューリスティック評価
- イ：思考発話法
- ウ：認知的ウォークスルー
- エ：A/Bテスト
- 正解：イ
- 解説：声に出してもらうのが思考発話法。

#### 問 ap-7-q04

- 問：高齢者や障害者を含む誰もが、情報やサービスを利用できる度合いを表すものはどれか。
- ア：ユーザビリティ
- イ：アクセシビリティ
- ウ：スケーラビリティ
- エ：ポータビリティ
- 正解：イ
- 解説：誰でも使えることがアクセシビリティ。

#### 問 ap-7-q05

- 問：典型的な利用者像を具体的な人物として設定し、設計に活用する手法はどれか。
- ア：ペルソナ
- イ：ステークホルダ
- ウ：アクタ
- エ：オピニオンリーダ
- 正解：ア
- 解説：ペルソナは架空の具体的な利用者像。
