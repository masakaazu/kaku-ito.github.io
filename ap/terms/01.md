## 1-1 離散数学

### まとめ表

**負の数の表し方（4ビットで −3 を表すと）**

| 表し方 | −3 の表現 | 4ビットで表せる範囲 | 特徴 |
| :-: | :-: | :-: | :-: |
| 符号付き絶対値 | 1011 | −7〜+7 | 先頭が符号、残りが絶対値。0が「+0」と「−0」の2つできる |
| 1の補数 | 1100 | −7〜+7 | 全ビットを反転する。0が2つできる |
| 2の補数 | 1101 | −8〜+7 | 反転して1を足す。0は1つ。引き算を足し算の回路でできる |

**計算で出る誤差（過去問の選択肢に4つ並ぶ）**

| 誤差 | 起きる場面 | 対策の例 |
| :-: | :-: | :-: |
| 桁落ち | 値がほぼ等しい2つの数の差を求めたとき、有効桁数が減る | 式を変形して引き算を避ける |
| 情報落ち | 絶対値が大きな数と小さな数を足し引きしたとき、小さい数が結果に反映されない | 絶対値の小さい数から順に足す |
| 丸め誤差 | 決められた桁数に収めるため、切捨て・切上げ・四捨五入したとき | 桁数（精度）を増やす |
| 打切り誤差 | 無限に続く計算を、有限の回数・項で打ち切ったとき | 打ち切るまでの回数を増やす |

**シフト演算（8ビット、右へ1ビット）**

| 種類 | 11010110 を右へ1ビット | 空いたビットに入るもの | 使い道 |
| :-: | :-: | :-: | :-: |
| 論理シフト | 01101011 | 常に0 | 符号なしの数・ビット列の操作 |
| 算術シフト | 11101011 | 符号ビットと同じ値（右シフト時） | 符号付きの数の 2^n 倍・2^n 分の1 |

| 演算 | 結果 | 覚え方 |
| :-: | :-: | :-: |
| 論理積（AND） | 0001 | 両方1のときだけ1 |
| 論理和（OR） | 0111 | どちらかが1なら1 |
| 排他的論理和（XOR） | 0110 | 異なるときだけ1 |
| 否定論理積（NAND） | 1110 | ANDの反対 |
| 否定論理和（NOR） | 1000 | ORの反対 |

### 基数と負の数

#### 2進数（にしんすう / Binary Number）

- 意味：0と1の2種類の数字で表し、桁が1つ上がるごとに重みが2倍になる数の表し方
- ポイント：nビットで表せる符号なし整数は 0〜2^n−1。nビットの数どうしの積は最大 2n ビットになる
- 例：R4秋 問1（nビットの整数aの2乗は最大で何ビットか→2n）

#### 8進数（はちしんすう / Octal Number）

- 意味：0〜7の8種類の数字で表す数の表し方
- ポイント：2進数を下から3ビットずつ区切ると、8進数の1桁になる

#### 16進数（じゅうろくしんすう / Hexadecimal Number）

- 意味：0〜9とA〜Fの16種類の記号で表す数の表し方
- ポイント：2進数を下から4ビットずつ区切ると16進数の1桁になる。1バイトはちょうど2桁

#### 基数変換（きすうへんかん / Radix Conversion）

- 意味：ある進数で表した数を、別の進数で表し直すこと
- ポイント：10進の整数→2進は2で割った余りを下から並べる。小数部は2を掛けて出た整数部を上から並べる。10進の0.1のように、2進では循環小数になって正確に表せない数がある
- 例：R5秋 問1（2桁の2進数 x1x2 の桁を入れ替えた数を、xとint(x/2)で表す）

#### 2の補数（にのほすう / Two's Complement）

- 意味：負の数を「全ビットを反転して1を足した値」で表す方法
- ポイント：nビットで −2^(n−1)〜2^(n−1)−1 を表せる。0の表し方が1つだけで、引き算を足し算の回路で行える。1の補数・符号付き絶対値は0が2つできる

#### 1の補数（いちのほすう / One's Complement）

- 意味：負の数を「全ビットを反転した値」で表す方法
- ポイント：+0（0000）と−0（1111）の2つの0ができる。範囲は −(2^(n−1)−1)〜2^(n−1)−1

#### 符号付き絶対値表現（ふごうつきぜったいちひょうげん / Sign and Magnitude）

- 意味：先頭の1ビットを符号（0＝正、1＝負）、残りのビットを絶対値として表す方法
- ポイント：人には分かりやすいが、0が2つでき、加減算の回路が複雑になる。浮動小数点数の符号部はこの考え方

#### BCD（びーしーでぃー / Binary Coded Decimal）

- 意味：10進数の1桁を4ビットの2進数で表す方法（2進化10進）。パック10進数やゾーン10進数の数字部分もこの表し方
- ポイント：4ビットのうち1010〜1111は使わない。事務計算で10進の丸め誤差を避けたいときに使う
- 語の意味：Binary＝2進の／Coded＝符号化された／Decimal＝10進数

#### パック10進数（ぱっくじっしんすう / Packed Decimal）

- 意味：10進数の1桁を4ビットで表し、1バイトに2桁を詰め、最後の4ビットに符号を置く表し方
- ポイント：ゾーン10進数は1バイトに1桁（上位4ビットはゾーン）。パックの方が詰まっていて短い

#### ゾーン10進数（ぞーんじっしんすう / Zoned Decimal）

- 意味：10進数の1桁を1バイトで表し、上位4ビットをゾーン、下位4ビットを数字に使う表し方
- ポイント：最下位バイトのゾーン部分で符号を表す。文字コードに近い形なので入出力に便利

### 固定小数点と浮動小数点

#### 固定小数点数（こていしょうすうてんすう / Fixed Point Number）

- 意味：小数点の位置をあらかじめ決めておき、整数と同じように扱う数の表し方
- ポイント：表せる範囲は狭いが、加減算が速く誤差が出にくい。整数は「小数点が最下位ビットの右にある固定小数点数」と考える

#### 浮動小数点数（ふどうしょうすうてんすう / Floating Point Number）

- 意味：数を「符号・仮数・指数」に分け、（仮数）×（基数）^（指数）の形で表す方法
- ポイント：小さな数から大きな数まで広い範囲を表せるが、仮数の桁数を超える部分は丸められる。情報落ち・桁落ちが起きるのはこの形式
- 例：R4春 問1（仮数部7ビットで情報落ちが起きない計算を選ぶ）

#### 仮数（かすう / Mantissa）

- 意味：浮動小数点数で、数の有効数字の部分
- ポイント：仮数部のビット数が精度（有効桁数）を決め、指数部のビット数が表せる範囲を決める

#### 指数（しすう / Exponent）

- 意味：浮動小数点数で、基数を何乗するか（小数点の位置）を表す部分
- ポイント：IEEE 754では負の指数も扱えるよう、バイアス（単精度は127）を足した値を記録する

#### 正規化（せいきか / Normalization）

- 意味：浮動小数点数の仮数の先頭が決まった形（2進なら 1.xxx）になるよう、指数を調整すること
- ポイント：表し方を1つに決め、有効桁を最大限に使うために行う。IEEE 754 は先頭の1を記録しない（けち表現）ので、仮数部23ビットで24ビット分の精度になる

#### 単精度浮動小数点数（たんせいど / Single Precision）

- 意味：IEEE 754で、全体を32ビット（符号1・指数8・仮数23）で表す浮動小数点数
- ポイント：10進で約7桁の精度。倍精度は64ビット（符号1・指数11・仮数52）で約15〜16桁

#### 倍精度浮動小数点数（ばいせいど / Double Precision）

- 意味：IEEE 754で、全体を64ビット（符号1・指数11・仮数52）で表す浮動小数点数
- ポイント：単精度より精度も範囲も大きい。科学技術計算の標準。丸め誤差を減らす対策として「倍精度にする」が選択肢に出る

#### IEEE 754（あいとりぷるいー754）

- 意味：浮動小数点数の表し方と演算方法を定めた国際標準規格
- ポイント：符号部・指数部（バイアス付き）・仮数部（先頭の1は省略）の並び。無限大や NaN（数でない値）の表し方も決まっている
- 語の意味：IEEE＝Institute of Electrical and Electronics Engineers（米国電気電子技術者協会）

### 演算の誤差

#### 桁落ち（けたおち / Cancellation）

- 意味：値がほぼ等しい2つの数の差を求めたとき、有効桁数が大きく減ることで生じる誤差
- ポイント：「ほぼ等しい」「差」がキーワード。情報落ちは「大きさが大きく違う」「和・差」で、場面が違う
- 例：R3春 問2で正解ア。イは丸め誤差、ウは情報落ち、エは打切り誤差

#### 情報落ち（じょうほうおち / Loss of Trailing Digits）

- 意味：絶対値が非常に大きな数と小さな数を加減算したとき、小さい数が結果に反映されずに生じる誤差
- ポイント：仮数の桁数に収まらず、小さい数が丸めで消える。対策は絶対値の小さいものから順に足すこと
- 例：R3春 問2の選択肢ウ。R4春 問1は、小さい数どうしを先に足すと情報落ちが起きない計算（ア）を選ぶ

#### 丸め誤差（まるめごさ / Rounding Error）

- 意味：決められた有効桁数に収めるため、切捨て・切上げ・四捨五入で下位の桁を削ったことで生じる誤差
- ポイント：コンピュータの数値は桁数が有限なので、ほぼ必ず生じる。倍精度にすると小さくできる
- 例：R3春 問2の選択肢イ

#### 打切り誤差（うちきりごさ / Truncation Error）

- 意味：無限級数や繰返し計算を、有限の項・回数で打ち切ったことで生じる誤差
- ポイント：ニュートン法・二分法などの近似解法で、終了条件を決めたときに生じる。丸め誤差とは原因が違う
- 例：R3春 問2の選択肢エ

#### オーバーフロー（あふれ / Overflow）

- 意味：演算結果の絶対値が大きすぎて、決められたビット数で表せる範囲を超えること
- ポイント：2の補数では、正＋正が負に、負＋負が正になったら起きている。アンダーフローは逆に0に近すぎて表せないこと

#### アンダーフロー（Underflow）

- 意味：浮動小数点数で、演算結果の絶対値が0に近すぎて、表せる最小の値より小さくなること
- ポイント：多くの場合0として扱われる。指数部のビット数が足りないと起きる。オーバーフローと対で覚える

#### 絶対誤差（ぜったいごさ / Absolute Error）

- 意味：近似値と真の値の差の大きさ
- ポイント：相対誤差は、それを真の値の大きさで割った割合。値の大きさが違うものの精度を比べるときは相対誤差を使う

#### 相対誤差（そうたいごさ / Relative Error）

- 意味：近似値と真の値の差を、真の値の大きさで割った割合
- ポイント：浮動小数点数は、どの大きさの値でもほぼ同じ相対誤差になるように作られている

### シフト演算

#### 論理シフト（ろんりしふと / Logical Shift）

- 意味：ビット列を左右にずらし、空いたビットに常に0を入れるシフト
- ポイント：符号を考えない。符号なしの数なら左に1ビットで2倍、右に1ビットで2分の1（余りは捨てる）

#### 算術シフト（さんじゅつしふと / Arithmetic Shift）

- 意味：符号ビットをそのまま保ち、残りのビットを左右にずらすシフト
- ポイント：右シフトでは空いた上位に符号ビットと同じ値を入れるので、負の数も正しく2^n分の1になる。左シフトで符号ビットと違う値がはみ出すとオーバーフロー

#### 循環シフト（じゅんかんしふと / Rotate Shift）

- 意味：一方の端からはみ出したビットを、反対側の端に戻すシフト
- ポイント：ビットが失われない。数の計算ではなく、暗号やビットパターンの操作に使う

### 集合

#### 和集合（わしゅうごう / Union）

- 意味：集合AとBの少なくとも一方に含まれる要素全体（A∪B）
- ポイント：論理和（OR）に対応する。ベン図では2つの円全体

#### 積集合（せきしゅうごう / Intersection）

- 意味：集合AとBの両方に含まれる要素全体（A∩B）
- ポイント：論理積（AND）に対応する。ベン図では2つの円の重なり部分

#### 補集合（ほしゅうごう / Complement）

- 意味：全体集合Sのうち、集合Aに含まれない要素全体（Ā、S−A）
- ポイント：否定（NOT）に対応する。ド・モルガンの法則で「Ā∩B̄＝(A∪B)の補集合」
- 例：R4春 問2（Ā∩B̄ に等しいものは Ā−B）

#### 差集合（さしゅうごう / Difference）

- 意味：集合Aの要素から、集合Bにも含まれる要素を除いたもの（A−B）
- ポイント：A−B＝A∩B̄。R4春 問2では Ā−B＝Ā∩B̄ と変形して正解を見抜く

#### 部分集合（ぶぶんしゅうごう / Subset）

- 意味：集合Aの要素がすべて集合Bにも含まれるときの、Bに対するA（A⊆B）
- ポイント：空集合はすべての集合の部分集合。要素数nの集合の部分集合は 2^n 個

#### 対称差（たいしょうさ / Symmetric Difference）

- 意味：集合AとBのどちらか一方だけに含まれる要素全体
- ポイント：排他的論理和（XOR）に対応する。(A∪B)−(A∩B) と書ける

#### ベン図（べんず / Venn Diagram）

- 意味：集合どうしの関係を、円の重なりと塗りつぶしで表した図
- ポイント：論理演算の問題でも、2つの円の塗り方で演算を表す
- 例：R3春 問1（排他的論理和の相補演算を、ベン図付きの選択肢から選ぶ）

### 命題と論理式

#### 命題（めいだい / Proposition）

- 意味：真か偽かがはっきり決まる文や式
- ポイント：「明日は晴れるだろう」のように真偽が決まらないものは命題ではない。命題を記号で組み合わせて扱うのが命題論理

#### 含意（がんい / Implication）

- 意味：「PならばQ」（P→Q）を表す論理演算。Pが真でQが偽のときだけ偽になる
- ポイント：P→Q は ¬P∨Q と同じ。前が偽なら後ろに関係なく真になる点が試験の決め手
- 例：R7春 問1（P、Qが真のとき、Rにかかわらず真になる式。前半が偽になる式エを選ぶ）

#### 対偶（たいぐう / Contraposition）

- 意味：「PならばQ」に対する「QでないならPでない」（¬Q→¬P）
- ポイント：元の命題と真偽が必ず一致する。逆（Q→P）と裏（¬P→¬Q）は一致するとは限らない

#### 恒真式（こうしんしき / Tautology）

- 意味：変数にどんな真偽の値を入れても、常に真になる論理式
- ポイント：「Rの真偽にかかわらず真になる式」を選ぶ問題は、変数を固定したときの恒真性を問うている

#### 命題論理（めいだいろんり / Propositional Logic）

- 意味：命題を一つの記号として扱い、論理演算で結んだ式の真偽を考える論理
- ポイント：述語論理は「xは人間である」のように変数をもつ文と「すべての」「ある」を扱える。命題論理はそれより表現力が低い

### 論理演算

#### 論理積（ろんりせき / AND）

- 意味：入力がすべて1（真）のときだけ1になる演算
- ポイント：ビットを取り出すマスク操作に使う。積集合に対応する
- 例：R5春 問1（(n+1) AND 255 で、256を0に戻す）

#### 論理和（ろんりわ / OR）

- 意味：入力のどれか1つでも1なら1になる演算
- ポイント：特定のビットを1にするときに使う。和集合に対応する

#### 否定（ひてい / NOT）

- 意味：入力が1なら0、0なら1を返す演算
- ポイント：補集合に対応する。上線（Ā）や¬で表す

#### 排他的論理和（はいたてきろんりわ / XOR）

- 意味：2つの入力が異なるときだけ1になる演算
- ポイント：同じ値で2回XORすると元に戻る。パリティの計算、ハミング符号の検査式、ビットの反転に使う
- 例：R3春 問1（排他的論理和の相補演算は等価演算）、R4春 問4のハミング符号の検査式
- 語の意味：Exclusive＝排他的な／OR＝または

#### 等価演算（とうかえんざん / XNOR）

- 意味：2つの入力が同じときだけ1になる演算（否定排他的論理和）
- ポイント：XORの結果をすべて反転したもの。XORとは互いに相補演算の関係
- 例：R3春 問1で正解ア

#### 否定論理積（ひていろんりせき / NAND）

- 意味：論理積の結果を否定した演算。入力がすべて1のときだけ0になる
- ポイント：NANDだけでAND・OR・NOTをすべて作れる（万能ゲート）。NORも同じ性質をもつ

#### 否定論理和（ひていろんりわ / NOR）

- 意味：論理和の結果を否定した演算。入力がすべて0のときだけ1になる
- ポイント：NORも万能ゲート。ORの相補演算はNOR、XORの相補演算は等価演算
- 例：R3春 問1の選択肢イ

#### 相補演算（そうほえんざん / Complementary Operation）

- 意味：どんな入力に対しても、結果が互いに否定の関係にある2つの演算
- ポイント：AND と NAND、OR と NOR、XOR と 等価演算（XNOR）が組になる
- 例：R3春 問1で定義が示された

#### 真理値表（しんりちひょう / Truth Table）

- 意味：論理式の入力の全組合せと、それぞれの出力を一覧にした表
- ポイント：n個の入力なら 2^n 行。論理式どうしが等価かどうかは、真理値表が一致するかで確かめる

### 論理式の法則と簡単化

#### ド・モルガンの法則（De Morgan's Laws）

- 意味：「AかつBでない」と「AでないかBでない」が等しく（¬(A∧B)＝¬A∨¬B）、「AまたはBでない」と「AでなくBでない」が等しい（¬(A∨B)＝¬A∧¬B）という法則
- ポイント：否定を分配すると、積と和が入れ替わる。集合では Ā∩B̄＝(A∪B)の補集合
- 例：R4春 問2の考え方の土台

#### 分配則（ぶんぱいそく / Distributive Law）

- 意味：A・(B＋C)＝A・B＋A・C、A＋(B・C)＝(A＋B)・(A＋C) が成り立つという法則
- ポイント：論理演算では、和が積に分配する2つ目の式も成り立つ点が普通の算数と違う

#### 吸収則（きゅうしゅうそく / Absorption Law）

- 意味：A＋A・B＝A、A・(A＋B)＝A が成り立つという法則
- ポイント：論理式を簡単にするときに使う。Aを含む項がある場合、A・Bの項は消せる

#### カルノー図（かるのーず / Karnaugh Map）

- 意味：入力の組合せを、隣どうしが1ビットだけ違う順（00, 01, 11, 10）に並べて出力を書き込み、論理式を簡単にするための表
- ポイント：隣り合う1を2・4・8個の長方形でまとめる。表の上下・左右の端もつながっているとみなす
- 例：R4秋 問2＝R7秋 問1（四隅のまとまりが Ā・B̄・D̄、中央の4つが B・D）

#### 論理関数（ろんりかんすう / Logic Function）

- 意味：0と1の入力を受け取り、0か1を返す関数
- ポイント：どんな論理関数も、AND・OR・NOTの組合せ（積和形）で表せる

### 場合の数と確率の基本

#### 階乗（かいじょう / Factorial）

- 意味：1からnまでの整数をすべて掛けた値（n!）
- ポイント：n個のものを1列に並べる並べ方の数。0!＝1 と決めている

#### 順列（じゅんれつ / Permutation）

- 意味：n個の中からr個を選び、順番を付けて並べる並べ方の数（nPr＝n!÷(n−r)!）
- ポイント：組合せとの違いは「順番を区別するか」。暗証番号のように並び順で意味が変わるなら順列

#### 組合せ（くみあわせ / Combination）

- 意味：n個の中から、順番を考えずにr個を選ぶ選び方の数（nCr＝n!÷{r!(n−r)!}）
- ポイント：サンプル抽出の確率は組合せで数える。R4秋 問3 は 90C3÷100C3＝(90×89×88)÷(100×99×98)
- 例：R4秋 問3（100個中10個不良のロットから3個抜いて全部良品の確率→178/245）

#### 加法定理（かほうていり / Addition Rule）

- 意味：事象AかBが起きる確率は、P(A)＋P(B)−P(A∩B) で求められるという定理
- ポイント：AとBが同時に起きない（排反）なら P(A)＋P(B) だけでよい

#### 乗法定理（じょうほうていり / Multiplication Rule）

- 意味：AとBが両方起きる確率は、P(A)×P(B|A) で求められるという定理
- ポイント：AとBが独立なら P(A)×P(B)。R4秋 問3 のように元に戻さずに取り出すときは、2個目以降の確率が変わる

#### 同時確率（どうじかくりつ / Joint Probability）

- 意味：2つの事象AとBが両方とも起きる確率 P(A∩B)
- ポイント：条件付き確率は「Aが起きたと分かったうえで」のBの確率で、同時確率をP(A)で割ったもの

#### 条件付き確率（じょうけんつきかくりつ / Conditional Probability）

- 意味：事象Aが起きたという条件のもとで、事象Bが起きる確率 P(B|A)＝P(A∩B)÷P(A)
- ポイント：ベイズの定理は、この条件の向きを逆にする（結果から原因の確率を求める）ための式

#### ベイズの定理（Bayes' Theorem）

- 意味：結果Bが観測されたときに、その原因がAである確率（事後確率）を、P(A|B)＝P(B|A)×P(A)÷P(B) で求める定理
- ポイント：「取り出した玉の色から、どの袋の玉だったかを推定する」「検査が陽性だったとき本当に病気である確率」のように、結果から原因をさかのぼる
- 例：R6春 問1で正解エ

#### 事前確率と事後確率（じぜんかくりつ・じごかくりつ / Prior / Posterior Probability）

- 意味：事前確率は、結果を見る前に考えていた原因の確率。事後確率は、結果を見た後に更新した原因の確率
- ポイント：ベイズの定理は事前確率を事後確率に更新する式。R6春 問1 のウ「ある袋が選ばれる確率」は事前確率にあたる

#### 排反事象（はいはんじしょう / Mutually Exclusive Events）

- 意味：同時には起きない2つの事象
- ポイント：排反なら P(A∩B)＝0。独立（互いに影響しない）とは別の概念で、排反な事象はふつう独立ではない

#### 独立事象（どくりつじしょう / Independent Events）

- 意味：一方が起きても、もう一方の起きる確率が変わらない2つの事象
- ポイント：P(A∩B)＝P(A)×P(B)。サイコロを2回振るのは独立。元に戻さないくじ引きは独立でない

#### 期待値（きたいち / Expected Value）

- 意味：確率変数のとりうる値に、それぞれの確率を掛けて合計した、平均的に期待できる値
- ポイント：意思決定の問題（期待値原理）でも使う。二項分布の期待値は np

### 確率分布

#### 確率密度関数（かくりつみつどかんすう / Probability Density Function）

- 意味：連続型の確率変数で、ある範囲に値が入る確率を、その範囲の面積で表すための関数
- ポイント：連続型では「ちょうどある値になる確率」は0で、範囲で考える。グラフの下の面積の合計は1

#### ベルヌーイ分布（Bernoulli Distribution）

- 意味：1回の試行で、確率pで成功（1）、1−pで失敗（0）となる分布
- ポイント：これをn回繰り返した成功回数の分布が二項分布

#### 二項分布（にこうぶんぷ / Binomial Distribution）

- 意味：成功確率pの独立した試行をn回行ったときの、成功回数の分布
- ポイント：k回成功する確率は nCk×p^k×(1−p)^(n−k)。平均 np、分散 np(1−p)

#### ポアソン分布（Poisson Distribution）

- 意味：一定の時間や範囲の中で、まれに起きる出来事が起きる回数の分布
- ポイント：M/M/1 の最初のMは「到着がポアソン分布に従う（到着間隔は指数分布）」という意味
- 例：R7秋 問2（伝票データはポアソン分布に従って到着する）

#### 指数分布（しすうぶんぷ / Exponential Distribution）

- 意味：出来事が起きてから、次に起きるまでの時間の分布
- ポイント：ポアソン分布の「回数」に対して、指数分布は「間隔」。M/M/1 の2つ目のMは「サービス時間が指数分布に従う」
- 例：R7秋 問2（処理時間は平均T秒の指数分布に従う）

#### 正規分布（せいきぶんぷ / Normal Distribution）

- 意味：平均値を中心に左右対称の釣鐘形になる連続型の分布で、平均と標準偏差の値によって山の位置と広がりが変わるもの
- ポイント：平均値・中央値・最頻値が一致する。平均±1標準偏差に約68%、±2標準偏差に約95%、±3標準偏差に約99.7%が入る
- 例：R5春 問2（平均60・標準偏差10のグラフは、60が頂点で左右対称、60〜70が1標準偏差）

#### 標準正規分布（ひょうじゅんせいきぶんぷ / Standard Normal Distribution）

- 意味：平均0、標準偏差1の正規分布
- ポイント：値から平均を引いて標準偏差で割る（標準化）と、どの正規分布もこれに直せる。偏差値は標準化した値を10倍して50を足したもの

#### カイ二乗分布（かいにじょうぶんぷ / Chi-squared Distribution）

- 意味：標準正規分布に従う独立な値を2乗して足した量が従う分布
- ポイント：観測度数と期待度数のずれを調べるカイ二乗検定に使う。値は0以上で、右にすそを引く非対称な形

#### マルコフ過程（Markov Process）

- 意味：次の状態になる確率が、今の状態だけで決まり、それより前の経緯によらない確率的な過程
- ポイント：状態の移り変わりを遷移確率の表（行列）で表す。天気の予測や、来店客の店の選び方の問題に出る

### 代表値とばらつき

#### 平均値（へいきんち / Mean）

- 意味：データの値をすべて足し、データの個数で割った値
- ポイント：極端に大きい・小さい値（外れ値）に引っ張られやすい。外れ値に強いのは中央値

#### 中央値（ちゅうおうち / Median）

- 意味：データを大きさの順に並べたとき、ちょうど真ん中にくる値（メジアン）
- ポイント：個数が偶数なら中央の2つの平均。外れ値の影響を受けにくい

#### 最頻値（さいひんち / Mode）

- 意味：データの中で最も多く現れる値（モード）
- ポイント：度数分布表では度数が最大の階級の値。正規分布では平均値・中央値と一致する

#### 分散（ぶんさん / Variance）

- 意味：各データと平均値の差を2乗し、その平均をとった値
- ポイント：単位がもとのデータの2乗になる。平方根をとると標準偏差

#### 標準偏差（ひょうじゅんへんさ / Standard Deviation）

- 意味：分散の正の平方根で、データが平均値のまわりにどれだけ散らばっているかを表す値
- ポイント：もとのデータと同じ単位になる。正規分布のグラフでは、大きいほど低く横に広がる
- 例：R5春 問2（標準偏差10の正規分布を選ぶ。イは55〜65が10なので標準偏差5）

#### 歪度（わいど / Skewness）

- 意味：分布が左右どちらにどれだけ偏っているか（非対称の度合い）を表す値
- ポイント：正規分布では0。右にすそが長いと正、左にすそが長いと負。尖度は「とがり具合」で別物

#### 尖度（せんど / Kurtosis）

- 意味：分布の山がどれだけとがっているか、すそがどれだけ重いかを表す値
- ポイント：正規分布を基準に比べる。歪度（左右の偏り）と混同しない

#### 度数分布表（どすうぶんぷひょう / Frequency Distribution Table）

- 意味：データの値をいくつかの区間（階級）に分け、各区間に入る個数（度数）を数えた表
- ポイント：これを棒グラフにしたものがヒストグラム

#### ヒストグラム（Histogram）

- 意味：度数分布表を、階級を横軸、度数を縦軸にとった柱状のグラフにしたもの
- ポイント：分布の形（山が1つか2つか、左右対称か）が分かる。品質管理（QC七つ道具）でも使う

#### 箱ひげ図（はこひげず / Box Plot）

- 意味：最小値・第1四分位数・中央値・第3四分位数・最大値の5つの値で、データの散らばりを箱とひげで表した図
- ポイント：箱の中にデータの真ん中の50%が入る。複数のグループの分布を並べて比べやすい

### 相関と回帰

#### 相関係数（そうかんけいすう / Correlation Coefficient）

- 意味：2つの変数の直線的な関係の強さを −1〜1 で表した値
- ポイント：1に近いほど正の相関、−1に近いほど負の相関、0に近いと直線的な関係がない。相関があっても因果関係があるとは限らない

#### 擬似相関（ぎじそうかん / Spurious Correlation）

- 意味：2つの変数の間に直接の関係はないのに、別の要因（第三の変数）の影響で相関があるように見えること
- ポイント：「アイスの売上と水難事故」はどちらも気温が原因。相関と因果を区別するときの代表例

#### 相関と因果（そうかんといんが / Correlation and Causation）

- 意味：一方が変わるともう一方も変わる関係（相関）と、一方が原因でもう一方が起きる関係（因果）の区別
- ポイント：因果があれば相関はあるが、相関があっても因果があるとは限らない。擬似相関に注意

#### 説明変数（せつめいへんすう / Explanatory Variable）

- 意味：回帰分析などで、結果を説明・予測するために使う変数
- ポイント：目的変数（予測したい変数）を説明する側。機械学習では特徴量と呼ぶ

#### 目的変数（もくてきへんすう / Objective Variable）

- 意味：回帰分析などで、予測したい・説明したい変数
- ポイント：説明変数の値から目的変数の値を求める式を作るのが回帰分析。機械学習の教師あり学習では正解ラベルにあたる

#### 回帰分析（かいきぶんせき / Regression Analysis）

- 意味：ある変数の値から、ほかの変数の値を予測する式（回帰式）を、データから求める分析の総称。説明変数が1つか複数か、予測するのが数値か確率かで種類が分かれる
- ポイント：説明変数が1つなら単回帰、複数なら重回帰。予測するのが「起きる確率（0〜1）」ならロジスティック回帰
- 例：R5秋 問2の選択肢イ

#### 単回帰分析（たんかいきぶんせき / Simple Regression Analysis）

- 意味：1つの説明変数で目的変数を予測する直線（回帰直線）を求める回帰分析
- ポイント：回帰直線は、各点と直線の縦のずれの2乗和が最小になるように引く（最小二乗法）

#### 重回帰分析（じゅうかいきぶんせき / Multiple Regression Analysis）

- 意味：2つ以上の説明変数で目的変数を予測する式を求める回帰分析
- ポイント：説明変数どうしが強く相関していると結果が不安定になる（多重共線性）

#### ロジスティック回帰分析（Logistic Regression Analysis）

- 意味：説明変数から、ある出来事が起きる確率（0〜1）を予測する回帰分析
- ポイント：名前は回帰だが、「買う・買わない」のような2クラス分類に使う。結果をS字の曲線（シグモイド関数）で0〜1に収める

#### 最小二乗法（さいしょうにじょうほう / Least Squares Method）

- 意味：データの各点と、当てはめる直線や曲線とのずれを2乗して合計し、それが最小になるように式を決める方法
- ポイント：回帰直線の求め方。2乗するのは、プラスとマイナスのずれが打ち消し合わないようにするため

### 多変量の分析と尺度

#### 主成分分析（しゅせいぶんぶんせき / Principal Component Analysis）

- 意味：多くの変数を、情報をなるべく失わずに少数の新しい変数（主成分）にまとめ、変数の数を減らす分析
- ポイント：機械学習では教師なし学習の「次元削減」の代表。因子分析は「共通の原因を探す」で、向きが逆
- 例：R5秋 問2で正解エ

#### 因子分析（いんしぶんせき / Factor Analysis）

- 意味：観測した複数の変数に共通して影響を与えている、目に見えない要因（因子）を見つけ出す分析
- ポイント：「国語と英語の点に共通する言語能力」のように、データの背後にある構造を探す
- 例：R5秋 問2の選択肢ア

#### クラスタ分析（Cluster Analysis）

- 意味：データの値が互いに似ているものどうしを集めて、いくつかのグループ（クラスタ）に分ける分析
- ポイント：正解のラベルを使わない（教師なし学習）。代表的な手法がk-means法
- 例：R5秋 問2の選択肢ウ

#### 相関分析（そうかんぶんせき / Correlation Analysis）

- 意味：2つの変数の間にどの程度の関係があるかを、相関係数などで調べる分析
- ポイント：関係の強さを調べるのが相関分析、一方から他方を予測する式を作るのが回帰分析

#### 名義尺度（めいぎしゃくど / Nominal Scale）

- 意味：区別のためだけに数字や記号を割り当てた尺度（性別、血液型、電話番号など）
- ポイント：大小も足し算も意味がない。数えられるのは度数と最頻値だけ

#### 順序尺度（じゅんじょしゃくど / Ordinal Scale）

- 意味：順番や大小には意味があるが、間隔は等しくない尺度（順位、満足度の5段階など）
- ポイント：中央値は使えるが、平均値は本来意味をもたない

#### 間隔尺度（かんかくしゃくど / Interval Scale）

- 意味：目盛りの間隔が等しく差に意味があるが、0が「何もない」を意味しない尺度（摂氏の温度、西暦など）
- ポイント：足し引きはできるが、比（2倍など）に意味がない。20℃は10℃の2倍暑いとは言えない

#### 比例尺度（ひれいしゃくど / Ratio Scale）

- 意味：0が「何もない」を意味し、差にも比にも意味がある尺度（身長、重さ、金額など）
- ポイント：四則演算すべてに意味がある。間隔尺度との違いは0の意味

### 推定と検定

#### 点推定（てんすいてい / Point Estimation）

- 意味：標本から、母集団の平均などの値を1つの値で推定すること
- ポイント：区間推定は「この範囲に入る」と幅で推定する

#### 区間推定（くかんすいてい / Interval Estimation）

- 意味：標本から、母集団の平均などの値が入る範囲を、決めた確率（信頼度）で推定すること
- ポイント：「95%信頼区間」は、同じ方法で何度も区間を作ると95%がその値を含むという意味

#### 尤度（ゆうど / Likelihood）

- 意味：あるパラメータの値を仮定したとき、実際に観測されたデータが得られる確からしさ
- ポイント：確率は「パラメータを固定してデータを考える」、尤度は「データを固定してパラメータを考える」

#### 最尤推定（さいゆうすいてい / Maximum Likelihood Estimation）

- 意味：観測されたデータが得られる尤度が最大になるパラメータの値を、推定値とする方法
- ポイント：機械学習のモデルの学習でも基本となる考え方

#### 帰無仮説（きむかせつ / Null Hypothesis）

- 意味：仮説検定で、「差がない」「効果がない」として立て、棄却できるかを調べる仮説
- ポイント：棄却されたときに採用するのが対立仮説。「棄却できなかった」は「正しいと証明された」ではない

#### 対立仮説（たいりつかせつ / Alternative Hypothesis）

- 意味：仮説検定で、帰無仮説が棄却されたときに採用する、「差がある」「効果がある」という仮説
- ポイント：本当に主張したいことを対立仮説に置き、その否定を帰無仮説にする

#### 有意水準（ゆういすいじゅん / Significance Level）

- 意味：帰無仮説を棄却する基準となる確率（5%や1%がよく使われる）
- ポイント：p値が有意水準より小さければ帰無仮説を棄却する。有意水準は第1種の誤りを犯す確率の上限

#### p値（ぴーち / p-value）

- 意味：帰無仮説が正しいとしたとき、観測された結果か、それより極端な結果が得られる確率（有意確率）
- ポイント：小さいほど「偶然では起きにくい」。p値＜有意水準 なら棄却

#### 棄却域（ききゃくいき / Rejection Region）

- 意味：検定で、統計量がその範囲に入れば帰無仮説を棄却する、と決めた値の範囲
- ポイント：棄却域の確率の合計が有意水準になる。両側検定では左右のすそに分ける

#### 第1種の誤り（だいいっしゅのあやまり / Type I Error）

- 意味：帰無仮説が本当は正しいのに、棄却してしまう誤り
- ポイント：「あわてんぼうの誤り」。起きる確率は有意水準α。有意水準を小さくするほど起きにくい

#### 第2種の誤り（だいにしゅのあやまり / Type II Error）

- 意味：帰無仮説が本当は誤りなのに、棄却しない誤り
- ポイント：「ぼんやり者の誤り」。起きる確率をβとすると、1−βが検出力。第1種を減らそうとすると第2種は増える

#### 検出力（けんしゅつりょく / Statistical Power）

- 意味：帰無仮説が誤りのとき、正しく棄却できる確率（1−β）
- ポイント：検定力ともいう。標本数を増やすと高くなる

#### t検定（てぃーけんてい / t-test）

- 意味：母集団の標準偏差が分からないとき、標本の平均の差が偶然かどうかを t分布を使って調べる検定
- ポイント：z検定は母集団の標準偏差が分かっている（または標本が大きい）ときに正規分布で調べる

#### z検定（ぜっとけんてい / z-test）

- 意味：母集団の標準偏差が分かっているときなどに、標準正規分布を使って平均の差を調べる検定
- ポイント：t検定との違いは、母集団の標準偏差を知っているかどうか

#### カイ二乗検定（かいにじょうけんてい / Chi-squared Test）

- 意味：観測された度数と、仮説から期待される度数のずれが偶然かどうかを、カイ二乗分布を使って調べる検定
- ポイント：アンケートの分割表で「性別と好みが独立か」を調べるような場面で使う。平均の差を調べるt検定と区別する

### 線形代数と数列

#### スカラ（Scalar）

- 意味：大きさだけをもち、向きをもたない1つの数
- ポイント：ベクトルは数を1列に、行列は2次元に、テンソルはそれ以上の次元に並べたもの

#### ベクトル（Vector）

- 意味：数を1列に並べたもので、大きさと向きをもつ量
- ポイント：AIでは単語や画像を数値のベクトルで表す。2つのベクトルの内積は、向きの近さ（類似度）の計算に使う

#### 行列（ぎょうれつ / Matrix）

- 意味：数を縦（列）と横（行）の長方形に並べたもの
- ポイント：m×n行列とn×p行列の積は m×p 行列。積は掛ける順番で結果が変わる（AB≠BA）

#### テンソル（Tensor）

- 意味：数を3次元以上に並べたもの（スカラ・ベクトル・行列を一般化したもの）
- ポイント：カラー画像は「縦×横×色」の3次元テンソル。ディープラーニングのデータの基本形

#### 単位行列（たんいぎょうれつ / Identity Matrix）

- 意味：対角線上がすべて1、それ以外がすべて0の正方行列
- ポイント：どんな行列に掛けても、その行列が変わらない（数の1にあたる）

#### 逆行列（ぎゃくぎょうれつ / Inverse Matrix）

- 意味：ある正方行列Aに掛けると単位行列になる行列 A^(−1)
- ポイント：いつも存在するとは限らない（行列式が0なら存在しない）。連立一次方程式を解くのに使う

#### 転置行列（てんちぎょうれつ / Transposed Matrix）

- 意味：行列の行と列を入れ替えた行列
- ポイント：m×n行列の転置は n×m 行列。逆行列（掛けて単位行列になる）とは別物

#### 固有値と固有ベクトル（こゆうち・こゆうべくとる / Eigenvalue / Eigenvector）

- 意味：正方行列Aに対して Ax＝λx が成り立つとき、λを固有値、0でないxを固有ベクトルという
- ポイント：行列を掛けても向きが変わらないベクトルと、そのときの倍率。主成分分析は、分散を表す行列の固有ベクトルの方向に新しい軸をとる

#### 等差数列（とうさすうれつ / Arithmetic Sequence）

- 意味：隣どうしの差が一定の数列
- ポイント：第n項は a＋(n−1)d。初項から第n項までの和は n(初項＋末項)÷2

#### 等比数列（とうひすうれつ / Geometric Sequence）

- 意味：隣どうしの比が一定の数列
- ポイント：二分法の区間の幅は 1, 1/2, 1/4… と公比1/2の等比数列で小さくなる

#### フィボナッチ数列（Fibonacci Sequence）

- 意味：前の2つの項を足して次の項を作る数列（1, 1, 2, 3, 5, 8, …）
- ポイント：再帰的なプログラムの例として出る。そのまま再帰で計算すると同じ計算を何度も繰り返すので、動的計画法で速くできる

#### 対数（たいすう / Logarithm）

- 意味：aを何乗するとxになるかを表す数（log_a x）
- ポイント：log₂(2^n)＝n。情報量の計算（−log₂p）や、2分探索の計算量 O(log n) に出る。log(xy)＝log x＋log y

### 数値解析

#### 二分法（にぶんほう / Bisection Method）

- 意味：f(a) と f(b) の符号が異なる区間を半分に分け、符号が変わる側を残すことを繰り返して、f(x)＝0 の解に近づける方法
- ポイント：1回ごとに区間の幅が1/2になるので、幅を 0.001 未満にするには 2^10＝1024 から 10回
- 例：R7春 問2（(2)の実行回数は10回）

#### ニュートン法（Newton's Method）

- 意味：解の近くの点で曲線 y＝f(x) の接線を引き、接線とx軸の交点を次の近似値とすることを繰り返して、f(x)＝0 の解を求める方法
- ポイント：初期値がよければ速く収束するが、初期値によっては収束しない。接線が引ける（微分できる）ことが条件
- 例：R3秋 問1で正解エ（手順の「接線」がキーワード）

#### ガウスの消去法（がうすのしょうきょほう / Gaussian Elimination）

- 意味：連立一次方程式で、式を何倍かして足し引きし、変数を一つずつ消していって解を求める方法
- ポイント：掃出法（はきだしほう）はこれを進めて、係数を対角線だけ1にする方法。f(x)＝0 を解く方法ではない
- 例：R3秋 問1の選択肢イ

#### オイラー法（Euler Method）

- 意味：微分方程式を、ある点での傾き（微分の値）を使って小さな幅ずつ値を進めることで、近似的に解く方法
- ポイント：方程式 f(x)＝0 の解ではなく、微分方程式の解の数値計算法。幅を小さくするほど精度が上がる
- 例：R3秋 問1の選択肢ア

#### シンプソン法（Simpson's Rule）

- 意味：積分する区間を細かく分け、それぞれを放物線で近似して面積を足し合わせ、定積分の値を求める方法
- ポイント：数値積分の方法。区間を直線（台形）で近似する台形公式より精度が高い
- 例：R3秋 問1の選択肢ウ

#### 台形公式（だいけいこうしき / Trapezoidal Rule）

- 意味：積分する区間を細かく分け、それぞれを台形とみなして面積を足し合わせ、定積分の値を求める方法
- ポイント：シンプソン法は放物線、台形公式は直線で近似する

#### 補間法（ほかんほう / Interpolation）

- 意味：分かっている点と点の間の値を、それらの点を通る直線や曲線で推定する方法
- ポイント：範囲の外を推定するのは補外（外挿）。線形補間は2点を直線で結ぶ

#### 収束（しゅうそく / Convergence）

- 意味：繰返し計算の結果が、ある値に限りなく近づいていくこと
- ポイント：近似解法では「前回との差が一定値以下になったら終了」として打ち切る。打ち切りによる誤差が打切り誤差

#### 数式処理（すうしきしょり / Computer Algebra）

- 意味：数値ではなく文字式のまま、因数分解・微分・積分などを記号的に計算すること
- ポイント：数値計算（近似値を求める）と違い、誤差のない正確な式が得られる

### グラフ理論

#### 無向グラフ（むこうぐらふ / Undirected Graph）

- 意味：頂点（ノード）を、向きのない辺（エッジ）で結んだグラフ
- ポイント：道路網や友人関係のように、行き来が対称な関係を表す

#### 有向グラフ（ゆうこうぐらふ / Directed Graph）

- 意味：頂点を、向き（矢印）のある辺で結んだグラフ
- ポイント：一方通行、作業の順序（PERT図）、Webのリンクを表す

#### 完全グラフ（かんぜんぐらふ / Complete Graph）

- 意味：すべての頂点どうしが、辺で直接結ばれているグラフ
- ポイント：頂点がn個なら辺は n(n−1)÷2 本。メッシュ型ネットワークの回線数の計算と同じ

#### 重みつきグラフ（おもみつきぐらふ / Weighted Graph）

- 意味：各辺に、距離・費用・時間などの数値（重み）を付けたグラフ
- ポイント：最短経路問題（ダイクストラ法）は、重みつきグラフで重みの合計が最小の経路を探す

#### 閉路（へいろ / Cycle）

- 意味：グラフで、ある頂点から辺をたどって、同じ辺を通らずに元の頂点へ戻る経路
- ポイント：閉路のない連結な無向グラフが木。閉路グラフはすべての頂点が1つの輪につながったグラフ

#### 正則グラフ（せいそくぐらふ / Regular Graph）

- 意味：すべての頂点の次数（つながる辺の数）が等しいグラフ
- ポイント：完全グラフも閉路グラフも正則グラフの一種

#### 木（き / Tree）

- 意味：閉路がなく、すべての頂点がつながっているグラフ
- ポイント：頂点がn個なら辺は必ず n−1 本。2分木・探索木などのデータ構造のもと

### 待ち行列

#### 待ち行列理論（まちぎょうれつりろん / Queueing Theory）

- 意味：窓口に客が到着してサービスを受けるしくみを確率で表し、待ち時間や行列の長さを求める理論
- ポイント：ケンドール記号「到着の分布/サービス時間の分布/窓口の数」で型を表す

#### M/M/1モデル（えむえむわん / M/M/1 Model）

- 意味：到着がポアソン分布（到着間隔が指数分布）、サービス時間が指数分布、窓口が1つの待ち行列モデル
- ポイント：平均待ち時間は ρ÷(1−ρ)×Ts。ρが1に近づくと待ち時間は急に長くなる。待ち行列の長さに制限がないことが前提
- 例：R3秋 問2＝R6春 問2、R4春 問3＝R6秋 問1、R7秋 問2

#### 平均到着率（へいきんとうちゃくりつ / Mean Arrival Rate）

- 意味：単位時間あたりに到着する客の平均の数（λ）
- ポイント：平均到着間隔の逆数。1時間に30人なら、平均到着間隔は2分

#### 平均サービス率（へいきんさーびすりつ / Mean Service Rate）

- 意味：単位時間あたりに窓口がサービスを終えられる客の平均の数（μ）
- ポイント：平均サービス時間の逆数。利用率 ρ＝λ÷μ

#### 平均サービス時間（へいきんさーびすじかん / Mean Service Time）

- 意味：客1人へのサービスにかかる時間の平均（Ts）
- ポイント：平均待ち時間（Wq）には含めない。応答時間＝待ち時間＋サービス時間

#### 利用率（りようりつ / Utilization）

- 意味：窓口がサービス中でふさがっている時間の割合（ρ＝平均到着率×平均サービス時間）
- ポイント：1未満でないと行列が無限に伸びる。2つの窓口の客を1つの窓口にまとめると、利用率は足し算になる
- 例：R3秋 問2（統合後の利用率は 2ρ）、R7秋 問2（平均待ち時間≧T になるのは利用率50%以上）

#### 平均待ち時間（へいきんまちじかん / Mean Waiting Time）

- 意味：客が到着してから、サービスを受け始めるまでの時間の平均
- ポイント：M/M/1 では ρ÷(1−ρ)×Ts。利用率0.5で待ち時間＝サービス時間、0.8で4倍、0.9で9倍

### 最適化問題

#### 線形計画法（せんけいけいかくほう / Linear Programming）

- 意味：一次式で表した制約条件のもとで、一次式で表した目的（利益など）を最大または最小にする値を求める方法
- ポイント：2変数ならグラフの制約の交点（端の点）を調べる。資源の配分や生産計画の問題に出る

#### 動的計画法（どうてきけいかくほう / Dynamic Programming）

- 意味：大きな問題を小さな部分問題に分け、部分問題の答えを表に記録して使い回しながら解く方法
- ポイント：同じ部分問題を何度も解かないので速い。分割統治法は部分問題が重ならない場合の考え方

#### ナップサック問題（Knapsack Problem）

- 意味：重さの上限がある袋に、重さと価値が決まった品物を詰めるとき、価値の合計が最大になる組合せを求める問題
- ポイント：組合せ最適化問題の代表。品物の数が増えると組合せが爆発的に増える。動的計画法で解ける

#### 巡回セールスマン問題（じゅんかいせーるすまんもんだい / Traveling Salesman Problem）

- 意味：すべての都市を1回ずつ訪れて出発点に戻る経路のうち、移動距離の合計が最小のものを求める問題
- ポイント：NP困難の代表で、都市が増えると厳密に解くのが難しい。実用では近似解法を使う

#### 最短経路問題（さいたんけいろもんだい / Shortest Path Problem）

- 意味：重みつきグラフで、2つの頂点を結ぶ経路のうち、重みの合計が最小のものを求める問題
- ポイント：ダイクストラ法で効率よく解ける（重みが負でない場合）。ルーティング（OSPF）でも使う

#### 組合せ最適化問題（くみあわせさいてきかもんだい / Combinatorial Optimization）

- 意味：とりうる候補が有限個の組合せの中から、最もよいものを選ぶ問題の総称。ナップサック問題・巡回セールスマン問題・最短経路問題もこれにあたる
- ポイント：ナップサック問題・巡回セールスマン問題が代表。変数が連続した値をとる連続最適化問題と対になる

#### 連続最適化問題（れんぞくさいてきかもんだい / Continuous Optimization）

- 意味：変数が連続した実数の値をとるとき、目的の値を最大または最小にする問題の総称。線形計画法で解く問題はこれにあたる
- ポイント：線形計画法や、機械学習の誤差を小さくする勾配降下法が代表

### まとめ表

**情報量の計算**

| 求めるもの | 式 | 例 |
| :-: | :-: | :-: |
| 確率pの出来事が起きたと知ったときの情報量 | −log₂ p ビット | 確率1/8なら 3ビット |

| 量子化 | 1回の値を何ビットで表すか（量子化ビット数） | ビット数に比例 |
| 符号化 | 量子化した値を0と1の並びにする | ― |

| 指標 | 式 | ひと言で |
| :-: | :-: | :-: |
| 正解率（Accuracy） | (TP＋TN)÷全体 | 全部のうち当たった割合 |
| 適合率（Precision） | TP÷(TP＋FP) | 陽性と予測したうち本当に陽性 |
| 再現率（Recall）＝真陽性率 | TP÷(TP＋FN) | 本当の陽性のうち見つけられた割合 |
| 偽陽性率 | FP÷(FP＋TN) | 本当は陰性なのに陽性と予測した割合 |
| 特異度＝真陰性率 | TN÷(FP＋TN) | 本当の陰性のうち陰性と当てた割合（1−偽陽性率） |
| F値 | 2×適合率×再現率÷(適合率＋再現率) | 適合率と再現率の調和平均 |

ROC曲線＝横軸が偽陽性率、縦軸が真陽性率（R5春 問3、R7秋 問3）。PR曲線＝適合率と再現率。AUC＝ROC曲線の下の面積（1に近いほどよい）。

### 情報量と符号

#### 情報量（じょうほうりょう / Amount of Information）

- 意味：ある出来事が起きたと知ったときに得られる情報の大きさ。確率pの出来事なら −log₂ p ビット
- ポイント：めったに起きないことほど大きい。確率1の出来事（必ず起きる）の情報量は0

#### 平均情報量（へいきんじょうほうりょう / Entropy）

- 意味：起こりうる出来事それぞれの情報量を、その確率で重み付けして平均した値（エントロピー）
- ポイント：情報源の「不確かさ」を表す。圧縮して1記号あたり何ビットまで減らせるかの下限になる

#### 標本化（ひょうほんか / Sampling）

- 意味：連続したアナログ信号から、一定の時間間隔で値を取り出すこと
- ポイント：1秒間に取り出す回数がサンプリング周波数。もとの信号の最高周波数の2倍以上で取り出せば、もとの波形を復元できる（サンプリング定理）
- 例：R3春 問3（サンプリング周波数40kHz）

#### 量子化（りょうしか / Quantization）

- 意味：標本化で取り出した値を、決められた段階のどれかに近似して、整数の値にすること
- ポイント：段階の数を量子化ビット数で表す（16ビットなら65,536段階）。近似で生じる差が量子化誤差
- 例：R3春 問3（量子化ビット数16ビット）

#### 符号化（ふごうか / Encoding）

- 意味：A/D変換の最後の段階で、量子化した値を決められた規則で0と1のビット列に置き換えること
- ポイント：A/D変換は「標本化→量子化→符号化」の順。データ圧縮のための符号化（情報源符号化）と、誤り対策のための符号化（通信路符号化）がある

#### A/D変換（えーでぃーへんかん / Analog to Digital Conversion）

- 意味：連続的に変わるアナログ信号を、標本化・量子化・符号化でデジタルデータに変えること
- ポイント：1秒間のデータ量＝サンプリング周波数×量子化ビット数（×チャネル数）
- 例：R3春 問3（40kHz×16ビット÷8＝80kバイト）

#### 情報源符号化（じょうほうげんふごうか / Source Coding）

- 意味：データの偏りを利用して、元の情報をなるべく短いビット列で表すための符号化（データ圧縮）の総称。ハフマン符号・ランレングス符号化が代表
- ポイント：ハフマン符号・ランレングス符号化が代表。通信路符号化は逆に冗長ビットを足して誤りに強くする

#### 通信路符号化（つうしんろふごうか / Channel Coding）

- 意味：伝送中の誤りを検出・訂正できるよう、データに冗長なビットを付け加える符号化
- ポイント：パリティ・CRC・ハミング符号が代表。データは長くなるが信頼性が上がる

#### ハフマン符号（ハフマンふごう / Huffman Code）

- 意味：出現する確率が高い文字ほど短いビット列を割り当てて、全体の平均の長さを短くする可変長の符号
- ポイント：出現確率の小さい2つを順にまとめて木を作る。どの符号も別の符号の先頭部分にならない（一意に区切れる）
- 例：符号の平均長＝各文字の（出現確率×ビット数）の合計

#### ランレングス符号化（Run-Length Encoding）

- 意味：同じ値が続く部分を「値と、続く個数」の組に置き換えて短くする圧縮方式
- ポイント：白黒の画像やFAXのように同じ値が長く続くデータで効果が大きい。値がばらばらだと逆に長くなる
- 語の意味：Run＝連続／Length＝長さ／Encoding＝符号化

#### 可逆圧縮（かぎゃくあっしゅく / Lossless Compression）

- 意味：圧縮したデータを、元のデータと完全に同じに戻せる圧縮の種類。ハフマン符号やランレングス符号化を使う方式はこれにあたる
- ポイント：ZIP、PNG、ハフマン符号、ランレングス符号化。非可逆圧縮（JPEG、MP3）は一部の情報を捨てるので完全には戻らないが、圧縮率が高い

#### 非可逆圧縮（ひかぎゃくあっしゅく / Lossy Compression）

- 意味：人が気づきにくい情報を捨てることで圧縮率を高め、元のデータに完全には戻らない圧縮
- ポイント：JPEG・MPEG・MP3 が代表。プログラムや文書には使えない

### 文字コード

#### ASCIIコード（あすきー / American Standard Code for Information Interchange）

- 意味：英数字と記号、制御文字を7ビットで表す、米国で定められた文字コード
- ポイント：128文字だけで、日本語は表せない。多くの文字コードの英数字部分はASCIIと同じ
- 語の意味：American＝米国の／Standard＝標準／Code＝符号／Information＝情報／Interchange＝交換

#### JISコード（じすこーど / JIS Code）

- 意味：日本産業規格（JIS）で定めた日本語の文字コードで、エスケープシーケンスで英数字と漢字を切り替えるもの
- ポイント：電子メールで使われてきた。シフトJISは切替えなしで混在させる方式

#### シフトJISコード（Shift JIS）

- 意味：英数字（1バイト）と漢字（2バイト）を、切替えの記号なしで混在させられるようにした日本語の文字コード
- ポイント：Windowsで広く使われた。漢字の1バイト目に、英数字に使わない範囲の値を使って見分ける

#### EUC（いーゆーしー / Extended UNIX Code）

- 意味：UNIX系のOSで日本語などを扱うために作られた、ASCIIを拡張した文字コード
- ポイント：漢字は2バイトとも最上位ビットを1にして、英数字と区別する
- 語の意味：Extended＝拡張された／UNIX＝OSの名前／Code＝符号

#### Unicode（ユニコード）

- 意味：世界中の文字を一つの体系で表すために、各文字に固有の番号（コードポイント）を割り当てた、業界団体が定めた文字コード。国際規格のUCSと番号を共通にしている
- ポイント：符号化の方式に UTF-8（1〜4バイトの可変長、英数字はASCIIと同じ1バイト）、UTF-16 などがある

#### UCS（ゆーしーえす / Universal Coded Character Set）

- 意味：ISO/IEC 10646 で定められた、世界の文字を一つにまとめた国際規格の文字集合。業界団体が定めたUnicodeと番号を共通にしている
- ポイント：Unicode と同じ文字の番号を使うよう、そろえて運用されている
- 語の意味：Universal＝全世界の／Coded＝符号化された／Character Set＝文字集合

#### UTF-8（ゆーてぃーえふえいと）

- 意味：Unicodeの文字を1〜4バイトの可変長で表す符号化方式
- ポイント：英数字はASCIIと同じ1バイト、日本語のかな・漢字はほとんど3バイト。Webで最も使われている
- 語の意味：UTF＝UCS Transformation Format（UCS変換形式）

### 形式言語と表記法

#### 形式言語（けいしきげんご / Formal Language）

- 意味：決められた記号の集まりと、文法の規則によって厳密に定義された言語
- ポイント：プログラム言語の文法は形式言語で定義する。正規表現で表せる言語は有限オートマトンで受理できる

#### BNF（びーえぬえふ / Backus-Naur Form）

- 意味：プログラム言語などの文法を、「::＝」（定義）と「｜」（または）などの記号で定義する記法
- ポイント：自分自身を使って定義（再帰）することで、繰返しを表す。〈数字〉::＝0｜1｜…｜9 のように書く
- 語の意味：Backus・Naur＝考案者の名前／Form＝記法

#### 構文図式（こうぶんずしき / Syntax Diagram）

- 意味：文法の規則を、矢印でつないだ箱や円の図で表したもの
- ポイント：BNFと同じ内容を図で表す。矢印をたどれる並びが、文法に合った文

#### 正規表現（せいきひょうげん / Regular Expression）

- 意味：文字列のパターンを、「*」（0回以上の繰返し）「|」（または）などの特殊な記号を使って表す記法
- ポイント：[0-9]+ は数字1文字以上の並び。表せる言語は有限オートマトンで受理できる言語と同じ

#### 文脈自由文法（ぶんみゃくじゆうぶんぽう / Context-Free Grammar）

- 意味：生成規則の左辺が1つの非終端記号だけでできていて、前後の文脈に関係なく置き換えられる文法
- ポイント：プログラム言語の構文の定義に使われ、BNFで書ける。カッコの対応のように、正規表現では表せない構造も表せる。プッシュダウンオートマトンで受理できる

#### 中置記法（ちゅうちきほう / Infix Notation）

- 意味：演算子を2つのオペランドの間に書く、ふつうの数式の書き方（A＋B）
- ポイント：演算の順番を決めるのにカッコと優先順位が必要。コンピュータでは後置記法に変えてから計算する

#### 逆ポーランド表記法（ぎゃくぽーらんど / Reverse Polish Notation）

- 意味：演算子をオペランドの後ろに書く記法（後置記法）。A＋B は AB＋
- ポイント：カッコがいらず、スタックで左から順に計算できる。数を積み、演算子が来たら上の2つを取り出して計算し、結果を積む
- 例：R5秋 問3（ABCD−×＋ → A＋B×(C−D) ＝ 32）、R6秋 問3（A＋B×C → ABC×＋）

#### ポーランド表記法（Polish Notation）

- 意味：演算子をオペランドの前に書く記法（前置記法）。A＋B は ＋AB
- ポイント：逆ポーランド（後置）と区別する。R6秋 問3 の ×＋ABC のような選択肢は前置の形

#### 構文木（こうぶんぎ / Syntax Tree）

- 意味：式や文の構造を、演算子を節、オペランドを葉とする木で表したもの
- ポイント：構文木を「左→右→根」の順（後行順）にたどると逆ポーランド表記になる

### オートマトン

#### 有限オートマトン（ゆうげんおーとまとん / Finite Automaton）

- 意味：有限個の状態をもち、入力された記号によって次の状態へ移る、計算のモデル
- ポイント：入力を読み終えたとき受理状態にいれば、その文字列を受理する。状態遷移表・状態遷移図で表す。受理できる言語は正規表現で表せる言語と同じ

#### 状態遷移図（じょうたいせんいず / State Transition Diagram）

- 意味：状態を円、入力による状態の移り変わりを矢印で表した図
- ポイント：開始状態は矢印で、受理状態は二重丸で示すことが多い

#### 状態遷移表（じょうたいせんいひょう / State Transition Table）

- 意味：「現在の状態」と「入力」の組合せごとに、次の状態を書き込んだ表
- ポイント：状態遷移図と同じ内容を表にしたもの。抜けている組合せを見つけやすい

#### プッシュダウンオートマトン（Pushdown Automaton）

- 意味：有限オートマトンに、スタックを記憶として加えた計算のモデル
- ポイント：カッコの対応のような入れ子の構造を扱える。受理できる言語は文脈自由文法で表せる言語と同じ

#### チューリング機械（チューリングきかい / Turing Machine）

- 意味：無限に長いテープと読み書きヘッド、有限個の状態だけで、あらゆる計算手順を表せるとした計算のモデル
- ポイント：コンピュータで計算できることの理論上の基準。チューリング機械で解けない問題の代表が停止問題

### 推論と正当性

#### 述語論理（じゅつごろんり / Predicate Logic）

- 意味：「xは人間である」のように変数を含む文（述語）と、「すべてのxについて」「あるxが存在する」を扱える論理
- ポイント：命題論理より表現力が高い。関係データベースの問合せや論理型言語（Prolog）の土台

#### 演繹推論（えんえきすいろん / Deductive Reasoning）

- 意味：一般的な法則や前提から、個別の結論を論理的に導く推論
- ポイント：三段論法が代表。前提が正しければ結論も必ず正しい。エキスパートシステムはルールから演繹的に推論する

#### 帰納推論（きのうすいろん / Inductive Reasoning）

- 意味：多くの個別の事例から、一般的な法則を導く推論
- ポイント：機械学習はデータから規則を見つける帰納的な方法。結論が必ず正しいとは限らない

#### 部分正当性（ぶぶんせいとうせい / Partial Correctness）

- 意味：プログラムが停止したならば、その結果が正しいという性質
- ポイント：停止するかどうかは問わない。全正当性＝部分正当性＋必ず停止すること

#### 全正当性（ぜんせいとうせい / Total Correctness）

- 意味：プログラムが必ず停止し、かつ結果が正しいという性質
- ポイント：部分正当性に「停止性」を加えたもの

#### 停止問題（ていしもんだい / Halting Problem）

- 意味：任意のプログラムと入力に対して、そのプログラムが停止するかどうかを判定する問題
- ポイント：これを一般に判定できるアルゴリズムは存在しない（決定不能）ことが証明されている

### 計算量

#### 時間計算量（じかんけいさんりょう / Time Complexity）

- 意味：入力の大きさnに対して、アルゴリズムの処理にかかる手間（ステップ数）の増え方
- ポイント：オーダー記号で表す。O(log n) ＜ O(n) ＜ O(n log n) ＜ O(n²) ＜ O(2^n) の順に遅くなる

#### 領域計算量（りょういきけいさんりょう / Space Complexity）

- 意味：入力の大きさnに対して、アルゴリズムが使う記憶領域の量の増え方
- ポイント：時間計算量と引換えになることが多い（表を作って速くすると、記憶領域が増える）

#### オーダー記号（Big O Notation）

- 意味：計算量を、nが大きくなったときに最も効いてくる項だけで表す記法（O(n²) など）
- ポイント：係数と小さい項は無視する。3n²＋5n は O(n²)

#### P問題（ぴーもんだい / Polynomial）

- 意味：多項式時間（nのべき乗程度の手間）で解けることが分かっている問題の集まり
- ポイント：整列や最短経路問題はP。NP問題は「答えが与えられれば多項式時間で正しいか確かめられる」問題

#### NP問題（えぬぴーもんだい / Nondeterministic Polynomial）

- 意味：答えの候補が与えられれば、それが正しいかを多項式時間で確かめられる問題の集まり
- ポイント：P問題はすべてNPに含まれる。P＝NPかどうかは未解決
- 語の意味：Nondeterministic＝非決定性の／Polynomial＝多項式

#### NP完全問題（えぬぴーかんぜんもんだい / NP-complete）

- 意味：NP問題の中で最も難しく、どのNP問題もこれに変換できる問題の集まり
- ポイント：一つでも多項式時間で解ければ、すべてのNP問題が解ける。ナップサック問題（判定版）、巡回セールスマン問題（判定版）など

### AIの基本的な考え方
#### ニューラルネットワーク（Neural Network）

- 意味：脳の神経細胞（ニューロン）のつながりをまね、入力に重みを掛けて足し合わせ、活性化関数を通して出力する素子を多数つないだモデル
- ポイント：入力層・中間層（隠れ層）・出力層からなる。中間層を多くしたものがディープラーニング


#### 機械学習（きかいがくしゅう / Machine Learning）

- 意味：人が規則を書くのではなく、コンピュータがデータから規則やパターンを学び、予測や判断をする技術
- ポイント：教師あり・教師なし・強化学習の3つが基本。ディープラーニングは機械学習の一つの手法



#### エキスパートシステム（Expert System）

- 意味：特定の分野の専門家の知識をルールとして蓄え、推論によって専門家と同じレベルの判断を行うシステム
- ポイント：知識ベース（ルールの集まり）と推論エンジン（ルールを使って結論を出す部分）でできている。データから学習するディープラーニングとは別
- 例：R3秋 問3の選択肢ア、R6春 問3の選択肢エ

#### 知識ベース（ちしきべーす / Knowledge Base）

- 意味：エキスパートシステムで、専門家の知識を「もし〜ならば〜」のルールや事実として蓄えた部分
- ポイント：推論エンジンが知識ベースを使って結論を導く。知識を集めて形にする技術が知識工学

#### 推論エンジン（すいろんえんじん / Inference Engine）

- 意味：知識ベースのルールと与えられた事実から、結論を導く処理を行う部分
- ポイント：前向き推論（事実からルールを当てはめていく）と後ろ向き推論（結論から確かめる）がある

#### 知識工学（ちしきこうがく / Knowledge Engineering）

- 意味：専門家の知識を引き出して整理し、コンピュータで使える形に表すための技術
- ポイント：エキスパートシステムを作るときの中心となる技術

#### 遺伝的アルゴリズム（いでんてきあるごりずむ / Genetic Algorithm）

- 意味：生物の進化をまね、解の候補を遺伝子に見立てて、突然変異・交叉・淘汰を繰り返し、よりよい解に近づける方法
- ポイント：最適解が保証されるわけではないが、組合せが膨大な問題で使われる
- 例：R3秋 問3の選択肢エ

#### バックトラック法（Backtracking）

- 意味：場合分けを深さ優先でたどって解を探し、行き詰まったら一つ前の分かれ道に戻って別の道を試す方法
- ポイント：8クイーン問題や迷路の探索で使う。AIの学習の方法ではなく、探索の方法
- 例：R3秋 問3の選択肢イ

#### データマイニング（Data Mining）

- 意味：大量のデータを分析して、これまで知られていなかった規則やパターンを見つけ出すこと
- ポイント：統計やクラスタ分析、機械学習の手法を使う。R6春 問3 の誤りの選択肢イ・ウは、ディープラーニングではなくこうした分析の説明

### 学習の種類

#### 教師あり学習（きょうしありがくしゅう / Supervised Learning）

- 意味：入力と正解（ラベル）の組を大量に与えて、入力から正解を予測する規則を学ばせる学習
- ポイント：数値を予測するのが回帰、グループを当てるのが分類。交差検証や過学習は主に教師あり学習の話

#### 教師なし学習（きょうしなしがくしゅう / Unsupervised Learning）

- 意味：正解を与えずに、データそのものの構造や特徴を見つけさせる学習
- ポイント：似たものを集めるクラスタリング（k-means法）、変数を減らす次元削減（主成分分析）が代表

#### 半教師あり学習（はんきょうしありがくしゅう / Semi-supervised Learning）

- 意味：正解付きの少しのデータと、正解のない大量のデータを組み合わせて学習する方法
- ポイント：正解を付ける（アノテーション）手間を減らすために使う

#### 強化学習（きょうかがくしゅう / Reinforcement Learning）

- 意味：環境の中で行動を試し、その結果として得られる報酬が最大になるような行動の仕方を学ぶ学習
- ポイント：正解のデータではなく「報酬」で学ぶ。ゲームやロボットの制御に使う。Q学習が代表
- 例：R4秋 問4の選択肢エ（報酬を与えて何が成功か分かるようにする）

#### 自己教師あり学習（じこきょうしありがくしゅう / Self-supervised Learning）

- 意味：データの一部を隠して残りから当てさせるなど、データ自身から正解を作り出して学習する方法
- ポイント：人が正解を付けなくても大量のデータで学べる。大規模言語モデルの事前学習（次の単語を当てる）がこれ

#### 回帰（かいき / Regression）

- 意味：教師あり学習で、売上や気温のような連続した数値を予測すること
- ポイント：分類は「どのグループか」を当てる。ロジスティック回帰は名前に反して分類に使う

#### 分類（ぶんるい / Classification）

- 意味：教師あり学習で、入力がどのクラス（グループ）に属するかを予測すること
- ポイント：2クラス分類のモデルは、混同行列・ROC曲線で評価する。正解なしでグループに分けるのはクラスタリング

#### クラスタリング（Clustering）

- 意味：教師なし学習で、データの似ているものどうしを集めてグループに分けること
- ポイント：グループの意味は後から人が解釈する。分類（正解のクラスを学ぶ）と区別する

#### 次元削減（じげんさくげん / Dimensionality Reduction）

- 意味：教師なし学習で、データの特徴をなるべく保ったまま、変数（次元）の数を減らすこと
- ポイント：主成分分析が代表。可視化や計算量の削減に使う

### 機械学習の代表的な手法

#### 線形回帰（せんけいかいき / Linear Regression）

- 意味：説明変数の一次式（直線や平面）で、目的変数の数値を予測する手法
- ポイント：係数は最小二乗法で決める。回帰の最も基本的なモデル

#### 決定木（けっていぎ / Decision Tree）

- 意味：「年齢は30歳以上か」のような条件で枝分かれを繰り返し、木の形で分類や予測を行う手法
- ポイント：判断の理由を人が読める。木を深くしすぎると過学習しやすい

#### ランダムフォレスト（Random Forest）

- 意味：データや変数をランダムに選んで多数の決定木を作り、その多数決や平均で予測する手法
- ポイント：アンサンブル学習の代表。1本の決定木より過学習しにくい

#### サポートベクトルマシン（Support Vector Machine）

- 意味：2つのクラスの境界線を、境界に最も近いデータ（サポートベクトル）との距離（マージン）が最大になるように引く分類の手法
- ポイント：マージン最大化がキーワード。曲がった境界も扱える（カーネル法）

#### k-means法（けーみーんずほう / k-means Clustering）

- 意味：データをk個のグループに分けるため、各グループの中心を決めては、各データを最も近い中心のグループに入れ直すことを繰り返す手法
- ポイント：教師なし学習のクラスタリング。グループ数kは人が先に決める

#### Q学習（きゅーがくしゅう / Q-learning）

- 意味：強化学習で、各状態でそれぞれの行動をとったときの将来の報酬の見込み（Q値）を表にして、試行を重ねながら更新していく手法
- ポイント：Q値が最大の行動を選べばよい。Q値の計算にニューラルネットワークを使うのが深層強化学習（DQN）

#### 方策勾配法（ほうさくこうばいほう / Policy Gradient Method）

- 意味：強化学習で、どの行動をどの確率で選ぶか（方策）を直接パラメータで表し、報酬が増える方向へ少しずつ調整する手法
- ポイント：Q学習が「行動の価値」を学ぶのに対し、方策そのものを学ぶ

#### 価値反復法（かちはんぷくほう / Value Iteration）

- 意味：強化学習で、各状態の価値（将来得られる報酬の見込み）の計算を収束するまで繰り返し、最適な行動を求める手法
- ポイント：環境の遷移の確率が分かっている場合に使う。動的計画法の考え方

### 学習の進め方と検証

#### 訓練データ（くんれんでーた / Training Data）

- 意味：モデルのパラメータを学習させるために使うデータ（学習データ）
- ポイント：訓練データでの誤差が訓練誤差。訓練データでいくら精度が高くても、汎化性能が高いとは限らない

#### 検証データ（けんしょうでーた / Validation Data）

- 意味：学習中に、ハイパーパラメータの調整やモデルの選択のために精度を確かめるデータ
- ポイント：訓練データとも、最終評価用のテストデータとも分けておく

#### テストデータ（Test Data）

- 意味：学習が終わったモデルの性能（汎化性能）を最後に評価するためだけに使う、学習に使っていないデータ
- ポイント：訓練データをテストデータに使うと、過学習を見逃す
- 例：R7春 問3の選択肢ア（訓練データをテストデータとして使用するのは誤り）

#### ハイパーパラメータ（Hyperparameter）

- 意味：学習率や決定木の深さなど、学習の前に人が決めておく設定値
- ポイント：重みのように学習で自動的に決まるパラメータとは別。グリッドサーチ・ランダムサーチで探す

#### 学習率（がくしゅうりつ / Learning Rate）

- 意味：1回の学習で、誤差を減らす方向へパラメータをどれだけ大きく動かすかを決めるハイパーパラメータ
- ポイント：大きすぎると最適な値を飛び越えて収束せず、小さすぎると学習に時間がかかる

#### グリッドサーチ（Grid Search）

- 意味：ハイパーパラメータの候補の値をすべて組み合わせて試し、最もよい組合せを探す方法
- ポイント：確実だが組合せが多いと時間がかかる。ランダムサーチは組合せをランダムに選んで試す

#### ランダムサーチ（Random Search）

- 意味：ハイパーパラメータの組合せをランダムに選んで試し、よいものを探す方法
- ポイント：グリッドサーチより少ない回数でよい組合せが見つかることが多い

#### ホールドアウト検証（Holdout Validation）

- 意味：データを訓練用と評価用に1回だけ分け、訓練用で学習して評価用で精度を確かめる方法
- ポイント：手軽だが、分け方の偶然で結果がぶれる。交差検証は分け方を変えて何度も行う

#### 交差検証（こうさけんしょう / Cross Validation）

- 意味：データを複数のグループに分け、一部で学習・残りで評価することを、グループを入れ替えながら繰り返して、汎化性能を評価する方法
- ポイント：k分割交差検証が代表。すべてのデータが一度は評価に使われる
- 例：R6秋 問2で正解エ

### 汎化性能を高める工夫

#### 汎化性能（はんかせいのう / Generalization Performance）

- 意味：学習に使っていない未知のデータに対して、どれだけ正しく予測できるかという性能
- ポイント：これを高めることが機械学習の目的。「汎化性能を下げる」は誤り
- 例：R7春 問3の選択肢エ（汎化性能を下げるのは誤り）

#### 汎化誤差（はんかごさ / Generalization Error）

- 意味：未知のデータに対するモデルの予測の誤差
- ポイント：訓練誤差は小さいのに汎化誤差が大きい状態が過学習

#### 訓練誤差（くんれんごさ / Training Error）

- 意味：学習に使った訓練データに対するモデルの予測の誤差
- ポイント：モデルを複雑にするほど小さくなるが、汎化誤差は小さくなるとは限らない

#### 過学習（かがくしゅう / Overfitting）

- 意味：訓練データに合わせすぎた結果、訓練データでは精度が高いのに、未知のデータでは精度が下がる状態
- ポイント：対策は訓練データを増やす（データ拡張）、正則化、ドロップアウト、モデルを単純にすること。モデルをもっと複雑にするのは逆効果
- 例：R4秋 問4で正解イ、R7春 問3（解消方法はイの訓練データを増やす）

#### データ拡張（でーたかくちょう / Data Augmentation）

- 意味：元の訓練データに回転・反転・ノイズの追加などの加工をして、訓練データの量を増やす方法
- ポイント：過学習を防ぐ代表的な対策
- 例：R7春 問3で正解イ（元の訓練データに加工を施し，訓練データの量を増やす）

#### 正則化（せいそくか / Regularization）

- 意味：モデルの複雑さを表すペナルティ（罰則）を誤差に加えて、訓練データに合わせすぎないように学習させる方法
- ポイント：過学習を防ぐ方法。パラメータが大きくなりすぎるのを抑える
- 例：R6秋 問2の選択肢ア

#### アンサンブル学習（Ensemble Learning）

- 意味：複数のモデルで学習し、その予測を多数決や平均などで組み合わせて、精度を高める方法
- ポイント：ランダムフォレストが代表。交差検証（評価の方法）と混同しない
- 例：R6秋 問2の選択肢イ

#### マルチタスク学習（Multi-task Learning）

- 意味：一つのモデルで関連する複数の課題を同時に学習させ、課題に共通する特徴を身につけさせる方法
- ポイント：汎化性能を「高める」ための方法。交差検証は汎化性能を「評価する」方法
- 例：R6秋 問2の選択肢ウ

#### バイアスとバリアンスのトレードオフ（Bias-Variance Tradeoff）

- 意味：モデルを単純にすると予測の偏り（バイアス）が大きくなり、複雑にすると訓練データによる予測のばらつき（バリアンス）が大きくなるという関係
- ポイント：バイアスが大きいと学習不足、バリアンスが大きいと過学習。両方を小さくするちょうどよい複雑さを探す

#### AIのロバスト性（ろばすとせい / Robustness）

- 意味：入力に小さな変化や雑音が加わっても、AIの出力が大きく変わらずに正しく動く性質
- ポイント：人には分からない加工で誤認識させる敵対的サンプルへの強さもこれにあたる

### モデルの評価指標

#### 混同行列（こんどうぎょうれつ / Confusion Matrix）

- 意味：2クラス分類で、予測（陽性・陰性）と実際（陽性・陰性）の組合せごとに件数を数えた2×2の表
- ポイント：真陽性（TP）・偽陽性（FP）・偽陰性（FN）・真陰性（TN）の4つ。各指標はこの表から計算する

#### 正解率（せいかいりつ / Accuracy）

- 意味：全データのうち、予測が当たった（陽性を陽性、陰性を陰性と予測した）データの割合
- ポイント：陽性がごく少ないデータでは、全部陰性と予測しても正解率が高くなってしまう

#### 適合率（てきごうりつ / Precision）

- 意味：陽性と予測したデータのうち、実際に陽性だったデータの割合（TP÷(TP＋FP)）
- ポイント：「当たりと言ったものがどれだけ本当に当たりか」。誤検知を減らしたいときに重視する

#### 再現率（さいげんりつ / Recall）

- 意味：実際に陽性のデータのうち、陽性と正しく予測できたデータの割合（TP÷(TP＋FN)）
- ポイント：真陽性率ともいい、ROC曲線の縦軸。見逃しを減らしたいとき（病気の検査など）に重視する。適合率とはトレードオフ
- 例：R5春 問3（ROC曲線は真陽性率と偽陽性率の関係）

#### F値（えふち / F-measure）

- 意味：適合率と再現率の調和平均（2×適合率×再現率÷(適合率＋再現率)）
- ポイント：どちらか一方だけが高くても大きくならない。両方のバランスを1つの値で見る

#### 偽陽性率（ぎようせいりつ / False Positive Rate）

- 意味：実際には陰性のデータのうち、誤って陽性と予測したデータの割合（FP÷(FP＋TN)）
- ポイント：ROC曲線の横軸。1−特異度。分母は「実際に陰性の件数」で、予測した件数ではない
- 例：R7秋 問3で正解イ（実際に“間違い”のデータに対し，誤って“正しい”と予測した割合）

#### 特異度（とくいど / Specificity）

- 意味：実際には陰性のデータのうち、陰性と正しく予測できたデータの割合（真陰性率）
- ポイント：1−偽陽性率。R7秋 問3 のウはこの説明
- 例：R7秋 問3の選択肢ウ

#### ROC曲線（あーるおーしーきょくせん / Receiver Operating Characteristic Curve）

- 意味：2クラス分類で、判定の基準（しきい値）を変えたときの、偽陽性率（横軸）と真陽性率（縦軸）の関係を描いた曲線
- ポイント：左上に寄るほどよいモデル。曲線の下の面積がAUC。適合率と再現率の関係はPR曲線
- 例：R5春 問3で正解ア
- 語の意味：Receiver＝受信者／Operating＝動作／Characteristic＝特性（もとはレーダーの信号検出の評価に使われた）

#### PR曲線（ぴーあーるきょくせん / Precision-Recall Curve）

- 意味：しきい値を変えたときの、再現率（横軸）と適合率（縦軸）の関係を描いた曲線
- ポイント：陽性がごく少ないデータの評価に向く。ROC曲線（真陽性率と偽陽性率）と取り違えない
- 例：R5春 問3の選択肢イ（真陽性率＝再現率と適合率の関係）はPR曲線

#### AUC（えーゆーしー / Area Under the Curve）

- 意味：ROC曲線の下側の面積で、分類モデルの性能を0〜1の値で表したもの
- ポイント：1に近いほどよく、0.5はでたらめに予測した場合と同じ
- 語の意味：Area＝面積／Under＝下の／Curve＝曲線

### ディープラーニングのしくみ

#### ディープラーニング（深層学習 / Deep Learning）

- 意味：脳の神経回路をまねたニューラルネットワークを何層にも重ね、データから特徴を自動で学習する機械学習の手法
- ポイント：層の間をつなぐ重み（パラメータ）を調整して学ぶ。特徴を人が設計しなくてよい点が従来の機械学習との違い
- 例：R3秋 問3で正解ウ、R6春 問3で正解ア

#### 多層パーセプトロン（たそうパーセプトロン / Multilayer Perceptron）

- 意味：入力層と出力層の間に中間層をもち、層ごとに全部の素子がつながった、基本的なニューラルネットワーク
- ポイント：中間層のない単純パーセプトロンは、直線で分けられる問題しか解けない（XORが解けない）

#### 誤差逆伝播法（ごさぎゃくでんぱほう / Backpropagation）

- 意味：出力と正解の誤差を、出力層から入力層の向きに逆にたどって伝え、各層の重みを誤差が小さくなる方向へ調整する学習の方法
- ポイント：ニューラルネットワークの学習の基本。「結果側から逆方向に」がキーワード
- 例：R4秋 問4の選択肢ウ（過学習の説明ではない）

#### 勾配消失問題（こうばいしょうしつもんだい / Vanishing Gradient Problem）

- 意味：層が深いネットワークで誤差を逆向きに伝えるとき、勾配（調整の手がかり）が層ごとに小さくなり、入力に近い層がほとんど学習されなくなる問題
- ポイント：シグモイド関数を使うと起きやすい。ReLU関数を使うと起きにくい

#### 活性化関数（かっせいかかんすう / Activation Function）

- 意味：ニューラルネットワークの各素子で、入力の重み付き和を、出力の値に変換する関数
- ポイント：非線形の関数を使うことで、複雑な関係を表せる。ReLU・シグモイド・tanh・ソフトマックスなど

#### ReLU関数（れる / Rectified Linear Unit）

- 意味：入力が0以下なら0、0より大きければ入力をそのまま出力する活性化関数
- ポイント：計算が簡単で、勾配消失が起きにくいため、中間層でよく使われる
- 語の意味：Rectified＝整流された（マイナスを切り捨てた）／Linear＝線形の／Unit＝素子

#### シグモイド関数（Sigmoid Function）

- 意味：入力を0〜1の範囲の値に変換する、なめらかなS字形の関数
- ポイント：2クラス分類の出力（確率）やロジスティック回帰に使う。層が深いと勾配消失が起きやすい

#### tanh関数（たんじぇんとはいぱぼりっく / Hyperbolic Tangent）

- 意味：入力を−1〜1の範囲の値に変換する、S字形の活性化関数
- ポイント：シグモイド関数の出力範囲を−1〜1に広げた形。0を中心に対称

#### ソフトマックス関数（Softmax Function）

- 意味：複数の出力の値を、すべて0〜1の範囲で合計が1になる確率の形に変換する関数
- ポイント：多クラス分類の出力層で使う。最も大きい値のクラスを予測結果とする

#### ドロップアウト（Dropout）

- 意味：学習のたびに、中間層の素子の一部をランダムに無効にして学習させる方法
- ポイント：特定の素子に頼りすぎるのを防ぎ、過学習を抑える。予測のときは全部の素子を使う

### 学習のしかた

#### 事前学習（じぜんがくしゅう / Pre-training）

- 意味：大量の一般的なデータで、モデルにあらかじめ広く使える特徴を学習させておくこと
- ポイント：その後、目的の課題のデータで追加学習（ファインチューニング）する

#### ファインチューニング（Fine-tuning）

- 意味：事前学習済みのモデルを、目的の課題のデータで追加学習させ、パラメータを微調整すること
- ポイント：少ないデータで高い精度が出せる。モデル全体の重みを調整する点が、一部だけ使う転移学習との違いとして説明されることが多い

#### 転移学習（てんいがくしゅう / Transfer Learning）

- 意味：ある領域で学習済みのモデルを、別の領域の課題に再利用して、効率的に学習させる方法
- ポイント：学習済みの層をそのまま使い、出力に近い層だけを学習し直すのが典型
- 例：R4秋 問4の選択肢ア（過学習の説明ではない）

#### バッチ学習（Batch Learning）

- 意味：訓練データ全部を使って誤差を計算し、まとめてパラメータを更新する学習の方法
- ポイント：安定するが、データが多いと1回の更新に時間とメモリがかかる

#### ミニバッチ学習（Mini-batch Learning）

- 意味：訓練データを小さなまとまり（ミニバッチ）に分け、まとまりごとにパラメータを更新する学習の方法
- ポイント：バッチ学習とオンライン学習の中間。ディープラーニングで最も一般的

#### オンライン学習（Online Learning）

- 意味：データが1件届くたびに、そのデータでパラメータを更新する学習の方法
- ポイント：次々に新しいデータが来る場面に向くが、1件ごとのばらつきの影響を受けやすい

### 画像・言語のモデル

#### CNN（しーえぬえぬ / Convolutional Neural Network）

- 意味：画像の小さな範囲ごとにフィルタを掛ける畳み込み層と、情報をまとめるプーリング層を重ねた、画像認識に強いニューラルネットワーク
- ポイント：位置が少しずれても同じ特徴を見つけられる。画像なら CNN、時系列なら RNN
- 語の意味：Convolutional＝畳み込みの／Neural Network＝ニューラルネットワーク

#### RNN（あーるえぬえぬ / Recurrent Neural Network）

- 意味：前の時点の出力を次の時点の入力に戻すことで、文章や音声のような順番のあるデータを扱うニューラルネットワーク
- ポイント：長い系列では前の方の情報を忘れやすい（勾配消失）。その改良がLSTM
- 語の意味：Recurrent＝再帰する・繰り返す

#### LSTM（えるえすてぃーえむ / Long Short Term Memory）

- 意味：RNNに、情報を残すか忘れるかを決める仕組み（ゲート）を加え、長い系列でも前の情報を保てるようにしたモデル
- ポイント：RNNの勾配消失の問題を和らげる。機械翻訳や音声認識で使われてきた
- 語の意味：Long Short Term＝長い短期の（短期の記憶を長く保つ）／Memory＝記憶

#### オートエンコーダ（Autoencoder）

- 意味：入力をいったん小さな表現に圧縮し、そこから元の入力を復元するように学習するニューラルネットワーク
- ポイント：正解ラベルがいらない。次元削減や、うまく復元できないデータを異常として見つける異常検知に使う

#### GAN（がん / Generative Adversarial Network）

- 意味：本物そっくりのデータを作る生成ネットワークと、本物か偽物かを見分ける識別ネットワークを競わせて学習させる生成モデル
- ポイント：2つのネットワークが「敵対的」に競う点がキーワード。画像の生成に使われる。新しいデータを作り出すモデルを生成モデルといい、GAN・拡散モデル・大規模言語モデルがその代表
- 語の意味：Generative＝生成する／Adversarial＝敵対的な／Network＝ネットワーク

#### 拡散モデル（かくさんもでる / Diffusion Model）

- 意味：データに少しずつノイズを加える過程を学習し、その逆にノイズから少しずつデータを復元することで新しいデータを生成するモデル
- ポイント：画像生成AIの主流。GAN（2つのネットワークの競争）とはしくみが違う

#### 深層強化学習（しんそうきょうかがくしゅう / Deep Reinforcement Learning）

- 意味：強化学習の価値や方策を、ディープラーニングのモデルで表して学習する方法
- ポイント：囲碁AI（AlphaGo）やゲームのプレイで有名。Q学習のQ値をニューラルネットワークで近似したものがDQN

#### Transformer（トランスフォーマー）

- 意味：自己注意機構を中心に作られた、文章などの系列データを扱うニューラルネットワークのモデル
- ポイント：RNNのように順番に処理せず、全体を並列に処理できるので大量のデータで学習しやすい。大規模言語モデルのもと

#### 自己注意機構（じこちゅういきこう / Self-Attention）

- 意味：文章中の各単語が、同じ文章のほかのどの単語とどれだけ関係が深いかを計算して、文脈を取り込む仕組み
- ポイント：離れた位置の単語の関係もとらえられる。Transformerの中心となる仕組み

### 生成AIと大規模言語モデル

#### 基盤モデル（きばんもでる / Foundation Model）

- 意味：大量で多様なデータで事前学習され、追加の学習や指示によってさまざまな課題に使える大規模なモデル
- ポイント：大規模言語モデルは、文章を扱う基盤モデルの代表

#### 言語モデル（げんごもでる / Language Model）

- 意味：単語の並びがどれだけ自然か、次にどの単語が来やすいかを確率で表すモデル
- ポイント：文章の続きを予測して生成する。規模を大きくしたものが大規模言語モデル

#### 大規模言語モデル（だいきぼげんごもでる / Large Language Model）

- 意味：膨大な文章で学習した、非常に多くのパラメータをもつ言語モデル（LLM）
- ポイント：Transformerがもと。質問への回答・要約・翻訳など、一つのモデルで多くの課題をこなす。もっともらしい誤り（ハルシネーション）を出すことがある

#### アラインメント（Alignment）

- 意味：AIの出力や振る舞いを、人間の意図や価値観、安全の基準に沿うように調整すること
- ポイント：RLHFやインストラクションチューニングがその方法

#### RLHF（あーるえるえいちえふ / Reinforcement Learning from Human Feedback）

- 意味：モデルの出力に人が付けた評価をもとに報酬を決め、強化学習でモデルを人の好む出力に近づける方法
- ポイント：アラインメントの代表的な方法
- 語の意味：Reinforcement Learning＝強化学習／from＝〜からの／Human Feedback＝人間のフィードバック

#### インストラクションチューニング（Instruction Tuning）

- 意味：「指示」と「望ましい回答」の組のデータでモデルを追加学習させ、指示に従った回答をするようにすること
- ポイント：ファインチューニングの一種。RLHFは人の評価を報酬に使う点が違う

#### ゼロショット学習（Zero-shot Learning）

- 意味：例を一つも示さずに、指示だけで、学習していない課題をモデルにこなさせること
- ポイント：例をいくつか示すのがフューショット学習

#### フューショット学習（Few-shot Learning）

- 意味：課題の例を少しだけ（数件）示して、モデルに同じような課題をこなさせること
- ポイント：大規模言語モデルでは、プロンプトの中に例を書くだけで追加学習なしにできる

#### プロンプトエンジニアリング（Prompt Engineering）

- 意味：生成AIからよい出力を得られるよう、指示文（プロンプト）の書き方を工夫すること
- ポイント：役割の指定、例の提示（フューショット）、手順を考えさせる指示などがある。モデルの重みは変えない

#### ハルシネーション（Hallucination）

- 意味：生成AIが、事実と異なる内容や存在しない情報を、もっともらしく作り出してしまうこと
- ポイント：「幻覚」の意味。対策として、外部の資料を検索して回答に使うRAGがある

#### RAG（らぐ / Retrieval-Augmented Generation）

- 意味：質問に関係する資料を外部のデータベースから検索し、その内容を生成AIに渡して回答を作らせる方法
- ポイント：モデルを学習し直さずに最新・社内の情報を使え、ハルシネーションを減らせる
- 語の意味：Retrieval＝検索・取り出し／Augmented＝拡張された／Generation＝生成

#### 蒸留（じょうりゅう / Knowledge Distillation）

- 意味：大きなモデル（教師）の出力をまねるように小さなモデル（生徒）を学習させ、性能をなるべく保ったままモデルを小さくする方法
- ポイント：モデル圧縮の一つ。量子化・プルーニングと並ぶ

#### モデルの量子化（Model Quantization）

- 意味：モデルのパラメータを表すビット数を減らして（32ビットの小数を8ビットの整数にするなど）、モデルを小さく速くする方法
- ポイント：A/D変換の量子化（アナログ値を段階の値にする）と同じ言葉だが、ここではモデル圧縮の方法

#### プルーニング（Pruning）

- 意味：モデルの中で、結果にあまり影響しない重みや素子を取り除いて、モデルを小さくする方法
- ポイント：「枝刈り」の意味。蒸留・量子化と並ぶモデル圧縮の方法

### コンパイラと言語

#### 字句解析（じくかいせき / Lexical Analysis）

- 意味：ソースプログラムの文字の並びを、予約語・変数名・定数・演算子などの意味のある最小単位（字句・トークン）に分ける処理
- ポイント：コンパイルの最初の段階。有限オートマトン（正規表現）で行える

#### 構文解析（こうぶんかいせき / Syntax Analysis）

- 意味：字句の並びが言語の文法に合っているかを調べ、構文木を作る処理
- ポイント：文法はBNFなどの文脈自由文法で定義される。字句解析の次の段階

#### 意味解析（いみかいせき / Semantic Analysis）

- 意味：構文としては正しいプログラムについて、変数の型の整合性や宣言の有無など、意味の正しさを調べる処理
- ポイント：「整数の変数に文字列を代入」のような誤りはここで見つかる

#### 最適化（さいてきか / Optimization）

- 意味：プログラムの結果を変えずに、実行が速くなる・小さくなるように処理を組み替えること
- ポイント：ループの外に出せる計算を外に出す、定数の計算を先に済ませておく、などがある

#### コード生成（こーどせいせい / Code Generation）

- 意味：解析と最適化の結果から、目的プログラム（機械語やアセンブリ言語）を作る処理
- ポイント：コンパイルの最後の段階

#### 中間言語（ちゅうかんげんご / Intermediate Language）

- 意味：ソースプログラムと機械語の間で使う、特定のCPUに依存しない形のコード
- ポイント：Javaのバイトコードが代表。実行時にインタプリタやJITコンパイラが機械語にする

#### 目的プログラム（もくてきぷろぐらむ / Object Program）

- 意味：コンパイラがソースプログラムを翻訳して作った、機械語などのプログラム
- ポイント：リンカで他の目的プログラムやライブラリと結合して、実行可能なプログラムにする

#### 手続型言語（てつづきがたげんご / Procedural Language）

- 意味：処理の手順を、命令を並べて順番に記述していく言語（C、COBOL、Fortran など）
- ポイント：変数の値を代入で書き換えながら処理を進める。最も基本的な考え方

#### 関数型言語（かんすうがたげんご / Functional Language）

- 意味：プログラムを、関数の定義と、関数に値を与えて結果を得ること（関数適用）の組合せで記述する言語（Haskell、Lisp など）
- ポイント：変数の値を書き換えない（副作用がない）のが基本。関数を値として扱える

#### 論理型言語（ろんりがたげんご / Logic Programming Language）

- 意味：事実と規則（述語論理）を記述し、問合せに対してシステムが推論で答えを導く言語（Prolog）
- ポイント：手順ではなく「何が成り立つか」を書く。エキスパートシステムの開発に使われた

#### オブジェクト指向言語（おぶじぇくとしこうげんご / Object-Oriented Language）

- 意味：データとそれを扱う手続をひとまとめにした「オブジェクト」を単位としてプログラムを組み立てる言語（Java、C++、Python など）
- ポイント：カプセル化・継承・多態性（ポリモーフィズム）が三大要素

## 1-4 通信に関する理論

### まとめ表

**誤り検出・訂正の方式**

| 方式 | 付け加えるもの | できること |
| :-: | :-: | :-: |
| パリティチェック（1方向） | 1の数を偶数（奇数）にそろえる1ビット | 1ビットの誤りの検出（2ビットの誤りは見逃す）。訂正はできない |
| 垂直水平パリティ | 行ごと・列ごとのパリティ | 誤りの行と列が交わる位置が分かるので、1ビットの誤りを訂正できる（R3秋 問4＝R5秋 問4） |
| ハミング符号 | 決めた位置の組合せごとの検査ビット（4ビットのデータに3ビット） | 1ビットの誤りの訂正、2ビットの誤りの検出 |
| CRC | 生成多項式でデータを割った余り（複数ビット） | 連続した誤り（バースト誤り）の検出に強い。訂正はしない |
| チェックサム | データを区切って足し合わせた値 | 簡単な誤りの検出 |

**ハミング符号の誤り位置の見つけ方（R4春 問4・R6春 問4）**

| 手順 | すること |
| :-: | :-: |
| 1 | 決められた検査式（排他的論理和、mod 2の和）を、受信した符号に当てはめて計算する |
| 2 | 成り立たない（0にならない）式に共通して含まれ、成り立つ式には含まれないビットが誤りの位置 |
| 3 | そのビットを反転して訂正する |

**多重化の方式**

| 方式 | 何で分けるか | 使われる所 |
| :-: | :-: | :-: |
| FDM（周波数分割多重） | 周波数（帯域） | ラジオ・テレビ放送 |
| TDM（時分割多重） | 時間（タイムスロット） | 電話のデジタル回線 |
| CDM（符号分割多重） | 拡散符号 | 第3世代携帯電話（CDMA） |
| WDM（波長分割多重） | 光の波長 | 光ファイバ |
| OFDM（直交周波数分割多重） | 互いに直交する多数の副搬送波 | 無線LAN・4G/5G・地上デジタル放送 |

**同期の方式**

| 方式 | 合わせ方 |
| :-: | :-: |
| 調歩同期 | 1文字ごとにスタートビットとストップビットを付ける |
| キャラクタ同期（SYN同期） | データの前に同期用の文字（SYN）を置く |
| フラグ同期 | データの前後に決まったビット列（フラグ 01111110）を置く。HDLC |
| フレーム同期 | 決められた長さのフレームの区切りを合わせる |

### 伝送路

#### 単方向通信（たんほうこう / Simplex）

- 意味：データを一方の向きにだけ送れる通信の方式
- ポイント：テレビ放送のように、受信側から送り返せない

#### 半二重通信（はんにじゅう / Half Duplex）

- 意味：両方向に送れるが、同時にはどちらか一方の向きにしか送れない通信の方式
- ポイント：トランシーバーのように、交互に切り替えて使う

#### 全二重通信（ぜんにじゅう / Full Duplex）

- 意味：両方向に同時にデータを送れる通信の方式
- ポイント：電話のように同時に話せる。送信用と受信用の2つの経路（または周波数）を使う

### 変調と復調

#### 振幅変調（しんぷくへんちょう / AM: Amplitude Modulation）

- 意味：送りたい信号に合わせて、搬送波の振幅（波の高さ）を変える変調方式
- ポイント：雑音の影響を受けやすい。AMラジオ
- 語の意味：Amplitude＝振幅／Modulation＝変調

#### 周波数変調（しゅうはすうへんちょう / FM: Frequency Modulation）

- 意味：送りたい信号に合わせて、搬送波の周波数を変える変調方式
- ポイント：振幅の変化として入る雑音に強い。FMラジオ
- 語の意味：Frequency＝周波数／Modulation＝変調

#### 位相変調（いそうへんちょう / PM: Phase Modulation）

- 意味：送りたい信号に合わせて、搬送波の位相（波のずれ）を変える変調方式
- ポイント：デジタルでは位相を4通りにずらして1回に2ビット送る方式（QPSK）などがある
- 語の意味：Phase＝位相／Modulation＝変調

#### QAM（きゅーえーえむ / Quadrature Amplitude Modulation）

- 意味：位相と振幅の両方を変えて、1回の変調で多くのビットを送る変調方式（直交振幅変調）
- ポイント：16QAMなら1回に4ビット、64QAMなら6ビット。無線LANや携帯電話で使う
- 語の意味：Quadrature＝直交（90度ずれた2つの波）／Amplitude＝振幅／Modulation＝変調

#### PCM（ぴーしーえむ / Pulse Code Modulation）

- 意味：アナログ信号を標本化・量子化・符号化して、パルスの列（デジタルデータ）で表す方式（パルス符号変調）
- ポイント：電話の音声のデジタル化（8kHz×8ビット＝64kビット/秒）が代表。A/D変換の手順そのもの
- 語の意味：Pulse＝パルス／Code＝符号／Modulation＝変調

#### PWM（ぴーだぶりゅーえむ / Pulse Width Modulation）

- 意味：一定の周期のパルスで、オンになっている時間の幅（デューティ比）を変えることで、平均の電力や信号の大きさを表す方式（パルス幅変調）
- ポイント：モーターの回転速度やLEDの明るさの制御に使う（PWM制御）
- 語の意味：Pulse＝パルス／Width＝幅／Modulation＝変調

#### モデム（Modem）

- 意味：デジタルデータをアナログの信号に変える変調と、その逆の復調を行う装置
- ポイント：電話回線でデータ通信をするために使われた。変調（MOdulation）と復調（DEModulation）を合わせた名前

### 多重化

#### FDM（えふでぃーえむ / Frequency Division Multiplexing）

- 意味：伝送路の周波数帯を分け、それぞれの周波数で別々の通信を同時に送る多重化方式（周波数分割多重）
- ポイント：ラジオ放送が例。隣の周波数と混ざらないよう、すき間（ガードバンド）を空ける
- 語の意味：Frequency＝周波数／Division＝分割／Multiplexing＝多重化

#### TDM（てぃーでぃーえむ / Time Division Multiplexing）

- 意味：伝送路を使う時間を細かく区切り、順番に別々の通信に割り当てる多重化方式（時分割多重）
- ポイント：各通信は自分のタイムスロットだけを使う
- 語の意味：Time＝時間／Division＝分割／Multiplexing＝多重化

#### CDM（しーでぃーえむ / Code Division Multiplexing）

- 意味：通信ごとに異なる拡散符号を掛けて同じ周波数・同じ時間に送り、受信側で符号を使って取り出す多重化方式（符号分割多重）
- ポイント：携帯電話のCDMA方式で使われた
- 語の意味：Code＝符号／Division＝分割／Multiplexing＝多重化

#### WDM（だぶりゅーでぃーえむ / Wavelength Division Multiplexing）

- 意味：1本の光ファイバに、波長の異なる複数の光の信号を同時に通す多重化方式（波長分割多重）
- ポイント：光ファイバの容量を大きく増やせる。FDMの考え方を光に使ったもの
- 語の意味：Wavelength＝波長／Division＝分割／Multiplexing＝多重化

#### OFDM（おーえふでぃーえむ / Orthogonal Frequency Division Multiplexing）

- 意味：互いに干渉しない（直交する）多数の副搬送波にデータを分けて、並列に送る多重化方式（直交周波数分割多重）
- ポイント：副搬送波どうしを重ねても干渉しないので周波数を効率よく使え、建物などで反射した電波（マルチパス）に強い。無線LAN・4G・5G・地上デジタル放送
- 語の意味：Orthogonal＝直交した／Frequency Division Multiplexing＝周波数分割多重

### 誤り検出と訂正

#### パリティチェック（Parity Check）

- 意味：データの1の数が偶数（偶数パリティ）または奇数（奇数パリティ）になるように1ビットを付け加え、受信側で1の数を数えて誤りを見つける方式
- ポイント：1ビットの誤りは検出できるが、2ビット同時の誤りは見逃す。どのビットが誤ったかは分からない

#### 垂直水平パリティ（すいちょくすいへいパリティ / Two-dimensional Parity）

- 意味：データを表の形に並べ、行ごとと列ごとの両方にパリティビットを付ける方式
- ポイント：誤りのある行と列が交わる位置が分かるので、1ビットの誤りを訂正できる。2ビットの誤りは訂正できない
- 例：R3秋 問4＝R5秋 問4（4×4のデータに行と列のパリティ→訂正できるのは1ビットまで）

#### CRC（しーあーるしー / Cyclic Redundancy Check）

- 意味：送信側がデータを生成多項式で割った余りを検査用のデータとして付けて送り、受信側が同じ生成多項式で割って余りが出ないかで誤りを調べる方式（巡回冗長検査）
- ポイント：送信側と受信側は同じ生成多項式を使う。検査用のデータは1ビットではない。連続したビットの誤り（バースト誤り）の検出に強い。訂正はしない
- 例：R7秋 問4で正解ウ
- 語の意味：Cyclic＝巡回する／Redundancy＝冗長性／Check＝検査

#### 生成多項式（せいせいたこうしき / Generator Polynomial）

- 意味：CRCで、データを割る数として送信側と受信側があらかじめ決めておく多項式
- ポイント：割り算は桁上がりのない2進の割り算（排他的論理和）で行う。R7秋 問4 イ「検査用のデータで割る」は誤り。割るのは生成多項式

#### ハミング符号（ハミングふごう / Hamming Code）

- 意味：データのビットの決められた組合せごとに検査ビットを付け、どの検査式が成り立たないかから、1ビットの誤りの位置を見つけて訂正できるようにした符号
- ポイント：4ビットのデータに3ビットの検査ビットを付けた7ビット符号が代表。1ビットの訂正と2ビットの検出ができる。誤り訂正符号（ECC：Error Correcting Code）の代表で、サーバのECCメモリに使う
- 例：R4春 問4（成り立たない式すべてに含まれるX1が誤り）、R6春 問4（c0＋c1×2＋c2×4＝3 で3ビット目を反転）

#### チェックサム（Checksum）

- 意味：データを一定の長さごとに区切って足し合わせた値を付けて送り、受信側でも同じ計算をして一致するかで誤りを調べる方式
- ポイント：計算が簡単だが、順番の入れ替わりなどは見逃すことがある。IPやTCPのヘッダで使う

#### ビット誤り率（ビットごりつ / Bit Error Rate）

- 意味：送ったビットのうち、誤って受信されたビットの割合
- ポイント：伝送路の品質を表す。1×10^−6 なら100万ビットに1ビットの誤り

### 同期

#### ビット同期（Bit Synchronization）

- 意味：受信側が、送られてくる1ビット1ビットの区切りのタイミングを送信側に合わせること
- ポイント：これができたうえで、文字の区切り（キャラクタ同期）やフレームの区切り（フレーム同期）を合わせる

#### 調歩同期（ちょうほどうき / Start-Stop Synchronization）

- 意味：1文字ごとに、前にスタートビット、後ろにストップビットを付けて、文字の始まりと終わりを知らせる同期の方式
- ポイント：仕組みが簡単だが、1文字ごとに余分なビットが付くので効率が悪い。シリアル通信（RS-232C）で使う

#### スタートビット（Start Bit）

- 意味：調歩同期で、1文字のデータの前に付けて、文字の始まりを知らせるビット
- ポイント：ストップビットは文字の終わりを示す

#### ストップビット（Stop Bit）

- 意味：調歩同期で、1文字のデータの後に付けて、文字の終わりを知らせるビット
- ポイント：スタートビットと組で使う

#### キャラクタ同期（SYN同期 / Character Synchronization）

- 意味：データのかたまりの前に、同期用の特別な文字（SYN）を置いて、文字の区切りを合わせる同期の方式
- ポイント：調歩同期のように1文字ごとに余分なビットを付けないので効率がよい

#### フラグ同期（Flag Synchronization）

- 意味：データのかたまりの前後に、決まったビット列（フラグ：01111110）を置いて、区切りを示す同期の方式
- ポイント：HDLC手順で使う。データ中に同じ並びが現れないよう、1が5つ続いたら0を挿入する

#### フレーム同期（Frame Synchronization）

- 意味：決められた長さのデータのまとまり（フレーム）の区切りを、送信側と受信側で合わせること
- ポイント：時分割多重（TDM）では、どのタイムスロットがどの通信かを知るためにフレームの区切りを合わせる

## 1-5 計測・制御に関する理論

### まとめ表

**制御の方式**

| 方式 | 考え方 | 例 |
| :-: | :-: | :-: |
| フィードバック制御（クローズドループ） | 結果を測って目標との差をなくすよう操作を直す | エアコンの室温調整 |
| フィードフォワード制御 | 外乱を前もって測り、結果に表れる前に操作を加える | 外気温の変化を先読みした空調 |
| シーケンス制御 | 決められた順序・条件に従って段階的に進める | 洗濯機、信号機、エレベーター |
| オープンループ制御 | 結果を測らず、決めた操作をするだけ | タイマー式のトースター |
| PID制御 | 差に比例（P）・差の積分（I）・差の微分（D）の3つで操作量を決める | 温度・速度の精密な制御 |
| オンオフ制御 | 目標を下回ったらオン、上回ったらオフ | こたつのサーモスタット |

| センサー | 測るもの | しくみ・特徴 |
| :-: | :-: | :-: |
| サーミスタ | 温度 | 温度で電気抵抗が変わる素子。体温計（R3春 問4） |
| フォトトランジスタ | 光の強さ | 光が当たると電流が流れる |
| ポテンショメータ | 回転の角度・位置 | 可変抵抗の抵抗値の変化で読み取る |
| 超音波センサー | 距離 | 音波の反射までの時間。測れるのは数m程度 |
| ドップラーセンサー | 動いているものの速さ（血流量など） | 反射した波の周波数のずれ（R5春 問4） |
| 可視光カメラ | 形・色・文字 | 天候の影響を受けやすいが、標識・信号の色を認識できる（R6秋 問4） |
| ミリ波レーダー | 距離・相対速度 | 雨や霧に強いが、色は分からない |

| ひずみゲージ | 力・重さ（ひずみ） | 伸び縮みで抵抗が変わる |

**フィルタの種類**

| フィルタ | 通すもの | 使い道 |
| :-: | :-: | :-: |
| ローパスフィルタ | 低い周波数 | 高い周波数の雑音を取る。A/D変換の前の折返し雑音の防止 |
| ハイパスフィルタ | 高い周波数 | ゆっくりした変動（直流成分）を取る |
| バンドパスフィルタ | 決めた範囲の周波数 | 特定の周波数の信号だけを取り出す |

### 信号処理

#### サンプリング定理（標本化定理 / Sampling Theorem）

- 意味：アナログ信号に含まれる最高周波数の2倍より高い周波数で標本化すれば、もとの信号を完全に復元できるという定理
- ポイント：人の声（〜4kHz）なら8kHz、音楽CD（〜20kHz）なら44.1kHzで標本化する。足りないと折返し雑音（エイリアシング）が出る

#### D/A変換（でぃーえーへんかん / Digital to Analog Conversion）

- 意味：デジタルデータを、連続的に変わるアナログ信号に戻すこと
- ポイント：ビット数（分解能）が多いほど、細かい電圧の段階を出せる。A/D変換の逆

#### DFT（でぃーえふてぃー / Discrete Fourier Transform）

- 意味：標本化した信号の値の並びを、どの周波数の成分がどれだけ含まれているかに分解する計算（離散フーリエ変換）。定義どおりの計算で、これを高速にした方法がFFT
- ポイント：音声の分析や画像の圧縮で使う。そのまま計算すると O(n²) の手間がかかる
- 語の意味：Discrete＝離散的な／Fourier＝考案者の名前／Transform＝変換

#### FFT（えふえふてぃー / Fast Fourier Transform）

- 意味：DFTを、計算をうまく分けて使い回すことで高速に行う方法（高速フーリエ変換）
- ポイント：計算量は O(n log n)。結果はDFTと同じ
- 語の意味：Fast＝高速な／Fourier Transform＝フーリエ変換

#### インパルス応答（いんぱるすおうとう / Impulse Response）

- 意味：ごく短い時間だけの強い入力（インパルス）を与えたときの、システムの出力の時間変化
- ポイント：これが分かれば、どんな入力に対する出力も計算できる（線形のシステムの場合）。ホールの残響の測定などに使う

#### ローパスフィルタ（Low-pass Filter）

- 意味：決めた周波数より低い成分だけを通し、高い成分を取り除くフィルタ
- ポイント：雑音を取って信号をなめらかにする。A/D変換の前に入れて折返し雑音を防ぐ

#### ハイパスフィルタ（High-pass Filter）

- 意味：決めた周波数より高い成分だけを通し、低い成分を取り除くフィルタ
- ポイント：ゆっくりした変動や直流成分を取る。画像では輪郭を強調するのに使う

#### バンドパスフィルタ（Band-pass Filter）

- 意味：決めた範囲（帯域）の周波数の成分だけを通すフィルタ
- ポイント：ラジオで特定の局の周波数だけを取り出すのが例

#### デジタルフィルタ（Digital Filter）

- 意味：デジタル化した信号に対して、計算によってフィルタの働きをさせるもの
- ポイント：部品を変えずにプログラムで特性を変えられる。電子回路で作るものはアナログフィルタ

#### 画像処理フィルタ（Image Processing Filter）

- 意味：画像の各画素の値を、周りの画素の値との計算で変換して、ぼかし・輪郭の強調・雑音の除去などを行う処理
- ポイント：平均化（ぼかし）はローパス、輪郭の抽出はハイパスにあたる。CNNの畳み込みも同じ形の計算

### 制御のしくみ

#### フィードバック制御（クローズドループ制御 / Feedback Control）

- 意味：制御した結果を測って目標値と比べ、その差（偏差）が小さくなるように操作量を直し続ける制御の総称。PID制御やオンオフ制御は、その操作量の決め方の種類
- ポイント：結果を入力側に戻すのでクローズドループ制御ともいう。外乱が起きた後に直すので、遅れが出る

#### フィードフォワード制御（Feedforward Control）

- 意味：外乱を前もって測り、それが結果に影響する前に、打ち消す操作を加える制御
- ポイント：先回りできるが、予測できない外乱には対応できないので、フィードバック制御と組み合わせて使う

#### オープンループ制御（Open-loop Control）

- 意味：結果を測って戻すことをせず、決められた操作だけを行う制御
- ポイント：仕組みは簡単だが、外乱で結果がずれても直せない。ステッピングモーターの位置決めはこれで足りることが多い

#### シーケンス制御（Sequence Control）

- 意味：あらかじめ決めた順序や条件に従って、制御の各段階を順番に進めていく制御
- ポイント：洗濯機・自動販売機・信号機。PLC（プログラマブルロジックコントローラ）で実現することが多い

#### PID制御（ぴーあいでぃーせいぎょ / Proportional-Integral-Derivative Control）

- 意味：目標との差に比例した操作（P）、差を積み重ねた量に応じた操作（I）、差の変化の速さに応じた操作（D）を組み合わせるフィードバック制御
- ポイント：Pだけだと差が残る（定常偏差）ので I で消し、Dで行き過ぎを抑える
- 語の意味：Proportional＝比例／Integral＝積分／Derivative＝微分

#### オンオフ制御（On-off Control）

- 意味：測った値が目標を下回ったら操作をオン、上回ったらオフにするだけの制御
- ポイント：仕組みは簡単だが、目標のまわりで値が上下に揺れ続ける

#### PWM制御（ぴーだぶりゅーえむせいぎょ / Pulse Width Modulation Control）

- 意味：電源を高速にオン・オフし、オンの時間の割合（デューティ比）を変えることで、モーターなどに加わる平均の電力を調整する制御
- ポイント：デューティ比50%なら平均で半分の電圧。電力の無駄が少ない

#### 応答特性（おうとうとくせい / Response Characteristic）

- 意味：入力を変えたとき、出力がどれだけ速く、どのような形で目標の値に近づくかという性質
- ポイント：立ち上がりの速さ、行き過ぎ（オーバーシュート）、落ち着くまでの時間で評価する

#### 制御安定性（せいぎょあんていせい / Control Stability）

- 意味：制御を続けたとき、出力が発散したり振動し続けたりせず、目標の値に落ち着く性質
- ポイント：フィードバックを強くしすぎると、行き過ぎと戻りを繰り返して不安定になる

#### 外乱（がいらん / Disturbance）

- 意味：制御対象に外から加わり、出力を目標からずらす想定外の影響
- ポイント：フィードバック制御は外乱の結果を見て直し、フィードフォワード制御は外乱を先に測って打ち消す

#### リアルタイムOS（りあるたいむおーえす / Real-time Operating System）

- 意味：決められた時間の制限の中で処理を終えることを重視して作られた、組込みシステム向けのOS
- ポイント：優先度の高いタスクをすぐに実行するプリエンプティブな方式が基本。速さよりも、時間の制限を守れることが大事

#### リアルタイム性（Real-time）

- 意味：入力やイベントに対して、定められた制限時間内に応答できること
- ポイント：「OSを使わない」「入力順を守る」ことではなく、締切りを守ることが本質。締切りを過ぎると致命的なのがハードリアルタイム、価値が下がるだけなのがソフトリアルタイム
- 例：R7春 問4で正解イ

#### MPU（えむぴーゆー / Micro Processing Unit）

- 意味：組込み機器の制御の中心となる、演算と制御を行うプロセッサ
- ポイント：メモリや入出力の機能まで1つのチップにまとめたものはマイコン（MCU）と呼ぶ
- 語の意味：Micro＝小さな／Processing＝処理／Unit＝装置

### センサー
#### アクチュエーター（Actuator）

- 意味：コンピュータからの電気信号を、回転・直線の動き・力などの機械的な動作に変える装置
- ポイント：センサー（状態を測る）と対になる。モーター・ソレノイド・シリンダが代表



#### サーミスタ（Thermistor）

- 意味：温度によって電気抵抗の値が大きく変わる半導体の素子を使った温度センサー
- ポイント：体温計や家電の温度測定に使う
- 例：R3春 問4で正解ア（体温を測るセンサー）

#### フォトトランジスタ（Phototransistor）

- 意味：光が当たると電流が流れるトランジスタで、光の強さを測るセンサー
- ポイント：光の有無で物の通過を調べる（光電センサー）のに使う。温度は測れない
- 例：R3春 問4の選択肢ウ

#### ポテンショメータ（Potentiometer）

- 意味：つまみや軸の回転・移動によって抵抗値が変わる可変抵抗を使い、角度や位置を測るセンサー
- ポイント：ロボットの関節の角度の検出などに使う
- 例：R3春 問4の選択肢エ

#### 超音波センサー（ちょうおんぱセンサー / Ultrasonic Sensor）

- 意味：人に聞こえない高い周波数の音波を出し、物に当たって戻るまでの時間から距離を測るセンサー
- ポイント：測れる距離は数m程度と短い。車の駐車支援に使う
- 例：R3春 問4の選択肢イ、R6秋 問4の選択肢イ（500m以上は誤り）

#### ドップラーセンサー（Doppler Sensor）

- 意味：動いている物に当てた波の、反射したときの周波数のずれ（ドップラー効果）から、物の速さを測るセンサー
- ポイント：超音波で血液の流れの速さを測る血流計、車の速度測定に使う
- 例：R5春 問4（ドップラー効果で測れるのは血流量）

#### 赤外線センサー（せきがいせんセンサー / Infrared Sensor）

- 意味：赤外線を受けて、人や物の存在・温度・距離を調べるセンサー
- ポイント：人の体から出る赤外線で人を検知する人感センサー、非接触の体温計に使う

#### イメージセンサー（Image Sensor）

- 意味：レンズで集めた光を、多数の受光素子で電気信号に変えて画像にするセンサー
- ポイント：CMOSとCCDがある。カメラの撮像素子

#### 可視光カメラ（かしこうカメラ / Visible Light Camera）

- 意味：目に見える光で周囲を撮影し、その画像から標識・信号・車線などを認識する車載のセンサー
- ポイント：天候や明るさの影響を受けやすいが、色や文字が分かるので、交通標識や信号の色の認識に使える
- 例：R6秋 問4で正解ア

#### ミリ波レーダー（ミリはレーダー / Millimeter-wave Radar）

- 意味：波長がミリメートル単位の電波を出し、反射から物までの距離や相対速度を測るセンサー
- ポイント：雨・霧・夜間に強いが、色は分からない。車の衝突被害軽減ブレーキや前の車の追従に使う
- 例：R6秋 問4の選択肢ウ（信号機の灯色の判別はできない）

#### LiDAR（らいだー / Light Detection And Ranging）

- 意味：レーザー光を当て、反射して戻るまでの時間から、周りの物の距離や形を3次元で細かく測るセンサー（レーザーレーダー）
- ポイント：形を細かく測れるが、雨や霧などの天候の影響を受けやすく、物陰にある物は測れない。光が戻るまでの時間で測る方式をToF（Time of Flight）といい、スマートフォンの距離センサーも同じ原理
- 例：R6秋 問4の選択肢エ（影響を受けにくい・建物の後ろが見えるは誤り）
- 語の意味：Light＝光／Detection＝検出／And Ranging＝と測距

#### 加速度センサー（かそくどセンサー / Acceleration Sensor）

- 意味：物の速さの変化（加速度）を測るセンサー
- ポイント：重力の向きも分かるので、スマートフォンの傾きや歩数の検出に使う。回転の速さはジャイロセンサー

#### ジャイロセンサー（Gyro Sensor）

- 意味：物がどれだけの速さで回転しているか（角速度）を測るセンサー
- ポイント：手ぶれ補正、ドローンの姿勢制御に使う。加速度センサーと組み合わせてIMUにする

#### 地磁気センサー（ちじきセンサー / Geomagnetic Sensor）

- 意味：地球の磁気を測って、方位を調べるセンサー
- ポイント：スマートフォンの電子コンパスに使う

#### IMU（あいえむゆー / Inertial Measurement Unit）

- 意味：加速度センサーとジャイロセンサーなどを組み合わせて、物の動きと向きを3次元で測る装置（慣性計測装置）
- ポイント：GPSが使えないトンネルの中でも位置の変化を推定できる。ドローン・ロケット・自動運転に使う
- 語の意味：Inertial＝慣性の／Measurement＝計測／Unit＝装置

#### ホール素子（ホールそし / Hall Element）

- 意味：磁界の中で電流を流すと、磁界の強さに応じた電圧が生じる現象（ホール効果）を使って、磁界を測る素子
- ポイント：モーターの回転の検出や、開閉の検知に使う

#### ひずみゲージ（Strain Gauge）

- 意味：物体に貼り付け、伸び縮み（ひずみ）による電気抵抗の変化から、加わった力や重さを測るセンサー
- ポイント：体重計・はかりや、橋などの構造物の監視に使う

#### 圧力センサー（あつりょくセンサー / Pressure Sensor）

- 意味：気体や液体の圧力を、電気信号に変えて測るセンサー
- ポイント：大気圧センサーは気圧から高さを推定でき、スマートフォンで建物の階を判断するのに使う

#### ウェアラブル生体センサー（Wearable Biosensor）

- 意味：体に身に着けて、心拍・血中酸素飽和度・体温などの生体の情報を測るセンサー
- ポイント：血中酸素飽和度は、赤色光と赤外光の吸収の違いで測る（パルスオキシメータ）。ドップラー効果では測れない
- 例：R5春 問4の選択肢ア（血中酸素飽和度）は光の吸収で測る

### アクチュエーター

#### ステッピングモーター（Stepping Motor）

- 意味：パルス信号を1つ受け取るごとに、決まった角度だけ回転するモーター
- ポイント：パルスの数で回転角が決まるので、センサーなしのオープンループ制御で位置決めができる。プリンタ・3Dプリンタ

#### DCサーボモーター（でぃーしーさーぼもーたー / DC Servo Motor）

- 意味：回転の位置や速さをセンサーで測りながら、指示どおりの位置・速さになるようフィードバック制御する直流モーター
- ポイント：精密な位置決めに使う。ステッピングモーターと違い、センサーで結果を確かめる

#### ブラシレスDCモーター（Brushless DC Motor）

- 意味：ブラシを使わず、電子回路で電流の向きを切り替えて回す直流モーター
- ポイント：ブラシがすり減らないので長持ちし、静か。ドローンやパソコンのファンに使う

#### ソレノイド（Solenoid）

- 意味：コイルに電流を流して生じる磁力で、鉄の芯を直線的に動かす装置
- ポイント：電子錠や弁の開閉に使う。回転ではなく、押す・引く動き

#### 油圧シリンダ（ゆあつシリンダ / Hydraulic Cylinder）

- 意味：油の圧力で、ピストンを直線的に動かす装置
- ポイント：非常に大きな力が出せるので、建設機械やプレス機に使う。空気圧シリンダは力は小さいが速く清潔

#### 空気圧シリンダ（くうきあつシリンダ / Pneumatic Cylinder）

- 意味：圧縮した空気の圧力で、ピストンを直線的に動かす装置
- ポイント：油圧より力は小さいが、動きが速く、油が漏れる心配がない。工場の組立てラインに使う

### 測位

#### GPS（じーぴーえす / Global Positioning System）

- 意味：複数の人工衛星から届く電波の到達時間の差から、受信機の位置を求める米国の衛星測位システム
- ポイント：4機以上の衛星の電波が必要。建物の中やトンネルでは使えない。衛星測位システムの総称はGNSS
- 語の意味：Global＝地球全体の／Positioning＝位置測定／System＝システム

#### RTK測位（あーるてぃーけーそくい / Real Time Kinematic）

- 意味：位置が分かっている基準局でも衛星の電波を受け、その補正の情報を使って、数cmの精度で位置を求める測位方式
- ポイント：ふつうのGPS単独測位（数m程度）よりずっと精密。農業機械の自動運転や測量に使う
- 語の意味：Real Time＝実時間の／Kinematic＝動きの

#### 基地局測位（きちきょくそくい / Cell-ID Positioning）

- 意味：携帯電話がつながっている基地局の位置や、複数の基地局からの電波の強さをもとに、端末の位置を求める方法
- ポイント：屋内でも使えるが、精度は基地局の間隔に左右され、GPSより粗い

#### 無線LANアクセスポイント測位（むせんLANアクセスポイントそくい / Wi-Fi Positioning）

- 意味：周りにある無線LANのアクセスポイントの識別子と電波の強さから、位置の分かったアクセスポイントの情報と照らし合わせて位置を求める方法
- ポイント：GPSが届かない屋内や地下街でも位置が分かる

### 1-1 離散数学

#### 問 ap-1-r03h-q1

- 問：任意のオペランドに対するブール演算Aの結果とブール演算Bの結果が互いに否定の関係にあるとき，AはBの（又は，BはAの）相補演算であるという。排他的論理和の相補演算はどれか。（原文は各選択肢にベン図付き）
- ア：等価演算
- イ：否定論理和
- ウ：論理積
- エ：論理和
- 正解：ア
- 解説：排他的論理和（XOR）は入力が異なるとき1、等価演算は入力が同じとき1。どの入力でも結果がちょうど反対になるので、互いに相補演算。
- アの意味：等価演算（XNOR）。00と11で1、01と10で0。XORの結果をすべて反転したもの。
- イの意味：否定論理和（NOR）。00のときだけ1。論理和（OR）の相補演算で、XORの相補演算ではない（11のときXORもNORも0になる）。
- ウの意味：論理積（AND）。11のときだけ1。00のときXORもANDも0になり、否定の関係にならない。
- エの意味：論理和（OR）。01・10・11で1。01と10のときXORもORも1になり、否定の関係にならない。
- 出典：IPA 令和3年度春期 応用情報技術者試験 午前 問1

#### 問 ap-1-r03h-q2

- 問：桁落ちによる誤差の説明として，適切なものはどれか。
- ア：値がほぼ等しい二つの数値の差を求めたとき，有効桁数が減ることによって発生する誤差
- イ：指定された有効桁数で演算結果を表すために，切捨て，切上げ，四捨五入などで下位の桁を削除することによって発生する誤差
- ウ：絶対値が非常に大きな数値と小さな数値の加算や減算を行ったとき，小さい数値が計算結果に反映されないことによって発生する誤差
- エ：無限級数で表される数値の計算処理を有限項で打ち切ったことによって発生する誤差
- 正解：ア
- 解説：桁落ちは「ほぼ等しい値どうしの差」で有効桁が減る誤差。例えば 1.2345−1.2344＝0.0001 では、有効数字5桁の数どうしの計算なのに結果の有効数字は1桁になる。
- アの意味：桁落ち。ほぼ等しい数の引き算で、上の方の桁が打ち消し合って有効桁が減る。
- イの意味：丸め誤差。決められた桁数に収めるために下位の桁を削ったことで生じる。
- ウの意味：情報落ち。大きさが大きく違う数を足し引きして、小さい方が消える。
- エの意味：打切り誤差。無限に続く計算を途中でやめたことで生じる。
- 出典：IPA 令和3年度春期 応用情報技術者試験 午前 問2

#### 問 ap-1-r04h-q1

- 問：浮動小数点数を，仮数部が7ビットである表示形式のコンピュータで計算した場合，情報落ちが発生しないものはどれか。ここで，仮数部が7ビットの表示形式とは次のフォーマットであり，( )₂内は2進数，Yは指数である。また，{ }内を先に計算するものとする。フォーマット：(1.X1X2X3X4X5X6X7)₂×2^Y（原文の上付き・下付き文字を ^ と ₂ で書き直した）
- ア：{(1.1)₂×2^−3＋(1.0)₂×2^−4}＋(1.0)₂×2^5
- イ：{(1.1)₂×2^−3−(1.0)₂×2^−4}＋(1.0)₂×2^5
- ウ：{(1.0)₂×2^5＋(1.1)₂×2^−3}＋(1.0)₂×2^−4
- エ：{(1.0)₂×2^5−(1.0)₂×2^−4}＋(1.1)₂×2^−3
- 正解：ア
- 解説：2^5 の数に足したとき仮数部7ビットに収まるのは、2^5 から 2^−2 までの位（小数点以下7桁目が 2^−2）。アは先に (1.1)₂×2^−3＋(1.0)₂×2^−4＝2^−3＋2^−4＋2^−4＝2^−2 となり、2^5＋2^−2 は7ビットに収まる。
- アの意味：正しい。小さい数どうしを先に足して 2^−2 にまとめてから大きい数に足すので、情報落ちしない（「小さい数から順に足す」対策そのもの）。
- イの意味：先に計算すると 2^−3＋2^−4−2^−4＝2^−3。2^5＋2^−3 は小数点以下8桁目が必要で、7ビットに収まらず情報落ちする。
- ウの意味：先に 2^5＋(2^−3＋2^−4) を計算するので、2^−4 の位が収まらず情報落ちする。さらに 2^−4 を足しても同じ。
- エの意味：先に 2^5−2^−4 を計算するので、2^−4 の位が収まらず情報落ちする。
- 出典：IPA 令和4年度春期 応用情報技術者試験 午前 問1

#### 問 ap-1-r04h-q2

- 問：全体集合S内に異なる部分集合AとBがあるとき，Ā∩B̄に等しいものはどれか。ここで，A∪BはAとBの和集合，A∩BはAとBの積集合，ĀはSにおけるAの補集合，A−BはAからBを除いた差集合を表す。
- ア：Ā−B
- イ：(Ā∪B̄)−(A∩B)
- ウ：(S−A)∪(S−B)
- エ：S−(A∩B)
- 正解：ア
- 解説：Ā∩B̄ は「AにもBにも入っていない部分」。Ā−B は「Aに入っていない部分から、Bに入っている部分を除いたもの」なので同じ部分になる（X−Y＝X∩Ȳ の関係）。
- アの意味：正しい。Ā−B＝Ā∩B̄。
- イの意味：Ā∪B̄ はド・モルガンの法則で A∩B の補集合なので、そこから A∩B を除いても変わらず、A∩B の補集合（AとBの両方に入っている部分以外すべて）になる。Aだけ・Bだけの部分も含むので違う。
- ウの意味：(S−A)∪(S−B)＝Ā∪B̄。和集合なので、Aだけ・Bだけの部分も含んでしまう。ド・モルガンの法則で ∩ と ∪ を取り違えた形。
- エの意味：S−(A∩B) は A∩B の補集合で、ウと同じ部分。Aだけ・Bだけの部分も含む。
- 出典：IPA 令和4年度春期 応用情報技術者試験 午前 問2

#### 問 ap-1-r04a-q1

- 問：aを正の整数とし，b＝a²とする。aを2進数で表現するとnビットであるとき，bを2進数で表現すると最大で何ビットになるか。
- ア：n＋1
- イ：2n
- ウ：n²
- エ：2^n
- 正解：イ
- 解説：nビットの整数aは最大で 2^n−1。その2乗は 2^(2n)−2^(n+1)＋1 で、2^(2n) より小さいので最大 2n ビットに収まる。例えば n＝4 のとき a＝15、b＝225＝(11100001)₂ で8ビット。
- アの意味：n＋1ビットは、2倍（a＋a）したときの最大のビット数。2乗には足りない。
- イの意味：正しい。nビットどうしの積は最大 2n ビット。
- ウの意味：n² ビットは大きすぎる。n＝4 なら16ビットになるが、実際は8ビットで足りる。
- エの意味：2^n はaが取りうる値の個数で、ビット数ではない。
- 出典：IPA 令和4年度秋期 応用情報技術者試験 午前 問1

#### 問 ap-1-r04a-q2

- 問：A，B，C，Dを論理変数とするとき，次のカルノー図と等価な論理式はどれか。ここで，・は論理積，＋は論理和，X̄はXの否定を表す。（原文は図。カルノー図を文で書き直した：行がAB＝00, 01, 11, 10、列がCD＝00, 01, 11, 10。AB＝00の行は 1, 0, 0, 1、AB＝01の行は 0, 1, 1, 0、AB＝11の行は 0, 1, 1, 0、AB＝10の行は 0, 0, 0, 0）
- ア：A・B・C̄・D＋B̄・D̄
- イ：Ā・B̄・C̄・D̄＋B・D
- ウ：A・B・D＋B̄・D̄

#### 問 ap-1-r04h-q4

- 問：ハミング符号とは，データに冗長ビットを付加して，1ビットの誤りを訂正できるようにしたものである。ここでは，X1，X2，X3，X4 の4ビットから成るデータに，3ビットの冗長ビット P3，P2，P1 を付加したハミング符号 X1X2X3P3X4P2P1 を考える。付加したビット P1，P2，P3 は，それぞれ X1⊕X3⊕X4⊕P1＝0，X1⊕X2⊕X4⊕P2＝0，X1⊕X2⊕X3⊕P3＝0 となるように決める。ここで，⊕は排他的論理和を表す。ハミング符号 1110011 には1ビットの誤りが存在する。誤りビットを訂正したハミング符号はどれか。

- イ：1010011
- ウ：1100011
- エ：1110111
- 正解：ア

- エの意味：X4 を反転したもの。X4 は3つ目の式に含まれないので、3つ目の式の不一致を説明できない。

#### 問 ap-1-r07a-q4

#### 問 ap-1-o07

- ウの意味：フィードフォワード制御。
- エの意味：PID制御。フィードバック制御の代表的な計算方法。
