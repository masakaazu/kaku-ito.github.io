## 20-1 技術開発戦略の立案（56語）

### まとめ表

**研究開発から事業化までの3つの障壁**

| 障壁 | どこの間にあるか | 中身 |
| :-: | :-: | :-: |
| 魔の川 | 基礎研究 → 製品開発 | 研究成果を具体的な製品にできるか |
| 死の谷 | 製品開発 → 事業化 | 製品化に必要な資金・資源を確保できるか |
| ダーウィンの海 | 事業化 → 産業化（市場で定着） | 競合との競争に勝ち残り、市場に定着できるか |

**イノベーションの分類**

| 分類の軸 | 種類 |
| :-: | :-: |
| 何を変えるか | プロダクトイノベーション（製品そのもの）／プロセスイノベーション（作り方・提供方法） |
| 変化の大きさ | ラディカルイノベーション（根本的・非連続）／インクリメンタル（漸進的な改良） |
| 誰と行うか | クローズド（自社のみ）／オープンイノベーション（外部と連携） |

**イノベータ理論（ロジャーズ）の5分類**

| 区分 | 割合 | 特徴 |
| :-: | :-: | :-: |
| イノベータ（革新者） | 2.5% | 新しいもの自体を好む |
| アーリーアダプタ（初期採用者） | 13.5% | 流行に敏感なオピニオンリーダー |
| ── キャズム ── |   | ここを越えるのが最大の難関 |
| アーリーマジョリティ（前期追随者） | 34% | 慎重だが平均より早い |
| レイトマジョリティ（後期追随者） | 34% | 周囲の多数が使ってから採用 |
| ラガード（遅滞者） | 16% | 最も保守的 |

**検証の段階**：PoC（技術的に実現できるか）→ PoV（価値があるか）→ PoB（ビジネスとして成り立つか）

**技術の獲得方法**：自社開発（技術研究）／委託研究／共同研究／技術提携／技術供与を受ける（ライセンス）／M&A／産学官連携

### イノベーション

#### MOT（えむおーてぃー / Management of Technology）

- 意味：技術経営。技術を事業の成果に結びつけ、企業の競争力を高めるための経営の考え方。
- ポイント：「技術を持っているだけでなく、それを利益に変える」ための経営。

#### プロダクトイノベーション（Product Innovation）

- 意味：新しい製品・サービスを生み出したり、既存の製品を大きく改良したりする革新。

#### プロセスイノベーション（Process Innovation）

- 意味：製品・サービスの作り方や提供方法を革新し、コスト削減・品質向上・スピードアップを図ること。
- ポイント：プロダクト＝「何を作るか」、プロセス＝「どう作るか」。

#### ラディカルイノベーション（Radical Innovation）

- 意味：従来の技術や市場の枠組みを根本から変える、非連続的な革新（急進的イノベーション）。
- ポイント：既存の延長で少しずつ改良するインクリメンタルイノベーションと対になる。

#### オープンイノベーション（Open Innovation）

- 意味：自社だけでなく、他社・大学・スタートアップなど外部の技術やアイデアを積極的に取り入れて革新を進める戦略。
- ポイント：自社内で完結させる「クローズドイノベーション」の反対。

#### イノベーションのジレンマ（Innovation Dilemma）⚠要確認

- 意味：優良企業が既存顧客や既存事業を大切にするあまり、破壊的な新技術への対応が遅れ、新興企業に市場を奪われる現象。
- ポイント：持続的イノベーション（既存製品の改良）に注力するほど、破壊的イノベーション（当初は低性能だが安価・便利）を軽視してしまう。
- ⚠要確認：サイトでは「コリンズとポラスが提唱」とあるが、一般的にはクレイトン・クリステンセンが提唱した理論とされる。

#### メイカームーブメント（Maker Movement）

- 意味：3Dプリンタなどのデジタル工作機器を使い、個人やコミュニティがものづくりを行う潮流。
- ポイント：DIYの考え方を基盤に、個人でも製品開発・販売ができるようになった。

#### リーンスタートアップ（Lean Startup）

- 意味：最小限の製品（MVP）を素早く作って市場に出し、顧客の反応を基に改善を繰り返す事業立ち上げの手法。
- ポイント：構築→計測→学習のサイクル。無駄（ムダな開発）を省くのが狙い。

#### APIエコノミー（えーぴーあいえこのみー / API Economy）

- 意味：APIを公開・利用して、企業同士のサービスやデータをつなぎ、新しいビジネスや価値を生み出す経済圏。
- 例：地図API、決済APIを組み合わせたサービス。

#### 市場創生（しじょうそうせい / Market Creation）

- 意味：これまでにない価値を提供し、新しい市場そのものを生み出すこと。

#### 市場価値（しじょうかち / Market Value）

- 意味：商品・サービスが市場で認められる価値（顧客がいくらまでなら払うか）。

#### イノベータ理論（いのべーたりろん / Innovator's Theory）

- 意味：新しい製品・技術が社会に普及していく過程を、採用時期の早い順に5つの層に分けて説明した理論（ロジャーズ）。
- ポイント：イノベータ2.5%＋アーリーアダプタ13.5%＝16%を超えると普及が加速するとされる（16%の壁）。

#### R&D（あーるあんどでぃ / Research and Development）

- 意味：研究開発。新しい製品や技術を生み出すための研究と、それを実用化する開発の活動。

#### VC（ぶいしー / Venture Capital）

- 意味：成長が見込まれる未上場のスタートアップに出資し、株式公開や売却で大きなリターンを狙う投資会社（ファンド）。

#### CVC（しーぶいしー / Corporate Venture Capital）

- 意味：事業会社が自ら設立する、スタートアップへの投資を行う組織（ファンド）。
- ポイント：VCは主に金銭的リターンが目的、CVCは自社の事業とのシナジー（新技術の獲得など）も目的。

#### MFTフレームワーク（えむえふてぃふれーむわーく / MFT Framework）⚠要確認

- 意味：市場（Market）・製品やサービスの機能（Function）・技術（Technology）の3層を対応づけて、技術がどの市場価値につながるかを整理する技術戦略のフレームワーク。
- ポイント：自社の技術を、どの機能を通じてどの市場に活かすかを考える。
- ⚠要確認：サイトでは「技術開発戦略を構築するための指針」とだけ説明され、M・F・Tの中身は書かれていない。上記は一般的な説明。

#### 価値創出の三要素（かちそうしゅつのさんようそ / Value Creation, Value Delivery, Value Capture）

- 意味：企業が価値を生み、利益にするための3要素＝価値創造（価値を作る）・価値提供（顧客に届ける）・価値獲得（対価として利益を得る）。
- ポイント：良い技術を作っても、届けて収益化できなければ事業にならない。

#### 技術のSカーブ（ぎじゅつのえすかーぶ / Technology S-Curve）

- 意味：技術の性能は、初期はゆっくり→急速に向上→限界に近づき鈍化する、というS字型の曲線で表されるという考え方。
- ポイント：性能向上が頭打ちになったら、次の新技術（次のSカーブ）への乗り換えを検討する。

#### キャズム（Chasm）

- 意味：新製品が初期市場（イノベータ・アーリーアダプタ）からメインストリーム市場（アーリーマジョリティ以降）へ広がる際にある大きな溝。
- ポイント：アーリーアダプタとアーリーマジョリティの間にある。

#### 魔の川（まのかわ / Devil River）⚠要確認

- 意味：基礎研究の成果を、具体的な製品開発へつなげる段階で立ちはだかる障壁。
- ⚠要確認：サイトの説明は「顧客がもたらす価値とビジネスの成果との関係」となっており、一般的な定義（研究→開発の間の障壁）と異なる。

#### 死の谷（しのたに / Valley of Death）

- 意味：製品開発から事業化へ移る段階で、資金や資源が不足して多くのプロジェクトが失敗する障壁。

#### ダーウィンの海（だーうぃんのうみ / Darwinian Sea）

- 意味：事業化した製品が市場で競合と競争し、生き残って産業として定着するまでの障壁。
- ポイント：魔の川→死の谷→ダーウィンの海の順番が問われる。

#### ハイプサイクル（Hype Cycle）⚠要確認

- 意味：新技術に対する世間の期待度が時間とともにどう変化するかを示したモデル（ガートナー社）。
- ポイント：①黎明期 → ②過度な期待のピーク期 → ③幻滅期 → ④啓発期 → ⑤生産性の安定期 の5段階。
- ⚠要確認：サイトでは「五つの段階」としながら4段階分しか名称が書かれておらず、各段階の訳語も一般的な表記（ガートナー日本法人の表記）と異なる。

#### QCDE（きゅーしーでぃーいー / Quality Cost Delivery Environment）

- 意味：製品・サービスを評価する4つの観点＝品質（Quality）・コスト（Cost）・納期（Delivery）・環境（Environment）。
- ポイント：一般的なQCDに環境（E）を加えたもの。

### 技術動向の把握・研究開発の進め方

#### 製品動向（せいひんどうこう / Product Trends）

- 意味：市場に出ている製品がどのように変化し、どのように受け入れられているかの傾向。

#### 技術動向（ぎじゅつどうこう / Technology Trend）

- 意味：ある技術がどの方向へ発展しているかの傾向。どの技術に投資すべきかを判断する材料になる。
- 注：#19 経営戦略マネジメントにも同名の用語あり。

#### 標準化動向（ひょうじゅんかどうこう / Standardization Trends）

- 意味：技術の規格・標準がどう定められ、変化しているかの動き。互換性や市場の広がりに影響する。

#### コア技術（こあぎじゅつ / Core Technology）

- 意味：企業の競争力の中心となる基盤技術。製品の性能や差別化を大きく左右する。
- ポイント：コアコンピタンス（#19）の技術版と考えるとよい。

#### 技術研究（ぎじゅつけんきゅう / Technical Research）

- 意味：新しい技術や改良点を探究し、製品開発や技術革新の土台を作る活動。

#### 委託研究（いたくけんきゅう / Contract Research）

- 意味：外部の研究機関や専門家に研究を依頼し、成果を受け取る形態。
- ポイント：共同研究は「一緒に行う」、委託研究は「任せる」。

#### 共同研究（きょうどうけんきゅう / Collaborative Research）

- 意味：複数の組織が資源・知識・技術を持ち寄り、協力して行う研究。

#### 技術マーケティング（ぎじゅつまーけてぃんぐ / Technical Marketing）

- 意味：自社の技術を活かせる市場や用途を探し、技術製品の価値を顧客に分かりやすく伝える活動。

#### 発想法（はっそうほう / Idea Generation Techniques）

- 意味：新しいアイデアを生み出すための手法の総称（例：ブレーンストーミング、KJ法、デザイン思考）。

#### 成功事例（せいこうじれい / Success Case）

- 意味：目標や課題を達成できた事例。技術開発戦略を立てる際の参考情報になる。

#### デザイン思考（でざいんしこう / Design Thinking）

- 意味：ユーザーへの共感から出発し、課題定義→アイデア→試作→テストを繰り返して解決策を作る考え方。
- 注：#19にも同名の用語あり。

#### システム思考（しすてむしこう / Systems Thinking）

- 意味：物事を要素の集まりとしてではなく、要素同士のつながり・相互作用を含めた全体として捉える考え方。
- ポイント：部分最適ではなく全体最適を目指す。

#### ペルソナ法（ぺるそなほう / Persona Method）

- 意味：典型的なユーザー像を、具体的な架空の人物（ペルソナ）として設定し、そのニーズや行動を基に開発・企画する手法。

#### バックキャスティング（Backcasting）

- 意味：あるべき未来の姿（目標）を先に決め、そこから逆算して今やるべきことを考える手法。
- ポイント：現在から積み上げて未来を予測する「フォアキャスティング」と対になる。

#### PoC（ぽっく / Proof of Concept）

- 意味：概念実証。新しいアイデアや技術が、実際に実現・機能するかを小規模に試して確かめること。

#### PoV（ぽぶ / Proof of Value）

- 意味：価値実証。新しい技術・製品が、顧客や業務にとって実際に価値（効果）があるかを確かめること。

#### PoB（ぴーおーびー / Proof of Business）

- 意味：事業実証。ビジネスとして収益を上げ、継続できるかを確かめること。
- ポイント：PoC（できるか）→PoV（価値があるか）→PoB（儲かるか）の順。

#### MVP（えむぶいぴー / Minimum Viable Product）

- 意味：顧客に価値を提供できる最小限の機能だけを備えた製品。早期にフィードバックを得るために作る。
- ポイント：リーンスタートアップの中心となる考え方。

### 技術の獲得・提携・知的財産

#### 技術獲得（ぎじゅつかくとく / Acquisition of Technology）

- 意味：必要な技術を手に入れること。自社開発、他社からの購入、提携、ライセンス契約、M&Aなどの方法がある。

#### 技術供与（ぎじゅつきょうよ / Technology Transfer）

- 意味：自社の技術やノウハウを他社に提供すること（多くはライセンス料などの対価を得る）。

#### 技術提携（ぎじゅつていけい / Technology Alliance）

- 意味：複数の企業が技術や知見を共有し、共同で開発などを行う協力関係。

#### M&A（えむあんどえー / Mergers and Acquisitions）

- 意味：企業の合併と買収。技術開発の文脈では、他社の技術や人材を丸ごと短期間で獲得する手段。
- 注：#19にも同名の用語あり。

#### 産学官連携（さんがくかんれんけい / Industry-Academia-Government Collaboration）

- 意味：企業（産）・大学など（学）・国や自治体（官）が協力して、技術開発や社会課題の解決を進めること。

#### TLO（てぃーえるおー / Technology Licensing Organization）

- 意味：技術移転機関。大学の研究成果を特許化し、企業にライセンスして実用化を進める組織。
- ポイント：産学連携の橋渡し役。ライセンス収入は研究資金に還元される。

#### 標準化戦略（ひょうじゅんかせんりゃく / Standardization Strategy）

- 意味：自社の技術を業界標準（規格）にすることや、標準に合わせることで、市場での優位や互換性を確保する戦略。
- ポイント：デジュレ標準（公的機関が決める）とデファクト標準（市場競争の結果、事実上の標準になる）がある。

#### 知的財産権（ちてきざいさんけん / Intellectual Property Rights）

- 意味：発明・著作物・デザイン・商標など、知的な創作の成果を一定期間独占的に利用できる権利。
- ポイント：特許権・実用新案権・意匠権・商標権（産業財産権）と著作権などを含む。

#### 早期審査制度（そうきしんさせいど / Accelerated Examination System）

- 意味：一定の条件を満たす特許出願などについて、通常より早く審査してもらえる制度。

#### パテントプール（Patent Pool）

- 意味：複数の特許権者が特許を持ち寄って一括管理し、まとめて第三者にライセンスする仕組み。
- ポイント：標準規格（例：動画圧縮方式）の普及で使われる。

#### クロスライセンス（Cross Licensing）

- 意味：特許を持つ企業同士が、互いの特許の使用を許可し合う契約。
- ポイント：パテントプールは「多数で1か所に集める」、クロスライセンスは「当事者同士で交換」。

#### 防衛特許（ぼうえいとっきょ / Defense Patent）⚠要確認

- 意味：自社の製品・技術を守るために取得する特許。他社に特許を取られて自社が使えなくなる事態を防ぐことが主な目的。
- ⚠要確認：サイトでは「他者がその技術を使用できないようにする役割」と説明されている。一般的には「自社が自由に実施できる状態を守る（他社の権利化を防ぐ）」ことが主目的とされることが多い。

#### アイディアソン（Ideathon）

- 意味：アイデア（Idea）＋マラソン（Marathon）。テーマに沿って参加者がチームで短時間にアイデアを出し合うイベント。
- ポイント：アイデア出しまで。実際に作るのはハッカソン。

#### ハッカソン（Hackathon）

- 意味：ハック（Hack）＋マラソン。技術者やデザイナーがチームを組み、短期間（1日〜数日）で試作品（プロトタイプ）を作るイベント。

#### 技術開発投資計画（ぎじゅつかいはつとうしけいかく / Technology Development Investment Plan）

- 意味：技術開発に必要な資金・資源をどこにどれだけ投じるかを定める計画。

#### 技術開発拠点計画（ぎじゅつかいはつきょてんけいかく / Technological Development Base Plan）

- 意味：研究所など技術開発を行う拠点を、どこにどう整備・運営するかを定める計画。

#### 人材計画（じんざいけいかく / Human Resource Planning）

- 意味：将来必要となる人材の数やスキルを見積もり、採用・育成・配置を計画すること。

#### 経営資源の最適配分（けいえいしげんのさいてきはいぶん / Optimal Allocation of Management Resources）

- 意味：人材・資金・設備・時間などの経営資源を、最も効果が出るようにプロジェクトや事業に振り分けること。

#### 投資対効果（とうしたいこうか / Return on Investment）

- 意味：投資した金額に対して、どれだけの利益・効果が得られたかを示す指標（ROI）。
- ポイント：ROI＝利益÷投資額×100（%）。例：100万円投資して20万円の利益 → ROI 20%。

#### コンカレントエンジニアリング（Concurrent Engineering）

- 意味：設計・製造・テストなどの工程を順番に行うのではなく、関係部門が同時並行で協力して進め、開発期間を短縮する手法。

#### パイロット生産（ぱいろっとせいさん / Pilot Production）

- 意味：量産を始める前に、小規模に試験的な生産を行い、品質や生産性、量産時の課題を確かめること。

#### 知的財産権管理（ちてきざいさんけんかんり / Intellectual Property Rights Management）

- 意味：特許・著作権・商標などの知的財産権を取得・保護し、活用（ライセンスなど）するための管理活動。

#### 市場ニーズ（しじょうにーず / Market Needs）

- 意味：市場の顧客が求めている商品・サービスへの要求や期待。技術開発計画の出発点となる。
- ⚠要確認：20-2内で同じ用語が2回掲載されている。

#### 技術ロードマップ（ぎじゅつろーどまっぷ / Technology Roadmap）

- 意味：技術を将来に向けてどのように開発・発展させるかを、時間軸に沿って図示した計画。

#### 製品応用ロードマップ（せいひんおうようろーどまっぷ / Product Application Roadmap）

- 意味：開発した技術を、どの製品にいつ応用し市場投入するかを時間軸で示した計画。

#### 特許取得ロードマップ（とっきょしゅとくろーどまっぷ / Patent Acquisition Roadmap）

- 意味：どの技術について、いつ特許を取得するかを時間軸で示した計画。

#### 市場ニーズ（しじょうにーず / Market Needs）⚠重複

- サイト上で2回目の掲載。内容は上記「市場ニーズ」と同じ。

- ア：技術の期待感の推移を表すものであり，黎明期，流行期，反動期，回復期，安定期に分類される。
- イ：技術の進歩の過程を表すものであり，当初は緩やかに進歩するが，やがて急激に進歩し，成熟期を迎えると進歩は停滞気味になる。

- イの意味：正しい。技術のSカーブ。緩やか→急激→停滞の順に進歩する。
- ウの意味：経験曲線（学習曲線）の説明。累積生産量が増えるほど生産性が上がり、単位当たりのコストが下がる。
