## 16-1 システム監査

### まとめ表

**システム監査の流れ（システム監査基準 令和5年）**

| 段階 | すること | 主な成果物 |
| :-: | :-: | :-: |
| 監査計画の策定 | リスクの大きさで優先度を決め（リスクアプローチ）、目的・範囲・方法・時期・体制を決める | 中長期計画・年度計画・個別監査計画 |
| 予備調査 | 資料の閲覧や聞き取りで、監査対象の実態（業務内容・業務分掌・体制）をつかむ | 本調査の監査手続書 |
| 本調査 | 監査手続を実施し、十分かつ適切な監査証拠を入手して評価する | 監査調書 |
| 結論の形成 | 監査証拠と監査調書から結論を出す | 指摘事項・改善提案 |
| 報告 | 監査報告書を作り、依頼者（経営者など）に報告する | 監査報告書 |
| フォローアップ | 改善が監査対象先の責任で行われているかを、監査人が事後に確かめる | フォローアップ報告書 |

**システム監査基準とシステム管理基準（経済産業省）**

| 名前 | 何か | 例えると |
| :-: | :-: | :-: |
| システム監査基準 | 監査人の**行為規範**。監査をどう行うか（倫理・計画・証拠・調書・報告・フォローアップ） | 監査人のルールブック |
| システム管理基準 | 監査で使う**判断の尺度**。情報システムのガバナンス・マネジメント・コントロールのあるべき姿 | 採点の物差し |

- 平成30年版 → 令和5年版に改訂された。過去問は出題の年によってどちらかを指定している（R5秋までは平成30年版、R6春からは令和5年版が多い）
- 令和5年版は「システム監査の属性」「実施」「報告」の三つに分けた12の基準と、「監査人の倫理」の4原則（誠実性・客観性・監査人としての能力及び正当な注意・秘密の保持）から成る

**監査人がすること・しないこと（よく出る誤りの選択肢）**

| 監査人がすること | 監査人がしないこと |
| :-: | :-: |
| 指摘事項と改善提案を報告する | 改善計画を作る（作るのは監査対象先） |
| 改善状況をモニタリング（フォローアップ）する | 改善の実施を指示する・改善プロジェクトを管理する |
| 監査調書を作り、保管する | 監査調書を社内に全部公開する・作らずに済ませる |
| 保証型か助言型かを依頼者のニーズで決める | 自分の都合だけで決める |

### 監査の種類

#### システム監査（System Audit）

- 意味：情報システムにかかわるリスクに適切に対応しているかを、独立かつ客観的な立場のシステム監査人が検証・評価し、保証や助言を行う監査。組織体の目標達成と、利害関係者への説明責任を果たすことに役立てる
- ポイント：対象は情報システムのガバナンス・マネジメント・コントロール。会計の正しさを見るのは会計監査、業務全般の有効性・効率性を見るのは業務監査、情報セキュリティに絞ったものは情報セキュリティ監査
- 語の意味：System＝体系・仕組み／Audit＝監査（ラテン語 audire＝聞く、が語源）

#### 会計監査（Accounting Audit）

- 意味：財務諸表などの会計記録が、会計の基準に従って正しく作られているかを確かめる監査
- ポイント：上場企業などでは公認会計士・監査法人による会計監査が法律で義務付けられている（法定監査）。業務の進め方全体を見るのは業務監査、情報システムを見るのはシステム監査
- 語の意味：Accounting＝会計／Audit＝監査

#### 業務監査（Operational Audit）

- 意味：会計以外の業務全般について、組織や制度・業務の進め方が有効かつ効率的に行われているかを確かめる監査
- ポイント：会社法では監査役が取締役の職務執行を監査する（業務監査と会計監査の両方）。会計記録だけを見るのは会計監査、経営方針の妥当性まで見るものは経営監査
- 語の意味：Operational＝業務の／Audit＝監査

#### 経営監査（Management Audit）

- 意味：経営の方針・戦略・組織そのものが妥当で、目標達成に役立っているかを評価する監査
- ポイント：業務の進め方を見る業務監査より上の層を見る。会計監査・業務監査・システム監査と並べて出る
- 語の意味：Management＝経営／Audit＝監査

#### 情報セキュリティ監査（Information Security Audit）

- 意味：情報資産のリスクに対して、情報セキュリティのコントロールが適切に整備・運用されているかを、独立かつ専門的な立場で検証・評価する監査。経済産業省の情報セキュリティ監査基準に沿って行う
- ポイント：判断の尺度は情報セキュリティ管理基準。保証型と助言型がある。情報システム全体を対象にするのはシステム監査、個人情報の扱いに絞ったものは個人情報保護監査
- 例：R3秋 問57（保証型と助言型の監査の実施）
- 語の意味：Information＝情報／Security＝安全／Audit＝監査

#### 個人情報保護監査（Personal Information Protection Audit）

- 意味：個人情報が法律や JIS Q 15001 に沿って適切に取り扱われ、漏えいなどのリスクに対策が取られているかを確かめる監査
- ポイント：プライバシーマークの取得・更新でも、自社の個人情報保護マネジメントシステムの内部監査が求められる。情報セキュリティ全般を見るのは情報セキュリティ監査
- 語の意味：Personal＝個人の／Information＝情報／Protection＝保護

#### コンプライアンス監査（Compliance Audit）

- 意味：法令・規則・社内規程・行動指針などが守られているか（法令遵守の状況）を確かめる監査
- ポイント：準拠性を中心に見る。職務分掌・倫理・透明性も対象になる。業務の効率を見るのは業務監査
- 語の意味：Compliance＝法令などを守ること（comply＝従う）

#### マネジメントシステム監査（Management System Audit）

- 意味：品質（ISO 9001）・環境（ISO 14001）・情報セキュリティ（ISO/IEC 27001）・サービス（ISO/IEC 20000-1）・事業継続（ISO 22301）などのマネジメントシステムが、規格の要求事項に適合し有効に運用されているかを確かめる監査
- ポイント：指針は JIS Q 19011。内部監査（第一者監査）・取引先による監査（第二者監査）・認証機関による審査（第三者監査）がある
- 例：R4秋 問58（JIS Q 27001 に基づく ISMS 内部監査）
- 語の意味：Management＝管理／System＝仕組み／Audit＝監査

#### 法定監査（Statutory Audit）

- 意味：法律で実施が義務付けられている監査。金融商品取引法監査・会社法監査など
- ポイント：システム監査は、法律の義務ではなく組織が自ら行う任意監査であることが多い。法定監査と連携して行う
- 語の意味：Statutory＝法律で定められた／Audit＝監査

#### 任意監査（Voluntary Audit）

- 意味：法律の義務ではなく、組織が自らの必要で行う監査
- ポイント：システム監査・情報セキュリティ監査の多くは任意監査。義務があるものは法定監査
- 語の意味：Voluntary＝自発的な／Audit＝監査

#### 内部監査（Internal Audit）

- 意味：組織の内部の監査部門（内部監査人）が、経営者の指示で行う監査。組織の目標達成に役立つよう、リスクマネジメント・コントロール・ガバナンスを評価し改善を促す
- ポイント：監査部門は監査対象の部門から独立させ、経営者（社長など）の直属に置く。外部の専門家が行うのは外部監査
- 例：R4秋 問58（ISMS 内部監査）
- 語の意味：Internal＝内部の／Audit＝監査

#### 外部監査（External Audit）

- 意味：組織の外部の独立した専門家（監査法人・外部のシステム監査人など）が行う監査
- ポイント：外観上の独立性を保ちやすく、第三者への説明に向く。組織内の監査部門が行うのは内部監査
- 語の意味：External＝外部の／Audit＝監査

#### 立入監査（On-site Audit）

- 意味：監査人が監査対象の部門や委託先の現場に実際に立ち入って行う監査
- ポイント：現地調査法と組み合わせる。委託先の場合、第三者の保証報告書に依拠できれば現地調査を省けることがある（R4春 問60 イ）
- 語の意味：On-site＝現場での／Audit＝監査

#### 保証型監査（保証を目的としたシステム監査 / Assurance Audit）

- 意味：監査人が入手した証拠を客観的に評価し、コントロールが適切であるという監査の結論や意見を述べて、一定の保証を与える監査
- ポイント：外部への説明や開示に使う。不特定多数の利害関係者がいるシステムでは、定期的に実施し結果を開示すると有用（R3秋 問57 エ）。改善の助言をするのは助言型監査
- 例：R3秋 問57
- 語の意味：Assurance＝保証・確信

#### 助言型監査（助言を目的としたシステム監査 / Advisory Audit）

- 意味：監査で見つかった問題点について、改善のための助言・提案・相談を行う監査。依頼者の求めに応じて行うことが多い
- ポイント：保証型と助言型は排他的ではなく、組み合わせてもよい。どちらで行うかは監査の依頼者のニーズで決める（R3秋 問57）
- 例：R3秋 問57
- 語の意味：Advisory＝助言の

### 監査の対象

#### 情報システムリスク（Information System Risk）

- 意味：情報システムにかかわって、組織体の目標達成を妨げるおそれのあるリスク。システムの障害・不正・セキュリティ事故だけでなく、IT の活用が不十分で機会を逃すことも含む
- ポイント：システム監査は、このリスクに適切に対応しているかを検証・評価する。リスクの大きさで監査の優先度を決めるのがリスクアプローチ
- 語の意味：Information＝情報／System＝仕組み／Risk＝危険・不確かさ

#### ガバナンス（監査の視点 / Governance）

- 意味：組織体の目標の達成を保証する仕組み。経営陣が方向付け（IT 戦略・方針）をし、モニタリングする（システム監査基準 令和5年の用語）
- ポイント：令和5年版のシステム監査基準では、監査の対象は情報システムの「ガバナンス・マネジメント・コントロール」の三つ（R6春 問59）。IT 投資のリターンや新技術の活用はガバナンスの視点（R7秋 問60 ア・エ）
- 例：R6春 問59（正解）、R7秋 問60
- 語の意味：Governance＝統治（govern＝治める）

#### マネジメント（監査の視点 / Management）

- 意味：ガバナンスで設定された方向に、組織体の目標を達成させるために、計画・構築・運営・モニタリングを行う活動
- ポイント：PDCA を回して管理されているか、を見るのがマネジメントの視点（R7秋 問60 ウ）。方向付けはガバナンス、一つ一つの管理手段はコントロール
- 例：R7秋 問60 ウ
- 語の意味：Management＝管理・経営

#### コントロール（監査の視点 / Control）

- 意味：リスクを低減するために取られる全ての管理手段。組織的・人的・技術的・物理的な手段がある
- ポイント：異常なアクセスを検出したら適時に対処し報告する、のような個々の手段がコントロールの視点（R7秋 問60 イ）。内部統制の「統制活動」とほぼ同じ意味
- 例：R7秋 問60（正解はイ）
- 語の意味：Control＝管理・統制

### 評価の観点

#### 準拠性（Compliance）

- 意味：法令・規程・基準・契約などに従っているかどうか
- ポイント：コンプライアンス監査で主に見る。有効性はねらった効果が出ているか、効率性は資源を無駄なく使っているか
- 語の意味：準拠＝よりどころに従うこと

#### 有効性（Effectiveness）

- 意味：情報システムやコントロールが、ねらった目的や効果を達成しているかどうか
- ポイント：効果が出ているかが有効性、少ない資源で出しているかが効率性。システム監査はこれらの視点から評価する
- 語の意味：Effective＝効果のある

#### 効率性（Efficiency）

- 意味：情報システムが、投入した資源（費用・時間・人）に見合う成果を、無駄なく生み出しているかどうか
- ポイント：開発・運用・保守プロセスの「信頼性・効率性」として用語例に出る。目的を達成しているかは有効性
- 語の意味：Efficient＝無駄のない

#### 信頼性（Reliability）

- 意味：情報システムが、障害が少なく、正しく処理を続けられるかどうか。データの正確性・網羅性も含めて見る
- ポイント：マスタファイルの監査項目では、二重化で止まりにくくするのは可用性、入力チェックは正確性（完全性）、特権アカウントの制限は機密性（R3春 問59）
- 語の意味：Reliable＝頼りになる

#### 可用性（監査項目 / Availability）

- 意味：必要なときに情報システムやデータを使える状態にあること
- ポイント：R3春 問59 では「サーバを二重化して耐障害性を高めている」が可用性の監査項目。権限の制限は機密性、入力チェックは完全性（インテグリティ）
- 例：R3春 問59（正解はア）
- 語の意味：Available＝利用できる

### 監査人の倫理

#### 監査人の倫理（Auditor's Ethics）

- 意味：システム監査基準（令和5年）が示す、監査人が守るべき4つの原則。誠実性・客観性・監査人としての能力及び正当な注意・秘密の保持
- ポイント：令和5年版で「監査人の倫理」として前に置かれた。独立性は基準4「監査の独立性と客観性の保持」で別に定められている
- 語の意味：倫理＝人として守るべき道

#### 誠実性（Integrity）

- 意味：監査の業務で、常に正直な態度を保ち、強い意志をもって適切に行動すること。監査人の倫理の4原則の一つ
- ポイント：監査人の倫理の4原則の一つ。偏らない判断は客観性、知り得た秘密を守るのは秘密の保持
- 語の意味：Integrity＝誠実さ・高潔さ

#### 客観性（Objectivity）

- 意味：個人や組織から不当な影響を受けず、偏りや利害の対立なしに監査人が判断すること。監査人の倫理の4原則の一つ
- ポイント：外から影響を受けていない「状態」が独立性、判断の「中身」が偏っていないのが客観性。どちらも基準4で保持を求めている
- 語の意味：Objective＝客観的な（object＝対象）

#### 独立性（Independence）

- 意味：第三者から不当な影響や圧力などを受けていない状態（システム監査基準 令和5年の用語）。外観上の独立性と精神上の独立性がある
- ポイント：R7秋 問58 の正解。監査部門を対象部門から切り離し、経営者の直属にするのは外観上の独立性を保つため
- 例：R7秋 問58（正解はエ）
- 語の意味：Independence＝独立（depend＝頼る、に否定の in）

#### 外観上の独立性（Independence in Appearance）

- 意味：監査人が、監査対象とは身分上・組織上・利害上のかかわりがなく、外から見て独立していること。独立性の一つ
- ポイント：自分が開発に参加したシステムを監査すると、外観上の独立性が損なわれる。心の持ち方の独立は精神上の独立性
- 語の意味：Appearance＝見かけ・外観

#### 精神上の独立性（Independence in Mind）

- 意味：監査人が、公正で客観的な態度を保ち、偏らずに判断すること。独立性の一つ
- ポイント：外観上の独立性と合わせて、独立性の両面になる。外から見て分かる関係の有無は外観上の独立性
- 語の意味：Mind＝心・精神

#### 正当な注意（Due Professional Care）

- 意味：監査の実施過程で、監査人として当然払うべき注意（システム監査基準 令和5年の用語）。監査人の倫理の4原則の一つ
- ポイント：R7秋 問58 ウ「監査で発見したことに基づく考えや意見」は所見の説明で、正当な注意ではない
- 例：R7秋 問58 ウ（誤り）
- 語の意味：Due＝当然の・正当な／Care＝注意

#### 正当な懐疑心（Professional Skepticism）

- 意味：何事も当然のこととせず、疑ってみる、又は確認してみる心（システム監査基準 令和5年の用語）
- ポイント：R7秋 問58 イ「客観性の保持という精神的な態度を堅持できること」は精神上の独立性に近い説明で、正当な懐疑心ではない
- 例：R7秋 問58 イ（誤り）
- 語の意味：懐疑＝疑いをもつこと／Skepticism＝懐疑

#### 秘密の保持（Confidentiality）

- 意味：監査人が、監査の業務上知り得た秘密を、正当な理由なく他に開示したり、自らの利益のために使ったりしないこと。監査人の倫理の4原則の一つ
- ポイント：監査人の倫理の4原則の一つ。監査調書を社内に全部公開すべき、という選択肢はこれに反する（R4春 問59 ア）
- 語の意味：Confidential＝内密の

#### 専門的能力の保持と向上（Professional Competence）

- 意味：監査人が、監査を適切に行うのに必要な知識・技能を持ち、継続的に高めること（基準2）
- ポイント：新しい技術（クラウド・AI・アジャイル）の監査にも対応できるよう学び続ける。監査の品質を組織として確保するのは基準3
- 語の意味：Professional＝専門職の／Competence＝能力

### 監査の体制

#### システム監査人の権限と責任（Authority and Responsibility）

- 意味：監査を行う権限（資料を求める・立ち入るなど）と責任を、監査規程や契約書などの文書で明らかにすること（基準1）
- ポイント：内部監査なら内部監査規程、外部に頼むならシステム監査委託契約書で定める。監査の目的や対象範囲もここで明確にする
- 語の意味：Authority＝権限／Responsibility＝責任

#### 内部監査規程（Internal Audit Charter）

- 意味：組織内の監査部門の目的・権限・責任・独立性・監査の進め方などを定めた社内規程。経営者（取締役会）が承認する
- ポイント：外部の監査人に頼むときに権限と責任を定めるのはシステム監査委託契約書
- 語の意味：Internal＝内部の／Charter＝憲章・規程

#### システム監査委託契約書（Audit Engagement Contract）

- 意味：外部のシステム監査人に監査を頼むとき、目的・範囲・権限・責任・報告の方法などを定めた契約書
- ポイント：内部の監査部門の場合は内部監査規程で定める
- 語の意味：委託＝任せること／Engagement＝業務の引受け

#### 監査の品質の確保（Quality Assurance of Audit）

- 意味：監査に対するニーズを満たしているかを含めて、一定の監査品質を確保するための体制を整え、運用すること（基準3）
- ポイント：監査の手順や調書をレビューする、外部の評価を受けるなど。監査人個人の能力を高めるのは基準2
- 語の意味：Quality＝品質／Assurance＝保証

### 監査の基準と指針

#### システム監査基準（System Audit Standards）

- 意味：経済産業省が定めた、システム監査を行う監査人の行為規範。システム監査業務の品質を確保し、有効かつ効率的な監査を実現するためのもの。平成30年版を改訂した令和5年版がある
- ポイント：監査人が「どう監査するか」の規範。判断の尺度（物差し）は システム管理基準。監査人が持つべき知識・技能の水準を定めたもの（R4秋 問60 イ）ではない
- 例：R4秋 問60（正解はア）
- 語の意味：Standards＝基準・標準

#### システム管理基準（System Management Standards）

- 意味：経済産業省が定めた、情報システムのガバナンス・マネジメント・コントロールの点検・評価・検証で使う判断の尺度。組織が情報システムを管理するときの実践規範にもなる
- ポイント：R4秋 問60 ウ「判断の尺度となるもの」はシステム管理基準の意義で、システム監査基準ではない。令和5年版のユーザ受入テストの項目は R7春 問60
- 例：R3秋 問58（アジャイル開発の監査の着眼点）、R7春 問60（ユーザ受入テスト）
- 語の意味：Management＝管理

#### システム管理基準追補版（財務報告に係る IT 統制ガイダンス）

- 意味：金融商品取引法の内部統制報告制度に対応して、財務報告にかかわる IT 統制の整備と評価の考え方をまとめた、システム管理基準の追補版
- ポイント：IT に係る全般統制と業務処理統制を具体的に示している。内部統制の評価の基準そのものは金融庁の実施基準
- 語の意味：追補＝あとから補うこと

#### 情報セキュリティ監査基準（Information Security Audit Standards）

- 意味：経済産業省が定めた、情報セキュリティ監査を行う監査人の行為規範。実施基準ガイドラインで保証型と助言型の進め方を示している
- ポイント：判断の尺度は情報セキュリティ管理基準。システム監査基準・システム管理基準と同じ「監査基準と管理基準」の組
- 例：R3秋 問57（実施基準ガイドライン）
- 語の意味：Security＝安全／Audit＝監査

#### 情報セキュリティ管理基準（Information Security Management Standards）

- 意味：経済産業省が定めた、情報セキュリティ監査で使う判断の尺度。JIS Q 27001・JIS Q 27002 をもとに、マネジメント基準と管理策基準から成る
- ポイント：R3春 問58（マルウェア対策の監査）はこの基準をもとにしている。クラウドに特化したものはクラウド情報セキュリティ管理基準
- 例：R3春 問58
- 語の意味：Management＝管理

#### クラウド情報セキュリティ管理基準（Cloud Information Security Management Standards）

- 意味：クラウドサービスの事業者と利用者の情報セキュリティ管理策をまとめた、経済産業省の管理基準。ISMAP（政府のクラウドの評価制度）の基礎にもなっている
- ポイント：情報セキュリティ管理基準のクラウド版。クラウドの監査で判断の尺度に使う
- 語の意味：Cloud＝雲（インターネットの向こうのサービス）

#### JIS Q 19011（ISO 19011）

- 意味：マネジメントシステム監査のための指針。監査プログラムの管理、監査の実施、監査員の力量を示した規格
- ポイント：品質・環境・情報セキュリティなど、どのマネジメントシステムの監査にも使える共通の指針。要求事項そのものは各規格（JIS Q 27001 など）にある
- 語の意味：JIS＝日本産業規格／Q＝管理システムの部門

#### 内部監査基準（Internal Auditing Standards）

- 意味：内部監査を行う際の基準。日本では日本内部監査協会が、国際的には内部監査人協会（IIA）が定める
- ポイント：IIA の基準体系は IPPF（専門職的実施の国際フレームワーク）。システム監査は内部監査の一部として行われることが多い
- 語の意味：Internal＝内部の／Auditing＝監査すること

#### IPPF（あいぴーぴーえふ / International Professional Practices Framework）

- 意味：内部監査人協会（IIA）が定めた、内部監査の専門職的実施の国際フレームワーク。使命・基本原則・定義・倫理綱要・基準などから成る（2024年にグローバル内部監査基準へ改訂）
- ポイント：内部監査の国際的な基準体系。日本の内部監査基準もこれに沿っている
- 語の意味：International＝国際的な／Professional＝専門職の／Practices＝実務／Framework＝枠組み
### 監査計画

#### 監査計画（Audit Plan）

- 意味：有効かつ効率的に監査を行うために、監査の目的・テーマ・対象範囲・方法・実施時期・体制・スケジュールを決めた計画（基準6）
- ポイント：リスクの大きさに基づいて優先度を決める（リスクアプローチ）。種類は中長期計画・年度計画・個別監査計画（基準7）
- 語の意味：Audit＝監査／Plan＝計画

#### 中長期計画（Medium- to Long-term Audit Plan）

- 意味：数年先までのシステム監査の方針（重点テーマ・体制・人材の育成など）を明らかにする計画
- ポイント：R6春 問58 エ「中長期における方針等を明らかにすることを目的として作成する文書」は中長期計画の説明で、監査調書ではない
- 例：R6春 問58 エ（誤り）
- 語の意味：中長期＝数年先までの期間

#### 年度計画（Annual Audit Plan）

- 意味：1年間に行う監査の対象・時期・担当・予算を決めた計画。中長期計画を受けて作る
- ポイント：一つ一つの監査の細かい手順やスケジュールを決めるのは個別監査計画
- 語の意味：年度＝1年の区切り

#### 個別監査計画（Individual Audit Plan）

- 意味：監査対象ごとに、具体的な監査の目的・範囲・手続・スケジュール・担当を定めた詳細な計画
- ポイント：R6春 問58 ウ「監査対象ごとに具体的な監査スケジュールを定めた詳細計画」は個別監査計画の説明で、監査調書ではない
- 例：R6春 問58 ウ（誤り）
- 語の意味：個別＝一つずつ

#### リスクアプローチ（Risk-based Approach）

- 意味：監査対象のリスクの大きさ（起こりやすさ × 起きたときの影響）に基づいて、監査の対象・時間・人員・手続の優先度を決める監査の進め方
- ポイント：全部を同じ深さで見るのではなく、リスクの高いところに資源を集中する。監査計画の策定で使う
- 語の意味：Risk＝リスク／Approach＝取り組み方

### 調査の段階

#### 予備調査（Preliminary Survey）

- 意味：本調査の前に、資料の閲覧や関係者への聞き取りで、監査対象の実態（事務手続・マニュアル・業務内容・業務分掌・体制など）を把握する調査
- ポイント：必ず現地に行く必要はなく、範囲も監査対象部門に限らない。十分な監査証拠を入手するのは本調査（R5春 問58・R6秋 問59）
- 例：R5春 問58（正解はイ）、R6秋 問59（正解はア）
- 語の意味：Preliminary＝予備の／Survey＝調査

#### 本調査（Detailed Audit / Fieldwork）

- 意味：予備調査で作った監査手続に従い、監査の結論を裏付ける十分かつ適切な監査証拠を入手し、評価する調査
- ポイント：実態を把握するのは予備調査。本調査で入手した証拠は監査調書にまとめる
- 語の意味：本＝中心の

#### 監査手続（Audit Procedures）

- 意味：監査項目について、十分かつ適切な監査証拠を入手するための手順。一つの監査目的に対して、通常は複数の監査手続を組み合わせる
- ポイント：R4秋 問59＝R7春 問59 の正解。監査計画の立案や進捗管理の手順、報告書を書く手順、チームを編成する手順ではない
- 例：R4秋 問59（正解はウ）、R7春 問59、R4春 問60 エ
- 語の意味：Procedure＝手順

#### 監査の結論（Audit Conclusion）

- 意味：監査調書と監査証拠をもとに、監査の目的に対して監査人が出す判断（基準10）
- ポイント：保証型なら「適切である」などの意見、助言型なら改善が必要な点と改善提案になる。結論を出す前に、監査対象先と事実の確認をする
- 語の意味：Conclusion＝結論

### 監査証拠と監査調書

#### 監査証拠（Audit Evidence）

- 意味：監査の結論を裏付けるために必要な情報。資料・データ・証言・監査証跡を含む記録などの全て
- ポイント：十分かつ適切なものを入手する。アジャイル開発では、体裁の整った管理文書だけでなく、作業の記録やツールのデータも監査証拠に使える（R4春 問60 ア が誤り）。監査対応のためだけの文書を現場に求めないようにする
- 例：R4春 問60
- 語の意味：Evidence＝証拠

#### 十分かつ適切な監査証拠（Sufficient and Appropriate Evidence）

- 意味：監査の結論を支えるのに量が十分（十分性）で、目的に合い信頼できる（適切性）監査証拠。監査証拠に求められる条件
- ポイント：量の面が十分性、質の面が適切性。どちらかが欠けると結論を支えられない
- 語の意味：Sufficient＝十分な／Appropriate＝適切な

#### 監査証跡（Audit Trail）

- 意味：処理の開始から結果までを後から追いかけられるように残した記録。いつ・誰が・何をしたかが分かるログや承認の記録など
- ポイント：監査証跡を残せるように情報システムを作っておくと、監査証拠を入手しやすい。アクセスログやトランザクションログはその一部
- 語の意味：Trail＝通った跡

#### 監査調書（Audit Working Papers）

- 意味：実施した監査手続、入手した監査証拠及び監査人が到達した結論の記録。監査の結論に至った過程を明らかにし、結論を支える合理的な根拠とする（基準9）
- ポイント：作成は必須で、適切に保管する（バックアップも取る）。事実だけでなく監査人の所見も書く。社内に全部公開するものではない。監査チームでは共有する（R4春 問59・R5秋 問58・R6春 問58）
- 例：R4春 問59（イ）、R5秋 問58（ウ）、R6春 問58（ア）
- 語の意味：Working Papers＝作業の書類

#### 所見（Findings / Observations）

- 意味：監査で発見したこと、又は発見したことに基づく考えや意見（システム監査基準 令和5年の用語）
- ポイント：監査調書には、発見した事実とその所見を書く（R5秋 問58）。R7秋 問58 ではこの説明が「正当な注意」の誤りの選択肢になった
- 例：R5秋 問58、R7秋 問58 ウ
- 語の意味：所見＝見て思ったこと

### 監査証拠になる記録

#### アクセスログ（Access Log）

- 意味：誰が・いつ・どこから・何にアクセスしたかの記録
- ポイント：不正なアクセスから保護し、改ざんされないように保管する。特権的なアクセスのログも分析の対象にする。処理の中身（取引）の記録はトランザクションログ
- 語の意味：Access＝接続・利用／Log＝記録

#### トランザクションログ（Transaction Log）

- 意味：データベースへの更新処理（トランザクション）の内容を順に記録したもの
- ポイント：障害時の回復にも、監査証拠にも使う。利用の記録はアクセスログ
- 語の意味：Transaction＝取引・処理単位／Log＝記録

#### インシデント報告書（Incident Report）

- 意味：障害やセキュリティ事故などのインシデントの発生・影響・対応・原因を記録した報告書
- ポイント：運用のコントロールが働いているかを確かめる監査証拠になる。開発の進み具合を示すのは進捗管理資料、日々の作業は運用・保守の記録
- 語の意味：Incident＝出来事・事故／Report＝報告

#### 進捗管理資料（Progress Management Documents）

- 意味：開発プロジェクトの計画と実績、課題などをまとめた資料
- ポイント：開発プロセスの監査の監査証拠になる。運用の作業の記録は運用・保守の記録
- 語の意味：進捗＝物事の進み具合

#### 運用・保守の記録（Operation and Maintenance Records）

- 意味：日々のシステムの運用作業・変更・保守の作業の記録
- ポイント：運用・保守プロセスの信頼性を確かめる監査証拠になる
- 語の意味：Operation＝運用／Maintenance＝保守

#### プルーフリスト（Proof List）

- 意味：入力したデータの内容をそのまま印刷・出力した一覧。元の伝票と突き合わせて、入力の漏れ・重複・誤りを確かめる
- ポイント：R5秋 問59 の正解のもと。「漏れなく、重複なく」（網羅性）は伝票とプルーフリストの照合で確かめる。入力値の形式や論理の正しさはテストデータ法、例外取引の承認は抽出して確かめる
- 例：R5秋 問59（正解はウ）
- 語の意味：Proof＝確認・証明／List＝一覧

### 監査技法

#### チェックリスト法（Checklist Method）

- 意味：監査人が作った質問の一覧（チェックリスト）に、監査対象部門が回答する形で証拠を集める技法
- ポイント：チェックリストを作るのは監査人。監査対象部門が作って自分で点検するのは CSA（統制自己評価）に近い（R5春 問59 エ が誤り）
- 例：R5春 問59 エ（誤り）、R6秋 問58 イ
- 語の意味：Check＝確認／List＝一覧

#### ドキュメントレビュー法（Document Review Method）

- 意味：監査対象の状況を示す文書や記録を入手し、閲覧して内容を点検する技法
- ポイント：R7春 問58 ア「資料及び文書類を入手し、内容を点検する」はこの技法。口頭で聞くのはインタビュー法、プロセスを追いかけるのはウォークスルー法
- 例：R7春 問58 ア、R6秋 問58 エ
- 語の意味：Document＝文書／Review＝見直すこと

#### インタビュー法（Interview Method）

- 意味：監査人が、監査対象の関係者に直接、口頭で問い合わせ、回答を入手する技法。質問書や調査票を使うこともある
- ポイント：R5春 問59 の正解（ア）。R7春 問58 イ の説明もこれ。答えた内容は文書や記録で裏付けを取る
- 例：R5春 問59（正解はア）、R3秋 問59 ア、R7春 問58 イ
- 語の意味：Interview＝面接・聞き取り

#### ウォークスルー法（Walk-through Method）

- 意味：データの生成から入力・処理・出力・活用までのプロセスと、組み込まれているコントロールを、書面上で又は実際に追跡して確かめる技法
- ポイント：R3秋 問59・R6秋 問58・R7春 問58 と毎年のように出る。「追跡」「生成から活用まで」が決め手
- 例：R3秋 問59（イ）、R6秋 問58（ア）、R7春 問58（ウ）
- 語の意味：Walk through＝通り抜ける・一通り追う

#### 突合・照合法（Reconciliation / Matching Method）

- 意味：関連する記録どうし（伝票と入力データ、帳簿と現物など）を突き合わせて、一致しているかを確かめる技法
- ポイント：R5秋 問59 のプルーフリストと受注伝票の照合はこの考え方。プロセス全体を追いかけるのはウォークスルー法
- 例：R6秋 問58 ウ
- 語の意味：突合＝突き合わせること／照合＝照らし合わせること

#### 現地調査法（On-site Inspection Method）

- 意味：監査人が監査対象の現場に直接行って、自ら観察・調査する技法
- ポイント：業務時間外に行わなければならない、という決まりはない。業務の実態を見るには業務時間内に行うのが普通（R5春 問59 イ が誤り）
- 例：R5春 問59 イ（誤り）
- 語の意味：現地＝その場所

#### 統計的サンプリング（Statistical Sampling）

- 意味：母集団から確率に基づいてサンプルを抜き出して調べ、その結果から母集団全体を統計的に推定する方法
- ポイント：全件を見られないときに使う。抜き出し方を監査人の判断で決めるのは非統計的サンプリング。CAAT を使えば全件を調べることもできる
- 語の意味：Statistical＝統計の／Sampling＝標本を取ること

### コンピュータ支援監査技法

#### CAAT（きゃっと / Computer Assisted Audit Techniques）

- 意味：コンピュータ支援監査技法。監査ソフトウェアなどを使って、大量のデータの検索・抽出・計算などを行う監査技法
- ポイント：専用の監査ソフトに限らず、表計算ソフトなど汎用のソフトも使える（R5春 問59 ウ が誤り）。テストデータ法・監査モジュール法・並行シミュレーション法などがある
- 例：R5春 問59 ウ（誤り）
- 語の意味：Computer＝計算機／Assisted＝支援された／Audit＝監査／Techniques＝技法

#### 監査ソフトウェア（Audit Software）

- 意味：監査のために、データの抽出・集計・突合・分析を行うソフトウェア。汎用監査ソフトウェアなど
- ポイント：CAAT の道具の一つ。全件のデータを分析して、例外（値引取引など）を抜き出すのに使う
- 語の意味：Software＝ソフトウェア

#### データ分析（Data Analytics）

- 意味：監査対象のデータを監査ソフトなどで分析し、異常値・例外・傾向を見つける方法
- ポイント：R5秋 問59 ア のように、例外取引を抽出して承認の記録を確かめるのに使う
- 語の意味：Data＝データ／Analytics＝分析

#### テストデータ法（Test Data Method）

- 意味：監査人が用意したテストデータを監査対象のプログラムで処理させ、期待した結果が出るかを確かめて、プログラムの処理やチェック機能の正しさを確かめる技法
- ポイント：R7春 問58 エ の説明。入力チェック（論理・フォーマット）が働くかを確かめるのに向く（R5秋 問59 イ）。漏れや重複の確認は伝票との照合
- 例：R5秋 問59 イ、R7春 問58 エ
- 語の意味：Test＝試験／Data＝データ

#### 監査モジュール法（Audit Module Method）

- 意味：監査対象のプログラムに監査用のモジュール（プログラム）を組み込み、本番の処理の中で監査に必要なデータを集める技法
- ポイント：本番で動きながら継続的にデータを集められる。外から同じ処理を再現して比べるのは並行シミュレーション法
- 例：R3秋 問59 ウ（誤り）
- 語の意味：Module＝部品のプログラム

#### 並行シミュレーション法（Parallel Simulation）

- 意味：監査人が、監査対象のプログラムと同じ処理をするプログラムを別に用意し、同じデータを処理させて結果を比べる技法
- ポイント：プログラムの論理の正確性を確かめる（R5秋 問59 エ）。入力の網羅性（漏れ・重複）を確かめる方法ではない
- 例：R5秋 問59 エ（誤り）
- 語の意味：Parallel＝並行の／Simulation＝模擬

#### ペネトレーションテスト法（Penetration Test）

- 意味：実際に攻撃者と同じ手口でシステムに侵入を試みて、セキュリティの弱点を確かめる技法
- ポイント：情報セキュリティの監査で使う。プロセスを追いかけるのはウォークスルー法
- 例：R3秋 問59 エ（誤り）
- 語の意味：Penetration＝侵入・貫通

### 報告とフォローアップ

#### システム監査報告書（System Audit Report）

- 意味：監査の目的・範囲・結果（結論・指摘事項・改善提案）を記載し、監査の依頼者などに提出する報告書（基準11）
- ポイント：保証型では保証の意見、助言型では改善提案が中心になる。R6春 問58 イ「監査の概要と結論を記載した要約版の報告書」は報告書の説明で、監査調書ではない
- 例：R6春 問58 イ（誤り）
- 語の意味：Report＝報告

#### 指摘事項（Audit Findings）

- 意味：監査で見つかった、改善が必要な問題点。監査報告書に記載する
- ポイント：基準や規程に合っていないものを書く。ルールどおりに行われていることは指摘しない（R3春 問58・R4秋 問58）
- 例：R3春 問58（ウ：認可していないソフトの使用）、R4秋 問58（エ：リスクアセスメントの後に受容基準を決めた）
- 語の意味：指摘＝取り上げて示すこと

#### 改善提案（Recommendations）

- 意味：指摘事項について、監査人が改善の方向を示した提案。監査報告書に記載する
- ポイント：提案するのは監査人、改善計画を作って実施するのは監査対象先。監査人が改善計画を作るのは不適切（R3秋 問60 ウ）
- 語の意味：提案＝考えを出すこと

#### 改善計画（Improvement Plan）

- 意味：監査対象先が、指摘事項と改善提案をもとに自ら作る改善の計画
- ポイント：作るのは監査対象先で、監査人ではない。経営者がリスクを受容すると判断した指摘事項は、改善しないこともある（R3秋 問60 ア は適切）
- 例：R3秋 問60、R6秋 問60 ア
- 語の意味：改善＝よくすること

#### フォローアップ（Follow-up）

- 意味：監査対象先の責任で行われる改善が、適切かつ適時に実施されているかを、監査人が事後に確認（モニタリング）すること（基準12）
- ポイント：監査人は改善の実施を指示しない・改善プロジェクトを管理しない・改善計画を作らない（R3春 問60＝R7秋 問59）。調査が終わらなかった項目の追跡調査ではない（R6秋 問60 エ）
- 例：R3春 問60（ウ）、R6秋 問60（ウ）、R7秋 問59（ウ）
- 語の意味：Follow up＝後を追う

#### フォローアップ報告書（Follow-up Report）

- 意味：フォローアップで確かめた改善の状況をまとめた報告書
- ポイント：改善が遅れている場合は、経営者に報告して判断を仰ぐ
- 語の意味：Follow-up＝事後の確認／Report＝報告

### 他の監査との連携

#### 金融商品取引法監査（Audit under the FIEA）

- 意味：金融商品取引法に基づき、上場企業などの財務諸表と内部統制報告書を公認会計士・監査法人が監査するもの
- ポイント：法定監査の一つ。会社法に基づくものは会社法監査
- 語の意味：金融商品＝株式・債券など

#### 会社法監査（Audit under the Companies Act）

- 意味：会社法に基づき、監査役（会）と会計監査人（公認会計士・監査法人）が行う監査
- ポイント：監査役は業務監査と会計監査を行う。上場企業の財務報告の監査は金融商品取引法監査
- 語の意味：会社法＝会社の設立や運営を定めた法律

#### 公認会計士（Certified Public Accountant）

- 意味：財務諸表の監査（会計監査）を独占業務とする国家資格者。監査法人に所属して法定監査を行う
- ポイント：システム監査は、会計監査人の監査や監査役の監査、内部監査人の監査と連携・調整して行う
- 語の意味：Certified＝認定された／Public＝公の／Accountant＝会計士

#### 監査法人（Audit Firm）

- 意味：公認会計士が集まって作る、会計監査（法定監査）を組織として行う法人
- ポイント：金融商品取引法監査や会社法監査（会計監査人）を担う。上場企業の内部統制報告書の監査も行う
- 語の意味：法人＝法律で人と同じように権利を持つ団体
### コンピュータ犯罪と不正の防止

#### 電磁的記録不正作出及び供用罪（刑法）

- 意味：人の事務処理を誤らせる目的で、権利・義務・事実の証明に関する電磁的記録（データ）を不正に作ったり、それを使ったりする罪
- ポイント：データを壊して業務を妨げるのは電子計算機損壊等業務妨害罪、不正なデータで財産上の利益を得るのは電子計算機使用詐欺罪
- 語の意味：電磁的記録＝電子データ／作出＝作り出すこと／供用＝使わせること

#### 電子計算機損壊等業務妨害罪（刑法）

- 意味：コンピュータやデータを壊したり、虚偽の情報や不正な指令を与えたりして、コンピュータを動かなくして業務を妨害する罪
- ポイント：DoS 攻撃でサーバを止めるのもこれに当たりうる。データを不正に作るのは電磁的記録不正作出、不正な処理でお金を得るのは電子計算機使用詐欺
- 語の意味：電子計算機＝コンピュータ／損壊＝壊すこと

#### 電子計算機使用詐欺罪（刑法）

- 意味：コンピュータに虚偽の情報や不正な指令を与えて、財産権の得喪・変更に関する不実の電磁的記録を作り、財産上の不法な利益を得る罪
- ポイント：口座残高を不正に書き換えるなど。業務を妨げる目的なら電子計算機損壊等業務妨害罪
- 語の意味：詐欺＝だまして利益を得ること

#### 不正アクセス禁止法（不正アクセス行為の禁止等に関する法律）

- 意味：他人の ID・パスワードを無断で使ったり、セキュリティの穴を突いたりして、アクセス制御のあるコンピュータを使えるようにする行為（不正アクセス行為）を禁止する法律
- ポイント：他人の ID・パスワードを無断で第三者に教える・不正に取得する・保管することも禁止。アクセス管理者には防御の努力義務がある
- 語の意味：アクセス＝接続して利用すること

#### 不正競争防止法（Unfair Competition Prevention Act）

- 意味：営業秘密の不正取得・使用、他社の有名な商品表示のまね、ドメイン名の不正取得など、不正な競争を防ぐ法律
- ポイント：営業秘密として守られるには秘密管理性・有用性・非公知性の三つが要る。どう管理すればよいかを示すのが営業秘密管理指針（経済産業省）
- 語の意味：不正競争＝ずるいやり方で競うこと

### 個人情報とセキュリティの制度

#### ISMS 適合性評価制度（ISMS Conformity Assessment Scheme）

- 意味：組織の ISMS が JIS Q 27001（ISO/IEC 27001）の要求事項に適合しているかを、第三者の認証機関が審査して認証する制度
- ポイント：組織の個人情報保護の仕組みを認定するのはプライバシーマーク制度
- 語の意味：ISMS＝情報セキュリティマネジメントシステム／適合＝条件に合うこと

#### 個人情報保護法（個人情報の保護に関する法律）

- 意味：個人情報を取り扱う事業者に、利用目的の特定・適正な取得・安全管理・第三者提供の制限・開示請求への対応などの義務を定めた法律
- ポイント：マイナンバーを含む個人情報（特定個人情報）はマイナンバー法でさらに厳しく扱う
- 語の意味：個人情報＝生きている個人を識別できる情報

#### マイナンバー法（番号利用法）

- 意味：行政手続における特定の個人を識別するための番号の利用等に関する法律。マイナンバーの利用範囲や、特定個人情報の取扱いを定める
- ポイント：利用は社会保障・税・災害対策などに限られる。事業者向けの具体的な扱いは「特定個人情報の適正な取扱いに関するガイドライン」
- 語の意味：My Number＝個人番号

#### JIS Q 15001（個人情報保護マネジメントシステム）

- 意味：個人情報保護マネジメントシステムの要求事項を定めた日本産業規格
- ポイント：プライバシーマーク制度の審査基準になる。情報セキュリティ全般の要求事項は JIS Q 27001
- 語の意味：JIS＝日本産業規格

#### プライバシーマーク制度（Privacy Mark）

- 意味：個人情報を適切に取り扱う体制を整えた事業者を、JIS Q 15001 に基づいて審査し、プライバシーマークの使用を認める制度（JIPDEC が運営）
- ポイント：事業者単位で認定する。ISMS の認証は ISMS 適合性評価制度
- 語の意味：Privacy＝私生活・個人の情報／Mark＝印

### その他の監査関連法規

#### 電子帳簿保存法（Act on Electronic Bookkeeping）

- 意味：国税関係の帳簿や書類を電子データで保存するための要件を定めた法律（正式名は電子計算機を使用して作成する国税関係帳簿書類の保存方法等の特例に関する法律）
- ポイント：電子取引のデータは電子のまま保存する。真実性（改ざん防止）と可視性（検索・表示）の確保が要件
- 語の意味：帳簿＝お金の出入りを記録した帳面

#### 電子署名法（電子署名及び認証業務に関する法律）

- 意味：本人による一定の要件を満たす電子署名がある電子文書は、本人が作ったものと推定されることなどを定めた法律
- ポイント：手書きの署名や押印と同じように扱えるようにする。認証業務（電子証明書の発行）の認定制度も定める
- 語の意味：署名＝自分の名前を書くこと

#### 労働者派遣法（Worker Dispatching Act）

- 意味：派遣元・派遣先・派遣労働者の関係と、それぞれの義務を定めた法律
- ポイント：派遣では派遣先が指揮命令する。請負で発注者が請負先の要員に直接指示すると偽装請負になる。システム監査ではこうした法令違反も指摘する
- 語の意味：派遣＝人を差し向けること

#### 金融商品取引法（Financial Instruments and Exchange Act）

- 意味：投資家を守るため、上場企業などに有価証券報告書の開示や、内部統制報告書の提出と監査を義務付けた法律
- ポイント：内部統制報告制度（J-SOX）の根拠になる。取締役会や監査役を定めるのは会社法
- 語の意味：金融商品＝株式・債券など

#### 会社法（Companies Act）

- 意味：会社の設立・機関（株主総会・取締役会・監査役など）・運営を定めた法律。大会社の取締役会に内部統制システムの基本方針の決定を求める
- ポイント：財務報告の内部統制の評価と監査を求めるのは金融商品取引法
- 語の意味：会社＝事業を行う法人

## 16-2 内部統制

### まとめ表

**内部統制の四つの目的と六つの基本的要素（金融庁 実施基準）**

| 四つの目的 | 六つの基本的要素 |
| :-: | :-: |
| 業務の有効性及び効率性 | 統制環境（全ての土台） |
| 報告の信頼性（財務報告など） | リスクの評価と対応 |
| 事業活動に関わる法令等の遵守 | 統制活動 |
| 資産の保全 | 情報と伝達 |
| | モニタリング（日常的モニタリング・独立的評価） |
| | IT への対応（日本独自） |

**IT に係る全般統制と業務処理統制**

| 統制 | 何に効くか | 例 |
| :-: | :-: | :-: |
| 全般統制 | 業務処理統制が働き続ける環境を守る（複数の業務システムに共通） | システムの開発・保守の管理、運用の管理、アクセス管理、外部委託の管理、入退室管理、ファイアウォールの運用 |
| 業務処理統制 | 一つの業務の処理が正しく行われるようにする（業務システムに組み込む） | 入力データの正当性チェック、マスタの管理、例外処理の修正と再処理、アクセス権の付与 |

- R6春 問60：販売管理システムの入力データの正当性チェック → 業務処理統制（ウ）。入退室管理・委託先の選定手続・ファイアウォールの運用は全般統制
- R5秋 問60：IT の統制は全般統制と業務処理統制から成る（イ）

**内部統制にかかわる人の役割（R5春 問60）**

| 人 | 役割 |
| :-: | :-: |
| 経営者 | 内部統制の整備と運用に**最終的な責任**を持つ |
| 取締役会 | 内部統制の整備と運用の**基本方針を決定**し、経営者を監督する |
| 監査役等 | 独立した立場から、取締役・執行役の職務の執行の監査の一環として内部統制を**監視・検証**する |
| 内部監査人 | **モニタリングの一環**として内部統制を検討・評価し、改善を促す |

### 内部統制の基本的要素

#### 統制環境（Control Environment）

- 意味：組織の気風を決め、全ての人の統制に対する意識に影響を与える、内部統制の土台。誠実性と倫理観・経営者の意向と姿勢・経営方針・取締役会と監査役の機能・組織構造・権限と責任・人的資源の方針など
- ポイント：ほかの基本的要素の基礎になる。個々の手続を決めて実行するのは統制活動
- 語の意味：Environment＝環境

#### リスクの評価と対応（Risk Assessment and Response）

- 意味：組織の目標の達成を妨げるリスクを識別・分析・評価し、回避・低減・移転・受容などの対応を選ぶプロセス
- ポイント：対応を具体的な手続にして実行するのが統制活動。リスクの評価は、変化する環境に合わせて繰り返す
- 語の意味：Risk＝危険／Assessment＝評価／Response＝対応

#### 統制活動（Control Activities）

- 意味：経営者の命令や指示が適切に実行されることを確保するために定める方針と手続。権限と職責の付与、職務の分掌、承認・照合・調整・検証など
- ポイント：一つ一つの業務の中で行う管理の手続。それが働いているかを継続的に見るのはモニタリング
- 語の意味：Activities＝活動

#### 情報と伝達（Information and Communication）

- 意味：必要な情報が識別・把握・処理され、組織内外や関係者に正しく伝えられることを確保すること
- ポイント：内部通報制度もこれに含まれる。情報システムはこの要素を支える
- 語の意味：Information＝情報／Communication＝伝達

#### モニタリング（Monitoring）

- 意味：内部統制が有効に機能していることを継続的に評価するプロセス。業務の中で行う日常的モニタリングと、業務から独立した視点で行う独立的評価がある
- ポイント：内部監査人による評価は独立的評価に当たる（R5春 問60 エ）。不備が見つかれば報告し是正する
- 例：R5春 問60
- 語の意味：Monitor＝見張る

#### 日常的モニタリング（Ongoing Monitoring）

- 意味：通常の業務の中で、上司の確認や照合などによって継続的に行うモニタリング
- ポイント：業務から離れた立場で定期的・随時に行うのは独立的評価
- 語の意味：日常的＝いつもの業務の中での

#### 独立的評価（Separate Evaluation）

- 意味：日常的モニタリングとは別に、経営者・取締役会・監査役・内部監査人などが、業務から独立した視点で定期的・随時に行う評価
- ポイント：内部監査はこれの代表。業務の中で行うのは日常的モニタリング
- 語の意味：独立＝ほかから離れていること

### IT への対応と IT の統制

#### IT への対応（Response to IT）

- 意味：組織の目標を達成するために、組織の内外の IT に適切に対応すること。IT 環境への対応と IT の利用及び統制から成る（日本の実施基準が独自に加えた要素）。IT の統制（IT 統制。IT に係る全般統制・IT に係る業務処理統制）もこの要素に入る
- ポイント：IT を使わず手作業だけで内部統制をしても、直ちに不備にはならない。IT で自動化した統制も、それだけで有効とは評価されない（R5秋 問60 ウ・エ が誤り）
- 例：R5秋 問60
- 語の意味：対応＝状況に応じて手を打つこと

#### IT 環境への対応（Response to IT Environment）

- 意味：組織が活動するうえで必要な、組織の内外の IT の利用状況（社会の IT の浸透度・組織が使う IT・外部委託の状況など）を把握し、対応すること。IT への対応の一部
- ポイント：企業の内部に限らない（R5秋 問60 ア が誤り）。IT を統制に組み込むのは IT の利用及び統制
- 例：R5秋 問60 ア（誤り）
- 語の意味：Environment＝環境

#### IT の統制（IT Controls）

- 意味：IT を使った業務やシステムに対して行う統制。IT に係る全般統制と IT に係る業務処理統制から成る。IT への対応の一部で、IT 統制ともいう
- ポイント：R5秋 問60 の正解（イ）。全般統制は業務処理統制が働き続ける環境を守り、業務処理統制は一つ一つの処理を正しくする
- 例：R5秋 問60（正解はイ）
- 語の意味：Controls＝統制の手段

#### IT に係る全般統制（IT General Controls）

- 意味：業務処理統制が有効に働く環境を保証するための統制。複数の業務処理統制に共通する、システムの開発・保守、運用の管理、アクセス管理などのセキュリティ、外部委託の管理など。IT の統制の一つ（IT への対応の一部）
- ポイント：入退室管理・開発の委託先の選定手続・ファイアウォールの運用は全般統制（R6春 問60 ア・イ・エ）。入力データのチェックは業務処理統制
- 例：R6春 問60（誤りの選択肢）
- 語の意味：General＝全般の・共通の

#### IT に係る業務処理統制（IT Application Controls）

- 意味：業務を管理するシステムの中で、承認された業務が全て正確に処理・記録されることを確保するために、業務プロセスに組み込まれた統制。入力情報の完全性・正確性・正当性のチェック、エラーの修正と再処理、マスタの維持管理、アクセスの承認など。IT の統制の一つ（IT への対応の一部）
- ポイント：R6春 問60 の正解「販売管理システムの入力データの正当性チェック機能」（ウ）。一つの業務システムに組み込むのが業務処理統制、システム全体を支えるのが全般統制
- 例：R6春 問60（正解はウ）
- 語の意味：Application＝業務のアプリケーション

### 内部統制の制度と枠組み

#### 内部統制（Internal Control）

- 意味：業務の有効性及び効率性・報告の信頼性・法令等の遵守・資産の保全の四つの目的を達成するために、業務に組み込まれ、組織内の全ての者によって遂行されるプロセス。健全で効率的な組織運営のために企業が自ら作って運用する仕組み。四つの目的をまとめて内部統制の目的という
- ポイント：実現には業務プロセスの明確化・職務分掌・実施ルールの設定・チェック体制の確立が要る。経営者が最終的な責任を持つ
- 語の意味：Internal＝内部の／Control＝統制

#### 内部統制の目的（Objectives of Internal Control）

- 意味：業務の有効性及び効率性、報告の信頼性、事業活動に関わる法令等の遵守、資産の保全の四つ。内部統制が達成を目指すもの
- ポイント：COSO の目的（業務・報告・コンプライアンス）に、日本の実施基準は「資産の保全」を加えた。基本的要素（六つ）と数を取り違えない
- 語の意味：目的＝目指すもの

#### 内部統制の限界（Limitations of Internal Control）

- 意味：内部統制はどれだけ整えても絶対的な保証はできない、という考え。判断の誤り・不注意・複数の人の共謀・想定外の取引・経営者による無視（内部統制の無効化）・費用と便益の比較による制約など
- ポイント：だから合理的な保証（ある程度の確かさ）を目指す。経営者が内部統制を無視して不正をすることもありうる
- 語の意味：限界＝これ以上はできないところ

#### 内部統制報告制度（J-SOX）

- 意味：金融商品取引法に基づき、上場企業の経営者が財務報告に係る内部統制を評価して内部統制報告書を出し、それを公認会計士・監査法人が監査する制度
- ポイント：米国の SOX 法（サーベンス・オクスリー法）にならったので J-SOX と呼ぶ。評価と監査の基準は金融庁の「財務報告に係る内部統制の評価及び監査の基準」と実施基準
- 語の意味：J＝Japan／SOX＝Sarbanes-Oxley Act

#### 内部統制報告書（Internal Control Report）

- 意味：経営者が、財務報告に係る内部統制の有効性を評価した結果をまとめ、有価証券報告書とあわせて提出する報告書
- ポイント：作るのは経営者、監査するのは公認会計士・監査法人
- 語の意味：報告書＝結果を知らせる文書

#### 財務報告に係る内部統制の評価及び監査の基準（金融庁）

- 意味：金融庁の企業会計審議会が定めた、財務報告に係る内部統制の評価と監査の基準。具体的な進め方は実施基準に書かれている
- ポイント：内部統制の四つの目的・六つの基本的要素・関係者の役割（R5春 問60）・IT への対応（R5秋 問60）はここから出る
- 例：R5春 問60、R5秋 問60
- 語の意味：財務報告＝財務諸表などの報告

#### 全社的な内部統制（Entity-level Controls）

- 意味：企業全体にかかわり、連結グループ全体に影響を与える内部統制。統制環境・リスクの評価・全社的な方針や手続など
- ポイント：まず全社的な内部統制を評価し、その結果をもとに業務プロセスに係る内部統制の評価範囲を決める
- 語の意味：全社的＝会社全体にわたる

#### 業務プロセスに係る内部統制（Process-level Controls）

- 意味：販売・購買・在庫など個々の業務プロセスの中に組み込まれた内部統制
- ポイント：全社的な内部統制の評価の後に、重要な業務プロセスを選んで評価する
- 語の意味：業務プロセス＝仕事の流れ

#### COSO（こーそー / Committee of Sponsoring Organizations of the Treadway Commission）

- 意味：米国のトレッドウェイ委員会支援組織委員会。内部統制のフレームワーク（COSO フレームワーク）と全社的リスクマネジメント（ERM）のフレームワークを公表している
- ポイント：COSO の内部統制の構成要素は五つ（統制環境・リスク評価・統制活動・情報と伝達・モニタリング活動）。日本の実施基準はこれに「IT への対応」を加えて六つ
- 語の意味：Committee＝委員会／Sponsoring＝支援する／Organizations＝組織／Treadway＝初代委員長の名前

#### ERM（いーあーるえむ / Enterprise Risk Management）

- 意味：全社的リスクマネジメント。組織全体のリスクを、戦略や目標と結び付けて総合的に管理する取組み（COSO が枠組みを公表）
- ポイント：内部統制より広く、戦略の設定やリスクを取る判断まで含む
- 語の意味：Enterprise＝企業・組織全体／Risk＝リスク／Management＝管理

#### CSA（しーえすえー / Control Self Assessment）

- 意味：統制自己評価。業務を行う部門の担当者自身が、自分たちの統制やリスクを、ワークショップや質問書で評価する手法
- ポイント：監査人による評価ではなく、現場の自己評価。内部監査人はその進行役や結果の検証をすることがある
- 語の意味：Control＝統制／Self＝自分で／Assessment＝評価

### 内部統制を実現する取組み

#### 職務分掌（Segregation of Duties）

- 意味：一つの取引について、承認・実行・記録・保管などの職務を別の人に分けて担当させ、互いにけん制させること
- ポイント：一人で全部できると不正や誤りが見つからない。開発者が本番環境を直接変更できないようにするのも職務分掌
- 語の意味：分掌＝分けて受け持つこと／Segregation＝分離／Duties＝職務

#### 業務プロセスの明確化（Clarification of Business Processes）

- 意味：業務の流れ・担当・使う情報を、業務フロー図や業務記述書などで明らかにすること
- ポイント：内部統制を作る第一歩。どこにリスクがあり、どんな統制が要るかを見つけやすくなる
- 語の意味：明確化＝はっきりさせること

#### 実施ルールの設定（Setting of Rules）

- 意味：業務を行うための規程・手順・基準を決めて、文書にすること
- ポイント：職務分掌・業務プロセスの明確化・チェック体制の確立と並ぶ、内部統制を実現するための取組みの一つ
- 語の意味：ルール＝決まり

#### チェック体制の確立（Establishment of Check System）

- 意味：業務が決まりどおりに行われているかを確かめる仕組み（承認・照合・上司の確認・内部監査など）を作ること
- ポイント：作業者と確認者を分けるのは職務分掌とセットになる
- 語の意味：体制＝仕組み・組織

### 内部統制の関係者

#### 経営者（内部統制 / Management）

- 意味：内部統制の整備及び運用について最終的な責任を持つ人。取締役会が決めた基本方針に基づいて内部統制を整え、運用する
- ポイント：R5春 問60 ウ の「独立した立場から監視・検証する」は監査役等の役割で、経営者ではない。株主は最終的な責任者ではない（ア）
- 例：R5春 問60
- 語の意味：経営者＝会社の業務を指揮する人（社長など）

#### 取締役会（Board of Directors）

- 意味：内部統制の整備及び運用に係る基本方針を決定し、経営者による整備・運用を監督する機関
- ポイント：R5春 問60 イ「監査役は基本方針を決定する」は誤りで、決めるのは取締役会
- 例：R5春 問60 イ（誤り）
- 語の意味：取締役＝会社の業務執行を決める役員

#### 監査役等（Audit & Supervisory Board Members）

- 意味：取締役・執行役の職務の執行に対する監査の一環として、独立した立場から内部統制の整備及び運用状況を監視・検証する役割と責任を持つ人。監査等委員会・監査委員会も含む
- ポイント：R5春 問60 ウ の説明は監査役等の役割（選択肢では経営者にすり替えている）
- 例：R5春 問60 ウ（誤り）
- 語の意味：監査役＝会社の業務と会計を監査する役員

#### 内部監査人（Internal Auditor）

- 意味：モニタリングの一環として、内部統制の整備及び運用状況を検討・評価し、必要に応じて改善を促す職務を担う人
- ポイント：R5春 問60 の正解（エ）。経営者の直属に置かれ、業務から独立した評価（独立的評価）を行う
- 例：R5春 問60（正解はエ）
- 語の意味：Internal＝内部の／Auditor＝監査人

### IT ガバナンス

#### IT ガバナンス（IT Governance）

- 意味：取締役会等がステークホルダのニーズに基づき、組織の価値と信頼を高めるために、IT の利活用のあるべき姿を示す IT 戦略と方針を決め、その実現のための活動を方向付け・モニタリングすること。組織体のガバナンスの構成要素の一つ
- ポイント：システム監査・情報セキュリティ監査・ソフトウェア資産管理は、IT ガバナンスを実現するための取組み。会社全体の統治はコーポレートガバナンス
- 語の意味：Governance＝統治

#### コーポレートガバナンス（Corporate Governance）

- 意味：企業を健全かつ効率的に経営するために、株主などの利害関係者の立場から経営を規律し、監視する仕組み（企業統治）
- ポイント：IT ガバナンスはその一部。上場企業には「コーポレートガバナンス・コード」がある
- 語の意味：Corporate＝企業の／Governance＝統治

#### JIS Q 38500（ISO/IEC 38500）

- 意味：組織の IT の利用に関するガバナンスの規格。経営陣（統治主体）が行う「評価（Evaluate）・指示（Direct）・モニタ（Monitor）」の三つのタスク（EDM モデル）と、六つの原則（責任・戦略・取得・パフォーマンス・適合・人間行動）を示す
- ポイント：IT ガバナンスの代表的な規格。IT 管理のプロセスと目標を細かく示すのは COBIT
- 語の意味：Evaluate＝評価する／Direct＝指示する／Monitor＝監視する

#### COBIT（こびっと / Control Objectives for Information and related Technology）

- 意味：ISACA（情報システムコントロール協会）が作った、IT ガバナンスと IT マネジメントのフレームワーク。目標・プロセス・評価の指標を体系的に示す
- ポイント：IT ガバナンスの評価に使う。JIS Q 38500 は原則とタスク、COBIT はより具体的なプロセスと管理の目標
- 語の意味：Control＝統制／Objectives＝目標／Information＝情報／Technology＝技術

#### PRM-IT（Process Reference Model for IT）

- 意味：IBM が作った、IT ガバナンスと IT マネジメントのプロセスを体系化した参照モデル
- ポイント：IT ガバナンスの評価のフレームワークとして、COBIT と並べて用語例に挙がっている
- 語の意味：Process＝プロセス／Reference＝参照／Model＝模型・型

#### 成熟度モデル（IT ガバナンス / Maturity Model）

- 意味：組織の IT ガバナンスやプロセスが、どの段階まで成熟しているかを、0〜5 などの水準で評価するための模型
- ポイント：現在の水準と目標の水準の差を見て、改善の順番を決める。COBIT や CMMI で使われる
- 語の意味：Maturity＝成熟

#### CIO（しーあいおー / Chief Information Officer）

- 意味：最高情報責任者。経営の立場から、IT 戦略を立てて実行を指揮し、情報システムへの投資と活用に責任を持つ役員
- ポイント：情報セキュリティに責任を持つのは CISO。CIO は経営戦略と IT 戦略を結び付ける
- 語の意味：Chief＝最高の／Information＝情報／Officer＝役員

#### CISO（しーそ / Chief Information Security Officer）

- 意味：最高情報セキュリティ責任者。組織全体の情報セキュリティの方針・体制・対策に責任を持つ役員
- ポイント：IT 全般の戦略は CIO。CISO はリスクと対策の面から経営に関わる
- 語の意味：Chief＝最高の／Information Security＝情報セキュリティ／Officer＝役員

#### IT 統制（IT Control）

- 意味：IT を利用した業務と情報システムに対して行う統制。内部統制の一部で、全般統制と業務処理統制がある。IT の統制と同じ意味で、IT に係る全般統制と IT に係る業務処理統制から成る
- ポイント：J-SOX では財務報告にかかわる IT 統制の評価が求められる。IT 統制の考え方は「システム管理基準追補版」にまとめられている
- 語の意味：統制＝決まりに従わせて管理すること

#### データガバナンス（Data Governance）

- 意味：組織のデータを資産として扱い、その品質・セキュリティ・利用のルールを決めて、全社で管理・活用する取組み
- ポイント：データの意味や項目を標準化するデータ管理者（DA）の活動と結び付く。IT ガバナンスの一部
- 語の意味：Data＝データ／Governance＝統治

#### コンプライアンス（Compliance）

- 意味：法令や社内規程、社会の規範・倫理を守って業務を行うこと（法令遵守）
- ポイント：守られているかを継続的に評価し改善する。評価する監査はコンプライアンス監査、現場が自ら評価するのは CSA
- 語の意味：Comply＝従う

#### 行動指針（Code of Conduct）

- 意味：組織の役員・従業員が守るべき行動の基準をまとめたもの（行動規範）
- ポイント：コンプライアンスの土台になる。内部統制の統制環境（誠実性と倫理観）を作る手段の一つ
- 語の意味：Code＝規範／Conduct＝行い

#### 透明性（Transparency）

- 意味：組織の意思決定や活動の過程が、利害関係者から見て分かるように開かれていること
- ポイント：コンプライアンス監査の用語例。説明責任（アカウンタビリティ）を果たすための前提になる
- 語の意味：Transparent＝透き通った

#### 説明責任（Accountability）

- 意味：組織が、自らの活動や結果について、利害関係者に説明する責任
- ポイント：システム監査の目的には、利害関係者への説明責任を果たすことが含まれる
- 語の意味：Account＝説明する／ability＝できること

#### 問 ap-16-o09

- 問：販売管理システムでは，同じ担当者が受注データの入力と，その受注の承認の両方を行えるようになっている。不正や誤りを防ぐ内部統制の改善策として，最も適切なものはどれか。

- イ：受注データの入力と承認を，別の担当者が行うように権限を分ける。
- ウ：承認した受注の一覧を，月末にまとめて上司に報告する。
- エ：受注データの入力画面に，入力値の形式のチェック機能を追加する。

- イの意味：正しい。職務分掌で、入力と承認を別の担当者にする。
- ウの意味：月末の報告では発見が遅れ、承認の時点での不正や誤りを防げない。
- エの意味：形式のチェックは入力の誤りを減らすが、本人による不正な承認は防げない。
- 出典：オリジナル問題（シラバス Ver.7.2 中分類16「内部統制」の用語例（職務分掌）をもとに作成）

#### 問 ap-16-o10

- 問：内部統制の限界の例として，適切なものはどれか。
- ア：職務分掌によって，受注の入力と承認を別の担当者が行うようにした。
- イ：IT を利用して，売上の計上の照合を自動化した。
- ウ：内部監査部門が，内部統制の有効性を定期的に評価した。
- エ：入力と承認の担当者が共謀すると，職務分掌による統制が働かなくなる。
- 正解：エ
- 解説：内部統制は、どれだけ整えても絶対的な保証はできない。複数の人の共謀、判断の誤りや不注意、想定外の取引、経営者による無視などには働かないことがある。これを内部統制の限界という。
- アの意味：職務分掌は内部統制の手段そのもの。限界の例ではない。
- イの意味：IT による自動化は、統制活動の一つの形。限界の例ではない。
- ウの意味：内部監査による定期的な評価は、モニタリング（独立的評価）。限界の例ではない。
- エの意味：正しい。共謀は、職務分掌を前提とした統制が働かなくなる、内部統制の限界の代表例。
- 出典：オリジナル問題（金融庁「財務報告に係る内部統制の評価及び監査の基準」の内部統制の限界、シラバス Ver.7.2 中分類16「内部統制の限界」の用語例をもとに作成）
