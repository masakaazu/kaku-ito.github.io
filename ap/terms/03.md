## 3-1 プロセッサ

### まとめ表

**性能の計算（R5春 問8・R7春 問8・R3春 問9の論点）**

| 指標 | 意味 | 式 |
| :-: | :-: | :-: |
| クロック周波数 | 1秒間のクロックの数 | 1 ÷ サイクルタイム |
| CPI | 1命令に平均何クロックかかるか | クロック周波数 ÷ 1秒間の命令数 |
| 1命令の平均実行時間 | 1命令に平均何秒かかるか | CPI × サイクルタイム（命令ミックスなら「実行時間×出現頻度」の合計） |
| MIPS | 1秒間に何百万命令実行できるか | 1 ÷ 1命令の平均実行時間 ÷ 10⁶ |
| FLOPS | 1秒間に何回の浮動小数点演算ができるか | 1コアの性能 × コア数 |

**パイプラインと高速化（R5春 問9・R6秋 問8・R4春 問8の論点）**

| 技術 | やり方 | 押さえどころ |
| :-: | :-: | :-: |
| 命令パイプライン | 命令の段階をずらして重ねる | k段で n命令なら k＋(n−1) サイクル |
| スーパーパイプライン | 段をもっと細かく分ける | 1段が短くなり、クロックを上げられる |
| スーパースカラ | パイプラインを複数本もち、実行時に同時に流す | 並べる判断はハードウェア |
| VLIW | 同時に実行できる命令を、コンパイル時に1つの長い命令にまとめる | 並べる判断はコンパイラ |

**フリンの分類（命令の流れとデータの流れの数）**

| 分類 | 命令 | データ | 例 |
| :-: | :-: | :-: | :-: |
| SISD | 1 | 1 | 昔の単一プロセッサ |
| SIMD | 1 | 複数 | GPU、ベクトル処理、画像処理の命令 |
| MISD | 複数 | 1 | 実用例はほとんどない |
| MIMD | 複数 | 複数 | マルチプロセッサ、マルチコア |

**アドレス指定方式（命令のアドレス部の値を a とする）**

| 方式 | 有効アドレス | 覚え方 |
| :-: | :-: | :-: |
| 即値 | （a そのものがデータ） | メモリを見に行かない |
| 直接 | a | a 番地にデータ |
| 間接 | a 番地に書いてあるアドレス | 2回たどる |
| インデックス | a ＋ インデックスレジスタ | 配列の i 番目 |
| ベース | a ＋ ベースレジスタ | プログラムの先頭からの位置 |
| 相対 | a ＋ プログラムカウンタ | 今の命令からの距離 |

### コンピュータの種類

#### パーソナルコンピュータ（ぱーそなるこんぴゅーた / Personal Computer）

- 意味：個人が使うことを前提にした汎用のコンピュータ。机に置くデスクトップ型と、持ち運べるノート型がある
- ポイント：PCと略す。OSとアプリケーションを入れて、文書作成から開発まで何にでも使う
- 語の意味：Personal＝個人の／Computer＝計算機

#### ワークステーション（わーくすてーしょん / Workstation）

- 意味：設計・解析・映像制作などの専門的な作業向けに、処理性能や画面表示の性能を高めた個人用のコンピュータ
- ポイント：使うのは1人だが、一般の机上の機械より高性能な部品を使う

#### サーバ（さーば / Server）

- 意味：ネットワークを通じて、ほかのコンピュータ（クライアント）にサービスや資源を提供するコンピュータ
- ポイント：長時間止めずに動かすので、電源やディスクを二重にするなど信頼性を高めた作りが多い

#### 汎用コンピュータ（はんようこんぴゅーた / Mainframe）

- 意味：事務計算から科学技術計算まで1台で幅広く処理する、大型の業務用コンピュータ。メインフレームとも呼ぶ
- ポイント：銀行の勘定系など、大量の取引を止めずに処理する基幹システムで使われてきた

#### スーパーコンピュータ（すーぱーこんぴゅーた / Supercomputer）

- 意味：気象予測や分子の計算など、大規模な科学技術計算を高速に行うためのコンピュータ
- ポイント：多数のプロセッサを並べて並列に計算する。性能は FLOPS で比べる
- 例：R7秋 問11（HPCマシンのコア数とコアの性能を上げたときの、ノード数と総理論ピーク演算性能を計算する）

#### 携帯端末（けいたいたんまつ / Mobile Device）

- 意味：スマートフォンやタブレット端末のように、電池で動き、持ち歩いて使う小型のコンピュータ
- ポイント：低消費電力が重要なので、性能の高いコアと省電力のコアを組み合わせたプロセッサを使うことが多い

#### シングルボードコンピュータ（しんぐるぼーどこんぴゅーた / Single Board Computer）

- 意味：CPU・メモリ・入出力端子を1枚の基板にまとめた小型のコンピュータ。SBCと略す
- ポイント：安価で、学習・試作・IoT機器の制御に使われる

#### 制御用コンピュータ（せいぎょようこんぴゅーた / Control Computer）

- 意味：工場の機械や家電・自動車などに組み込まれ、センサの値を読んでモーターなどを動かす制御を受け持つコンピュータ
- ポイント：決められた時間内に必ず応答すること（リアルタイム性）が重視される
- 例：R7秋 問10（回転センサのパルスの周期をタイマで数え、モーターの毎秒の回転数を求める）

#### マイクロコンピュータ（まいくろこんぴゅーた / Microcomputer）

- 意味：プロセッサ・メモリ・入出力回路を1つのチップにまとめた小さなコンピュータ。マイコンと呼ぶ
- ポイント：機器の中に組み込まれて使われる。1チップに全部入っているのでワンチップマイコンとも呼ぶ

#### 量子コンピュータ（りょうしこんぴゅーた / Quantum Computer）

- 意味：0と1を同時にとれる量子の性質（重ね合わせ・量子もつれ）を使って計算するコンピュータ
- ポイント：特定の問題（素因数分解・組合せ最適化・量子化学の計算など）で、従来のコンピュータより圧倒的に速くなると期待されている

### 量子コンピュータのしくみ

#### 量子ゲート方式（りょうしげーとほうしき / Gate-based Quantum Computing）

- 意味：量子ビットに論理演算に当たる操作（ゲート）を順に加えて計算する方式。汎用の計算ができる
- ポイント：アニーリング方式が最適化問題専用なのに対し、こちらは様々なアルゴリズムを組める
- 例：R6春 問9（量子ゲート方式の説明→複数の状態を同時に表す量子ビットと、その重ね合わせを利用する）

#### 量子アニーリング方式（りょうしあにーりんぐほうしき / Quantum Annealing）

- 意味：量子の性質を使って、たくさんの組合せの中からエネルギーが一番低い状態（最適な組合せ）を探す方式
- ポイント：組合せ最適化問題に特化している。ゲートを組み合わせる汎用の計算はしない

#### 量子ビット（りょうしびっと / Qubit）

- 意味：0の状態と1の状態を重ね合わせてもつことができる、量子コンピュータの情報の単位
- ポイント：nビットの古典ビットは2ⁿ通りのうち1つしか表せないが、こちらは n個で2ⁿ通りの状態を同時に重ね合わせて扱える
- 語の意味：Quantum＝量子の／bit＝2進数の1桁

#### 重ね合わせ（かさねあわせ / Superposition）

- 意味：観測するまで、複数の状態が同時に存在しているという量子の性質
- ポイント：観測すると、どれか1つの状態に確率的に決まる

#### 量子超越性（りょうしちょうえつせい / Quantum Supremacy）

- 意味：従来のコンピュータでは現実的な時間で解けない計算を、量子コンピュータが実際に解いてみせること
- ポイント：「量子力学に基づいて作られていること」や「装置が小さいこと」ではなく、計算時間で上回ることを指す
- 例：R6秋 問9（従来のコンピュータでは実用的な時間で処理できない計算を、高速に実行できること）

### 五大装置

#### 演算装置（えんざんそうち / Arithmetic Unit）

- 意味：四則演算や論理演算など、データの計算を行う装置
- ポイント：制御装置と合わせてプロセッサ（CPU）を作る。ALU（算術論理演算装置）が中心

#### 制御装置（せいぎょそうち / Control Unit）

- 意味：命令を取り出して解読し、ほかの装置に指示を出して全体を動かす装置
- ポイント：データは扱わず、指示（制御の流れ）を出す役目

#### 記憶装置（きおくそうち / Storage Unit）

- 意味：プログラムやデータを記憶する装置。主記憶と補助記憶に分かれる
- ポイント：プロセッサが直接読み書きするのは主記憶。補助記憶のデータは主記憶に読み込んでから使う

#### 入力装置（にゅうりょくそうち / Input Device）

- 意味：キーボードやマウスのように、外からデータや指示をコンピュータに取り込む装置
- ポイント：取り込んだデータはまず記憶装置へ送られる

#### 出力装置（しゅつりょくそうち / Output Device）

- 意味：ディスプレイやプリンタのように、処理結果を人や外部に取り出す装置
- ポイント：データの流れは「入力→記憶→演算→記憶→出力」。制御装置の指示は全部の装置に出る

### プロセッサの種類

#### CPU（しーぴーゆー / Central Processing Unit）

- 意味：プログラムの命令を順に読んで実行し、コンピュータ全体の処理を受け持つ中心のプロセッサ
- ポイント：複雑な処理や分岐の多い処理が得意。コア数はGPUより少ない
- 語の意味：Central＝中央の／Processing＝処理／Unit＝装置

#### GPU（じーぴーゆー / Graphics Processing Unit）

- 意味：画像処理のために、単純な演算器を数千個並べて同じ計算を一斉に行うプロセッサ
- ポイント：行列演算が速いので、ディープラーニングの学習にも使われる
- 例：R3春 問10・R4秋 問8（ディープラーニングにGPUを使う利点→行列演算ユニットで行列演算を高速に実行できる）
- 語の意味：Graphics＝画像／Processing＝処理／Unit＝装置

#### GPGPU（じーぴーじーぴーゆー / General-Purpose computing on GPU）

- 意味：画像処理用のプロセッサがもつ並列計算の力を、画像以外の科学技術計算やAIの計算に使うこと
- ポイント：プロセッサの名前というより「使い方」の名前
- 語の意味：General-Purpose＝汎用の／computing＝計算／on＝〜の上での

#### DSP（でぃーえすぴー / Digital Signal Processor）

- 意味：音声や画像などの信号処理を高速に行うことに特化したプロセッサ
- ポイント：積和演算（掛けて足す）を1命令で行う回路をもつ。携帯電話やオーディオ機器で使う
- 語の意味：Digital＝デジタルの／Signal＝信号／Processor＝処理装置

#### FPU（えふぴーゆー / Floating Point Unit）

- 意味：浮動小数点数の演算を専門に行う演算装置。コプロセッサとしてCPUを補う
- ポイント：今は多くのCPUに内蔵されている
- 語の意味：Floating＝浮動の／Point＝小数点／Unit＝装置

#### AIチップ（えーあいちっぷ / AI Chip）

- 意味：ニューラルネットワークの学習や推論に必要な行列演算を、高速かつ低い電力で行うことに特化した半導体。グーグル社のTPUなどがある
- ポイント：汎用性を捨て、精度の低い数値で大量に計算することで効率を上げる

#### TPU（てぃーぴーゆー / Tensor Processing Unit）

- 意味：グーグル社が開発した、機械学習のテンソル（多次元の数値の配列）計算に特化したプロセッサ。AIチップの一つ
- ポイント：行列の掛け算を一度に大量に行う回路をもつ
- 語の意味：Tensor＝テンソル（多次元配列）／Processing＝処理／Unit＝装置

### データの単位とバイト順

#### ビット（びっと / Bit）

- 意味：0か1かを表す、情報の最小の単位
- ポイント：nビットで2ⁿ通りを表せる
- 語の意味：binary digit（2進数の1桁）を縮めた語

#### バイト（ばいと / Byte）

- 意味：8ビットをまとめた単位。1文字（半角英数字）を表すのに使う
- ポイント：記憶容量や転送量の単位に使う。転送速度は「ビット／秒」で書かれることが多いので、8倍・8分の1の換算に注意

#### ワード（わーど / Word）

- 意味：プロセッサが1回の命令でまとめて扱うデータの大きさ。16ビット・32ビット・64ビットなどプロセッサによって違う
- ポイント：「64ビットCPU」の64はこの大きさ（レジスタの幅）を指す

#### キャラクタ（きゃらくた / Character）

- 意味：1つの文字を表すのに使うデータの大きさの単位
- ポイント：文字コードによって大きさが違う（ASCIIは1バイト、UTF-8の日本語はふつう3バイト）

#### ビッグエンディアン（びっぐえんでぃあん / Big Endian）

- 意味：複数バイトのデータをメモリに置くとき、上位のバイトから小さいアドレスへ順に並べる方式
- ポイント：16進の 12345678 なら、アドレスの小さい順に 12・34・56・78 と並ぶ。人が読む順と同じ。ネットワークのデータはこの順

#### リトルエンディアン（りとるえんでぃあん / Little Endian）

- 意味：複数バイトのデータをメモリに置くとき、下位のバイトから小さいアドレスへ順に並べる方式
- ポイント：12345678 なら 78・56・34・12 の順。x86系のプロセッサが採用している

### 命令セットとアーキテクチャ

#### RISC（りすく / Reduced Instruction Set Computer）

- 意味：命令の種類を減らし、どの命令も長さをそろえて1クロック程度で実行できるようにしたプロセッサの設計
- ポイント：命令が単純なのでパイプラインに向く。制御は回路で直接行う（布線論理制御）
- 語の意味：Reduced＝減らした／Instruction＝命令／Set＝一式／Computer＝計算機

#### CISC（しすく / Complex Instruction Set Computer）

- 意味：複雑で高機能な命令をたくさん用意し、1命令で多くの仕事をさせるプロセッサの設計
- ポイント：命令の長さがまちまちで、実行に必要なクロック数も命令によって違う。制御はマイクロプログラムで行うことが多い
- 語の意味：Complex＝複雑な／Instruction＝命令／Set＝一式／Computer＝計算機

#### ハーバードアーキテクチャ（はーばーどあーきてくちゃ / Harvard Architecture）

- 意味：命令を読むための経路（バスとメモリ）とデータを読み書きするための経路を分けたコンピュータの構成
- ポイント：命令の読込みとデータのアクセスを同時にできるので速い。DSPやキャッシュ（命令用とデータ用を分ける）で使われる

#### プリンストンアーキテクチャ（ぷりんすとんあーきてくちゃ / Princeton Architecture）

- 意味：命令とデータを同じメモリに置き、同じバスで読み書きするコンピュータの構成。ノイマン型とも呼ぶ
- ポイント：作りは簡単だが、命令とデータの読込みが同じバスを取り合う（ノイマンボトルネック）

### 命令の形式

#### 固定長命令（こていちょうめいれい / Fixed-length Instruction）

- 意味：どの命令も同じ長さ（例えば32ビット）にそろえた命令の形式
- ポイント：次の命令の位置がすぐ分かるので、解読とパイプライン処理が簡単になる。RISCで採用

#### 可変長命令（かへんちょうめいれい / Variable-length Instruction）

- 意味：命令の種類によって長さが違う命令の形式
- ポイント：よく使う命令を短くでき、プログラムが小さくなる。その代わり解読が複雑。CISCで採用

#### 1オペランド形式（いちおぺらんどけいしき / One-operand Format）

- 意味：命令のアドレス部に、データの場所を1つだけ書く命令の形式。もう一方のデータはアキュムレータを使う
- ポイント：「アキュムレータ ← アキュムレータ ＋ メモリの値」のような命令になる

#### 2オペランド形式（にオペランドけいしき / Two-operand Format）

- 意味：命令のアドレス部に、データの場所を2つ書く命令の形式
- ポイント：「レジスタ1 ← レジスタ1 ＋ レジスタ2」のように、片方が結果の置き場所を兼ねる

### 演算装置と制御装置の部品

#### 加算器（かさんき / Adder）

- 意味：2つの2進数を足し合わせる回路。演算装置の中心
- ポイント：引き算は「補数を足す」ことで加算の回路で行う

#### 補数器（ほすうき / Complementer）

- 意味：2進数の各ビットを反転させるなどして、補数を作る回路
- ポイント：2の補数を作れば、減算を加算に置き換えられる
- 例：R3秋 問8（16ビットの符号付き加算で、絶対値の和が32,768以下でもオーバーフローする組合せがある→符号が異なる2数の加算はオーバーフローしない）

#### 乗算器（じょうさんき / Multiplier）

- 意味：2つの数の掛け算を行う回路
- ポイント：シフトと加算の繰返しで作れるが、専用の回路にすると速い

#### 積和演算器（せきわえんざんき / Multiply-Accumulator）

- 意味：「掛けた結果を足し込む（a×b＋c）」を1回で行う回路。MACとも呼ぶ
- ポイント：信号処理やニューラルネットワークの計算で大量に使うので、DSPやAIチップに多く載っている

#### アキュムレータ（あきゅむれーた / Accumulator）

- 意味：演算の途中結果をためておくための、演算装置の中のレジスタ
- ポイント：1オペランド形式の命令では、計算の相手と結果の置き場所を兼ねる
- 語の意味：Accumulate＝ためていく

#### デコーダ（でこーだ / Decoder）

- 意味：命令の命令部を読み取り、どの回路をどう動かすかの信号に変える回路。命令解読器・復号器とも呼ぶ
- ポイント：制御装置の部品。命令の取出し→解読→実行の「解読」を受け持つ

### レジスタ

#### プログラムカウンタ（ぷろぐらむかうんた / Program Counter）

- 意味：次に実行する命令が入っているアドレスを保持するレジスタ。命令アドレスレジスタ・逐次制御カウンタとも呼ぶ
- ポイント：命令を取り出すたびに命令の長さ分だけ進む。分岐命令はこの値を書き換える

#### 命令レジスタ（めいれいれじすた / Instruction Register）

- 意味：主記憶から取り出した、いま実行中の命令を入れておくレジスタ。IRと略す
- ポイント：ここに入った命令の命令部をデコーダが解読する
- 語の意味：Instruction＝命令／Register＝記録する場所

#### 汎用レジスタ（はんようれじすた / General Register）

- 意味：演算の途中のデータやアドレスなど、何にでも使えるレジスタ。GRと略す
- ポイント：数が多いほど主記憶を読み書きする回数を減らせる

#### インデックスレジスタ（いんでっくすれじすた / Index Register）

- 意味：アドレス部の値に足して有効アドレスを作るための、増減する値（指標）を入れるレジスタ。指標レジスタとも呼ぶ
- ポイント：配列の何番目かを入れて、同じ命令で配列の要素を順に処理する

#### ベースレジスタ（べーすれじすた / Base Register）

- 意味：プログラムが置かれた先頭の番地を入れておき、アドレス部の値に足して有効アドレスを作るためのレジスタ
- ポイント：これを書き換えるだけで、プログラムを主記憶のどこに置いても動かせる（再配置）

#### メモリアドレスレジスタ（めもりあどれすれじすた / Memory Address Register）

- 意味：これから読み書きする主記憶のアドレスを入れておくレジスタ。MARと略す
- ポイント：データそのものを入れるのはデータレジスタの方
- 語の意味：Memory＝記憶装置／Address＝番地／Register＝記録する場所

#### データレジスタ（でーたれじすた / Data Register）

- 意味：主記憶との間でやり取りするデータを一時的に入れておくレジスタ。DRやMR（メモリレジスタ）とも呼ぶ
- ポイント：アドレスはMARに、データはこちらに入れて読み書きする

#### スタックポインタ（すたっくぽいんた / Stack Pointer）

- 意味：主記憶上のスタックの一番上の位置を指すレジスタ
- ポイント：サブルーチンの呼出しや割込みで、戻り先を積むたびに値が変わる

### 基本の論理回路

#### AND回路（あんどかいろ / AND Gate）

- 意味：入力がどちらも1のときだけ1を出す回路。論理積
- ポイント：ビットの一部を取り出す（マスクする）のに使う

#### OR回路（おあかいろ / OR Gate）

- 意味：入力のどちらかが1なら1を出す回路。論理和
- ポイント：特定のビットを1にするのに使う

#### NOT回路（のっとかいろ / NOT Gate）

- 意味：入力を反転させて出す回路。否定
- ポイント：入力は1つだけ

#### NAND回路（なんどかいろ / NAND Gate）

- 意味：論理積の結果を反転させて出す回路。入力がどちらも1のときだけ0になる
- ポイント：これだけを組み合わせて、どんな論理回路も作れる
- 語の意味：Not＝否定／AND＝論理積

#### NOR回路（のあかいろ / NOR Gate）

- 意味：論理和の結果を反転させて出す回路。入力がどちらも0のときだけ1になる
- ポイント：これだけを組み合わせても、どんな論理回路も作れる
- 語の意味：Not＝否定／OR＝論理和

#### XOR回路（えっくすおあかいろ / Exclusive OR Gate）

- 意味：入力の2つが異なるときに1を出す回路。排他的論理和
- ポイント：足し算の1桁目（桁上がりを除いた和）はこの回路で求まる
- 語の意味：eXclusive＝排他的な／OR＝論理和

### 回路の組立て

#### 半加算器（はんかさんき / Half Adder）

- 意味：1ビットどうしを足して、和と桁上がりを出す組合せ回路。下の桁からの桁上がりは受け取らない
- ポイント：和は XOR、桁上がりは AND で作る

#### 全加算器（ぜんかさんき / Full Adder）

- 意味：1ビットどうしに下の桁からの桁上がりも加えて足し、和と桁上がりを出す回路
- ポイント：半加算器2つと OR 回路で作れる。並べると複数ビットの足し算ができる

#### 組合せ回路（くみあわせかいろ / Combinational Circuit）

- 意味：出力が、いまの入力だけで決まる論理回路
- ポイント：過去の状態を覚えない。加算器やデコーダが代表

#### 順序回路（じゅんじょかいろ / Sequential Circuit）

- 意味：出力が、いまの入力と、回路が記憶している過去の状態の両方で決まる論理回路
- ポイント：記憶する部品（フリップフロップ）をもつ。カウンタやレジスタが代表

#### フリップフロップ（ふりっぷふろっぷ / Flip-flop）

- 意味：0か1の状態を保持し続けられる回路。1ビットを記憶する基本部品
- ポイント：レジスタやSRAMの記憶素子に使われる

### 命令の種類

#### 算術演算命令（さんじゅつえんざんめいれい / Arithmetic Instruction）

- 意味：加算・減算・乗算・除算など、数としての計算を行う命令
- ポイント：結果の符号やオーバーフローがフラグに記録される

#### 論理演算命令（ろんりえんざんめいれい / Logical Instruction）

- 意味：AND・OR・XOR・NOT など、ビットごとの論理演算を行う命令
- ポイント：桁上がりがなく、各ビットを独立に扱う

#### 転送命令（てんそうめいれい / Transfer Instruction）

- 意味：レジスタとメモリの間や、メモリの中でデータを移す命令（ロード・ストア・ムーブ）
- ポイント：転送元と転送先が重なっているときは、まだ読んでいないデータを上書きしないよう順番に注意する
- 例：R6春 問8（1001〜1004番地を1003〜1006番地へ1語ずつ転送→重なる部分を先に上書きしないよう、末尾の1004から降順に転送する）

#### 比較命令（ひかくめいれい / Compare Instruction）

- 意味：2つの値を比べ、大小や等しいかどうかの結果を状態（フラグ）に記録する命令
- ポイント：値そのものは変えない。結果を見て分岐命令が行き先を決める

#### 分岐命令（ぶんきめいれい / Branch Instruction）

- 意味：次に実行する命令の場所を変える命令。条件付きと無条件がある
- ポイント：プログラムカウンタを書き換える。パイプラインの流れを乱す原因になる

#### シフト命令（しふとめいれい / Shift Instruction）

- 意味：ビットの並びを左右にずらす命令
- ポイント：左に1ビットずらすと2倍、右に1ビットずらすと2分の1。符号を保つ算術シフトと、保たない論理シフトがある

#### 入出力命令（にゅうしゅつりょくめいれい / I/O Instruction）

- 意味：入出力装置との間でデータをやり取りしたり、装置に動作を指示したりする命令
- ポイント：OSだけが使える特権命令にしていることが多い

### 命令の実行手順

#### 命令フェッチ（めいれいふぇっち / Instruction Fetch）

- 意味：プログラムカウンタが指す番地から命令を読み出し、命令レジスタに入れる段階
- ポイント：命令実行の最初の段階
- 語の意味：Fetch＝取ってくる

#### 命令デコード（めいれいでこーど / Instruction Decode）

- 意味：取り出した命令の命令部を解読し、何をする命令かを調べる段階
- ポイント：RISCの5段パイプラインでは、この段でレジスタの値も読み出す

#### オペランドフェッチ（おぺらんどふぇっち / Operand Fetch）

- 意味：命令が使うデータを、有効アドレスで示されたメモリやレジスタから読み出す段階
- ポイント：この前に、アドレス部から有効アドレスを求める「アドレス計算」がある

#### 命令の実行（めいれいのじっこう / Execute）

- 意味：解読した内容にしたがって、演算装置で計算などを行う段階
- ポイント：RISCの5段パイプラインは「命令フェッチ→デコードとレジスタ読出し→実行とアドレス生成→メモリアクセス→書込み」の順
- 例：R6秋 問8（RISCの5段パイプラインの順序→④命令フェッチ、③デコード、②実行、⑤メモリアクセス、①書込み）

### 命令語とアドレス

#### 命令部（めいれいぶ / Operation Code）

- 意味：命令語のうち、加算・転送など「何をするか」を表す部分。オペコードとも呼ぶ
- ポイント：デコーダが解読する部分

#### アドレス部（あどれすぶ / Operand）

- 意味：命令語のうち、演算に使うデータやその場所を表す部分。オペランドとも呼ぶ
- ポイント：ここに書かれた値と指定方式から、実際に使う番地を計算する

#### 有効アドレス（ゆうこうあどれす / Effective Address）

- 意味：アドレス部の値をレジスタの値などで修飾して求めた、実際にデータが置かれている主記憶の番地。実効アドレスとも呼ぶ
- ポイント：試験では「この方式なら何番地になるか」を計算させる

#### アドレス修飾（あどれすしゅうしょく / Address Modification）

- 意味：アドレス部の値に、インデックスレジスタやベースレジスタの値を足すなどして、実際の番地を作ること
- ポイント：修飾のしかたの違いがアドレス指定方式の違いになる

### アドレス指定方式

#### 即値アドレス指定（そくちあどれすしてい / Immediate Addressing）

- 意味：アドレス部に書かれた値を、番地ではなくデータそのものとして使う方式
- ポイント：メモリを読みに行かないので速い。定数を使うときの方式

#### 直接アドレス指定（ちょくせつあどれすしてい / Direct Addressing）

- 意味：アドレス部に書かれた値を、そのままデータの番地として使う方式
- ポイント：有効アドレス＝アドレス部の値

#### 間接アドレス指定（かんせつあどれすしてい / Indirect Addressing）

- 意味：アドレス部が指す番地に書かれている値を、データの番地として使う方式
- ポイント：番地を2回たどる。ポインタをたどる処理に当たる

#### インデックスアドレス指定（いんでっくすあどれすしてい / Indexed Addressing）

- 意味：アドレス部の値に指標レジスタの値を足して、データの番地を作る方式。インデックス修飾とも呼ぶ
- ポイント：アドレス部に配列の先頭、レジスタに何番目かを入れる

#### ベースアドレス指定（べーすあどれすしてい / Base Addressing）

- 意味：プログラムの先頭番地を入れたレジスタの値にアドレス部の値を足して、データの番地を作る方式
- ポイント：アドレス部には「プログラムの先頭からの距離」を書く

#### 相対アドレス指定（そうたいあどれすしてい / Relative Addressing）

- 意味：プログラムカウンタの値にアドレス部の値を足して、データや分岐先の番地を作る方式
- ポイント：「いまの命令から何番地先か」で表すので、プログラムをどこに置いても書き換えずに動く

#### 絶対アドレス指定（ぜったいあどれすしてい / Absolute Addressing）

- 意味：主記憶の番地を、0番地から数えた実際の番地で直接書く方式
- ポイント：置く場所を変えるとアドレスを直す必要がある

### 割込みの種類

#### SVC割込み（えすぶいしーわりこみ / Supervisor Call Interrupt）

- 意味：プログラムがOSの機能（入出力やメモリの確保など）を使うために、自分から発生させる割込み。内部割込みの一つ
- ポイント：システムコールのときに起きる。プログラムの中の命令が原因
- 語の意味：Supervisor＝監督者（OS）／Call＝呼出し

#### プログラム割込み（ぷろぐらむわりこみ / Program Interrupt）

- 意味：0での割り算・オーバーフロー・不正な命令やアドレスなど、実行中のプログラムの誤りが原因で起きる割込み。内部割込みの一つ
- ポイント：ページフォールト（仮想記憶でページが主記憶にないこと）もこの種類に入れることが多い

#### 入出力割込み（にゅうしゅつりょくわりこみ / I/O Interrupt）

- 意味：入出力装置が、転送の終わりや異常をプロセッサに知らせるために起こす割込み。外部割込みの一つ
- ポイント：これがあるので、プロセッサは入出力の完了を待たずに別の処理を進められる

#### マシンチェック割込み（ましんちぇっくわりこみ / Machine Check Interrupt）

- 意味：電源の異常やメモリの故障など、ハードウェアの障害を検出したときに起きる割込み。外部割込みの一つ
- ポイント：プログラムの誤りではなく、機械の故障が原因

#### タイマ割込み（たいまわりこみ / Timer Interrupt）

- 意味：あらかじめ設定した時間が経ったことを知らせるために、時計の回路が起こす割込み。外部割込みの一つ
- ポイント：OSはこれを使って、一定時間ごとに実行するタスクを切り替える（タイムスライス）

#### コンソール割込み（こんそーるわりこみ / Console Interrupt）

- 意味：オペレータが操作卓（コンソール）のボタンなどを操作したときに起きる割込み。外部割込みの一つ
- ポイント：人の操作が原因の割込み

### 割込みの制御

#### 内部割込み（ないぶわりこみ / Internal Interrupt）

- 意味：実行中のプログラムが原因で起きる割込みの総称。SVC割込みやプログラム割込みが入る
- ポイント：同じ条件で同じプログラムを動かせば、同じ場所で必ず起きる（同期的）

#### 外部割込み（がいぶわりこみ / External Interrupt）

- 意味：実行中のプログラムとは関係なく、プロセッサの外の出来事が原因で起きる割込みの総称。入出力割込み・タイマ割込み・マシンチェック割込みなどが入る
- ポイント：いつ起きるかがプログラムの進み具合と関係しない（非同期的）

#### マスク可能割込み（ますくかのうわりこみ / Maskable Interrupt）

- 意味：プログラムの設定で、一時的に受け付けないようにできる割込み
- ポイント：大事な処理の最中に邪魔されないよう、禁止しておける

#### マスク不能割込み（ますくふのうわりこみ / Non-Maskable Interrupt）

- 意味：禁止の設定をしても必ず受け付けられる割込み。NMIと略す
- ポイント：電源異常など、すぐに対応しないと困る事象に使う
- 語の意味：Non＝〜でない／Maskable＝覆い隠せる／Interrupt＝割込み

#### 多重割込み（たじゅうわりこみ / Nested Interrupt）

- 意味：ある割込みを処理している最中に、別の割込みを受け付けること
- ポイント：優先度の高い割込みだけを受け付け、低いものは今の処理が終わるまで待たせる

### マイクロプログラム制御

#### マイクロプログラム制御（まいくろぷろぐらむせいぎょ / Microprogrammed Control）

- 意味：1つの機械語命令を、もっと細かい手順（マイクロ命令）の並びとしてプロセッサ内のメモリに書いておき、それを順に実行して命令を処理する方式
- ポイント：命令を後から追加・変更しやすい。CISCで多く使われた。回路で直接制御するより遅い

#### 布線論理制御（ふせんろんりせいぎょ / Hard-wired Control）

- 意味：命令の実行手順を、論理回路の配線そのもので作り込んで制御する方式。ワイヤードロジックとも呼ぶ
- ポイント：速いが、変更には回路の作り直しが必要。RISCで使う

#### 水平型マイクロ命令（すいへいがたまいくろめいれい / Horizontal Microcode）

- 意味：マイクロ命令の各ビットが、制御する回路の1本1本に直接対応しているマイクロ命令の形式
- ポイント：1つの命令が長いが、解読がいらず、同時に多くの回路を動かせる

#### 垂直型マイクロ命令（すいちょくがたまいくろめいれい / Vertical Microcode）

- 意味：制御の内容を符号にして短くまとめたマイクロ命令の形式
- ポイント：命令は短いが、実行のたびに解読が必要で、同時にできることは少ない

#### エミュレーション（えみゅれーしょん / Emulation）

- 意味：あるコンピュータの命令や動作を、別のコンピュータの上でまねて実行すること
- ポイント：マイクロプログラムを入れ替えると、別の機械の命令体系をまねられる

### プロセッサの性能指標

#### クロック周波数（くろっくしゅうはすう / Clock Frequency）

- 意味：プロセッサの動作のタイミングを合わせる信号が、1秒間に何回刻まれるか。単位はHz
- ポイント：1.25GHzなら1秒間に12.5億回。同じCPIなら、高いほど速い
- 例：R5春 問8（1.25GHzで1秒間に10億命令→1命令あたり1.25クロック）

#### サイクルタイム（さいくるたいむ / Cycle Time）

- 意味：クロック1回分の時間
- ポイント：周波数の逆数。1GHzなら1ナノ秒
- 例：R7春 問8（周期1ナノ秒・CPI 4.0 のAと、周期4ナノ秒・CPI 0.5 のB→1命令はAが4ナノ秒、Bが2ナノ秒で、Aの処理時間はBの2倍）

#### CPI（しーぴーあい / Cycles Per Instruction）

- 意味：1つの命令を実行するのに、平均で何クロックかかるか
- ポイント：小さいほど速い。逆数のIPC（1クロックあたり何命令）でも表す
- 語の意味：Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令

#### MIPS（みっぷす / Million Instructions Per Second）

- 意味：1秒間に何百万個の命令を実行できるかを表す性能の値
- ポイント：1命令の平均実行時間の逆数。平均20ナノ秒なら 1÷(20×10⁻⁹)＝5,000万命令＝50MIPS
- 例：R3春 問9（命令ミックスから平均実行時間25ナノ秒を求め、40MIPS）
- 語の意味：Million＝百万／Instructions＝命令／Per＝〜あたり／Second＝秒

#### FLOPS（ふろっぷす / Floating-point Operations Per Second）

- 意味：1秒間に浮動小数点数の演算を何回できるかを表す性能の値
- ポイント：科学技術計算やスーパーコンピュータの性能に使う。G（10⁹）・T（10¹²）・P（10¹⁵）を付けて表す
- 例：R7秋 問11（10GFLOPSのコアを2倍の性能にし、総コア数を4倍の32,000にする→20GFLOPS×32,000＝640TFLOPS）
- 語の意味：Floating-point＝浮動小数点／Operations＝演算／Per Second＝毎秒

#### 命令ミックス（めいれいみっくす / Instruction Mix）

- 意味：命令の種類ごとの実行時間と出現する割合の組。これで1命令の平均実行時間を求める
- ポイント：「実行時間×出現頻度」を全部の種類について足すと平均になる。科学技術計算向けをギブソンミックス、事務計算向けをコマーシャルミックスと呼ぶ

### パイプライン処理

#### 命令パイプライン（めいれいぱいぷらいん / Instruction Pipeline）

- 意味：命令の実行を複数の段階に分け、前の命令が次の段階に進んだら、すぐ次の命令の最初の段階を始めて、命令を重ねて処理する方式
- ポイント：k段で n命令なら k＋(n−1) サイクル。1命令の時間は短くならないが、まとめて処理する速さが上がる
- 例：R5春 問9（5段で20命令→5＋19＝24サイクル）

#### スーパーパイプライン（すーぱーぱいぷらいん / Superpipeline）

- 意味：パイプラインの1段をさらに細かく分け、段数を増やして1段の処理時間を短くする方式
- ポイント：クロック周波数を上げられるが、分岐で流れが乱れたときの損が大きくなる

#### スーパースカラ（すーぱーすから / Superscalar）

- 意味：パイプラインを複数本用意し、同時に実行できる命令をハードウェアが見つけて、同じクロックで複数の命令を流す方式
- ポイント：並べる判断は実行するときにハードウェアが行う

#### VLIW（ぶいえるあいだぶりゅー / Very Long Instruction Word）

- 意味：同時に実行できる複数の動作を、コンパイルの段階で1つの長い命令にまとめておき、それを並列に実行する方式
- ポイント：並べる判断はコンパイラが行うので、ハードウェアは簡単になる
- 例：R4春 問8・R7秋 問8（同時に実行可能な複数の動作をコンパイルの段階でまとめて一つの複合命令とする方式）
- 語の意味：Very Long＝とても長い／Instruction＝命令／Word＝語

#### ベクトル処理方式（べくとるしょりほうしき / Vector Processing）

- 意味：配列（ベクトル）のたくさんの要素に、同じ演算を1つの命令でまとめて行う方式
- ポイント：科学技術計算向け。フリンの分類ではSIMDに当たる

### パイプラインハザード

#### パイプラインハザード（ぱいぷらいんはざーど / Pipeline Hazard）

- 意味：何らかの理由で次の命令を予定どおり流せず、パイプラインが止まったり、やり直しになったりすること。データハザード・構造ハザード・制御ハザードの3種類がある
- ポイント：これが起きると、命令パイプラインの効果が下がる

#### データハザード（でーたはざーど / Data Hazard）

- 意味：後の命令が、前の命令の計算結果を使うのに、その結果がまだできていないために待たされること
- ポイント：結果をレジスタに書き込む前に次の命令へ直接渡す（フォワーディング）ことで待ちを減らす

#### 構造ハザード（こうぞうはざーど / Structural Hazard）

- 意味：複数の命令が同じ回路やメモリを同時に使おうとして、取り合いになること
- ポイント：命令用とデータ用のキャッシュを分けるなど、回路を増やして防ぐ

#### 制御ハザード（せいぎょはざーど / Control Hazard）

- 意味：分岐命令の行き先が決まるまで次に読む命令が分からず、先に読み込んだ命令が無駄になること
- ポイント：分岐予測や遅延分岐で損を減らす

### ハザードを減らす技術

#### 分岐予測（ぶんきよそく / Branch Prediction）

- 意味：分岐命令が分岐するかどうかを、過去の結果などから予想すること
- ポイント：予想した先の命令を先に読み込んでおく。外れたら読み込んだ分を捨てる

#### 投機実行（とうきじっこう / Speculative Execution）

- 意味：分岐の条件が決まる前に、予測した分岐先の命令を実際に実行してしまう技術
- ポイント：外れたら実行結果を取り消す。予測して「読む」だけでなく「実行する」まで進めるのが違い
- 例：R5秋 問9（分岐条件の結果が決定する前に、分岐先を予測して命令を実行するもの）

#### アウトオブオーダー実行（あうとおぶおーだーじっこう / Out-of-order Execution）

- 意味：前の命令の結果を待っている間に、それに関係のない後ろの命令を先に実行する技術
- ポイント：プログラムに書かれた順番とは違う順で実行するが、結果は元の順に確定させる

#### 遅延分岐（ちえんぶんき / Delayed Branch）

- 意味：分岐命令の直後に置いた命令を、分岐するかどうかに関係なく必ず実行する決まりにして、分岐で空く時間を埋める技術
- ポイント：直後の位置に何を置くかはコンパイラが決める

#### レジスタリネーミング（れじすたりねーみんぐ / Register Renaming）

- 意味：同じレジスタ名を使っているだけで本当は関係のない命令どうしに、別の物理的なレジスタを割り当てて、並べて実行できるようにする技術
- ポイント：名前が同じことによる見かけの依存関係をなくす

### マルチコアとスレッド

#### マルチコアプロセッサ（まるちこあぷろせっさ / Multi-core Processor）

- 意味：1つのチップの中に、命令を実行する回路（コア）を複数載せたプロセッサ
- ポイント：コアが1つのシングルコアに比べ、クロックを上げずに処理能力を上げられる

#### ヘテロジニアスマルチコア（へてろじにあすまるちこあ / Heterogeneous Multi-core）

- 意味：性能や得意分野の違う種類のコアを組み合わせて1つのチップに載せたプロセッサ
- ポイント：重い処理は高性能コア、軽い処理は省電力コアに任せて、性能と消費電力を両立させる。スマートフォンで使う
- 例：R5秋 問8（スマートフォンなどで高い処理性能と低消費電力の両立のため、異なる目的に適した複数の種類のコアを搭載）
- 語の意味：Heterogeneous＝異なる種類からなる

#### ホモジニアスマルチコア（ほもじにあすまるちこあ / Homogeneous Multi-core）

- 意味：同じ種類のコアだけを複数載せたプロセッサ
- ポイント：どのコアにも同じように仕事を割り振れる。パソコンやサーバのCPUに多い
- 語の意味：Homogeneous＝同じ種類からなる

#### big.LITTLE（びっぐりとる / big.LITTLE）

- 意味：英アーム社が提唱した、高性能で電力の大きいコアと、性能は低いが省電力のコアを組み合わせる構成
- ポイント：負荷に応じて使うコアを切り替える。異なる種類のコアを組み合わせる構成の代表例

#### マルチスレッディング（まるちすれっでぃんぐ / Multithreading）

- 意味：1つのコアで複数のスレッド（処理の流れ）の命令を並べて実行し、演算器の空き時間を減らす技術
- ポイント：インテル社のハイパースレッディングが代表。OSからは1つのコアが2つに見える

#### ソフトコアプロセッサ（そふとこあぷろせっさ / Soft-core Processor）

- 意味：FPGAのように中身を書き換えられる回路の上に、回路の設計データとして作り込んだプロセッサ
- ポイント：必要な機能だけ入れて作れる。チップに焼き付けたものをハードコアと呼ぶ

### フリンの分類

#### SISD（しすど / Single Instruction Single Data）

- 意味：1つの命令の流れで、1つのデータの流れを処理する方式
- ポイント：並列処理をしない、従来の単一プロセッサ
- 語の意味：Single＝1つの／Instruction＝命令／Data＝データ

#### SIMD（しむど / Single Instruction Multiple Data）

- 意味：1つの命令で、複数のデータに同じ演算を同時に行う方式
- ポイント：画像処理やベクトル処理、GPUの計算に向く
- 語の意味：Single＝1つの／Instruction＝命令／Multiple＝複数の／Data＝データ

#### MISD（みすど / Multiple Instruction Single Data）

- 意味：複数の命令の流れで、1つのデータの流れを処理する方式
- ポイント：実用例はほとんどない。分類として覚える
- 語の意味：Multiple＝複数の／Instruction＝命令／Single＝1つの／Data＝データ

#### MIMD（みむど / Multiple Instruction Multiple Data）

- 意味：複数の命令の流れで、それぞれ別のデータを処理する方式
- ポイント：各プロセッサが独立に別々のプログラムを動かせる。マルチプロセッサやマルチコアが当たる
- 語の意味：Multiple＝複数の／Instruction＝命令／Data＝データ

### マルチプロセッサの構成

#### 密結合マルチプロセッサ（みつけつごうまるちぷろせっさ / Tightly Coupled Multiprocessor）

- 意味：複数のプロセッサが1つの主記憶を共有し、1つのOSで動く構成
- ポイント：プロセッサを増やすと、主記憶の取り合いが性能向上の妨げになる

#### 疎結合マルチプロセッサ（そけつごうまるちぷろせっさ / Loosely Coupled Multiprocessor）

- 意味：プロセッサごとに主記憶とOSをもち、通信でつながって協力する構成
- ポイント：1台が壊れても他が動き続けやすい。クラスタはこの形

#### SMP（えすえむぴー / Symmetric Multiprocessing）

- 意味：主記憶を共有する複数のプロセッサが、どれも同じ立場でOSの処理もアプリケーションの処理も分担する方式。対称型マルチプロセッシング
- ポイント：役割を決めて分担する非対称型（AMP）と対になる。カーネルとユーザのプロセスを区別せず、同等のプロセッサに処理を分散する
- 語の意味：Symmetric＝対称の／Multi＝複数の／Processing＝処理

#### AMP（えーえむぴー / Asymmetric Multiprocessing）

- 意味：OSを動かすプロセッサ、アプリケーションを動かすプロセッサのように、それぞれの役割を決めて処理を分担する方式。非対称型マルチプロセッシング
- ポイント：制御は簡単だが、役割のプロセッサが忙しいと全体が待たされる
- 語の意味：Asymmetric＝非対称の／Multi＝複数の／Processing＝処理

#### タンデム結合（たんでむけつごう / Tandem Coupling）

- 意味：前段のプロセッサが受付などの前処理を、後段のプロセッサが本体の処理をするように、プロセッサを直列につないで処理を分担する構成
- ポイント：処理を流れ作業のように分ける。Tandem＝縦に並んだ

#### クラスタ（くらすた / Cluster）

- 意味：複数のコンピュータをネットワークでつなぎ、外から見て1台のシステムのように動かす構成
- ポイント：性能を上げる目的と、1台が壊れても止まらないようにする目的がある

#### アレイコンピュータ（あれいこんぴゅーた / Array Computer）

- 意味：同じ構成の演算装置を格子状に多数並べ、1つの制御装置の命令で全部に同じ演算をさせるコンピュータ
- ポイント：配列（行列）の計算向け。SIMD型のマルチプロセッサ

#### 超並列プロセッサ（ちょうへいれつぷろせっさ / Massively Parallel Processor）

- 意味：数千〜数万個のプロセッサをつないで、大きな問題を分けて同時に計算する構成
- ポイント：各プロセッサが自分のメモリをもつ。スーパーコンピュータで使う

### 並列化の効果と結合網

#### アムダールの法則（あむだーるのほうそく / Amdahl's Law）

- 意味：処理の一部だけを速くしたとき、全体がどれだけ速くなるかを表す法則。並列化できる割合を r、プロセッサ数を n とすると、速度向上比は 1÷{(1−r)＋r/n}
- ポイント：並列化できない部分が残る限り、プロセッサをいくら増やしても速度向上比は 1÷(1−r) で頭打ちになる
- 例：R4春 問12（並列化できない計算処理がある場合、速度向上比はプロセッサ数を増やしても、ある水準に漸近的に近づく）、R7春 問11（r＝0.9の高速化率が r＝0.3の3倍になるのはプロセッサ6台のとき）

#### 並列処理の隘路（へいれつしょりのあいろ / Parallel Bottleneck）

- 意味：並列にできず、順番に処理するしかない部分。複数のプロセッサが主記憶を同時に使おうとする競合や、データベースのロック待ちなど
- ポイント：これがあるので、プロセッサ数に比例して速くはならない

#### バリア同期（ばりあどうき / Barrier Synchronization）

- 意味：並列に動く処理がすべて決められた地点に着くまで、先に着いたものを待たせて足並みをそろえるしくみ
- ポイント：一番遅い処理に合わせることになるので、仕事の分け方が偏ると待ち時間が増える

#### トーラス（とーらす / Torus）

- 意味：プロセッサを格子状に並べてつなぎ、さらに端と端もつないで輪にした結合網
- ポイント：格子の端どうしもつながるので、遠いプロセッサまでの距離が短くなる。ドーナツ形

#### ハイパーキューブ（はいぱーきゅーぶ / Hypercube）

- 意味：2ⁿ個のプロセッサを n次元の立方体の頂点に置き、辺でつないだ結合網
- ポイント：どのプロセッサからも最大 n回の中継で全部に届く

#### ハイパーツリー（はいぱーつりー / Hypertree）

- 意味：木の形の結合網に、同じ深さの節どうしをつなぐ線を足して、根に通信が集中しないようにした結合網
- ポイント：木構造の弱点（上の節に通信が集まる）を補う
## 3-2 メモリ

### まとめ表

**半導体メモリの種類**

| 種類 | 電源を切ると | しくみ・特徴 | 主な用途 |
| :-: | :-: | :-: | :-: |
| DRAM | 消える | コンデンサの電荷で記憶。リフレッシュが必要。安くて大容量 | 主記憶 |
| SRAM | 消える | フリップフロップで記憶。リフレッシュ不要。高速だが高い | キャッシュメモリ |
| マスクROM | 消えない | 製造時に書き込み、書き換えられない | ゲーム機のソフト、家電のプログラム |
| EEPROM | 消えない | 電気で書き換えられる | 設定値の保存 |
| フラッシュメモリ | 消えない | ブロック単位でまとめて消して書く。書換え回数に上限 | SSD・USBメモリ・SDカード |
| FeRAM | 消えない | 強誘電体の性質で記憶。高速・低電力で書換え回数が多い | ICカード |

**キャッシュメモリの計算（R4春 問9・R6春 問10・R4秋 問10の論点）**

| 求めるもの | 式 |
| :-: | :-: |
| 実効アクセス時間 | ヒット率 × キャッシュの時間 ＋ (1 − ヒット率) × 主記憶の時間 |
| ヒット率（実効時間から逆算） | (主記憶の時間 − 実効時間) ÷ (主記憶の時間 − キャッシュの時間) |
| 2段キャッシュのヒット率 | L1のヒット率 ＋ (1 − L1のヒット率) × L2のヒット率 |

**キャッシュの書込み方式（R3春 問12・R5春 問10・R4秋 問9の論点）**

| 方式 | 書き込むとき | 主記憶の内容 | 速さ |
| :-: | :-: | :-: | :-: |
| ライトスルー | キャッシュと主記憶の両方に同時に書く | いつもキャッシュと一致 | 書込みのたびに主記憶へ行くので遅い |
| ライトバック | キャッシュだけに書く。追い出すときに主記憶へ書き戻す | 一時的に古いことがある | 速い |

**キャッシュの対応付け（マッピング）**

| 方式 | 主記憶のブロックを置ける場所 | 特徴 |
| :-: | :-: | :-: |
| ダイレクトマップ | キャッシュの決まった1か所 | 簡単・速いが、同じ場所を取り合いやすい |
| フルアソシエイティブ | キャッシュのどこでもよい | 取り合いは少ないが、全部を探すので回路が大きい |
| セットアソシエイティブ | 決まった組（セット）の中のどこでもよい | 上の2つの中間 |

### メモリの性質

#### RAM（らむ / Random Access Memory）

- 意味：どの番地にも同じ時間で読み書きできる半導体メモリ。ふつう電源を切ると内容が消える
- ポイント：主記憶やキャッシュに使う。DRAMとSRAMがある
- 語の意味：Random＝任意の／Access＝読み書き／Memory＝記憶装置

#### ROM（ろむ / Read Only Memory）

- 意味：もとは読出し専用の半導体メモリ。電源を切っても内容が消えない
- ポイント：今は電気で書き換えられる種類（EEPROM・フラッシュメモリ）も含めて呼ぶ
- 語の意味：Read＝読む／Only＝だけ／Memory＝記憶装置

#### 揮発性（きはつせい / Volatile）

- 意味：電源を切ると記憶した内容が消えてしまう性質
- ポイント：DRAM・SRAM・レジスタ・キャッシュがこの性質。停電に備えるにはバッテリーやUPSが要る

#### 不揮発性（ふきはつせい / Non-volatile）

- 意味：電源を切っても記憶した内容が消えない性質
- ポイント：ROM・フラッシュメモリ・FeRAM・磁気ディスクがこの性質

### RAMの種類

#### DRAM（でぃーらむ / Dynamic Random Access Memory）

- 意味：コンデンサにたまった電荷の有無で1ビットを記憶する半導体メモリ
- ポイント：電荷が少しずつ漏れるので、定期的に書き直す動作（リフレッシュ）が要る。構造が簡単で安く大容量なので主記憶に使う
- 語の意味：Dynamic＝動的な（記憶を保つのに動作が要る）

#### SRAM（えすらむ / Static Random Access Memory）

- 意味：フリップフロップの回路で1ビットを記憶する半導体メモリ
- ポイント：リフレッシュが不要で高速だが、1ビットに使う部品が多く高価。キャッシュメモリに使う
- 語の意味：Static＝静的な（何もしなくても記憶を保つ）

#### SDRAM（えすでぃーらむ / Synchronous DRAM）

- 意味：プロセッサ側のバスのクロックに同期して動くようにした、コンデンサ型のメモリ
- ポイント：クロックに合わせて連続したデータを効率よく送れる
- 語の意味：Synchronous＝同期した

#### DDR SDRAM（でぃーでぃーあーるえすでぃーらむ / Double Data Rate SDRAM）

- 意味：クロック信号の立上りと立下りの両方でデータを送り、1クロックで2回転送するメモリ
- ポイント：DDR2・DDR3・DDR4・DDR5と世代が進むごとに速くなる。世代が違うと差し込めない（互換性がない）
- 語の意味：Double＝2倍の／Data＝データ／Rate＝速度

#### FeRAM（えふいーらむ / Ferroelectric RAM）

- 意味：強誘電体（電圧をかけた向きを覚える物質）の性質を使い、電源を切っても内容が消えない半導体メモリ
- ポイント：書込みが速く、消費電力が小さく、書換え回数も多い。ICカードなどで使う
- 語の意味：Ferroelectric＝強誘電体の

#### リフレッシュ（りふれっしゅ / Refresh）

- 意味：電荷の漏れで記憶が消えないよう、一定時間ごとに中身を読み出して書き直す動作
- ポイント：コンデンサで記憶するメモリ（DRAM）だけに必要

### ROMの種類

#### マスクROM（ますくろむ / Mask ROM）

- 意味：製造するときに内容を書き込み、後から書き換えられない読出し専用メモリ
- ポイント：大量生産すると安い。家電の制御プログラムやゲームのカートリッジに使う

#### PROM（ぴーろむ / Programmable ROM）

- 意味：利用者が1回だけ内容を書き込める読出し専用メモリ
- ポイント：一度書いたら消せない
- 語の意味：Programmable＝書き込める

#### EPROM（いーぴーろむ / Erasable PROM）

- 意味：紫外線を当てて内容を全部消し、書き直せる読出し専用メモリ
- ポイント：消去には専用の装置が要る。チップに紫外線を当てる窓がある
- 語の意味：Erasable＝消去できる

#### EEPROM（いーいーぴーろむ / Electrically Erasable PROM）

- 意味：電気的に内容を消して書き直せる読出し専用メモリ
- ポイント：バイト単位で書き換えられる。設定値の保存などに使う
- 語の意味：Electrically＝電気的に／Erasable＝消去できる

#### フラッシュメモリ（ふらっしゅめもり / Flash Memory）

- 意味：電気的に書き換えられ、電源を切っても消えない半導体メモリのうち、ブロック単位でまとめて消去する方式のもの
- ポイント：書換え回数に上限がある。SSD・USBメモリ・SDカードに使う

### フラッシュメモリのしくみ

#### NAND型フラッシュメモリ（なんどがたふらっしゅめもり / NAND Flash）

- 意味：フラッシュメモリのうち、記憶素子を直列につないだ構造のもの
- ポイント：集積度が高く大容量・安価。ページ単位で読み書きする。SSDやSDカードに使う

#### NOR型フラッシュメモリ（のあがたふらっしゅめもり / NOR Flash）

- 意味：フラッシュメモリのうち、記憶素子を並列につないだ構造のもの
- ポイント：1バイト単位で速く読めるので、プログラムを置いてそのまま実行する用途（組込み機器）に向く

#### ウェアレベリング（うぇあれべりんぐ / Wear Leveling）

- 意味：書換え回数に上限のあるメモリで、特定のブロックに書込みが集中しないよう、各ブロックの書換え回数を管理して書き込む位置を分散させる技術
- ポイント：寿命を延ばすための技術。不良ブロックを置き換える技術や、書き込む量が増えてしまう現象と区別する
- 例：R5春 問11（各ブロックの書込み回数がなるべく均等になるよう、物理的な書込み位置を選択する）、R5秋 問10（ブロックごとの書換え回数を管理して寿命を延ばす技術）
- 語の意味：Wear＝すり減り／Leveling＝平らにすること

#### ライトアンプリフィケーション（らいとあんぷりふぃけーしょん / Write Amplification）

- 意味：消去がブロック単位のため、少しのデータを書き換えるだけでも、実際にはもっと多くのデータを書き直すことになる現象
- ポイント：書込み量が増えるので寿命が縮む。技術ではなく「困った現象」の名前
- 語の意味：Write＝書込み／Amplification＝増幅

#### 多値セル（たちせる / Multi-Level Cell）

- 意味：1つの記憶セルにたまる電子の量を何段階にも分けて、1セルに複数ビットを記録する方式。MLC・TLC・QLCなど
- ポイント：大容量で安くなるが、書換え回数の上限は減り、速度も落ちる。1セル1ビットはSLC

### 主記憶の構成と誤り検出

#### 記憶部（きおくぶ / Memory Array）

- 意味：主記憶のうち、記憶素子を格子状に並べてデータを実際に覚えている部分
- ポイント：行と列の組合せで、1つの記憶場所が決まる

#### アドレス選択機構（あどれすせんたくきこう / Address Selector）

- 意味：プロセッサから指定されたアドレスを解読して、記憶部の中の該当する場所を選ぶ回路
- ポイント：アドレスを行と列に分け、デコーダで選ぶ

#### 読取り書込み機構（よみとりかきこみきこう / Read/Write Circuit）

- 意味：選ばれた記憶場所からデータを読み出したり、データを書き込んだりする回路
- ポイント：読み書きの向きは、制御の信号で切り替える

#### ECC（いーしーしー / Error Correcting Code）

- 意味：データに検査用のビットを付けて、誤りを見つけるだけでなく正しく直せるようにする符号。サーバの主記憶で使う
- ポイント：ハミング符号を使い、1ビットの誤りを訂正し、2ビットの誤りを検出するものが多い
- 語の意味：Error＝誤り／Correcting＝訂正する／Code＝符号

#### パリティチェック（ぱりてぃちぇっく / Parity Check）

- 意味：データの1の数が偶数（または奇数）になるように1ビット足しておき、その数が合わなければ誤りとみなす方法
- ポイント：1ビットの誤りは見つかるが、どこが誤りかは分からないので直せない。2ビット同時の誤りは見逃す

### 記憶階層

#### レジスタ（れじすた / Register）

- 意味：プロセッサの中にある、演算に使うデータを一時的に置く最も速い記憶場所
- ポイント：数は少ないが、1クロックで読み書きできる

#### キャッシュメモリ（きゃっしゅめもり / Cache Memory）

- 意味：プロセッサと主記憶の速度の差を埋めるために間に置く、小容量で高速なメモリ
- ポイント：よく使うデータの写しを置いておき、主記憶まで行く回数を減らす。SRAMで作る

#### 主記憶装置（しゅきおくそうち / Main Memory）

- 意味：実行中のプログラムとデータを置き、プロセッサが直接読み書きする記憶装置
- ポイント：DRAMで作る。電源を切ると消える

#### 補助記憶装置（ほじょきおくそうち / Auxiliary Storage）

- 意味：プログラムやデータを、電源を切っても消えないように長く保存しておく記憶装置
- ポイント：ハードディスクやSSD。プロセッサは直接読めないので、主記憶に読み込んでから使う

#### ディスクキャッシュ（でぃすくきゃっしゅ / Disk Cache）

- 意味：主記憶と磁気ディスクの速度の差を埋めるために、間に置くバッファ用のメモリ
- ポイント：プロセッサと主記憶の間のものとは置き場所が違う。「主記憶と磁気ディスク装置との間にバッファメモリを置く」と出たらこちら

### キャッシュの対応付け

#### ダイレクトマップ方式（だいれくとまっぷほうしき / Direct Mapped）

- 意味：主記憶の各ブロックを、キャッシュの決まった1か所にしか置けないようにした方式
- ポイント：探す場所が1つなので速く回路も簡単だが、同じ場所に割り当てられたブロックどうしが追い出し合う

#### フルアソシエイティブ方式（ふるあそしえいてぃぶほうしき / Fully Associative）

- 意味：主記憶のどのブロックでも、キャッシュの任意の場所に置けるようにした方式
- ポイント：空いていればどこにでも置けるが、探すときは全部の場所を同時に比べる回路（連想メモリ）が要る
- 例：R4春 問10（任意のキャッシュメモリのブロックを、主記憶のどの部分にも割り当てられる）
- 語の意味：Fully＝完全に／Associative＝連想の

#### セットアソシエイティブ方式（せっとあそしえいてぃぶほうしき / Set Associative）

- 意味：キャッシュをいくつかの組（セット）に分け、主記憶の各ブロックを決まった組の中のどこにでも置けるようにした方式
- ポイント：1つの組に置ける場所が n個なら「nウェイ」と呼ぶ。2つの方式の中間
- 語の意味：Set＝組／Associative＝連想の

#### 連想メモリ（れんそうめもり / Content Addressable Memory）

- 意味：番地を指定するのではなく、内容を与えると、それと一致するデータがある場所を一度に探し出すメモリ。CAMと略す
- ポイント：全部の場所を同時に比べる。キャッシュのタグの検索やネットワーク機器の経路表に使う
- 語の意味：Content＝内容／Addressable＝場所を指定できる

### キャッシュの書込みと置換え

#### ライトスルー方式（らいとするーほうしき / Write Through）

- 意味：プロセッサが書き込むとき、キャッシュメモリと主記憶の両方に同時に書き込む方式
- ポイント：主記憶の内容はいつもキャッシュと一致する。そのぶん書込みのたびに主記憶へ行くので遅い
- 例：R3春 問12・R5春 問10（ライトスルー方式では主記憶の内容は常に最新）、R4秋 問9（両方に同時にデータを書き込む）
- 語の意味：Write＝書く／Through＝通り抜けて

#### ライトバック方式（らいとばっくほうしき / Write Back）

- 意味：プロセッサが書き込むときはキャッシュだけを書き換え、そのデータがキャッシュから追い出されるときに主記憶へ書き戻す方式
- ポイント：書込みは速いが、しばらくの間、主記憶の内容が古いままになる。追い出すときに書き戻しが必要
- 語の意味：Write＝書く／Back＝戻す

#### LRU方式（えるあーるゆーほうしき / Least Recently Used）

- 意味：キャッシュがいっぱいのとき、最後に使われてから一番長い時間がたったブロックを追い出す方式
- ポイント：「最近使ったものはまた使う」という性質（局所性）を利用する。ページ置換えでも同じ考え方を使う
- 語の意味：Least＝最も少なく／Recently＝最近／Used＝使われた

#### キャッシュコヒーレンシ（きゃっしゅこひーれんし / Cache Coherency）

- 意味：複数のプロセッサがそれぞれキャッシュをもつとき、同じデータの写しの内容をすべて一致させること。キャッシュの一貫性
- ポイント：1つのプロセッサが書き換えたら、ほかのキャッシュの写しを無効にするなどして守る
- 語の意味：Coherency＝一貫性

### キャッシュの性能

#### ヒット率（ひっとりつ / Hit Ratio）

- 意味：読みたいデータがキャッシュメモリに入っていた割合
- ポイント：1 − ヒット率 ＝ ミス率。実効時間からの逆算も出る
- 例：R6春 問10（主記憶60ナノ秒・キャッシュ10ナノ秒で実効15ナノ秒→ヒット率0.9）、R4秋 問10（L1が0.95、L2が0.6→0.95＋0.05×0.6＝0.98）

#### ミス率（みすりつ / Miss Ratio）

- 意味：読みたいデータがキャッシュメモリになく、主記憶まで読みに行った割合
- ポイント：容量を増やしたり、置き場所の決め方を工夫したりすると下がる

#### 実効アクセス時間（じっこうあくせすじかん / Effective Access Time）

- 意味：キャッシュに当たった場合と外れた場合を平均した、1回の読み書きにかかる時間
- ポイント：ヒット率 × キャッシュの時間 ＋ ミス率 × 主記憶の時間
- 例：R4春 問9・R6秋 問10（キャッシュが主記憶の1/30、ヒット率95%→0.95×1/30＋0.05×1≒0.08倍）

#### ミスペナルティ（みすぺなるてぃ / Miss Penalty）

- 意味：キャッシュに目的のデータがなかったとき、主記憶から持ってくるために余計にかかる時間
- ポイント：キャッシュの階層を増やすと、この時間を小さくできる

#### アクセス時間（あくせすじかん / Access Time）

- 意味：読み書きの指示を出してから、データの読み書きが終わるまでの時間
- ポイント：次の指示を受け付けられるまでの時間（サイクル時間）は、これより長い

#### サイクル時間（さいくるじかん / Memory Cycle Time）

- 意味：メモリに読み書きの指示を出してから、次の読み書きの指示を出せるようになるまでの時間
- ポイント：DRAMは読み出すと中身が壊れるので書き直す時間が要り、こちらの方が長くなる

### キャッシュの分け方

#### 命令キャッシュ（めいれいきゃっしゅ / Instruction Cache）

- 意味：プログラムの命令だけを入れるキャッシュメモリ
- ポイント：データ用と分けると、命令の取出しとデータの読み書きを同時にできる（構造ハザードを防ぐ）

#### データキャッシュ（でーたきゃっしゅ / Data Cache）

- 意味：プログラムが読み書きするデータだけを入れるキャッシュメモリ
- ポイント：書込みがあるので、書込み方式（スルーかバックか）が問題になる

#### 1次キャッシュ（いちじきゃっしゅ / L1 Cache）

- 意味：プロセッサのコアに一番近い、最も小さく最も速いキャッシュメモリ。L1キャッシュ
- ポイント：ここになければ、次の段の大きいキャッシュを探す

#### 2次キャッシュ（にじきゃっしゅ / L2 Cache）

- 意味：1段目のキャッシュになかったときに探す、少し大きく少し遅いキャッシュメモリ。L2キャッシュ
- ポイント：さらに外側の3次キャッシュ（L3）は複数のコアで共有することが多い

### 主記憶を速く・大きくする

#### メモリインタリーブ（めもりいんたりーぶ / Memory Interleave）

- 意味：主記憶を複数のバンクに分け、連続した番地を別々のバンクに順に割り当てて、複数のバンクに同時に読み書きの指示を出せるようにする方式
- ポイント：1つのバンクがサイクル時間の待ちに入っている間に、次のバンクを読める
- 例：R3秋 問9（主記憶を複数のバンクに分けて、CPUからのアクセス要求を並列的に処理できるようにする）
- 語の意味：Interleave＝交互にはさむ

#### バンク（ばんく / Bank）

- 意味：主記憶を、独立して読み書きできるように分けた1つ1つの単位
- ポイント：番地を順にバンク0・1・2・3…へ割り当てる

#### DIMM（でぃむ / Dual Inline Memory Module）

- 意味：メモリの部品を複数載せた小さな基板の規格で、表と裏の端子が別々の信号を受け持つもの。デスクトップPCやサーバで使う
- ポイント：ノートPC向けに小さくしたものがSO-DIMM
- 語の意味：Dual＝2つの／Inline＝一列の／Memory＝記憶装置／Module＝部品のまとまり

#### SO-DIMM（えすおーでぃむ / Small Outline DIMM）

- 意味：ノートPCや小型機器用に、基板の長さを短くしたメモリモジュールの規格
- ポイント：デスクトップ用のものとは大きさも端子の数も違い、差し替えられない
- 語の意味：Small＝小さい／Outline＝外形

#### ユニファイドメモリ（ゆにふぁいどめもり / Unified Memory）

- 意味：画面表示用の領域（フレームバッファ）を専用に設けず、主記憶の一部をCPUとGPUで共有して使う方式
- ポイント：部品が減って安く省電力になるが、主記憶の帯域を表示処理と取り合う
- 例：R5秋 問11・R7秋 問9（主記憶の一部を表示領域として使用する）
- 語の意味：Unified＝統一された

### 光ディスク

#### CD-ROM（しーでぃーろむ / Compact Disc Read Only Memory）

- 意味：製造時に記録した内容を読み出すだけの光ディスク。容量は約700MB
- ポイント：読出し専用型。ソフトウェアや音楽の配布に使われた
- 語の意味：Compact＝小型の／Disc＝円盤／Read Only＝読出し専用

#### CD-R（しーでぃーあーる / CD-Recordable）

- 意味：利用者が1回だけ書き込める（追記できる）コンパクトディスク
- ポイント：追記型。書いた部分は消せないが、空いている部分には後から追加できる
- 語の意味：Recordable＝記録できる

#### CD-RW（しーでぃーあーるだぶりゅー / CD-ReWritable）

- 意味：記録した内容を消して、何度も書き直せるコンパクトディスク
- ポイント：書換型。約1,000回書き換えられる
- 語の意味：ReWritable＝書き直せる

#### DVD-R（でぃーぶいでぃーあーる / DVD-Recordable）

- 意味：1回だけ書き込める（追記できる）DVD。片面1層で約4.7GB
- ポイント：追記型。2層にすると約8.5GB
- 語の意味：Digital Versatile Disc＝多用途のデジタル円盤／Recordable＝記録できる

#### DVD-RAM（でぃーぶいでぃーらむ / DVD-Random Access Memory）

- 意味：何度も書き換えられ、ハードディスクのように任意の場所を読み書きできるDVD
- ポイント：書換型。書換え回数は約10万回と多い

#### ブルーレイディスク（ぶるーれいでぃすく / Blu-ray Disc）

- 意味：青紫色のレーザ光を使い、記録の密度を上げた光ディスク。1層で約25GB
- ポイント：レーザの波長が短いほど細かく記録できる（CD→DVD→ブルーレイの順に短い）。読出し専用・追記型・書換型がある

### 取り外せる記録媒体

#### USBメモリ（ゆーえすびーめもり / USB Flash Drive）

- 意味：フラッシュメモリを使い、パソコンのUSB端子に差して使う小型の記録媒体
- ポイント：持ち運びやすい反面、紛失・盗難による情報漏えいの原因になりやすい

#### SDメモリカード（えすでぃーめもりかーど / SD Memory Card）

- 意味：フラッシュメモリを使った切手大のメモリカード。容量によってSD・SDHC・SDXCの規格がある
- ポイント：SDは2GBまで、SDHCは32GBまで、SDXCは2TBまで。デジタルカメラやスマートフォンで使う
- 語の意味：Secure Digital＝安全なデジタル（著作権保護の機能をもつ）

#### 磁気テープ（じきてーぷ / Magnetic Tape）

- 意味：磁性体を塗ったテープに、データを先頭から順に記録する記録媒体。データ保存用の装置をストリーマとも呼ぶ
- ポイント：順番にしか読めない（順次アクセス）が、容量あたりが安いのでバックアップの長期保存に使う

#### DAT（だっと / Digital Audio Tape）

- 意味：もとは音声をデジタルで記録するための小型の磁気テープ。データのバックアップにも使われた
- ポイント：テープを斜めになぞるヘリカルスキャン方式で記録する
- 語の意味：Digital＝デジタルの／Audio＝音声／Tape＝テープ

#### RAMディスク（らむでぃすく / RAM Disk）

- 意味：主記憶の一部を、ディスク装置のように見せかけて使うしくみ。RAMファイル・半導体ディスクとも呼ぶ
- ポイント：とても速いが、電源を切ると内容が消える
## 3-3 バス

### まとめ表

**バスの線の役割**

| バス | 運ぶもの | 向き | 幅で決まること |
| :-: | :-: | :-: | :-: |
| アドレスバス | 読み書きする番地 | プロセッサ → メモリ・装置 | 扱える主記憶の大きさ（32本なら2³²＝4Gバイト） |
| データバス | 読み書きするデータ | 双方向 | 1回に運べるデータの量 |
| コントロールバス | 読むか書くか・タイミング・割込みなどの信号 | 双方向 | ― |

**バスの転送能力**

| 求めるもの | 式 | 例 |
| :-: | :-: | :-: |
| 1秒間に運べる量 | バス幅（バイト）× クロック周波数 × 1クロックの転送回数 | 64ビット幅・100MHz・1回なら 8バイト×10⁸＝800Mバイト／秒 |

**バスの規格**

| 規格 | 方式 | 主な用途 |
| :-: | :-: | :-: |
| PCI | パラレル | 昔の拡張カード |
| PCI Express | シリアル（レーンを束ねて速くする） | 拡張カード・グラフィックスボード・SSD |
| NVMe | PCI Express の上で動く手順 | SSD を高速に使う |
| SCSI | パラレル（デイジーチェーン） | 昔のサーバのディスク |
| IEEE 1394 | シリアル（デイジーチェーン・ツリー） | 昔のビデオカメラ |

### バスの線の役割

#### アドレスバス（あどれすばす / Address Bus）

- 意味：プロセッサが、読み書きしたい主記憶や装置の番地を送るための信号線の束
- ポイント：本数で、指定できる番地の数（主記憶の最大容量）が決まる。n本なら2ⁿ番地

#### データバス（でーたばす / Data Bus）

- 意味：プロセッサと主記憶・入出力装置の間で、データそのものを運ぶ信号線の束
- ポイント：本数（幅）が多いほど、1回にたくさん運べる。向きは双方向

#### コントロールバス（こんとろーるばす / Control Bus）

- 意味：読むか書くかの指示や、タイミング・割込みの合図などの制御信号を運ぶ信号線の束。制御バスとも呼ぶ
- ポイント：番地やデータではなく「どう動くか」を伝える

#### バス幅（ばすはば / Bus Width）

- 意味：バスが一度に運べるビット数。信号線の本数に当たる。バスの容量とも呼ぶ
- ポイント：バスの性能（クロック周波数）と掛け合わせて、転送能力が決まる

### バスの置き場所

#### 内部バス（ないぶばす / Internal Bus）

- 意味：プロセッサのチップの中で、レジスタや演算装置などをつなぐバス
- ポイント：CPU内部バスとも呼ぶ。チップの外のバスより速い

#### システムバス（しすてむばす / System Bus）

- 意味：プロセッサと主記憶・入出力の制御回路をつなぐ、チップの外の基本となるバス。外部バスとも呼ぶ
- ポイント：アドレス・データ・制御の3種類の信号線からなる

#### メモリバス（めもりばす / Memory Bus）

- 意味：プロセッサ（またはその制御回路）と主記憶だけをつなぐ専用のバス
- ポイント：入出力と分けることで、主記憶との読み書きを速くできる

#### 入出力バス（にゅうしゅつりょくばす / I/O Bus）

- 意味：プロセッサ側と入出力装置（の制御回路）をつなぐバス。拡張カードを差すための拡張バスもこの一種
- ポイント：PCI Express などの規格がある

### バスの制御

#### バスアービタ（ばすあーびた / Bus Arbiter）

- 意味：複数の装置が同時にバスを使おうとしたとき、どれに使わせるかを決める回路
- ポイント：Arbiter＝仲裁者。調停のしかたに、集中制御・デイジーチェーン・ポーリングなどがある

#### バスマスタ（ばすますた / Bus Master）

- 意味：バスの使用権をもち、自分から転送を始められる装置
- ポイント：プロセッサのほか、DMAコントローラもこれになれる。指示を受けて応じる側をバススレーブと呼ぶ

#### 集中制御方式（しゅうちゅうせいぎょほうしき / Centralized Arbitration）

- 意味：1つの調停回路がすべての装置からの使用要求を受け取り、どれにバスを使わせるかを一括して決める方式
- ポイント：調停回路が1か所なので管理しやすいが、そこが故障すると全体が止まる

#### ポーリング方式（ぽーりんぐほうしき / Polling）

- 意味：制御する側が、各装置に順番に「使いたいか」「終わったか」を問い合わせて回る方式
- ポイント：装置側から知らせる割込み方式と逆。問い合わせのたびにプロセッサの時間を使う
- 語の意味：Poll＝問い合わせる

#### 割込み方式（わりこみほうしき / Interrupt-driven）

- 意味：装置の側から合図（割込み）を出して、使いたいことや終わったことを知らせる方式
- ポイント：制御する側は合図が来るまで別の仕事ができる

### バスの性能

#### バスクロック（ばすくろっく / Bus Clock）

- 意味：バスがデータを送るタイミングを合わせる信号の周波数。バスの性能とも呼ぶ
- ポイント：プロセッサの動作クロックとは別。幅と掛けて転送能力を求める

#### バスのスループット（ばすのすするーぷっと / Bus Throughput）

- 意味：バスが1秒間に運べるデータの量
- ポイント：幅（バイト）×周波数×1クロックの転送回数。DDRなら1クロックで2回

#### バスアクセスモード（ばすあくせすもーど / Bus Access Mode）

- 意味：外部のデータバスを何ビット幅で使うかを決める動作の設定。8ビット・16ビットなどを指定する
- ポイント：つなぐ装置のデータ幅に合わせて切り替える

#### バースト転送（ばーすとてんそう / Burst Transfer）

- 意味：最初に番地を1回だけ送り、その後は連続した番地のデータを続けてまとめて送る転送方式
- ポイント：1データごとに番地を送らないので速い。キャッシュへの読込みで使う

### バスの規格

#### PCI（ぴーしーあい / Peripheral Component Interconnect）

- 意味：パソコンの中で拡張カードをつなぐための、パラレル方式のバスの規格
- ポイント：今は後継のシリアル方式の規格に置き換わった
- 語の意味：Peripheral＝周辺の／Component＝部品／Interconnect＝相互接続

#### PCI Express（ぴーしーあいえくすぷれす / PCI Express）

- 意味：パソコンの中で拡張カードやSSDなどをつなぐ、シリアル方式の高速なバスの規格
- ポイント：PCIeと略す。レーンと呼ぶ伝送路を×1・×4・×16のように束ねて速くする。グラフィックスボードは×16

#### NVMe（えぬぶいえむいー / Non-Volatile Memory Express）

- 意味：フラッシュメモリを使ったSSDを、PCI Express の高速な伝送路の上で効率よく使うための通信の手順の規格
- ポイント：ハードディスク向けに作られた手順（AHCI）より、待ち行列が多く深いので速い
- 語の意味：Non-Volatile＝不揮発性の／Memory＝記憶装置／Express＝高速の

#### SCSI（すかじー / Small Computer System Interface）

- 意味：ハードディスクなどの周辺装置をつなぐための、パラレル方式のインタフェースの規格。ANSI X3.131 として規格化された
- ポイント：装置を数珠つなぎにし、両端に終端抵抗（ターミネータ）を付ける
- 語の意味：Small＝小型の／Computer＝計算機／System＝システム／Interface＝接続口

#### IEEE 1394（あいとりぷるいーいちさんきゅうよん / IEEE 1394）

- 意味：ビデオカメラなどをつなぐために作られた、シリアル方式の高速なインタフェースの規格。FireWire・i.LINKとも呼ばれた
- ポイント：数珠つなぎやツリー状につなげ、パソコンなしで機器どうしをつなげる
## 3-4 入出力デバイス

### まとめ表

**有線のインタフェース**

| 規格 | 方式 | 主な用途 | 押さえどころ |
| :-: | :-: | :-: | :-: |
| USB | シリアル | 周辺機器全般 | ハブでツリー状に最大127台。給電もできる |
| Thunderbolt | シリアル | 高速な外付け機器・ディスプレイ | USB Type-C と同じ形の端子を使う |
| RS-232C | シリアル | 昔のモデム・機器の設定用 | 1対1でつなぐ |
| HDMI | シリアル（デジタル） | テレビ・ディスプレイ | 映像と音声を1本で送る |
| DisplayPort | シリアル（デジタル） | パソコンのディスプレイ | 映像と音声。数珠つなぎもできる |
| シリアルATA | シリアル | 内蔵のハードディスク・SSD | パラレルATAの後継 |
| ファイバチャネル | シリアル | サーバとストレージ（SAN） | 光ケーブルも電気ケーブルも使える |

**近距離の無線**

| 規格 | 距離 | 特徴 | 主な用途 |
| :-: | :-: | :-: | :-: |
| Bluetooth | 数m〜数十m | 2.4GHz帯の電波 | イヤホン・キーボード |
| BLE | 数m〜数十m | 低消費電力の Bluetooth | センサ・ウェアラブル |
| ZigBee | 数十m | 低速・低消費電力・多数の機器で網目状につなぐ | センサネットワーク |
| Wi-SUN | 数百m〜1km程度 | 920MHz帯。低消費電力で遠くまで | スマートメーター |
| IrDA | 1m以内 | 赤外線。間に物があると届かない | 昔の携帯電話の赤外線通信 |
| NFC | 10cm程度 | 13.56MHz帯。かざして通信 | 交通系ICカード・電子決済 |

**入出力の制御方式（R7春 問9の論点）**

| 方式 | データを運ぶのは | プロセッサの負担 |
| :-: | :-: | :-: |
| プログラム制御方式 | プロセッサが1データずつ | 大きい |
| DMA方式 | DMAコントローラが主記憶と装置の間で直接 | 始めと終わりだけ |
| チャネル制御方式 | 入出力専用のプロセッサ（チャネル）がチャネルプログラムに従って | さらに小さい（大型機） |

### 有線のインタフェース

#### USB（ゆーえすびー / Universal Serial Bus）

- 意味：キーボード・マウス・記録媒体など、様々な周辺機器をつなぐためのシリアル方式のインタフェースの規格
- ポイント：ハブを使ってツリー状に最大127台つなげる。電源を入れたまま抜き差しでき、ケーブルから電気も送れる
- 語の意味：Universal＝汎用の／Serial＝直列の／Bus＝信号線の束

#### Thunderbolt（さんだーぼると / Thunderbolt）

- 意味：インテル社とアップル社が開発した、高速なデータ転送と映像の出力を1本のケーブルで行えるインタフェースの規格
- ポイント：Thunderbolt 3 以降は USB Type-C と同じ形の端子を使う。PCI Express と DisplayPort の信号をまとめて送る

#### RS-232C（あーるえすにーさんにーしー / RS-232C）

- 意味：モデムや機器の設定用の端末をつなぐための、古くからあるシリアル方式のインタフェースの規格
- ポイント：低速で1対1の接続。今でもネットワーク機器の設定用（コンソール）で使われる
- 語の意味：Recommended Standard＝推奨規格

#### HDMI（えいちでぃーえむあい / High-Definition Multimedia Interface）

- 意味：映像と音声を1本のケーブルでデジタルのまま送る、テレビやディスプレイ向けのインタフェースの規格
- ポイント：著作権保護の仕組み（HDCP）をもつ。端子は台形
- 語の意味：High-Definition＝高精細の／Multimedia＝映像や音声／Interface＝接続口

#### DisplayPort（でぃすぷれいぽーと / DisplayPort）

- 意味：パソコンとディスプレイをつなぐための、映像と音声をデジタルで送るインタフェースの規格。VESAが定めた
- ポイント：1つの出力からディスプレイを数珠つなぎにして複数台に出せる。端子は片側の角が欠けた形

#### シリアルATA（しりあるえーてぃーえー / Serial ATA）

- 意味：パソコンの中のハードディスクやSSD、光ディスク装置をつなぐための、シリアル方式のインタフェースの規格。SATAと略す
- ポイント：パラレル方式のATAを置き換えた。電源を入れたまま抜き差しできる
- 語の意味：Serial＝直列の／AT Attachment＝AT互換機への接続

#### ファイバチャネル（ふぁいばちゃねる / Fibre Channel）

- 意味：サーバとストレージを高速につなぐための、シリアル方式のインタフェースの規格。FCと略す
- ポイント：ストレージ専用のネットワーク（SAN）で使う。名前に「光」とあるが、光ケーブルも電気（銅線）ケーブルも使える
- 例：R6秋 問11（FCの特徴→伝送媒体には電気ケーブル又は光ケーブルを用いることができる）
- 語の意味：Fibre＝繊維（光ファイバ）／Channel＝通信路

#### NIC（にっく / Network Interface Card）

- 意味：コンピュータを有線LANにつなぐための拡張カードや回路。有線LANインタフェースカード
- ポイント：1台ごとに固有のMACアドレスをもつ。無線LAN用のものもある
- 語の意味：Network＝ネットワーク／Interface＝接続口／Card＝カード

### USBの規格と電源

#### USB Type-C（ゆーえすびーたいぷしー / USB Type-C）

- 意味：上下の区別がなく、どちら向きにも差せる楕円形の、USBの端子の形の規格
- ポイント：形の規格であって、速さの規格ではない。映像出力や大きな電力の供給にも使える
- 例：R3秋 問10（USB Type-C のプラグ側コネクタの断面図を選ぶ）

#### USB PD（ゆーえすびーぴーでぃー / USB Power Delivery）

- 意味：USBのケーブルで、ノートPCを充電できるほどの大きな電力（最大240W）を送れるようにした給電の規格
- ポイント：つないだ機器どうしで、電圧と電流を相談して決める
- 語の意味：Power＝電力／Delivery＝届けること

#### バスパワー（ばすぱわー / Bus-powered）

- 意味：周辺機器が、USBなどの接続ケーブルを通じて受け取る電気だけで動く方式
- ポイント：ACアダプタが要らないが、使える電力に上限がある

#### セルフパワー（せるふぱわー / Self-powered）

- 意味：周辺機器が、自分のACアダプタや電池から電気をとって動く方式
- ポイント：電力を多く使う機器（大きなハブや外付けディスク）向け

### 近距離の無線

#### Bluetooth（ぶるーとぅーす / Bluetooth）

- 意味：2.4GHz帯の電波を使い、数m〜数十mの距離で機器どうしをつなぐ無線通信の規格
- ポイント：イヤホン・キーボード・マウスに使う。最初に機器どうしを登録する（ペアリング）

#### BLE（びーえるいー / Bluetooth Low Energy）

- 意味：消費電力を極めて小さくした、近距離の無線通信の規格
- ポイント：Bluetooth 4.0 で加わった。ボタン電池で長く動くので、センサやウェアラブル機器、ビーコンに使う
- 語の意味：Low＝低い／Energy＝電力

#### ZigBee（じぐびー / ZigBee）

- 意味：低速だが低消費電力で、多数の機器を網目状（メッシュ）につなげる近距離無線の規格。IEEE 802.15.4 を基にしている
- ポイント：センサネットワークや家電の制御に使う

#### Wi-SUN（わいさん / Wireless Smart Utility Network）

- 意味：920MHz帯の電波を使い、低消費電力で数百m〜1km程度届く無線通信の規格
- ポイント：電力会社のスマートメーターで使われている。電波が回り込みやすく、障害物に強い
- 語の意味：Wireless＝無線の／Smart＝賢い／Utility＝電気・ガス・水道／Network＝ネットワーク

#### IrDA（あいあーるでぃーえー / Infrared Data Association）

- 意味：赤外線を使い、1m以内の近い距離で向かい合わせてデータをやり取りする通信の規格
- ポイント：光なので、間に物があると届かない。昔の携帯電話どうしの連絡先交換に使われた
- 語の意味：Infrared＝赤外線／Data＝データ／Association＝協会

#### NFC（えぬえふしー / Near Field Communication）

- 意味：13.56MHz帯の電波を使い、10cm程度まで近づけてかざすだけで通信する無線の規格
- ポイント：交通系ICカード・電子マネー・スマートフォンの決済に使う。かざさないと通信しないので安全性が高い
- 語の意味：Near＝近い／Field＝場／Communication＝通信

#### 無線LANインタフェースカード（むせんらんいんたふぇーすかーど / Wireless LAN Card）

- 意味：コンピュータを無線LAN（Wi-Fi）につなぐための拡張カードや回路
- ポイント：今はほとんどのノートPCやスマートフォンに内蔵されている

### 接続形態

#### スター接続（すたーせつぞく / Star Topology）

- 意味：中心の集線装置に、各機器を1本ずつのケーブルで放射状につなぐ接続形態
- ポイント：1台の故障がほかに広がりにくいが、中心が壊れると全部止まる

#### カスケード接続（かすけーどせつぞく / Cascade Connection）

- 意味：集線装置（ハブ）どうしを段々につないで、つなげる機器の数を増やす接続形態
- ポイント：USBでは段数に上限がある（ハブは5段まで）
- 語の意味：Cascade＝連なった小さな滝

#### デイジーチェーン接続（でいじーちぇーんせつぞく / Daisy Chain）

- 意味：機器から機器へ、数珠つなぎに順番につないでいく接続形態
- ポイント：SCSIやThunderbolt・DisplayPortで使う。途中の機器が外れると先がつながらない
- 語の意味：Daisy chain＝ヒナギクの花輪

#### ツリー接続（つりーせつぞく / Tree Topology）

- 意味：根元から枝分かれするように、集線装置を介して木の形に機器をつなぐ接続形態
- ポイント：USBはこの形

#### ハブ（はぶ / Hub）

- 意味：複数のケーブルを集めて、1つの差込口を複数に増やす集線装置
- ポイント：USBハブは1つのUSB端子を複数に増やす

#### ターミネータ（たーみねーた / Terminator）

- 意味：数珠つなぎの両端に付けて、信号が端で跳ね返って乱れるのを防ぐ部品。終端抵抗
- ポイント：SCSIやバス型のLANで必要

### データの伝え方

#### シリアル転送（しりあるてんそう / Serial Transmission）

- 意味：1本の信号線で、データを1ビットずつ順番に送る方式
- ポイント：線が少なくてすみ、ずれ（スキュー）の問題がないので、高速化しやすい。今の主流

#### パラレル転送（ぱられるてんそう / Parallel Transmission）

- 意味：複数の信号線で、複数のビットを同時に並べて送る方式
- ポイント：1回にたくさん送れるが、線ごとの到着のずれ（スキュー）で、速くするのが難しい

#### スキュー（すきゅー / Skew）

- 意味：複数の信号線で同時に送ったビットが、届く時間にばらつきが出ること
- ポイント：これがあるので、何本も線を並べる方式は高速化に限界がある

#### UART（ゆーあーと / Universal Asynchronous Receiver/Transmitter）

- 意味：並んだビットのデータを1ビットずつの列に変えて送り、受け取った列を元に戻す回路。送受信のタイミングを合わせるクロックの線を使わない
- ポイント：開始ビットと停止ビットで1文字の区切りを知らせる（調歩同期）。マイコンの通信でよく使う
- 語の意味：Universal＝汎用の／Asynchronous＝非同期の／Receiver＝受信器／Transmitter＝送信器

### 入出力の制御

#### プログラム制御方式（ぷろぐらむせいぎょほうしき / Programmed I/O）

- 意味：プロセッサが入出力命令を実行して、装置と主記憶の間のデータを1つずつ自分で運ぶ方式
- ポイント：転送の間、プロセッサがかかりきりになる

#### DMA方式（でぃーえむえーほうしき / Direct Memory Access）

- 意味：専用の制御回路が、プロセッサを介さずに、主記憶と入出力装置の間（または主記憶どうし）で直接データを転送する方式。直接記憶アクセス
- ポイント：プロセッサは転送の始めに指示を出し、終わりを割込みで知らされるだけ。その間ほかの処理ができる
- 例：R7春 問9（DMAコントローラーの説明→メモリと入出力装置、又はメモリとメモリとの間のデータ転送を、MPUを介さずに行う）
- 語の意味：Direct＝直接の／Memory＝記憶装置／Access＝読み書き

#### チャネル制御方式（ちゃねるせいぎょほうしき / Channel I/O）

- 意味：入出力専用の小さなプロセッサが、専用の手順書（チャネルプログラム）に従って、入出力を丸ごと受け持つ方式
- ポイント：大型の汎用コンピュータで使う。プロセッサの負担はさらに小さい

#### 入出力コントローラ（にゅうしゅつりょくこんとろーら / I/O Controller）

- 意味：入出力装置ごとに付いて、プロセッサからの指示を受けて装置を動かし、データの受け渡しの仲立ちをする回路
- ポイント：装置の動作が終わると、割込みでプロセッサに知らせる

#### メモリマップドI/O（めもりまっぷどあいおー / Memory-mapped I/O）

- 意味：入出力装置の制御用のレジスタを主記憶の番地の一部に割り当て、ふつうの転送命令で装置を操作する方式
- ポイント：専用の入出力命令が要らない。番地の一部が装置に使われる

### デバイスドライバ

#### デバイスドライバ（でばいすどらいば / Device Driver）

- 意味：OSと周辺装置の間に入り、装置ごとの違いを吸収して、OSから同じ手順で装置を使えるようにするソフトウェア
- ポイント：装置の種類・機種ごとに用意する。アプリケーションはOSを通じて装置を使う

#### プラグアンドプレイ（ぷらぐあんどぷれい / Plug and Play）

- 意味：周辺装置をつなぐだけで、OSが装置を見分け、必要なソフトウェアの組込みや設定を自動で行うしくみ
- ポイント：電源を入れたまま抜き差しできるかどうかは別の話
- 語の意味：Plug＝差す／Play＝使う

#### ホットプラグ（ほっとぷらぐ / Hot Plug）

- 意味：コンピュータの電源を入れたまま、周辺装置や部品を抜き差しできる機能。ホットスワップとも呼ぶ
- ポイント：USBやシリアルATAが対応している。サーバでは動かしたまま故障したディスクを交換できる

#### ファームウェア（ふぁーむうぇあ / Firmware）

- 意味：機器の中のROMやフラッシュメモリに書き込まれ、その機器の基本的な動作を制御するソフトウェア
- ポイント：OSの上で動くソフトウェアではなく、機器そのものに組み込まれている。更新で不具合を直せる
- 語の意味：Firm＝固い（ハードとソフトの中間）
## 3-5 入出力装置

### まとめ表

**ディスプレイの方式（R5春 問12・R4秋 問11の論点）**

| 方式 | 光らせ方 | 特徴 |
| :-: | :-: | :-: |
| 液晶 | 裏からの光（バックライト）が通る量を液晶で調節する | 薄い・低消費電力。自分では光らない |
| 有機EL | 電圧をかけると発光する有機物の素子が自分で光る | バックライト不要で薄く、黒がしっかり黒い。曲げられる |
| プラズマ | 放電で出た紫外線で蛍光体を光らせる | 大画面向き。今はほぼ作られていない |
| CRT（ブラウン管） | 電子ビームを蛍光体に当てて光らせる | 奥行きが大きい |
| 電子ペーパー | 色の付いた帯電粒子を電極に集めて表示する（電気泳動型） | 表示を保つのに電力が要らない。光らないので目にやさしい |

**磁気ディスクの平均アクセス時間（R3秋 問11の論点）**

| 時間 | 中身 | 求め方 |
| :-: | :-: | :-: |
| 平均シーク時間 | ヘッドを目的のトラックへ動かす時間 | 問題で与えられる |
| 平均回転待ち時間（サーチタイム） | 目的のデータがヘッドの下に来るまで待つ時間 | 1回転の時間 ÷ 2 |
| データ転送時間 | データを読み取る時間 | データ量 ÷ 転送速度 |
| 平均アクセス時間 | 上の3つの合計 | 6,000回転/分なら1回転10ミリ秒→回転待ち5ミリ秒 |

**画面のデータ量**

| 求めるもの | 式 | 例 |
| :-: | :-: | :-: |
| 1画面のデータ量 | 横の画素数 × 縦の画素数 × 1画素のビット数 ÷ 8 | 1,920×1,080画素・24ビットカラー → 約6.2Mバイト |

### コンピュータの外に付く入力装置

#### キーボード（きーぼーど / Keyboard）

- 意味：キーを押して文字や指示を入力する装置
- ポイント：押したキーの位置を表す信号が送られ、どの文字になるかはOSの設定で決まる

#### Nキーロールオーバー（えぬきーろーるおーばー / N-key Rollover）

- 意味：たくさんのキーを同時に押しても、押した全部のキーを正しく読み取れる性能
- ポイント：安い装置は同時に押せる数に限りがあり、取りこぼす。ゲームや速記で求められる

#### 音声入力装置（おんせいにゅうりょくそうち / Voice Input Device）

- 意味：マイクで拾った人の声などの音を、デジタルのデータに変えて取り込む装置
- ポイント：音声認識と組み合わせると、話した言葉を文字にできる

#### A/Dコンバータ（えーでぃーこんばーた / Analog-to-Digital Converter）

- 意味：電圧などの連続的に変わる信号を、数値（デジタルの値）に変える回路
- ポイント：センサの値をコンピュータに取り込むときに使う。標本化→量子化→符号化の順
- 語の意味：Analog＝連続的な量／Digital＝数値の／Converter＝変換器

#### D/Aコンバータ（でぃーえーこんばーた / Digital-to-Analog Converter）

- 意味：数値（デジタルの値）を、電圧などの連続的に変わる信号に変える回路
- ポイント：音を鳴らしたり、モーターを動かしたりするときに使う
- 語の意味：Digital＝数値の／Analog＝連続的な量／Converter＝変換器

### ポインティングデバイス

#### マウス（まうす / Mouse）

- 意味：机の上で動かした向きと量を読み取り、画面上の矢印（カーソル）を動かす装置
- ポイント：今は底の光で動きを読む光学式が主流

#### タッチパネル（たっちぱねる / Touch Panel）

- 意味：画面を指やペンで直接触れた位置を読み取る装置。表示と一体になったものはタッチスクリーンとも呼ぶ
- ポイント：触れたときの電気の変化を読む静電容量方式（スマートフォン）と、押した圧力で膜が触れ合う抵抗膜方式がある

#### トラックボール（とらっくぼーる / Trackball）

- 意味：装置の上に出ているボールを指で回して、カーソルを動かす装置
- ポイント：装置そのものを動かさないので、狭い場所でも使える

#### ジョイスティック（じょいすてぃっく / Joystick）

- 意味：棒（レバー）を前後左右に傾けて、向きと量を入力する装置
- ポイント：ゲームや、重機・ロボットの操作に使う

#### デジタイザ（でじたいざ / Digitizer）

- 意味：専用の板の上でペンなどで指した位置を、座標の値として読み取る装置
- ポイント：図面を正確になぞって取り込むのに使う。板の上に描くタイプはペンタブレットと呼ぶ

#### ペンタブレット（ぺんたぶれっと / Pen Tablet）

- 意味：板の上を専用のペンでなぞって、手書きの線や筆圧をコンピュータに入力する装置
- ポイント：イラストやデザインに使う。筆圧で線の太さを変えられる

### 読み取る装置

#### イメージスキャナ（いめーじすきゃな / Image Scanner）

- 意味：紙の文書や写真に光を当て、反射した光を読み取って画像のデータとして取り込む装置
- ポイント：読み取りの細かさは dpi（1インチあたりの点の数）で表す

#### OCR（おーしーあーる / Optical Character Reader）

- 意味：紙に書かれた文字を光で読み取り、文字のデータ（文字コード）に変換する装置やソフトウェア
- ポイント：画像として取り込むだけでなく、何の文字かまで判別する
- 語の意味：Optical＝光学的な／Character＝文字／Reader＝読み取り装置

#### OMR（おーえむあーる / Optical Mark Reader）

- 意味：マークシートの塗りつぶされた位置を光で読み取る装置
- ポイント：試験の答案やアンケートの集計に使う。文字ではなく「印の位置」を読む
- 語の意味：Optical＝光学的な／Mark＝印／Reader＝読み取り装置

#### バーコードリーダ（ばーこーどりーだ / Barcode Reader）

- 意味：太さの違う線の並びや、白黒の正方形の模様を光で読み取って、数字や文字に変える装置
- ポイント：商品のJANコードや、2次元の模様のQRコードを読む。POSレジで使う

#### 磁気カードリーダ（じきかーどりーだ / Magnetic Card Reader）

- 意味：カードの帯状の磁気に記録されたデータを読み取る装置
- ポイント：磁気の帯は複製（スキミング）されやすいので、ICチップを使う方式に置き換わりつつある

#### ICカードリーダ（あいしーかーどりーだ / IC Card Reader）

- 意味：カードに埋め込まれた半導体チップと、接点や電波でデータをやり取りする装置
- ポイント：チップの中で暗号の計算ができるので、偽造されにくい。接触型と非接触型（NFC）がある

#### 生体認証装置（せいたいにんしょうそうち / Biometric Device）

- 意味：指紋・顔・静脈・虹彩など、体の特徴を読み取って本人かどうかを確かめる装置
- ポイント：忘れたり盗まれたりしにくいが、他人を受け入れる誤りと本人を拒否する誤りの両方がある

#### デジタルカメラ（でじたるかめら / Digital Camera）

- 意味：レンズで集めた光を撮像素子（CCDやCMOSのイメージセンサ）で電気信号に変え、画像のデータとして記録する装置
- ポイント：画素数が多いほど細かく写せるが、データ量も増える

### ディスプレイの方式

#### 液晶ディスプレイ（えきしょうでぃすぷれい / Liquid Crystal Display）

- 意味：裏から当てた光が通る量を、電圧で向きが変わる液体の結晶で調節して表示する装置。LCDと略す
- ポイント：自分では光らないので、バックライトが要る
- 語の意味：Liquid＝液体の／Crystal＝結晶／Display＝表示装置

#### TFT液晶（てぃーえふてぃーえきしょう / Thin Film Transistor LCD）

- 意味：画素の1つ1つに薄いトランジスタのスイッチを付けて、画素ごとに電圧を直接制御する液晶ディスプレイ。アクティブマトリクス方式
- ポイント：応答が速く、画質が良い。今の液晶はほぼこの方式
- 語の意味：Thin＝薄い／Film＝膜／Transistor＝トランジスタ

#### STN液晶（えすてぃーえぬえきしょう / Super Twisted Nematic LCD）

- 意味：縦横の電極の交点に電圧をかけて画素を選ぶ、構造が簡単で安い液晶ディスプレイ。パッシブマトリクス方式
- ポイント：応答が遅く、にじみやすい。昔の携帯電話や電卓の表示に使われた
- 語の意味：Super＝超／Twisted＝ねじれた／Nematic＝ネマティック（液晶の種類）

#### 有機ELディスプレイ（ゆうきいーえるでぃすぷれい / Organic EL Display）

- 意味：電圧をかけると自分で光る有機化合物の素子を、画素として並べた表示装置。OLEDとも呼ぶ
- ポイント：バックライトが要らないので薄く、曲げられる。黒を完全に消灯で表せる
- 例：R5春 問12（有機ELディスプレイの説明→電圧をかけて発光素子を発光させて表示する）
- 語の意味：Organic＝有機の／Electro-Luminescence＝電気による発光

#### プラズマディスプレイ（ぷらずまでぃすぷれい / Plasma Display）

- 意味：細かな部屋に入れたガスに電圧をかけて放電させ、出た紫外線で蛍光体を光らせて表示する装置
- ポイント：大画面に向いていたが、消費電力が大きく、今はほぼ作られていない

#### 電子ペーパー（でんしぺーぱー / Electronic Paper）

- 意味：紙のように周りの光を反射させて文字や画像を表す表示装置。色の付いた電気を帯びた粒を、電圧で表側に集めて表示する方式（電気泳動型）が代表
- ポイント：表示を保つのに電力が要らず、書き換えるときだけ電気を使う。電子書籍の端末に使う
- 例：R4秋 問11（電気泳動型電子ペーパーの説明→電圧を印加した電極に、着色した帯電粒子を集めて表示する）

### 表示のしかた

#### インタレース（いんたれーす / Interlace）

- 意味：画面の走査線を1本おきに、奇数番目と偶数番目の2回に分けて描く表示方式。飛越し走査
- ポイント：送るデータは半分ですむが、ちらつきやすい。昔のテレビ放送の方式

#### ノンインタレース（のんいんたれーす / Non-interlace）

- 意味：画面の走査線を上から順に1本ずつ全部描く表示方式。順次走査（プログレッシブ）
- ポイント：ちらつきが少ない。パソコンのディスプレイはこの方式

#### テキストモード（てきすともーど / Text Mode）

- 意味：画面を文字の升目に分け、各升目に文字コードを書き込んで、文字だけを表示する表示モード
- ポイント：データが少なくてすむが、図や写真は表示できない

#### グラフィックスモード（ぐらふぃっくすもーど / Graphics Mode）

- 意味：画面の1点1点（画素）の色を指定して、図や写真も表示できる表示モード
- ポイント：画素ごとの色を表示用のメモリ（フレームバッファ）に置く

#### パックトピクセル方式（ぱっくとぴくせるほうしき / Packed Pixel）

- 意味：1つの画素の色を表すビットを、表示用のメモリの連続した場所にまとめて置く方式
- ポイント：1画素の色を1回で読み書きできる。今の主流

#### プレーナピクセル方式（ぷれーなぴくせるほうしき / Planar Pixel）

- 意味：色を表すビットを桁ごとに別々の面（プレーン）に分けて表示用のメモリに置く方式
- ポイント：1画素の色を知るには、全部の面から1ビットずつ集める必要がある
- 語の意味：Planar＝面の

### 画面の解像度

#### VGA（ぶいじーえー / Video Graphics Array）

- 意味：横640×縦480画素の画面の大きさ
- ポイント：アナログ映像の端子の名前（D-sub 15ピン）としても使う
- 語の意味：Video＝映像／Graphics＝図形／Array＝配列

#### SVGA（えすぶいじーえー / Super VGA）

- 意味：横800×縦600画素の画面の大きさ
- 語の意味：Super＝超

#### XGA（えっくすじーえー / eXtended Graphics Array）

- 意味：横1,024×縦768画素の画面の大きさ
- 語の意味：eXtended＝拡張された

#### フルHD（ふるえいちでぃー / Full HD）

- 意味：横1,920×縦1,080画素の画面の大きさ
- ポイント：この縦横2倍（3,840×2,160）が4K
- 語の意味：Full＝完全な／High Definition＝高精細

### 人と機器をつなぐ装置

#### ヘッドマウントディスプレイ（へっどまうんとでぃすぷれい / Head Mounted Display）

- 意味：頭にかぶって目の前に画面を置き、映像を見る表示装置。HMDと略す
- ポイント：頭の動きに合わせて映像を変え、VR（仮想現実）やAR（拡張現実）に使う

#### アイトラッキングデバイス（あいとらっきんぐでばいす / Eye Tracking Device）

- 意味：目の動きを読み取って、どこを見ているかを調べる装置
- ポイント：視線で操作したり、Webページのどこが見られているかを調べたりするのに使う

#### ハプティックデバイス（はぷてぃっくでばいす / Haptic Device）

- 意味：振動や力を返して、触った感じ（触覚）を人に伝える装置
- ポイント：ゲーム機の振動や、遠隔手術の操作装置に使う
- 語の意味：Haptic＝触覚の

#### プロジェクタ（ぷろじぇくた / Projector）

- 意味：映像を光でスクリーンや壁に大きく映し出す表示装置
- ポイント：明るさはルーメンで表す

#### 音声出力装置（おんせいしゅつりょくそうち / Audio Output Device）

- 意味：デジタルの音のデータを、スピーカやイヤホンから音として出す装置
- ポイント：数値を連続した信号に戻す変換の回路を使う

### 印字のしかた

#### インパクトプリンタ（いんぱくとぷりんた / Impact Printer）

- 意味：ピンなどでインクリボンを紙に打ち付けて印字するプリンタ
- ポイント：音が大きいが、複写の伝票（カーボン紙）に同時に印字できる。ドットインパクトプリンタが代表

#### ノンインパクトプリンタ（のんいんぱくとぷりんた / Non-impact Printer）

- 意味：紙をたたかずに、インクを吹き付けたり、トナーを熱で定着させたりして印字するプリンタ
- ポイント：静かで印字がきれい。レーザプリンタやインクジェットプリンタが当たる

#### シリアルプリンタ（しりあるぷりんた / Serial Printer）

- 意味：1文字（1点）ずつ、ヘッドを横に動かしながら印字するプリンタ
- ポイント：速さは cps（1秒あたりの文字数）で表す

#### ラインプリンタ（らいんぷりんた / Line Printer）

- 意味：1行分をまとめて印字するプリンタ
- ポイント：速さは lpm（1分あたりの行数）で表す。大型機の帳票印刷に使われた

#### ページプリンタ（ぺーじぷりんた / Page Printer）

- 意味：1ページ分のデータをまとめて受け取り、ページ単位で印字するプリンタ
- ポイント：速さは ppm（1分あたりの枚数）で表す。レーザプリンタが代表

### プリンタの種類

#### レーザプリンタ（れーざぷりんた / Laser Printer）

- 意味：レーザ光で感光ドラムに像を描き、そこに付いたトナー（粉）を紙に移して熱で定着させるプリンタ
- ポイント：速く、印字がきれい。事務用の主流

#### インクジェットプリンタ（いんくじぇっとぷりんた / Inkjet Printer）

- 意味：細かいノズルから液体のインクの粒を紙に吹き付けて印字するプリンタ
- ポイント：カラー写真の印刷に向く。家庭用の主流

#### 熱転写プリンタ（ねつてんしゃぷりんた / Thermal Transfer Printer）

- 意味：インクを塗ったリボンを熱で溶かして、紙に写して印字するプリンタ
- ポイント：にじみにくく長持ちするので、ラベルやバーコードの印刷に使う

#### 3Dプリンタ（すりーでぃーぷりんた / 3D Printer）

- 意味：立体の設計データをもとに、樹脂などの材料を薄い層にして積み重ね、立体物を作る装置
- ポイント：試作品を短い時間で作れる。積層造形とも呼ぶ

#### プロッタ（ぷろった / Plotter）

- 意味：ペンを動かしたり、インクを吹き付けたりして、大きな紙に図面を描く出力装置
- ポイント：建築や機械の設計図など、大判の線画に使う

### 補助記憶装置

#### ハードディスク装置（はーどでぃすくそうち / Hard Disk Drive）

- 意味：磁性体を塗った円盤を高速で回し、磁気ヘッドでデータを読み書きする記憶装置。HDD
- ポイント：容量あたりが安く大容量。機械の部品が動くので、衝撃に弱く、読み書きに待ち時間がある

#### SSD（えすえすでぃー / Solid State Drive）

- 意味：フラッシュメモリを使い、機械的に動く部品なしでデータを記録する記憶装置
- ポイント：ヘッドの移動や回転待ちがないので速く、衝撃に強い。書換え回数に上限がある
- 語の意味：Solid State＝半導体の（動く部品のない）／Drive＝記憶装置

#### 磁気テープ装置（じきてーぷそうち / Magnetic Tape Unit）

- 意味：磁気テープを巻き取りながら、データを先頭から順に読み書きする装置
- ポイント：大量のデータのバックアップに使う

#### 光ディスク装置（ひかりでぃすくそうち / Optical Disc Drive）

- 意味：レーザ光を当てて、CD・DVD・ブルーレイディスクを読み書きする装置
- ポイント：媒体を取り外して持ち運べる

### 磁気ディスクの構造

#### トラック（とらっく / Track）

- 意味：ディスクの面に同心円状に並んだ、データを記録する1周分の輪
- ポイント：内側も外側もセクタの数が同じ方式と、外側ほど多い方式がある

#### セクタ（せくた / Sector）

- 意味：1周分の輪を、扇形に区切った小さな単位。読み書きの最小単位
- ポイント：1つの大きさは512バイトや4,096バイト

#### シリンダ（しりんだ / Cylinder）

- 意味：複数枚の円盤で、同じ半径の位置にある輪をまとめたもの
- ポイント：ヘッドを動かさずに読み書きできる範囲。データをここにまとめて置くと速い

#### 磁気ヘッド（じきへっど / Magnetic Head）

- 意味：円盤の面のわずか上に浮いて、磁気を読み書きする部品
- ポイント：円盤の面ごとに1つあり、全部が一緒に動く

#### アクセスアーム（あくせすあーむ / Access Arm）

- 意味：読み書きする部品を先に付け、円盤の半径の方向に動かす腕
- ポイント：これを動かす時間がシークタイム

#### スピンドル（すぴんどる / Spindle）

- 意味：円盤を固定して高速で回す軸（とモーター）
- ポイント：回転数は rpm（1分あたりの回転数）で表す。速いほど回転待ちが短い

### アクセス時間

#### シークタイム（しーくたいむ / Seek Time）

- 意味：読み書きする部品を、目的の輪（トラック）の上まで動かすのにかかる時間。位置決め時間
- ポイント：平均の値は問題で与えられることが多い
- 例：R3秋 問11（平均シーク時間10ミリ秒＋平均回転待ち5ミリ秒＋転送0.1ミリ秒＝15.1ミリ秒）
- 語の意味：Seek＝探す

#### サーチタイム（さーちたいむ / Search Time）

- 意味：目的のデータが、回転して読み書きの部品の下に来るまで待つ時間。回転待ち時間
- ポイント：平均は1回転の時間の半分。6,000回転/分なら1回転10ミリ秒で、平均5ミリ秒

#### データ転送時間（でーたてんそうじかん / Data Transfer Time）

- 意味：目的の場所に着いてから、データを読み書きし終えるまでの時間
- ポイント：データ量 ÷ 転送速度。1,000バイトを10Mバイト/秒なら0.1ミリ秒

#### 平均アクセス時間（へいきんあくせすじかん / Average Access Time）

- 意味：読み書きの指示を受けてからデータを読み書きし終えるまでにかかる時間の平均
- ポイント：位置決め・回転待ち・転送の3つの時間の合計

#### デフラグメンテーション（でふらぐめんてーしょん / Defragmentation）

- 意味：ディスクの中でばらばらの場所に分かれて記録されたファイルを、連続した場所に並べ直すこと
- ポイント：ヘッドの移動が減って速くなる。SSDでは効果が小さく、書換え回数を減らすので行わない

### ブロック化

#### ブロック化因数（ぶろっくかいんすう / Blocking Factor）

- 意味：1つのブロック（まとめて読み書きする単位）に入れる論理レコードの数
- ポイント：大きくすると、ブロックの間のすき間が減り、記録できる量が増える

#### IBG（あいびーじー / Inter Block Gap）

- 意味：磁気テープで、ブロックとブロックの間に空けるすき間。ブロック間隔
- ポイント：テープの加速・減速に使う。ブロックを大きくするとこの数が減り、容量が有効に使える
- 語の意味：Inter＝間の／Block＝ブロック／Gap＝すき間

#### 論理レコード（ろんりれこーど / Logical Record）

- 意味：プログラムから見た1件分のデータのまとまり（社員1人分など）
- ポイント：いくつかまとめて1回で読み書きする単位が物理レコード（ブロック）

#### 物理レコード（ぶつりれこーど / Physical Record）

- 意味：装置に対して1回で読み書きするデータのまとまり。ブロックとも呼ぶ
- ポイント：1件分のデータを何件かまとめて作る

### ボリュームとラベル

#### ボリューム（ぼりゅーむ / Volume）

- 意味：磁気テープ1巻やディスク1台のように、記録媒体を1つのまとまりとして扱う単位
- ポイント：取り外せる媒体では、どの媒体かを見分けるための名前を付ける

#### ボリュームラベル（ぼりゅーむらべる / Volume Label）

- 意味：記録媒体の先頭に書く、その媒体の名前や持ち主などを表す情報
- ポイント：違う媒体を付けて上書きする事故を防ぐ

#### 見出しラベル（みだしらべる / Header Label）

- 意味：磁気テープで、ファイルの前に書く、ファイル名や作成日などを表す情報
- ポイント：ファイルの始まりを示す

#### 後書きラベル（あとがきらべる / Trailer Label）

- 意味：磁気テープで、ファイルの後ろに書く、ブロックの数などを表す情報
- ポイント：ファイルの終わりを示す。読み取った件数の確認に使う

### ディスクをまとめて使う

#### ディスクアレイ（でぃすくあれい / Disk Array）

- 意味：複数のディスク装置を組み合わせて、1台の大きな装置として使うしくみ。RAIDで構成する
- ポイント：分散して読み書きして速くしたり、冗長にして故障に強くしたりする

#### RAID5（れいどふぁいぶ / RAID 5）

- 意味：データと、誤りを直すためのパリティを、複数のディスクに分散して書き込む構成
- ポイント：n台のうち1台分がパリティに使われ、実際に使える容量は (n−1)台分。1台が壊れても復元できる
- 例：R4春 問11（8Tバイトの装置6台を、ホットスペア1台込みで構成→残り5台のうち1台分がパリティで、4台分の32Tバイト）
- 語の意味：Redundant＝冗長な／Array of＝〜の配列／Inexpensive Disks＝安価なディスク

#### ホットスペアディスク（ほっとすぺあでぃすく / Hot Spare Disk）

- 意味：ディスクが故障したときにすぐ代わりに使えるよう、電源を入れたまま待機させておく予備のディスク
- ポイント：ふだんはデータを入れないので、容量の計算からは除く

#### MAID（めいど / Massive Array of Idle Disks）

- 意味：大量のディスクのうち、使っていないものの回転を止めておき、使うときだけ動かすしくみ
- ポイント：消費電力を減らせる。めったに読まないデータの保管向け
- 語の意味：Massive＝大量の／Array＝配列／Idle＝休んでいる／Disks＝ディスク

#### 問 ap-3-r03h-q9

- 問：表に示す命令ミックスによるコンピュータの処理性能は何MIPSか。（原文の表を文字で書き直した：整数演算命令 実行速度10ナノ秒・出現頻度50%／移動命令 40ナノ秒・30%／分岐命令 40ナノ秒・20%）
- ア：11
- イ：25
- ウ：40
- エ：90
- 正解：ウ
- 解説：1命令の平均実行時間は、実行速度×出現頻度の合計。10×0.5＋40×0.3＋40×0.2＝5＋12＋8＝25ナノ秒。1秒間に実行できる命令数は 1÷(25×10⁻⁹)＝4×10⁷＝4,000万命令なので、40MIPS。
- アの意味：11。出現頻度で重み付けせずに実行速度を合計した90ナノ秒を1命令の時間とみなし、1÷90ナノ秒≒11MIPSとした値。
- イの意味：25。1命令の平均実行時間（25ナノ秒）をそのまま答えた値。MIPSは時間の逆数で、1秒間に何百万命令かを表す。
- ウの意味：正しい。1÷25ナノ秒＝4,000万命令／秒＝40MIPS。
- エの意味：90。実行速度を合計した値（10＋40＋40）。出現頻度で重み付けしていないうえ、逆数にもしていない。
- 出典：IPA 令和3年度春期 応用情報技術者試験 午前 問9

#### 問 ap-3-r03h-q10

- 問：ディープラーニングの学習にGPUを用いる利点として，適切なものはどれか。
- ア：各プロセッサコアが独立して異なるプログラムを実行し，異なるデータを処理できる。
- イ：汎用の行列演算ユニットを用いて，行列演算を高速に実行できる。
- ウ：浮動小数点演算ユニットをコプロセッサとして用い，浮動小数点演算ができる。
- エ：分岐予測を行い，パイプラインの利用効率を高めた処理を実行できる。
- 正解：イ
- 解説：ディープラーニングの学習は、大量の数値の行列の掛け算・足し算が中心。GPUは単純な演算器を数千個並べて同じ計算を一斉に行うので、行列演算を高速にこなせる。
- アの意味：MIMD（マルチプロセッサやマルチコアのCPU）の特徴。GPUは多くのコアに同じ命令を一斉に実行させるのが得意で、コアごとに別のプログラムを動かすことには向かない。
- イの意味：正しい。行列演算を一斉に処理できることがGPUを使う理由。
- ウの意味：FPU（浮動小数点演算装置）の説明。浮動小数点演算ができるだけなら、今のCPUもできるので、GPUを使う利点にならない。
- エの意味：CPUの高速化技術（分岐予測）の説明。分岐の多い処理を速くする工夫で、GPUの利点ではない。
- 出典：IPA 令和3年度春期 応用情報技術者試験 午前 問10（令和4年度秋期 問8もほぼ同じ問題。イの「汎用の」がない）

#### 問 ap-3-r03a-q8

- 問：演算レジスタが16ビットのCPUで符号付き16ビット整数x1，x2を16ビット符号付き加算（x1＋x2）するときに，全てのx1，x2の組合せにおいて加算結果がオーバーフローしないものはどれか。ここで，|x|はxの絶対値を表し，負数は2の補数で表すものとする。
- ア：|x1|＋|x2|≦32,768 の場合
- イ：|x1|及び|x2|がともに32,767未満の場合
- ウ：x1×x2＞0 の場合
- エ：x1とx2の符号が異なる場合
- 正解：エ
- 解説：16ビットの2の補数で表せる範囲は −32,768〜32,767。符号が異なる2数を足すと、結果は2数の間（大きい方の絶対値より小さい値）に収まるので、範囲を超えることはない。
- アの意味：x1＝x2＝16,384 なら |x1|＋|x2|＝32,768 で条件を満たすが、和の32,768は最大値32,767を超えてオーバーフローする。
- イの意味：x1＝x2＝30,000 なら条件を満たすが、和の60,000は範囲を大きく超える。
- ウの意味：x1×x2＞0 は「同じ符号」という意味。同じ符号どうしの加算こそ、絶対値が大きいとオーバーフローする。
- エの意味：正しい。正と負を足すと、結果の絶対値はどちらの絶対値よりも大きくならない。
- 出典：IPA 令和3年度秋期 応用情報技術者試験 午前 問8

#### 問 ap-3-r04h-q8

- 問：プロセッサの高速化技法の一つとして，同時に実行可能な複数の動作を，コンパイルの段階でまとめて一つの複合命令とし，高速化を図る方式はどれか。
- ア：CISC
- イ：MIMD
- ウ：RISC
- エ：VLIW
- 正解：エ
- 解説：VLIW（Very Long Instruction Word）は、同時に実行できる複数の動作をコンパイラが見つけて1つの長い命令にまとめ、ハードウェアはそれを並列に実行するだけにする方式。並べる判断をコンパイラがするのがポイント。
- アの意味：CISC。複雑で高機能な命令をたくさん用意する設計。1命令で多くの仕事をするが、コンパイル時に並列の動作をまとめる方式ではない。
- イの意味：MIMD。フリンの分類で、複数の命令の流れが別々のデータを処理する方式（マルチプロセッサなど）。1つの複合命令にまとめる話ではない。
- ウの意味：RISC。命令を単純にして長さをそろえる設計。パイプラインに向くが、複数の動作を1命令にまとめるものではない。
- エの意味：正しい。VLIW。
- 出典：IPA 令和4年度春期 応用情報技術者試験 午前 問8（令和7年度秋期 問8と同じ問題）

#### 問 ap-3-r04h-q12

- 問：プロセッサ数と，計算処理におけるプロセスの並列化が可能な部分の割合とが，性能向上へ及ぼす影響に関する記述のうち，アムダールの法則に基づいたものはどれか。
- ア：全ての計算処理が並列化できる場合，速度向上比は，プロセッサ数を増やしてもある水準に漸近的に近づく。
- イ：並列化できない計算処理がある場合，速度向上比は，プロセッサ数に比例して増加する。
- ウ：並列化できない計算処理がある場合，速度向上比は，プロセッサ数を増やしてもある水準に漸近的に近づく。
- エ：並列化できる計算処理の割合が増えると，速度向上比は，プロセッサ数に反比例して減少する。
- 正解：ウ
- 解説：並列化できる割合を r、プロセッサ数を n とすると、速度向上比は 1÷{(1−r)＋r/n}。n をいくら大きくしても r/n が0に近づくだけで、並列化できない部分 (1−r) が残るので、1÷(1−r) に近づいて頭打ちになる。
- アの意味：全部が並列化できる（r＝1）なら、速度向上比は n そのもので、プロセッサ数に比例して増え続ける。頭打ちにならない。
- イの意味：比例して増えるのは全部が並列化できる場合だけ。並列化できない部分があると、増え方はだんだん鈍る。
- ウの意味：正しい。並列化できない部分が上限を決める。
- エの意味：並列化できる割合が増えると、速度向上比は大きくなる。反比例して減ることはない。
- 出典：IPA 令和4年度春期 応用情報技術者試験 午前 問12

#### 問 ap-3-r05h-q8

- 問：動作周波数1.25GHzのシングルコアCPUが1秒間に10億回の命令を実行するとき，このCPUの平均CPI（Cycles Per Instruction）として，適切なものはどれか。
- ア：0.8
- イ：1.25
- ウ：2.5
- エ：10
- 正解：イ
- 解説：1秒間のクロック数は1.25GHz＝12.5億回。その間に10億命令を実行するので、1命令あたりのクロック数（CPI）は 12.5億÷10億＝1.25。
- アの意味：0.8。10億÷12.5億で、逆数（1クロックあたりの命令数、IPC）を求めてしまった値。
- イの意味：正しい。クロック数÷命令数。
- ウの意味：2.5。1.25を2倍した値で、計算の根拠がない。CPIはクロック数÷命令数で求める。
- エの意味：10。10億の「10」をそのまま答えた値。
