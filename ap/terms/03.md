## 3-1 プロセッサ

### まとめ表

**性能の計算**

| 指標 | 式 |
| :-: | :-: |
| CPI | 1命令あたりのクロック数 |
| 実行時間 | 命令数 × CPI ÷ クロック周波数 |
| MIPS | 1秒間に実行できる命令数（百万単位）＝ クロック周波数 ÷ CPI ÷ 10^6 |


### CPUのしくみ

#### CPU（しーぴーゆー / Central Processing Unit）

- 意味：命令を読み取って解読し、計算や制御を行う装置
- ポイント：制御装置と演算装置からなる
- 語の意味：Central＝中央の／Processing＝処理／Unit＝装置

#### レジスタ（Register）

- 意味：CPUの中にある、とても速い小さな記憶場所
- ポイント：プログラムカウンタ・命令レジスタ・汎用レジスタなど

#### アドレス指定方式（Addressing Mode）

- 意味：命令の中のアドレス部から、データの場所を決める方法
- ポイント：即値・直接・間接・指標（インデックス）・基底・相対など

#### パイプライン（Pipeline）

- 意味：命令の実行をいくつかの段階に分け、少しずつずらして同時に進める方式
- ポイント：分岐やデータの依存で流れが止まること（ハザード）がある

#### スーパスカラ（Superscalar）

- 意味：パイプラインを複数持ち、同時に複数の命令を実行する方式

#### 分岐予測（Branch Prediction）

- 意味：分岐先を予測して先に命令を進め、パイプラインの乱れを減らす方法
- ポイント：外れたら投機実行した結果を捨てる

#### CISC・RISC（Complex / Reduced Instruction Set Computer）

- 意味：CISCは複雑で多機能な命令を持つCPU、RISCは単純で長さのそろった命令を持つCPU
- ポイント：RISCはパイプラインに向き、ワイヤードロジックで制御する
- 語の意味：Complex＝複雑な／Reduced＝減らした／Instruction Set＝命令の集まり

#### マルチコアプロセッサ（Multi-core Processor）

- 意味：1つのチップに複数のコア（処理の中心）を載せたCPU

#### GPU（じーぴーゆー / Graphics Processing Unit）

- 意味：画像処理向けのプロセッサ。大量の単純な計算を並列に行える
- ポイント：AIの学習にも使う
- 語の意味：Graphics＝画像／Processing＝処理／Unit＝装置

#### CPI（しーぴーあい / Cycles Per Instruction）

- 意味：1命令の実行に必要なクロック数の平均
- 語の意味：Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令

#### MIPS（みっぷす / Million Instructions Per Second）

- 意味：1秒間に何百万の命令を実行できるかを表す性能の指標
- 語の意味：Million＝百万／Instructions＝命令／Per Second＝毎秒

#### フリンの分類（Flynn's Taxonomy）

- 意味：命令とデータの流れの数で並列処理を分ける分類
- ポイント：SISD・SIMD・MISD・MIMD。SIMDは1つの命令で複数のデータを処理する


## 3-2 メモリ

### まとめ表

**キャッシュの書込み方式**

| 方式 | 書き込み先 | 特徴 |
| :-: | :-: | :-: |
| ライトスルー | キャッシュと主記憶に同時に書く | 一貫性を保ちやすいが遅い |
| ライトバック | キャッシュだけに書き、追い出すときに主記憶へ | 速いが制御が複雑 |


### 記憶装置

#### DRAM・SRAM（Dynamic / Static RAM）

- 意味：DRAMはコンデンサに電荷をためて記憶し、リフレッシュが必要。安く大容量で主記憶に使う。SRAMはフリップフロップで記憶し、速いが高価でキャッシュに使う
- 語の意味：Dynamic＝動的／Static＝静的／RAM＝読み書きできる記憶装置

#### フラッシュメモリ（Flash Memory）

- 意味：電源を切っても内容が消えず、電気的に書き換えられるメモリ
- ポイント：SSDやUSBメモリに使う。書換えの回数に上限がある

#### キャッシュメモリ（Cache Memory）

- 意味：CPUと主記憶の速さの差を埋める、小さく速いメモリ
- ポイント：1次・2次・3次と階層になっている

#### 実効アクセス時間（Effective Access Time）

- 意味：キャッシュを使うときの平均のアクセス時間
- ポイント：ヒット率×キャッシュの時間 ＋（1−ヒット率）×主記憶の時間

#### 参照の局所性（Locality of Reference）

- 意味：最近使ったデータや、その近くのデータは、また使われやすいという性質
- ポイント：キャッシュが効く理由

#### メモリインタリーブ（Memory Interleave）

- 意味：主記憶を複数のバンクに分け、同時にアクセスして速くする方式

#### ECC（いーしーしー / Error Correcting Code）

- 意味：記憶したデータの誤りを見つけて直す符号
- 語の意味：Error＝誤り／Correcting＝訂正する／Code＝符号


## 3-3 バス


### データの通り道

#### バス（Bus）

- 意味：装置どうしをつなぎ、データをやり取りする共通の通り道
- ポイント：アドレスバス・データバス・制御バスがある

#### バス幅（Bus Width）

- 意味：一度に送れるビット数
- ポイント：転送速度 ＝ バス幅 × クロック周波数

#### PCI Express（Peripheral Component Interconnect Express）

- 意味：拡張カードをつなぐシリアル転送のバスの規格
- ポイント：レーン数を増やすと速くなる
- 語の意味：Peripheral＝周辺の／Component＝部品／Interconnect＝相互接続


## 3-4 入出力デバイス


### つなぐ規格

#### USB（ゆーえすびー / Universal Serial Bus）

- 意味：パソコンと周辺機器をつなぐシリアルの規格
- ポイント：バスパワーで電源も送れる。ホットプラグに対応
- 語の意味：Universal＝汎用の／Serial＝直列の／Bus＝伝送路

#### DMA（でぃーえむえー / Direct Memory Access）

- 意味：CPUを通さずに、入出力装置と主記憶の間で直接データを転送する方式
- ポイント：CPUの負担が減る
- 語の意味：Direct＝直接の／Memory＝記憶装置／Access＝読み書き

#### 割込み（Interrupt）

- 意味：実行中の処理を中断して、別の処理を先に行うしくみ
- ポイント：内部割込み（0での割り算・ページフォールトなど）と外部割込み（入出力の完了・タイマなど）

#### デバイスドライバ（Device Driver）

- 意味：OSが周辺機器を動かすためのソフトウェア

#### Bluetooth（ブルートゥース）

- 意味：近くの機器を無線でつなぐ規格
- ポイント：BLEは消費電力が少なくIoTに向く


## 3-5 入出力装置


### 装置

#### SSD（えすえすでぃー / Solid State Drive）

- 意味：フラッシュメモリを使った補助記憶装置
- ポイント：HDDより速く衝撃に強い。ウェアレベリングで書込みを分散する
- 語の意味：Solid State＝半導体の／Drive＝装置

#### HDDのアクセス時間（Access Time）

- 意味：平均シーク時間 ＋ 平均回転待ち時間 ＋ データ転送時間
- ポイント：平均回転待ち時間は1回転の時間の半分

#### 有機EL（Organic Electro-Luminescence）

- 意味：電気を流すと自ら光る材料を使ったディスプレイ
- ポイント：バックライトがいらず、薄く曲げられる


## 問題演習

- 書式：「#### 問 問題ID」の下に、問・ア〜エ・正解・解説を書く。「###」は小分類（クイズの範囲に使う）

### 3-1 プロセッサ

#### 問 ap-3-q01

- 問：クロック周波数2GHz、CPIが4のCPUの性能は何MIPSか。
- ア：50
- イ：200
- ウ：500
- エ：8,000
- 正解：ウ
- 解説：2×10^9 ÷ 4 ÷ 10^6 ＝ 500MIPS。

#### 問 ap-3-q02

- 問：1つの命令で複数のデータに同じ演算を行う並列処理方式はどれか。
- ア：SISD
- イ：SIMD
- ウ：MISD
- エ：MIMD
- 正解：イ
- 解説：SIMDは Single Instruction Multiple Data。画像処理などに向く。

#### 問 ap-3-q03

- 問：RISCの特徴として適切なものはどれか。
- ア：命令の長さがばらばらで複雑
- イ：マイクロプログラムで制御する
- ウ：命令が単純で長さがそろい、パイプラインに向く
- エ：命令の数がとても多い
- 正解：ウ
- 解説：RISCは単純な命令をワイヤードロジックで速く実行する。

#### 問 ap-3-q04

- 問：パイプラインで、分岐命令などにより後続の命令を先に進められなくなる現象はどれか。
- ア：スラッシング
- イ：ハザード
- ウ：デッドロック
- エ：フラグメンテーション
- 正解：イ
- 解説：パイプラインの流れが乱れることをハザードという。

### 3-2 メモリ

#### 問 ap-3-q05

- 問：キャッシュのアクセス時間10ns、主記憶のアクセス時間60ns、ヒット率90％のときの実効アクセス時間は何nsか。
- ア：15
- イ：19
- ウ：50
- エ：55
- 正解：ア
- 解説：0.9×10＋0.1×60＝9＋6＝15ns。

#### 問 ap-3-q06

- 問：キャッシュへの書込みと同時に主記憶にも書き込む方式はどれか。
- ア：ライトバック
- イ：ライトスルー
- ウ：ライトアロケート
- エ：インタリーブ
- 正解：イ
- 解説：両方に同時に書くのはライトスルー。

#### 問 ap-3-q07

- 問：リフレッシュ動作が必要で、主記憶に使われるメモリはどれか。
- ア：SRAM
- イ：DRAM
- ウ：フラッシュメモリ
- エ：マスクROM
- 正解：イ
- 解説：DRAMはコンデンサの電荷が抜けるのでリフレッシュが必要。

### 3-4 入出力デバイス

#### 問 ap-3-q08

- 問：CPUを介さずに入出力装置と主記憶の間でデータを転送する方式はどれか。
- ア：DMA
- イ：割込み
- ウ：ポーリング
- エ：パイプライン
- 正解：ア
- 解説：DMAはCPUの負担を減らす転送方式。

#### 問 ap-3-q09

- 問：内部割込みに該当するものはどれか。
- ア：入出力の完了
- イ：タイマの時間切れ
- ウ：0での割り算
- エ：電源の異常
- 正解：ウ
- 解説：実行中のプログラムが原因で起きるのが内部割込み。ほかは外部割込み。

### 3-5 入出力装置

#### 問 ap-3-q10

- 問：平均シーク時間10ms、回転数6,000回転/分の磁気ディスクで、平均回転待ち時間は何msか。
- ア：5
- イ：10
- ウ：15
- エ：20
- 正解：ア
- 解説：1回転は60÷6000＝10ms。平均回転待ちはその半分の5ms。
