## 3-1 プロセッサ

### まとめ表

**性能の計算**

| 指標 | 式 |
| :-: | :-: |
| CPI | 1命令あたりのクロック数 |
| 実行時間 | 命令数 × CPI ÷ クロック周波数 |
| MIPS | 1秒間に実行できる命令数（百万単位）＝ クロック周波数 ÷ CPI ÷ 10^6 |


### CPUのしくみ

#### CPU（しーぴーゆー / Central Processing Unit）

- 意味：命令を読み取って解読し、計算や制御を行う装置
- ポイント：制御装置と演算装置からなる
- 語の意味：Central＝中央の／Processing＝処理／Unit＝装置

#### レジスタ（Register）

- 意味：CPUの中にある、とても速い小さな記憶場所
- ポイント：プログラムカウンタ・命令レジスタ・汎用レジスタなど

#### アドレス指定方式（Addressing Mode）

- 意味：命令の中のアドレス部から、データの場所を決める方法
- ポイント：即値・直接・間接・指標（インデックス）・基底・相対など

#### パイプライン（Pipeline）

- 意味：命令の実行をいくつかの段階に分け、少しずつずらして同時に進める方式
- ポイント：分岐やデータの依存で流れが止まること（ハザード）がある

#### スーパスカラ（Superscalar）

- 意味：パイプラインを複数持ち、同時に複数の命令を実行する方式

#### 分岐予測（Branch Prediction）

- 意味：分岐先を予測して先に命令を進め、パイプラインの乱れを減らす方法
- ポイント：外れたら投機実行した結果を捨てる

#### CISC・RISC（Complex / Reduced Instruction Set Computer）

- 意味：CISCは複雑で多機能な命令を持つCPU、RISCは単純で長さのそろった命令を持つCPU
- ポイント：RISCはパイプラインに向き、ワイヤードロジックで制御する
- 語の意味：Complex＝複雑な／Reduced＝減らした／Instruction Set＝命令の集まり

#### マルチコアプロセッサ（Multi-core Processor）

- 意味：1つのチップに複数のコア（処理の中心）を載せたCPU

#### GPU（じーぴーゆー / Graphics Processing Unit）

- 意味：画像処理向けのプロセッサ。大量の単純な計算を並列に行える
- ポイント：AIの学習にも使う
- 語の意味：Graphics＝画像／Processing＝処理／Unit＝装置

#### CPI（しーぴーあい / Cycles Per Instruction）

- 意味：1命令の実行に必要なクロック数の平均
- 語の意味：Cycles＝クロックの回数／Per＝〜あたり／Instruction＝命令

#### MIPS（みっぷす / Million Instructions Per Second）

- 意味：1秒間に何百万の命令を実行できるかを表す性能の指標
- 語の意味：Million＝百万／Instructions＝命令／Per Second＝毎秒

#### フリンの分類（Flynn's Taxonomy）

- 意味：命令とデータの流れの数で並列処理を分ける分類
- ポイント：SISD・SIMD・MISD・MIMD。SIMDは1つの命令で複数のデータを処理する


### CPU（発展）

#### 制御装置・演算装置（Control Unit / Arithmetic Logic Unit）

- 意味：命令を解読して各装置に指示するのが制御装置、計算を行うのが演算装置（ALU）

#### プログラムカウンタ（Program Counter）

- 意味：次に実行する命令のアドレスを持つレジスタ

#### 命令レジスタ（Instruction Register）

- 意味：読み出した命令を一時的に持つレジスタ

#### アキュムレータ（Accumulator）

- 意味：演算の結果を一時的にためるレジスタ

#### フラグレジスタ（Flag Register）

- 意味：演算結果がゼロか、負か、桁あふれしたかなどの状態を示すレジスタ

#### 命令実行サイクル（Instruction Cycle）

- 意味：命令の取出し→解読→オペランドの読出し→実行→結果の書込み

#### 即値アドレス指定（Immediate Addressing）

- 意味：命令の中にデータそのものを書く方式

#### 直接・間接アドレス指定（Direct / Indirect Addressing）

- 意味：直接はアドレス部がデータの場所、間接はアドレス部が「データの場所の場所」

#### 指標アドレス指定（Indexed Addressing）

- 意味：アドレス部に指標レジスタの値を足して場所を求める方式
- ポイント：配列に便利

#### 相対アドレス指定（Relative Addressing）

- 意味：プログラムカウンタの値にアドレス部を足して場所を求める方式

#### クロック周波数（Clock Frequency）

- 意味：CPUが1秒間に刻むクロックの数
- ポイント：1GHzなら1クロック1ナノ秒

#### スーパパイプライン（Superpipeline）

- 意味：パイプラインの段数を増やして1段を短くし、速くする方式

#### VLIW（ぶいえるあいだぶりゅー / Very Long Instruction Word）

- 意味：同時に実行できる複数の命令を1つの長い命令にまとめる方式
- 語の意味：Very Long＝とても長い／Instruction Word＝命令語

#### 投機実行（Speculative Execution）

- 意味：分岐の結果がわかる前に、予測した側の命令を先に実行すること

#### マイクロプログラム制御・ワイヤードロジック制御（Microprogram / Wired Logic）

- 意味：命令を小さなプログラムで実行する方式（CISC）と、回路で直接実行する方式（RISC）

#### マルチプロセッサ（Multiprocessor）

- 意味：複数のプロセッサで処理を分担する方式
- ポイント：密結合（主記憶を共有）と疎結合（それぞれ主記憶を持つ）

#### アムダールの法則（Amdahl's Law）

- 意味：並列化できない部分があると、プロセッサを増やしても速くなる限界があるという法則

#### ハイパースレッディング（Hyper-Threading / SMT）

- 意味：1つのコアを論理的に2つに見せ、同時に2つのスレッドを処理する技術

#### NPU（えぬぴーゆー / Neural Processing Unit）

- 意味：AIの計算を速く行うための専用プロセッサ
- 語の意味：Neural＝神経網の／Processing＝処理／Unit＝装置

#### 割込みの優先順位（Interrupt Priority）

- 意味：複数の割込みが起きたとき、どれを先に処理するかの順番


### 性能と省電力

#### 命令ミックス（Instruction Mix）

- 意味：命令の種類ごとの実行時間と出現する割合から、平均の命令実行時間を求める方法

#### 平均命令実行時間（Average Instruction Time）

- 意味：Σ（命令の実行時間×出現率）
- ポイント：MIPS ＝ 1 ÷ 平均命令実行時間（マイクロ秒）

#### 演算性能 FLOPS（FLoating-point Operations Per Second）

- 意味：1秒間に行える浮動小数点の演算の回数
- ポイント：スーパーコンピュータの性能に使う

#### ベクトルプロセッサ（Vector Processor）

- 意味：配列のような多くのデータに、同じ演算をまとめて行うプロセッサ

#### 動的電圧周波数制御（DVFS）

- 意味：負荷に合わせて電圧と周波数を下げ、電力を節約する方式

#### コアの数と並列処理（Cores and Parallelism）

- 意味：コアを増やすと同時に処理できるが、並列化できない部分があると効果は限られる


## 3-2 メモリ

### まとめ表

**キャッシュの書込み方式**

| 方式 | 書き込み先 | 特徴 |
| :-: | :-: | :-: |
| ライトスルー | キャッシュと主記憶に同時に書く | 一貫性を保ちやすいが遅い |
| ライトバック | キャッシュだけに書き、追い出すときに主記憶へ | 速いが制御が複雑 |


### 記憶装置

#### DRAM・SRAM（Dynamic / Static RAM）

- 意味：DRAMはコンデンサに電荷をためて記憶し、リフレッシュが必要。安く大容量で主記憶に使う。SRAMはフリップフロップで記憶し、速いが高価でキャッシュに使う
- 語の意味：Dynamic＝動的／Static＝静的／RAM＝読み書きできる記憶装置

#### フラッシュメモリ（Flash Memory）

- 意味：電源を切っても内容が消えず、電気的に書き換えられるメモリ
- ポイント：SSDやUSBメモリに使う。書換えの回数に上限がある

#### キャッシュメモリ（Cache Memory）

- 意味：CPUと主記憶の速さの差を埋める、小さく速いメモリ
- ポイント：1次・2次・3次と階層になっている

#### 実効アクセス時間（Effective Access Time）

- 意味：キャッシュを使うときの平均のアクセス時間
- ポイント：ヒット率×キャッシュの時間 ＋（1−ヒット率）×主記憶の時間

#### 参照の局所性（Locality of Reference）

- 意味：最近使ったデータや、その近くのデータは、また使われやすいという性質
- ポイント：キャッシュが効く理由

#### メモリインタリーブ（Memory Interleave）

- 意味：主記憶を複数のバンクに分け、同時にアクセスして速くする方式

#### ECC（いーしーしー / Error Correcting Code）

- 意味：記憶したデータの誤りを見つけて直す符号
- 語の意味：Error＝誤り／Correcting＝訂正する／Code＝符号


### 記憶装置（発展）

#### 記憶階層（Memory Hierarchy）

- 意味：レジスタ→キャッシュ→主記憶→補助記憶の順に、速いが小さいものから遅いが大きいものへ並ぶ構造

#### ROM（ろむ / Read Only Memory）

- 意味：読出し専用で、電源を切っても内容が消えないメモリ
- ポイント：マスクROM・EEPROM・フラッシュメモリなど
- 語の意味：Read Only＝読むだけの／Memory＝記憶装置

#### EEPROM（Electrically Erasable Programmable ROM）

- 意味：電気的に内容を消して書き換えられるROM

#### 揮発性・不揮発性（Volatile / Non-volatile）

- 意味：電源を切ると内容が消えるのが揮発性（RAM）、消えないのが不揮発性（ROM・フラッシュ）

#### キャッシュのヒット率（Hit Rate）

- 意味：欲しいデータがキャッシュにあった割合

#### ダイレクトマッピング（Direct Mapping）

- 意味：主記憶のブロックを、キャッシュの決まった1か所に置く方式

#### セットアソシアティブ（Set Associative）

- 意味：キャッシュをいくつかの組に分け、組の中なら自由に置ける方式

#### フルアソシアティブ（Fully Associative）

- 意味：キャッシュのどこにでも置ける方式

#### 主記憶の容量（Main Memory Capacity）

- 意味：容量が足りないと仮想記憶のページングが増えて遅くなる

#### DDR SDRAM（Double Data Rate SDRAM）

- 意味：クロックの立上りと立下りの両方でデータを送り、速くしたDRAM

#### 3次元積層メモリ（3D Stacked Memory）

- 意味：メモリを縦に重ねて容量と速さを上げたもの
- ポイント：HBMなど

#### 不揮発性メモリの新技術（MRAM / ReRAM）

- 意味：磁気や抵抗の変化で記憶する、速くて消えないメモリ


### メモリの使い方

#### メモリの誤り訂正（ECCメモリ）

- 意味：誤りを検出・訂正できる符号を付けたメモリ
- ポイント：サーバで使う

#### キャッシュの一貫性（Cache Coherence）

- 意味：マルチプロセッサで、各プロセッサのキャッシュの内容を食い違わないように保つこと

#### 主記憶のアクセス時間（Memory Access Time）

- 意味：読出しの要求から、データが得られるまでの時間

#### メモリの帯域幅（Memory Bandwidth）

- 意味：1秒あたりに主記憶とやり取りできるデータ量


## 3-3 バス


### データの通り道

#### バス（Bus）

- 意味：装置どうしをつなぎ、データをやり取りする共通の通り道
- ポイント：アドレスバス・データバス・制御バスがある

#### バス幅（Bus Width）

- 意味：一度に送れるビット数
- ポイント：転送速度 ＝ バス幅 × クロック周波数

#### PCI Express（Peripheral Component Interconnect Express）

- 意味：拡張カードをつなぐシリアル転送のバスの規格
- ポイント：レーン数を増やすと速くなる
- 語の意味：Peripheral＝周辺の／Component＝部品／Interconnect＝相互接続


### バス（発展）

#### アドレスバス・データバス・制御バス（Address / Data / Control Bus）

- 意味：場所を伝える線、データを運ぶ線、読み書きの合図を伝える線

#### システムバス（System Bus）

- 意味：CPUと主記憶をつなぐバス

#### 入出力バス（I/O Bus）

- 意味：CPUと入出力装置をつなぐバス

#### シリアル転送・パラレル転送（Serial / Parallel Transfer）

- 意味：1本の線で1ビットずつ送る方式と、複数の線で同時に送る方式
- ポイント：今は高速なシリアル転送が主流

#### バスの転送速度（Bus Transfer Rate）

- 意味：バス幅（バイト）×クロック周波数
- 例：64ビット・100MHzなら800Mバイト/秒


## 3-4 入出力デバイス


### つなぐ規格

#### USB（ゆーえすびー / Universal Serial Bus）

- 意味：パソコンと周辺機器をつなぐシリアルの規格
- ポイント：バスパワーで電源も送れる。ホットプラグに対応
- 語の意味：Universal＝汎用の／Serial＝直列の／Bus＝伝送路

#### DMA（でぃーえむえー / Direct Memory Access）

- 意味：CPUを通さずに、入出力装置と主記憶の間で直接データを転送する方式
- ポイント：CPUの負担が減る
- 語の意味：Direct＝直接の／Memory＝記憶装置／Access＝読み書き

#### 割込み（Interrupt）

- 意味：実行中の処理を中断して、別の処理を先に行うしくみ
- ポイント：内部割込み（0での割り算・ページフォールトなど）と外部割込み（入出力の完了・タイマなど）

#### デバイスドライバ（Device Driver）

- 意味：OSが周辺機器を動かすためのソフトウェア

#### Bluetooth（ブルートゥース）

- 意味：近くの機器を無線でつなぐ規格
- ポイント：BLEは消費電力が少なくIoTに向く


### つなぐ規格（発展）

#### HDMI（えいちでぃーえむあい / High-Definition Multimedia Interface）

- 意味：映像と音声を1本のケーブルで送るディジタルの規格
- 語の意味：High-Definition＝高精細の／Multimedia＝マルチメディア／Interface＝接続規格

#### DisplayPort（ディスプレイポート）

- 意味：パソコンとディスプレイをつなぐディジタルの映像規格

#### Thunderbolt（サンダーボルト）

- 意味：データ・映像・電源をまとめて送れる高速なインタフェース
- ポイント：USB Type-Cの形

#### SATA（さた / Serial ATA）

- 意味：HDDやSSDをつなぐシリアルの規格

#### NVMe（えぬぶいえむいー / Non-Volatile Memory Express）

- 意味：SSDをPCI Express経由で速く使うための規格
- 語の意味：Non-Volatile＝不揮発性の／Memory＝記憶装置／Express＝高速な

#### NFC（えぬえふしー / Near Field Communication）

- 意味：10cmほどの近い距離で通信する無線の規格
- ポイント：交通系ICカードや決済に使う
- 語の意味：Near Field＝近い範囲の／Communication＝通信

#### IrDA（あいあーるだ / Infrared Data Association）

- 意味：赤外線でデータを送る規格

#### ポーリング（Polling）

- 意味：CPUが入出力装置の状態を定期的に問い合わせる方式
- ポイント：割込みよりCPUの負担が大きい

#### チャネル制御（Channel Control）

- 意味：入出力専用の装置（チャネル）が、CPUの代わりに入出力を制御する方式

#### ホットプラグ（Hot Plug）

- 意味：電源を入れたまま機器を抜き差しできる機能

#### プラグアンドプレイ（Plug and Play）

- 意味：つなぐだけでOSが自動で認識して設定する機能


## 3-5 入出力装置


### 装置

#### SSD（えすえすでぃー / Solid State Drive）

- 意味：フラッシュメモリを使った補助記憶装置
- ポイント：HDDより速く衝撃に強い。ウェアレベリングで書込みを分散する
- 語の意味：Solid State＝半導体の／Drive＝装置

#### HDDのアクセス時間（Access Time）

- 意味：平均シーク時間 ＋ 平均回転待ち時間 ＋ データ転送時間
- ポイント：平均回転待ち時間は1回転の時間の半分

#### 有機EL（Organic Electro-Luminescence）

- 意味：電気を流すと自ら光る材料を使ったディスプレイ
- ポイント：バックライトがいらず、薄く曲げられる


### 装置（発展）

#### 磁気ディスク（HDD / Hard Disk Drive）

- 意味：回転する円盤に磁気で記録する補助記憶装置
- ポイント：シリンダ・トラック・セクタで場所を表す

#### 光ディスク（Optical Disc）

- 意味：レーザ光で読み書きするディスク
- ポイント：CD・DVD・Blu-ray

#### 磁気テープ（Magnetic Tape）

- 意味：大容量で安く、バックアップの保管に使う記憶媒体
- ポイント：順番にしか読めない

#### ウェアレベリング（Wear Leveling）

- 意味：フラッシュメモリの書込み回数を、全体に平均して散らす技術
- ポイント：寿命を延ばす

#### タッチパネル（Touch Panel）

- 意味：画面に触れて入力する装置
- ポイント：静電容量方式・抵抗膜方式

#### イメージスキャナ（Image Scanner）

- 意味：紙の画像や文字を読み取ってディジタルにする装置

#### OCR（おーしーあーる / Optical Character Recognition）

- 意味：画像の中の文字を読み取ってテキストにする技術
- 語の意味：Optical＝光学的な／Character＝文字／Recognition＝認識

#### 液晶ディスプレイ（LCD / Liquid Crystal Display）

- 意味：液晶で光を通したり止めたりして表示する画面
- ポイント：バックライトが必要

#### 3Dプリンタ（3D Printer）

- 意味：データをもとに材料を積み重ねて立体を作る装置

#### インクジェット・レーザプリンタ（Inkjet / Laser Printer）

- 意味：インクを吹き付ける方式と、レーザとトナーで印刷する方式

#### 解像度・dpi（Resolution / dots per inch）

- 意味：1インチあたりの点の数
- ポイント：多いほど細かい

#### 画面の解像度と色数（Display Resolution）

- 意味：画面の画素の数と、1画素で表せる色の数
- ポイント：VRAMの容量 ＝ 画素数×1画素のビット数


### 補助記憶の計算

#### シリンダ・トラック・セクタ（Cylinder / Track / Sector）

- 意味：磁気ディスクの記録位置の単位
- ポイント：セクタが読み書きの最小単位

#### 記憶容量の計算（Disk Capacity）

- 意味：1トラックのバイト数 × トラック数 × 面の数などで求める

#### ブロック化（Blocking）

- 意味：複数のレコードをまとめて1つのブロックとして読み書きすること
- ポイント：ブロック化因数は1ブロックのレコード数


## 問題演習

- 書式：「#### 問 問題ID」の下に、問・ア〜エ・正解・解説を書く。「###」は小分類（クイズの範囲に使う）

### 3-1 プロセッサ

#### 問 ap-3-q01

- 問：クロック周波数2GHz、CPIが4のCPUの性能は何MIPSか。
- ア：50
- イ：200
- ウ：500
- エ：8,000
- 正解：ウ
- 解説：2×10^9 ÷ 4 ÷ 10^6 ＝ 500MIPS。

#### 問 ap-3-q02

- 問：1つの命令で複数のデータに同じ演算を行う並列処理方式はどれか。
- ア：SISD
- イ：SIMD
- ウ：MISD
- エ：MIMD
- 正解：イ
- 解説：SIMDは Single Instruction Multiple Data。画像処理などに向く。

#### 問 ap-3-q03

- 問：RISCの特徴として適切なものはどれか。
- ア：命令の長さがばらばらで複雑
- イ：マイクロプログラムで制御する
- ウ：命令が単純で長さがそろい、パイプラインに向く
- エ：命令の数がとても多い
- 正解：ウ
- 解説：RISCは単純な命令をワイヤードロジックで速く実行する。

#### 問 ap-3-q04

- 問：パイプラインで、分岐命令などにより後続の命令を先に進められなくなる現象はどれか。
- ア：スラッシング
- イ：ハザード
- ウ：デッドロック
- エ：フラグメンテーション
- 正解：イ
- 解説：パイプラインの流れが乱れることをハザードという。

#### 問 ap-3-q11

- 問：命令中のアドレス部の値にプログラムカウンタの値を加えて有効アドレスを求める方式はどれか。
- ア：直接アドレス指定
- イ：間接アドレス指定
- ウ：相対アドレス指定
- エ：即値アドレス指定
- 正解：ウ
- 解説：相対アドレス指定。

#### 問 ap-3-q12

- 問：処理の80％を並列化できるプログラムを、プロセッサ4台で実行したときの速度向上比に最も近いものはどれか。
- ア：1.6倍
- イ：2.5倍
- ウ：3.2倍
- エ：4倍
- 正解：イ
- 解説：アムダールの法則で 1÷(0.2＋0.8÷4)＝1÷0.4＝2.5倍。

#### 問 ap-3-q13

- 問：次に実行する命令のアドレスを保持するレジスタはどれか。
- ア：命令レジスタ
- イ：プログラムカウンタ
- ウ：アキュムレータ
- エ：指標レジスタ
- 正解：イ
- 解説：プログラムカウンタ。

### 3-2 メモリ

#### 問 ap-3-q05

- イ：19
- ウ：50
- エ：55
- 正解：ア
- 解説：0.9×10＋0.1×60＝9＋6＝15ns。

- エ：インタリーブ
- 正解：イ
- 解説：両方に同時に書くのはライトスルー。

#### 問 ap-3-q15

### 3-5 入出力装置

#### 問 ap-3-q10

- 問：平均シーク時間10ms、回転数6,000回転/分の磁気ディスクで、平均回転待ち時間は何msか。
- ア：5
- イ：10
- ウ：15
- エ：20
- 正解：ア
- 解説：1回転は60÷6000＝10ms。平均回転待ちはその半分の5ms。

- ウ：約24Mバイト
- エ：約50Mバイト
