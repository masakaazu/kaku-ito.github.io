## 20-1 LAN と接続装置

### まとめ表

| 装置 | 層 | 見るもの | コリジョン／ブロードキャスト |
| :-: | :-: | :-: | :-: |
| リピータハブ | 物理層 | 電気信号 | どちらも通す |
| L2 スイッチ（ブリッジ） | データリンク層 | MAC アドレス | コリジョンは分ける／ブロードキャストは通す |
| ルータ・L3 スイッチ | ネットワーク層 | IP アドレス | どちらも通さない |
| ロードバランサー | トランスポート層〜 | ポート・URL など | 複数のサーバに振り分け |

### 無線 LAN

#### CSMA/CA（しーえすえむえーしーえー / Carrier Sense Multiple Access with Collision Avoidance）

- 意味：無線 LAN（IEEE 802.11a/b/g/n など）のアクセス制御方式。電波が空いていることを確かめ、さらにランダムな時間待ってから送信して、衝突を避ける
- ポイント：無線では送信中に衝突を検出できないので、有線の CSMA/CD（衝突を検出して再送）ではなく「回避」する。受信側は ACK を返し、届かなければ再送する
- 語の意味：Carrier Sense＝搬送波の検知、Collision Avoidance＝衝突の回避

#### 隠れ端末問題（かくれたんまつもんだい / Hidden Node Problem）

- 意味：二つの端末がどちらもアクセスポイントとは通信できるが、互いの電波（キャリア）は届かず検出できないため、同時に送信してアクセスポイントで衝突しやすくなる問題
- ポイント：対策は RTS/CTS（送信の前に予約を交わす）。逆に、送ってよいのに近くの別の通信を検知して送信を控えてしまうのが「さらし端末問題」（H31 問18）

#### OFDMA（おーえふでぃーえむえー / Orthogonal Frequency Division Multiple Access）

- 意味：一つのチャネルを多数の小さな周波数の単位（サブキャリアのまとまり）に分け、同時に複数の端末に割り当てて通信する多元接続方式。Wi-Fi 6（IEEE 802.11ax）や LTE・5G で使う
- ポイント：OFDM は一つの端末が全部の周波数を使う変調方式、OFDMA はそれを複数の端末で分け合う。端末が多い環境での効率が上がる

### スイッチと冗長化

#### スパニングツリープロトコル（すぱにんぐつりーぷろとこる / STP: Spanning Tree Protocol）

- 意味：複数の経路があるブリッジ（L2 スイッチ）のネットワークで、ブリッジ同士が情報（BPDU）を交換して一部のポートを止め、ループのない木構造にするプロトコル。IEEE 802.1D
- ポイント：ループがあるとブロードキャストが回り続ける（ブロードキャストストーム）。障害時は止めていたポートを使って迂回路を作る。改良版が RSTP（高速）

#### ルートポートと代表ポート（るーとぽーととだいひょうぽーと / Root Port, Designated Port）

- 意味：STP で、各ブリッジからルートブリッジへの最もコストが小さい経路のポートがルートポート。各リンクで、ルートブリッジまでの経路コストが小さいブリッジの側のポートが代表ポート
- ポイント：ルートポートでも代表ポートでもないポートがブロッキング（止める）ポートになる。アクセスポート・トランクポートは VLAN の用語（R5春 問19）

#### IEEE 802.1Q（あいとりぷるいーはちまるにーてんいちきゅー / IEEE 802.1Q VLAN Tagging）

- 意味：イーサネットフレームに VLAN の番号（VLAN ID、12 ビット）を入れたタグを付けて、1本の回線（トランクポート）で複数の VLAN を運ぶ規格
- ポイント：一つの VLAN だけに属し、タグなしで端末をつなぐのがアクセスポート。タグを二重にして事業者網で運ぶのが IEEE 802.1ad（QinQ）

#### リンクアグリゲーション（りんくあぐりげーしょん / Link Aggregation）

- 意味：スイッチ同士などを複数の物理ポート・回線でつなぎ、それらを束ねて一つの論理ポートとして扱う技術。帯域を増やし、1本が切れても通信を続けられる
- ポイント：IEEE 802.1AX（LACP）。MIMO は無線で複数のアンテナを使う技術で別物（R3春 問19）

#### VRRP（ぶいあーるあーるぴー / Virtual Router Redundancy Protocol）

- 意味：複数のルータで一つの仮想的な IP アドレス（と MAC アドレス）を共有し、マスタのルータが故障したらバックアップが引き継ぐことで、デフォルトゲートウェイを冗長化するプロトコル
- ポイント：クライアントのデフォルトゲートウェイの設定を変えずに障害を回避できる（R4秋 問20）。RSTP はスイッチのループ防止、RTSP は動画のストリーミングの制御

#### VXLAN（ぶいえっくすらん / Virtual eXtensible LAN）

- 意味：L2 のイーサネットフレームを UDP でカプセル化し、L3（IP）のネットワークの上に論理的な L2 ネットワークを作るプロトコル。24 ビットの識別子で約 1600 万のネットワークを作れる
- ポイント：データセンターやクラウドのオーバーレイネットワークに使う。VLAN の 4094 個の上限を超えられる（R3秋 問18）

### まとめ表

| 種類 | IPv4 アドレスの範囲 | 用途 |
| :-: | :-: | :-: |
| クラス A・B・C | 0〜191（A・B）、192〜223（C）で始まる | ホストに割り当てる |
| クラス D | 224.0.0.0〜239.255.255.255 | マルチキャスト |
| プライベート | 10/8、172.16/12、192.168/16 | 組織の中で自由に使う |

| ディレクテッドブロードキャスト | ホスト部が全部 1 | 指定したサブネットの全ホスト |

### IPv4 と IPv6

#### サブネットマスク（さぶねっとますく / Subnet Mask）

- 意味：IP アドレスのうち、ネットワーク部（サブネット）を表すビットを 1、ホスト部を 0 にした値。/26 は先頭 26 ビットがネットワーク部
- ポイント：使えるホスト数は「2 の（ホスト部のビット数）乗 − 2」（ネットワークアドレスとブロードキャストアドレスを除く）。255.255.255.192（/26）なら 64 − 2 ＝ 62 台、FFFFFF80（/25）なら 128 − 2 ＝ 126 台
- 例：クラス C を 50 ノードずつの 4 つに分ける → ホスト部 6 ビット（62 台）→ 255.255.255.192（R5秋 問18）

#### IP のフラグメンテーション（あいぴーのふらぐめんてーしょん / IP Fragmentation）

- 意味：送る IP パケットが経路の MTU（一度に送れる最大の長さ）より大きいとき、複数の断片に分割すること。IPv4 では送信元のホストと中継するルータが分割でき、再構築は宛先のホストだけが行う
- ポイント：IPv6 では経路の途中のルータは分割せず、送信元だけが分割する（経路 MTU 探索）。小さな断片で検査をすり抜ける攻撃もある

#### IPv6（あいぴーぶいろく / Internet Protocol Version 6）

- 意味：128 ビットのアドレスを使う IP。アドレス空間は IPv4（32 ビット）の 2 の 96 乗倍。基本ヘッダーは 40 オクテットの固定長で、オプションは拡張ヘッダー（長さは 8 オクテットの整数倍）で付ける
- ポイント：ARP は使わず NDP で MAC アドレスを調べる。ブロードキャストはなく、マルチキャストで代わりをする。途中のルータはフラグメンテーションしない（R4秋 問18）

#### NDP（えぬでぃーぴー / Neighbor Discovery Protocol）

- 意味：IPv6 で、ICMPv6 のメッセージを使って、隣のノードの MAC アドレスの解決（近隣要請・近隣広告）、ルータの発見（ルータ要請・ルータ広告）、アドレスの重複検出などを行うプロトコル
- ポイント：IPv4 の ARP と ICMP のルータ発見などの役割をまとめたもの。偽のルータ広告（RA）による攻撃には RA ガードで対策する

#### ARP（あーぷ / Address Resolution Protocol）

- 意味：IPv4 で、同じネットワークにある相手の IP アドレスから MAC アドレスを調べるプロトコル。ブロードキャストで問い合わせ、該当するホストがユニキャストで答える
- ポイント：DHCP で配られたアドレスを使う前に、自分のアドレスを問い合わせて応答がないことを確かめる（GARP、R5秋 問20）。RARP は逆に MAC アドレスから IP アドレスを得る古いプロトコル

#### ICMP（あいしーえむぴー / Internet Control Message Protocol）

- 意味：IP の通信で起きた誤りの通知や、到達の確認に使うプロトコル。Echo Request／Echo Reply（ping）、Destination Unreachable、Time Exceeded、Redirect などのメッセージがある
- ポイント：TTL が 0 になったら Time Exceeded、より良いルータを教えて経路の変更を求めるのが Redirect（R6秋 問19）。フラグメントの再組立てのタイムアウトも Time Exceeded

### ルーティングとアドレスの使い分け

#### OSPF（おーえすぴーえふ / Open Shortest Path First）

- 意味：ルータ同士がリンクの状態の情報を交換して、同じリンク状態データベースを持ち、それぞれがコストの合計が最小の経路を計算するリンクステート型のルーティングプロトコル。組織の中（AS 内）で使う
- ポイント：RIP-2 はホップ数で経路を決める距離ベクトル型で、30 秒ごとに更新する。可変長サブネットマスクとマルチキャストでの更新は RIP-2 と OSPF の両方にある。リンク状態データベースを使うのは OSPF だけ（R7秋 問19）

#### BGP（びーじーぴー / Border Gateway Protocol）

- 意味：インターネットで、異なる組織のネットワーク（AS: 自律システム）の間で経路の情報を交換するルーティングプロトコル。経路に通った AS の並び（AS パス）を付けて伝える
- ポイント：OSPF は AS の中、BGP は AS の間。誤った経路の広告（BGP ハイジャック）で通信が乗っ取られることがあり、RPKI で経路の正当性を確かめる

#### マルチキャストとエニーキャスト（まるちきゃすととえにーきゃすと / Multicast, Anycast）

- 意味：マルチキャストは一つの宛先アドレスで、参加したグループの複数の相手に同時に届ける通信（IPv4 はクラス D、参加の管理は IGMP）。エニーキャストは同じアドレスを複数の場所に置き、経路上最も近い一つに届ける通信
- ポイント：239.0.1.1 はクラス D でマルチキャストに使える（R5秋 問19）。DNS のルートサーバはエニーキャストで世界中に分散している

#### ブロードキャストアドレス（ぶろーどきゃすとあどれす / Broadcast Address）

- 意味：同じサブネットの全てのホストに届ける宛先のアドレス。255.255.255.255（リミテッドブロードキャスト）と、ホスト部が全部 1 のアドレス（ディレクテッドブロードキャスト、例：192.168.10.255）がある
- ポイント：どちらもサブネット内のブロードキャストに使える（R5春 問20）。ルータはブロードキャストを中継しないので、自分のサブネットを知らない DHCP のクライアントは 255.255.255.255 宛てに送り、DHCP リレーエージェントが中継する（R2 問18）

#### NAPT（なぷと / Network Address Port Translation）

- 意味：複数の内部の端末のプライベートアドレスとポート番号の組を、一つのグローバルアドレスと異なるポート番号の組に変換して、インターネットと通信させる技術。IP マスカレードとも呼ぶ
- ポイント：NAT はアドレスだけを1対1で変換、NAPT はポート番号も変換して1対多にする。外から内への通信は、変換表がないと届かない

### TCP と QUIC

#### TCP（てぃーしーぴー / Transmission Control Protocol）

- 意味：トランスポート層で、コネクションを確立し、順序番号と確認応答、再送、ウィンドウ制御（バイト単位）によって、データを順番どおり確実に届けるプロトコル
- ポイント：TCP ヘッダーにあるのは送信元・宛先のポート番号、順序番号、確認応答番号、ウィンドウサイズなど。IP アドレス・TTL・プロトコル番号は IP ヘッダーにある（R6春 問18）

#### QUIC（くいっく / QUIC）

- 意味：UDP の上で、TLS 1.3 による暗号化とコネクションの確立をまとめて行い、複数のストリームを並行して送る、トランスポート層のプロトコル。HTTP/3 で使う（RFC 9000）
- ポイント：TCP＋TLS より接続が速く、一つのストリームのパケットの紛失が他のストリームを止めない。ほとんどのヘッダーも暗号化されるので、途中の機器で中身を検査しにくい

### アプリケーションのプロトコル

#### DHCP（でぃーえいちしーぴー / Dynamic Host Configuration Protocol）

- 意味：ネットワークにつないだ端末に、IP アドレス、サブネットマスク、デフォルトゲートウェイ、DNS サーバなどの設定を自動で配るプロトコル。DISCOVER・OFFER・REQUEST・ACK の順でやり取りする
- ポイント：クライアントは最初、自分のアドレスもサブネットも知らないので、255.255.255.255 宛てのブロードキャストで問い合わせる。別のサブネットのサーバへはルータの DHCP リレーエージェントが中継する

#### HTTP（えいちてぃーてぃーぴー / Hypertext Transfer Protocol）

- 意味：Web のクライアントとサーバの間のプロトコル。リクエストはリクエスト行・ヘッダー・メッセージボディからなり、応答はステータスコードで結果を示す
- ポイント：フォームのデータは GET ならリクエスト行（URL のクエリ）、POST ならメッセージボディに入る（R7春 問20）。ステータスコードは 1xx 情報、2xx 成功、3xx リダイレクト、4xx クライアントの誤り、5xx サーバの誤り（R7秋 問20）

#### Ajax・REST・GraphQL（えいじゃっくす・れすと・ぐらふきゅーえる / Ajax, REST, GraphQL）

- 意味：Ajax は JavaScript で、ページを読み直さずにサーバと非同期に通信して画面の一部を書き換える技術。REST は URL で表したリソースを HTTP のメソッドで操作する API の設計の考え方。GraphQL は、クライアントが必要なデータの形を問合せで指定して一度に取得できる API の問合せ言語
- ポイント：地図のスクロールや検索候補の逐次表示は Ajax（R7秋 問18）。DOM は HTML の文書を操作するためのモデル、SAX は XML を先頭から順に読む解析の方式

#### サブミッションポート（さぶみっしょんぽーと / Submission Port）

- 意味：メールソフトがメールサーバにメールを送信（投稿）するときに使う TCP 587 番ポート。SMTP 認証で利用者を確認してから受け付ける
- ポイント：プロバイダが 25 番ポートで外へ直接送る通信を止める（OP25B）迷惑メール対策と組み合わせて、正規の利用者は 587 番で送る（R6春 問19）

#### SNMP（えすえぬえむぴー / Simple Network Management Protocol）

- 意味：ネットワーク機器の状態の情報（MIB）を、管理する側（マネージャ）が機器（エージェント）から取得・設定するプロトコル。機器の側から異常を自発的に知らせるのがトラップ
- ポイント：GetRequest は取得、SetRequest は設定、Response は応答、SNMPv2-Trap はエージェントが自発的に通知（H31 問20）。SNMPv3 は利用者の認証と暗号化ができる

#### SNTP（えすえぬてぃーぴー / Simple Network Time Protocol）

- 意味：NTP を簡単にしたもので、PC などがネットワーク上の時刻サーバから時刻を取得して合わせるプロトコル（UDP 123 番）
- ポイント：ログの時刻をそろえるのに重要（#12）。NNTP はネットニュース、RTCP は RTP の制御、TFTP は認証のない簡単なファイル転送（R4春 問19）

## 20-4 通信サービス・モバイル・IoT

### まとめ表

| 名前 | しくみ |
| :-: | :-: |
| PPPoE | PPP をイーサネットの上で使い、利用者の認証をしてインターネットに接続 |
| IPoE | 認証の手順なしに、IP をそのまま（ネイティブに）流して接続（IPv6 で使う） |
| IPsec | ネットワーク層で IP パケットを暗号化・カプセル化 |
| L2TP | データリンク層（PPP）のフレームをトンネルで運ぶ |
| IP-VPN | 通信事業者の閉じた IP 網で拠点をつなぐ |
| インターネット VPN | インターネットの上に IPsec などで暗号化したトンネルを作る |
| 広域イーサネット | 事業者の網で拠点を L2 でつなぐ |

### 接続とトンネル

#### PPPoE（ぴーぴーぴーおーいー / PPP over Ethernet）

- 意味：電話回線などのシリアル回線で使う PPP の、コネクションの確立や認証、データ転送の仕組みを、イーサネット（LAN）の上で実現するプロトコル
- ポイント：光回線のインターネット接続で、利用者 ID とパスワードの認証に使われてきた（H31 問19）。IPoE は PPPoE の認証の手順を使わずに IP を直接流す方式で、混雑しにくい

#### トンネリングプロトコル（とんねりんぐぷろとこる / Tunneling Protocol）

- 意味：あるプロトコルのデータを別のプロトコルで包んで（カプセル化して）運ぶプロトコル。IPsec はネットワーク層の IP パケットを IP パケットでカプセル化できる。L2TP と PPTP はデータリンク層の PPP のフレームを運ぶ
- ポイント：ネットワーク層のパケットを対象に IP でカプセル化するのは IPsec（R6秋 問18）。L2TP は暗号化の機能を持たないので、IPsec と組み合わせる（L2TP/IPsec）

### モバイルと IoT

#### 5G の SA 方式と NSA 方式（ふぁいぶじーのえすえーほうしきとえぬえすえーほうしき / Stand Alone, Non-Stand Alone）

- 意味：NSA 方式は、制御の信号を 4G（LTE）の設備で扱い、5G の基地局をデータの通信に使う方式。SA 方式は、5G の基地局と 5G のコアネットワークだけで動く方式
- ポイント：ネットワークスライシングや超低遅延などの 5G 本来の機能は、5G コアを使う SA 方式で実現する

#### ネットワークスライシング（ねっとわーくすらいしんぐ / Network Slicing）

- 意味：一つの物理的な通信網を、用途ごとに性能（帯域・遅延・同時接続数）が違う複数の仮想的なネットワーク（スライス）に分けて提供する 5G の技術
- ポイント：自動運転向けの低遅延のスライス、IoT 向けの多数接続のスライスなどを分けられる。スライスの間の分離が破られないことがセキュリティの要件になる

#### LPWA（えるぴーだぶりゅえー / Low Power Wide Area）

- 意味：通信速度は低いが、少ない電力で数 km〜数十 km の広い範囲を通信できる、IoT 向けの無線通信の総称。LTE-M・NB-IoT（携帯電話の免許の帯域）と、LoRaWAN・Sigfox・Wi-SUN（免許の要らない帯域）がある
- ポイント：電池で何年も動くセンサーに向く。NB-IoT は LTE-M より帯域が狭く、より低速・低消費電力で、移動しながらの通信には向かない

#### IMEI（あいえむいーあい / International Mobile Equipment Identity）

- 意味：携帯電話などの端末そのものに付けられた、世界で一意の 15 桁の識別番号
- ポイント：SIM の加入者を表す IMSI とは別。盗まれた端末の利用を止めるのに使われる

#### 伝送時間の計算（でんそうじかんのけいさん / Transmission Time Calculation）

- 意味：回線で送れるデータ量や時間を、「回線速度 × 伝送効率」を実際に使える速度として計算すること。バイトはビットにすると 8 倍
- 例：1G ビット/秒・効率 50% → 5 × 10⁸ ビット/秒使える。1台が 1 分に 6M バイト ＝ 48 × 10⁶ ビット → 1 秒に 0.8 × 10⁶ ビット。5 × 10⁸ ÷ 0.8 × 10⁶ ＝ 625 台（R5春 問18）

#### 問 sc-20-r05h-q18

- 問：1 台のサーバと複数台のクライアントが，1G ビット／秒の LAN で接続されている。業務のピーク時には，クライアント 1 台につき 1 分当たり 6M バイトのデータをサーバからダウンロードする。このとき，同時使用してもピーク時に業務を滞りなく遂行できるクライアント数は何台までか。ここで，LAN の伝送効率は 50%，サーバ及びクライアント内の処理時間は無視できるものとし，1G ビット／秒＝10⁹ ビット／秒，1M バイト＝10⁶ バイトとする。
- ア：10
- イ：625
- ウ：1,250
- エ：5,000
- 正解：イ
- 解説：使える速度は 10⁹ × 0.5 ＝ 5 × 10⁸ ビット/秒。1 台は 6 × 10⁶ × 8 ÷ 60 ＝ 8 × 10⁵ ビット/秒。5 × 10⁸ ÷ 8 × 10⁵ ＝ 625 台。
- アの意味：計算の単位を誤った値。
- イの意味：正しい。
- ウの意味：伝送効率 50% を掛け忘れた値。
- エの意味：バイトをビットに直さず（8 倍せず）、効率も掛けた値。

#### 問 sc-20-o07
